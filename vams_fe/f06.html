설정 (관리자)

SettingsPage가 단일 라우트(/settings) 안에서 카테고리별 솔루션 작업 설정(WorkConfig)·솔루션별 연동 설정(Integration)·사용자 권한 설정(UserRole) 3개 탭을 제공하는 관리자 설정 화면입니다. 연동 탭은 드래프트/베이스라인 스토어 기반 dirty 가드와 즉시 저장 모델을, 권한 탭은 낙관적 업데이트 기반 역할 변경을 구현하며 권한 3계층(일반운영자/중간관리자/시스템관리자) 정책과 연동됩니다.

기능 개요

설정 메뉴는 src/features/settings/routes.ts가 self-export 하는 단일 라우트 settings로 앱 셸(AppShellContainer) 하위에 등록되며, SettingsPage.vue가 공용 세그먼트형 탭 컴포넌트(VTabs, Reka UI TabsRoot 합성)로 3개 탭을 렌더합니다. 탭 구성은 SETTINGS_TAB_ITEMS 상수에 정의된 카테고리별 솔루션 작업 설정(work) · 솔루션별 연동 설정(integration) · 사용자 권한 설정(roles)이며, 활성 탭은 딥링크 없이 페이지 내부 activeTab ref가 소유합니다. 탭 전환 시 handleTabChange가 가드를 거쳐, 차단되면 마지막 통과 탭(committedTab)으로 롤백하는 구조입니다.

탭1(WorkConfig)은 장르/세부장르 필터 + DataTable + 페이지네이션으로 카테고리 작업 항목을 조회하고 CategoryItemFormModal로 항목 추가/수정을 수행합니다. 솔루션 마스터는 API(E10 /solutions) 응답이 없으면 FE 상수 SETTING_SOLUTIONS(포스터·썸네일·자막·구간마킹·얼굴인식·골라보기·하이라이트·개인화 포스터/하이라이트 9종)로 폴백합니다. 탭2(Integration)는 전체 자동 연동 마스터 스위치 + SolutionIntegrationCard 9장으로 구성되며, useSettingsEditorStore의 드래프트/베이스라인 이중 상태로 dirty를 판정하고 토글·체크 변경마다 전체 스냅샷을 PUT 하는 즉시 저장 모델을 씁니다. 저장 실패 시 직전 저장 상태로 자동 복원됩니다.

탭3(UserRole)은 역할 필터(VSelect) + 키워드 검색 + UserRoleTable로 사용자 목록을 조회하고, 역할 변경(E8 PUT /users/:id/role)은 Vue Query 캐시를 먼저 갱신하는 낙관적 업데이트로 처리합니다. 역할 코드는 OPERATOR/MANAGER/ADMIN 3계층으로, 앱 전역의 권한 판정 컴포저블 useCan(authStore role 기반)이 참조하는 권한 정책의 관리 지점입니다. 모든 API는 SETTINGS_API·USER_API 등 추상 경로 상수를 경유하고 dev에서는 MSW가 인터셉트하며, DTO→도메인 변환은 api/adapters/settings.ts 단일 지점에서만 수행합니다.

2026-08 공통 컴포넌트 정합 라운드에서 설정 화면도 소폭 조정되었습니다. 공통 DataTable에 Figma Table Size 축(size — medium 60 / small / xsmall)이 도입되면서 기본 행 높이가 60px가 되었는데, 설정 탭의 표는 Figma Size 확정 전까지 현행 48px를 유지해야 해 SettingsPage.vue가 --v-table-row-h: var(--table-cell-h-small)로 명시 핀(P2b)을 겁니다. 연동 카드의 스위치도 VSwitch size를 구 명칭 md에서 Figma Draft 명칭 medium으로 교체했습니다. 한편 LNB는 v0.7 반영으로 'AI 개인화'가 개인화 포스터/개인화 하이라이트로 2분할되고 얼굴인식이 분리되어 13개 메뉴가 되었지만, 연동 탭의 솔루션 마스터(SETTING_SOLUTIONS)는 여전히 9종으로 LNB 메뉴 수와 직접 대응하지 않습니다(모니터링·설정은 솔루션이 아니고, AI Pick은 솔루션 목록에 없습니다).

설계 포인트 — dirty 가드 이중 결선
연동 탭의 미저장 드래프트 보호는 두 경로에 결선됩니다. 같은 페이지 안의 탭 전환은 useSettingsGuard.guardTabChange가, 다른 메뉴로의 라우트 이탈은 onBeforeRouteLeave 훅이 각각 확인 모달(useConfirm)을 띄우고, 이동을 확정하면 resetIntegration()으로 드래프트를 폐기합니다. 한편 라우트 자체의 권한 차단 meta는 제거되어 있어(비침습 원칙) 화면 접근 제어보다 데이터 정합 보호에 무게를 둔 구현입니다.

관계. SettingsPage가 탭 셸로 3개 탭 컴포넌트를 소유하고, 연동 탭만 Pinia 드래프트 스토어(useSettingsEditorStore)를 씁니다. 나머지 탭은 Vue Query 캐시(서버 상태)와 로컬 ref만으로 동작하는 얇은 구조입니다.

핵심 코드

src/features/settings/pages/SettingsPage.vue — 탭 전환 가드와 committedTab 롤백
/** 활성 탭 (D1: 내부 상태, 딥링크 없음). */
const activeTab = ref<SettingsTab>('work')
/** 가드를 통과한 마지막 탭 — 차단 시 롤백 기준 */
let committedTab: SettingsTab = 'work'

const { guardTabChange } = useSettingsGuard()

async function handleTabChange(newTab: string) {
  if (newTab === committedTab) return // 현재 탭 재클릭 = 무반응

  // 이 시점 activeTab은 이미 newTab(v-model) — 가드 차단 시 롤백
  const allowed = await guardTabChange(committedTab, newTab)
  if (allowed) {
    committedTab = newTab as SettingsTab
  } else {
    activeTab.value = committedTab // 차단 시 이전 탭으로 롤백
  }
}
src/features/settings/stores/useSettingsEditorStore.ts — 솔루션 토글과 마스터 파생 동기화(V7)
/**
 * 솔루션 개별 토글.
 * 전체 자동 연동(마스터)은 "모든 솔루션이 ON일 때만 ON"으로 파생 동기화(V7).
 * → 하나라도 OFF되면 마스터 OFF / 개별 토글로 전부 ON이 되면 마스터 ON.
 */
function toggleSolution(code: SettingSolutionCode, enabled: boolean): void {
  if (!integrationDraft.value) return
  const solutions = integrationDraft.value.solutions.map((s) =>
    s.code === code ? { ...s, enabled } : s,
  )
  // 마스터 = 모든 솔루션 ON일 때만 ON (하나라도 OFF면 OFF)
  const masterEnabled = solutions.every((s) => s.enabled)
  integrationDraft.value = { ...integrationDraft.value, solutions, masterEnabled }
}
src/features/settings/composables/useSettingsGuard.ts — 탭2 dirty 확인 가드
async function guardTabChange(fromTab: string, toTab: string): Promise<boolean> {
  if (fromTab !== 'integration' || !integrationDirty.value) {
    return true // 탭2 아니거나 dirty 아님 → 바로 허용
  }
  if (fromTab === toTab) return false // 현재 탭 재클릭 = 무반응

  const ok = await confirm({
    titleKey: 'settings.common.leaveConfirm.title',
    messageKey: 'settings.common.leaveConfirm.message',
    confirmKey: 'settings.common.leaveConfirm.confirm',
    cancelKey: 'settings.common.leaveConfirm.cancel',
  })

  if (ok) {
    store.resetIntegration() // 이동 확인 시 드래프트 폐기
  }
  return ok
}
