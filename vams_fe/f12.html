AI Pick (씬 추출)

운영자가 영상 파일을 직접 올려 AI 씬 추출을 의뢰하고 결과 장면 목록을 확인하는 메뉴입니다. 다른 메뉴와 달리 검색·필터 없이 4개 파라미터만 쓰는 단순 목록이며, 생성 중인 작업이 있을 때만 지수 백오프로 목록을 재조회하는 폴링 폴백을 갖습니다.

기능 개요

AI Pick은 영상 파일을 업로드하면 AI가 의미 단위 장면(씬)을 잘라 주는 기능입니다. 다른 메뉴가 상위 시스템에서 내려온 작업을 검수하는 구조인 데 비해, Pick은 운영자가 작업의 시작점이라 목록 화면의 성격 자체가 다릅니다. 목록(PickListPage)은 공용 listQuery 스토어를 쓰되 요청에는 serviceType·page·size·sort 4개 키만 실어 보냅니다. 검색어·상태칩·장르·조회기간·긴급 여부는 이 메뉴의 계약에 없어 쿼리 빌더에서 아예 읽지 않고, 다른 메뉴에서 영속된 PRIORITY 정렬값이 남아 있을 수 있으므로 방어적으로 LATEST로 접습니다. 그래서 공통 toListQuery를 재사용하지 않고 전용 빌더 toPickListQuery를 둡니다.

업로드(PickUploadModal + usePickUpload)는 empty → uploading → uploaded → submitting 4단계 상태기계입니다. 파일 제약은 .mp4 단일 확장자·video/mp4 MIME·2 GiB 상한이며, 서버 왕복 전에 FE가 선제 검증해 부적합하면 empty를 유지합니다. 업로드 진행률은 표시하지 않고 indeterminate 로딩만 보여 주며(실측 근거), 서버 오류 코드(VAMS-PCK-101/102)는 토스트 메시지 키로 매핑합니다. 업로드 취소는 AbortController로 처리하고 AbortError는 실패 토스트에서 제외합니다.

업로드 직전에는 useVideoFileMeta가 <video> 엘리먼트로 메타(재생시간·해상도)를 probe 합니다. 미리보기 용도가 아니라 메타 추출만이 목적이라 Object URL을 만들자마자 성공·실패·타임아웃 어느 경로로 끝나든 즉시 revoke 하고 엘리먼트의 src를 떼어 냅니다. probe는 6초 타임아웃을 두고 실패해도 업로드를 막지 않으며, 값이 없으면 모달에 -로 표기합니다.

목록 폴링(usePickListPolling)은 별도 프레임워크를 도입하지 않고 vue-query의 함수형 refetchInterval과 순수 함수 nextPickPollInterval()만으로 구현했습니다. 정지 조건(진행 중 작업 0건 · 오버레이 열림 · 탭 숨김 · 연속 실패 3회 · 전체 30분 상한)과 상한 캡 판정은 순수 함수가 담당하고, 실제 백오프 증가(5s → 10s → 20s → 30s)는 watch(rows)에서만 수행합니다. refetchInterval 콜백 안에서 값을 올리면 vue-query가 옵저버 갱신마다 그 콜백을 평가해 실제 tick과 무관하게 몇 번 만에 30초 캡에 도달해 버리기 때문입니다(QA에서 확인된 결함). 진행 중이던 작업이 완료·실패로 전이하면 스냅샷 비교로 감지해 토스트를 띄웁니다.

상세(PickDetailPage)는 /pick/:jobId bare 라우트의 읽기 전용 화면이라 dirty·이탈 가드가 없습니다. 데이터는 2단 조회로 얻습니다 — jobId로 작업 이력과 contentId를 확보한 뒤, 그 contentId를 키로 영상 파일 정보와 장면 목록을 조회합니다(enabled로 2단을 게이팅). 장면 목록(PickSceneList)은 Pick 번호·장면 시간·타임코드·설명을 보여 주고, 권장 구간(60~180초)을 벗어난 장면은 경고 스타일로 강조합니다. 결과 다운로드는 공통 httpGetBlob을 쓰며 Content-Disposition의 RFC 5987 filename*을 우선 해석해 한글 파일명을 보존합니다.

참고 — 계약 상태와 회귀 테스트
PICK_API의 일부 경로(일괄 삭제·상태 조회)는 아직 [가설]이며 BE 실경로 가설이 주석으로 병기되어 있습니다. 이번 갱신에서 AI Pick 유닛 테스트 44건이 추가되어 공통 HTTP 파서, 상태 fold, 그리고 폐기된 금지 필드(작업이력의 engineVersion — Flipbook 삭제 + API v1.0.3 폐기)가 되살아나지 않도록 회귀 방어하고 있습니다.

/**
 * 순수 함수 — 5s→10s→20s→30s(상한) 캡 + 정지 조건(진행 0건/overlay/hidden/연속실패/전체상한) 판정만
 * 담당. 실제 지수 백오프 escalation(×2)은 호출부가 currentMs 를 갱신해 다음 tick 에 주입한다.
 */
export function nextPickPollInterval(ctx: NextPollCtx): number | false {
  if (!ctx.hasGenerating) return false
  if (ctx.overlayOpen) return false
  if (ctx.hidden) return false
  if (ctx.errorStreak >= PICK_POLL.errorStreakStop) return false
  if (ctx.elapsedMs >= PICK_POLL.totalCapMs) return false
  return Math.min(ctx.currentMs, PICK_POLL.maxMs)
}

src/features/pick/composables/useVideoFileMeta.ts — Object URL 누수 없는 메타 probe
const PROBE_TIMEOUT_MS = 6000

function cleanup(url: string, video: HTMLVideoElement): void {
  URL.revokeObjectURL(url)
  inFlightUrls.delete(url)
  video.removeAttribute('src')
  video.load()
}

/** 실패해도 업로드를 막지 않는다 — 메타는 null → 모달 표기 '-' */
async function probe(file: File): Promise<ProbedVideoMeta> {
  const url = URL.createObjectURL(file)
  const video = document.createElement('video')
  video.preload = 'metadata'
  return new Promise<ProbedVideoMeta>((resolve) => {
    const timer = setTimeout(() => { cleanup(url, video); resolve(EMPTY_META) }, PROBE_TIMEOUT_MS)
    video.onloadedmetadata = () => {
      clearTimeout(timer)
      const meta: ProbedVideoMeta = {
        durationSec: Number.isFinite(video.duration) ? video.duration : null,
        width: video.videoWidth || null,
        height: video.videoHeight || null,
      }
      cleanup(url, video)
      resolve(meta)
    }
    video.onerror = () => { clearTimeout(timer); cleanup(url, video); resolve(EMPTY_META) }
    video.src = url
  })
}
src/features/pick/queries.ts — 다른 메뉴와 다른 4키 전용 쿼리 빌더
// ⚠ toListQuery(thumbnail/highlight) 재사용 금지 — Pick 전용 4키 빌더.
//    검색/필터/조회기간/긴급 파라미터 미전송.
export interface PickListQueryParams {
  serviceType: 'AIPICK'
  page: string
  size: string
  sort: 'createDate,desc' | 'createDate,asc'
}

export function toPickListQuery(s: SearchData): PickListQueryParams {
  // PRIORITY 정규화 — 영속값이 다른 메뉴 값으로 남아 있을 수 있으므로 방어적으로 fold.
  const sortType: SortType = s.sortType === 'PRIORITY' ? 'LATEST' : s.sortType
  return {
    serviceType: 'AIPICK',
    page: String(s.page),
    size: String(s.size),
    sort: sortType === 'OLDEST' ? 'createDate,asc' : 'createDate,desc',
  }
}
src/features/pick/composables/usePickUpload.ts — FE 선제 검증과 에러 코드 매핑
/** 서버 업로드 에러 코드(VAMS-PCK-1xx) → 토스트 messageKey 매핑 */
function mapUploadErrorKey(e: unknown): string {
  const code = (e as { body?: { error?: { code?: string } } } | undefined)?.body?.error?.code
  if (code === 'VAMS-PCK-101') return 'pick.toast.uploadTypeError'
  if (code === 'VAMS-PCK-102') return 'pick.toast.uploadSizeError'
  return 'pick.toast.uploadFail'
}

/** FE 선제 검증(서버 왕복 없음) — 확장자/MIME 불일치 또는 2GiB 초과 시 phase 는 'empty' 유지 */
function validateFile(file: File): boolean {
  const dotIdx = file.name.lastIndexOf('.')
  const ext = dotIdx >= 0 ? file.name.slice(dotIdx).toLowerCase() : ''
  const extOk = (PICK_FILE_CONSTRAINTS.extensions as readonly string[]).includes(ext)
  const mimeOk =
    !file.type || (PICK_FILE_CONSTRAINTS.mimeTypes as readonly string[]).includes(file.type)
  if (!extOk || !mimeOk) { toast.error({ messageKey: 'pick.toast.uploadTypeError' }); return false }
  if (file.size > PICK_FILE_CONSTRAINTS.maxBytes) { /* 크기 초과 토스트 */ return false }
  return true
}
src/api/http.ts — 한글 파일명 보존 Blob 다운로드(공통 인프라 보강)
export async function httpGetBlob(path: string): Promise<{ blob: Blob; filename: string | null }> {
  const res = await fetch(new URL(path, window.location.origin).toString(), {
    method: 'GET', credentials: 'include',
  })
  if (!res.ok) { /* status·body 를 실은 에러로 throw */ }
  const disposition = res.headers.get('Content-Disposition')
  // RFC 5987 filename*=UTF-8''<percent-encoded> 우선 해석(한글 파일명) — 없으면 ASCII filename="..." 폴백.
  const extMatch = disposition ? /filename\*=UTF-8''([^;]+)/i.exec(disposition) : null
  const asciiMatch = disposition ? /filename="?([^";]+)"?/.exec(disposition) : null
  // 잘못된 percent-encoding(`%ZZ` 등)이 URIError 를 던져도 다운로드가 실패 처리되지 않도록 방어.
  const decoded = extMatch?.[1] ? safeDecodeURIComponent(extMatch[1]) : null
  const filename = decoded ?? asciiMatch?.[1] ?? null
  return { blob: await res.blob(), filename }
}
