AI 자막 편집기

자막 작업 목록에서 bare 풀스크린 편집기(SubtitleEditPage)로 진입해, wavesurfer 파형 타임라인·편집 단축키(S/D/A/F/Q/W)·KRCC/KT 변환·찾기/바꾸기·동기화 시프트와 20종 이상의 편집 다이얼로그로 AI 생성 자막을 검수·편집하고 SMI로 최종 저장(연동)하는 본 과제 최대 규모 기능입니다.

기능 개요

AI 자막 엔진(어뮤즈랩 협업 alfaeditor)이 생성한 자막을 운영자가 사람 검수로 다듬는 화면입니다. 자막 작업 목록(SubtitleListPage, LNB 하위 /subtitle)에서 행을 선택하면 meta.layout:'bare' 풀스크린 라우트 /subtitle/:jobId/edit의 SubtitleEditPage로 진입합니다. 화면은 헤더 / 자막 리스트 + 영상·편집 패인 / 하단 전폭 파형 타임라인 3구역으로 구성되며, Pinia setup 스토어 subtitleEditor가 currentTimeMs·selectedLineId·playing을 단일 진실로 삼아 리스트·영상·파형 3자를 동기화합니다. 모든 seek/선택은 SyncSource(list/video/waveform/find/keyboard 등) 소스 태그를 달아 무한 이벤트 루프를 차단합니다.

진입 시 스토어 init()이 E7 점유 확인 → E1 콘텐츠 메타 → E4 임시저장 복구 순으로 alfaeditor API를 호출하고, 타인이 편집 중(RUNNING)이면 sessionState='denied'로 차단합니다. 편집 락은 WebSocket 세션(useSubtitleSocket, WS /alti/socket) 자체가 담당하며, 서버의 temporary_storage 메시지(5분 주기)가 자동 임시저장(E5)을 트리거합니다. 파형은 useWaveform이 wavesurfer.js + Regions 플러그인으로 라인 ↔ region을 양방향 동기화하고, 빈 구간 드래그로 새 자막 라인을 삽입할 수 있습니다. 편집 트랜잭션(텍스트 적용·타임코드 변경·분할/병합 등)은 useEditHistory 메멘토 스택(최대 100단계)에 적재되어 Ctrl+Z / Ctrl+Shift+Z로 undo/redo 됩니다.

편집 도구는 Subtitle Edit 기반 단축키(useSubtitleShortcuts — S 시작시간, D 종료시간, A/F 다음·이전 줄, Q/W 이전·다음 병합, Ctrl+R 자동 줄바꿈)와 찾기/이동·찾아 바꾸기·다중 바꾸기·선택해서 바꾸기·오류 일괄수정·간격 채우기·동기화 시프트·타임코드·색상/글꼴·다운로드(검수 전 SRT / 완료 SMI) 등 다이얼로그 18종 + 컨텍스트 메뉴·팝업으로 제공됩니다. KRCC 바꾸기/KT 포맷 변환(useSubtitleTransform)은 서버 왕복 없는 FE 정규식 연산이며 비가역(history 미적재) 정책입니다. 검수 완료 시 requestLink()가 buildSmi()로 완성 SMI 문자열을 만들어 E6로 최종 저장하고 작업 상태를 연동대기(W)로 전이합니다.

설계 포인트 — 대량 트랙 성능
700줄 이상 트랙에서 편집 1회마다 reactive 배열 deep watch가 CPU를 크게 점유하는 문제를, in-place 편집은 linesRevision 카운터로 얕게 트리거하고 삭제/삽입은 raw 배열에서 renumber 후 배열 참조를 1회만 재할당(reactive write n+1 → 1)하는 방식으로 해결했습니다. 또한 문자키 단축키는 e.key 대신 물리 키코드 e.code로 판정해 한국어 IME 상태에서도 동작합니다.

// rev.3 진입 시퀀스 — E7 status → E1 content → E4 temporary(복구)
const statusResult = await getStatus(cId, langForE7)            // E7: 점유 확인
if (statusResult.state === 'RUNNING') {
  sessionState.value = 'denied'                                 // 타인 점유 → 진입 차단
  trackStatus.value = 'ready'
  return
}

const meta = await fetchContent(cId, langForE7)                 // E1: 콘텐츠 메타
contentId.value = meta.contentId
language.value = meta.language                                  // E1 응답 language가 정본
videoUrl.value = meta.videoUrlPath
audioUrl.value = meta.audioUrlPath

let lines: SubtitleLine[] = []
const tmp = await fetchTemporary(meta.contentId, meta.language) // E4: 임시저장 복구
if (tmp !== null) {
  lines = tmp.captions                                          // E4 200: 복구
    .map((c, i) => toSubtitleLine(c, i))
    .sort((a, b) => a.startMs - b.startMs)
    .map((l, i) => ({ ...l, no: i + 1 }))
} else if (meta.initialCaptions && meta.initialCaptions.length > 0) {
  lines = meta.initialCaptions.map((c, i) => toSubtitleLine(c, i)) // 204: 폴백
}

//   'ㅁ'/'ㄹ' 같은 한글 자모로 들어와 case 'a'/'f' 가 영구 미매칭.
// 단일키(Q/W/A/F/S/D)는 text-input 컨텍스트에서 절대 발동 금지(오발동 방지 핵심).
if (!ctrl && !shift && !alt) {
  switch (code) {
    case 'KeyQ':                             // Q → 이전 줄과 병합
      store.runLineOp('mergePrev', selId); return
    case 'KeyW':                             // W → 다음 줄과 병합
      store.runLineOp('mergeNext', selId); return
    case 'KeyS':                             // S → 시작 시간 = 플레이헤드
      store.setStartToPlayhead(selId); return
    case 'KeyD':                             // D → 종료 시간 = 플레이헤드
      store.setEndToPlayhead(selId); return
  }
}
src/features/subtitle/edit/composables/useSubtitleTransform.ts — KT 포맷 변환 순수함수 (서버 왕복 없음)
/**
 * applyKtFormatToLines: 각 라인 텍스트의 문장 끝 마침표·느낌표 일괄 제거.
 * 와이어 ST-007 §2 변환 규칙. 비가역 — history push 없음(아키 §4.4 정책).
 */
export function applyKtFormatToLines(lines: SubtitleLine[]): {
  lines: SubtitleLine[]
  changedCount: number
} {
  const re = /[.!]+$/gm                      // 다중행 고려, 각 줄 끝의 [.!] 제거
  let changedCount = 0
  const nextLines = lines.map((l) => {
    const next = l.text.replace(re, '')
    if (next === l.text) return { ...l }
    changedCount++
    return { ...l, text: next }
  })
  return { lines: nextLines, changedCount }
}
