AI 썸네일 검수

구간 썸네일(SECTION)·10초 썸네일(GTV/GTM) 작업을 검수하는 워크플로입니다. 공통 리스트 패턴의 목록에서 bare 풀스크린 상세로 진입해, working copy 모델 위에서 대표 구간 지정·구간 썸네일 프레임 교체를 수행하고 저장·재생성·C-Cube 연동까지 이어집니다.

기능 개요

AI 썸네일 메뉴는 AI 엔진이 VOD 콘텐츠에서 자동 추출한 썸네일 작업을 검수하는 화면입니다. 작업유형은 두 가지로, thumbKind가 SECTION이면 구간 썸네일(콘텐츠의 구간별 대표 이미지, 편집 가능), GTV/GTM이면 10초 썸네일(읽기전용 정보 카드)로 분기합니다 — 이 판정은 domain/thumbnail.ts의 TEN_SEC_KINDS·isSectionKind/isTenSecKind 단일 소스를 공유합니다. 목록 화면 ThumbnailListPage는 전 메뉴 공통 리스트 패턴을 따르며 검색어·상태칩 7종(전체/대기/검수필요/실패/검수중/검수완료/연동완료 — domain/statusChip.ts 공통 SSOT)·장르/세부장르 2단 필터·작업유형 필터(전체/구간/10초, 10초 선택 시 thumbKinds='GTV,GTM')·조회기간·긴급만 보기를 제공하고, 정렬 옵션·기본값은 sortOrderFor(chip)가 선택 상태칩에 따라 동적으로 바꿉니다(전체=우선순위 PRIORITY 기본, 연동완료=최신입수순, 그 외=오래된입수순). 검색 조건은 createListQueryStore 기반 스토어로 영속되고(페이지당 건수는 공통 정책 10/20/50), 행 선택 시 우측 패널(ThumbnailDetailPanel)에서 AI 작업이력과 콘텐츠 정보를 확인합니다.

목록 화면의 껍데기는 8개 메뉴가 복제하던 마크업을 걷어내고 공통 컴포넌트로 교체됐습니다. ID/명 2단 셀은 IdNameCell, 행 [검수] 버튼은 TableActionButton(Figma Cell Item 실측 min-width 64), 로딩은 TableLoading, 0건 화면은 ListEmptyState의 3-way 분기(로드실패 > 필터결과없음 > 데이터없음, store.hasActiveFilters 주입)를 씁니다. 조회기간 프리셋(shared/lib/datePreset.ts)·달력 팝오버(shared/components/composite/date-picker/)·일괄액션 활성 판정(shared/composables/useBulkActionEligibility.ts)도 feature 로컬 복제본을 지우고 shared 단일 구현을 참조합니다. 컬럼 폭 모델은 패널 개폐로 두 벌을 손튜닝하던 방식(compact) 대신 §8 grow 관용구로 재선언됐습니다 — 콘텐츠는 잉여를 전량 흡수하는 주열(grow:1, basis=min), 시리즈는 부족할 때만 min까지 양보하는 보조열(grow:0), 긴급 65·장르·작업유형·입수일시·상태·액션은 뷰포트 tier(useMediaQuery('(max-width: 1280px)'))별 고정폭이라 컨테이너 폭만으로 패널 개폐 상태가 재현됩니다. 우측 패널도 공통 PanelInfoTable·GenrePath·UrgentBadge·PanelActionButton으로 바뀌었고, 작업이력의 엔진 버전 항목은 제거됐습니다(GUI 정본 삭제 + API 리스트 v1.0.3 폐기 표시 → v1.0.4 공통#3 응답 필드 실삭제). 상태 아이콘도 GUI 정본 실측에 맞춰 대기=빈 링(도넛), 검수완료=민트 전용 자산으로 교체됐습니다.

목록의 행을 열면 /thumbnail/:jobId?kind=… 라우트의 ThumbnailDetailPage(상세화면 S4)로 이동합니다. 이 라우트는 meta.layout:'bare' 풀스크린으로 LNB·앱 헤더 없이 렌더되며, 상단은 공통 DetailHeader+DetailHeaderActions(초기화·재생성·저장·연동)입니다. 구간 썸네일 상세(ThumbnailSegmentDetail)는 구간 카드 그리드(1920px 6열)를 보여주고, 카드에서 대표로 지정 버튼으로 콘텐츠 대표 구간을 바꾸거나, 카드를 클릭해 편집 모달(ThumbnailSegmentEditModal)에서 AI가 추출한 프레임 중 하나를 해당 구간의 썸네일로 교체합니다. 이전/다음 구간 이동으로 모달을 닫지 않고 연속 검수할 수 있습니다.

편집은 useThumbnailDetail 컴포저블의 working copy 모델로 동작합니다. 서버 응답을 깊은 복제(cloneSegments)한 로컬 사본 위에서만 대표 지정·프레임 교체가 일어나고(dirty 플래그 갱신), 저장 시 POST /thumbnails/:jobId/segments로 일괄 커밋합니다. 초기화는 진입 시점 데이터로 복귀하고, 미저장 상태로 뒤로가기를 누르면 3버튼 확인 다이얼로그(confirmChoice — [취소]/[저장하지 않고 종료]/[저장 후 종료], behavior VAMS-TH-003)가 뜨며 [저장 후 종료]는 저장 실패 시 이탈을 중단합니다. 재생성은 확인 후 AI 재작업을 요청하고 목록으로 복귀하며, 연동은 POST /thumbnails/link로 해당 작업을 C-Cube 연동 큐에 올립니다.

설계 포인트
서버 상태(Vue Query 캐시)와 편집 상태(working copy)를 분리해 초기화·이탈 경고를 단순하게 만들었습니다. 저장 성공 시 setQueryData로 캐시를 응답으로 교체해 재조회 없이 정합성을 유지하고, DTO는 api/adapters/thumbnail.ts에서만 도메인 모델로 변환되어(알 수 없는 jobState는 parseJobState가 'P'로 폴백) 화면 코드는 도메인 타입만 다룹니다.

src/features/thumbnail/composables/useThumbnailDetail.ts — working copy 편집 모델
const segments = ref<ThumbnailSegment[]>([])
const dirty = ref(false)
watch(
  () => segmentQuery.data.value,
  (d) => {
    if (d) {
      segments.value = cloneSegments(d.segments)   // 진입 시점 스냅샷 = 초기화 복귀 지점
      dirty.value = false
    }
  },
  { immediate: true },
)

function setRepresentative(segmentId: string): void {
  segments.value = segments.value.map((s) => ({
    ...s,
    isRepresentative: s.segmentId === segmentId,   // 대표 구간은 콘텐츠당 1개
  }))
  dirty.value = true
}
function setSegmentThumb(segmentId: string, frameId: string): void {
  segments.value = segments.value.map((s) => {
    if (s.segmentId !== segmentId) return s
    const frames = s.frames.map((f) => ({ ...f, isSegmentThumb: f.frameId === frameId }))
    const chosen = frames.find((f) => f.frameId === frameId)
    return {
      ...s,
      frames,
      imageUrl: chosen?.imageUrl ?? s.imageUrl,    // 선택 프레임이 구간 카드 이미지가 됨
      timecode: chosen?.timecode ?? s.timecode,
    }
  })
  dirty.value = true
}

async function goBack(): Promise<void> {
  if (dirty.value) {
    // 이전 확인 3버튼(behavior VAMS-TH-003 1-1): [취소]/[저장하지 않고 종료]/[저장 후 종료]
    const choice = await confirmChoice({
      titleKey: 'thumbnail.confirm.leave.title',
      messageKey: 'thumbnail.confirm.leave.message',
      confirmKey: 'thumbnail.confirm.leave.saveExit', // 저장 후 종료(primary)
      extraKey: 'thumbnail.detail.leaveConfirm',      // 저장하지 않고 종료
    })
    if (choice === 'cancel') return
    if (choice === 'confirm') {
      await save()                  // 저장 후 종료
      if (dirty.value) return       // 저장 실패 시 이탈 중단
    }
  }
  await router.push('/thumbnail')
}

export async function fetchSegmentDetail(jobId: string): Promise<ThumbnailSegmentDetail> {
  const dto = await httpGet<ThumbnailSegmentDetailResponseDto>(THUMBNAIL_API.segmentDetail(jobId))
  return toSegmentDetail(dto)                       // DTO → 도메인 변환은 어댑터에서만

  )

src/features/thumbnail/queries.ts — 목록 쿼리 변환 (PRIORITY 가드 · 작업유형 필터)
export function toListQuery(s: SearchData): ThumbnailListQueryParams {
  // PRIORITY 가드 — 상태칩이 '전체'가 아니면 우선순위 정렬을 LATEST 로 강등
  const sortType: SortType =
    s.sortType === 'PRIORITY' && s.statusChip !== 'all' ? 'LATEST' : s.sortType

  const base: ThumbnailListQueryParams = {
    page: String(s.page),
    size: String(s.size),
    serviceType: 'THUMBNAIL',                       // 고정 주입
    sortType,
  }
  if (s.keyword) base.keyword = s.keyword
  const states = CHIP_TO_STATES[s.statusChip]       // 화면 상태칩 → 내부 jobState 코드 변환
  if (states.length > 0) base.jobStates = states.join(',')

  // 필터 2단 — 장르/세부장르(빈 문자열이면 생략 = 전체)
  if (s.genre) base.genre = s.genre
  if (s.detailGenre) base.detailGenre = s.detailGenre

  // 작업유형 필터 — all=생략 / SECTION=구간 / TENSEC=10초(TEN_SEC_KINDS=GTV,GTM 단일 소스)
  if (s.thumbKind !== 'all') {
    base.thumbKinds = s.thumbKind === 'TENSEC' ? TEN_SEC_KINDS.join(',') : s.thumbKind
  }

  if (s.dateRange) {
    base.startDate = s.dateRange.from
    base.endDate = s.dateRange.to
  }
  if (s.urgentOnly) base.urgentOnly = 'true'        // 긴급만 보기
  return base
}
