AI 썸네일 검수

구간 썸네일(SECTION)·10초 썸네일(GTV/GTM) 작업을 검수하는 워크플로입니다. 공통 리스트 패턴의 목록에서 bare 풀스크린 상세로 진입해, working copy 모델 위에서 대표 구간 지정·구간 썸네일 프레임 교체를 수행하고 저장·재생성·C-Cube 연동까지 이어집니다.

기능 개요

AI 썸네일 메뉴는 AI 엔진이 VOD 콘텐츠에서 자동 추출한 썸네일 작업을 검수하는 화면입니다. 작업유형은 두 가지로, thumbKind가 SECTION이면 구간 썸네일(콘텐츠의 구간별 대표 이미지, 편집 가능), GTV/GTM이면 10초 썸네일(읽기전용 정보 카드)로 분기합니다. 목록 화면 ThumbnailListPage는 전 메뉴 공통 리스트 패턴을 따르며 검색어·상태칩(썸네일은 검수완료 제외 6종)·장르/세부장르 2단 필터·조회기간·긴급만 보기와 우선순위 정렬(PRIORITY — 긴급 0순위 고정 + 검수필요·실패 우선)을 제공합니다. 검색 조건은 createListQueryStore 기반 스토어로 영속되고, 행 선택 시 우측 패널(ThumbnailDetailPanel)에서 AI 작업이력과 콘텐츠 정보를 확인합니다.

목록의 행을 열면 /thumbnail/:jobId?kind=… 라우트의 ThumbnailDetailPage(상세화면 S4)로 이동합니다. 이 라우트는 meta.layout:'bare' 풀스크린으로 LNB·앱 헤더 없이 렌더되며, 상단은 공통 DetailHeader+DetailHeaderActions(초기화·재생성·저장·연동)입니다. 구간 썸네일 상세(ThumbnailSegmentDetail)는 구간 카드 그리드(1920px 6열)를 보여주고, 카드에서 대표로 지정 버튼으로 콘텐츠 대표 구간을 바꾸거나, 카드를 클릭해 편집 모달(ThumbnailSegmentEditModal)에서 AI가 추출한 프레임 중 하나를 해당 구간의 썸네일로 교체합니다. 이전/다음 구간 이동으로 모달을 닫지 않고 연속 검수할 수 있습니다.

편집은 useThumbnailDetail 컴포저블의 working copy 모델로 동작합니다. 서버 응답을 깊은 복제(cloneSegments)한 로컬 사본 위에서만 대표 지정·프레임 교체가 일어나고(dirty 플래그 갱신), 저장 시 POST /thumbnails/:jobId/segments로 일괄 커밋합니다. 초기화는 진입 시점 데이터로 복귀하고, 미저장 상태로 뒤로가기를 누르면 이탈 확인 다이얼로그가 뜹니다. 재생성은 확인 후 AI 재작업을 요청하고 목록으로 복귀하며, 연동은 POST /thumbnails/link로 해당 작업을 C-Cube 연동 큐에 올립니다.

설계 포인트
서버 상태(Vue Query 캐시)와 편집 상태(working copy)를 분리해 초기화·이탈 경고를 단순하게 만들었습니다. 저장 성공 시 setQueryData로 캐시를 응답으로 교체해 재조회 없이 정합성을 유지하고, DTO는 api/adapters/thumbnail.ts에서만 도메인 모델로 변환되어(알 수 없는 jobState는 parseJobState가 'P'로 폴백) 화면 코드는 도메인 타입만 다룹니다.

src/features/thumbnail/composables/useThumbnailDetail.ts — working copy 편집 모델
const segments = ref<ThumbnailSegment[]>([])
const dirty = ref(false)
watch(
  () => segmentQuery.data.value,
  (d) => {
    if (d) {
      segments.value = cloneSegments(d.segments)   // 진입 시점 스냅샷 = 초기화 복귀 지점
      dirty.value = false
    }
  },
  { immediate: true },
)

function setRepresentative(segmentId: string): void {
  segments.value = segments.value.map((s) => ({
    ...s,
    isRepresentative: s.segmentId === segmentId,   // 대표 구간은 콘텐츠당 1개
  }))
  dirty.value = true
}
function setSegmentThumb(segmentId: string, frameId: string): void {
  segments.value = segments.value.map((s) => {
    if (s.segmentId !== segmentId) return s
    const frames = s.frames.map((f) => ({ ...f, isSegmentThumb: f.frameId === frameId }))
    const chosen = frames.find((f) => f.frameId === frameId)
    return {
      ...s,
      frames,
      imageUrl: chosen?.imageUrl ?? s.imageUrl,    // 선택 프레임이 구간 카드 이미지가 됨
      timecode: chosen?.timecode ?? s.timecode,
    }
  })
  dirty.value = true
}

export async function fetchSegmentDetail(jobId: string): Promise<ThumbnailSegmentDetail> {
  const dto = await httpGet<ThumbnailSegmentDetailResponseDto>(THUMBNAIL_API.segmentDetail(jobId))
  return toSegmentDetail(dto)                       // DTO → 도메인 변환은 어댑터에서만

): Promise<ThumbnailSegmentDetail> {
  const dto = await httpPost<SaveSegmentsRequestDto, ThumbnailSegmentDetailResponseDto>(
    THUMBNAIL_API.segmentDetail(jobId),
    { segments: segments.map((s) => ({ /* segmentId·isRepresentative·frames ... */ })) },
  )
  return toSegmentDetail(dto)
}

export async function postRegenerate(jobId: string): Promise<{ ok: boolean }> {

src/features/thumbnail/queries.ts — 목록 쿼리 변환과 PRIORITY 정렬 가드
export function toListQuery(s: SearchData): ThumbnailListQueryParams {
  // PRIORITY 가드 — 상태칩이 '전체'가 아니면 우선순위 정렬을 LATEST 로 강등
  const sortType: SortType =
    s.sortType === 'PRIORITY' && s.statusChip !== 'all' ? 'LATEST' : s.sortType

  const base: ThumbnailListQueryParams = {
    page: String(s.page),
    size: String(s.size),
    serviceType: 'THUMBNAIL',                       // 고정 주입
    sortType,
  }
  if (s.keyword) base.keyword = s.keyword
  const states = CHIP_TO_STATES[s.statusChip]       // 화면 상태칩 → 내부 jobState 코드 변환
  if (states.length > 0) base.jobStates = states.join(',')
  if (s.urgentOnly) base.urgentOnly = 'true'        // 긴급만 보기
  return base
}
