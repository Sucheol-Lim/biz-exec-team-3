대시보드 (통합 AI 작업 목록)

포스터·썸네일·자막 등 전 AI 엔진의 작업(Job)을 단일 목록에서 조회·필터링하는 VAMS 홈 화면입니다. 서비스 타입 다중 필터(8종)·상태칩(7종)·상태칩별 동적 정렬을 제공하고, 검색 조건은 vams:listQuery:dashboard 키로 localStorage에 영속되어 재방문 시 복원됩니다.

기능 개요

대시보드는 VAMS 로그인 후 처음 만나는 홈 화면으로, 포스터·썸네일·자막·개인화·구간마킹·얼굴인식(CI)·골라보기·하이라이트 8개 서비스 타입의 AI 작업을 하나의 목록으로 통합 조회합니다. 화면은 DashboardListPage.vue가 ContentListLayout 슬롯 합성으로 구성하며, 검색(SearchBox+최근검색)·상태칩 7종(전체/대기/검수필요/실패/검수중/검수완료/연동완료)·AI작업 다중 칩·조회기간 프리셋·긴급만 보기 스위치를 검색 조건으로 제공합니다.

검색 조건 상태는 공통 팩토리 createListQueryStore('dashboard')가 만든 Pinia 싱글톤 스토어가 담당합니다. 스토어는 @vueuse/core의 useStorage로 vams:listQuery:dashboard 키에 화이트리스트(상태칩·서비스타입·조회기간·정렬 등 — keyword·page는 제외)를 영속해, 다른 메뉴에 다녀와도 필터가 유지됩니다. 조회는 toListQuery()가 SearchData를 쿼리 파라미터로 변환(서비스타입 CSV, 상태칩→jobStates 코드 변환)해 TanStack Vue Query의 queryKey로 삼는 구조라, 필터를 바꾸면 자동 재조회됩니다. 응답 DTO는 api/adapters/dashboard.ts에서만 도메인 모델(DashboardJobRow)로 변환되어 화면은 DTO를 직접 만지지 않습니다.

행 단위 액션은 상태 기반 CTA로 결정됩니다. useDashboardActions().ctaFor()가 내부 상태코드 10종(P·I·F·S·R·V·W·T·E·L) 중 실패(F)→재처리, 연동실패(E)→재연동, 검수 가능 상태(S·V·L)→[검수]를 매핑하고, [검수]는 reviewRoute()로 서비스 타입별 상세 화면(/poster/:jobId 등)으로 라우팅합니다. 우측 상세 패널(DashboardDetailPanel)은 작업 이력·콘텐츠 정보를 별도 쿼리로 노출합니다.

설계 포인트
기본 정렬은 "검수필요·실패 우선"(PRIORITY)이지만 상태칩이 all이 아니면 우선순위 정렬이 무의미하므로 toListQuery()가 LATEST로 강등하는 가드를 둡니다. 상태칩 변경 시에도 칩별 기본 정렬(SORT_BY_CHIP)로 자동 전환됩니다. 백엔드 미연동 개발 단계라 dev 서버에서는 MSW가 DASHBOARD_API 경로를 인터셉트해 fixtures를 반환합니다.

src/features/dashboard/queries.ts — searchData → 쿼리 파라미터 변환과 PRIORITY 가드
export function toListQuery(s: SearchData): DashboardListQueryParams {
  // PRIORITY 가드 — 상태칩이 all 이 아니면 LATEST 로 강등
  const sortType: SortType =
    s.sortType === 'PRIORITY' && s.statusChip !== 'all' ? 'LATEST' : s.sortType

  const base: DashboardListQueryParams = {
    page: String(s.page),
    size: String(s.size),
    sortType,
  }

  // AI작업 필터(다중) — 비었으면 전체
  if (s.serviceTypes.length > 0) {
    base.serviceTypes = s.serviceTypes.join(',')
  }

  if (s.keyword) {
    base.keyword = s.keyword
  }

  const states = CHIP_TO_STATES[s.statusChip]   // 상태칩 → 내부 상태코드 목록
  if (states.length > 0) {
    base.jobStates = states.join(',')
  }
  ...
  return base
}
src/shared/stores/listQuery.ts — 검색 조건 영속 (vams:listQuery:<slug>)
export function createListQueryStore(slug: string) {
  return defineStore(`listQuery:${slug}`, () => {
    // useStorage 영속(화이트리스트) — 키 vams:listQuery:{slug}
    const persisted = useStorage<PersistedSearchData>(
      `vams:listQuery:${slug}`,
      pickPersisted(defaultSearchData()),
      localStorage,
      { mergeDefaults: true },
    )

    // searchData 초기값 = 기본값 + 영속 화이트리스트 머지
    const searchData = reactive<SearchData>({
      ...defaultSearchData(),
      ...persisted.value,
    })

    // searchData 변경 → 영속 화이트리스트 동기화
    watch(
      () => pickPersisted(searchData),
      (val) => { persisted.value = val },
      { deep: true },
    )
    ...
  })()   // defineStore(...)() 즉시실행 — 싱글톤 인스턴스 반환
}
src/features/dashboard/composables/useDashboardActions.ts — 상태코드 → CTA 매핑
/**
 * 상태 → CTA 매핑 (cell-actions / DetailCta 공유). null 이면 버튼 없음.
 * - F → 재처리 / E → 재연동(link) / S·V·L → 검수(상세 이동)
 * - 대기·진행(P·W·I·T·R) → null
 */
function ctaFor(jobState: JobState): CtaConfig | null {
  switch (jobState) {
    case 'F':
      return { labelKey: 'dashboard.action.reprocess', action: 'reprocess' }
    case 'E':
      return { labelKey: 'dashboard.action.link', action: 'link' }
    case 'S':
    case 'V':
    case 'L':
      return { labelKey: 'dashboard.action.review', action: 'review' }
    default:
      return null
  }
}
