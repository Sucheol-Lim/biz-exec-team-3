AI 포스터 검수·편집

포스터 작업 목록(/poster) → 결과 이미지 검수·대표 선택 상세 → Konva 캔버스 기반 이미지·타이틀 편집기로 이어지는 워크플로입니다. 크롭·색 조정·선명도·마스킹·업스케일과 타이틀 오려두기·제거·다중 선택(N객체 모델), 스냅샷 기반 undo/redo(최대 50단계 FIFO)를 제공하고, 편집 결과를 원본 해상도로 bake 하여 multipart 로 등록합니다.

기능 개요

AI 포스터 엔진은 콘텐츠 1건당 method1~4 4종(목록형 이미지/타이틀, 상세 배경형 이미지/타이틀) 결과 이미지를 생성합니다. 운영자는 LNB의 포스터 목록(PosterListPage, /poster)에서 상태칩·장르 2단 필터·조회기간·긴급만보기로 작업을 찾고(검색 조건은 vams:listQuery:poster 키로 영속), 행을 클릭해 풀스크린(bare) 상세(PosterDetailPage, /poster/:jobId)로 진입합니다. 상세는 usePosterDetail이 2단 조회(jobId → fetchPosterDetail → contentId → fetchPosterResults)로 결과 이미지를 불러와 목록형/상세배경형 탭으로 보여주고, 대표 선택을 draft 로 관리하다가 savePosterSelection(PUT editList)으로 저장합니다. 연동·재처리는 postLink/postReprocess로 요청합니다.

상세에서 결과 이미지를 선택하면 편집기(PosterEditPage, /poster/:jobId/edit-image/:resultId 또는 edit-title)로 진입합니다. 편집기의 중심은 오케스트레이터 컴포저블 usePosterEdit로, 크롭(cropTool)·색 조정(adjustTool — 밝기·대비·채도·선명도) 도구를 EditTool 계약으로 관리하고, 도구가 커밋한 자기 차원을 EditorState{crop, adjust}로 합성해 usePosterEditorStore에 스냅샷으로 push 합니다. undo/redo 는 스냅샷 스택+커서 이동으로 동작하며 최대 50단계(Figma Flipbook Policy 6 근거, MAX_SNAPSHOTS) 초과 시 가장 오래된 이력부터 FIFO 제거됩니다. 조정 슬라이더는 라이브 드래그=SVG filter 프리뷰(스냅샷 없음), 릴리즈(valueCommit)=1스냅샷 커밋으로 스냅샷 남발을 막습니다.

이 밖에 이미지 제거 마스킹(usePosterMaskDraw — stroke 누적, BE 인페인팅 전송 seam), 업스케일(usePosterUpscale — useAsyncJob 폴링 + x2/x4 완료 토스트), 타이틀 편집(usePosterTitleEdit)이 같은 스토어·도구 패턴 위에 얹혀 있습니다. 타이틀 편집기는 이동·리사이즈(transform 1차원)에서 N객체 모델(G3a~G5b)로 확장되어, 영역설정 올가미 폴리곤의 오려두기(cutOut — 조각을 독립 객체로 분리)·제거(removeRegion — 투명 구멍)를 regionRaster의 canvas 합성(destination-in/out)으로 100% FE 처리하고, 객체 클릭 선택 전환·Shift 토글·Ctrl/Cmd+A·마퀴 드래그 다중 선택과 그룹 변형(sizePositionTool)을 지원합니다. 스냅샷 TitleEditorStateV2는 픽셀 없이 assetId 문자열만 담는 JSON-safe 구조이고 실제 raster 는 비반응 assetStore에 보관되며, undo/redo 는 reconcile이 스냅샷 ↔ 캔버스 노드를 diff 로 결정론 동기합니다. 타이틀 등록 bake(exportFrameBlob)는 등록된 객체 노드를 z-order 로 대지에 합성합니다. C11 출력 정책이 투명 PNG로 확정되어(TITLE_EXPORT_OPTS = { background: null, mimeType: 'image/png' }) 타이틀 등록 버튼이 활성화됐습니다 — 타이틀은 상세 오버레이에서 포스터 위에 겹쳐지므로 배경을 대지색으로 채우지 않고 알파를 보존합니다. 이미지 편집기 등록 시 exportBlob이 크롭·조정·선명도를 원본 해상도로 bake 한 Blob 을 만들고 saveEditedPoster가 multipart(POST edit-save)로 업로드하며(파일 확장자는 blob MIME 을 따라 이미지=jpg/타이틀=png), 성공 시 결과 쿼리 invalidate + 스토어 $reset으로 dirty 를 해제합니다. dirty 상태 이탈은 onBeforeRouteLeave 가드가 확인 다이얼로그로 막습니다(INV-9).

설계 포인트 — 도구 불가지 · 도메인 무지
usePosterEditorStore는 도구·Konva·fetch 를 import 하지 않는 도구 불가지(INV-4) 스냅샷 스택이고, CanvasHost는 "크롭·밝기" 의미를 모른 채 일반 Konva 핸들과 픽셀 export 만 노출하는 도메인 무지(INV-8) 캔버스입니다. 도메인 의미의 합성·복원은 전부 usePosterEdit 오케스트레이터 한 곳에 모여 있어, 타이틀 편집기가 같은 스토어·캔버스를 재사용합니다. 타이틀 N객체 확장에서도 CanvasHost는 제네릭 객체 노드 레지스트리(addObjectNode·setObjectSource·getObjectNodes)만 노출할 뿐 "오려두기" 의미는 모르며, 이 레지스트리를 쓰지 않는 이미지 편집기는 단일 primary 경로 그대로입니다(회귀 0).

src/features/poster/stores/poster.store.ts — 스냅샷 push (redo 분기 절단 + 50단계 FIFO)
function pushSnapshot(s: Snapshot): void {
  // cursor 뒤 분기 제거
  snapshots.value = snapshots.value.slice(0, cursor.value + 1)
  snapshots.value.push(s)
  // FIFO cap: 초과분만큼 앞(가장 오래된)에서 제거
  if (snapshots.value.length > MAX_SNAPSHOTS) {
    snapshots.value = snapshots.value.slice(snapshots.value.length - MAX_SNAPSHOTS)
  }
  cursor.value = snapshots.value.length - 1 // shift 후 끝으로 자동 보정
}
src/features/poster/composables/usePosterEdit.ts — 도구 차원 → EditorState 합성 커밋 (INV-4)
function commitActiveTool(): void {
  const tool = activeTool.value
  if (!tool) return
  if (tool.id === 'crop') {
    committedCrop = cropToolInstance?.commit() ?? null
  } else if (tool.id === 'adjust') {
    committedAdjust = adjustToolInstance?.commit() ?? { ...DEFAULT_ADJUST }
    adjustState.value = { ...committedAdjust }
  }
  activeTool.value = null
  pushEditorState()
}

function pushEditorState(): void {
  const state: EditorState = { crop: committedCrop, adjust: { ...committedAdjust } }
  store.pushSnapshot(state)
}

/** 편집 이미지 등록 (POST multipart: file + type). BE 1차 I/F: POST /d-cms/poster/edit-save/{contentId} */
export async function saveEditedPoster(
  contentId: string,
  file: Blob,
  type: PosterResultType,
): Promise<{ code: string; message: string }> {
  const form = new FormData()
  // 확장자는 실제 blob MIME 을 따른다 — 이미지편집=image/jpeg, 타이틀편집=image/png(투명). 공유 함수라 전역 .jpg 금지.
  const ext = file.type === 'image/png' ? 'png' : 'jpg'
  form.append('file', file, `edited-${type}.${ext}`)
  form.append('type', type)
  return httpPostFormData<{ code: string; message: string }>(
    POSTER_RESULT_API.editSave(contentId),
    form,
  )
}
src/features/poster/composables/tools/regionRaster.ts — 올가미 폴리곤 오려두기/제거 raster 연산 (destination-in/out, 100% FE)
export function rasterizeRegion(
  source: CanvasImageSource,
  srcW: number,
  srcH: number,
  polygon: number[],
  keep: 'inside' | 'outside',
  cropToBbox: boolean,
): RasterResult {
  const bbox = polygonBbox(polygon)
  const full = document.createElement('canvas')
  full.width = Math.max(1, Math.round(srcW))
  full.height = Math.max(1, Math.round(srcH))
  const ctx = full.getContext('2d')!
  ctx.drawImage(source, 0, 0, srcW, srcH)
  ctx.globalCompositeOperation = keep === 'inside' ? 'destination-in' : 'destination-out'
  ctx.fillStyle = '#000' // 색 무관(합성은 알파만) — nonzero winding
  tracePolygon(ctx, polygon)
  ctx.fill()
  ctx.globalCompositeOperation = 'source-over'

  if (!cropToBbox) return { canvas: full, bboxSource: bbox } // 나머지(구멍) — 원본 치수 유지
  // bbox 로 잘라 축소(조각) — 원본px bbox 영역만 복사.
  const cw = Math.max(1, Math.round(bbox.width))
  const ch = Math.max(1, Math.round(bbox.height))
  const cropped = document.createElement('canvas')
  cropped.width = cw
  cropped.height = ch
  const cctx = cropped.getContext('2d')!
  cctx.drawImage(full, bbox.x, bbox.y, bbox.width, bbox.height, 0, 0, cw, ch)
  return { canvas: cropped, bboxSource: bbox }
}
