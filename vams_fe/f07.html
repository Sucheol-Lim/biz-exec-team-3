기능 개요

VAMS의 13개 메뉴는 모두 "콘텐츠 리스트 → 검색/필터 → 상세 → 편집 → 연동"이라는 공통 워크플로를 공유하므로, 화면 코드가 도메인마다 UI를 재발명하지 않도록 src/shared/components에 3계층 공통 컴포넌트 라이브러리를 둡니다. base(VButton·VInput·VSelect·VCheckbox·VRadio/VRadioGroup·VSwitch·VSlider·VProgressBar·VTooltip·VIcon·IconButton·Divider 13종 + 공용 mixin partial _base.scss)는 Reka UI 헤드리스 프리미티브 위의 얇은 래퍼이고, composite 37종은 도메인 정책이 스며든 조합 컴포넌트이며, layout(AppShell·ContentListLayout·DetailPanelLayout·TabbedPageLayout 4종)은 데이터·스토어 로직이 전혀 없는 named slot 전용 골격입니다. composite는 규모가 커지면서 하위 카테고리 폴더로 갈라졌습니다 — data-table/(DataTable + types + useColumnLayout), date-picker/(DateRangePicker·DateRangeCalendarPopover), toolbar/(ListToolbar·ToolbarBox·ToolbarCount·DateRangeControl), chart/(BaseChart·BarChart·StackedBarChart·ChartFrame + chartTheme·chartTooltipFormatter·resolveCssVar)입니다.

2026-08 라운드의 핵심은 10개 리스트 페이지에 복붙돼 있던 관용구를 중수준 공통 컴포넌트로 승격한 것입니다. 툴바는 3층으로 나뉘어, 컨테이너 ListToolbar(Figma Header/Table 정본 — 타이틀 바 + 서브 바, 슬롯 없는 영역은 렌더 자체를 생략해 빈 flex 아이템이 gap을 오염시키지 않게 함)가 ToolbarCount(총 N건 · 선택 N건)와 ToolbarBox(라벨 + 값 + chevron 박스 드롭다운, VSelect 래핑)를 슬롯으로 받고, 조회기간은 ToolbarBox에 #suffix로 기간 표시와 달력 팝오버를 얹은 DateRangeControl이 담당합니다. 리스트 셀·상태도 IdNameCell(ID/명 2단, 1280 이하에서 세로 2줄로 전환), ListEmptyState(로드실패 > 필터결과없음 > 데이터없음 3분기 통합), TableLoading(36px 원형 스피너), TableActionButton·PanelActionButton, UrgentBadge(긴급 배지 — 상세패널 8곳의 자체 구현 제거)로 통일되었고, 상세패널 쪽은 PanelInfoTable·CopyValueField·GenrePath·HeaderGenre가 신설되었습니다. 컴포넌트가 아닌 로직도 shared/composables/useBulkActionEligibility(8벌 복제 제거)·useCopy, shared/lib/datePreset(9벌 복제 제거)로 승격되었습니다.

DataTable은 두 축이 추가되었습니다. 첫째는 컬럼 너비 반응형(useColumnLayout)으로, ColumnDef에 grow가 지정된 컬럼만 flex에 참여시켜 컨테이너 폭을 flexbox 결합 분배 알고리즘으로 px 계산해 주입합니다 — grow>0은 잉여 흡수, grow:0은 축소 전용(성장하지 않고 minWidth까지만 양보), grow 미지정은 완전 고정(레거시 경로 무접촉)입니다. 흡수 주체(grow>0)가 하나도 없으면 아예 비활성(growMode=false)이라 기존 화면은 영향을 받지 않고, virtual 경로도 이 컴포저블을 쓰지 않습니다. 둘째는 행 상태 분리로, 체크박스 다중선택(selected = Accent, fill만)과 "현재 우측 패널이 열린 행"(activeKey = Selected, fill + 1px 라인)이 별개 상태가 되었습니다. 여기에 Figma Table Size 축(size: medium 60 / small / xsmall)이 도입되며 구 density prop은 높이에 영향하지 않는 no-op으로 @deprecated 처리되었습니다.

스타일의 단일 출처는 src/styles/tokens.scss입니다. L1 primitive는 Figma 공식 컴포넌트 라이브러리 팔레트(Neutral/Cool Neutral/Blue Gray/Blue/Navy/Red/Orange/Green 등)와 1:1 정합하는 색 변수이고, L2 semantic(--color-text-primary 등)과 L2 status(상태칩 7종 ↔ 내부 10상태 매핑, --status-*-fg/bg·dot 색)가 그 위에 놓이며, L3 컴포넌트 스타일은 "L2만 참조, L1 직접 참조 금지" 규칙을 따릅니다. 컨트롤 높이도 Figma Draft 치수 명칭(--ctrl-h-tiny 24px ~ --ctrl-h-xlarge 44px)을 그대로 추종하고, 구 sm/md/lg 명칭은 deprecated alias로 하위호환만 유지합니다. 2026-07 Draft(N6Lkk77) 재정합으로 L1 팔레트에서 구 Sky Blue 값이 Royal Blue 계열로 개명·이동하고 Sky Blue는 cyan 계열로 재정의되었으며, Magenta·Purple·Mint 3계열이 신규 추가되었습니다. 검수완료 상태칩은 신설 Mint 계열(--status-done-*·--status-dot-done)로 연동완료(Green)와 구분되고, 검정 12% 오버레이 구분선 토큰 --color-divider도 추가되었습니다. 이 토큰 체계는 f08의 품질 게이트(check:cssvars·figma-token-check·픽셀 게이트)가 기계 검증하는 대상이기도 합니다.

2026-08 실측 라운드에서 토큰이 다시 손질되었습니다. 추정 파생값으로 두었던 --c-mint-200이 Figma 팔레트 실측값 #aeebe4로 교체되고(figma-token-check 대조 항목에도 등재), 테이블 행 hover는 고유색 #f3efff에서 공용 인터랙션 색 Blue Gray/900 6%(#2b31420f)로, LNB 선택 텍스트·보더는 드리프트가 교정되어 각각 --c-navy-500과 Blue/300 40% 알파로 바뀌었습니다. Figma에 대응 semantic이 없어 화면 코드가 raw hex로 쓰던 자리들도 우리 쪽 L2 층으로 끌어올려, 긴급 깃발(--color-urgent-flag)·빈 상태 아이콘(--color-empty-icon)·원본 변경 경고(--color-origin-changed와 패널용 --color-origin-changed-panel이 의도적으로 다른 값)·페이지 제목(--color-header-title)·패널 채움(--color-panel-bg)·헤더 구분선(--color-header-divider) 토큰이 신설되었습니다. 모니터링 차트를 위해서는 상태칩 dot과 별개 축인 L2 chart(Graph 팔레트)가 새로 생겼습니다 — --graph-gray/purple/red/orange/blue/green과 차트 전용 다크 툴팁 --color-chart-tooltip-bg(VTooltip의 Navy 툴팁과 별개)입니다.

개발자 경험 축으로는 dev 전용 컴포넌트 카탈로그가 있습니다. src/app/router/index.ts가 import.meta.env.DEV일 때만 /_catalog 라우트(bare 레이아웃, AppShell 미적용)를 등록해 prod 번들에서 완전히 제외하며, CatalogHome이 컴포넌트 카드 인덱스를, src/dev/catalog/stories의 46종 스토리가 각 컴포넌트의 variant×size 매트릭스 데모를 제공합니다. 2026-08 라운드에서 상세패널 공통 3종(PanelInfoTable·CopyValueField·GenrePath)과 IdNameCell, 차트(Chart), 모니터링 위젯 8종(작업현황·연동현황·연동률·GPU 사용률·최근 로그·대시보드 프리뷰·대시보드 상태·로그이력), PickUploadModal 스토리가 추가되었습니다. 스토리는 데모용에 그치지 않고 e2e 시각회귀의 촬영 대상이기도 해서(tests/e2e/catalog.spec.ts, 1280 단일 뷰포트 운영) 공통 컴포넌트 변경이 스냅샷 diff로 드러납니다.

설계 포인트
base 래퍼는 CSS var 훅 패턴을 씁니다. VButton이 --v-btn-bg·--v-btn-fg 등 훅을 선언하고 variant modifier가 이를 L2 토큰으로 재지정하므로, 하드코딩 hex 없이 variant 12종(primary~transparent, 2026-08에 ghost-secondary·secondary-multiple 추가)이 토큰 체계 안에서 파생됩니다. focus 링·disabled 상태는 _base.scss의 공용 mixin(focus-ring·disabled-state)으로 전 컴포넌트가 동일하게 통일됩니다. 반대로 Reka UI가 SelectPortal로 body 직속 teleport 하는 드롭다운 패널처럼 consumer CSS가 닿지 않는 영역은 prop으로만 제어할 수 있어, VSelect에 maxVisibleItems(항목 32px 고정 높이 × N + 뷰포트 패딩 4×2로 max-height 산출)가 추가되었습니다.

src/shared/components/base/VButton.vue — Reka UI Primitive 얇은 래퍼와 size 정규화
// VButton — Primitive(asChild) 기반 얇은 래퍼 (B_architecture W1)
import { Primitive } from 'reka-ui'

// Figma Draft(N6Lkk77) size 명칭 추종: tiny24·xsmall28·small32·medium36·large40
// 구 sm/md/lg는 deprecated alias — Wave2에서 제거 예정
type SizeNew = 'tiny' | 'xsmall' | 'small' | 'medium' | 'large'

// 구 명칭 → 신규 명칭 정규화 (하위호환)
const normalizedSize = computed((): SizeNew => {
  if (size === 'sm') return 'xsmall'
  if (size === 'md') return 'small'
  if (size === 'lg') return 'medium'
  return size as SizeNew
})

<Primitive
  :as="as"
  class="v-btn"
  :class="[`v-btn--${variant}`, `v-btn--${normalizedSize}`, { 'v-btn--rounded': rounded }]"
  :disabled="disabled || loading || undefined"
  :aria-disabled="disabled || loading || undefined"
>

/** flex 참여(가변) 컬럼 — grow 지정(0 포함). grow 미지정 = 고정(레거시 colWidth 경로).
 *  grow:0 = 축소전용(성장X, minWidth까지 축소O) */
function isFlexCol<TRow>(col: ColumnDef<TRow>): boolean {
  return col.grow !== undefined
}
/** growMode 게이트 — surplus 를 흡수할 grow>0 컬럼 존재 여부(흡수 주체 없으면 레거시 유지) */
function hasGrowWeight<TRow>(col: ColumnDef<TRow>): boolean {
  return (col.grow ?? 0) > 0
}

const pool = W - checkW - fixedSum          // W = rootEl.clientWidth (ResizeObserver 관측)
const basisSum = items.reduce((s, v) => s + v.basis, 0)

if (pool >= basisSum) {
  // 여유 — grow 비율로 surplus 배분(grow:0 은 0 기여 → basis 유지) + maxWidth 클램프 1-pass 재배분
  const surplus = pool - basisSum
  const totalGrow = items.reduce((s, v) => s + v.grow, 0)
  for (const v of items) {
    px.set(v.key, totalGrow > 0 ? v.basis + (surplus * v.grow) / totalGrow : v.basis)
  }
} else {
  // 부족 — shrink(basis 비례) + minWidth 클램프. grow:0 도 포함(축소전용 참여).
  //        클램프로 빠진 컬럼의 몫을 남은 컬럼에 다시 나누며 변화 없을 때까지 반복.
}
