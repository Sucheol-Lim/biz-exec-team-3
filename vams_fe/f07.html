src/shared/components의 base 13종 + composite 20여 종 + layout 4종 공통 컴포넌트 라이브러리와 dev 전용 카탈로그(/_catalog)입니다. Figma 실측 토큰(tokens.scss, L1→L2→L3 3계층)을 단일 출처로 삼고, base 컴포넌트는 Reka UI 헤드리스 래퍼 전략으로 접근성과 픽셀 퍼펙트를 동시에 확보합니다.

기능 개요

VAMS의 12개 메뉴는 모두 "콘텐츠 리스트 → 검색/필터 → 상세 → 편집 → 연동"이라는 공통 워크플로를 공유하므로, 화면 코드가 도메인마다 UI를 재발명하지 않도록 src/shared/components에 3계층 공통 컴포넌트 라이브러리를 둡니다. base(VButton·VInput·VSelect·VCheckbox·VRadio/VRadioGroup·VSwitch·VSlider·VTooltip·VIcon·IconButton·Divider + 공용 mixin partial _base.scss)는 Reka UI 헤드리스 프리미티브 위의 얇은 래퍼이고, composite(DataTable·StatusBadge·SearchBox·FilterChips·Pagination·VModal·Tabs·FormField·DateRangePicker 등 20여 종)는 도메인 정책이 스며든 조합 컴포넌트이며, layout(AppShell·ContentListLayout·DetailPanelLayout·TabbedPageLayout 4종)은 데이터·스토어 로직이 전혀 없는 named slot 전용 골격입니다.

스타일의 단일 출처는 src/styles/tokens.scss입니다. L1 primitive는 Figma 공식 컴포넌트 라이브러리 팔레트(Neutral/Cool Neutral/Blue Gray/Blue/Navy/Red/Orange/Green 등)와 1:1 정합하는 색 변수이고, L2 semantic(--color-text-primary 등)과 L2 status(상태칩 7종 ↔ 내부 10상태 매핑, --status-*-fg/bg·dot 색)가 그 위에 놓이며, L3 컴포넌트 스타일은 "L2만 참조, L1 직접 참조 금지" 규칙을 따릅니다. 컨트롤 높이도 Figma Draft 치수 명칭(--ctrl-h-tiny 24px ~ --ctrl-h-xlarge 44px)을 그대로 추종하고, 구 sm/md/lg 명칭은 deprecated alias로 하위호환만 유지합니다. 이 토큰 체계는 f08의 품질 게이트(check:cssvars·figma-token-check·픽셀 게이트)가 기계 검증하는 대상이기도 합니다.

개발자 경험 축으로는 dev 전용 컴포넌트 카탈로그가 있습니다. src/app/router/index.ts가 import.meta.env.DEV일 때만 /_catalog 라우트(bare 레이아웃, AppShell 미적용)를 등록해 prod 번들에서 완전히 제외하며, CatalogHome이 컴포넌트 카드 인덱스를, src/dev/catalog/stories의 30개 스토리가 각 컴포넌트의 variant×size 매트릭스 데모를 제공합니다.

설계 포인트
base 래퍼는 CSS var 훅 패턴을 씁니다. VButton이 --v-btn-bg·--v-btn-fg 등 훅을 선언하고 variant modifier가 이를 L2 토큰으로 재지정하므로, 하드코딩 hex 없이 variant 10종(primary~transparent)이 토큰 체계 안에서 파생됩니다. focus 링·disabled 상태는 _base.scss의 공용 mixin(focus-ring·disabled-state)으로 전 컴포넌트가 동일하게 통일됩니다.

관계. base 래퍼(VButton)는 Reka UI Primitive에 렌더를 위임하고 _base.scss mixin과 L2 토큰만 참조합니다. composite(StatusBadge)는 도메인 상태 토큰을, layout(ContentListLayout)은 slot 골격만을 담당하며, dev 카탈로그가 이들 전부를 스토리로 데모합니다.

핵심 코드

src/shared/components/base/VButton.vue — Reka UI Primitive 얇은 래퍼와 size 정규화
// VButton — Primitive(asChild) 기반 얇은 래퍼 (B_architecture W1)
import { Primitive } from 'reka-ui'

// Figma Draft(N6Lkk77) size 명칭 추종: tiny24·xsmall28·small32·medium36·large40
// 구 sm/md/lg는 deprecated alias — Wave2에서 제거 예정
type SizeNew = 'tiny' | 'xsmall' | 'small' | 'medium' | 'large'

// 구 명칭 → 신규 명칭 정규화 (하위호환)
const normalizedSize = computed((): SizeNew => {
  if (size === 'sm') return 'xsmall'
  if (size === 'md') return 'small'
  if (size === 'lg') return 'medium'
  return size as SizeNew
})

<Primitive
  :as="as"
  class="v-btn"
  :class="[`v-btn--${variant}`, `v-btn--${normalizedSize}`, { 'v-btn--rounded': rounded }]"
  :disabled="disabled || loading || undefined"
  :aria-disabled="disabled || loading || undefined"
>
src/styles/tokens.scss — L1 primitive → L2 semantic → L2 status 3계층 토큰
/* 참조 방향: L3 component → L2 semantic → L1 primitive (L1 직접참조 금지).
 * ⚠️ L1 = Figma 공식 컴포넌트 라이브러리 변수 1:1 정합. */

/* L1 primitive (Figma Palette) */
:root {
  --c-blue-gray-950: #1c202c;
  --c-blue-500: #5d74eb;
  ...
}

/* L2 semantic (light) */
:root, [data-theme='light'] {
  --color-text-primary: var(--c-blue-gray-950);   /* Input/Text/Value */
  --color-text-secondary: var(--c-blue-gray-700);
  ...
}

/* L2 status (semantic 위 도메인 레이어 — 7칩 ↔ 10상태) */
:root, [data-theme='light'] {
  --status-review-fg: var(--c-blue-600);
  --status-review-bg: var(--c-blue-50);           /* 검수필요 */
  --status-dot-review: var(--c-orange-400);       /* dot = Orange/400 */
  ...
}
src/app/router/index.ts — dev 전용 /_catalog 라우트 (prod 빌드 제외)
// dev 전용 카탈로그 — prod 빌드 제외(B_architecture §3.1)
// meta.layout='bare' → AppShell 미적용 독립 화면, beforeEach bootstrap 통과(bare 면제)
if (import.meta.env.DEV) {
  routes.splice(routes.length - 1, 0, {
    path: '/_catalog',
    meta: { layout: 'bare' },
    component: () => import('@/dev/catalog/CatalogLayout.vue'),
    children: [
      { path: '', name: 'catalog-home',
        component: () => import('@/dev/catalog/CatalogHome.vue') },
      { path: 'button', name: 'catalog-button',
        component: () => import('@/dev/catalog/stories/VButton.story.vue') },
      // ... base 8종 + composite(S2a/S2b) + layout(S2c) 스토리 라우트
    ],
  })
}
