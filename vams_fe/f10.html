AI 골라보기 (Watch Pick)

장면·인물·비식별 그룹 축으로 묶인 클립을 타임라인에서 편집하는 bare 풀스크린 에디터입니다. 구간 타임라인과 시퀀스 타임라인 2개의 독립 뷰포트, BE 프레임 기반 필름스트립, 클립 추가·제외·분할과 50단계 undo/redo를 갖추며 모든 편집은 로컬 스테이징 후 [저장] 1회로만 서버에 반영됩니다.

기능 개요

AI 골라보기는 시청자가 특정 인물·장면만 골라 볼 수 있도록 AI가 뽑아낸 클립 구간을 운영자가 검수·편집하는 메뉴입니다. 목록(WatchPickListPage)과 우측 WatchPickDetailPanel은 다른 메뉴와 동일한 공통 리스트 패턴을 따르고, [검수]로 AppShell 밖 bare 풀스크린 편집화면 WatchPickEditPage에 진입합니다. 편집화면은 상단 정보바(ClipInfoBar)와 툴바, 가운데 플레이어(WatchPickEditPlayer)·재생 박스, 하단 구간 타임라인(WatchPickRangeTimeline)과 시퀀스 타임라인(WatchPickSequenceTimeline), 그리고 클립 카드 그리드(ClipCardGrid)로 구성됩니다.

편집 데이터는 2단계 조회로 조립됩니다. 먼저 목록과 같은 fetchWatchPickDetail로 콘텐츠 정보를 얻고, 편집 결과는 fetchWatchPickResult가 실 계약 4종(C1 flat 행 · C3 행동코드 · C4 인물 · C5 비식별 그룹)을 병렬 호출해 어댑터에서 조인합니다. 이 중 필수는 C1뿐입니다 — 나머지 셋은 표시명 조인 소스라 Promise.allSettled로 개별 실패를 빈 배열로 degrade 해 코드·ID 폴백으로 화면을 띄웁니다. 여기에 이번 갱신에서 셰이프 드리프트 방어가 추가됐습니다. API 스펙 v1.0.4에서 C4 응답이 data[]에서 data.personList[]로 한 겹 깊어졌는데, 셰이프가 어긋나면 거부가 아니라 undefined로 이행하고 allSettled는 그것을 성공으로 보기 때문에 degrade가 걸리지 않고 어댑터의 persons.map에서 터져 편집 화면 전체가 뜨지 않았습니다. 지금은 fetch 지점과 settled() 두 곳에서 배열 여부를 확인해 degrade 경로로 되돌립니다.

상태 소유권은 vue-query가 아니라 Pinia watchPickEdit 스토어에 있습니다. result 쿼리는 staleTime: Infinity 로더 전용이고 성공 시 hydrate()가 1회 이관하며, 이후 렌더 소스는 store.result뿐입니다. 클립 저장·추가·제외·분할은 전부 resultMutations.ts의 순수 불변 transform을 스토어 액션으로 감싼 로컬 커밋(네트워크 0)이고, BE 쓰기는 saveWatchPickResult(C2 PATCH, editList 전체 스냅샷) 하나뿐입니다. dirty는 3종으로 분리해 isClipDirty(선택 클립 draft 3필드)·isJobDirty(result !== baselineResult 참조 비교)·isAnyDirty로 나누며, 실행취소는 커서 + 스냅샷 배열 방식으로 50단계(MAX_HISTORY_STEPS)까지 보관합니다. 신규 클립은 임시 ID(TMP_CLIP_ID_PREFIX)로 발급하고 저장 응답의 idMap(없으면 위치 기반 buildIdMapFallback)으로 재매핑합니다.

타임라인은 DOM에 의존하지 않는 순수 ms 뷰포트(useTimelineViewport)로 구현했습니다. 자막 편집기의 WaveSurfer 위임 로직(setViewWindow·zoomCenter·휠 팬·플레이헤드 추종·조작 후 FOLLOW_RESUME_MS 유예)을 DOM 없이 재구현한 것으로, viewStartMs/viewEndMs 두 ref가 진리원이고 나머지는 전부 파생입니다. 구간·시퀀스 타임라인은 이 뷰포트를 각자 1개씩 갖습니다(공유 금지). 좌표 변환은 timeline/scale.ts의 순수 함수(msToX·xToMs·getMsAtClientX·snapToFrame)가 담당합니다. 배경 필름스트립은 초기의 가변폭 LOD 타일 설계를 폐기하고 화면 고정 72×48 그리드로 재설계했습니다 — 타일 위치는 줌·팬에 불변이고 각 타일의 프레임 이미지 내용만 뷰 창에 따라 바뀌며, 임의 시각의 최근접 프레임은 이진탐색(frameUrlAt, O(log n))으로 찾습니다. 프리뷰 높이는 드래그 리사이즈(기본 248 / 최소 92 / 최대 492px)로 조절되며 localStorage에 영속됩니다.

설계 포인트 — 인물 재지정은 전량 로컬
비식별 그룹을 실제 인물로 지정하는 C6(PUT)은 personId를 body·path·query 중 어디로 넘기는지 BE 미확답(WP-C2)이라 배선하지 않았습니다. 인물 재지정 모달(WatchPickPersonAssignModal)은 assignUnknownLocal/excludeUnknownLocal로 전량 로컬 스테이징하고, 결과는 [저장]의 editList 전체 스냅샷에 실려 나갑니다. 엔드포인트는 주석 seam으로만 남겨 두었습니다.

src/features/watch-pick/edit/queries.ts — C4 v1.0.4 셰이프 드리프트 방어 + 조인 degrade
// C4 응답은 v1.0.4 에서 `data[]` → `data.personList[]` 로 한 겹 깊어졌다.
// ⚠️ 셰이프가 어긋나면 거부가 아니라 undefined 로 이행한다 — allSettled 는 그걸 성공으로
// 보므로 빈 배열 degrade 가 안 걸리고 어댑터의 `persons.map` 에서 터진다.
function fetchPersons(contentId: string) {
  return httpGet<WatchPickPersonListResponseDto>(WATCHPICK_API.persons(contentId)).then((r) => {
    const list = r?.data?.personList
    if (!Array.isArray(list)) return []       // degrade 경로로 되돌린다
    return list
  })
}

export async function fetchWatchPickResult(jobId: string): Promise<WatchPickResult> {
  const rows = await fetchResultRows(jobId)   // 필수 — 실패 시 그대로 throw
  const [actionsR, personsR, groupsR] = await Promise.allSettled([
    fetchActionCodes(), fetchPersons(jobId), fetchUnknownGroups(jobId),
  ])
  // fulfilled 라도 값이 배열이 아니면 어댑터에서 터지므로 함께 막는다.
  const settled = <T>(r: PromiseSettledResult<T[]>): T[] =>
    r.status === 'fulfilled' && Array.isArray(r.value) ? r.value : []
  return toWatchPickResult(jobId, rows, settled(actionsR), settled(personsR), settled(groupsR))
}
src/features/watch-pick/edit/composables/useFilmstrip.ts — 최근접 프레임 이진탐색
const TILE_W = 72 // GUI 실측 — 배경 필름스트립 타일 폭(고정, 줌/팬에 불변)

/** 임의 시각(ms)에 가장 가까운 BE 프레임 URL. frames는 어댑터가 timeMs 오름차순 정렬 보장. */
function frameUrlAt(ms: number): string | null {
  const frames = opts.filmstrip.value?.frames
  if (!frames || frames.length === 0) return null
  let lo = 0
  let hi = frames.length - 1
  while (lo < hi) {
    const mid = (lo + hi) >> 1
    if (frames[mid]!.timeMs < ms) lo = mid + 1
    else hi = mid
  }
  if (lo > 0) {
    const prev = frames[lo - 1]!
    const cur = frames[lo]!
    if (Math.abs(prev.timeMs - ms) <= Math.abs(cur.timeMs - ms)) return prev.url
  }
  return frames[lo]!.url
}
src/features/watch-pick/edit/timeline/scale.ts — DOM 무결합 좌표 변환
/** ms → 트랙 내 x좌표(px). 선형 매핑. */
export function msToX(ms: number, viewStartMs: number, viewEndMs: number, trackW: number): number {
  const span = viewEndMs - viewStartMs
  if (span <= 0) return 0
  return ((ms - viewStartMs) / span) * trackW
}

/** el 기준 clientX → ms. rect 기반, clamp[viewStartMs, viewEndMs]. */
export function getMsAtClientX(
  el: HTMLElement,
  clientX: number,
  viewStartMs: number,
  viewEndMs: number,
): number {
  const rect = el.getBoundingClientRect()
  const ratio = rect.width > 0 ? (clientX - rect.left) / rect.width : 0
  const clampedRatio = Math.max(0, Math.min(1, ratio))
  return viewStartMs + clampedRatio * (viewEndMs - viewStartMs)
}
src/features/watch-pick/edit/stores/watchPickEdit.ts — 로컬 스테이징 진입점과 dirty 3종
/** 실행취소/재실행 최대 단계 — 초과 시 oldest 스냅샷 드롭. */
const MAX_HISTORY_STEPS = 50

// shallowRef인 이유: 그래프가 immutable이라 deep reactivity가 불필요(프록시 비용 0), 루트 교체만으로
// 모든 파생 computed가 갱신되며, structuredClone(toRaw()) 같은 프록시 클론 함정도 피한다.
const result = shallowRef<WatchPickResult | null>(null)          // 현재 편집본(렌더 소스)
const baselineResult = shallowRef<WatchPickResult | null>(null)  // 진입 스냅샷 = 마지막 저장 성공본

/** 잡 dirty — 참조 비교 O(1). 모든 transform이 불변 + no-op이 prev를 반환해야 성립. */
const isJobDirty = computed<boolean>(() => result.value !== baselineResult.value)

/** 최초 fetch 성공 → 1회 hydrate. hydratedJobId 가드로 잡 전환 누수 방지(재호출은 no-op). */
function hydrate(jobId: string, r: WatchPickResult): void {
  if (hydratedJobId.value === jobId) return
  hydratedJobId.value = jobId
  result.value = r
  baselineResult.value = r     // 동일 참조(복사 없음)
  history.value = [r]          // 진입 시점 = 히스토리 유일 스냅샷
  historyIndex.value = 0
}
