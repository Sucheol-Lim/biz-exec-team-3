기능 개요

차량 환경에서는 내비 안내·통화·타 미디어가 수시로 음원을 가로채므로, 라디오는 오디오 포커스를 명시적으로 요청하고 변화에 반응해야 합니다. RadioPlayerHelper는 AudioManager.OnAudioFocusChangeListener를 구현하며, MediaPlayer 준비 완료(onPrepared()) 시점에 tryToGetAudioFocus()로 포커스를 요청합니다. Android O 이상에서는 AudioAttributes(USAGE_MEDIA / CONTENT_TYPE_MUSIC)를 담은 AudioFocusRequest로, 그 이하에서는 레거시 requestAudioFocus()로 요청하며, GRANTED 일 때만 재생을 시작합니다.

포커스 변화 콜백 onAudioFocusChange()는 종류별로 다른 회복 정책을 적용합니다. LOSS(영구 상실)는 stopPlayer() 대신 pausePlayer()를 호출해(2022.11.08 변경) recovery 가능 상태로 둡니다. LOSS_TRANSIENT(일시 상실)는 mute, LOSS_TRANSIENT_CAN_DUCK은 볼륨을 0.2로 낮춰 덕킹합니다. 포커스가 GAIN으로 돌아오면 재생 중이던 경우 unmute 하고, 직전이 덕킹 상태였다면 볼륨을 1.0으로 복원합니다.

설계 포인트
영구 상실을 stop 이 아니라 pause 로 처리한 것이 핵심입니다. 이로써 포커스 복귀 또는 사용자 재생 명령 시 같은 채널을 곧바로 이어서 재생할 수 있고, 정지 시에는 abandonAudioFocus()로 포커스를 명시 반환합니다.

핵심 코드

media/RadioPlayerHelper.java — 포커스 요청(O 이상)
private boolean tryToGetAudioFocus() {
    int result;
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
        AudioAttributes attrs = new AudioAttributes.Builder()
                .setUsage(AudioAttributes.USAGE_MEDIA)
                .setContentType(AudioAttributes.CONTENT_TYPE_MUSIC).build();
        AudioFocusRequest req = new AudioFocusRequest.Builder(AudioManagerCompat.AUDIOFOCUS_GAIN)
                .setAudioAttributes(attrs)
                .setOnAudioFocusChangeListener(this).build();
        result = mAudioManager.requestAudioFocus(req);
    } else {
        result = mAudioManager.requestAudioFocus(this, AudioManager.STREAM_MUSIC, AudioManager.AUDIOFOCUS_GAIN);
    }
    return result == AudioManager.AUDIOFOCUS_REQUEST_GRANTED;
}
media/RadioPlayerHelper.java — 포커스 변화별 회복 정책
public void onAudioFocusChange(int focusChange) {
    switch (focusChange) {
        case AudioManager.AUDIOFOCUS_GAIN:
            if (mediaPlayer != null) {
                if (mediaPlayer.isPlaying() && playerState == PlayerState.PLAYER_PLAYING) unMutePlayer();
                if (mAudioFocusStatus == AudioManager.AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK) mediaPlayer.setVolume(1.0f, 1.0f);
            }
            break;
        case AudioManager.AUDIOFOCUS_LOSS:               // 영구 상실 → pause(=recovery 대비)
            if (mediaPlayer != null) { pausePlayer(); playerState = PlayerState.PLAYER_NONE; }
            break;
        case AudioManager.AUDIOFOCUS_LOSS_TRANSIENT:      // 일시 상실 → mute
            if (mediaPlayer != null && mediaPlayer.isPlaying()) mutePlayer();
            break;
        case AudioManager.AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK:  // 덕킹
            if (mediaPlayer != null && mediaPlayer.isPlaying()) mediaPlayer.setVolume(0.2f, 0.2f);
            break;
    }
}
