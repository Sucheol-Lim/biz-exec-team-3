기능 개요

채널 전환은 진입 경로가 여럿이지만 모두 세션 콜백 한 곳으로 모입니다. 화면에서는 RadioFragment의 이전/다음 버튼 클릭과 좌우 스와이프(OnSwipeTouchListener)가 transportControls.skipToNext()/skipToPrevious()를 호출하고, 알림의 prev/next 액션은 radio.playPrevChannel/radio.playNextChannel 브로드캐스트를, 런처도 동일 브로드캐스트를 보냅니다. 서비스 내부 리시버가 이 브로드캐스트를 받아 다시 세션 콜백으로 위임합니다.

세션 콜백의 onSkipToNext()/onSkipToPrevious()는 updatePosition()으로 현재 인덱스를 한 칸 이동시킵니다. 마지막에서 다음으로 가면 0번으로, 0번에서 이전으로 가면 마지막으로 감싸는 순환 구조입니다. 이동한 위치의 MediaMetadata로 onPrepareFromUri() → onPlay()가 이어져 새 채널이 재생되고, 전환 중에는 STATE_SKIPPING_TO_NEXT/PREVIOUS 상태를 세션에 반영해 UI가 로딩 표시를 띄울 수 있게 합니다.

설계 포인트
재생 위치는 서비스의 nowPlayPos와 RadioViewModel의 nowPlayPos 양쪽에서 관리됩니다. 서비스가 권위 있는 위치를 잡고, 메타데이터 변경 콜백(onMetadataChanged)으로 ViewModel 인덱스가 동기화되어 목록·재생 화면의 선택 상태가 맞춰집니다.

핵심 코드

media/RadioBrowserService.java — 순환 인덱스 + skipToNext 콜백
private void updatePosition(Target target, Integer targetPosition) {
    int pos = 0;
    if (target == Target.TARGET_NEXT) {
        pos = nowPlayPos + 1;
        if (pos > mediaItems.size() - 1) pos = 0;          // 끝 → 처음
    } else if (target == Target.TARGET_PREV) {
        pos = nowPlayPos - 1;
        if (pos < 0) pos = mediaItems.size() - 1;           // 처음 → 끝
    } else if (target == Target.TARGET_SPECIFIC) {
        pos = targetPosition;
    }
    nowPlayPos = pos;
}

public void onSkipToNext() {
    updatePosition(Target.TARGET_NEXT, 0);
    MediaMetadataCompat metadataItem = mediaItems.getMetadata(getNowPlayPos());
    radioSession.setPlaybackState(buildPlaybackState(PlaybackStateCompat.STATE_SKIPPING_TO_NEXT));
    onPrepareFromUri(metadataItem.getDescription().getMediaUri(), bundle);  // → onPlay()
}
ui/RadioFragment.java — 버튼·스와이프 → transport control
void onPrevNextButtonClicked(Direction direction) {
    if (direction == Direction.DIRECTION_NEXT)
        requireActivity().getMediaController().getTransportControls().skipToNext();
    else if (direction == Direction.DIRECTION_PREV)
        requireActivity().getMediaController().getTransportControls().skipToPrevious();
}
