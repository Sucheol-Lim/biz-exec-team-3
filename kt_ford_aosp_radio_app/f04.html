SBS 스트림 AES 복호화

Base64Decoder가 assets/encryption.txt의 2줄(암호화된 키 + 시크릿)에서 세션키를 복원한 뒤 AES/ECB/PKCS5Padding으로 SBS 스트림 URL을 복호화합니다.

기능 개요

SBS 온에어 API 응답의 mediaurl은 평문이 아니라 Base64로 인코딩된 AES 암호문입니다. 이를 풀기 위해 Base64Decoder.Decrypt()가 두 단계로 동작합니다. 먼저 getSessionKey()가 앱 assets/encryption.txt 파일을 열어 첫 줄(암호화된 키)과 둘째 줄(시크릿)을 읽고, 둘째 줄을 AES 키로 삼아 첫 줄을 복호화해 실제 "세션키"를 얻습니다. 이 세션키로 다시 mediaurl 암호문을 복호화하면 재생 가능한 SBS 스트림 URL이 나옵니다.

변환 방식은 두 단계 모두 AES/ECB/PKCS5Padding이며, 입력은 Base64.decode()로 디코딩한 바이트 배열입니다. 과거에는 키가 코드에 하드코딩되어 있었으나, 2022년 12월 보안성 검사(8950325) 대응으로 키를 assets 파일로 분리해 소스 코드에서 제거했습니다. 따라서 SBS 재생을 위해서는 encryption.txt 키 파일이 반드시 동봉되어야 정상 복호화됩니다.

보안 참고
세션키 자체가 다시 암호화되어 파일에 저장되는 "키의 키" 구조라, 단순히 파일을 열람해도 평문 세션키가 노출되지 않습니다. 다만 복호화 알고리즘이 ECB 모드라는 점은 보안 관점에서 약점으로 남습니다(소스 기준 사실).

관계. 정적 유틸 Base64Decoder가 Java Cipher로 2단계 AES 복호화를 수행하고, RadioPlayerHelper가 SBS 재생 경로에서 이를 호출합니다.

핵심 코드

util/Base64Decoder.java — 세션키 복원 + URL 복호화
private static final String transformation = "AES/ECB/PKCS5Padding";

public static String Decrypt(Context context, String text) throws Exception {
    String sessionKey = getSessionKey(context);
    if (sessionKey != null) {
        Cipher cipher = Cipher.getInstance(transformation);
        cipher.init(Cipher.DECRYPT_MODE, new SecretKeySpec(sessionKey.getBytes(), "AES"));
        byte[] results = cipher.doFinal(Base64.decode(text, Base64.DEFAULT));
        return new String(results, StandardCharsets.UTF_8);
    }
    return null;
}

private static String getSessionKey(Context context) {
    BufferedReader reader = new BufferedReader(new InputStreamReader(
            context.getAssets().open(Constants.API_KEY_FILE_NAME), StandardCharsets.UTF_8));
    String key       = reader.readLine();   // 1행: 암호화된 키
    String secretKey = reader.readLine();   // 2행: 시크릿
    Cipher cipher = Cipher.getInstance(transformation);
    cipher.init(Cipher.DECRYPT_MODE, new SecretKeySpec(secretKey.getBytes(), "AES"));
    byte[] results = cipher.doFinal(Base64.decode(key, Base64.DEFAULT));
    return new String(results, StandardCharsets.UTF_8);  // 복원된 세션키
}
