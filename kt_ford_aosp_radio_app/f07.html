음성(TTS) "지금 듣고 있는 채널" 응답

런처의 radio.nowPlaying 요청을 받아 현재 재생 채널명을 안내 문구로 만들고 kas.action.app.tts 인터페이스로 런처에 회신합니다(기가지니 음성 명령 시나리오).

기능 개요

"지금 듣고 있는 채널 뭐야?" 같은 음성 명령이 들어오면 기가지니 인사이드 플랫폼/런처가 radio.nowPlaying 브로드캐스트를 보냅니다. RadioBrowserService의 내부 리시버가 이를 받아 sendCurrentPlayInfo()를 메인 핸들러에 post 합니다. 이 메서드는 현재 플레이어 상태를 확인해, 재생 중이면 현재 MediaMetadata에서 채널명(mediaId)을 읽어 R.string.tts_now_playing("지금 듣고 있는 채널은 %s 라디오 입니다.")으로 문구를 만듭니다.

만든 문구는 Utils.sendTTSForLauncher()가 kas.action.app.tts 액션 인텐트에 담아 런처 컴포넌트(LAUNCHER_APP_PACKAGE / LAUNCHER_BROADCAST_PACKAGE)로 직접 보내며, 런처가 이를 음성으로 안내합니다. 일시정지 상태면 "라디오 청취중이 아닙니다."(tts_not_playing)를 보내고, 완전 정지 상태면 회신 없이 런처(기가지니 인사이드)가 자체 처리하도록 둡니다.

설계 포인트
회신은 일반 브로드캐스트가 아니라 setComponent()로 런처의 AppBroadcastReceiver를 명시 지정해 보냅니다. 또한 FLAG_INCLUDE_STOPPED_PACKAGES를 붙여 런처가 정지 상태여도 전달되게 합니다.

흐름. nowPlaying 요청 시 재생 상태를 확인해, 재생 중이면 채널명 안내 문구를, 일시정지면 미청취 문구를 kas.action.app.tts로 회신합니다.

핵심 코드

media/RadioBrowserService.java — 현재 재생 정보 회신
private void sendCurrentPlayInfo() {
    if (radioPlayerHelper.getPlayerState() != RadioPlayerHelper.PlayerState.PLAYER_PLAYING) {
        if (radioPlayerHelper.getPlayerState() == RadioPlayerHelper.PlayerState.PLAYER_PAUSED) {
            Utils.sendTTSForLauncher(this, getResources().getString(R.string.tts_not_playing));
        }
        return;   // 정지 상태는 런처(기가지니 인사이드)에서 처리
    }
    MediaMetadataCompat mediaMetadataCompat = radioPlayerHelper.getCurrentMediaMetaData();
    if (mediaMetadataCompat != null) {
        String title = mediaMetadataCompat.getDescription().getMediaId();
        Utils.sendTTSForLauncher(this, getResources().getString(R.string.tts_now_playing, title));
    }
}
util/Utils.java — kas.action.app.tts 회신
public static void sendTTSForLauncher(Context context, String tts) {
    Intent intent = new Intent();
    intent.setAction(Constants.ACTION_TTS);                 // "kas.action.app.tts"
    intent.putExtra(Constants.KEY_APP_TYPE, Constants.APP_TYPE);
    intent.putExtra(Constants.KEY_TEXT, tts);
    intent.setComponent(new ComponentName(
            Constants.LAUNCHER_APP_PACKAGE, Constants.LAUNCHER_BROADCAST_PACKAGE));
    intent.setFlags(Intent.FLAG_INCLUDE_STOPPED_PACKAGES);
    context.sendBroadcast(intent);
}
