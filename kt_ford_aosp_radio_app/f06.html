기능 개요

이 앱은 KT 차량 런처(com.kt.automotive.service.launcher)와 브로드캐스트 인텐트로 느슨하게 결합됩니다. 수신 경로는 두 곳입니다. 매니페스트에 등록된 RadioReceiver는 앱이 떠 있지 않아도 받을 수 있는 진입용 액션(radio.play, kas.action.app.start, kas.action.app.clear)을 처리하고, RadioBrowserService가 동적 등록한 내부 리시버는 서비스가 살아 있는 동안의 제어 액션(다음/이전 채널, 정지·셧다운·clear, nowPlaying)을 처리합니다.

radio.play로 들어오면 RadioReceiver가 extras의 metadata(예 {"Channel":"SBS 파워 FM"})를 파싱해 특정 채널 재생 의도를 인텐트에 담은 뒤 startForegroundService()로 서비스를 띄웁니다. 정지 계열 액션(radio.stop, kas.action.app.stop/shutdown/clear)은 서비스 내부 리시버가 받아 세션 콜백의 onStop()으로 위임합니다. 한편 MainActivity도 별도 리시버로 kas.action.app.back(→ moveTaskToBack)과 정지·종료(→ finish)를 처리해 화면 수준 동작을 담당합니다.

설계 포인트
모든 런처 액션 문자열과 키는 Constants에 한곳으로 모여 있습니다. 보안성 검사(8950324) 대응으로 매니페스트의 exported 속성을 명시 제거해 기본값을 사용하도록 정리했습니다.

흐름. 진입 액션은 매니페스트 리시버가, 가동 중 제어 액션은 서비스 내부 리시버가 받아 세션 콜백으로 위임합니다.

핵심 코드

receiver/RadioReceiver.java — radio.play 진입 처리
if (action.equals(Constants.ACTION_START_RADIO)) {        // "radio.play"
    Intent startIntent = new Intent(context, RadioBrowserService.class);
    startIntent.putExtra(Constants.KEY_PLAY_WITH_START_SERVICE, true);
    Bundle bundle = intent.getExtras();
    if (bundle != null) {
        String metaData = bundle.getString("metadata");  // {"Channel":"SBS 라디오"}
        if (metaData != null) {
            String channel = Utils.getJsonElementToString(
                    Utils.getStringToJsonObject(metaData), Constants.INTENT_KEY_CHANNEL);
            if (channel != null) {
                startIntent.putExtra(Constants.INTENT_KEY_CHANNEL, channel);
                startIntent.putExtra(Constants.KEY_PLAY_WITH_START_SERVICE, false);
            }
        }
    }
    context.startForegroundService(startIntent);
} else if (action.equals(Constants.KAS_ACTION_APP_CLEAR)) {
    RadioPreferenceManager.getInstance().resetData();
}
media/RadioBrowserService.java — 가동 중 제어 액션 분기
switch (action) {
    case Constants.ACTION_NEXT_CHANNEL:  getRadioSessionCallback().onSkipToNext();     break;
    case Constants.ACTION_PREV_CHANNEL:  getRadioSessionCallback().onSkipToPrevious(); break;
    case Constants.ACTION_STOP_RADIO:
    case Constants.KAS_ACTION_APP_STOP:
    case Constants.KAS_ACTION_APP_SHUTDOWN:
    case Constants.KAS_ACTION_APP_CLEAR: getRadioSessionCallback().onStop();           break;
    case Constants.ACTION_NOW_PLAYING:   new Handler().post(() -> sendCurrentPlayInfo()); break;
}
