기능 개요

RadioNotification은 미디어 컨트롤 알림을 만들고 포그라운드 서비스 상태를 관리합니다. 생성자에서 알림 채널(KT.RADIO, IMPORTANCE_LOW)과 이전/정지/다음 세 가지 알림 액션을 미리 구성합니다. 각 액션은 각각 radio.playPrevChannel·radio.stop·radio.playNextChannel 브로드캐스트를 보내는 PendingIntent입니다.

RadioPlayerHelper가 재생 상태를 바꿀 때마다 updateSessionPlaybackStateAndNotification()을 거쳐 RadioNotification.update(metadata, state)가 호출됩니다. 이 메서드는 현재 상태가 STOPPED/NONE/ERROR 면 stopForeground(true)로 알림을 내리고, 그 외(재생/연결/일시정지)에는 채널명·아이콘·MediaStyle(compact 뷰에 3개 액션 노출)을 채운 알림을 만들어 notify()한 뒤 startForeground(NOTIFICATION_ID, notification)으로 포그라운드 상태를 갱신합니다. 알림 본문을 누르면 MainActivity가 단일 인스턴스(SINGLE_TOP)로 다시 떠 재생 화면으로 복귀합니다.

설계 포인트
알림 갱신과 포그라운드 승격이 한 메서드에 묶여 있어, "재생 중이면 항상 포그라운드 + 알림 표시, 멈추면 둘 다 해제"라는 불변식이 단일 지점에서 보장됩니다.

핵심 코드

media/RadioNotification.java — 상태별 알림 갱신 + 포그라운드
public void update(MediaMetadataCompat metadata, PlaybackStateCompat playbackState) {
    if (playbackState.getState() == PlaybackStateCompat.STATE_STOPPED
            || playbackState.getState() == PlaybackStateCompat.STATE_NONE
            || playbackState.getState() == PlaybackStateCompat.STATE_ERROR) {
        service.stopForeground(true);
        return;
    }
    NotificationCompat.Builder b = new NotificationCompat.Builder(service, channelId);
    b.setSmallIcon(R.drawable.radio_app_icon);
    b.setLargeIcon(metadata.getDescription().getIconBitmap());
    b.addAction(mPlayPrevAction); b.addAction(mStopAction); b.addAction(mPlayNextAction);
    b.setContentTitle(metadata.getDescription().getTitle());
    // 알림 클릭 → MainActivity(SINGLE_TOP) 복귀
    b.setContentIntent(resumePendingIntent);
    androidx.media.app.NotificationCompat.MediaStyle style = new androidx.media.app.NotificationCompat.MediaStyle();
    style.setShowActionsInCompactView(0, 1, 2);
    b.setStyle(style);
    notification = b.build();
    notificationManager.notify(NOTIFICATION_ID, notification);
    service.startForeground(RadioNotification.NOTIFICATION_ID, notification);
}
