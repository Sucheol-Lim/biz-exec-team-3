백그라운드 지속 재생

MediaBrowserServiceCompat + MediaSessionCompat 기반 포그라운드 서비스로 동작해, Activity가 닫히거나 다른 앱으로 전환돼도 라디오 재생이 끊기지 않습니다.

기능 개요

재생 코어는 화면(MainActivity)과 완전히 분리된 RadioBrowserService로 구현되어 있습니다. 이 서비스는 MediaBrowserServiceCompat을 상속하고, 내부에 MediaSessionCompat과 그 콜백 RadioSessionCallback을 두어 미디어 컨트롤 표준(play/pause/stop/skipNext/skipPrev)을 처리합니다. UI는 RadioClient(MediaBrowser 클라이언트)를 통해서만 서비스에 연결되므로, 화면이 백그라운드로 가도 재생 상태는 서비스 안에서 유지됩니다.

재생이 시작되면 서비스는 startForegroundService()로 기동되고, RadioNotification.update()가 호출되어 startForeground()로 포그라운드 서비스 상태가 됩니다. 이렇게 포그라운드 서비스가 되면 시스템이 메모리 회수 대상에서 우선순위를 낮춰 백그라운드에서도 스트림 재생이 지속됩니다. 정지(onStop()) 시에는 세션을 비활성화·release 하고 stopSelf()로 서비스를 종료합니다.

설계 포인트
세션의 FLAG_HANDLES_MEDIA_BUTTONS / FLAG_HANDLES_TRANSPORT_CONTROLS 플래그를 켜고 setActive(true)로 활성화해, 미디어 버튼·알림 액션·클라이언트 transport control 이 모두 동일한 세션 콜백으로 수렴하도록 했습니다.

흐름. 클라이언트가 세션 transport control 로 재생을 요청하면 세션 콜백이 서비스를 포그라운드로 승격하고 알림을 갱신해 백그라운드 재생을 유지합니다.

관계. RadioBrowserService가 미디어 브라우저 서비스를 상속하고 세션·콜백·알림을 소유하여 UI 없이도 재생 수명주기를 관리합니다.

핵심 코드

media/RadioBrowserService.java — 세션 생성·활성화(onCreate)
radioSession = new MediaSessionCompat(this, TAG);
radioSessionCallback = new RadioSessionCallback();
radioSession.setFlags(
        MediaSessionCompat.FLAG_HANDLES_MEDIA_BUTTONS |
        MediaSessionCompat.FLAG_HANDLES_TRANSPORT_CONTROLS);
radioSession.setPlaybackState(stateBuilder.build());
radioSession.setCallback(radioSessionCallback);
radioSession.setActive(true);
setSessionToken(radioSession.getSessionToken());

radioNotification  = new RadioNotification(this);
radioPlayerHelper  = new RadioPlayerHelper(this, radioSession, radioNotification);
media/RadioBrowserService.java — onPlay 에서 포그라운드 서비스 기동
public void onPlay() {
    if (!isServiceStarted()) {
        Intent intent = new Intent(getApplicationContext(), RadioBrowserService.class);
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            startForegroundService(intent);
        } else {
            startService(intent);
        }
    }
    MediaMetadataCompat metadataItem = mediaItems.getMetadata(getNowPlayPos());
    radioSession.setMetadata(metadataItem);
    radioPlayerHelper.prepareChannel(metadataItem);   // 이후 notification.update → startForeground
}
