기능 개요

MBC·SBS를 제외한 나머지 채널은 채널 데이터의 mediaUri 자체가 곧바로 재생 가능한 HLS(.m3u8) 스트림입니다. 따라서 RadioPlayerHelper.playChannel()이 채널명에서 "MBC"·"SBS"를 찾지 못하면 playOtherChannel()로 떨어지고, 여기서는 사업자 API 호출 없이 mediaUri를 그대로 playFromUri()에 넘깁니다.

playFromUri()는 MediaPlayer 인스턴스를 준비(필요 시 reset())하고 setDataSource() 후 prepareAsync()를 호출합니다. 준비가 끝나면 onPrepared() 콜백에서 오디오 포커스를 얻은 뒤 start()로 재생을 시작합니다. 동일 채널을 다시 누른 경우(mediaChanged == false이고 이미 재생 중)에는 데이터 소스를 다시 설정하지 않고 재생 상태/알림만 갱신해 불필요한 재버퍼링을 막습니다.

설계 포인트
세 경로(MBC/SBS/기타)가 모두 마지막에 playFromUri(metadata, uri)로 합류합니다. 즉 "어떤 URL을 얻느냐"만 다르고 실제 MediaPlayer 제어·오디오 포커스·알림 흐름은 단일 경로로 공유됩니다.

핵심 코드

media/RadioPlayerHelper.java — 기타 채널 직접 재생
private void playOtherChannel(MediaMetadataCompat metadata) {
    // 채널 데이터의 mediaUri(.m3u8)를 그대로 재생
    playFromUri(metadata, metadata.getDescription().getMediaUri());
}

private void playFromUri(MediaMetadataCompat metadata, Uri uri) {
    boolean mediaChanged = (mCurrentMediaMetaData == null || getCurrentMediaChanged(metadata));
    if (mediaPlayer == null) {
        mediaPlayer = new MediaPlayer();
        mediaPlayer.setAudioStreamType(AudioManager.STREAM_MUSIC);
        mediaPlayer.setOnCompletionListener(this);
        mediaPlayer.setOnPreparedListener(this);
        mediaPlayer.setOnErrorListener(this);
    } else if (mediaChanged || !mediaPlayer.isPlaying()) {
        mediaPlayer.reset();
    }
    if (mediaChanged || !mediaPlayer.isPlaying()) {
        mCurrentMediaMetaData = metadata;
        mediaPlayer.setDataSource(uri.toString());
        mediaPlayer.prepareAsync();
    }
}
