기능 개요

야간 주행 시 화면 눈부심을 줄이기 위해 주간·야간 테마를 분리합니다. 리소스 차원에서는 values/values-night 색상 세트와 drawable-*/drawable-night-* 드로어블 세트를 각각 두어, 단말이 night uiMode 일 때 자동으로 야간 리소스가 선택됩니다. 예를 들어 radio_text_playing 색상이 주간 #3EBCFF에서 야간 #2CA6CF로 바뀝니다.

런타임 분기는 두 곳에서 거듭니다. MainActivity.onCreate()가 AppCompatDelegate.setDefaultNightMode(MODE_NIGHT_AUTO_BATTERY)로 야간 모드 정책을 설정하고, onConfigurationChanged()에서 uiMode 변경을 감지하면 nav host Fragment 를 detach/attach 해 새 리소스로 다시 그립니다. 어댑터·프래그먼트는 Utils.isNightMode(config)로 현재 모드를 판별해, 예컨대 ChannelListAdapter가 야간이면 로고 투명도를 0.88로 낮추는 식의 미세 조정을 합니다.

설계 포인트
테마 전환의 큰 줄기는 Android 리소스 한정자(-night)에 위임하고, 코드에서는 (1) 모드 정책 설정, (2) uiMode 변경 시 Fragment 재생성, (3) 투명도 같은 세부 보정만 담당합니다. 덕분에 색·이미지 교체는 리소스 파일 추가만으로 처리됩니다.

흐름. uiMode 가 야간으로 바뀌면 Fragment 가 재생성되며 -night 리소스가 선택되고, 어댑터는 야간 투명도로 미세 보정합니다.

관계. MainActivity가 야간 모드 정책을 잡고, Utils.isNightMode() 판별을 어댑터가 활용하며, 색·이미지는 -night 리소스가 담당합니다.

핵심 코드

util/Utils.java — uiMode 야간 여부 판별
public static boolean isNightMode(Configuration config) {
    return (config.uiMode & Configuration.UI_MODE_NIGHT_MASK)
            == Configuration.UI_MODE_NIGHT_YES;
}
ui/ChannelListAdapter.java — 야간 시 로고 투명도 조정
// 생성자: ChannelListFragment 에서 Utils.isNightMode(...) 결과 주입
public ChannelListAdapter(RadioViewModel vm, RadioItemCallback listener, boolean isNight) {
    this.isNight = isNight;
}
private float getOpacity() {
    return isNight ? 0.88f : 1.0f;   // 야간엔 살짝 흐리게
}
// onBindViewHolder: holder.binding.imageChannelListItemLogo.setAlpha(getOpacity());
