적응형 멀티윈도우 UI

기능 개요

차량 디스플레이는 차종마다 해상도가 다르고 split screen 멀티윈도우에서 half 크기로도 표시됩니다. 이를 위해 리소스는 해상도(dpi)·방향별로 layout/layout-port/layout-ldpi, drawable-port-* 등으로 분기되고, 런타임에서는 RadioViewModel이 멀티윈도우 여부(isInMultiWindowMode)와 실제 방향(realOrientation)을 LiveData로 들고 있습니다. RadioFragment·ChannelListFragment가 이 값을 관찰해 half/full 스타일과 RecyclerView span 수를 동적으로 바꿉니다.

MainActivity는 onMultiWindowModeChanged()에서 ViewModel 의 멀티윈도우 플래그를 갱신하고, onConfigurationChanged()에서 uiMode 가 바뀌면 nav host Fragment 를 detach/attach 하여 새 리소스로 재생성합니다. 또한 setConfigFromRealOrientation()이 시스템 Configuration 의 방향을 실제 화면 방향(Utils.getScreenOrientation())에 강제로 맞춰, split 환경에서 방향이 어긋나 잘못된 레이아웃이 선택되는 문제를 보정합니다. RadioFragment.initView()는 멀티윈도우면 initViewHalfStyle(), 아니면 initViewFullStyle()을 적용하고 Airbnb Paris 로 텍스트/마진 스타일을 동적 지정합니다.

설계 포인트
KT Ford 향은 Freedom·PIP 모드를 쓰지 않고 시스템이 half 로 고정한 split screen 만 사용합니다. 그래서 분기 기준이 "멀티윈도우 on/off × 가로/세로" 네 조합으로 단순화되어 있고, 채널 목록 span 수도 이 조합으로 1 또는 2로 결정됩니다.

핵심 코드

ui/MainActivity.java — uiMode 변경 시 Fragment 재생성
public void onConfigurationChanged(Configuration newConfig) {
    setConfigFromRealOrientation(newConfig);
    if (uiMode != newConfig.uiMode) {           // 주야간 등 uiMode 전환
        FragmentManager fm = getSupportFragmentManager();
        Fragment fragment = fm.findFragmentById(R.id.nav_host);
        if (fragment != null) {
            fm.beginTransaction().detach(fragment).commit();
            fm.beginTransaction().attach(fragment).commit();   // 새 리소스로 재생성
        }
        uiMode = newConfig.uiMode;
    }
}
ui/ChannelListFragment.java — 멀티윈도우·방향별 span 결정
private int getSpanCount() {
    if (viewModel.getRealOrientation() == Configuration.ORIENTATION_PORTRAIT) {
        return 1;                                  // 세로: 1열
    } else {
        return viewModel.isInMultiWindowMode() ? 1 : 2;  // 가로 half:1, full:2
    }
}
