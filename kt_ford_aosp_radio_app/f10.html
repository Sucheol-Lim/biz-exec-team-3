마지막 청취 채널 복원

RadioPreferenceManager(SharedPreferences)가 마지막 청취 위치(LCW)를 저장·복원해, 재실행 시 직전에 듣던 채널로 이어집니다.

기능 개요

사용자가 마지막에 듣던 채널을 기억하기 위해 RadioPreferenceManager가 SharedPreferences(kt.ford.radio.service)에 채널 인덱스를 LCW(last channel watched) 키로 저장합니다. 이 매니저는 LazyHolder 싱글턴이며, RadioApplication.onCreate()에서 init(context)로 한 번 초기화됩니다.

저장 시점은 재생이 시작되는 세션 콜백 onPlay()로, 현재 nowPlayPos를 setIntValue(LCW, pos)로 기록합니다. 복원 시점은 서비스 생성 onCreate()로, getSavedPlayListPosition()이 저장된 인덱스를 읽어 updatePosition(TARGET_SPECIFIC, ...)으로 시작 위치를 맞춥니다. 따라서 차량을 재시동하거나 앱을 다시 실행해도 직전 채널부터 이어집니다. 런처가 kas.action.app.clear를 보내면 resetData()가 LCW를 0으로 되돌려 첫 채널로 초기화합니다.

설계 포인트
복원 값은 인덱스(int)만 저장합니다. 채널 카탈로그가 ChannelListItems에 고정되어 있어 인덱스만으로 동일 채널을 가리킬 수 있으므로, URL·메타데이터를 따로 저장하지 않아 구현이 단순합니다.

핵심 코드

media/RadioBrowserService.java — 복원/저장 진입점
// onCreate(): 저장된 위치로 시작 채널 복원
updatePosition(Target.TARGET_SPECIFIC, getSavedPlayListPosition());

private int getSavedPlayListPosition() {
    return RadioPreferenceManager.getInstance().getIntValue(RadioPreferenceManager.LCW);
}

// onPlay(): 현재 위치를 LCW 로 저장
private void savePlayListPosition(int val) {
    RadioPreferenceManager.getInstance().setIntValue(RadioPreferenceManager.LCW, val);
}
manager/RadioPreferenceManager.java — LCW 보관/초기화
public static final String LCW = "key.last.channel.watched";

public void setIntValue(String key, int value) {
    servicePreferences.edit().putInt(key, value).apply();
}
public int getIntValue(String key) {
    return servicePreferences.getInt(key, 0);
}
public void resetData() {                       // kas.action.app.clear 대응
    servicePreferences.edit().putInt(LCW, 0).commit();
}
