다국어 리소스 (한/영)

기능 개요

앱은 기본 로케일(한국어) 문자열을 res/values/strings.xml에 두고, 영문 로케일을 위한 res/values-en-rUS/strings.xml을 추가로 제공합니다. 단말 로케일이 미국 영어면 Android 리소스 시스템이 자동으로 영문 세트를 선택하므로, 앱 이름이 한국어에서는 라디오, 영문에서는 Radio로, 채널 목록 제목이 채널 리스트에서 Channel List로 전환됩니다. 이 영문 리소스는 릴리스 v1.0.7(2023-01-30 "add english resource") 커밋에서 추가되었습니다.

전환은 코드 분기 없이 전적으로 Android 리소스 한정자(-en-rUS)에 위임됩니다. 매니페스트의 android:label="@string/app_name"과 UI의 @string/... 참조가 그대로 현재 로케일의 값으로 해석됩니다. 다만 TTS 안내 문구(tts_now_playing 등)는 translatable="false"로 한국어 고정이며, 영문 세트에는 포함되지 않습니다.

설계 포인트
영문 세트는 사용자 가시 텍스트(앱 이름·채널 목록 제목·헤더)만 번역하고, 기가지니 음성 안내 문구는 한국어로 고정했습니다. 음성 시나리오가 국내 라디오·한국어 TTS 전제이기 때문입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant SYS as 시스템(Locale) participant RES as Resource Resolver participant KO as values/strings.xml (한국어) participant EN as values-en-rUS/strings.xml (영문) participant UI as MainActivity / 라벨 UI->>RES: getString(R.string.app_name) alt Locale = en-rUS RES->>EN: app_name EN-->>UI: "Radio" else 그 외(기본 한국어) RES->>KO: app_name KO-->>UI: "라디오" end

흐름. 동일한 @string/app_name 참조가 단말 로케일에 따라 한국어/영문 리소스로 해석됩니다.

클래스 다이어그램

classDiagram class StringResources_ko { app_name = "라디오" channel_list = "채널 리스트" text_radio_header_title = "라디오" tts_now_playing (translatable=false) } class StringResources_en { app_name = "Radio" channel_list = "Channel List" text_radio_header_title = "Radio" } class AndroidResourceResolver { +resolve(resId, locale) } class UIConsumers { AndroidManifest label Fragment header / 목록 제목 } AndroidResourceResolver ..> StringResources_ko : 기본 AndroidResourceResolver ..> StringResources_en : en-rUS UIConsumers ..> AndroidResourceResolver : getString

관계. 동일 string id 에 대해 리졸버가 로케일별 문자열 세트를 선택하고, 매니페스트·UI 가 그 결과를 소비합니다.

핵심 코드

res/values/strings.xml — 기본(한국어)
<resources>
    <string name="app_name">라디오</string>
    <string name="channel_list">채널 리스트</string>
    <string name="text_radio_header_title">라디오</string>
    <string name="tts_now_playing" translatable="false">지금 듣고 있는 채널은 %s 라디오 입니다.</string>
</resources>
res/values-en-rUS/strings.xml — 영문(미국)
<resources>
    <string name="app_name">Radio</string>
    <string name="channel_list">Channel List</string>
    <string name="text_radio_header_title">Radio</string>
</resources>
