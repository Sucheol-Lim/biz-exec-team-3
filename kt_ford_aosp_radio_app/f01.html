기능 개요

라디오 앱이 제공하는 채널은 별도 서버에서 내려받지 않고 ChannelListItems 클래스 안에 12개로 하드코딩되어 있습니다. KBS는 판권 문제로 제외되었으며, MBC 표준 FM·FM4U, SBS 파워 FM·러브 FM, TBS FM·eFM, 아리랑 FM, BBS 불교방송, FEBC 극동방송, CTS 라디오·라디오 JOY, 국악방송이 순서대로 등록됩니다.

ChannelListItems는 ArrayList<MediaBrowserCompat.MediaItem>를 상속해, 각 채널을 채널명(mediaId)·스트림 URL(mediaUri)·아이콘 드로어블(일반/큰 사이즈)을 담은 MediaItem으로 만듭니다. 이 리스트는 재생 코어 RadioBrowserService의 onLoadChildren()에서 HOME 브라우저블 노드의 자식으로 노출되고, UI 측 RadioClient가 구독해 채널 목록 화면(RecyclerView)에 표시합니다.

채널명은 재생 분기의 기준이기도 합니다. RadioPlayerHelper.playChannel()이 mediaId에 "MBC" / "SBS" 포함 여부를 보고 사업자 API 호출 또는 HLS 직접 재생으로 분기하므로, 채널명은 단순 표시값이 아니라 동작 분기 키 역할을 합니다.

설계 포인트
채널이 코드에 고정되어 있어 채널 추가·URL 변경 시 앱 빌드·배포가 필요합니다. 대신 외부 채널 디렉터리 서버 의존성이 없어 단말 부팅 직후에도 채널 목록이 즉시 준비됩니다.

private void initRadioList() {
    add(createMediaItem("MBC 표준 FM", "https://sminiplay.imbc.com/ktsecureurl.ashx?channel=sfm", R.drawable.thum_radio_mbc, R.drawable.thum_radio_mbc_m));
    add(createMediaItem("MBC FM4U",   "https://sminiplay.imbc.com/ktsecureurl.ashx?channel=mfm", R.drawable.thum_radio_mbcfm, R.drawable.thum_radio_mbcfm_m));
    add(createMediaItem("SBS 파워 FM", "https://apis.sbs.co.kr/gorealra-api/1.0/onair/kt/channel/POWERFM", R.drawable.thum_radio_sbs, R.drawable.thum_radio_sbs_m));
    add(createMediaItem("SBS 러브 FM", "https://apis.sbs.co.kr/gorealra-api/1.0/onair/kt/channel/LOVEFM", R.drawable.thum_radio_sbs, R.drawable.thum_radio_sbs_m));
    add(createMediaItem("TBS FM",     "https://cdnfm.tbs.seoul.kr/.../playlist.m3u8", R.drawable.thum_radio_tbs, R.drawable.thum_radio_tbs_m));
    // ... 아리랑 FM / BBS / FEBC / CTS / CTS JOY / 국악방송 (총 12개)
}

private MediaBrowserCompat.MediaItem createMediaItem(String mediaId, String uri, int drawable, int drawableBig) {
    return new MediaBrowserCompat.MediaItem(new MediaDescriptionCompat.Builder()
            .setMediaId(mediaId)
            .setMediaUri(Uri.parse(uri))
            .setIconBitmap(BitmapFactory.decodeResource(context.getResources(), drawable))
            .setTitle(mediaId)
            .setExtras(bundle)
            .build(), MediaBrowserCompat.MediaItem.FLAG_PLAYABLE);
}
