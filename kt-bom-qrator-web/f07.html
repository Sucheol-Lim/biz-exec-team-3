큐톤(Cue-tone) 광고 트리거

방송 큐톤(Cue-tone) 광고 메시지 수신 시 광고 연동 트리거를 노출합니다. 캐시된 큐톤 캠페인 목록에서 자산을 매칭해 표시하고, RED 키 입력 시 BOM 서버의 getCuetoneCmpInfo(BW016)로 캠페인 정보를 받아 링크를 실행합니다.

기능 개요

큐톤 트리거의 진입점은 qrator의 QRT_SHOW_TRIGGER_WHEN_CUETONE_AD 메시지입니다. qrator._processResponseQrtShowTriggerWhenCuetoneAD가 먼저 위젯/BOM 앱/sharpUi 실행 여부를 확인하고, 옵저버에 obs_isLoadingUnboundApplication으로 다른 언바운드 앱이 없음을 확인한 뒤에야 cuetoneAD.show(assetId, subscriptionId, campaignId, adId, requestCode)를 호출합니다.

CuetoneADModel은 부팅 시 캐시 서버에서 큐톤 캠페인 목록을 받아 localStorage에 보관합니다. show()가 호출되면 findCampaign()이 자산/구독/캠페인 ID로 매칭하고 노출 유효시간(START_TIME~END_TIME)을 검사해 캠페인을 찾습니다. 캠페인이 있으면 CuetoneADTrigger 뷰로 트리거를 그리고, SHOW_TIME초 후 자동으로 비활성화(_deactivate)되는 타이머를 겁니다.

사용자가 RED 키를 누르면 _executeLink이 requestCampaignInfo로 getCuetoneCmpInfo(BW016)를 호출합니다. 요청 데이터에는 stbType_WEBAPP(2)·serviceType(OTV/OTS)·자산·구독·캠페인 ID가 담깁니다. 응답의 link_type·link_param은 brk_executeLink 내부 메시지로 brk에 전달되어 실행됩니다. adId는 cryptoUtil.encryptAESWithCBC로 암호화해 로그에 남깁니다.

채널 변경 시 자동 종료
활성화(_activate) 시점에 broadcast 객체의 onPlayStateChange·onChannelChangeSucceeded·onChannelChangeError를 구독합니다. 광고 노출 중 채널이 바뀌면 즉시 _deactivate되어 트리거가 사라지고 qrator로 제어가 돌아갑니다.

핵심 코드

apps/CuetoneADTrigger/js/CuetoneADModel.js — getCuetoneCmpInfo(BW016) 요청
this.requestCampaignInfo = function (campaign, resultCallback) {
    var urn = ConstRequestBS.GET_CUETONE_CMP_INFO_BW016,
        url = commonProperty.BRK_e7works_serverIp + '/' + urn;

    var data = _mergeObject({
        svcContId: campaign.SVC_CONT_ID,
        assetId:   campaign.ASSET_ID,
        campId:    campaign.CAMP_ID,
        sbscrptnId: campaign.SBSCRPTN_ID
    }, requestFixedData);                  // said / stbType_WEBAPP(2) / serviceType

    _requestByPost(url, data, function (result) {
        if (result.emergency_yn === ConstResponseBS.emergency_yn_CLOSE) return;
        resultCallback(result.sessionId, result.svcContId, result.camp_info);
    }, function (result) {
        test.getCuetoneCmpInfo(resultCallback);
    });
};
apps/CuetoneADTrigger/js/CuetoneAD.js — show: 매칭 캠페인 표시와 SHOW_TIME 타이머
show: function (assetId, subscriptionId, campaignId, adId, requestCode) {
    var campaign = model.findCampaign(assetId, subscriptionId, campaignId);
    if (!campaign) { return; }

    _showTrigger(campaign, function (result) {
        if (result) {
            _activate(campaign, adId, requestCode);   // qrator.show + 채널이벤트 구독
        } else {
            _deactivate();
        }
    });
}
