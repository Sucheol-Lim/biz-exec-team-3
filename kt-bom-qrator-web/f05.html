BOM VOD 트리거

VOD 재생 시작(OAM_VOD_START) 메시지를 받아 콘텐츠 연동형 BOM 캠페인을 노출하는 트리거입니다. 다른 언바운드 앱이 없을 때 표시되며, VOD 종료(OAM_VOD_END) 시 정리됩니다.

기능 개요

VOD 트리거는 홈포탈/옵저버가 보내는 VOD 재생 메시지를 진입점으로 삼습니다. qrator.postMessage.listener가 QRT_VOD_START·OAM_VOD_START·QRT_VOD_END·OAM_VOD_END 메시지를 받으면 bomVodTrigger.qMessage()로 바이패스합니다. VOD 시작 메시지에는 contentID·categoryID·rating 등이 담겨 있어, 이를 currentContentInfo로 보관하고 vodTriggerModel.runCampaign(contentID)으로 콘텐츠에 매칭되는 캠페인을 조회합니다.

표시 흐름(show)은 채널 트리거와 유사합니다. isLoadingUnboundApplication으로 다른 언바운드 앱 실행 여부를 확인하고, 없으면 옵저버에 requestShow를 보낸 뒤 vodTriggerView.show(campData)로 트리거 UI를 그립니다. 진행 중인 채널 트리거가 있으면 VOD 시작 시점에 bomChannelTrigger.clearState(true)로 먼저 정리합니다.

사용자가 빨강(RED) 키를 누르면 _executeLinkType()이 vodTriggerModel.getCampaignInfo()의 link_type을 해석합니다. BOM 앱 실행(1)은 qrt_runBrokeringApp, #채널 이동(9)은 qrt_moveToSharpLink 메시지를 brk에 보내고, 그 외 타입은 brk.handleLinkType()으로 위임합니다. 파랑(BLUE) 키는 "하루 보지 않기"(setInacitveTrigger)를 설정합니다.

트리거 블록 상태
VOD 트리거는 트리거 블록(block) 상태가 아닐 때만 동작합니다. 노출 스케줄·콘텐츠 매칭은 vodTriggerModel이, 사용자 동의·차단 여부 같은 전역 조건은 storageDataManager가 담당합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant HP as 홈포탈/옵저버 participant Q as qrator participant BVT as bomVodTrigger participant MODEL as vodTriggerModel participant OBS as Observer participant BRK as brk HP->>Q: OAM_VOD_START (contentID, categoryID) Q->>BVT: qMessage(event) BVT->>BVT: bomChannelTrigger.clearState(true) BVT->>MODEL: runCampaign(contentID) MODEL-->>BVT: campData (매칭 캠페인) BVT->>OBS: isLoadingUnboundApplication() OBS-->>BVT: res = no BVT->>OBS: requestShow() OBS-->>BVT: yes BVT-->>HP: vodTriggerView.show(campData) Note over BVT: 사용자 RED 키 BVT->>BRK: qrt_runBrokeringApp / handleLinkType HP->>Q: OAM_VOD_END Q->>BVT: clearState(true)

흐름. VOD 시작 메시지 → 채널 트리거 정리 → 콘텐츠 캠페인 조회 → 언바운드 앱 확인 후 표시. RED 키로 link_type별 동작을 brk에 위임하고, VOD 종료 메시지에 트리거를 정리합니다.

관계. bomVodTrigger가 vodTriggerModel(상태·캠페인)·vodTriggerView(렌더)를 소유하고, 콘텐츠 캠페인 조회는 vodTriggerApi(BW009), 링크 실행은 brk에 위임합니다.

핵심 코드

apps/bomVodTrigger/js/main.js — qMessage: VOD 시작/종료 처리
case "qrt_vod_start" :
case "OAM_VOD_START" :
    currentContentInfo = msg;
    // 채널 연동형 트리거 상태 정리
    bomChannelTrigger.clearState(true);
    // VOD 연동형 트리거 스케쥴링 시작
    vodTriggerModel.runCampaign(currentContentInfo.contentID);
    break;

case "qrt_vod_end" :
case "OAM_VOD_END" :
    self.clearState(true);
    break;
apps/bomVodTrigger/js/main.js — _executeLinkType: RED 키 후 링크 분기
var type = parseInt(data.link_type, 10);
if (type === RES.link_type.RUN_BOM_APP_1) {
    _runBomApp({ method: 'qrt_runBrokeringApp', app_id: data.link_param1,
        scene_id: data.link_param2, addition_id: data.link_param3,
        req_cd: C.REQUEST_CODE, contract_id: contractId, content_id: contentId });
} else if (type === RES.link_type.RUN_SHARP_CHANNEL_9) {
    _runBomApp({ method: 'qrt_moveToSharpLink', sharpLink_id: data.link_param1, ... });
} else {
    brk.handleLinkType(type,
        [data.link_param1, data.link_param2, data.link_param3, data.link_param4],
        { _origin: REQ.BW009_getVodCmpInfo, fromApp: C.REQUEST_CODE, ... });
}
