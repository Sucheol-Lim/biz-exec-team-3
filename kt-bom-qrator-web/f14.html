3-프로파일 빌드/배포 파이프라인

Gulp 기반으로 L(운영)/S(BMT)/D(개발) 3종 프로파일(및 로컬 확인용 M/mock)을 빌드해 단말 위젯 패키지 .wgt(zip)로 만들고, 빌드 환경값(build-env.js)을 주입하는 파이프라인입니다. FTP 업로드 코드는 2026-09-18에 전량 제거되었고, 상용(L) 패키지는 gulp tag:live로 git 태그만 생성·push합니다.

기능 개요

빌드는 gulpfile.js에 등록된 콜론 표기 task(dist:*, package:*, tag:live)를 기준으로 합니다. 정식 프로파일은 운영(L)·BMT(S)·개발(D)이며, 각각 config/config-live.json·config-bmt.json·config-develop.json에 e7works·sharp_ui·live_agent·cache·image·tvpay_module 엔드포인트를 둡니다. 여기에 로컬 mock 서버(localhost:9000)를 바라보는 M(config-mock.json) 프로파일이 dist:mock으로만 추가되어 있으며, package:*/tag:live 대상에는 들어가지 않습니다.

dist 파이프라인(distPipeline)은 setTarget → cleanFiles → uglifyJs → copyCommonFiles → copyResFiles → injectSim → createBuildEnv → verifyDistBuildEnv 순서입니다. injectSim은 --sim CLI 플래그가 없으면 아무 것도 하지 않고 건너뜁니다. 핵심은 createBuildEnv로, 프로파일 JSON과 버전/날짜/차수(우선순위 CLI > ENV > config.js > 오늘 날짜)·git 커밋 해시를 모아 dist/common/js/core/build-env.js에 window.BUILD_ENV 객체로 주입합니다. verifyDistBuildEnv는 serverTo가 L/S/D/M인지, 엔드포인트 URL 형식·버전 접미사가 올바른지 검증합니다.

package 파이프라인은 dist 후 makeReleaseRule → createWgt → recordArtifact로 산출물 파일명(KT-BRK-QRATOR-WEB-V<버전>_...wgt 규칙)과 경로를 정하고, gulp-zip으로 dist 전체를 .wgt로 압축합니다. 업로드 단계는 더 이상 없습니다. 상용 패키지에 한해 tag:live(=package:live + gitTagRelease)가 V<버전>_<날짜> git 태그를 만들어 push합니다(SKIP_GIT=1로 태그만 생략 가능, L 이외 serverTo는 태그 생성을 건너뜁니다). 만들어진 .wgt를 저장소 밖으로 내보내는 것은 더 이상 gulp/CI가 아니라 릴리즈 문서 첨부로 사람이 확인 후 수행합니다.

FTP 제거 (2026-09-18)
FTP 서버가 폐지되어 gulp-ftp·deployFtp·deployAll·release:* task와 .env의 FTP_HOST/USER/PASS/REMOTE_PATH를 전량 제거했습니다. 함께 죽어 있던 RELEASES.md 자동 생성 함수(appendReleaseLog·updateReleaseNotes)와 createWgtUnderWorking도 함께 정리했습니다. RELEASES.md는 이제 인계 대장으로, 정식·검토본만 사람이 기록합니다.
PC 랩 자산(--sim)
public/test/sim(앱 내 시뮬레이터)와 public/test/platform(OIPF 스텁·상대 앱 회신)은 기본 빌드에 포함되지 않습니다. gulp dist:live --sim처럼 --sim을 붙여야 dist/common/js/{sim,platform}/로 복사되고 dist/index.html에 스크립트 태그 3줄이 주입됩니다. 인계 빌드에는 쓰지 않습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant DEV as 개발자 (gulp CLI) participant DIST as distPipeline participant ENV as createBuildEnv participant CFG as config-live.json participant PKG as packagePipeline (createWgt) participant GIT as gitTagRelease DEV->>DIST: gulp tag:live --ver .. --date .. --testTo .. DIST->>DIST: setTarget(L) → clean → uglify → copy DIST->>DIST: injectSim() (--sim 없으면 skip) DIST->>ENV: createBuildEnv() ENV->>CFG: 프로파일 엔드포인트 읽기 ENV->>ENV: 버전/날짜/커밋 결정 → build-env.js 출력 DIST->>DIST: verifyDistBuildEnv() (serverTo L/S/D/M 검증) DIST->>PKG: makeReleaseRule → createWgt (zip) → recordArtifact PKG->>GIT: gitTagRelease() — serverTo===L 일 때만 GIT-->>DEV: git tag V버전_날짜 생성 + push (SKIP_GIT=1로 생략)

흐름. tag:live는 dist 빌드 → build-env.js 주입·검증 → .wgt 패키징 → git 태그 생성·push로 끝납니다. FTP 업로드 단계는 2026-09-18에 제거되어, 실제 .wgt 전달은 이 파이프라인 밖(릴리즈 문서 첨부)에서 이뤄집니다. CLI 인자(--ver/--brkV/--date/--testTo)가 .env보다 우선합니다.

클래스 다이어그램

classDiagram class distPipeline { +setTarget(targetKey) +cleanFiles() +uglifyJs() +copyCommonFiles() +copyResFiles() +injectSim(cb) +createBuildEnv(cb) +verifyDistBuildEnv(cb) } class packagePipeline { +makeReleaseRule(cb) +createWgt() +recordArtifact(done) } class tagLive { +gitTagRelease(cb) } class profileConfig { +e7works +sharp_ui +live_agent +cache +image +tvpay_module } class mockProfile { +serverTo M +endpoint localhost 9000 } packagePipeline --|> distPipeline : 선행 series tagLive --|> packagePipeline : 선행 series(live 전용) distPipeline --> profileConfig : createBuildEnv 주입 mockProfile --|> profileConfig : dist mock 전용, package tag 대상 아님

관계. dist → package → tag:live가 gulp.series로 단계적으로 합성되며, tag:live는 package:live 뒤에 gitTagRelease만 이어 붙입니다(구 releasePipeline·deployFtp·release:all은 삭제). createBuildEnv가 프로파일 config를 런타임 값으로 주입하며, mock 프로파일은 dist:mock 전용으로 package/tag 계열과 분리되어 있습니다.

핵심 코드

gulpfile.js — dist/package 파이프라인 합성과 tag:live/dist:mock task 등록
function distPipeline(targetKey) {
    return gulp.series(setTarget(targetKey), cleanFiles, uglifyJs,
        copyCommonFiles, copyResFiles, injectSim, createBuildEnv, verifyDistBuildEnv);
}
function packagePipeline(targetKey) {
    return gulp.series(distPipeline(targetKey), makeReleaseRule, createWgt, recordArtifact);
}
gulp.task('dist:mock',    distPipeline('mock'));     // localhost:9000, package/tag 대상 아님
gulp.task('package:live', packagePipeline('live'));

// tag:live — 상용 패키지를 만든 뒤 V<ver>_<날짜> 태그를 만들어 push (SKIP_GIT=1 로 생략)
gulp.task('tag:live', gulp.series('package:live', gitTagRelease));
gulpfile.js — createBuildEnv: 프로파일 엔드포인트/버전 주입 (mock 프로파일 포함)
const profile = _getJsonFilename(serverTo);                 // L/S/D/M → config 파일
const cfgJson = JSON.parse(fs.readFileSync(path.join('config', `${profile}.json`), 'utf-8'));

const payload = {
    serverTo,
    endpoints: {
        e7works: cfgJson.e7works, sharpUi: cfgJson.sharp_ui,
        liveAgent: cfgJson.live_agent, cache: cfgJson.cache,
        image: cfgJson.image, tvpay: cfgJson.tvpay_module
    },
    versions: { qratorVersion, brkVersion, commit },        // CLI>ENV>config 우선
    generatedAt: new Date().toISOString(),
};
const outFile = path.join(dist, 'common/js/core', 'build-env.js');
const body = `(function (g) { g.BUILD_ENV = ${JSON.stringify(payload, null, 2)}; })(window);\n`;

// verifyDistBuildEnv 에서: serverTo 는 L/S/D/M 만 허용(구버전은 L/S/D)
if (!/^[LSDM]$/.test(obj.serverTo || '')) return cb(new Error('serverTo 값이 올바르지 않습니다.'));
gulpfile.js — gitTagRelease: 상용(L) 패키지에만 태그 생성 (2026-09-18 push 오타 수정)
function gitTagRelease(cb) {
    if (process.env.SKIP_GIT) return cb();                  // 옵셔널: 태그 생략

    if (description.serverTo !== ConstKey.LIVE_L) {
        log('[gitTagRelease] ignored serverTo:' + description.serverTo);
        return cb();                                         // L 이 아니면 태그 생성 없이 종료
    }

    const {qratorV, uploadDate} = description.meta || {};
    const tag = `V${qratorV}_${uploadDate}`;
    // 이미 존재하면 skip (git rev-parse -q --verify refs/tags/<tag>)

    cp.execSync(`git tag -a "${tag}" -m ${JSON.stringify(body)}`, {stdio: 'inherit'});
    cp.execSync(`git push origin ${tag}`, {stdio: 'inherit'});   // 이전: `git push origin -f ${tag}"` (오타·강제push)
    cb();
}
