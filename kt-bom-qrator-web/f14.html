3-프로파일 빌드/배포 파이프라인

Gulp 기반으로 L(운영)/S(BMT)/D(개발) 3종 프로파일을 빌드해 단말 위젯 패키지 .wgt(zip)로 만들고, 빌드 환경값(build-env.js)을 주입한 뒤 FTP로 업로드하는 파이프라인입니다.

기능 개요

빌드는 gulpfile.js에 등록된 콜론 표기 task(dist:*, package:*, release:*)를 기준으로 합니다. 세 프로파일은 운영(L)·BMT(S)·개발(D)이며, 각각 config/config-live.json·config-bmt.json·config-develop.json에 e7works·sharp_ui·live_agent·cache·image·tvpay_module 엔드포인트를 둡니다.

dist 파이프라인(distPipeline)은 setTarget → cleanFiles → uglifyJs → copyCommonFiles → copyResFiles → createBuildEnv → verifyDistBuildEnv 순서입니다. 핵심은 createBuildEnv로, 프로파일 JSON과 버전/날짜/차수(우선순위 CLI > ENV > config.js > 오늘 날짜)·git 커밋 해시를 모아 dist/common/js/core/build-env.js에 window.BUILD_ENV 객체로 주입합니다. verifyDistBuildEnv는 serverTo가 L/S/D인지, 엔드포인트 URL 형식·버전 접미사가 올바른지 검증합니다.

package 파이프라인은 dist 후 makeReleaseRule → createWgt → recordArtifact로 산출물 파일명(KT-BRK-QRATOR-WEB-V<버전>_...wgt 규칙)과 경로를 정하고, gulp-zip으로 dist 전체를 .wgt로 압축합니다. release는 패키지 후 FTP 업로드까지 수행합니다. release:all은 resetArtifacts → package:live → package:bmt → package:develop → deployAll 순으로 3개 .wgt를 모아 한 번에 같은 원격 디렉터리에 올립니다.

task 이름 표기 주의
과거 README의 gulp default·gulp package_live·gulp release_all 표기는 현재 gulpfile.js의 콜론 표기 task(dist:*/package:*/release:*)와 다릅니다. 실행 시 gulp dist:live처럼 콜론(:)을 사용해야 합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant DEV as 개발자 (gulp CLI) participant DIST as distPipeline participant ENV as createBuildEnv participant CFG as config-*.json participant PKG as packagePipeline (createWgt) participant FTP as deployAll / FTP DEV->>DIST: gulp release:all (또는 release:live) DIST->>DIST: setTarget → clean → uglify → copy DIST->>ENV: createBuildEnv() ENV->>CFG: 프로파일 엔드포인트 읽기 ENV->>ENV: 버전/날짜/커밋 결정 → build-env.js 출력 DIST->>DIST: verifyDistBuildEnv() (serverTo/URL 검증) DIST->>PKG: makeReleaseRule → createWgt (zip) PKG->>PKG: recordArtifact (L/S/D 누적) PKG->>FTP: deployAll() — 3개 .wgt 일괄 업로드 FTP-->>DEV: remotePath 업로드 완료

흐름. release:all은 프로파일별 dist 빌드 → build-env.js 주입·검증 → .wgt 패키징 → 아티팩트 누적 → FTP 일괄 업로드로 이어집니다. CLI 인자(--ver/--brkV/--date/--testTo)가 .env보다 우선합니다.

클래스 다이어그램

classDiagram class distPipeline { +setTarget(targetKey) +cleanFiles() +uglifyJs() +copyCommonFiles() +copyResFiles() +createBuildEnv(cb) +verifyDistBuildEnv(cb) } class packagePipeline { +makeReleaseRule(cb) +createWgt() +recordArtifact(done) } class releasePipeline { +deployFtp() } class releaseAll { +resetArtifacts(done) +deployAll() } class profileConfig { +e7works +sharp_ui +live_agent +cache +image +tvpay_module } packagePipeline --|> distPipeline : 선행 series releasePipeline --|> packagePipeline : 선행 series releaseAll --> packagePipeline : L/S/D 반복 distPipeline --> profileConfig : createBuildEnv 주입

관계. dist → package → release가 gulp.series로 단계적으로 합성되고, release:all은 3개 프로파일 package를 모아 deployAll로 일괄 업로드합니다. createBuildEnv가 프로파일 config를 런타임 값으로 주입합니다.

핵심 코드

gulpfile.js — dist/package/release 파이프라인 합성과 task 등록
function distPipeline(targetKey) {
    return gulp.series(setTarget(targetKey), cleanFiles, uglifyJs,
        copyCommonFiles, copyResFiles, createBuildEnv, verifyDistBuildEnv);
}
function packagePipeline(targetKey) {
    return gulp.series(distPipeline(targetKey), makeReleaseRule, createWgt, recordArtifact);
}
gulp.task('dist:live',    distPipeline('live'));
gulp.task('package:live', packagePipeline('live'));
gulp.task('release:all',
    gulp.series(resetArtifacts, 'package:live', 'package:bmt', 'package:develop', deployAll));
gulpfile.js — createBuildEnv: 프로파일 엔드포인트/버전 주입
const profile = _getJsonFilename(serverTo);                 // L/S/D → config 파일
const cfgJson = JSON.parse(fs.readFileSync(path.join('config', `${profile}.json`), 'utf-8'));

const payload = {
    serverTo,
    endpoints: {
        e7works: cfgJson.e7works, sharpUi: cfgJson.sharp_ui,
        liveAgent: cfgJson.live_agent, cache: cfgJson.cache,
        image: cfgJson.image, tvpay: cfgJson.tvpay_module
    },
    versions: { qratorVersion, brkVersion, commit },        // CLI>ENV>config 우선
    generatedAt: new Date().toISOString(),
};
const outFile = path.join(dist, 'common/js/core', 'build-env.js');
const body = `(function (g) { g.BUILD_ENV = ${JSON.stringify(payload, null, 2)}; })(window);\n`;
