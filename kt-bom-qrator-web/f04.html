BOM 채널 트리거

특정 채널 시청 시 화면 위에 노출되는 채널 연동형 BOM 캠페인 트리거입니다. 채널 이동 성공(onChannelChangeSucceeded)을 감지해 시청 시간·노출 시간대·하루 보지 않기 등의 조건을 확인하고, 바운드/언바운드 앱 미실행 시 트리거를 표시합니다.

기능 개요

BOM 채널 트리거는 chTriggerManager(qDaemon)가 관리하는 채널 캠페인 스케줄과 짝을 이룹니다. 매니저는 부팅 시 캐시 서버에서 CMP_CAMP_CH_WEB.json 편성 파일을 받아 localStorage에 저장하고, 단말의 채널 이벤트(onChannelChangeSucceeded)를 구독합니다. 채널이 바뀌면 진행 중인 vod/bom/cmp 트리거를 정리한 뒤 runCampaign(ch)으로 현재 채널의 유효 캠페인을 평가합니다.

getValidCampaign은 노출 시간대(DISP_TIME FR~TO)와 현재 시각을 비교해 유효 캠페인을 고르고, getCurrentChannelCampaignList는 채널 sid 매칭과 "하루 보지 않기"(inactiveChannelList) 설정을 거릅니다. 선택된 캠페인이 반응형(REACT_TYPE)이면 CMP 트리거로, 아니면 chTriggerModel.setCampaign()을 통해 BOM 채널 트리거로 넘어갑니다.

bomChannelTrigger.show()는 표시 전 두 가지를 확인합니다. (1) 바운드 앱이 실행 중인지(oipfUtil.checkRunningBoundApp()), (2) 다른 언바운드 앱이 떠 있는지(obs_isLoadingUnboundApplication). 둘 다 아니고 미디어 재생 시간(getMediaTime())이 양수면 옵저버에 표시 요청 후 트리거를 그립니다. 사용자가 빨강(RED) 키를 누르면 getChannelCampaignInfo(BW008)로 링크 정보를 받아 BOM 앱 실행 등으로 분기합니다.

트리거 상태(triggerState)
chTriggerModel.triggerState는 init / ready / checkOtherApp / show / runBomApp / hide / clear를 거칩니다. 다른 언바운드 앱이 발견되면 checkOtherApp으로 대기했다가, 앱 종료 후 다시 표시를 시도합니다.

흐름. 채널 이동 → runCampaign으로 유효 캠페인 평가 → BOM 트리거면 언바운드 앱/미디어 시간 확인 후 표시. RED 키 입력 시 getChannelCampaignInfo(BW008) 링크 정보로 BOM 앱 실행 등을 brk에 위임합니다.

핵심 코드

apps/qDaemon/chTriggerManager.js — runCampaign: 유효 캠페인 평가와 분기
var currentCampaignList = getCurrentChannelCampaignList(campaignList, ch);
currentChannelCamp = getValidCampaign(currentCampaignList, currentTime);
if (!currentChannelCamp) {
    console.log("chTriggerManager : runCampaign(invalid)");
    return;
}

if (currentChannelCamp.REACT_TYPE) {        // CMP 트리거
    if (self.checkCampaignCondition(currentChannelCamp)) {
        cmpChannelTrigger.setCampaign(currentChannelCamp, currentTime);
    }
} else {                                     // BOM 채널 트리거
    chTriggerModel.setCampaign(currentChannelCamp, currentTime);
}
apps/bomChannelTrigger/js/main.js — show: 언바운드 앱/미디어 시간 확인 후 표시
self.show = function (currentChannelCamp) {
    if (window.oipfObjectFactory && !oipfUtil.checkRunningBoundApp()) {
        self.sendMessage.isLoadingUnboundApplication(function (msg) {
            if (msg.res === "no") {
                if (chTriggerModel.triggerState === 'checkOtherApp') {
                    qrator.setCurrentApp(false);
                    chTriggerModel.setTriggerState('ready');
                } else if (oipfUtil.getMediaTime() > 0) {
                    self.sendMessage.requestShow(function () {
                        _showTrigger(currentChannelCamp);
                    });
                } else {
                    self.hide();
                }
            } else {                          // 다른 언바운드 앱 실행 중
                qrator.setCurrentApp(false);
                chTriggerModel.setTriggerState('checkOtherApp');
            }
        });
    } else {
        _showTrigger(currentChannelCamp);
    }
};
