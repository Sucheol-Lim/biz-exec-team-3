CMP(캠페인) 채널 트리거

스케줄 푸시 기반 캠페인 편성정보 트리거입니다. 알림형(REACT_TYPE=1)과 반응형(REACT_TYPE=2)으로 나뉘며, 다른 앱 실행 시 노출 방식(EXEC_TYPE 1/2)에 따라 강제 종료-후-표시 또는 대기-후-표시로 분기합니다.

기능 개요

CMP 채널 트리거는 채널 트리거(f04)와 동일한 chTriggerManager 스케줄을 공유하지만, 캠페인의 REACT_TYPE이 설정된 "반응형/알림형" 캠페인을 담당합니다. 매니저의 runCampaign이 REACT_TYPE이 있는 캠페인을 발견하면 checkCampaignCondition(플랫폼 타입·가입 상품·마케팅 동의·관심지수·이전 채널 시청 시간 등)을 통과한 경우에 한해 cmpChannelTrigger.setCampaign()으로 넘어옵니다.

표시 시도(_attempt)는 먼저 미디어 재생 시간(getMediaTime() > 0)으로 iframe 노출 여부를 확인합니다. 그다음 실행 타입(EXEC_TYPE)에 따라 두 경로로 갈립니다. EXEC_TYPE=1(isForceExitAndShow)은 최초 1회 다른 앱을 강제 종료하고 표시(_forceExitAndShow)한 뒤, 이후엔 외부 앱이 끝날 때까지 폴링합니다. EXEC_TYPE=2는 다른 앱이 실행 중이면 노출하지 않고 CHECK_OTHER_APP 상태로 대기합니다.

외부 상태 조회(_queryExternalState)는 바운드 앱(checkRunningBoundApp)과 언바운드 앱(obs_isLoadingUnboundApplication) 두 가지를 차례로 확인합니다. 이때 옵저버와의 표시/조회 요청은 요청-응답 라우터(RequestReplyRouter.sendSerial, 5000/4000ms 타임아웃)를 통해 직렬화됩니다. 키 처리는 알림형(_handleAlertKey)과 반응형(_handleResponsiveKey)으로 분리되어, RED(이동/마이크로사이트)·BLUE(하루 보지 않기)·ENTER·ESCAPE·#키 등을 다르게 처리합니다.

캠페인 데이터 정책 (2026.01 KTBOM-291)
알림형(REACT_TYPE=1)은 EXEC_TYPE=1 고정, 반응형(REACT_TYPE=2)은 EXEC_TYPE 취사선택(디폴트 2)입니다. 단 ACAP 단말은 EXEC_TYPE=2로 설정해도 1로 동작하도록 고정됩니다. BOM_APP_INFO가 있으면 트리거 UI 없이 바로 BOM 앱을 실행(_runPBom)합니다.

흐름. 매니저가 반응형 캠페인을 넘기면 _attempt가 미디어 시간·EXEC_TYPE을 평가하고, 요청-응답 라우터로 옵저버 표시를 직렬 요청한 뒤 트리거를 표시합니다. RED 키로 getTemplateId(BW013) 후 링크 실행을 brk에 위임합니다.

핵심 코드

apps/cmpChannelTrigger/main.js — _attempt: EXEC_TYPE 분기
function _attempt(reason) {
    if (_isPlaybackNotStarted()) {            // iframe 노출중이면 차단
        self.hide('playback_not_started');
        return;
    }
    if (cmpChTriggerModel.isForceExitAndShow()) return _attemptExec1(reason); // EXEC_TYPE=1
    _attemptExec2(reason);                                                    // EXEC_TYPE=2
}

function _attemptExec1(reason) {
    if (!cmpChTriggerModel.hasShownOnce()) {  // 최초 1회는 강제 종료 후 표시
        _forceExitAndShow();
        return;
    }
    _queryExternalState(function (extState) {
        if (extState === EXT_STATE.RUNNING) {
            cmpChTriggerModel.setState(TRG_STATE.CHECK_OTHER_APP);
            return;
        }
        _showTriggerFlow();
    });
}
apps/cmpChannelTrigger/main.js — _requestShow: 요청-응답 라우터로 표시 직렬화
function _requestShow(callback) {
    RequestReplyRouter.sendSerial({
        from: C.ID, to: qrator.aid.observer,
        method: C.METHOD.OBS_REQUEST_SHOW,
        payload: { method: C.METHOD.OBS_REQUEST_SHOW, from: qrator.aid.appstore },
        ttlMs: 5000,
        onReply: function (msg) {
            var ok = (msg && (msg.res === 'yes' || msg.res === true));
            if (typeof callback === 'function') callback(ok);
        },
        onTimeout: function () { if (typeof callback === 'function') callback(false); }
    });
}
