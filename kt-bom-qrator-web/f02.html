Brokering 위젯 UI (brk)

BOM(e7works) 서버와 연동해 위젯 상품 목록/상세를 표시하고 BOM 앱을 실행하는 핵심 서브앱입니다. brk_api·brk_amoc·brk_itemList·brk_detailList·brk_oipf·brk_liveAgent 컴포넌트로 구성되며, 상태 머신(hide/show/nouiShow)으로 위젯·BOM 앱·봄업(bomup)을 통제합니다.

기능 개요

brk는 위젯의 본 기능을 담당하는 가장 큰 서브앱으로, locationMVM 기반 앱 매니저(appMgr)와 외부 컴포넌트들을 묶어 동작합니다. brk_api는 BOM(e7works) 서버 호출(위젯 목록 getWidgetMainApp(BW003), 세션 getSessionId(BW005), 봄앱 주소 getWebAppUrl(BW001), #채널 링크 getChannelLinkInfo(BW006) 등)을 담당하고, brk_oipf는 단말 OIPF 정보(SAID/모델/펌웨어)를, brk_amoc는 부가 데이터를, brk_liveAgent는 라이브 에이전트 로그 전송을 맡습니다.

위젯 표시(show)는 메인 페이지 모델(goMain)을 트리거해 getWidgetMainApp으로 앱 목록과 이미지를 받아 1·2 depth 리스트(brk_itemList/brk_detailList)를 그립니다. 가입 불가 상품(prd_cd_black_list)이면 미지원 서비스 팝업을, 이미지 로드 실패면 에러 팝업을 띄웁니다. 사용자가 항목을 고르면 handleLinkType → dispatchActionWithSession으로 링크 타입별 동작(BOM 앱 실행·채널 이동·매시업 등)을 수행합니다.

brk는 외부 메시지의 종착점이기도 합니다. qrator가 qrt_runBrokeringApp·qrt_moveToSharpLink·BOM_* 메시지를 brk.qMessage()로 넘기면, responseMessageCallback 맵으로 메서드별 처리기를 호출합니다. 또한 onTimerBompup·startBomup으로 셋톱 부팅 시 백그라운드 BOM 앱(봄업)을 자동 트리거하는 로직도 포함합니다.

표시 상태(nowState)
brk는 자체 상태 hide(미표시) · show(위젯 UI 표시) · nouiShow(UI 없이 BOM 앱만 백그라운드 실행)를 가집니다. isActiveState()는 show 또는 nouiShow를 의미하며, 트리거·샤프키 등 다른 서브앱이 충돌 여부를 판단할 때 이 상태를 조회합니다.

핵심 코드

apps/brk/js/main.js — requestShow: 옵저버 승인 후 위젯 표시
requestShow: function (link) {
    (function trigger(isShowSharpUi) {
        if (isShowSharpUi) {                  // 샵 UI가 떠 있으면 먼저 종료
            sharpUi.requestHide(function () { trigger(); });
        } else {
            _turnOnBrk(function (message) {   // obs_requestShow 전송
                var res = message.res;
                if (res === METHOD.VALUE_YES) {
                    _acceptObsRequestShow(undefined, link);
                } else {
                    _denyObsRequestShow();
                }
            });
        }
    })(sharpUi.getState() === 'show');
},
apps/brk/js/component/brk_api.js — getWidgetMainApp(BW003) 목록 조회
self.getWidgetMainApp = function (weatherDatas, sucFn, errFn, entryPoint) {
    var data = {
        pageCount: 0, pageNumber: 1,
        said: self.getDependency('saId'),
        dongCode: self.getDependency('dongCode'),
        stbType: self.getDependency('stbType'),     // 1:Acap, 2:web
        stbModel: self.getDependency('stbModel'),
        serviceType: self.getDependency('serviceType')
    };

    return _ajaxByPost(ConstRequestBS.GET_WIDGET_MAIN_APP_BW003, data, function (stats, result) {
        if (result.result_cd !== ConstResponseBS.result_cd_SUCCESS) {
            _executeError(errFn, ConstError.REASON_NO_RESULT, ...);
            return;
        }
        if (storageDataManager.hasSameProductCode(result.prd_cd_black_list)) {
            _executeError(errFn, ConstError.REASON_NOT_SUPPORTED_SERVICE, ...); // 미지원 상품
            return;
        }
        _showWidget(result);   // 이미지 로드 후 목록 렌더
    }, function (status, body) {
        _executeError(errFn, ConstError.REASON_API_ERROR, false, '');
    });
};
