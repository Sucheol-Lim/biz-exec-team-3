링크 타입별 실행 분기

link_type 값에 따라 BOM 앱 실행(1)·채널 이동(2/8)·매시업(4)·홈포탈 VOD/카테고리/시리즈(5/6/7)·#채널(9)·위젯 재시작(11)·안드로이드 네이티브/브로드캐스트 인텐트(21/22) 등으로 분기하는 brk의 라우팅 코어입니다.

기능 개요

모든 트리거·위젯·쇼핑키·큐톤이 최종적으로 "무엇을 실행할지"를 결정하는 단일 분기점이 brk.handleLinkType(linkType, dataList, options)입니다. link_type 정수값은 core-constants.js의 BOM_SERVER_RESPONSE.link_type에 정의되어 있으며, NO_ACTION_0·RUN_BOM_APP_1·RUN_BOUND_APP_CHANNEL_2·RUN_MASHUP_4·RUN_HP_VOD_DETAIL_5·RUN_HP_CATEGORY_6·RUN_HP_SERIES_7·RUN_CHANNEL_8·RUN_SHARP_CHANNEL_9·RESTART_WIDGET_11·RUN_OBS_ANDROID_NATIVE_APP_21·RUN_OBS_BROADCAST_INTENT_22 등이 있습니다. (3=unicast는 KTBOM-282로 제거됨)

분기는 두 단계입니다. 먼저 _buildPayloadFromLinkType이 _LINK_PAYLOAD_MAP으로 원시 데이터 배열(link_param1~4)을 타입별 의미 있는 페이로드(예: {bomAppId, sceneId}, {locator}, {contentId, categoryId})로 변환합니다. 미지 타입이면 undefined가 되어 위젯을 종료(_requestHide)합니다. 그다음 dispatchActionWithSession이 세션 ID를 확보(없으면 getSessionId(BW005))한 뒤 _dispatchTrigger가 _HANDLER_MAP에서 실제 처리 함수를 찾아 호출합니다.

처리 함수는 타입별로 다릅니다. _processRunBomApp은 getWebAppUrl(BW001)로 봄앱 주소를 받아 자식 앱을 띄우고, _processRunBoundAppChannel/_processRunChannel은 oipfMgr.setChannel로 채널을 옮기며, _processRunMashup은 매시업 매니저에 메시지를 보냅니다. 홈포탈 VOD/카테고리/시리즈(5/6/7)는 표시 전 _requestHide로 위젯을 먼저 닫고 홈포탈에 위임하며, 안드로이드 네이티브/브로드캐스트 인텐트(21/22)는 옵저버 메시지로 단말 네이티브 실행을 요청합니다.

데이터 기반 매핑 테이블
거대한 switch 대신 UTIL.addKeys(map, [type...], fn)로 _LINK_PAYLOAD_MAP(데이터 변환)과 _HANDLER_MAP(실행 함수)을 구성합니다. 같은 처리를 공유하는 타입(예: 6과 7, 21과 22)을 한 번에 등록해 중복을 줄이고, 미등록 타입은 자연스럽게 no-op/종료로 떨어집니다.

시퀀스 다이어그램

흐름. 호출자가 handleLinkType을 부르면 페이로드 변환 → 세션 확보 → 핸들러 맵 분기 순으로 진행됩니다. 타입에 따라 봄앱 실행·채널 이동·매시업·홈포탈 위임·네이티브 인텐트로 갈립니다.

관계. brk가 link_type 상수를 키로 _LINK_PAYLOAD_MAP(데이터→페이로드)과 _HANDLER_MAP(타입→실행 함수)을 사용합니다. 두 테이블이 분기의 핵심입니다.

핵심 코드

apps/brk/js/main.js — handleLinkType: 페이로드 변환 후 디스패치
handleLinkType: function (linkType, dataList, options) {
    if (linkType === LINK_TYPE.NO_ACTION_0) {
        qratorProxy.hide();
        return;
    }
    options = (options && typeof options === 'object') ? options : {};
    var payload = _buildPayloadFromLinkType(linkType, dataList);

    if (!payload) {                       // undefined = 미지 타입
        _requestHide();
        return;
    }
    this.dispatchActionWithSession(linkType, payload, options);
},
apps/brk/js/main.js — _HANDLER_MAP: 타입별 처리 함수 등록(데이터 기반)
T.addKeys(map, [RESP.link_type_RUN_BOM_APP, LINK_TYPE.RUN_BOM_APP_1], function (inputDatas, options, errFn) {
    _processRunBomApp(inputDatas, options, errFn);              // getWebAppUrl(BW001)
});
T.addKeys(map, [RESP.link_type_RUN_BOUND_APP_CHANNEL, LINK_TYPE.RUN_BOUND_APP_CHANNEL_2], function (inputDatas, options) {
    _processRunBoundAppChannel(inputDatas.locator, options);    // setChannel
});
T.addKeys(map, [RESP.link_type_RUN_MASHUP, LINK_TYPE.RUN_MASHUP_4], function (inputDatas, options) {
    _processRunMashup(inputDatas.target, options);              // mashup_startApplication
});
T.addKeys(map, [LINK_TYPE.RESTART_WIDGET_11], function (_in, options) {
    _processRestartWidget(options);
});
T.addKeys(map, [LINK_TYPE.RUN_OBS_ANDROID_NATIVE_APP_21], function (inputDatas, options) {
    _processRunAndroidNativeApp(inputDatas, options);           // obs_startAndroidNativeApp
});
T.addKeys(map, [LINK_TYPE.RUN_OBS_BROADCAST_INTENT_22], function (inputDatas, options) {
    _processRunBroadcastIntent(inputDatas, options);            // obs_broadcastIntent
});
