qDaemon 백그라운드 매니저

위젯 UI와 별개로 백그라운드 시나리오를 관리하는 매니저 묶음입니다. 채널 트리거 스케줄(chTriggerManager), 사용자/스토리지 데이터(storageDataManager), 라이브 에이전트 로그(liveAgentManager)를 담당합니다.

기능 개요

qDaemon은 단일 앱이 아니라 전역으로 노출되는 세 매니저의 묶음입니다. qrator.init()이 STB 모드일 때 storageDataManager.init() → chTriggerManager.init() → storageDataManager.checkIpAddress() 순으로 기동합니다. 위젯이 보이지 않아도 이들은 백그라운드에서 계속 동작해 트리거 노출 조건을 평가하고 로그를 남깁니다.

chTriggerManager는 채널 트리거(f04)·CMP 트리거(f06)의 두뇌입니다. 부팅 시 캐시 서버에서 편성 파일(CMP_CAMP_CH_WEB.json)을 받아 만료시각(newChExpDate)과 함께 localStorage에 저장하고, 만료 시각에 맞춰 갱신 타이머(setUpdateTimer)를 겁니다. 단말 채널 이벤트(onPlayStateChange/onChannelChangeSucceeded 등)를 받아 채널별 유효 캠페인을 골라 적절한 트리거에 전달합니다.

storageDataManager는 가입 상품 코드·마케팅 동의·관심지수·리워드 이력·IP 변경 등 사용자 컨텍스트와 트리거 갱신 시각(getUpdateTime/getUpdateTimeByRandom)을 관리하며, chTriggerManager.checkCampaignCondition이 캠페인 조건 검사에 직접 참조합니다. liveAgentManager는 라이브 에이전트 서버로 노출/이동/결제 로그를 전송합니다. 세션 ID를 /getsessionid로 받아오고, 파이프(|) 구분 문자열로 로그를 직렬화해 StpLogSaveController.do에 POST합니다.

로그 타입 (liveAgentManager)
pushTriggerStartLog(logType 14, 푸시 트리거 노출), microSiteStartLog(15, 마이크로사이트 노출), tvpayModuleStartLog(16, 결제 모듈 노출)이 정의되어 있습니다. 모두 세션 ID·SAID·시작 시각·콘텐츠 ID를 필수로 담습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant Q as qrator.init() participant SDM as storageDataManager participant CTM as chTriggerManager participant CACHE as 캐시 서버 (img.bom.kt.com) participant STB as 방송 객체 participant LAM as liveAgentManager Q->>SDM: init() Q->>CTM: init() → startScheduling() CTM->>CACHE: fileLoad(CMP_CAMP_CH_WEB.json) CACHE-->>CTM: 편성 목록 CTM->>CTM: setLocalCampaignData / setUpdateTimer Q->>SDM: checkIpAddress() STB->>CTM: onChannelChangeSucceeded(ch) CTM->>CTM: runCampaign → getValidCampaign CTM->>SDM: checkCampaignCondition 참조 CTM->>LAM: (트리거 노출 시) pushTriggerStartLog LAM->>LAM: getSessionId → sendLog (|구분 직렬화)

흐름. init 시 세 매니저가 기동해 편성 파일을 받아 캐싱하고, 채널 이벤트마다 유효 캠페인을 평가합니다. 노출 조건은 storageDataManager를 참조하고, 노출 시 liveAgentManager가 세션을 받아 로그를 전송합니다.

클래스 다이어그램

classDiagram class chTriggerManager { -campaignList -inactiveChannelList -updateTimer +init() +startScheduling() +runCampaign(ch) +checkCampaignCondition(camp) +setInacitveTrigger(channelType, sid) +removeCampaign(camp) +channelEventListener } class storageDataManager { +init() +checkIpAddress() +getUpdateTime() +getUpdateTimeByRandom() +getBaseProductCode() +getMarketingAgreeYn() +getInterestIndex() +getRewardedCampaign() } class liveAgentManager { -currentSessionId +pushTriggerStartLog(bomSaId, contentId) +microSiteStartLog(bomSaId, contentId) +tvpayModuleStartLog(bomSaId, contentId) +getCurrentSessionId() } chTriggerManager --> storageDataManager : 조건/갱신시각 참조 chTriggerManager --> liveAgentManager : 노출 로그

관계. 세 매니저는 모두 전역 객체로, chTriggerManager가 캠페인 조건 검사에 storageDataManager를, 노출 로그에 liveAgentManager를 사용합니다.

if (stbInfo.isSTB) {

    storageDataManager.checkIpAddress();   // IP 변경여부 체크
    ...
}
apps/qDaemon/liveAgentManager.js — sendLog: 파이프 구분 직렬화 후 전송
function sendLog(data, sucFn, errorFn) {
    var StringData = '';
    for (var i = 0; i < keyList.length; i++) {
        StringData += data[keyList[i]] + "|";       // logType|sessionId|saId|...
    }
    var url = commonProperty.BRK_liveAgent_serverIp + '/bat/StpLogSaveController.do';
    $.ajax({
        type: "POST", url: url, dataType: "json",
        data: { "parameter": StringData },
        contentType: 'application/x-www-form-urlencoded',
        timeout: 5000,
        success: function (msg) { if (msg.result_cd == 1 && sucFn) sucFn(msg); },
        error: function (msg) { if (errorFn) errorFn(msg); }
    });
}
