샤프(#)키 처리 (sharp)

리모컨 # 키(VK_F12)로 현재 채널에서 실행 가능한 BOM 앱을 선택·실행하는 sharp UI입니다. 채널뷰(chview)·비밀번호(pwd)·아람(aram)·서비스 에러 팝업을 제공하며, # 키 더블 입력 시 "샵샵(##)" 동작으로 전환됩니다.

기능 개요

샤프 UI는 위젯이 숨겨진 상태(_handleKeyWhileHidden)에서 # 키(VK_F12)가 들어오면 _sharpKeyWhenHide → sharpUi.sharpKey()로 진입합니다. 단, 위젯·BOM 앱이 떠 있거나 양방향(데이터) 채널 상태라면 # 키를 처리하지 않습니다. 진입하면 옵저버에 obs_requestShow를 보내 표시 승인을 받은 뒤, 채널뷰(goChview) 모델을 트리거해 현재 채널의 # 채널 정보를 보여줍니다.

모든 통신은 qrator를 통한 postMessage입니다. requestShow(timer)는 활성 앱을 sharpUi로 바꾸고 옵저버에 표시를 요청하며, requestHide는 obs_hide를 보내 종료합니다. 표시·숨김 응답은 qMessage(events)에서 메서드별로 처리됩니다. 자체 API(sharp_api)로 사내 sharp_ui 서버(mapi.bom.kt.com/sharpui)와 연동합니다.

특수 기능인 "샵샵(##)"은 ssharp 모듈이 담당합니다. 짧은 시간 내 # 키가 두 번 들어오면 스택(ssharpStacks)이 2 이상이 되어 isStandby()가 참이 되고, 다른 언바운드 앱 실행 여부를 확인한 뒤 qrt_moveToSharpLink를 brk로 전달해 #채널 링크로 이동합니다.

하위 화면 구성
sharp는 view/page/chview.js(채널뷰)와 view/popup/의 pwd.js(비밀번호 입력)·aram.js(아람 알림)·serviceError.js(서비스 에러)로 화면을 구성합니다. 각 뷰는 appMgr.modelTrigger()로 전환됩니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 사용자/리모컨 participant Q as qrator participant SH as sharpUi (main) participant SS as ssharp participant OBS as Observer participant VIEW as appMgr (chview) U->>Q: # 키(VK_F12), hide 상태 Q->>Q: _sharpKeyWhenHide() (위젯/데이터채널 아니면) Q->>SH: sharpUi.sharpKey() SH->>SS: ssharp.ssharpProcess() SS->>OBS: isOnUnboundApplication() (obs_isLoadingUnboundApplication) OBS-->>SS: 다른 언바운드 앱 없음 SS->>SH: requestShow(0) SH->>OBS: obs_requestShow OBS-->>SH: res = yes SH->>VIEW: modelTrigger(goChview) VIEW-->>U: 채널뷰 표시 Note over U,SS: # 키 재입력(2회) → ssharpTrigger U->>SS: # 키 SS->>SH: brk.qMessage(qrt_moveToSharpLink)

흐름. hide 상태에서 # 키가 들어오면 ssharpProcess가 다른 언바운드 앱 유무를 확인하고, 없으면 옵저버 승인을 받아 채널뷰를 표시합니다. # 키가 한 번 더 들어와 standby가 되면 qrt_moveToSharpLink로 #채널 이동을 brk에 위임합니다.

클래스 다이어그램

관계. sharpUi가 내부 ssharp(##)을 소유하고, sharp_api·oipf 컴포넌트로 서버/단말 정보를 다룹니다. 표시·활성 전환은 qrator에 위임합니다.

핵심 코드

qrator/js/main.js — _sharpKeyWhenHide: # 키 처리 가드
function _sharpKeyWhenHide(event) {
    // 위젯(또는 BOM앱)이 실행중이거나 양방향 채널 상태라면 #키를 처리하지 않음
    if (stateManager.isShow() || oipfUtil.isDataChannel()) {
        return;
    }
    _sharpKey(event);
}

function _sharpKey(event) {
    sharpUi.sharpKey(event);
    _consumed(event);
}
apps/sharp/js/main.js — ssharpProcess: 샵샵 진입과 언바운드 앱 확인
ssharpProcess: function () {
    var ssharp = this;
    qrator.activateSharpUI();

    // 다른 언바운드 앱이 실행중인지 체크함
    ssharpTimer = sharpUi.isOnUnboundApplication(null, function () {
        // 다른 언바운드 앱이 실행 중일 때, hide 상태로 전환
        qrator.deactivateSharpUI();
        ssharp.free();
    }, function () {
        // 실행 중인 다른 언바운드 앱이 없을 경우
        ssharpTimer = sharpUi.requestShow(0);
    }, 0);
}
