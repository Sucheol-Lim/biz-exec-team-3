동적 서브앱 로딩(부트스트랩)

모듈 번들러 없이 동작하는 클래식 스크립트 부트스트랩입니다. APP_MINIFEST(app-manifest)가 선언한 서브앱 스크립트 트리를 loader가 순차 로드한 뒤, document ready 시 qrator.init()으로 위젯을 기동합니다.

기능 개요

이 앱은 ES5 바닐라 JavaScript로, webpack 같은 번들러를 쓰지 않습니다. index.html이 라이브러리(jQuery·Underscore·Backbone·CryptoJS·keyEvent)와 공통 코어·유틸을 정해진 순서로 로드한 뒤, 서브앱 스크립트는 부트스트랩 3단(app-manifest → loader → bootstrap)이 동적으로 로드합니다.

app-manifest.js는 전역 window.APP_MINIFEST에 서브앱별 스크립트 트리를 선언적으로 정의합니다. 예를 들어 brk/js 아래 baseComponent·component·model·view/page·view/popup의 파일 목록과 마지막 main.js 순서를 배열로 기술합니다. 로드 순서가 곧 의존 순서이므로, 컴포넌트가 본체보다 먼저 평가되도록 main.js를 맨 뒤에 둡니다.

bootstrap.js는 jQuery $(function(){...})(document ready)에서 Boot.loadAppScripts(lo, window.APP_MINIFEST, done)를 호출합니다. loader.js의 loadAppScripts는 locationMVM의 lo 클로저로 side_lo.loadOn('apps', manifest, ...)를 실행해 매니페스트 트리를 순차 로드하고, 완료 콜백에서 qrator.init()을 호출해 위젯을 기동합니다. 빌드 시 주입되는 build-env.js는 bootstrap-env.js를 통해 런타임 엔드포인트/버전으로 적용됩니다.

왜 동적 로딩인가
서브앱마다 다수의 작은 스크립트로 나뉘어 있어, 매니페스트로 로드 트리를 한곳에서 선언하면 index.html을 건드리지 않고도 서브앱 구성을 바꿀 수 있습니다. 번들러 의존 없이 구형 STB 웹 미들웨어에서도 안정적으로 동작합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant HTML as index.html participant LIB as 라이브러리/코어 스크립트 participant MAN as APP_MINIFEST (app-manifest) participant BOOT as bootstrap.js participant LO as loader (Boot.loadAppScripts) participant Q as qrator HTML->>LIB: jQuery/Underscore/Backbone/Crypto/keyEvent 로드 HTML->>LIB: build-env.js → bootstrap-env.js (엔드포인트/버전 적용) HTML->>MAN: window.APP_MINIFEST 선언 HTML->>BOOT: document ready BOOT->>LO: Boot.loadAppScripts(lo, APP_MINIFEST, done) LO->>LO: side_lo.loadOn('apps', manifest) (순차 로드) LO-->>BOOT: done() BOOT->>Q: qrator.init() Note over Q: 서브앱 등록 후 기본 brk 표시

흐름. index.html이 라이브러리·코어·빌드 환경을 먼저 로드하고 APP_MINIFEST를 선언한 뒤, document ready에서 loader가 매니페스트 트리를 순차 로드하고 완료 콜백에서 qrator.init()을 기동합니다.

클래스 다이어그램

classDiagram class APP_MINIFEST { +brk/js (트리) +sharp/js (트리) } class Boot { +loadAppScripts(lo, manifest, done) } class loader { +loadAppScripts(lo, manifest, done) } class bootstrap { +onDocumentReady() } class bootstrapEnv { +applyBuildEnv(BUILD_ENV) } class qrator { +init() } bootstrap --> Boot : loadAppScripts 호출 Boot ..|> loader : 구현 loader --> APP_MINIFEST : 트리 순차 로드 bootstrap --> qrator : init() bootstrapEnv --> qrator : 엔드포인트/버전 주입

관계. bootstrap이 Boot.loadAppScripts(loader 구현)를 호출해 APP_MINIFEST 트리를 로드하고 qrator.init()을 기동합니다. bootstrapEnv는 빌드 주입값을 런타임 설정으로 적용합니다.

핵심 코드

common/js/boot/app-manifest.js — 서브앱 스크립트 트리 선언
window.APP_MINIFEST = [
    {
        'brk/js': [
            {baseComponent: ['api.js']},
            {component: ['brk_amoc.js', 'brk_api.js', 'brk_detailList.js',
                         'brk_itemList.js', 'brk_liveAgent.js', 'brk_oipf.js']},
            {model: ['base.js']},
            {view: [
                {page: ['main.js', 'noui.js']},
                {popup: ['loading.js', 'notification.js', 'dim.js', 'exitPopup.js', 'testlog.js']}
            ]},
            'brk-constants.js',
            'main.js'                  // 본체는 항상 마지막
        ]
    }, {
        'sharp/js': [ ... 'sharp-constants.js', 'main.js' ]
    }
];
common/js/boot/bootstrap.js — document ready 후 로드·기동
$(function () {
    Boot.loadAppScripts(lo, window.APP_MINIFEST, function () {
        if (window.qrator && typeof qrator.init === 'function') {
            console.log('[boot] qrator.init');
            qrator.init();
        } else {
            console.error('[boot] qrator.init not found');
        }
    });
});
