서비스 미지원 단말 안내

서비스 미지원(ACAP 등) 또는 미지원 상품 가입 단말에서 전체 화면 안내 이미지를 표시합니다. 원격 이미지 서버(img.bom.kt.com)를 우선 시도하고, 네트워크 오류나 https 미지원 등 로드 실패 시 로컬 리소스로 대체합니다.

기능 개요

미지원 안내는 위젯 메인 진입 과정에서 트리거됩니다. brk_api.getWidgetMainApp(BW003) 응답에 가입 불가 상품 목록(prd_cd_black_list)이 있고 사용자가 그에 해당하면, REASON_NOT_SUPPORTED_SERVICE 에러가 콜백으로 전달되고 brk의 goMain 에러 처리에서 appMgr.modelTrigger('popNotSupportedService')로 안내 팝업을 띄웁니다.

안내 화면(notSupportedService 팝업)은 1280×720 전체 화면 배경 이미지로 구성됩니다. 핵심은 이미지 로딩 전략입니다. oipfUtil.imageLoader로 원격 서버 이미지(BRK_image_serverIp + '/tv/NOTICE/web-widget-close.png', 캐시 회피용 타임스탬프 쿼리 포함)를 먼저 시도하고, load 성공 시 그 URL을 배경으로 적용합니다. 그러나 error(네트워크 오류·https 미지원 등) 또는 5초 타임아웃이 발생하면 콜백으로 로컬 리소스(common/image/web-widget-close.png)로 대체합니다.

이 "원격 우선, 로컬 대체" 패턴은 안내 문구를 운영 중 서버에서 교체할 수 있게 하면서도, 구형 STB의 https 미지원이나 네트워크 단절 상황에서도 최소한 로컬 이미지로 안내가 보장되도록 합니다. 키 처리는 ESC/ENTER/BACK으로 이전 화면 복귀(backHistory)·dim 해제(clearDim)를 수행하고, 위젯·앱스토어 핫키는 hotKeyAction으로 그대로 전달합니다.

근거 범위 참고
소스에서 직접 확인되는 것은 notSupportedService 팝업의 원격-우선/로컬-대체 이미지 로딩과 prd_cd_black_list 기반 미지원 상품 분기입니다. "ACAP 단말"이라는 표현은 사내 Confluence/과제 개요 기준이며, 코드상 단말 구분은 stbType_ACAP(1)/stbType_WEBAPP(2) 상수와 서버 응답으로 이루어집니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant BRK as brk (goMain) participant API as brk_api participant POP as notSupportedService 팝업 participant IMG as oipfUtil.imageLoader participant REMOTE as 원격 이미지 서버 participant LOCAL as 로컬 리소스 BRK->>API: getWidgetMainApp(BW003) API-->>BRK: REASON_NOT_SUPPORTED_SERVICE (prd_cd_black_list) BRK->>POP: modelTrigger(popNotSupportedService) POP->>IMG: imageLoader(remote web-widget-close.png?ts) IMG->>REMOTE: img.src = 원격 URL alt 로드 성공 REMOTE-->>IMG: load IMG->>POP: background = 원격 URL (전체화면) else 오류 / 5초 타임아웃 IMG->>LOCAL: errorCallback LOCAL->>POP: background = common/image/web-widget-close.png end

흐름. BW003에서 미지원 상품으로 판정되면 안내 팝업을 띄우고, 원격 이미지를 우선 로드합니다. 성공하면 원격 이미지를, 오류/타임아웃이면 로컬 이미지를 전체화면 배경으로 적용합니다.

클래스 다이어그램

classDiagram class brk { +show(param) -goMain() } class brk_api { +getWidgetMainApp(weather, suc, err, ep) } class storageDataManager { +hasSameProductCode(prd_cd_black_list) } class notSupportedService { -info_main_text +init() +getView() } class oipfUtil { +imageLoader(imgPath, loadCb, errCb, timeout) } brk --> brk_api : BW003 호출 brk_api --> storageDataManager : 미지원 상품 판정 brk --> notSupportedService : 팝업 트리거 notSupportedService --> oipfUtil : 원격/로컬 이미지 로드

관계. brk_api가 storageDataManager로 미지원 상품을 판정하고, brk가 notSupportedService 팝업을 띄웁니다. 팝업은 oipfUtil.imageLoader로 원격-우선/로컬-대체 이미지를 적용합니다.

핵심 코드

apps/brk/js/view/popup/notSupportedService.js — 원격 우선, 실패 시 로컬 대체
oipfUtil.imageLoader(commonProperty.BRK_image_serverIp + '/tv/NOTICE/web-widget-close.png?' + new Date().getTime(),
    function (url) {                          // 원격 로드 성공
        view.$abs().$css({
            zIndex: 2,
            background: "url(" + url + ")"
        }).$setWidth(1280).$setHeight(720);
    },
    function () {                             // 오류/타임아웃 → 로컬 대체
        view.$abs().$css({
            zIndex: 2,
            background: "url('common/image/web-widget-close.png')"
        }).$setWidth(1280).$setHeight(720);
    });
common/js/oipfUtil.js — imageLoader: load/error/timeout 분기
self.imageLoader = function (imgPath, loadCallback, errorCallback, timeout) {
    if (!imgPath || imgPath === "") { if (typeof errorCallback == "function") errorCallback(); return; }
    var timer = null, _timeout = timeout ? timeout : 5000;   // 기본 5초

    var image = $("<img>")
        .on('load',  function () { clearTimer(); loadCallback && loadCallback(imgPath); })
        .on('error', function () { clearTimer(); errorCallback && errorCallback(imgPath); })
        .attr('src', imgPath);

    timer = setTimeout(function () {          // 타임아웃도 errorCallback
        clearTimer();
        if (typeof errorCallback == "function") errorCallback();
    }, _timeout);
};
