Windmill 데이터 연동 (cappl.dm)

cappl.dm이 Windmill 플랫폼의 UPMS/ACMS 등 서비스 API(cappl/dm/api)를 HttpClient로 호출하고, TbroadAuthorization이 STB 인증·액세스 토큰을 관리해 사용자 프로파일·광고·추천 데이터를 환경별 URL로 가져옵니다.

기능 개요

cappl.dm은 SK브로드밴드의 부가 서비스 플랫폼인 Windmill과 연동하는 데이터 매니저 계층입니다. Windmill은 UPMS(사용자/프로파일), ACMS(콘텐츠/메타), Search, RCMD(추천), OneAd(광고) 등 여러 서비스 도메인으로 나뉘며, 본 앱은 이를 REST API로 호출해 사용자 프로파일·광고·추천·예약 데이터를 받아옵니다. API 엔드포인트 템플릿은 cappl/dm/api/ServiceAPI.java에 상수로 정의되어 있고(categories/menu, accounts, auth/authenticate 등), UPMSMethods·ACMSMethods 인터페이스가 도메인별 메서드 시그니처를 제공합니다.

통합 서비스 진입점은 WindmillService 인터페이스로, 여러 메서드 인터페이스(UPMS/ACMS 등)를 상속하고 getConfiguration()으로 환경 설정(WindmillConfiguration)을 제공합니다. 실제 HTTP 통신은 cappl/dm/http의 HttpClient.request(HttpRequest)가 수행하며, 요청 메서드(RequestMethod)·파라미터(HttpParameter)·응답(HttpResponse)·재시도·오류(processError → WindmillException)를 처리합니다. 비동기 호출은 WindmillAsyncDispatcher/WindmillServiceAsync가 담당합니다.

인증은 TbroadAuthorization이 일원화합니다. reAuth()가 postStbAuthentication()으로 STB를 인증하고 계정별 windmillAccessToken(AccessToken)을 확보합니다. 개인/그룹 사용자 구분(PERSONAL_USER/GROUP_USER)에 따라 admin·family 계정 토큰을 관리하며, 이후 모든 API 호출에 이 토큰을 실어 보냅니다. 서버 URL은 라이브(LIVE)/위성(SAT)/개발(DEV) 환경별로 windmill.properties에 분리되어 있습니다.

리소스 모델 풍부
cappl/dm/resource에는 User·Accounts·Channel·Product·Campaign·ReservedProgram·AccessToken 등 40여 개의 응답 리소스 모델이 정의되어 있어, Windmill JSON 응답을 타입 있는 객체로 역직렬화합니다.

시퀀스 다이어그램

흐름. TbroadAuthorization이 STB 인증으로 액세스 토큰을 확보한 뒤, WindmillService 호출이 HttpClient.request()를 통해 토큰을 실어 API를 호출하고 응답을 리소스 모델로 변환합니다.

관계. WindmillService가 UPMS/ACMS 메서드 인터페이스를 상속하고 HttpClient로 HTTP를 수행합니다. 인증·토큰은 TbroadAuthorization이, 엔드포인트 템플릿은 ServiceAPI가 제공합니다.

핵심 코드

cappl/dm/api/UPMSMethods.java — UPMS 인증·계정 API 시그니처
public interface UPMSMethods {
    public User getCurrentUser() throws WindmillException;
    public Accounts postAuthenticate(String clientId, String deviceUdid, String pinCode) throws WindmillException;
    public AccessToken postAccessToken(String loginId, String password, String clientId, String deviceId)
            throws WindmillException;
    public boolean postDestroyToken() throws WindmillException;
    public User getUserAccount(boolean withSTB, boolean withHH) throws WindmillException;
}
cappl/dm/TbroadAuthorization.java — STB 재인증으로 토큰 확보
public synchronized void reAuth() throws WindmillException {
    if (Log.INCLUDE) {
        Log.message("[TbroadAuthorization] reAuth, ");
    }
    postStbAuthentication();                 // STB 인증 → Accounts/AccessToken 확보
    // admin/family 계정의 windmillAccessToken을 보관해 이후 API 호출에 사용
}
