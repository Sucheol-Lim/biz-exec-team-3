VOD 재생 제어

VODManager가 IXC로 Castis VOD 플레이어(com.castis.vod.control.VODPlayer)를 룩업하고, VODPlayHandler가 재생/정지/이벤트 수신을, VODPlayBar·VODUIManager가 재생 제어 UI를, VODErrorCode가 오류 코드를 다룹니다.

기능 개요

VOD(주문형 비디오) 재생은 별도의 VOD 애플리케이션(Castis)이 제공하는 VODPlayer 원격 인터페이스를 통해 이뤄집니다. VODPlayer는 java.rmi.Remote를 확장한 IXC(Inter-Xlet Communication) 인터페이스로, 본 로컬 앱은 VODManager.lookupVOD(context)에서 IxcRegistry.lookup(context, WindmillConfig.VOD_APP_LOCATOR)로 이 플레이어 구현을 찾아 보관합니다.

실제 재생 제어는 싱글톤 VODPlayHandler가 담당합니다. VODPlayHandler는 VODEventListener·ServiceContextListener·TVTimerWentOffListener를 구현해, stopAndPlay(...)/play()로 재생을 시작하고 VOD 서버에서 오는 이벤트(receiveEvent(vodEvent))를 수신합니다. VOD 이벤트는 VODEVENT_SESSION_NORMAL(0)·VODEVENT_END_OF_FILE(2)·VODEVENT_PAUSE_TIMEOUT(3)·VODEVENT_NEED_TUNE(5) 등으로 정의됩니다. 재생 결과 코드는 VODRESULT_SUCCESS(0)·VODRESULT_INVALID_FILE(3)·VODRESULT_MAX_SESSION_ERROR(4) 등입니다.

UI는 vod/ui의 VODPlayBar(재생 진행 바)와 WaterMark(워터마크), 그리고 VODUIManager가 담당합니다. 재생 위치·트릭 플레이(되감기/빨리감기) 같은 세부 제어는 VODPlayController가, 재생 자체의 흐름은 VODPlayHandler가 다룹니다. 표준화된 오류 코드는 VODErrorCode에 모여 있어 UI에서 사용자에게 적절한 메시지를 노출합니다.

IXC 기반 분리 구조
재생 엔진(VODPlayer)은 본 앱이 아니라 별도 VOD Xlet에 있으며, OCAP IXC 레지스트리로 원격 호출됩니다. 따라서 호출은 모두 RemoteException을 던질 수 있고, 본 앱은 핸들러 계층에서 이를 감싸 처리합니다.

핵심 코드

vod/manager/VODManager.java — IXC로 원격 VODPlayer 룩업
private VODPlayer vodPlayer;

public void lookupVOD(XletContext context) {
    // OCAP IXC 레지스트리에서 Castis VOD 플레이어 원격 스텁을 찾아 보관
    vodPlayer = (VODPlayer) IxcRegistry.lookup(context, WindmillConfig.VOD_APP_LOCATOR);
}

public VODPlayer getVodPlayer() {
    return vodPlayer;
}
com/castis/vod/control/VODPlayer.java — 원격 재생 인터페이스(결과/이벤트 코드)
public interface VODPlayer extends Remote {
    public static final int VODRESULT_SUCCESS = 0;
    public static final int VODRESULT_INVALID_FILE = 3;
    public static final int VODRESULT_MAX_SESSION_ERROR = 4;

    public static final int VODEVENT_END_OF_FILE = 2;
    public static final int VODEVENT_PAUSE_TIMEOUT = 3;
    public static final int VODEVENT_NEED_TUNE = 5;

    public int play(String fileName, int[] TSList, long offset, int requestID) throws RemoteException;
    public void stop() throws RemoteException;
    public void addVODEventListener(VODEventListener eventListener) throws RemoteException;
}
