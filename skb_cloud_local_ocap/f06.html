STB 상태 모니터링 (Monitor)

Monitor가 부팅 시 NavigatorHandler·ServiceHandler·CAS·EPG를 단계적으로 기동하고 IXC 인터페이스를 바인딩하며, 대기모드(StandbyModeControl)·배터리(BatteryStatusManager)·컬러키 등 시스템 레벨 제어를 담당합니다.

기능 개요

Monitor는 OCAP 미들웨어의 모니터 애플리케이션 역할에 해당하는 시스템 레벨 제어 계층입니다. Monitor.init(xletContext)는 인스턴스를 만들어 start()를 호출하고, start()는 정해진 step 순서대로 하위 서브시스템을 기동합니다. (step1) NavigatorHandler 초기화로 채널 데이터베이스를 구성하고, (step2) IXC(Inter-Xlet Communication) 인터페이스를 바인딩하며, (step3) EPG 관련 ProgramTable·MiniEpgController를, (step4) ServiceHandler·컬러키·COQP·채널 로그 전송기 등을 띄웁니다.

대기모드는 싱글톤 StandbyModeControl이 Alticast PowerModeControl과 연계해 standby 진입/해제를 관리하고, 별도 standby 체크 스레드와 전용 키 컨트롤(레이어드 UI)을 운영합니다. 저배터리 상황은 LowBatteryControl/BatteryStatusManager가 감시하며, 컬러키는 ColorKeyManager가 처리합니다. CAS는 CaManagerImpl이 Monitor 기동 단계에서 함께 초기화됩니다.

Monitor의 키 입력 경로는 monitor/svc의 MonitorKeyHandler·DefaultKeyManager 등으로 구성되며, 가상 마우스·TV 잠금(TVLocker)·STB 버전 전송(STBVersionSendManager) 같은 운영 기능도 이 계층에 포함됩니다.

단계적 기동(step) 순서
Monitor.start()는 로그에 step1~step4를 명시하며 채널 DB → IXC 바인딩 → EPG → 서비스 핸들러 순으로 순차 기동합니다. 부팅 의존성이 큰 모듈이므로 순서가 고정되어 있습니다.

흐름. HomeMain이 Monitor.init()을 호출하면 CAS·채널 DB·IXC·EPG·서비스 핸들러가 step 순서로 기동되고, 이후 대기모드·배터리·키 이벤트를 시스템 레벨에서 처리합니다.

관계. Monitor가 NavigatorHandler·ServiceHandler를 소유하고, CAS·대기모드·컬러키·배터리 제어 서브시스템을 기동·연계합니다. monitor/svc 패키지가 시스템 제어 구현을 담습니다.

핵심 코드

monitor/Monitor.java — init이 start를 호출하고 step 순서로 기동
public static final Monitor init(XletContext xletContext) {
    instance = new Monitor();
    try {
        instance.start(xletContext);
    } catch (XletStateChangeException e) {
        e.printStackTrace();
    }
    return instance;
}

public void start(XletContext xletContext) throws XletStateChangeException {
    this.xletContext = xletContext;
    maService = createMaService();
    UserPreferenceUtilImpl.getInstance().load();
    CaManagerImpl.getInstance();                 // CAS 초기화

    // step 1 : 채널 데이터베이스 구성
    navHandler = createNavHandler();
    navHandler.init();
    // step 2 : IXC 바인딩
    controlIXCInterface(true);
    // step 3 : EPG
    ProgramTable.getInstance();
    MiniEpgController.getInstance();
    // step 4 : 서비스 핸들러 / 컬러키 / 채널 로그 전송기 ...
}
