채널맵 · 플랫폼 정보 (OOB)

OOBManager가 OOB(Out-Of-Band) 경로의 섹션 필터로 메타·채널맵·플랫폼 정보를 수신해 DataCenter에 올리고, ChannelMapManager·PlatformInfoManager가 이를 구독해 채널맵·플랫폼 정보를 갱신합니다. 인밴드 데이터는 IframeManager가 다룹니다.

기능 개요

케이블 STB는 채널맵·플랫폼 설정 같은 운영 데이터를 OOB(Out-Of-Band, 대역외) 경로로 받습니다. OOBManager가 진입점으로, startRetrieving()에서 먼저 메타 데이터(OOB_META)용 마스터 섹션 필터(OOBTableSectionFilter)를 가동합니다. 메타에는 각 OOB 테이블(채널맵·플랫폼 정보·메뉴·캠페인)의 테이블 ID·확장 ID가 담겨 있어, 이를 근거로 테이블별 섹션 필터를 추가로 띄워 실제 데이터를 수신합니다.

수신한 OOB 데이터는 직접 매니저로 전달되지 않고 공용 데이터 버스인 DataCenter에 키(OOBConfiguration.OOB_CHANNEL_MAP·OOB_PLATFORM_INFO 등)로 저장됩니다. OOBManager·ChannelMapManager·PlatformInfoManager는 모두 DataUpdateListener를 구현해 이 키들을 구독하고, 데이터가 갱신되면 dataUpdated() 콜백을 받습니다. 부팅 시 OOB 데이터는 플래시(readFromFlash())에서 먼저 읽어 빠르게 화면을 구성하고, 새 OOB 수신분으로 갱신합니다.

ChannelMapManager.start()는 현재 DataCenter에 있는 채널맵을 ChannelMapAsyncTask(비동기 Runnable)로 파싱해 OOB 채널 데이터를 빌드하고(buildOobChannelData()), 동시에 채널맵 키와 OCAP 채널 DB 변경을 리스닝합니다. PlatformInfoManager는 플랫폼 정보(PlatformInfo)와 버전 파일(platform_info_ver.dat 등)을 관리하며 BI 로고·iframe zip의 해시를 비교해 변경분만 갱신합니다.

인밴드(Iframe)는 별도 경로
OOB가 채널맵·플랫폼 같은 운영 데이터용이라면, 인밴드(In-band) 경로의 IframeManager(home/data/inband)는 방송 스트림에 실린 Iframe 데이터를 받아 시청제한·미가입·오디오 채널 등의 상태(IFRAME_BLOCKED_USER·IFRAME_UNSUBSCRIBED 등)를 사용자 프리퍼런스에 저장합니다.

흐름. OOBManager가 메타 → 테이블별 섹션 필터로 OOB 데이터를 받아 DataCenter에 올리면, 이를 구독한 ChannelMapManager·PlatformInfoManager가 dataUpdated()로 채널맵·플랫폼 정보를 갱신합니다.

관계. OOBManager가 섹션 필터로 받은 OOB 데이터를 DataCenter에 올리고, 구독자인 ChannelMapManager·PlatformInfoManager가 갱신을 받습니다. 인밴드 IframeManager는 OCDataManager를 상속합니다.

핵심 코드

home/data/oob/OOBManager.java — 메타 우선 필터링으로 OOB 수신 시작
public void startRetrieving() {
    // 1) 먼저 OOB Meta Data를 필터링해 각 테이블의 ID/확장 ID를 얻는다
    masterFilter = new OOBTableSectionFilter(OOBConfiguration.TABLE_META_DATA);
    masterFilter.startFiltering(OOBConfiguration.OOB_META);
    // 2) 메타에 담긴 테이블별로 채널맵/플랫폼 정보 섹션 필터를 추가 가동
    //    수신 결과는 DataCenter 키(OOB_CHANNEL_MAP / OOB_PLATFORM_INFO)에 저장
}
home/data/oob/ChannelMapManager.java — DataCenter 채널맵 구독 후 비동기 빌드
public void start() {
    // 현재 DataCenter에 있는 채널맵을 비동기로 파싱·빌드
    new ChannelMapAsyncTask().execute(DataCenter.getInstance().get(OOBConfiguration.OOB_CHANNEL_MAP));
    // 채널맵 갱신과 OCAP 채널 DB 변경을 구독
    DataCenter.getInstance().addDataUpdateListener(OOBConfiguration.OOB_CHANNEL_MAP, this);
    OcapChannelDatabaseManager.getInstance().addListener(this);
    isBuildOOBChannel = false;
}
