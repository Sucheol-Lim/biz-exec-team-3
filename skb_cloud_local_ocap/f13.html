푸시 메시지 처리 (PMS)

PushMessageReceiver가 서버 푸시 메시지를 수신해 PushMessageEventHandlerImpl.handleEvent()로 전달하면 JSON으로 파싱·이벤트 발화하고, 사용자 액션 결과는 UDPSender로 피드백 서버(PMS_FEEDBACK_IP:8800)에 전송합니다.

기능 개요

PMS(Push Message System)는 운영 사업자 서버가 STB로 보내는 푸시 메시지(공지·이벤트·점검 안내 등)를 수신·표시하고, 사용자 반응을 서버로 되돌려주는 양방향 모듈입니다. 부팅 시 HomeMain.start()가 PushMessageEventHandlerImpl.getInstance()를 생성하면 내부에서 PushMessageReceiver와 PushMessageDataManager가 초기화됩니다.

수신 경로는 PushMessageReceiver(PushEventListener 구현)가 플랫폼 PushManager에 리스너로 등록되어, 메시지가 오면 notifyPushEvent(s)를 받아 PushMessageEventHandlerImpl.handleEvent(message)로 넘깁니다. handleEvent()는 원문 메시지를 PushMessageDataManager에 저장하고, GSON으로 pms.resource.PushMessage 객체로 역직렬화한 뒤, messageId가 유효하면 fireEvent()로 등록된 PushMessageEventListener들에게 이벤트를 발화합니다(보통 팝업 표시로 이어짐).

피드백 경로는 sendFeedbackMessage(messageId, resultCode, detail)입니다. PMS 팝업에 대한 사용자 액션이 발생하면 PushFeedbackMessage(메시지 ID·MAC 주소·시각·상세)를 만들어 GSON JSON으로 직렬화하고, UDPSender로 Def.PMS_FEEDBACK_IP의 8800 포트에 UDP 패킷을 전송합니다. 디바이스 등록(PushMessageConfiguration)은 별도로 HTTP(PMS_FEEDBACK_IP:8080/push/api1/devices/create)를 사용합니다.

수신은 이벤트, 피드백은 UDP
메시지 수신은 플랫폼 PushManager 이벤트 리스너로, 피드백 전송은 경량 UDP 패킷으로 처리됩니다. 피드백 IP/포트는 com.tb.config.Def와 windmill.properties에서 환경별로 설정됩니다.

핵심 코드

pms/event/PushMessageEventHandlerImpl.java — 수신 메시지 파싱·이벤트 발화
public void handleEvent(String message) {
    try {
        if (message != null) {
            PushMessageDataManager.getInstance().storePushMessage(message);
            PushMessage pushMessage =
                (PushMessage) GsonUtil.parseResponse(pms.resource.PushMessage.class, message);
            if (pushMessage.messageId != null) {
                fireEvent(pushMessage);          // 등록 리스너에 이벤트 발화 → 팝업
            }
        }
    } catch (WindmillException e) {
        e.printStackTrace();
    }
}
pms/event/PushMessageEventHandlerImpl.java — 사용자 액션 UDP 피드백
public void sendFeedbackMessage(String messageId, String resultCode, String detail) {
    PushFeedbackMessage feedback = new PushFeedbackMessage();
    String currentTime = new SimpleDateFormat("yyyy-MM-dd'T'HH:mm:ssZ").format(new Date());
    feedback.id      = messageId;
    feedback.detail  = detail;
    feedback.address = Util.getMacAddr();
    feedback.time    = currentTime;

    String jsonStr = GsonUtil.getJsonString(feedback);
    UDPSender sender = new UDPSender();
    sender.start(Def.PMS_FEEDBACK_IP, 8800, jsonStr);   // 피드백 서버로 UDP 전송
}
