Mini EPG · 채널 예약

MiniEpgController가 접근/서핑/오디오 채널 목록과 현재·다음 프로그램(ProgramTable)을 관리해 간이 편성표를 제공하고, ReserveManager가 시청 예약을 Reminder(TVTimer)로 등록·트리거합니다.

기능 개요

Mini EPG는 채널 전환 시 화면 하단에 뜨는 채널 배너의 편성 정보(현재/다음 프로그램)와 채널 목록 탐색을 담당하는 간이 편성표입니다. 싱글톤 MiniEpgController가 ChannelDatabaseEventListener로 동작하며, 채널 DB 변경 시 접근 가능 채널(chAccessable), 서핑 채널(chSurfable), 오디오 채널(chAudio) 목록과 즐겨찾기·스킵·유료 채널 ID 배열을 갱신합니다(updateChannels()). 프로그램 정보는 ProgramTable/ProgramInfo에서 가져옵니다.

채널 예약은 miniepg/reserve의 ReserveManager가 담당합니다. ReserveManager는 (1) 예약된 프로그램 리스트(reservedPrograms, 최대 30개), (2) 정해진 시간에 트리거될 알림 리스트(alarmReminderList), (3) 트리거 후 사용자 액션을 처리하는 actReminderList 세 가지를 관리합니다. 예약은 사용자 프리퍼런스(UserPreferenceItem.RESERVED_PROGRAMS)에 저장되어 부팅 시 load()로 복원됩니다.

각 예약은 Reminder가 TVTimerSpec으로 등록되며, 프로그램 시작 alarmBefore(기본 60초) 전에 AlarmEventListener로 알림이 발생합니다. MiniEpgController.init()이 ReserveManager.start()를 호출해 예약 데이터를 로드하고 알림 리스너를 등록합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant MON as Monitor participant MEC as MiniEpgController participant PT as ProgramTable participant RM as ReserveManager participant TVT as TVTimer participant AL as AlarmEventListener MON->>MEC: getInstance() / init() MEC->>MEC: updateChannels() (접근/서핑/오디오 목록) MEC->>PT: 현재/다음 프로그램 조회 MEC->>RM: addAlarmEventListener(AlarmListener) MEC->>RM: start() RM->>RM: load() (예약 프로그램 복원) loop 예약별 RM->>TVT: addReminder (TVTimerSpec, 시작 60초 전) end Note over RM,AL: 예약 시각 도달 TVT->>RM: timerWentOff RM->>AL: 알림 발생 (시청 안내 팝업)

흐름. MiniEpgController가 채널·편성 목록을 구성하고 ReserveManager.start()로 예약을 로드합니다. 각 예약은 TVTimer로 등록되어 시작 전에 알림을 트리거합니다.

관계. MiniEpgController는 채널 DB 이벤트를 받아 편성 목록을 갱신하고 ProgramTable로 프로그램 정보를 얻습니다. ReserveManager는 예약을 Reminder로 보관하고 AlarmEventListener로 알림을 통보합니다.

핵심 코드

miniepg/MiniEpgController.java — 채널 목록 갱신 후 예약 매니저 기동
private void init() {
    updateChannels();                                  // 접근/서핑/오디오 채널 목록 구성
    MiniEpgChannelEventListener.getInstance();         // 채널 선택 이벤트 등록
    MiniEpgUPController.getInstance();                 // UP(즐겨찾기/스킵 등) 변경 이벤트
    // 예약: 알림 리스너 먼저 등록 후 start (load 시점에 Timer 리스너 등록 가능)
    ReserveManager.getInstance().addAlarmEventListener(AlarmListener.getInstance());
    ReserveManager.getInstance().start();
}
miniepg/reserve/ReserveManager.java — 예약/알림 리스트 정의
public static final int MAX_RESERVE = 30;
public static long DEFAULT_ALARM_BEFORE = 60 * 1000L;   // 시작 60초 전 알림
public long alarmBefore = DEFAULT_ALARM_BEFORE;

List reservedPrograms  = new ArrayList(MAX_RESERVE);    // 예약된 프로그램
List alarmReminderList = new ArrayList(MAX_RESERVE);    // 트리거될 알림(TVTimerSpec)
List actReminderList   = new ArrayList(MAX_RESERVE);    // 트리거 후 사용자 액션
