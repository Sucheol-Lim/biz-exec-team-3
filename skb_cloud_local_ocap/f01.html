채널 탐색·전환 (Navigator)

ChannelController가 OCAP ServiceContext를 통해 채널을 튜닝하고, ChannelDatabase·ChannelRing이 채널 목록 순회를, ChannelZapper가 채널 up/down·이전 채널 키 입력을 처리합니다.

기능 개요

Navigator는 가입자가 채널을 바꾸는 경로 전체를 담당합니다. 추상 클래스 ChannelController가 채널 선택 로직의 골격을 제공하고, OCAP 미들웨어 환경에서는 구현체 OcapChannelController가 javax.tv.service.selection.ServiceContext를 사용해 실제 튜닝을 수행합니다. 채널 모델은 Channel(및 케이블 전용 확장 TbroadChannel)로 표현되고, 정렬된 채널 묶음은 ChannelRing이 순환 리스트로 관리합니다.

리모컨에서 채널 up/down·이전 채널 키가 들어오면 싱글톤 ChannelZapper가 keyPressed()에서 이를 받아, ChannelRing.getNextChannel()/getPreviousChannel()로 대상 채널을 결정한 뒤 ChannelController.changeChannel()을 호출합니다. ChannelController.changeChannel()은 내부적으로 selectChannel(...)을 호출해 차단 채널·수신제한(CAS)·연령 제한 여부를 검사하고, 통과하면 ServiceContext.select()로 채널을 전환합니다.

OCAP 전용 채널 데이터(navigator/channel/ocap)와 TBroad 케이블 채널 모델(navigator/channel/tbroad)이 분리되어 있어, OCAP 미들웨어가 제공하는 SI/서비스 정보와 SK브로드밴드 케이블 고유의 채널 속성(장르·SDV 여부 등)을 함께 다룹니다.

차단 채널 처리
최근 작업(2026-02-24 커밋)에서 DCA(직접 채널 접근) 자동완성 리스트에 차단 채널이 표시되지 않도록 수정되었습니다. 채널 순회·검색 단계에서 차단/수신제한 채널을 필터링하는 정책이 Navigator 전반에 반영되어 있습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant REMOTE as 리모컨 키 (CH UP/DOWN) participant ZAP as ChannelZapper participant RING as ChannelRing participant CC as ChannelController participant OCC as OcapChannelController participant SC as ServiceContext (OCAP) REMOTE->>ZAP: keyPressed(code, when) ZAP->>ZAP: keyChannelPressed(up) ZAP->>RING: getNextChannel(cur) / getPreviousChannel(cur) RING-->>ZAP: 대상 Channel ZAP->>CC: changeChannel(channel, select) CC->>CC: selectChannel(...) 차단/CAS/연령 확인 CC->>OCC: (구현) 튜닝 수행 OCC->>SC: select(locator) SC-->>OCC: NormalContentEvent / SelectionFailedEvent OCC->>CC: notify ChannelEventListener Note over CC,SC: 영상 표시 후 채널 배너/Mini EPG 갱신

흐름. 채널 키가 ChannelZapper로 들어와 ChannelRing에서 대상 채널을 정한 뒤, ChannelController.changeChannel() → OcapChannelController가 ServiceContext.select()로 튜닝합니다.

관계. 추상 ChannelController를 OcapChannelController가 구현하고, ChannelZapper가 키 입력을 받아 ChannelRing 조회 후 컨트롤러에 전환을 위임합니다. 케이블 전용 속성은 TbroadChannel이 확장합니다.

핵심 코드

navigator/channel/ChannelController.java — changeChannel은 selectChannel로 위임
public void changeChannel(Channel channel, boolean select, boolean fromEPG, boolean isBack) {
    if (Log.INCLUDE) {
        Log.message("[ChannelController] changeChannel, call selectChannel channel : " + channel);
    }
    selectChannel(channel, select, false, true, null, fromEPG, isBack);
}

public void reTune(Channel channel) {
    // 동일 채널 재튜닝 (차단 해제 후 재선택 등)
    selectChannel(channel, true, false, true, null, false, false);
}
navigator/control/ChannelZapper.java — 채널 키 입력 진입점
public void keyPressed(int code, long when) {
    // 채널 up/down 및 이전 키 입력 처리
    // ...
    // 내부적으로 keyChannelPressed(up, when)을 호출해
    // ChannelRing에서 다음/이전 채널을 찾아 전환을 요청한다.
}
