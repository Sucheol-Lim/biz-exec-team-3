기능 개요

SDV(Switched Digital Video)는 케이블망 대역폭을 절약하기 위해, 시청자가 없는 채널은 전송하지 않다가 누군가 채널을 요청하면 그때 해당 채널을 특정 주파수에 스위칭해 할당하는 기술입니다. 본 앱은 부팅 시 SDVInit.init()으로 SDV 서브시스템을 초기화합니다(HomeMain.start()에서 (new SDVInit()).init(true) 호출).

SDVInit.init()은 (1) readDefaultDescriptor()로 MC(Mini Carousel) 주/백업 주파수·프로그램 번호를 읽고, (2) MCReader로 MC 섹션 수신을 시작한 뒤, (3) main 주파수로 튜닝해 MC 섹션을 기다리고(waitMCRead(), 최대 5회 재시도·2초 지연), 실패하면 backup 주파수로 재시도합니다. 수신한 MCSection에는 SDV 채널 매핑·SG(Service Group) 정보가 담겨 있습니다.

실제 SDV 채널 시청 요청은 SDVManager가 처리합니다. SDVManager.isSdvAvailable()로 가용성을 확인하고, CCPService.requestCCPSelect(channel, listener)로 CCP(Channel Change Protocol) 서버에 채널 선택을 요청합니다. CCP 서버가 할당한 주소(getAccessPointAddress(sgId))로 keep-alive(KeepAliveMessage)를 보내 세션을 유지하고, 결과(CCPSelectResult)에 따라 튜닝 정보가 결정됩니다. CCP 응답 코드는 200(성공)·412(SG 코드 재획득 필요)·400(소켓 오류) 등으로 구분됩니다.

FCC와의 관계
SDV 채널은 FCC priming 대상에서 제외됩니다(FastChannelChangeManager.findUsablePrimerProxy()의 isSDV() 체크). SDV는 요청 시점에 동적으로 주파수가 할당되므로 인접 채널을 미리 튜닝해 두는 FCC 방식과 맞지 않기 때문입니다.

핵심 코드

sdv/SDVInit.java — MC 디스크립터 튜닝과 섹션 수신 재시도
public void init(boolean isInit) {
    this.isInit = isInit;
    boolean readDes = readDefaultDescriptor();   // main/backup freq·progNo 획득
    MCReader.getInstance().resetSection();
    SelectionProviderManager.getInstance();
    MCReader.getInstance().startMCReady();

    boolean triedWithBackup = false;
    if (mainFreq > 0 && mainProgNo > 0) {
        OcapLocator[] result = tune(mainFreq, mainProgNo);
        if (result == null && backupFreq > 0 && backupProgNo > 0) {
            triedWithBackup = true;
            result = tune(backupFreq, backupProgNo);   // main 실패 시 backup
        }
    }
    MCSection mcSection = waitMCRead();           // 최대 5회 재시도, 2초 지연
    if (mcSection == null && !triedWithBackup && backupFreq > 0 && backupProgNo > 0) {
        MCReader.getInstance().startMCReady();
        tune(backupFreq, backupProgNo);
        mcSection = waitMCRead();
    }
}
