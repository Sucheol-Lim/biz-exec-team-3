쿠폰 · 부가 서비스

기능 개요

coupon 패키지는 SK브로드밴드 쿠폰 시스템 연동의 데이터 모델을 담당합니다. 핵심은 CouponBox(Resource 인터페이스 구현)로, 쿠폰 서버가 내려주는 파이프(|) 구분 텍스트 응답을 parse(String[] src)에서 토큰화해 총 보유 건수·만료 기간·잔여 결제/보너스 금액·사용률과 개별 쿠폰 배열(Coupon[])로 변환합니다. 각 Coupon은 쿠폰 번호·이름·결제/보너스 금액·만료일·상태(coupon_status)·구매 유형 등의 필드를 가집니다. 쿠폰 서버 URL은 내부/외부로 분리되어 windmill.properties에 설정됩니다.

쿠폰 이벤트 알림은 cappl.dm의 TbroadCouponNoticeCollector(NoticeCollector 상속)가 수집합니다. 메일 타입 알림(NOTICE_TYPE_MAIL)을 모아 이벤트 쿠폰(Coupon eventCoupon)을 추출하고, 이미 사용자에게 노출했는지(isShowed()/setShowed())를 family 계정(TbroadAuthorization.getFamilyAccount())의 eventCouponId로 판별해 중복 노출을 막습니다.

광고 부가 서비스는 OneAd가 대표적입니다. 싱글톤 OneADIdManager가 doCheck()로 OneAd 광고 ID 인증 상태를 확인하고, 사용자(TbroadAuthorization.getCurrentUser()) 기준으로 광고 ID를 발급·갱신해 사용자 프리퍼런스에 저장합니다(writeUP()). 이 ID는 클라우드 홈에 광고를 표시할 때(CloudHomeMain.startConnect()의 IAD 처리, oneAdIDCheck()) 사용됩니다. 홈초이스 앱스토어 등 다른 부가 서비스도 홈 화면의 진입점에서 호출됩니다.

핵심 코드

coupon/dto/CouponBox.java — 파이프 구분 응답을 쿠폰 모델로 파싱
public Resource parse(String[] src) {
    String[] base = TextUtil.tokenize(src[0], "|");
    total_num_rows       = Util.parseInt(base[2]);
    expire_duration      = Util.parseLong(base[3]);
    total_rest_pay_amt   = base[4];
    total_rest_bonus_amt = base[5];
    if (base.length <= 7) {
        num_rows = Util.parseInt(base[6]);
    } else {
        use_rate = Util.parseInt(base[6]);
        num_rows = Util.parseInt(base[7]);
    }
    coupon = new Coupon[num_rows];
    for (int i = 0; i < num_rows; i++) {
        coupon[i] = new Coupon();
        coupon[i].parse(src[i + 1]);     // 라인별 개별 쿠폰 파싱
    }
    return this;
}
