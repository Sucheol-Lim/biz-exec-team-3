FCC 고속 채널 전환

FastChannelChangeManager가 현재 채널의 인접 채널을 여분 튜너에 미리 튜닝(ChannelPrimer)해 두어, 가입자가 채널을 바꿀 때 영상 표시 지연을 줄입니다. standby(대기) 상태에서는 priming을 수행하지 않습니다.

기능 개요

케이블 STB에서 채널을 바꾸면 튜너 재동기·SI 수신·디스크램블 과정 때문에 영상이 뜨기까지 지연이 생깁니다. FCC(Fast Channel Change)는 이 지연을 줄이기 위해, 가입자가 현재 보고 있는 채널을 기준으로 다음/이전 채널을 여분 튜너에 미리 튜닝(priming)해 둡니다. FastChannelChangeManager.primeChannels(to)가 호출되면 현재 채널을 LEVEL_CURRENT로, 사용자가 다음에 누를 확률이 높은 인접 채널을 LEVEL_FCC로 지정해 ChannelPrimerProxy(내부적으로 Alticast ChannelPrimer를 감쌈)에 준비시킵니다.

채널 방향(FORWARD/BACKWARD)은 직전 채널과 대상 채널의 ChannelRing 인덱스를 비교해 결정합니다. 채널 UP 흐름이면 상위 채널(up1)을, DOWN 흐름이면 하위 채널(down1)을 prime 대상으로 잡습니다. 8VSB 채널은 VSB 튜너 자원이 제한적이므로 findUsablePrimerProxy()에서 튜너 사용 현황(getTunerId())을 보고 가장 적합한 primer를 재활용합니다.

standby에서 FCC tune 차단
primeChannels() 진입부에서 Host.getInstance().getPowerMode()가 FULL_POWER가 아니면(=대기 모드) 즉시 return 하여 priming을 건너뜁니다. 최근 커밋(2025-12-11 "standby에서 fcc tune 막음")에서 강화된 동작으로, 대기 상태에서 불필요한 튜너 점유와 전력 소모를 막습니다. SDV 채널은 prime 대상에서 제외됩니다(findUsablePrimerProxy()의 isSDV() 체크).

관계. FastChannelChangeManager가 여러 ChannelPrimerProxy를 소유하며 각 proxy는 Alticast ChannelPrimer를 감쌉니다. priming 전 Host 전원 모드와 채널의 SDV 여부를 확인합니다.

핵심 코드

navigator/channel/fcc/FastChannelChangeManager.java — standby 차단 · 방향 판정 · prime
public synchronized void primeChannels(Channel to) {
    Host host = Host.getInstance();
    if (host.getPowerMode() != Host.FULL_POWER) {
        if (Log.INCLUDE) {
            Log.message("[FastChannelChangeManager] primeChannels() it's standby, so return");
        }
        return;                                  // 대기 모드 → FCC tune 차단
    }
    initCache();
    if (to == null || channels.length == 0) return;

    int idxTo = channelRing.indexOf(to.getNumber(), to.getMinorNumber());
    if (idxTo < 0) return;

    Channel fcc = channels[(idxTo + 1) % channels.length];   // up1 (기본 방향)
    if (curChannel != null) {
        // 직전 채널과 대상 채널 인덱스로 FORWARD/BACKWARD 판정
        if (channelDirection == BACKWARD) {
            fcc = channels[(idxTo - 1 + channels.length) % channels.length]; // down1
        }
    }
    setPrimerProxy(LEVEL_CURRENT, to);
    setPrimerProxy(LEVEL_FCC, fcc);
    stopUnusedPrimerProxies();
    curChannel = to;
    if (cacheMap[LEVEL_FCC] == null) {
        primeChannel(fcc, LEVEL_FCC);            // 인접 채널을 여분 튜너에 미리 튜닝
    }
}
