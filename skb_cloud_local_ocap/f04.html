기능 개요

이 앱의 가장 큰 구조적 특징은 클라우드 하이브리드입니다. 홈 화면 UI는 STB 로컬에서 전부 그리지 않고, 서버 측 클라우드 앱(com.tbroad.cloud.ep3)이 렌더링한 화면을 STB가 받아 표시합니다. 로컬 앱은 이 연동의 클라이언트 역할을 하며, 진입점은 싱글톤 CloudHomeMain입니다. CloudHomeMain은 ConnectCallbackListener·ShowHomeCallbackListener·PowerModeChangeListener를 구현해 연결 결과, 홈 표시 요청, 전원 모드 변화를 모두 한 곳에서 받습니다.

부팅 시 HomeMain.start()는 연결 상태가 CONNECTED가 될 때까지 CloudHomeMain.startConnect()를 시도합니다. startConnect()는 홈 액션·자동시작 플래그·IAD(인앱 광고) 등을 담은 JSON 메시지를 만들어 connect() → CloudConnector.requestConnect()로 서버에 세션을 요청합니다. 연결 옵션과 복구 타입(RECOVERY_NONE/ONCE/AUTO)에 따라 세션이 수립되며, 결과는 CONNECT_SUCCESS·CONNECT_SESSION_RESULT_FAIL 등 코드로 콜백됩니다.

연결 후 키 입력은 CloudKeyHandler(LayeredKeyHandler 구현)가 받아 현재 서비스 상태(STATE_CLOUD 등)에 따라 클라우드로 키를 전달하거나 로컬에서 처리합니다. 세션 유효성은 CloudSessionRuleChecker가 타이머로 주기 점검하고, 하트비트 오류나 네트워크 단절 시 RecoveryManager가 재연결·복구를 담당합니다. PIP 화면은 HomePIPManager가 다룹니다.

세션 · 키 · 화면 3축 연계
CloudConnector(세션), CloudKeyHandler(키 입력 라우팅), commandShow()/onMessage()(화면 표시 명령)가 클라우드 연동의 세 축입니다. ICS·TLS·worker(cloud/ics·cloud/tls·cloud/worker)가 하위 통신·작업 처리를 담당합니다.

핵심 코드

cloud/CloudHomeMain.java — 세션 연결 요청과 JSON 액션 메시지 구성
public void startConnect() {
    setCloudState();
    setConnectionState(CONNECTING);

    CloudHomeCommendManager.getInstance().remakeChannelInfo();
    JSONObject message = CloudHomeCommendManager.getInstance().getActionCommon();
    try {
        message.put(CloudHomeCommendManager.KEY_ACTION, MessageToCloud.KEY_HOME);
        message.put(CloudHomeCommendManager.KEY_AUTO_START, true);
        String homeIad = HomeIAdManager.getInstance().getRandomHomeIAD();
        if (homeIad != null) {
            message.put(CloudHomeCommendManager.KEY_HOME_IAD, homeIad);
        }
        message.put(CloudHomeCommendManager.WEATHER_IDX, CloudConfig.getInstance().getWeatherIdx());
    } catch (JSONException e) {
        e.printStackTrace();
    }
    connect(message, CloudConnector.RECOVERY_NONE);   // 서버에 세션 요청
    oneAdIDCheck();
}
