CAS 수신제한 연동

CaManagerImpl이 CaManager 인터페이스를 구현해 CAS 시스템 ID에 맞는 핸들러(AltiCaHandler/NagraCaHandler)를 생성하고, 채널 수신제한 확인·구매 요청·미리보기(PreviewInfo)를 TBroad CA Adaptor를 통해 처리합니다.

기능 개요

CAS(수신제한 시스템, Conditional Access System)는 가입자 권한에 따라 채널·콘텐츠 시청을 허용/제한합니다. 본 앱은 싱글톤 CaManagerImpl(CaManager 인터페이스 구현)로 CAS 연동을 일원화합니다. CaManagerImpl은 부팅 시 Monitor 단계에서 초기화되며, setCasSystemId()로 SystemInfo에서 CAS 시스템 ID를 읽어온 뒤 createCaHandler()로 해당 CAS에 맞는 핸들러를 생성합니다.

핸들러는 공통 추상 CaHandler를 상속하는 AltiCaHandler(Alticast CAS)와 NagraCaHandler(Nagra CA) 두 종류가 있습니다. 채널 전환 시 requestCaChannel(channel)이 호출되어 해당 채널의 수신 가능 여부를 핸들러에 위임하고, 유료 채널·이벤트 구매는 requestCaPurchase()/requestCaPurchaseWithPrdId()로 처리합니다. 결과는 CaResultListener로 통보되어 UI(구매 팝업·차단 안내 등)에 반영됩니다.

스마트카드 상태(isValidSmartCardStatus()·getSmartCardID())와 만료 여부(getIsExpired())도 CaManagerImpl이 제공하며, 내부 CasSystemCheckThread가 CAS 시스템 상태를 주기 점검합니다. 미리보기는 PreviewInfo로 표현되어, 미가입 채널을 제한 시간 동안 시청하게 하는 프리뷰 기능을 다룹니다. 실제 CAS/CA 네이티브 연동은 lib/의 Alticast CAS와 tbroad_ca_adaptor.zip(TBroad CA Adaptor)을 통합니다.

관계. CaManagerImpl이 CaManager를 구현하고 CAS 종류에 따라 AltiCaHandler/NagraCaHandler를 생성합니다. 둘 다 추상 CaHandler를 상속하며, 결과는 CaResultListener로 통보됩니다.

핵심 코드

monitor/ca/CaManagerImpl.java — CAS 핸들러 생성과 채널 수신제한 요청
public class CaManagerImpl implements CaManager {

    public void createCaHandler() {
        // CAS 시스템 ID에 따라 핸들러 선택
        //caHandler = new NagraCaHandler("NagraCaHandler");
        caHandler = new AltiCaHandler("AltiCaHandler");
        if (listener != null) {
            caHandler.setCaResultListener(listener);
        }
    }

    public void requestCaChannel(Channel channel) {
        if (Log.INCLUDE) {
            Log.message("[CaManagerImpl] requestCaChannel, channel = " + channel);
        }
        caHandler.requestCaChannel(channel);   // 수신제한 확인을 핸들러에 위임
    }

    public void requestCaPurchaseWithPrdId(Channel channel, String prdId) {
        caHandler.requestCaProductWithPrdId(channel, prdId);
    }
}
