재생 오류 처리

ExoPlayer 오류를 분류해 일부는 즉시 재준비(prepare)로 복구하고, 복구 불가 오류는 세션 상태를 STATE_ERROR로 만들어 MainActivity가 PodcastDialog 오류 안내를 띄웁니다. 로드 재시도는 PodcastLoadErrorHandlingPolicy가 담당합니다.

기능 개요

재생 오류는 PodcastExoplayerListener.onPlayerError()에서 PlaybackException.errorCode로 분류됩니다. 위치 범위 초과(ERROR_CODE_IO_READ_POSITION_OUT_OF_RANGE)나 라이브 윈도우 이탈(ERROR_CODE_BEHIND_LIVE_WINDOW)처럼 회복 가능한 오류는 exoplayerHelper.prepare()로 즉시 재준비해 자연 복구합니다. 그 외 네트워크·디코딩·DRM 등 복구 불가 오류는 updateSessionPlaybackStateError(errorCode, name)로 세션 PlaybackState를 STATE_ERROR로 세팅합니다.

MainActivity는 onCreate()에서 재생 상태 LiveData를 관찰하다가 상태가 STATE_ERROR가 되면 showMediaPlayerErrorDialog()를 호출해 PodcastDialog(TYPE_MEDIA_PLAYER_ERROR_NOTICE)를 띄우고, 정상 상태로 돌아오면 같은 타입의 다이얼로그를 닫습니다. 네트워크 조회 실패(SubscriptionCallback.onError)는 별도로 showNetworkErrorDialog()가 처리합니다. 한편 ExoPlayer의 미디어 소스 로드 실패에 대한 재시도 간격·횟수는 PodcastLoadErrorHandlingPolicy(DefaultLoadErrorHandlingPolicy 확장)가 각 MediaSource에 설정되어 처리합니다.

3단 방어
(1) 로드 단계는 PodcastLoadErrorHandlingPolicy가 재시도, (2) 회복 가능 재생 오류는 onPlayerError()가 prepare()로 자동 복구, (3) 복구 불가 오류만 STATE_ERROR → 사용자 다이얼로그로 노출됩니다.

관계. PodcastExoplayerListener가 오류를 분류해 헬퍼로 위임하고, 복구 불가 오류만 MainActivity의 PodcastDialog로 표면화됩니다. 로드 재시도는 정책 클래스가 담당합니다.

핵심 코드

media/PodcastExoplayerListener.java — 오류 코드별 복구/표면화 분기
@Override
public void onPlayerError(PlaybackException error) {
    switch (error.errorCode) {
        case PlaybackException.ERROR_CODE_BEHIND_LIVE_WINDOW:
        case PlaybackException.ERROR_CODE_IO_READ_POSITION_OUT_OF_RANGE:
            exoplayerHelper.prepare();                                  // 자동 복구
            break;
        case PlaybackException.ERROR_CODE_IO_NETWORK_CONNECTION_FAILED:
        case PlaybackException.ERROR_CODE_DECODING_FAILED:
        /* ... 다수의 복구 불가 코드 ... */
            exoplayerHelper.updateSessionPlaybackStateError(error.errorCode, error.getErrorCodeName());
            break;
    }
}
ui/MainActivity.java — STATE_ERROR 관찰 시 다이얼로그 표시
podcastViewModel.getPodcastData().getPlaybackState().observe(this, playbackStateCompat -> {
    if (playbackStateCompat != null && playbackStateCompat.getState() == PlaybackStateCompat.STATE_ERROR) {
        showMediaPlayerErrorDialog();
    } else {
        dismissMediaPlayerErrorDialog();
    }
});
