이전 시청 정보 복원

기능 개요

마지막 청취 정보는 채널 ID(PID)와 에피소드 ID(EID) 두 값으로 표현되며, PodcastPreferenceManager가 key.mypod.last.pid·key.mypod.last.eid 키로 SharedPreferences에 저장합니다. 재생이 진행되어 미디어 아이템이 전환될 때마다 PodcastExoplayerHelper.saveLastPod()가 현재 항목의 PID/EID를 저장해 둡니다.

복원은 서비스 시작 시점에 일어납니다. onCreate()에서 100ms 지연 후 startLastWatchedEpisode(false)를 호출하며, 저장된 PID/EID가 유효하면 해당 채널의 에피소드 목록을 받아 onGetLastWatched()에서 저장된 EID와 일치하는 항목을 찾아 세션에 큐·메타데이터를 세팅합니다. 일반 진입(fromVoice=false)은 재생까지 하지 않고 onPrepareFromMediaId()로 "준비" 상태만 만들고, 음성/런처 진입(fromVoice=true)은 onPlayFromMediaId()로 곧바로 자동 재생합니다. 저장 정보가 없으면 음성 진입 시에는 추천 1위 팟을 대신 재생하고, 일반 진입 시에는 STATE_NONE으로 둡니다.

준비 vs 재생 구분
onPrepareFromMediaId()는 setHelperPlayWhenReady(false)로 정지 상태에서 위치만 복원하고, onPlayFromMediaId()는 true로 즉시 재생합니다. 덕분에 앱을 다시 열었을 때 의도치 않게 소리가 나는 일 없이 직전 지점부터 이어 들을 준비만 됩니다.

핵심 코드

media/PodcastBrowserService.java — 마지막 항목으로 복원 분기
public void startLastWatchedEpisode(boolean fromVoice) {
    lastWatchedItem = podcastPreferenceManager.getLastWatchedItem();
    if (lastWatchedItem.getPID().equals("") || lastWatchedItem.getEID().equals("")) {
        if (fromVoice) {
            PodcastRequest.getRecommendList(RECOMMEND_LIST_COUNT, false, null, true, this, null); // 추천1위
        } else {
            podcastPlayerHelper.updateSessionPlaybackState(PlaybackStateCompat.STATE_NONE);
        }
    } else {
        PodcastRequest.getEpisodeList(EPISODE_LOAD_COUNT, lastWatchedItem.getPID(), "desc", true, fromVoice, this, null);
    }
}
media/PodcastBrowserService.java — 저장된 EID와 일치하는 항목 준비/재생
for (int i = 0; i < list.size(); i++) {
    String eid = list.get(i).getDescription().getMediaId();
    if (lastWatchedItem.getEID().equals(eid)) {
        Bundle bundle = new Bundle();
        bundle.putBoolean(Constants.KEY_LAST_WATCHED, true);
        if (fromVoice) {
            podcastSessionCallback.onPlayFromMediaId(eid, bundle);   // 자동 재생
        } else {
            podcastSessionCallback.onPrepareFromMediaId(eid, bundle); // 준비만
        }
        break;
    }
}
