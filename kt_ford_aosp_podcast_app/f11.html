야간(Night) 모드

values-night·drawable-night* 리소스로 야간 테마를 제공하고, 야간일 때 썸네일 등에 알파(NIGHT_MODE_ALPHA = 0.88)를 적용해 밝기를 낮춥니다.

기능 개요

야간 모드는 두 층위로 처리됩니다. 첫째, 안드로이드 표준 리소스 한정자입니다. res/values-night/colors.xml로 야간 색상을, res/drawable-night·drawable-night-hdpi/…/xxxhdpi로 밀도별 야간 아이콘 세트를 제공해, 시스템 uiMode가 야간이면 해당 리소스가 자동 선택됩니다. MainActivity는 onConfigurationChanged()에서 uiMode 변경을 감지하면 nav_host Fragment를 detach/attach로 재생성해 야간 리소스를 다시 바인딩합니다.

둘째, 코드 레벨의 알파 보정입니다. Utils.isNightMode(config)로 야간 여부를 판정하고, Utils.getOpacity(isNightMode)가 야간이면 Constants.NIGHT_MODE_ALPHA(0.88f), 주간이면 NO_ALPHA(1.00f)를 돌려줍니다. 재생 화면·재생 목록의 썸네일 이미지뷰에 이 값을 setAlpha()로 적용해 야간에는 이미지를 살짝 어둡게 표시합니다. 목록 어댑터도 setNightMode(Utils.isNightMode(...))로 야간 상태를 받아 아이템 표현을 조정합니다.

리소스 + 코드 이중 적용
색/아이콘은 리소스 한정자가, 이미지 밝기(알파)는 코드가 담당합니다. 0.88이라는 값은 차량 야간 주행 시 화면 눈부심을 줄이기 위한 미세 조정으로, 한 곳(Constants)에 상수로 모여 있어 일괄 변경이 가능합니다.

핵심 코드

common/util/Utils.java — 야간 판정과 알파 산출
public static boolean isNightMode(Configuration config) {
    return (config.uiMode & Configuration.UI_MODE_NIGHT_MASK) == Configuration.UI_MODE_NIGHT_YES;
}

public static float getOpacity(boolean isNightMode) {
    return isNightMode ? Constants.NIGHT_MODE_ALPHA : Constants.NO_ALPHA;  // 0.88f : 1.00f
}
ui/PlayControlFragment.java — 썸네일에 야간 알파 적용
binding.layoutPlayControlBodyContentInfo.imageviewPlayControlEpisode
    .setAlpha(Utils.getOpacity(Utils.isNightMode(getResources().getConfiguration())));
