미디어 아이콘 제공

기능 개요

미디어 세션의 MediaItem 아이콘 URI는 외부 시스템(런처·시스템 미디어 표시)도 읽을 수 있어야 합니다. 원격 HTTP 썸네일 URL을 그대로 넘기면 권한·접근 문제가 생기므로, 채널/에피소드 목록을 만들 때 MediaIconContentProvider.mapUrl()로 원격 URL을 content://com.altimedia.automotive.kt.service.podcast/… 형태의 ContentProvider URI로 변환해 아이콘 URI로 설정합니다. 변환 시 원격 URL ↔ content URI 매핑을 내부 uriMap에 보관합니다.

다른 프로세스나 같은 앱의 UI가 이 content:// URI를 열면 openFile()이 호출됩니다. 이때 매핑된 원격 URL을 Glide로 다운로드(asFile(), 최대 10초 타임아웃)해 캐시 파일로 저장하고 ParcelFileDescriptor(읽기 전용)로 돌려줍니다. 앱 UI 측은 화면에 직접 그릴 때는 getImageUriFromContentsUri()로 content URI에서 원격 URL을 역조회해 Glide로 로드합니다. ContentProvider는 AndroidManifest.xml에 authorities com.altimedia.automotive.kt.service.podcast, exported="false"로 선언되어 있습니다.

매핑·캐싱 한 곳에
쓰기(목록 생성)는 mapUrl()로 원격→content 매핑을 등록하고, 읽기(아이콘 표시)는 같은 프로바이더의 openFile()이 Glide 캐시 파일을 FD로 제공합니다. UI 내부 표시는 getImageUriFromContentsUri()로 원격 URL을 직접 얻어 우회 로드합니다.

핵심 코드

media/MediaIconContentProvider.java — 원격 URL → content URI 매핑
public static Uri mapUrl(Uri uri, String parentId) {
    String path;
    if (uri.getEncodedPath() != null) {
        path = uri.getEncodedPath().substring(1).replace('/', ':');
        Uri contentUri = new Uri.Builder()
                .scheme(ContentResolver.SCHEME_CONTENT)
                .authority(Constants.PROVIDER_AUTHORITY)
                .path(parentId)
                .appendPath(path)
                .build();
        uriMap.put(contentUri, uri);   // content URI ↔ 원격 URL 매핑
        return contentUri;
    }
    return Uri.EMPTY;
}
media/MediaIconContentProvider.java — openFile: Glide 캐시 파일을 FD로 제공
public ParcelFileDescriptor openFile(@NonNull Uri uri, @NonNull String mode) throws FileNotFoundException {
    Uri remoteUri = uriMap.get(uri);
    if (remoteUri == null) throw new FileNotFoundException(uri.getPath());
    File file = new File(getContext().getCacheDir(), uri.getPath());
    if (!file.exists()) {
        File cacheFile = Glide.with(getContext()).asFile().load(remoteUri)
                .submit().get(DOWNLOAD_TIMEOUT_SECONDS, TimeUnit.SECONDS);
        cacheFile.renameTo(file);
        file = cacheFile;
    }
    return ParcelFileDescriptor.open(file, ParcelFileDescriptor.MODE_READ_ONLY);
}
