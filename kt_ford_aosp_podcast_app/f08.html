기능 개요

기가지니 음성 명령은 podcast.play 인텐트로 전달됩니다. PodcastReceiver가 이를 받아 KEY_PLAY_FROM_VOICE=true와 음성 메타데이터(metadata JSON 문자열)를 실어 PodcastBrowserService를 startService()로 깨웁니다. 서비스의 onStartCommand()는 메타데이터를 파싱해 NE-podcast·NE-category·NE-search·NE-start 값으로 동작을 분기합니다.

분기는 다음과 같습니다. (1) NE-podcast와 NE-search가 함께 오면 키워드 검색(예: "팟캐스트 김어준") → 검색 후 첫 채널 자동 재생, (2) "팟캐스트 들려줘"·"재생"(NE-start)이면 현재 상태에 따라 재개하거나 마지막 시청 항목 재생, (3) "인기팟캐스트"(NE-category=인기팟캐스트, NE-search=인기)면 랭킹 목록 조회 후 자동 재생, (4) "추천팟캐스트"면 추천 목록, (5) 그 외 카테고리 발화(예: "정치 팟캐스트 틀어줘", NE-category=시사및정치팟캐스트)면 카테고리 채널 목록을 받아 첫 채널 자동 재생. 음성 경로는 모두 fromVoice=true로 흘러, 결과 목록을 화면에 띄우는 대신 첫 채널·첫 에피소드를 곧장 재생합니다.

카테고리 정규화
카테고리 채널 조회 시 PodcastRequest.getCategoryChannelList()는 발화에서 "팟캐스트" 접미를 제거(category.replace("팟캐스트", ""))한 뒤 channellist?type=category&category=로 게이트웨이를 호출합니다.

흐름. podcast.play + JSON 메타데이터를 받아 발화 종류별로 게이트웨이를 호출하고, 음성 경로는 첫 채널의 첫 에피소드를 자동 재생합니다.

핵심 코드

media/PodcastBrowserService.java — onStartCommand 음성 메타데이터 분기
if (intent.getBooleanExtra(Constants.KEY_PLAY_FROM_VOICE, false)) {
    String metadata = intent.getStringExtra(Constants.VOICE_KEY_METADATA);
    JsonObject jsonMetadata = Utils.getStringToJsonObject(metadata);
    String valuePodcast = Utils.getJsonElementToString(jsonMetadata, Constants.VOICE_KEY_PODCAST);
    String valueCategory = Utils.getJsonElementToString(jsonMetadata, Constants.VOICE_KEY_CATEGORY);
    String valueSearch   = Utils.getJsonElementToString(jsonMetadata, Constants.VOICE_KEY_SEARCH);
    String valueStart    = Utils.getJsonElementToString(jsonMetadata, Constants.VOICE_KEY_START);

    if (valuePodcast != null && valueSearch != null) {            // 키워드 검색
        PodcastRequest.getSearchResult(SEARCH_COUNT, SEARCH_TYPE_SEARCH, valueSearch, SEARCH_ROOT_ID, true, this, null);
    } else if (Constants.VOICE_VALUE_CATEGORY_POPULARITY.equals(valueCategory)
            && Constants.VOICE_VALUE_SEARCH_POPULARITY.equals(valueSearch)) {   // 인기
        PodcastRequest.getRankingList(POPULARITY_LIST_COUNT, "ranking", null, true, this, null);
    } else if (Constants.VOICE_VALUE_CATEGORY_RECOMMEND.equals(valueCategory)) {  // 추천
        PodcastRequest.getRecommendList(RECOMMEND_LIST_COUNT, false, null, true, this, null);
    } else if (valueCategory != null) {                          // 카테고리 발화
        PodcastRequest.getCategoryChannelList(CATEGORY_CHANNEL_LIST_COUNT, "category", valueCategory, SEARCH_ROOT_ID, true, this, null);
    }
}
receiver/PodcastReceiver.java — podcast.play 인텐트를 서비스로 전달
case Constants.ACTION_START_PODCAST: {
    Intent playIntent = new Intent(context, PodcastBrowserService.class);
    playIntent.putExtra(Constants.KEY_PLAY_FROM_VOICE, true);
    if (metadata != null) {
        playIntent.putExtra(Constants.VOICE_KEY_METADATA, metadata);
    }
    context.startService(playIntent);
    break;
}
