마이팟 구독 관리

팟을 마이팟(보관함)으로 등록/해제하고 보관함에서 삭제합니다. 구독 목록은 단말 SharedPreferences에 콤마 구분 문자열로 저장되며 최대 20개(MAX_MYPOD_NUM = 20)까지 관리됩니다.

기능 개요

마이팟 등록/해제는 UI가 직접 저장소를 만지지 않고 미디어 브라우저 커스텀 액션으로 서비스에 위임하는 구조입니다. 재생 화면·재생 목록의 마이팟 버튼을 누르면 PodcastData.PodcastCustomAction(MYPOD.ON 또는 MYPOD.OFF, extra에 pid)을 LiveData로 발행하고, PodcastMediaClient가 이를 관찰해 mediaBrowser.sendCustomAction()으로 서비스에 전달합니다.

서비스의 onCustomAction()은 PodcastPreferenceManager.addSync()/deleteSync()/deleteListSync()를 호출해 보관함을 동기 갱신합니다. 저장 형식은 key.mypod 키에 pid1,pid2,... 콤마 구분 문자열이며, addSync()는 중복을 건너뛰고 목록 크기가 MAX_MYPOD_NUM(20)에 도달하면 추가를 거부합니다. UI에서는 추가 전에도 목록 크기를 검사해 20개 초과면 PodcastDialog(TYPE_MYPOD_MAX_NOTICE)로 안내합니다. 변경 결과는 갱신된 pid 리스트(CUSTOM_KEY_MYPOD_PID_LIST) 번들로 반환되어 setMyPodList()로 ViewModel에 반영되고, 동시에 SharedPreferences.OnSharedPreferenceChangeListener가 notifyChildrenChanged(MYPOD_ROOT_ID)를 호출해 마이팟 화면 목록을 다시 그립니다.

상한 처리 위치
20개 상한은 두 군데에서 방어합니다. UI(PlayControlFragment/PlayListFragment)가 클릭 시점에 크기를 검사하고, 저장소(PodcastPreferenceManager.addSync())도 동일 상한에서 false를 반환합니다. 보관함 다중 삭제는 MYPOD.DELETE + pid 리스트로 한 번에 처리합니다.

핵심 코드

media/PodcastBrowserService.java — MYPOD.ON 커스텀 액션 처리
if (TextUtils.equals(Constants.CUSTOM_ACTION_MYPOD_ON, action)) {
    if (extras != null) {
        String pid = extras.getString(Constants.CUSTOM_KEY_MYPOD_PID);
        if (pid != null && pid.length() > 0) {
            if (PodcastPreferenceManager.getInstance().addSync(PodcastPreferenceManager.KEY_MY_POD, pid)) {
                result.sendResult(getMyPodListBundle());
                return;
            }
        }
    }
    result.sendError(null);
}
common/manager/PodcastPreferenceManager.java — 20개 상한·중복 방지 저장
public boolean addSync(@NonNull String key, @NonNull String value) {
    String local = servicePreferences.getString(key, "");
    if (local.equals("")) {
        return setSync(key, value);
    } else {
        StringTokenizer st = new StringTokenizer(local, ",");
        while (st.hasMoreTokens()) {
            if (value.equals(st.nextToken())) return false;   // 중복
        }
        ArrayList<String> list = makeListFromCommaSeparatorSequence(local);
        if (list.size() == Constants.MAX_MYPOD_NUM) return false;  // 상한 20
        return setSync(key, local + "," + value);
    }
}
