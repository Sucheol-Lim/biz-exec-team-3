기능 개요

차량 인포테인먼트는 분할 화면(멀티윈도우, half)과 전체 화면(full), 그리고 가로/세로 방향이 런타임에 바뀝니다. MainActivity는 configChanges로 screenLayout|screenSize|smallestScreenSize|orientation|uiMode를 직접 처리하도록 선언되어 있고, 멀티윈도우 진입/이탈은 onMultiWindowModeChanged()에서 PodcastViewModel.setIsInMultiWindowMode()로 상태를 갱신합니다. 각 Fragment는 이 LiveData(getIsInMultiWindowMode())를 관찰해 showMultiWindowView()로 half/full 레이아웃을 전환합니다.

레이아웃 전환은 두 방식을 병행합니다. 첫째, 정적 리소스 한정자(res/layout 가로 기본, res/layout-port 세로, res/layout-ldpi 저밀도, res/values-port·res/values-ldpi·res/values-mdpi 등)로 단말 구성에 맞는 레이아웃·치수를 자동 선택합니다. 둘째, Airbnb Paris(Paris.style(view).apply(R.style.xxx_half/full))로 동일 뷰에 half/full 스타일을 코드에서 즉시 적용해 분할 화면 전환을 부드럽게 처리합니다. 또한 GridLayoutManager의 span 수·방향(가로/세로)을 getSpanCount()에서 멀티윈도우·방향 조합에 따라 계산해 목록 그리드를 재배치합니다.

방향 강제 정합
MainActivity.setConfigFromRealOrientation()는 실제 단말 방향(Utils.getScreenOrientation())과 전달된 Configuration.orientation이 어긋나면 updateConfiguration()으로 방향을 강제 정렬해, 차량 단말에서 방향 보고가 일관되지 않을 때 발생하는 레이아웃 깨짐을 보정합니다. uiMode가 바뀌면 nav_host Fragment를 detach/attach로 재생성합니다.

핵심 코드

ui/PodcastFragment.java — half/full 스타일 동적 적용
private void showHalfWindowView() {
    Paris.style(binding.layoutPodcastBody.recyclerviewPodcastList).apply(R.style.recyclerview_podcast_sub_half);
    Paris.style(binding.layoutPodcastBody.getRoot()).apply(R.style.layout_podcast_body_half);
}

private void showFullWindowView() {
    Paris.style(binding.layoutPodcastBody.recyclerviewPodcastList).apply(R.style.recyclerview_podcast_sub_full);
    Paris.style(binding.layoutPodcastBody.getRoot()).apply(R.style.layout_podcast_body_full);
}
ui/PodcastFragment.java — 멀티윈도우·방향에 따른 그리드 span 계산
private int getSpanCount(boolean isInMultiWindowMode) {
    int spanCount;
    if (podcastViewModel.getRealOrientation() == Configuration.ORIENTATION_LANDSCAPE) {
        spanCount = 1;
    } else {
        if (isInMultiWindowMode) {
            spanCount = 1;
        } else {
            spanCount = 3;
        }
    }
    return spanCount;
}
