메인 화면 (추천·인기·마이팟)

MainFragment가 미디어 브라우저 루트(PODCAST_ROOT_ID)를 구독해 추천 1위 팟, 인기팟·마이팟·추천팟 메뉴를 한 화면에 모아 보여주는 시작 화면입니다. 메뉴 항목 선택은 채널 목록으로, 일반 팟 선택은 곧바로 재생으로 이어집니다.

기능 개요

메인 화면은 Navigation 그래프의 시작 목적지(mainFragment)이며, 화면 생성 시점에 PodcastViewModel.subscribeMediaItem(PODCAST_ROOT_ID, ...)로 미디어 브라우저 루트를 구독합니다. 서비스(PodcastBrowserService)는 이 루트 구독에 대해 추천 목록을 조회한 뒤, 추천 1위 팟을 재생 가능한 머리 항목으로 두고 그 뒤에 인기팟·마이팟·추천팟 3개의 브라우저블 메뉴를 붙여 MediaItem 리스트로 돌려줍니다.

MainListAdapter가 이 목록을 그리드로 렌더링합니다. 항목을 누르면 MainFragment.initAdapter()의 클릭 리스너가 동작하는데, 누른 항목이 메뉴(인기/마이팟/추천 루트 ID)면 PodcastFragment로 이동해 채널 목록을 펼치고, 그렇지 않은 추천 1위 팟이면 해당 채널을 다시 구독해 첫 에피소드를 playFromMediaId로 재생하면서 PlayControlFragment로 전환합니다. 화면 하단에는 현재 재생 정보를 보여주는 미니 플레이어 바가 항상 노출됩니다.

설계 포인트
메인 화면은 콘텐츠를 직접 네트워크로 받지 않습니다. MediaBrowserCompat 구독만 걸고 결과는 SubscriptionCallback.onChildrenLoaded()로 전달받아 PodcastViewModel에 캐시(addMediaItemList)합니다. 마이팟 변경 시 서비스가 notifyChildrenChanged()로 통지하면 같은 콜백이 다시 호출되어 목록이 갱신됩니다.

흐름. 화면 진입 시 루트를 구독하면 서비스가 추천 1위 팟과 3개 메뉴를 묶어 돌려주고, 항목 종류(메뉴/팟)에 따라 채널 목록 또는 재생 화면으로 분기합니다.

핵심 코드

ui/MainFragment.java — 항목 클릭 시 메뉴/팟 분기 처리
if (isMenuMediaItem(mediaItem)) {
    //인기팟, MY팟, 추천팟
    String mediaId = mediaItem.getDescription().getMediaId();
    MainFragmentDirections.ActionMainFragmentToPodcastFragment action =
            MainFragmentDirections.actionMainFragmentToPodcastFragment();
    action.setMediaId(mediaId);
    Navigation.findNavController(requireView()).navigate(action);
} else {
    isClicked.set(true);
    podcastViewModel.subscribeMediaItem(mediaItem.getDescription().getMediaId(), playListSubsCallback);
}
ui/MainFragment.java — 루트 구독 결과를 ViewModel 캐시에 반영
public void onChildrenLoaded(@NonNull String parentId, @NonNull List<MediaBrowserCompat.MediaItem> children) {
    ArrayList<MediaBrowserCompat.MediaItem> list = new ArrayList<>(children);
    if (podcastViewModel.getMediaItemList(parentId) == null
            || Utils.isDiffArrayList(podcastViewModel.getMediaItemList(parentId), list)) {
        podcastViewModel.addMediaItemList(parentId, list);
        adapter.notifyItemRangeChanged(Constants.START_INDEX, list.size());
    }
    podcastViewModel.isContentLoading.setValue(false);
}
