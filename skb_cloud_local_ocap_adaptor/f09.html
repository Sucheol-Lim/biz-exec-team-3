기능 개요

SI(Service Information)는 방송 채널 메타데이터를 다루는 영역입니다. 어댑터는 이를 CladSIService 인터페이스로 노출하며, CladContext.getSIService() 로 획득합니다. 단일 메서드 getChannelList(String ringName) 가 "채널 링" 이름을 받아 해당 분류의 채널 목록을 반환합니다.

채널 링 이름은 인터페이스 상수로 정의됩니다. CHANNEL_LIST_NAME_SURFABLE("SURFABLE"), SURFABLE_AV, SURFABLE_AUDIO, FAVORITE, BLOCKED, SKIPPED 가 있어, 서핑 가능한 전체/AV/오디오 채널, 즐겨찾기, 차단·건너뛴 채널을 구분해 조회할 수 있습니다. Cloud App 은 이 상수를 ring 인자로 넘겨 원하는 분류의 채널만 받습니다.

반환 타입은 ROP 직렬화 구조체 CladChannelList 입니다. 세 필드 ccidList(채널 ID 목록), name(링 이름), additionalInformations(부가정보 목록)로 구성되며, 직렬화는 CladChannelListCodec 이 처리합니다. JS 코덱에서도 동일한 Struct([ListCodec, STRING], "ccidList", STRING, "name", [NullableCodec,[ListCodec,STRING]], "additionalInformations")로 등록되어 양쪽 직렬화 포맷이 일치합니다.

설계 포인트
OCAP 확장 인터페이스 OcapCladSIService 는 CladSIService 를 상속해 getVodTsId(boolean forceScan) 를 추가합니다. 채널 링 조회는 베이스에 두고, VOD 전송용 TS ID 스캔처럼 플랫폼 특화 동작은 확장에 둬 인터페이스를 계층화했습니다(상세는 "사업자 전용 확장" 기능 참고).

핵심 코드

clad/si/CladSIService.java — 채널 링 상수와 조회 메서드
public interface CladSIService {
    public static final String CHANNEL_LIST_NAME_SURFABLE = "SURFABLE";
    public static final String CHANNEL_LIST_NAME_SURFABLE_AV = "SURFABLE_AV";
    public static final String CHANNEL_LIST_NAME_SURFABLE_AUDIO = "SURFABLE_AUDIO";
    public static final String CHANNEL_LIST_NAME_FAVORITE = "FAVORITE";
    public static final String CHANNEL_LIST_NAME_BLOCKED = "BLOCKED";
    public static final String CHANNEL_LIST_NAME_SKIPPED = "SKIPPED";
    CladChannelList getChannelList (String ringName);
}
clad/si/CladChannelList.java — 반환 구조체
public class CladChannelList {
    public List ccidList;                 // 채널 ID 목록
    public String name;                   // 링 이름
    public List additionalInformations;   // 부가정보
    public CladChannelList () {}
    public CladChannelList (List arg0, String arg1, List arg2) {
        this.ccidList = arg0;
        this.name = arg1;
        this.additionalInformations = arg2;
    }
}
