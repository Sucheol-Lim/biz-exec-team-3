TV 채널 제어

CladTVService 가 채널 선택(selectChannel*), 현재/이전/LCW 채널 조회, 타입별·캠페인 제외 채널 리스트 조회, 기본 채널·서비스 이탈·재부팅 등 TV 동작을 정의합니다.

기능 개요

CladTVService 는 어댑터가 노출하는 TV 동작의 단일 인터페이스입니다. CladContext.getTVService() 로 획득하며, ROP 태그 0xafba1113baf041aa 으로 식별됩니다. 채널 선택 계열은 sourceId 기반(selectChannel(int sourceId, List), selectChannelToWatch(int sourceId))과 채널 ID 기반(selectChannelById(String), selectChannelToWatchById(String))이 함께 제공됩니다.

현재 상태 조회로는 getCurrentChannel(), getPreviousChannel(), getLCW()(Last Channel Watched)가 있고, 채널 목록 조회로는 타입별 getChannelList(int type)·getChannelListByCurrent(int)·캠페인 제외 getChannelListWithoutCampaign(int)·문자열 형태 getChannelListStr(int)·채널 ID 묶음 getChannelListByChannelIds(List) 등이 있습니다. 기본 채널은 getDefaultChannel()/setDefaultChannel(int) 로 다루고, 즐겨찾기 결과는 상수 FAVORIT_FAIL=0/FAVORIT_SUCCESS=1/FAVORIT_OVER_COUNT=2 로 표현됩니다.

그 밖에 서비스 이탈(exitToService(int sourceId, int param)), 셋톱박스 재부팅(reboot()), CA 구매 요청(requestCaPurchase), 언바운드 앱 시작(startUnboundApp) 등이 정의됩니다. 본 저장소의 구현체 CladTVServiceImpl 은 대부분 기본값(false/null/"")을 반환하는 골격 상태이며 실제 플랫폼 연동은 상위 범위로 추정됩니다.

설계 포인트
채널 선택 결과 권한은 비동기 콜백 ChannelEventListener.onChannelEvent 로 전달됩니다. setChannelEventListener 로 등록한 리스너에 채널 변경·권한 코드가 통지되며, 이 흐름은 "권한·서비스 컨텍스트 콜백" 기능에서 상세히 다룹니다.

핵심 코드

clad/tv/CladTVService.java — TV 동작 인터페이스(발췌)
public interface CladTVService {
    public static final int FAVORIT_FAIL = 0;
    public static final int FAVORIT_SUCCESS = 1;
    public static final int FAVORIT_OVER_COUNT = 2;
    void setChannelEventListener (ChannelEventListener listener);
    void selectChannel (int sourceId, List parameters);
    void selectChannelToWatch (int sourceId);
    void selectChannelById (String chId);
    String getCurrentChannel ();
    String getPreviousChannel ();
    String getLCW ();
    List getChannelList (int type);
    List getChannelListWithoutCampaign (int type);
    int getDefaultChannel ();
    boolean setDefaultChannel (int chNum);
    boolean exitToService (int sourceId, int param);
    boolean reboot ();
}
cladimpl/tv/CladTVServiceImpl.java — 채널 이벤트 통지(골격 구현)
public void setChannelEventListener(ChannelEventListener listener) {
    this.listener = listener;
}

public void onChannelEvent(String chid, int chNum, String chName, int perm) {
    if (listener != null) {
        try {
            listener.onChannelEvent(chid, chNum, chName, perm);
        } catch (Exception e) {
            listener = null;
            e.printStackTrace();
        }
    }
}
