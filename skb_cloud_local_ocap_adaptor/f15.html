JS ↔ Java 코덱 일치

js/cloud_adaptor.js 가 동일 인터페이스/구조체를 Java 측과 같은 64bit 태그·32bit 메서드 해시로 등록해, 브라우저/클라우드 런타임과 STB Java 런타임이 ROP로 정확히 매칭되도록 합니다.

기능 개요

ROP 통신이 성립하려면 호출하는 쪽(Cloud/브라우저, JS)과 호출받는 쪽(STB, Java)이 동일한 타입 식별 체계를 공유해야 합니다. 인터페이스는 64bit 태그로, 각 메서드는 32bit 해시로 식별되는데, 이 값이 양쪽에서 한 비트라도 다르면 호출이 매칭되지 않습니다. js/cloud_adaptor.js 는 JS 측의 타입 등록 스크립트로, Java 산출물(*Skel/stub/S*)과 동일한 태그·해시를 등록하는 역할을 합니다.

스크립트는 acba.define("js:cloud_adaptor", ["js:rop"], function(r) { ... }) 형태로 js:rop 런타임에 의존하는 모듈을 정의합니다. 본문에서 ROP 기본 타입(I8/I16/I32/I64/STRING/BOOLEAN/F32/F64 등)과 코덱(NullableCodec/ListCodec/MapCodec/StructCodec/InterfaceCodec)을 꺼낸 뒤, r.addTypes({ ... }) 한 번으로 모든 인터페이스·구조체를 일괄 등록합니다.

각 인터페이스 항목은 [InterfaceCodec, "<64bit 태그>", <상수 배열>, { <메서드 해시>: [이름, 인자 코덱, 반환 코덱], ... }] 구조입니다. 예를 들어 clad.CladServiceManager 의 태그 "d855fbc474dc6a53" 과 메서드 0xb2815b12: getCloudAdaptorVersion 은 Java 측 CladServiceManagerSkel.getTag()·processRequest 의 값과 정확히 일치합니다. 구조체(clad.CloudApp, clad.si.CladChannelList)는 StructCodec 으로 필드 순서·타입까지 Java 클래스와 맞춰 등록됩니다.

설계 포인트
이 파일은 IDL(alticast_cloud_adaptor.idl)에서 Java 산출물과 함께 생성되는 코덱입니다. IDL 을 고치면 Java *Skel·stub/S* 와 이 JS 코덱을 다시 생성해야 양쪽 태그·해시가 일치합니다(IDL 컴파일러는 저장소 미포함). 즉 이 파일은 "두 런타임 간 ABI 계약서" 역할을 합니다.

흐름. 모듈 로딩 시 JS 코덱이 모든 타입을 Java 와 동일한 태그·해시로 등록하고, 이후 원격 호출은 그 식별자로 STB Java 의 Skeleton 과 매칭됩니다.

관계. JS 코덱의 InterfaceCodec/StructCodec 등록 항목이 Java 측 Skeleton 의 태그·메서드 해시, 구조체 클래스의 필드 정의와 1:1로 대응합니다.

핵심 코드

js/cloud_adaptor.js — 모듈 정의와 타입 등록(발췌)
acba.define("js:cloud_adaptor", ["js:rop"], function(r) {
    var types = r.types
    var STRING = types.String
    var I64 = types.i64
    var InterfaceCodec = r.codecs.Interface
    var StructCodec = r.codecs.Struct
    r.addTypes({
    'clad.CladServiceManager': [InterfaceCodec, "d855fbc474dc6a53", undefined,
        {0xb2815b12: ["getCloudAdaptorVersion", undefined, [STRING]],
         0x31ecefec: ["createCladContext", [I64], ["clad.CladContext"]],
         0xae901df4: ["getMainWindowOwner", undefined, [I64]]}],
    'clad.CloudApp': [StructCodec, I64, "id", STRING, "name", STRING, "cloudUrl",
         /* ... 필드 순서·타입을 Java CloudApp 과 일치 ... */ ],
    /* ... 나머지 인터페이스/구조체 동일 패턴 ... */
    })
    return null
})
clad/CladServiceManagerSkel.java — Java 측 동일 태그·해시(대조)
public long getTag () { return 0xd855fbc474dc6a53l; }   // JS "d855fbc474dc6a53" 와 일치

public void processRequest (LocalCall lc) {
    switch (lc.buffer.readI32()) {
    case 0xb2815b12: __call_getCloudAdaptorVersion(lc); return;  // JS 0xb2815b12 와 일치
    case 0x31ecefec: __call_createCladContext(lc); return;
    }
}
