기능 개요

BT RCU(블루투스 리모컨) 제어와 외부 앱 실행은 CladConfigService 인터페이스 안에 함께 정의됩니다(환경 설정 기능과 같은 인터페이스). BT RCU 관련으로는 RCU 페어링 모드 진입(setBTRCUMode())과 해제(setBTRCUModeOut()), 연결 기기 수 조회(getBTConnectedDeviceCount()), 기기 등록 모드(setBTDeviceRegistMode()), 연결 기기 목록 모드(setConnectedBTDeviceListMode())가 있습니다. 모두 모드 전환을 트리거하고 성공 여부를 boolean 으로 회신합니다.

외부 앱 실행은 세 종류입니다. startBrowser(int type, String url) 는 type 상수(TYPE_FULL_BROWSER(0)/TYPE_WEB_APP(1))에 따라 풀 브라우저 또는 웹앱으로 URL 을 엽니다. startSmartApp(int smartAppType, String url, String lastId) 는 스마트앱 타입(MY_APP(0)/BROWSER(1)/APP_STORE(2)/HOME_CHOICE_APP_STORE(3))을 받아 스마트앱을 실행하며 복귀용 lastId 를 전달합니다. startICS(String appName, String lastId) 는 ICS 앱을 실행합니다.

그 밖에 자가진단 팝업(showSelfDiagnosticsPopup()), 기기 등록 해제(requestUnRegister(String deviceId)), VOD 숨김 정보 조회(getVODHiddenInfo()), PMS 목록 조회(getPMS()) 등 운영·진단성 메서드도 같은 인터페이스에 포함됩니다.

설계 포인트
외부 앱 실행에 복귀 식별자 lastId 를 인자로 받는 점이 특징입니다. 외부 앱이 끝난 뒤 어느 화면/앱으로 돌아갈지를 호출 시점에 명시해, 브라우저·스마트앱·ICS 간 전환에서 내비게이션 컨텍스트를 잃지 않도록 합니다.
