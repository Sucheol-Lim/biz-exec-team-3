미디어 재생 제어

CladMediaPlayerService 가 playStart/pause/resume, 트레일러 재생, 다양한 정지(playStop/playStopWithoutTune/playStopWithChChange/playStopWithReservedCh), stopAndPlay, setMediaConfig 를 정의합니다.

기능 개요

CladMediaPlayerService 는 미디어 재생의 베이스 인터페이스로, CladContext.getMediaPlayerService() 로 획득합니다. 기본 재생 제어는 playStart()(int 반환), pause()/resume()(boolean)로 구성되고, 트레일러 재생용 playStartVodTrailer() 와 sid 지정 playStartTrailer(int sid) 가 별도로 있습니다.

정지 동작은 상황별로 네 갈래로 세분화됩니다. 일반 정지 playStop(), 튜닝 없이 정지 playStopWithoutTune(), 채널 전환을 동반한 정지 playStopWithChChange(), 예약 채널로 정지 playStopWithReservedCh(int sid) 입니다. 정지와 다음 콘텐츠 재생을 한 번에 처리하는 stopAndPlay(List value) 는 int 결과를 반환합니다(2019-02-27 커밋 d319626 에서 추가).

재생 환경 설정은 setMediaConfig(String key, List value) 로 키-값 형태로 지정합니다. 이 베이스 인터페이스는 VOD 전용 확장 UmpMediaPlayerService 의 부모이며, UMP 는 여기에 데이터소스 설정·VOD 요청 ID·이벤트/결과 상수 등을 더합니다(상세는 "UMP 기반 VOD 재생" 기능 참고).

설계 포인트
정지 메서드를 단일 stop() 이 아니라 네 종류로 나눈 이유는, 셋톱박스에서 미디어 정지 후 후속 동작(채널 튜닝 여부·예약 채널 이동)이 달라 자원/튜너 처리 흐름이 다르기 때문입니다. Cloud App 이 의도를 명시하도록 메서드를 분리했습니다.
