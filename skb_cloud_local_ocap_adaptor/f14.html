기능 개요

이 어댑터는 공통 인터페이스(clad.*) 위에 OCAP 플랫폼 확장(clad.*.ocap)과 TBroad 사업자 확장(clad.*.ocap.tbroad)을 계층으로 쌓는 구조입니다. 상속을 통해 베이스의 모든 동작을 물려받으면서 환경별 메서드·상수만 더합니다.

TV 영역에서는 OcapCladTVService extends CladTVService 가 OCAP 계층을, TbroadCladTVService extends OcapCladTVService 가 TBroad 계층을 형성합니다. TBroad 계층은 List getChannelHistory() 한 메서드를 추가해 채널 시청 이력 조회를 지원합니다(JS 코덱에서 메서드 해시 0x7d96e224). 채널 이벤트 리스너도 TbroadChannelEventListener extends ChannelEventListener 가 베이스의 PERM_* 코드에 더해 ADULT_BLOCKED(10)·WRONG_PIN(11) 상수를 추가해, 성인 콘텐츠 차단과 핀 오류를 별도 코드로 구분합니다.

SI 영역에서는 OcapCladSIService extends CladSIService 가 int[] getVodTsId(boolean forceScan) 을 추가합니다. VOD 전송에 필요한 TS ID 를 조회하며, forceScan 인자로 강제 재스캔 여부를 지정합니다. 이렇게 베이스 인터페이스는 사업자에 독립적으로 두고, OCAP/TBroad 전용 동작은 확장 인터페이스로 분리해 다른 사업자 어댑터와 공통 코드를 공유할 수 있게 했습니다.

설계 포인트
각 확장 인터페이스는 별도 ROP 64bit 태그를 갖습니다(예: TbroadCladTVService = 0x2c5e6fdb4e57285d, OcapCladSIService = 0x58c31b5f176fbd97). 따라서 Cloud App 은 실행 환경에 맞는 태그의 인터페이스로 원격 객체를 바인딩하며, 상속받은 베이스 메서드 해시는 동일하게 공유합니다.

관계. OCAP·TBroad 확장 인터페이스가 공통 베이스를 상속해 사업자 전용 메서드(getChannelHistory, getVodTsId)와 권한 코드(ADULT_BLOCKED/WRONG_PIN)를 더합니다.

핵심 코드

clad/tv/ocap/tbroad/TbroadCladTVService.java — 채널 이력 추가
public interface TbroadCladTVService extends OcapCladTVService {
    List getChannelHistory ();      // TBroad 전용
}
clad/tv/ocap/tbroad/TbroadChannelEventListener.java · clad/si/ocap/OcapCladSIService.java
public interface TbroadChannelEventListener extends ChannelEventListener {
    public static final byte ADULT_BLOCKED = 10;   // 성인 차단
    public static final byte WRONG_PIN = 11;       // 핀 오류
}

public interface OcapCladSIService extends CladSIService {
    int[] getVodTsId (boolean forceScan);          // VOD 전송용 TS ID 스캔
}
