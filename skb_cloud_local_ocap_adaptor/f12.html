기능 개요

CladConfigService 는 단말 환경 설정과 보안(핀·등급) 전반을 다루는 인터페이스로, CladContext.getConfigService() 로 획득합니다. 설정 조회는 문자열 반환 메서드들로 제공됩니다. getSafeSetting()(안전 설정), getTVSetting(), getServiceSetting(), getSystemInfo() 가 각 영역의 설정을 직렬화된 문자열로 돌려줍니다.

보안 영역에서는 클라우드 핀 모드 전환(setCloudPinMode(boolean)), 시청 등급 조회·설정(getParentalRating()/setParentalRating(int)), 재인증 요청(requestReAuth())을 제공합니다. 핀 코드 관리는 메시지 기반 managePin(String message) 한 메서드로 처리하며 문자열 결과를 반환하는데, 이는 커밋 0787dd0·202b902(2018-11-29, "managePin 추가")에서 도입된 기능입니다.

사용자 설정은 키-값 형태로 다룹니다. setUserConfig(key, value) 로 저장, getUserConfig(key, value) 로 조회하며, 설정 변경 통지를 받으려면 setUserConfigListener(UserConfigListener listener, List key) 로 관심 키 목록과 리스너를 등록합니다. 등록된 리스너는 onUserConfigChanged(String key) 콜백으로 어떤 키가 바뀌었는지 통지받습니다. (이 인터페이스는 BT RCU·외부 앱 실행 메서드도 함께 포함하며, 그 부분은 별도 기능 페이지에서 다룹니다.)

설계 포인트
managePin 을 개별 메서드 대신 String message 입력 → String 출력 형태로 둔 것은, 핀 등록/변경/검증 등 여러 핀 작업을 하나의 메시지 프로토콜로 캡슐화해 IDL 표면을 단순하게 유지하기 위한 설계로 보입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant Cloud as Cloud App participant CTX as CladContextImpl participant CFG as CladConfigService participant L as UserConfigListener Cloud->>CTX: getConfigService() CTX-->>Cloud: CladConfigService Cloud->>CFG: getSystemInfo() CFG-->>Cloud: 시스템 정보(String) Cloud->>CFG: setUserConfigListener(listener, keys) Cloud->>CFG: managePin(message) CFG-->>Cloud: 핀 처리 결과(String) Cloud->>CFG: setParentalRating(rating) CFG->>L: onUserConfigChanged(key) L-->>Cloud: 설정 변경 통지

흐름. 설정 서비스를 받아 시스템 정보 조회·핀 관리·시청 등급 설정을 수행하고, 관심 키 변경은 UserConfigListener 콜백으로 통지받습니다.
