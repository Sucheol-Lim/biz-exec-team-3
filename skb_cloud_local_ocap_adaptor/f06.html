기능 개요

예약·즐겨찾기 기능은 모두 CladTVService 인터페이스 안에 함께 정의됩니다. 예약은 sourceId·제목·시작/종료 시각·등급(rating)을 인자로 받는 한 묶음의 메서드 집합으로 구성됩니다. reserve(...) 가 일반 예약, forceReserve(...) 가 충돌을 무시한 강제 예약, cancelReserve(...) 가 예약 취소, isReserved(...) 가 예약 여부 조회를 담당하며 모두 boolean 으로 성공 여부를 반환합니다.

예약 충돌은 findDuplicatedReserve(String startTime, String endTime) 로 사전에 점검합니다. 주어진 시간대에 겹치는 기존 예약을 찾아 그 정보를 문자열로 반환하므로(없으면 null), Cloud App 은 일반 reserve 대신 forceReserve 를 쓸지 판단할 수 있습니다. 현재 예약 목록 전체는 getReservedPrograms() 가 리스트로 돌려줍니다.

즐겨찾기는 addFavorite(int sourceId) 와 removeFavorite(int sourceId) 로 다룹니다. 추가는 결과를 int 로 반환하는데, 그 값은 인터페이스 상수 FAVORIT_FAIL(0)·FAVORIT_SUCCESS(1)·FAVORIT_OVER_COUNT(2) 중 하나입니다. 즉 단순 성공/실패뿐 아니라 즐겨찾기 한도 초과 같은 사유를 구분해 전달할 수 있습니다.

설계 포인트
예약 메서드가 모두 동일한 5개 인자(int sourceId, String title, String startTime, String endTime, int rating)를 받는 것은, 예약 식별을 키-쌍이 아니라 프로그램 정보 전체로 매칭하기 위한 것으로 보입니다. 등급(rating)이 인자에 포함돼 시청 등급 제한 예약도 표현할 수 있습니다.

흐름. 예약 전 충돌을 점검해 일반/강제 예약을 선택하고, 즐겨찾기 추가는 결과 상수로 한도 초과까지 구분해 회신합니다.
