기능 개요

UMP(Unicast Media Player)는 VOD 콘텐츠를 단방향 유니캐스트로 받아 재생하는 모듈입니다. UmpMediaPlayerService 는 CladMediaPlayerService 를 상속하므로 기본 재생 제어(playStart/pause/stop 계열)를 모두 가지면서, 여기에 VOD 세션 전용 기능을 더합니다.

세션 시작은 demandVODRequestID(assetId, categoryId) 로 요청 ID를 확보한 뒤, 데이터소스를 네 가지 변형 중 하나로 설정합니다. setDataSourceUmp0(fileName, tsList, offset, requestId), 우선순위 기준을 더한 ...Ump1(..., priorityCriteria), nodeGroupId 기반 ...Ump2(fileName, nodeGroupId, offset, requestId), 그리고 그 둘을 합친 ...Ump3 입니다. 모두 int 결과를 반환하며, 그 값은 VODRESULT_SUCCESS(1) 부터 VODRESULT_SERVER_ERROR(9) 까지의 결과 상수로 해석됩니다(useExtendedResultCode() 로 확장 결과 코드 사용).

재생 이벤트는 UmpEventListener.onEvent(int vodEvent) 로 수신합니다. 이벤트 상수에는 광고 시작/종료(VODEVENT_ADVERT_START/STOP), 파일 시작/끝(BEGIN/END_OF_FILE), 튜닝 필요(NEED_TUNE), 일시정지 타임아웃, 세션 에러/정상 등이 있습니다. 세션 상태는 getUMPStatus() 가 UMP_STATUS_INIT(50)/PLAYING(501)/READY(502) 중 하나로 반환하며, ECM 그룹(setECMGroup(byte[]))·미디어 비율(getMediaRatio/setMediaRatio)·앱 이름·VOD 요청 ID·버전(getUMPVersion) 등 부가 제어도 제공합니다.

설계 포인트
데이터소스 설정을 0~3 네 오버로드로 둔 것은 ROP/레거시 Java 에 메서드 오버로딩 시그니처 충돌을 피하면서 인자 조합(tsList vs nodeGroupId, priorityCriteria 유무)을 명시적으로 구분하기 위함입니다. 각 변형은 JS 코덱에서 서로 다른 메서드 해시(0x38729873~0x253890c8)로 등록됩니다.

public interface UmpMediaPlayerService extends CladMediaPlayerService {
    public static final int VODEVENT_ADVERT_START = 100;

    public static final int UMP_STATUS_INIT = 50;
    public static final int UMP_STATUS_PLAYING = 501;
    public static final int UMP_STATUS_READY = 502;
    public static final int VODRESULT_SUCCESS = 1;

    int setDataSourceUmp2 (String fileName, int nodeGroupId, long offset, int requestId);
    void demandVODRequestID (String assetId, String categoryId);
    void setECMGroup (byte[] ecmgroup);
    int getUMPStatus ();
    String getUMPVersion ();
}
