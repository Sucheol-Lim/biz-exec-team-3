윈도우 표시·소유권 제어

showWindow()/hideWindow() 로 메인/위젯 윈도우를 제어하며, 메인 윈도우 소유권이 다른 앱으로 넘어가면 AppManager 가 기존 소유 앱에 onHidden, 나머지 앱에 onMainWindowShown/Hidden 을 통지합니다.

기능 개요

OCAP STB 화면에는 동시에 여러 Cloud App 이 떠 있을 수 있지만, 전체 화면을 점유하는 메인 윈도우 는 한 시점에 한 앱만 소유합니다. 앱이 CladContextImpl.showWindow(windowId, windowMode) 를 호출하면 컨텍스트는 모드에 따라 mainWindow 멤버 또는 widgetWindows 해시테이블에 CladWindow 를 등록한 뒤, 소유권 판단을 AppManager.showWindow(windowId, windowMode, appId) 로 위임합니다.

AppManager 는 WINDOW_LOCK 동기화 블록에서 메인 윈도우 소유권을 관리합니다. 요청 모드가 MAIN_WINDOW 이고 현재 소유자가 존재하며 그 소유자가 요청 앱과 다르면, 기존 소유 앱 컨텍스트에 onHidden() 을 보내 화면을 양보시키고, mainWindowOwner·mainWindowId 를 새 앱으로 갱신한 뒤 notifyMainWindowOwnerChanged(appId, false) 를 호출합니다.

이 통지 메서드는 소유자를 제외한 모든 컨텍스트를 순회하며 onMainWindowShown(appId) 를 보냅니다. 반대로 hideWindow 시 닫히는 윈도우가 메인 윈도우(windowId == mainWindowId)이면 소유권을 비우고(NO_MAIN_WINDOW_OWNER = -1) notifyMainWindowOwnerChanged(appId, true) 로 나머지 앱에 onMainWindowHidden() 을 통지합니다.

설계 포인트
소유권 전환 시 두 종류의 통지가 분리됩니다. 화면을 잃는 기존 소유자 에게는 직접 onHidden() 을, 화면 상태가 바뀐 것을 알아야 하는 나머지 앱 에게는 onMainWindowShown/Hidden 을 브로드캐스트합니다. 모든 메인 윈도우 상태는 AppManager 한 곳에 집중되어 일관성을 유지합니다.

핵심 코드

cladimpl/manager/AppManager.java — 메인 윈도우 소유권 전환과 통지
public void showWindow(long windowId, byte windowMode, long appId) {
    synchronized (WINDOW_LOCK) {
        if (windowMode == CladContext.MAIN_WINDOW) {
            if (mainWindowOwner > NO_MAIN_WINDOW_OWNER && appId != mainWindowOwner) {
                CladContextImpl context =
                    (CladContextImpl) contextMap.get(new Long(mainWindowOwner));
                context.onHidden();                 // 기존 소유자에게 양보 통지
                mainWindowOwner = appId;             // 소유권 갱신
                mainWindowId = windowId;
                notifyMainWindowOwnerChanged(appId, false);
            }
        }
    }
}

private void notifyMainWindowOwnerChanged(long appId, boolean noOwner) {
    CladContextImpl[] contexts = getAvailableContexts();
    for (int i = 0; i < contexts.length; i++) {
        long id = contexts[i].getId();
        if (id != appId) {                          // 소유자 제외 전체에 브로드캐스트
            if (noOwner) contexts[i].onMainWindowHidden();
            else         contexts[i].onMainWindowShown(appId);
        }
    }
}
