권한·서비스 컨텍스트 콜백

기능 개요

채널 선택과 서비스 표시 결과는 동기 반환값이 아니라 비동기 콜백으로 Cloud App 에 전달됩니다. 두 개의 리스너 인터페이스가 이 역할을 합니다. ChannelEventListener 는 채널 변경 시 채널 ID·번호·이름과 함께 권한 코드(perm)를 onChannelEvent(chid, chNum, chName, perm) 로 통지합니다. 권한 코드는 상수로 정의되어 PERM_OK(0), PERM_USER_SKIPPED(1), PERM_PARENTAL_RATING_BLOCKED(2), PERM_CA_BLOCKED(3), PERM_ADULT_BLOCKED(4), PERM_WRONG_PIN(5) 로 구분됩니다.

ServiceContextListener 는 서비스 컨텍스트 생명주기 이벤트를 onServiceContextEvent(event, reason) 로 통지합니다. 이벤트 상수에는 PresentationChangedEvent(10), AlternativeContentEvent(101), NormalContentEvent(102), PresentationTerminatedEvent(20), SelectionFailedEvent(30), ServiceContextDestroyedEvent(40) 등이 있어, 일반/대체 콘텐츠 전환과 표시 종료·선택 실패 같은 상태 변화를 구분합니다.

통지 경로는 두 갈래입니다. 리스너 등록은 CladTVServiceImpl.setChannelEventListener / setServiceContextListener 로 컨텍스트별 TV 서비스에 보관되며, 플랫폼에서 채널 이벤트가 발생하면 AppManager.notifyChannelEvent(chId, chNum, chName, perm) 가 모든 활성 컨텍스트의 TV 서비스를 순회하며 onChannelEvent 를 호출해 브로드캐스트합니다.

설계 포인트
권한 코드를 enum 이 아니라 int 상수로 둔 것은 레거시 Java/ROP 직렬화 호환을 위함입니다. 콜백 도중 예외가 나면 CladTVServiceImpl.onChannelEvent 는 리스너를 null 로 비워(끊긴 원격 참조 정리) 이후 호출에서 죽은 stub 으로 재시도하지 않도록 합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant Cloud as Cloud App participant TV as CladTVServiceImpl participant AM as AppManager participant PF as STB 플랫폼 Cloud->>TV: setChannelEventListener(listener) Cloud->>TV: setServiceContextListener(scListener) PF->>AM: 채널 이벤트 발생 AM->>AM: notifyChannelEvent(chId, chNum, chName, perm) loop 모든 활성 컨텍스트 AM->>TV: onChannelEvent(chId, chNum, chName, perm) TV->>Cloud: listener.onChannelEvent(... perm ...) end PF->>TV: onServiceContextEvent(event, reason) TV->>Cloud: scListener.onServiceContextEvent(event, reason)

흐름. 리스너 등록 후, 채널 이벤트는 AppManager 가 전 컨텍스트에 브로드캐스트해 권한 코드와 함께 통지하고, 서비스 컨텍스트 이벤트는 등록 리스너로 직접 전달됩니다.

클래스 다이어그램

관계. 두 리스너는 TV 서비스에 등록되며, 채널 이벤트는 AppManager 가 모든 TV 서비스로 브로드캐스트해 권한 코드를 통지합니다.

핵심 코드

clad/tv/ChannelEventListener.java — 권한 코드 상수와 콜백
public interface ChannelEventListener {
    public static final int PERM_OK = 0;
    public static final int PERM_USER_SKIPPED = 1;
    public static final int PERM_PARENTAL_RATING_BLOCKED = 2;
    public static final int PERM_CA_BLOCKED = 3;
    public static final int PERM_ADULT_BLOCKED = 4;
    public static final int PERM_WRONG_PIN = 5;
    void onChannelEvent (String chid, int chNum, String chName, int perm);
}
cladimpl/manager/AppManager.java — 채널 이벤트 전 컨텍스트 브로드캐스트
public void notifyChannelEvent(String chId, int chNum, String chName, int perm) {
    CladContextImpl[] contexts = getAvailableContexts();
    for (int i = 0; i < contexts.length; i++) {
        CladTVServiceImpl tvService = (CladTVServiceImpl) contexts[i].getTVService();
        if (tvService != null) {
            tvService.onChannelEvent(chId, chNum, chName, perm);   // 각 앱 리스너로 통지
        }
    }
}
