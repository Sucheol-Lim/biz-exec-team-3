기능 개요

Cloud App 의 UI 와 방송 비디오를 한 화면에 함께 배치하려면 비디오 표시 영역을 자유롭게 조정해야 합니다. CladTVService 는 이를 위해 픽셀 기반과 비율 기반 두 가지 리사이즈 API 를 제공합니다. resizeVideo(int x, int y, int width, int height) 는 절대 픽셀 좌표·크기로, resizeVideoByRatio(float x, float y, float width, float height) 는 화면 대비 비율(float)로 비디오 영역을 지정합니다. 두 메서드 모두 적용 성공 여부를 boolean 으로 반환합니다.

현재 비디오 영역은 getCurrentVideoSize() 로 조회하며, 정수 배열 형태(x, y, width, height)로 반환됩니다. 이는 Cloud 측이 현재 상태를 기준으로 다음 레이아웃을 계산할 수 있게 합니다.

PIP(Picture-In-Picture)는 selectPIPChannel(int x, int y, int width, int height) 로 부가 화면 위치·크기를 지정하며 채널을 PIP 로 띄웁니다. 전체 화면 복귀는 selectLCWFullSize() 가 마지막 시청 채널(LCW)을 전체 크기로 되돌립니다. 이 두 메서드는 최근 커밋 d319626(2019-02-27, "api 추가 — selectPIPChannel(x,y,w,h), selectLCWFullSize()")로 추가되었습니다.

설계 포인트
DFC(Display Format Conversion) 계열 동작을 픽셀과 비율 두 단위로 모두 노출한 점이 특징입니다. 비율 기반은 해상도가 다른 단말에서도 같은 레이아웃 비율을 유지할 수 있어, 클라우드 UI 가 단말 해상도에 독립적으로 비디오 배치를 지정하기 좋습니다.

흐름. 현재 영역을 조회한 뒤 픽셀/비율로 리사이즈하고, PIP 표시와 전체 화면 복귀로 화면 레이아웃을 전환합니다.
