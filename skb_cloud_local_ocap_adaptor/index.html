개요

이 저장소는 TBroad(SKB) OCAP(OpenCable Application Platform) 셋톱박스의 Local App(Monitor App, MA) 환경에서 동작하는 Cloud Adaptor(Clad) 의 인터페이스 정의(IDL)와 그 산출물(Java 스켈레톤/스텁, JS 코덱), 그리고 일부 구현체(impl)를 담고 있습니다. 클라우드 측 애플리케이션(예: 클라우드 기반 UI/EPG)과 셋톱박스의 Local Native(OCAP/Java) 환경이 서로 원격 객체를 주고받을 수 있도록 양쪽의 직렬화 규약과 서비스 인터페이스를 맞춰 주는 어댑터 계층입니다.

통신은 Alticast의 ROP(Remote Object Protocol) 위에서 이뤄집니다. 각 인터페이스는 64bit 태그(예: 0xd855fbc474dc6a53)로, 메서드는 32bit 해시(예: 0xb2815b12)로 식별되며, Skeleton(서버측 디스패처)과 Stub(클라이언트측 프록시)이 이 식별자로 호출을 주고받습니다. 모든 인터페이스·구조체의 단일 원본(single source of truth)은 alticast_cloud_adaptor.idl 한 파일이며, Java *Skel·stub/S* 와 JS cloud_adaptor.js 코덱이 이 IDL로부터 생성됩니다.

대상 기능은 채널 선택/예약/즐겨찾기 등 TV 제어, SI(채널 리스트) 조회, 미디어/VOD(UMP) 재생, 핀·시청등급·BT RCU·브라우저 실행 등 환경 설정, 메인/위젯 윈도우 표시 제어와 앱 간 메인 윈도우 소유권 전환, 그리고 앱 단위 세션 데이터 관리입니다. 런타임은 구형 STB에 맞춘 Java(레거시, 제네릭 미사용) 와, 브라우저/클라우드 측의 JavaScript 두 갈래로 구성됩니다.

저장소의 위치 설정
이 저장소는 독립 실행/빌드되는 애플리케이션이 아니라 상위 플랫폼 빌드에 포함되는 소스 컴포넌트입니다. 저장소 내부에 build.gradle·pom.xml·Makefile·package.json 등 빌드 스크립트가 없으며, 외부 ROP 런타임(com.alticast.rop.*)과 IO 패키지(com.alticast.io.*)에 의존합니다(해당 라이브러리는 본 저장소에 미포함).

주요 기능

서비스 매니저 진입점
CladServiceManager 가 어댑터 버전(getCloudAdaptorVersion() = "1.0") 제공, 앱별 컨텍스트 생성·캐싱(createCladContext(applicationId)), 메인 윈도우 소유자 조회를 담당합니다.
앱 단위 컨텍스트
CladContext 가 TV/SI/Media/Config 하위 서비스를 lazy 생성해 반환하고, 윈도우·세션 데이터·콜백 핸들러 등록을 앱 단위로 관리합니다.
윈도우 표시·소유권 제어
showWindow()/hideWindow() 로 메인/위젯 윈도우를 제어하며, 메인 윈도우 소유권이 다른 앱으로 넘어가면 AppManager 가 기존 소유 앱에 onHidden, 나머지 앱에 onMainWindowShown/Hidden 을 통지합니다.
세션 데이터 관리
앱ID→Map 구조의 세션 저장소를 통해 setSessionData/addSessionData/getSessionData/getSessionDataAll 로 키-값을 보관·조회합니다.
TV 채널 제어
selectChannel*(sourceId/chId), 현재/이전/LCW 채널 조회, 채널 리스트 조회(타입별·캠페인 제외 등), getDefaultChannel/setDefaultChannel, exitToService, reboot 등 TV 동작을 정의합니다.
예약·녹화 및 즐겨찾기
reserve/forceReserve/cancelReserve/isReserved, findDuplicatedReserve, getReservedPrograms 와 즐겨찾기 추가/삭제(addFavorite/removeFavorite, 결과 상수 FAVORIT_*)를 제공합니다.
비디오 리사이즈(DFC) · PIP
resizeVideo/resizeVideoByRatio 로 픽셀·비율 기반 비디오 크기 조정, getCurrentVideoSize, selectPIPChannel, selectLCWFullSize 를 지원합니다.
권한·서비스 컨텍스트 콜백
ChannelEventListener 로 채널 권한(PERM_OK/USER_SKIPPED/PARENTAL_RATING_BLOCKED/CA_BLOCKED/ADULT_BLOCKED/WRONG_PIN)을, ServiceContextListener 로 서비스 컨텍스트 이벤트(Presentation/Alternative/Normal/Terminated 등)를 콜백합니다.
SI 채널 리스트 조회
CladSIService.getChannelList(ringName) 로 SURFABLE/SURFABLE_AV/SURFABLE_AUDIO/FAVORITE/BLOCKED/SKIPPED 등 채널 링을 조회합니다. CladChannelList 구조체로 ccidList·name·부가정보를 반환합니다.
미디어 재생 제어
playStart/pause/resume, 트레일러 재생, 다양한 정지(playStop/playStopWithoutTune/playStopWithChChange/playStopWithReservedCh), stopAndPlay, setMediaConfig 를 정의합니다.
UMP 기반 VOD 재생
UmpMediaPlayerService 가 setDataSourceUmp0~3, demandVODRequestID, VOD 이벤트/상태/결과 상수(VODEVENT_*/UMP_STATUS_*/VODRESULT_*), getUMPStatus/getUMPVersion, ECM 그룹·미디어 비율 등 VOD 세션 전반을 다룹니다.
환경 설정 · 핀 관리
CladConfigService 가 안전/TV/서비스 설정·시스템 정보 조회, 클라우드 핀 모드·시청 등급, 재인증(requestReAuth), managePin, 사용자 설정 get/set과 변경 리스너를 제공합니다.
BT RCU · 외부 앱 실행
BT RCU 페어링/연결 기기 관리(setBTRCUMode/setBTDeviceRegistMode 등), 브라우저·스마트앱·ICS 실행(startBrowser/startSmartApp/startICS), 자가진단 팝업, 등록 해제를 지원합니다.
사업자 전용 확장(TBroad)
OcapCladTVService(OCAP 확장)와 TbroadCladTVService(getChannelHistory() 추가)·TbroadChannelEventListener(ADULT_BLOCKED/WRONG_PIN 추가), OcapCladSIService.getVodTsId(forceScan) 로 사업자 환경을 확장합니다.
JS ↔ Java 코덱 일치
js/cloud_adaptor.js 가 동일 인터페이스/구조체를 Java 측과 같은 64bit 태그·32bit 메서드 해시로 등록해, 브라우저/클라우드 런타임과 STB Java 런타임이 ROP로 정확히 매칭되도록 합니다.

계층 · 외부 연동 관계

인터페이스 계약(clad/*) 은 IDL이 정의한 서비스 계약이며, 같은 위치의 *Skel 은 들어온 ROP 호출을 메서드 해시로 분기해 cladimpl/* 구현체로 위임하는 서버측 디스패처입니다. 반대편(Cloud)에서 이 객체를 원격 호출할 때 쓰는 클라이언트측 프록시는 stub/S<64bit 태그>.java 형태로 인터페이스 태그와 1:1 대응합니다(예: Sd855fbc474dc6a53 = CladServiceManager).

구현체(cladimpl/*) 중 윈도우 소유권·세션 데이터·채널 이벤트 전파 같은 매니징은 AppManager 에 모여 있고, 컨텍스트는 서비스 인스턴스를 lazy 생성합니다. 단, 개별 TV/SI/Media/Config 구현(*ServiceImpl)은 대부분 기본값을 반환하는 골격 상태이며, 실제 플랫폼 연동 코드는 이 저장소 범위 밖으로 추정됩니다. 외부 의존성으로는 com.alticast.rop.*(Skeleton/Stub/Codec/Exportable/RemoteCall) 와 com.alticast.io.Buffer 가 필요하며 본 저장소에는 포함되지 않습니다(import 기준). JS 측 코덱 등록 흐름의 상대편은 사내 클라우드 서비스 서버이며, 그 운영(Docker/Grafana/app.log)은 Confluence "클라우드 시스템 분석" 문서에 정리되어 있습니다.

핵심 동작 흐름

1. 어댑터 초기화 · 앱 컨텍스트 획득

  1. CladServiceManager 생성CladServiceManagerImpl 생성자가 createAppManager() 를 호출해 AppManager 싱글톤을 init("com.alticast.cladimpl.manager.AppManager") 로 초기화합니다.
  2. 버전 확인Cloud App 이 getCloudAdaptorVersion() 을 호출하면 어댑터가 "1.0" 을 반환해 호환성을 확인합니다.
  3. 컨텍스트 생성·캐싱createCladContext(applicationId) 가 AppManager 의 컨텍스트 맵을 조회해 없으면 CladContextImpl 을 새로 만들어 addCladContext 로 캐싱하고 반환합니다.
  4. 서비스 lazy 획득앱이 getTVService()/getSIService()/getMediaPlayerService()/getConfigService() 를 호출하면 컨텍스트가 해당 *ServiceImpl 을 최초 호출 시점에 생성해 재사용합니다.
  5. 콜백 등록setAppHandler()/setWindowMonitor() 로 Cloud→Local 콜백을 등록해 메시지·윈도우 통지를 수신할 준비를 합니다.

2. 메인 윈도우 소유권 전환

  1. 메인 윈도우 표시 요청앱이 CladContextImpl.showWindow(windowId, MAIN_WINDOW) 를 호출하면 컨텍스트가 CladWindow 를 만들고 AppManager.showWindow(windowId, mode, appId) 로 위임합니다.
  2. 기존 소유자 통지AppManager 가 현재 메인 윈도우 소유자가 다른 앱이면 그 컨텍스트에 onHidden() 을 보내 화면 양보를 알립니다.
  3. 소유권 갱신mainWindowOwner 와 mainWindowId 를 새 앱으로 갱신합니다.
  4. 나머지 앱 브로드캐스트notifyMainWindowOwnerChanged() 가 소유자를 제외한 모든 컨텍스트에 onMainWindowShown(appId) 를 통지합니다. hideWindow 시 소유권이 비면 onMainWindowHidden() 을 통지합니다.

3. UMP 기반 VOD 재생

  1. VOD 요청 ID 확보UmpMediaPlayerService.demandVODRequestID(assetId, categoryId) 로 요청 ID를 받고 필요 시 setVodRequestID/setApplicationName/setECMGroup 등을 설정합니다.
  2. 데이터소스 설정setDataSourceUmp0~3 으로 파일명·TS 리스트(또는 nodeGroupId)·offset·requestId(·우선순위 기준)를 지정하면 결과 코드(VODRESULT_*)를 반환합니다.
  3. 재생 시작playStart()(또는 트레일러용 playStartVodTrailer/playStartTrailer) 로 재생을 시작합니다.
  4. 이벤트 수신UmpEventListener.onEvent(vodEvent) 로 광고 시작/종료, 파일 시작/끝, NEED_TUNE, 세션 에러/정상 등 VODEVENT_* 이벤트를 수신합니다. 상태는 getUMPStatus()(INIT/PLAYING/READY)로 확인합니다.
  5. 정지playStop 계열 또는 stopAndPlay 로 재생을 종료하거나 다음 콘텐츠로 전환합니다.

빌드 · 실행

이 저장소는 독립 빌드되는 애플리케이션이 아니라 상위 플랫폼 빌드에 포함되는 소스 컴포넌트입니다. 저장소 내에 빌드 스크립트가 없으므로 사실에 근거한 구성 정보만 안내합니다.

# Java 소스 루트

  com.alticast.clad.*       # IDL 생성 인터페이스 + Skeleton
  com.alticast.cladimpl.*   # Local 구현체 + AppManager
  com.alticast.stub.*       # IDL 생성 Stub (S<태그>.java)

# 컴파일 시 클래스패스에 필요한 외부 의존성(본 저장소 미포함)
com.alticast.rop.*   # Skeleton, Stub, Codec, Exportable, RemoteCall, New
com.alticast.io.*    # Buffer

# JS 측 (acba 모듈 로더 + js:rop 런타임에서 로드)
js/cloud_adaptor.js  # acba.define("js:cloud_adaptor", ["js:rop"], ...)
IDL 변경 시 재생성 필요(추정)
alticast_cloud_adaptor.idl 을 수정하면 Java *Skel·stub/S* 와 js/cloud_adaptor.js 를 IDL 컴파일러로 다시 생성해야 양쪽의 인터페이스 태그·메서드 해시가 일치합니다. IDL 컴파일러 자체는 본 저장소에 포함되어 있지 않습니다.

산출물 형태 는 컴파일된 별도 바이너리가 아니라, 상위 플랫폼/애플리케이션 빌드에 함께 컴파일되는 Java 소스 패키지와 JS 코덱 스크립트입니다. 로깅은 CladLog.INCLUDE = false 로 비활성화되어 있으며, 이는 최근 커밋 "nolog로 수정" 과 일치합니다.
