텍스트 제거 (Text Removal)

포스터 원본 이미지에서 글자 영역을 지우는 기능입니다. 전체(all) 자동 제거와 영역 선택(select) 제거를 지원하며, 작업을 요청해 jobId를 받은 뒤 10초 간격으로 상태를 폴링해 결과 이미지를 미리보기에 반영합니다.

기능 개요

텍스트 제거는 포스터 편집의 첫 단계입니다. 사용자가 우측 패널(RightPanel.vue)에서 제거 방식을 고르면, EditArea.vue의 handleRemove()가 요청 본문을 구성해 POST /projects/{projectId}/text-removals(api.poster.postTextRemoval)로 작업을 생성합니다. 전체 제거(all)는 마스크 없이 { imageUrl }만 보내고, 영역 선택(select)은 캔버스에서 만든 maskImage를 함께 보냅니다.

작업 요청은 즉시 끝나지 않고 비동기로 처리됩니다. 서버는 202 Accepted와 함께 jobId를 반환하고, EditArea는 text-removal-started 이벤트로 이를 부모 PosterEdit.vue에 전달합니다. PosterEdit은 startTextRemovalPolling()으로 10초 간격 폴링을 시작해 getTextRemovalStatus를 호출하고, 응답의 result.imageUrl이 채워지면 미리보기 이미지를 교체하고 상태를 textRemoveSuccess(=text_removed)로 전환합니다.

상태 머신
PosterEdit.vue의 POSTER_STATE는 original → text_removing → text_removed → expanded 순서를 가집니다. 텍스트 제거가 진행 중이면 전역 로딩 오버레이가 뜨고, 완료 시 토스트(posterEdit.completed)로 알립니다. 작업 전에는 postTextRemovalTokenUsage로 예상 차감 토큰(기본 REMOVE 20)을 조회해 하단에 안내합니다.

흐름. 선택 모드면 캔버스 마스크를 먼저 추출하고, 전체 모드면 imageUrl만 전송합니다. 요청은 jobId만 받고 끝나며, 실제 결과는 부모 컨테이너의 10초 폴링이 채웁니다.

관계. EditArea는 요청 발화와 마스크 추출을 맡고, PosterEdit은 상태 머신과 폴링을 오케스트레이션합니다. 두 컴포넌트 모두 $api.poster(poster.js)를 통해 동일한 프록시 엔드포인트를 호출합니다.

핵심 코드

posteredit/components/EditArea.vue — handleRemove(): 전체/선택 분기와 요청 발화
let requestBody = { imageUrl }; // 전체(all)일 때 maskImage 없이 요청

if (textDeleteToolSelect.value !== 'all') {
    // mask 이미지 얻기
    const maskResult = await removeSelected();
    const maskImage = maskResult?.maskImage;

    if (!maskImage || typeof maskImage !== 'string') {
        // 사용자가 영역을 선택하지 않은 경우
        emit('loading', { visible: false });
        showMessagePopup(t('posterEdit.apiError'), true);
        return;
    }
    requestBody = { imageUrl, maskImage };
}

const response = await api.poster.postTextRemoval(props.projectId, requestBody);
const jobId = response?.data?.jobId;

if (response?.status !== 202 || !jobId) {
    emit('loading', { visible: false });
    showMessagePopup(t('posterEdit.apiError'), true);
    return;
}

emit('text-removal-started', { jobId });   // 부모가 폴링 시작
resetRemoveUI();
posteredit/PosterEdit.vue — 10초 폴링으로 결과 이미지 반영
const statusResponse = await api.poster.getTextRemovalStatus(projectId, jobId);
if (statusResponse?.status !== 200) return;

const statusData = statusResponse.data;
const textRemovedPath = statusData?.result?.imageUrl;

if (textRemovedPath) {
    stopPolling();
    handleLoading({ visible: false });
    projectDetail.value.imageUrl = textRemovedPath;
    projectDetail.value.textRemovedImageUrl = textRemovedPath;
    projectDetail.value.status = 'textRemoveSuccess';   // → text_removed 상태
    editAreaKey.value = (editAreaKey.value || 0) + 1;   // EditArea 강제 재렌더
    openToastPopup(t('posterEdit.completed'));
    return;
}
// ...
pollTimer = setInterval(pollOnce, 10_000);
