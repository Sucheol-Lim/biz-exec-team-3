이미지 확장 (Outpainting)

원본 또는 텍스트 제거 이미지를 선택한 배너 규격으로 AI 확장합니다. 각 배너의 가로·세로 해상도와 원본 배치 위치(상/하/좌/우/중앙)를 지정해 한 번에 여러 규격을 일괄 생성하고, jobId를 받아 결과 화면으로 넘어갑니다.

기능 개요

이미지 확장은 편집의 두 번째 단계로, 한 장의 포스터를 여러 배너 규격으로 늘려 만드는 아웃페인팅 작업입니다. 사용자가 RightPanel.vue에서 템플릿(Set-F/S/H 또는 직접 설정)을 고르고, ImageExtensionPopup.vue에서 각 배너의 원본 배치 위치(Left/Right/Middle/Top/Bottom)를 지정해 확정하면 EditArea.handleImageExtensionConfirm()이 호출됩니다.

실제 요청 본문 구성은 apiUtils.js의 requestImageExtension()이 담당합니다. 현재 이미지 URL(currentImageUrlForApi, 텍스트 제거가 있으면 그 결과)과 함께, 선택한 템플릿의 contents를 순회하며 { name, width, height, alignment } 항목 배열과 템플릿 식별용 type을 만들어 POST /projects/{projectId}/image-expansions(postImageExpansion)로 전송합니다. 서버는 jobId를 반환하고, EditArea는 image-extension-result 이벤트로 이를 부모에 넘겨 결과 화면(ResultArea)으로 전환합니다.

입력 이미지 선택
확장의 입력은 currentImageUrlForApi입니다. 텍스트 제거 결과(textRemovedImageUrl)가 있으면 그것을, 없으면 원본(imageUrl 또는 originalImageUrl)을 사용합니다. 즉 텍스트를 먼저 지우고 확장하는 워크플로를 그대로 따릅니다.

핵심 코드

posteredit/assets/js/utils/apiUtils.js — requestImageExtension(): payload 구성
export async function requestImageExtension(api, projectId, currentImageUrl, extensionData) {
    const { template, originPositions } = extensionData

    const requestData = {
        imageUrl: currentImageUrl,
        items: template.contents.map(content => ({
            name: content.typeTitle,
            width: content.resolution.width,
            height: content.resolution.height,
            alignment: originPositions[content.id]    // 배너별 원본 배치 위치
        })),
        type: template.name
    }

    const response = await api.poster.postImageExpansion(projectId, requestData)
    if (response.data) return response.data            // { jobId, ... }
    throw new Error('Image extension request failed')
}
posteredit/components/EditArea.vue — 확정 후 결과 화면으로 전환
async function handleImageExtensionConfirm(extensionData) {
    showImageExtensionPopup.value = false

    const result = await requestImageExtension(
        api, props.projectId, currentImageUrlForApi.value, extensionData
    )
    props.projectDetail.type = extensionData.template.name;

    emit('image-extension-result', { jobId: result.jobId })   // ResultArea로 이동
}
