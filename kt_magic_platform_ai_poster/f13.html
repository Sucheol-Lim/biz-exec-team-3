다국어 지원

편집 모듈은 한국어/영어 로케일(ko.json·en.json)을 갖춘 자체 useI18n composable과 vue-i18n을 병행 사용해 UI 문구를 국제화합니다. 브라우저 언어와 localStorage 선택을 우선순위로 초기 언어를 결정합니다.

기능 개요

포스터 편집 모듈은 자체 i18n 인스턴스를 둡니다. posteredit/i18n.js가 createI18n({ legacy: false, ... })로 Composition API 모드 인스턴스를 만들고 ko.json·en.json 메시지를 등록합니다. 메시지는 common, posterEdit, rightPanel, imageExtension, imageExtensionResult 등 영역별 네임스페이스로 묶여 있고, 예를 들어 common.tokenInfo는 {cost} 보간을 포함한 "작업 완료 시 {cost}토큰이 차감됩니다" 문구입니다.

각 컴포넌트는 composables/useI18n.js를 import해서 쓰는데, 이 composable은 vue-i18n의 useI18n을 그대로 재노출하는 얇은 래퍼입니다. 즉 "자체 composable"이라는 표현은 모듈 전용 진입점을 의미하고, 실제 번역 엔진은 vue-i18n입니다. 초기 언어는 getInitialLocale()이 ① localStorage(posterEditLocale) ② 브라우저 언어 ③ 기본값 ko 순으로 결정하며, setLocale()로 런타임에 바꾸면 localStorage 저장과 <html lang> 갱신까지 함께 수행합니다. 이미지 확장의 원본 위치 라벨(imageExtension.positions.*)도 로케일로 번역됩니다(예: Top → 상단).

번역 키 예시
배너 원본 위치 코드(Top/Bottom/Middle/Left/Right)는 API에는 영문 그대로 보내고, 화면 표시만 getOriginPositionOptions()가 t('imageExtension.positions.' + pos)로 한글(상단/하단/가운데/왼쪽/오른쪽)로 변환합니다. 데이터와 표시를 분리한 구조입니다.

관계. i18n.js가 로케일 JSON으로 vue-i18n 인스턴스를 만들고, 컴포넌트는 useI18n 래퍼로 그 인스턴스의 t()에 접근합니다.

핵심 코드

posteredit/i18n.js — 인스턴스 생성과 초기 언어 결정
const i18n = createI18n({
    legacy: false,                        // Composition API
    locale: getInitialLocale(),           // localStorage → 브라우저 → 'ko'
    fallbackLocale: DEFAULT_LOCALE,
    messages: { ko, en }
})

function getInitialLocale() {
    const savedLocale = localStorage.getItem('posterEditLocale')
    if (savedLocale && SUPPORTED_LOCALES.includes(savedLocale)) return savedLocale
    const browserLocale = getBrowserLocale()
    if (SUPPORTED_LOCALES.includes(browserLocale)) return browserLocale
    return DEFAULT_LOCALE                 // 'ko'
}

export function setLocale(locale) {
    i18n.global.locale.value = locale
    localStorage.setItem('posterEditLocale', locale)
    document.querySelector('html').setAttribute('lang', locale)
}
posteredit/composables/useI18n.js — vue-i18n 재노출 래퍼
import { useI18n as vueUseI18n } from 'vue-i18n'

// posteredit 전용 i18n composable (각 컴포넌트에서 import)
export function useI18n() {
    return vueUseI18n()
}
