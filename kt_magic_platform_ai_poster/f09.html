원본 되돌리기 / 다시 편집

텍스트 제거 결과를 원본으로 되돌리거나(reset), 확장 작업을 초기화하고 다시 편집 단계로 돌아갑니다. 진행 중 확장 작업은 취소하고, 완료/오류 작업은 결과를 비운 뒤 편집 화면으로 복귀합니다.

기능 개요

되돌리기는 두 단계에서 각각 동작합니다. 편집 단계(EditArea.vue)에서는 "원본으로 되돌리기" 버튼이 텍스트 제거 결과가 있을 때만 활성화되고, 누르면 ResetConfirmPopup 확인 후 resetToOriginal()이 PUT /projects/{projectId}/text-removals/reset(putResetProject)을 호출합니다. 성공하면 응답의 원본 imageUrl을 받아 reset-to-original-complete 이벤트로 부모에 알리고, PosterEdit이 textRemovedImageUrl을 비우고 editAreaKey를 증가시켜 EditArea를 재렌더합니다.

결과 단계(ResultArea.vue)의 "다시 편집하기"는 handleBackToEdit()가 처리합니다. 확장 작업이 진행 중(status 0/1)이면 먼저 deleteImageExpansionJob으로 작업을 취소하고, 생성된 결과 이미지가 있으면 deleteImages로 정리합니다. 완료/오류 상태면 putResetExpansion으로 확장을 초기화한 뒤 back-to-edit 이벤트를 emit해 편집 화면으로 돌아갑니다. ReworkConfirmPopup으로 사용자 확인을 거칩니다.

프로젝트 복제(copy) 관련
카드 설명의 "프로젝트 복제(copy)로 새 편집 세션"에 해당하는 postCopyProject 엔드포인트가 poster.js에 정의되어 있으나, 현재 user 앱 코드에서 실제로 호출하는 위치는 확인되지 않았습니다(추정 — 미사용 또는 다른 앱 전용). 실제 "다시 편집" 동작은 putResetExpansion/putResetProject 경로로 구현되어 있습니다.

시퀀스 다이어그램

sequenceDiagram autonumber actor U as 사용자 participant EA as EditArea.vue participant RA as ResultArea.vue participant API as api.poster participant PE as PosterEdit.vue rect rgb(245,245,250) Note over U,PE: 편집 단계 — 원본 되돌리기 U->>EA: "원본으로 되돌리기" (확인 팝업) EA->>API: putResetProject(projectId) API-->>EA: 200, { imageUrl(원본) } EA->>PE: emit reset-to-original-complete({ originalImageUrl }) PE->>PE: textRemovedImageUrl=null · editAreaKey++ end rect rgb(245,250,245) Note over U,PE: 결과 단계 — 다시 편집하기 U->>RA: "다시 편집하기" (확인 팝업) alt 진행 중(status 0/1) RA->>API: deleteImageExpansionJob(projectId, jobId) else 완료/오류 RA->>API: deleteImages + putResetExpansion(projectId) end RA->>PE: emit back-to-edit PE->>PE: showResultArea=false (EditArea로 복귀) end

흐름. 편집 단계는 텍스트 제거를 원복하고, 결과 단계는 작업 상태에 따라 취소 또는 초기화 후 편집 화면으로 복귀합니다.

관계. 두 화면이 각자 reset/취소 API를 호출하고 이벤트로 PosterEdit에 복귀를 알립니다. postCopyProject는 API에 정의되어 있으나 user 앱 호출은 미확인입니다.

핵심 코드

posteredit/components/EditArea.vue — resetToOriginal(): 텍스트 제거 원복
async function resetToOriginal() {
    emit('loading', { visible: true });
    const response = await api.poster.putResetProject(props.projectId);

    if (response?.status === 200) {
        const originalImageUrl = response?.data?.imageUrl;
        if (originalImageUrl) {
            emit('reset-to-original-complete', { originalImageUrl });
            openToastPopup(t('posterEdit.completed'));
        } else {
            showMessagePopup(t('posterEdit.apiError'), true);
        }
    }
    emit('loading', { visible: false });
}
posteredit/components/ResultArea.vue — handleBackToEdit(): 상태별 취소/초기화
const status = props.extensionData?.status
const isInProgress = status === 0 || status === 1 || status === 'prepare' || status === 'processing'

if (isInProgress) {
    await api.poster.deleteImageExpansionJob(props.projectId, extensionId.value)   // 진행 중 → 취소
}

const imageIds = results.value.filter(r => r.id !== 'loading').map(r => r.id)
if (imageIds.length > 0) {
    await api.poster.deleteImages(props.projectId, extensionId.value, { data: { imageIds } })
}

if (!isInProgress) {
    await api.poster.putResetExpansion(props.projectId)        // 완료/오류 → 초기화
}

emit('back-to-edit')
