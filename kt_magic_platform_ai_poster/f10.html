토큰 사용량 사전 조회

텍스트 제거·이미지 확장 각각에 대해 작업 전 예상 토큰 사용량을 조회하는 API를 호출하고, "작업 완료 시 N토큰이 차감됩니다" 안내를 노출합니다.

기능 개요

텍스트 제거(REMOVE)와 이미지 확장(EXPAND)은 작업 완료 시 토큰을 차감하는 과금형 기능입니다. 사용자가 실제로 토큰을 쓰기 전에 예상 차감량을 알 수 있도록, 각 작업 진입 시점에 사전 조회 API를 호출합니다. 텍스트 제거는 EditArea.vue가 마운트 후 fetchTextRemovalTokenUsage()로 postTextRemovalTokenUsage({ imageUrl })를 호출해 response.data.amount를 textRemovalTokenAmount에 저장하고, 하단 토큰 안내(common.tokenInfo = "작업 완료 시 {cost}토큰이 차감됩니다")에 바인딩합니다.

이미지 확장은 ImageExtensionPopup.vue가 fetchImageExpansionTokenUsage()로 postImageExpansionTokenUsage({ imageUrl, items: [{width:100,height:100,alignment:'Middle'}] })를 호출해 배너 1개당 단가(imageExpansionTokenUnitPrice)를 받습니다. 이후 선택한 배너 개수(템플릿 contents 수 또는 커스텀 유효 행 수)를 곱해 총 예상 토큰(imageExpansionTokenAmount)을 computed로 산출해 보여 줍니다.

기본 토큰 단가
PosterEdit.vue의 TOKEN_COST 상수는 REMOVE: 20, EXPAND: 80입니다. 다만 화면에 표시되는 값은 이 상수가 아니라 서버 token-usage 응답의 amount를 따르며, 확장은 단가 × 배너 수로 합산합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant EA as EditArea.vue participant POP as ImageExtensionPopup.vue participant API as api.poster Note over EA: 편집 진입 (onMounted) EA->>API: postTextRemovalTokenUsage({ imageUrl }) API-->>EA: { amount } EA->>EA: textRemovalTokenAmount = amount → 안내 문구 Note over POP: 확장 팝업 진입 (onMounted) POP->>API: postImageExpansionTokenUsage({ imageUrl, items:[1개 샘플] }) API-->>POP: { amount } (배너 1개당 단가) POP->>POP: 총 토큰 = 단가 × 선택 배너 수 (computed)

흐름. 텍스트 제거는 이미지 URL만으로 예상량을 받고, 이미지 확장은 단가를 받아 선택한 배너 수만큼 곱해 총액을 계산합니다.

클래스 다이어그램

classDiagram class EditArea { -textRemovalTokenAmount +fetchTextRemovalTokenUsage() } class ImageExtensionPopup { -imageExpansionTokenUnitPrice +imageExpansionTokenAmount +fetchImageExpansionTokenUsage() } class PosterApi { +postTextRemovalTokenUsage(data) +postImageExpansionTokenUsage(data) } class PosterEdit { +TOKEN_COST } EditArea ..> PosterApi : postTextRemovalTokenUsage ImageExtensionPopup ..> PosterApi : postImageExpansionTokenUsage PosterEdit ..> EditArea : TOKEN_COST prop

관계. 두 진입 컴포넌트가 각자 token-usage 엔드포인트를 호출하고, 확장 팝업은 단가에 배너 수를 곱해 총액 computed를 노출합니다.

핵심 코드

posteredit/components/EditArea.vue — 텍스트 제거 예상 토큰 조회
const textRemovalTokenAmount = ref(null)

async function fetchTextRemovalTokenUsage() {
    const imageUrl = currentImageUrlForApi.value
    if (!imageUrl) return
    const response = await api.poster.postTextRemovalTokenUsage({ imageUrl })
    textRemovalTokenAmount.value = response?.data?.amount ?? null
}
// 화면 안내: t('common.tokenInfo', { cost: textRemovalTokenAmount })
//          → "작업 완료 시 {cost}토큰이 차감됩니다"
posteredit/components/popups/ImageExtensionPopup.vue — 단가 조회 + 총액 계산
async function fetchImageExpansionTokenUsage() {
    if (!props.imageUrl) return
    const response = await api.poster.postImageExpansionTokenUsage({
        imageUrl: props.imageUrl,
        items: [{ width: 100, height: 100, alignment: 'Middle' }],   // 단가 샘플 1건
    })
    imageExpansionTokenUnitPrice.value = response?.data?.amount ?? null
}

const imageExpansionTokenAmount = computed(() => {
    if (imageExpansionTokenUnitPrice.value === null) return null
    const count = isCustomMode.value
        ? customContents.value.filter(validateRow).length
        : (selectedTemplate.value.contents?.length ?? 0)
    return imageExpansionTokenUnitPrice.value * count          // 단가 × 배너 수
})
