배너 템플릿 세트

Set-F(5종)·Set-S(10종)·Set-H(11종) 사전 정의 템플릿과 "직접 설정" 커스텀 옵션을 제공합니다. KT 서비스 화면(HomeTop, miniEPG, 빅배너 등)에 맞춘 해상도 규격이 imageExtensionTemplates.js에 정적으로 정의됩니다.

기능 개요

템플릿 세트는 이미지 확장이 만들어 낼 배너 규격의 카탈로그입니다. imageExtensionTemplates.js가 IMAGE_EXTENSION_TEMPLATES 배열로 4개 항목을 정의합니다. Set-F(id 1, 5종: 가로/세로 조합), Set-S(id 2, 10종: N/W/S/K 시리즈), Set-H(id 3, 11종: KT 서비스 화면 규격), 그리고 직접 설정(id 0, isCustom: true, contents 비어 있음)입니다.

각 템플릿의 contents 항목은 { id, typeTitle, resolution{width,height}, originPositions } 구조이며, originPositions는 공통 상수 DEFAULT_ORIGIN_POSITIONS = ['Left','Right','Middle','Top','Bottom']를 공유합니다. RightPanel.vue의 v-select가 이 배열을 :items로 받아 드롭다운을 그리고, ImageExtensionPopup.vue는 getTemplateById()로 선택된 템플릿을 조회해 배너 목록을 표 형태로 보여 줍니다. "직접 설정"이면 사용자가 width/height를 직접 입력하는 커스텀 행 UI로 전환됩니다.

Set-H = KT 서비스 화면 규격
Set-H에는 HomeTop(1280×364), miniEPG(264×147), 카테고리 배너(710×424), VOD Loading(1280×720), 빅배너(1980×900) 등 실제 KT IPTV/매직 서비스 화면에 들어갈 규격이 그대로 담겨 있습니다. 디자이너가 한 포스터로 여러 노출 면을 동시에 뽑을 수 있게 한 의도입니다.

시퀀스 다이어그램

흐름. 정적 카탈로그가 드롭다운을 채우고, 선택된 id로 getTemplateById가 템플릿 객체를 돌려줍니다. 커스텀 여부에 따라 팝업 UI가 갈립니다.

관계. 모듈이 템플릿 4종을 보유하고, 각 템플릿은 배너별 Content(해상도·원본 위치 옵션)를 가집니다. getTemplateById로 조회합니다.

핵심 코드

posteredit/assets/js/utils/imageExtensionTemplates.js — Set-H(KT 서비스 화면 규격) 일부와 직접 설정
const DEFAULT_ORIGIN_POSITIONS = ['Left','Right','Middle','Top','Bottom'];

export const IMAGE_EXTENSION_TEMPLATES = [
    { id: 1, name: "Set-F", contents: [ /* 가로(1) 1920x1080 ... 세로(3) 360x540 (5종) */ ] },
    { id: 2, name: "Set-S", contents: [ /* N-1 700x1000 ... K-T2 600x240 (10종) */ ] },
    {
        id: 3, name: "Set-H",
        contents: [
            { id: 1, typeTitle: "HomeTop",  resolution: { width: 1280, height: 364 }, originPositions: DEFAULT_ORIGIN_POSITIONS },
            { id: 2, typeTitle: "miniEPG",  resolution: { width: 264,  height: 147 }, originPositions: DEFAULT_ORIGIN_POSITIONS },
            { id: 5, typeTitle: "VOD Loading", resolution: { width: 1280, height: 720 }, originPositions: DEFAULT_ORIGIN_POSITIONS },
            { id: 11, typeTitle: "빅배너",   resolution: { width: 1980, height: 900 }, originPositions: DEFAULT_ORIGIN_POSITIONS }
            /* ... 총 11종 */
        ]
    },
    { id: 0, name: "직접 설정", isCustom: true, contents: [] }
];

export function getTemplateById(templateId) {
    return IMAGE_EXTENSION_TEMPLATES.find(t => t.id === templateId) || null;
}
posteredit/components/panels/RightPanel.vue — 템플릿 드롭다운 바인딩
<v-select
    :items="IMAGE_EXTENSION_TEMPLATES"
    item-title="name"
    item-value="id"
    v-model="selectedTemplate"
    :placeholder="t('rightPanel.selectTemplate')"
/>
