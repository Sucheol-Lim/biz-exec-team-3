미리보기 확대/축소

Konva 캔버스 기반 미리보기에 5%~200% 줌 레벨과 줌 팝업, 화면 맞춤 보정을 제공합니다. Ctrl/Cmd + 휠 스크롤 줌과 초기 이미지 크기 자동 맞춤(fit) 로직을 포함합니다.

기능 개요

미리보기 줌은 캔버스를 감싸는 PreviewZoomWrapper.vue가 담당합니다. 줌 값(previewZoomLevel)은 EditArea.vue가 보유하고, 래퍼는 콘텐츠 wrapper에 CSS zoom 속성을 적용해 0.05~2.0 범위로 캔버스를 확대/축소합니다. 헤더의 줌 버튼을 누르면 ZoomLevelPopup.vue가 열려 5%·25%·50%·75%·100%·150%·200% 프리셋과 "화면 맞춤"을 고를 수 있습니다.

스크롤 줌은 useWheelHandler 컴포저블로 등록한 휠 핸들러가 처리합니다. Mac은 metaKey, Windows는 ctrlKey가 눌린 상태에서만 줌으로 동작하며, deltaY 방향에 따라 0.01씩 증감하고 Math.max(0.05, Math.min(2, ...))로 범위를 제한합니다. 초기 진입과 이미지 로드 시에는 setDefaultZoomLevel()이 콘텐츠 대비 컨테이너 크기 비율(여백 1.2 배율 고려)을 계산해 화면에 꼭 맞는 줌으로 자동 설정합니다. 줌이 바뀌면 콘텐츠를 가로 가운데로 스크롤 보정합니다.

초기 크기 보정
setDefaultZoomLevel()은 ratio = min(containerH / (contentH × 1.2), containerW / (contentW × 1.2))로 화면 맞춤 배율을 구하고 0.05~2.0으로 클램프합니다. ResizeObserver로 콘텐츠 크기 변화를 감지해 wrapper 크기를 다시 측정합니다.

핵심 코드

posteredit/components/PreviewZoomWrapper.vue — Ctrl/Cmd + 휠 스크롤 줌
useWheelHandler('preview-zoom-wrapper', (e) => {
    if (!e.target.closest('.preview-zoom-wrapper')) return false;
    // Mac: metaKey(Cmd), Windows: ctrlKey(Ctrl)
    if (e.metaKey || e.ctrlKey) {
        e.preventDefault();
        const delta = e.deltaY > 0 ? -0.01 : 0.01;
        const newZoomLevel = Math.max(0.05, Math.min(2, props.previewZoomLevel + delta));
        props.setPreviewZoomLevel(newZoomLevel);
        return true;
    }
    return false;
});
posteredit/components/PreviewZoomWrapper.vue — 초기 화면 맞춤 보정
const setDefaultZoomLevel = async () => {
    await nextTick();
    const containerHeight = wrapperContainerRef.value.clientHeight;
    const containerWidth  = wrapperContainerRef.value.clientWidth;
    const contentHeight   = contentContainerRef.value.clientHeight;
    const contentWidth    = contentContainerRef.value.clientWidth;
    if (!contentWidth || !contentHeight) return;

    let ratio = Math.min(
        containerHeight / (contentHeight * 1.2),
        containerWidth  / (contentWidth  * 1.2)
    );
    ratio = Math.max(0.05, Math.min(2, ratio));   // 5%~200% 클램프
    props.setPreviewZoomLevel(ratio);
    await updateContentWrapperSize();
}
