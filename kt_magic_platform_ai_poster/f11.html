기능 개요

PosterView.vue는 지니 포스터 편집툴의 진입 화면입니다. Vue 컴포넌트 안에서 jQuery DataTables를 직접 제어하는 하이브리드 방식으로, loadTableData()가 getPosterList(from, to)로 받은 data.items를 initOrUpdateDataTable(rows)에 넘겨 테이블을 생성·갱신합니다. 날짜 범위는 마운트 시 오늘 기준 1개월 전부터로 초기화되며(initialDate.setMonth(today.getMonth() - 1)), KST 보정 헬퍼(toKSTDayStart/End, formatDateToKSTISO)로 searchCondition.from/to를 만듭니다.

페이지 길이는 DATATABLE_DEFAULTS 기반 pageLength와 커스텀 select(insertCustomSelectToDataTable)로 제어하고, daterangepicker와 moment를 동적 import로 로드합니다. 프로젝트 생성은 onCreateBtnClick이 FormData에 name과 업로드 file을 담아 postCreatePoster(formData)로 보내고, 성공 시 응답의 id로 곧바로 편집 페이지(goToEditPage)를 새 창으로 엽니다. 포스터명 클릭(.poster-name-link)도 같은 goToEditPage로 이어집니다.

편집 화면은 새 창
goToEditPage(projectId)는 window.open(url + '?projectId=...', 'edit_{id}')로 편집 팝업을 열고, child.name에 핸드오프 데이터를 JSON으로 실어 보냅니다. 팝업 차단 시 알림을 띄웁니다. 편집 컨테이너(PosterEdit.vue)는 이 projectId 쿼리로 프로젝트 상세를 불러옵니다.

관계. PosterView가 API로 목록·생성을 처리하고 DataTables 인스턴스를 직접 다루며, 편집은 새 창의 PosterEdit으로 위임합니다.

핵심 코드

user/src/views/user/poster/PosterView.vue — 기본 1개월 범위 + 목록 조회
const today = new Date()
const initialDate = new Date(today)
initialDate.setMonth(today.getMonth() - 1) // ✅ 항상 1개월
const dateRange = ref([toKSTDayStart(initialDate), toKSTDayEnd(today)])

const searchCondition = reactive({
    from: formatDateToKSTISO(toKSTDayStart(initialDate)),
    to:   formatDateToKSTISO(toKSTDayEnd(today)),
})

async function loadTableData() {
    const { data } = await api.poster.getPosterList(searchCondition.from, searchCondition.to)
    const result = data?.items || []
    initOrUpdateDataTable(result)        // jQuery DataTables 생성/갱신
    return result
}
user/src/views/user/poster/PosterView.vue — 생성(FormData) 후 편집 새 창
const onCreateBtnClick = async (value) => {
    const formData = new FormData()
    formData.append('name', value?.name ?? '')
    formData.append('file', value?.file)
    const response = await api.poster.postCreatePoster(formData)

    const projectId = response?.data?.id
    if (projectId) goToEditPage(projectId)   // window.open(...?projectId=...)
    await loadTableData()
}
