영역 그리기 도구

선택 모드에서 사각형(rect)·브러쉬(brush)·지우개(eraser) 도구로 제거할 영역의 마스크를 그립니다. PreviewPanel.vue의 Konva 캔버스 위에서 동작하며, 브러쉬·지우개 크기는 슬라이더(기본 24, 범위 10~200)로 조절합니다.

기능 개요

영역 그리기는 부분 텍스트 제거에 쓸 마스크를 사용자가 직접 그리는 도구 모음입니다. EditArea.vue가 도구 상태(textDeleteToolSelect=none/all/select, activeDrawTool=rect/brush/eraser, selectedToolGroup=rect/brush)와 크기 값(brushSize, eraserSize 기본 24)을 관리하고, 이를 props로 PreviewPanel.vue에 내려 줍니다. PreviewPanel은 props.textDeleteToolSelect와 props.activeDrawTool 변화를 watch로 감지해 Konva Stage 이벤트를 다시 바인딩합니다(bindStageEventsByState).

사각형 도구는 rectMouseDown/Move/Up으로 드래그 영역을 그리고, 브러쉬·지우개는 startDraw/drawMove/endDraw로 선을 칠합니다. 지우개는 화면용 캔버스에서 globalCompositeOperation = 'destination-out'으로 지우면서, 전송용 API 마스크 캔버스에는 검정(#000)으로 덮어 "제거 안 함"으로 되돌립니다. 도구를 전환하면 isDrawing 상태와 이벤트가 초기화되어 잔여 입력이 다른 도구로 새지 않습니다.

두 개의 캔버스
PreviewPanel은 화면 표시용 maskCanvas(반투명 핑크 #f62556, opacity 0.4)와 서버 전송용 apiMaskCanvas(제거 영역 흰색 #fff, 배경 검정)를 분리해 동시에 갱신합니다. 사용자에게 보이는 색과 실제 마스크 의미(흰=제거)가 다르기 때문입니다.

시퀀스 다이어그램

sequenceDiagram autonumber actor U as 사용자 participant EA as EditArea.vue participant PP as PreviewPanel.vue participant ST as Konva Stage participant MC as maskCanvas (화면) participant AC as apiMaskCanvas (전송) U->>EA: 브러쉬/지우개/사각형 선택 EA->>PP: props activeDrawTool / brushSize 변경 PP->>ST: bindStageEventsByState() 재바인딩 U->>ST: mousedown (그리기 시작) ST->>PP: startDraw(e) PP->>MC: 핑크 stroke 시작 (source-over) PP->>AC: 흰색 stroke 시작 (제거=흰) loop 드래그 중 ST->>PP: drawMove(e) → clampPointToImage() PP->>MC: lineTo + stroke PP->>AC: lineTo + stroke end ST->>PP: mouseup → endDraw() Note over PP: 지우개는 destination-out(화면) / #000(전송)

흐름. 도구 선택은 props로 내려오고, 실제 그리기는 Konva Stage의 포인터 이벤트가 화면용·전송용 두 캔버스에 동시 반영합니다. 좌표는 clampPointToImage로 이미지 영역 안쪽에 가둡니다.

관계. EditArea가 도구·크기 상태를 props로 내려 주면, PreviewPanel이 그 값에 맞춰 Konva Stage 이벤트를 바인딩하고 두 캔버스에 그립니다.

핵심 코드

posteredit/components/panels/PreviewPanel.vue — drawMove(): 화면용·전송용 동시 stroke
const clamped = clampPointToImage(pos);
const size = props.activeDrawTool === "eraser" ? props.eraserSize : props.brushSize;

// UI용(화면): 핑크, 지우개는 destination-out
maskCtx.lineWidth = size;
maskCtx.strokeStyle = "#f62556";
maskCtx.globalCompositeOperation =
    props.activeDrawTool === "eraser" ? "destination-out" : "source-over";
maskCtx.lineTo(clamped.x, clamped.y);
maskCtx.stroke();

// maskImage 전송용: 제거=흰(#fff), 지우개는 검정(#000)으로 되돌림
apiMaskCtx.lineWidth = size;
apiMaskCtx.globalCompositeOperation = "source-over";
apiMaskCtx.strokeStyle = props.activeDrawTool === "eraser" ? "#000" : "#fff";
apiMaskCtx.lineTo(clamped.x, clamped.y);
apiMaskCtx.stroke();

maskImage?.getLayer()?.batchDraw();
posteredit/components/panels/PreviewPanel.vue — bindStageEventsByState(): 도구별 이벤트 바인딩
if (props.activeDrawTool === 'rect') {
    stage.container().style.cursor = 'crosshair';
    stage.on("mousedown", rectMouseDown);
    stage.on("touchstart", rectMouseDown);
    return;
}

if (props.activeDrawTool === 'brush' || props.activeDrawTool === 'eraser') {
    stage.container().style.cursor = 'none';      // 커스텀 브러쉬 커서 사용
    stage.on("mousedown touchstart", startDraw);
    stage.on("mousemove touchmove", drawMove);
    stage.on("mouseup touchend", endDraw);
}
