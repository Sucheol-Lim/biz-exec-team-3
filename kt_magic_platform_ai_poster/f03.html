마스크 기반 부분 제거

선택 영역은 캔버스에서 흑백 마스크 이미지(maskImage, base64 PNG)로 생성되어 요청 본문에 포함됩니다. 전체 제거 시에는 마스크 없이 imageUrl만 전송하며, 선택 제거 시 흰색 픽셀이 하나도 없으면 요청을 막습니다.

기능 개요

마스크는 "어디를 지울지"를 서버에 알리는 흑백 PNG입니다. PreviewPanel.vue는 화면 표시용 캔버스와 별개로 전송용 apiMaskCanvas를 유지하는데, 이 캔버스는 처음에 전체를 검정(#000=유지)으로 채우고, 사각형·브러쉬가 칠한 영역만 흰색(#fff=제거)으로 표시합니다. 사용자가 "제거" 버튼을 누르면 removeSelected()가 모드(all/select)에 따라 마스크를 마무리하고 base64 문자열로 추출합니다.

전체 모드(all)에서는 이미지 영역 전체를 흰색으로 칠한 마스크를 만들 수 있지만, 실제 EditArea.handleRemove()는 전체 모드일 때 removeSelected()를 호출하지 않고 { imageUrl }만 전송합니다. 선택 모드(select)에서는 hasAnyWhitePixel()로 흰색 픽셀이 실제 존재하는지 검사하고, 없으면 null을 반환해 빈 요청을 차단합니다. 추출된 마스크는 getApiMaskBase64String()이 toDataURL("image/png")에서 헤더(data:image/png;base64,)를 제거한 순수 base64로 만들어 { imageUrl, maskImage } 형태로 보냅니다.

마스크 색 규약
전송용 마스크에서 흰색(#fff) = 제거 대상, 검정(#000) = 유지입니다. 화면에는 핑크 반투명으로 보여 주지만(maskCanvas), 서버로 가는 값은 이 흑백 규약을 따르는 별도 캔버스(apiMaskCanvas)에서 추출합니다.

관계. removeSelected()가 apiMaskCanvas를 마무리하고 { maskImage }를 반환하면, EditArea.handleRemove()가 이를 요청 본문에 합쳐 전송합니다.

핵심 코드

posteredit/components/panels/PreviewPanel.vue — removeSelected(): 모드별 마스크 마무리
async function removeSelected() {
    if (!apiMaskCanvas || !apiMaskCtx) return null;
    const image = imageLayer.findOne('Image');
    if (!image) return null;

    if (selectionMode.value === 'all') {
        apiMaskCtx.fillStyle = '#000';                              // 배경 유지
        apiMaskCtx.fillRect(0, 0, apiMaskCanvas.width, apiMaskCanvas.height);
        const box = image.getClientRect({ relativeTo: stage });
        apiMaskCtx.fillStyle = '#fff';                             // 이미지 전체 = 제거
        apiMaskCtx.fillRect(box.x, box.y, box.width, box.height);
    } else if (selectionMode.value === 'select') {
        const hasArea = hasAnyWhitePixel(apiMaskCtx, apiMaskCanvas.width, apiMaskCanvas.height);
        if (!hasArea) return null;                                 // 선택 영역 없음 → 차단
    } else {
        return null;
    }

    const maskBase64String = getApiMaskBase64String();
    clearMask(); selectedRects.value = []; clearOverlay();
    return { maskImage: maskBase64String };
}
posteredit/components/panels/PreviewPanel.vue — base64 추출과 흰 픽셀 검사
function getApiMaskBase64String() {
    if (!apiMaskCanvas) return null;
    const dataUrl = apiMaskCanvas.toDataURL("image/png");
    return dataUrl.replace(/^data:image\/png;base64,/, "");   // 순수 base64만
}

function hasAnyWhitePixel(ctx, w, h) {
    const img = ctx.getImageData(0, 0, w, h).data;
    for (let i = 0; i < img.length; i += 4) {
        if (img[i] > 200 && img[i + 1] > 200 && img[i + 2] > 200) return true;
    }
    return false;
}
