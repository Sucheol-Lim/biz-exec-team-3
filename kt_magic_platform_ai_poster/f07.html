결과 조회·다운로드

기능 개요

ResultArea.vue는 확장 작업이 끝난 배너들을 그리드 카드(ResultCard.vue)로 보여 줍니다. 서버 응답의 items는 배너(규격)마다 여러 이미지를 담은 2단 구조라, results computed가 이를 flatMap으로 펼쳐 카드 한 장당 이미지 하나로 평탄화하고 각 이미지에 배너의 width/height를 붙입니다. 좌측 정보 패널에는 템플릿명·요청 시각·진행률·전체 상태가 표시됩니다.

다운로드는 선택한 이미지 ID 배열을 postDownloadImages(projectId, jobId, { imageIds, format })로 보내고, 응답을 responseType: 'blob'으로 받습니다. handleConfirmDownload가 이 응답을 new Blob([...], { type: 'application/zip' })로 감싼 뒤 URL.createObjectURL + 임시 앵커 클릭으로 ZIP 파일을 내려받고 즉시 revokeObjectURL로 정리합니다. 삭제는 deleteImages(projectId, jobId, { data: { imageIds } })로 처리하고, 성공 시 rawItems에서 해당 이미지를 제거해 화면을 갱신합니다.

선택 모드
체크박스로 하나 이상 선택하면(selectedCount > 0) 다운로드·삭제 버튼이 나타나고 "전체 선택" 토글이 활성화됩니다. 선택 ID는 selectedImageIds computed가 모아 다운로드/삭제 요청 본문에 그대로 사용합니다.

시퀀스 다이어그램

sequenceDiagram autonumber actor U as 사용자 participant RA as ResultArea.vue participant RC as ResultCard.vue participant API as api.poster participant DOM as Browser (Blob/anchor) RA->>RC: results(평탄화된 카드) 렌더 U->>RC: 카드 선택 (체크박스) RC->>RA: toggle-selection(resultId) U->>RA: "다운로드" → handleConfirmDownload(format) RA->>API: postDownloadImages(projectId, jobId, {imageIds, format}) (blob) API-->>RA: ZIP blob RA->>DOM: createObjectURL + anchor.click() → revokeObjectURL Note over U: 선택 항목 ZIP 저장 U->>RA: "삭제" → handleConfirmDelete RA->>API: deleteImages(projectId, jobId, {imageIds}) RA->>RA: rawItems에서 제거 → 그리드 갱신

흐름. 평탄화된 카드에서 선택한 ID를 모아 ZIP blob으로 다운로드하거나 삭제 API로 정리합니다. 다운로드는 임시 앵커로 처리하고 즉시 URL을 해제합니다.

관계. ResultArea가 카드 목록과 선택 상태를 관리하고, 다운로드 형식은 DownloadPopup이 결정하며, 실제 ZIP/삭제는 $api.poster로 처리합니다.

핵심 코드

posteredit/components/ResultArea.vue — ZIP blob 다운로드
async function handleConfirmDownload(format) {
    showDownloadPopup.value = false
    if (!format || selectedImageIds.value.length === 0) return

    const response = await api.poster.postDownloadImages(
        props.projectId, extensionId.value,
        { imageIds: selectedImageIds.value, format: format.toLowerCase() }
    )

    const blob = new Blob([response.data], { type: 'application/zip' })
    const url = URL.createObjectURL(blob)
    const anchor = document.createElement('a')
    anchor.href = url
    anchor.download = `${props.projectDetail?.name || props.projectId}.zip`
    anchor.click()
    URL.revokeObjectURL(url)
}
posteredit/components/ResultArea.vue — 2단 items → 카드 평탄화
const results = computed(() => {
    if (!rawItems.value || rawItems.value.length === 0) return []
    return rawItems.value.flatMap(item => {
        if (item.id === 'loading') return [item]              // 로딩 카드 유지
        return (item.images || []).map(img => ({
            ...img, width: item.width, height: item.height     // 배너 규격 부착
        }))
    })
})
