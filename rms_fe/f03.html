배치 리포트

batchReport가 Log/Report/Failure 탭으로 배치 집계 결과를 나누어 보여주고, batchReportDetail로 상세를 조회합니다. 각 행의 파일은 /api/v1/files/download로 내려받고, 테이블 데이터는 react-csv(CSVLink)로 내보냅니다.

기능 개요

배치 리포트 화면(batchReport.tsx)은 MUI Tabs로 LOG·DEVICE(report)·FAIL(failure) 세 탭을 제공합니다. LOG 탭은 tabs/Log.tsx(LogReport), 나머지 두 탭은 tabs/Etc.tsx(EtcReport)가 렌더링합니다. 데이터는 ParameterApiManager를 통해 조회하는데, LOG 탭은 getFileMetaLast(/api/v1/file-metas), Report/Failure 탭은 getReportHistory(/api/v1/report-historys)를 호출합니다.

각 리포트 행에는 결과 파일이 첨부되어 있어, 운영자가 다운로드를 누르면 downloadFile()이 REACT_APP_RMS_BE_SERVER_URL + /api/v1/files/download?objectName=... URL을 fetch로 받아 Blob으로 저장합니다. Report/Failure 탭(Etc.tsx)에서는 파일명 텍스트 링크 대신 다운로드 아이콘 버튼(customFileComponet + DownloadIcon)으로 내려받으며, 테이블의 리포트 주기 컬럼 라벨도 items.report_cycle로 정리되었습니다. 컬럼 정의는 reportColumns/failureColumns로 분리되어, Failure 탭(tabState === 'FAIL')에서는 실패 유형(thresholdType, 라벨 items.failure_type) 컬럼이 추가로 표시됩니다. 데이터가 없을 때의 빈 목록 문구도 탭별로 분기되어 Report 탭은 empty.no_report_data, Failure 탭은 empty.no_failure_data, LOG 탭은 empty.log 메시지를 보여줍니다. 화면에 표시된 테이블 자체는 공용 ReactTable의 react-csv CSVLink로 CSV 내보내기가 가능합니다. 상세 보기는 batchReportDetail이 getBatchReport(/api/v1/batch-reports)로 단건 데이터를 받아 표시하고, 뒤로가기 시 navigate('/monitoring/batch')로 목록으로 복귀합니다. 최근 변경분에서 배치 리포트 로직 자체는 그대로이고, 라우팅에서 빠져 있던 구버전 화면 batchReport_old.tsx와 그 테이블 타입 정의(types/dashboardDetail/table_old.tsx)가 dead code로 정리·삭제되었습니다.

조회와 다운로드의 분리
목록 조회는 콜백 스타일 request 헬퍼(axios)로, 파일 다운로드는 sessionStorage의 accessToken을 Authorization 헤더로 붙인 직접 fetch + Blob 방식으로 처리됩니다. 둘의 책임이 분리되어 있어 대용량 리포트 파일도 테이블 렌더와 무관하게 받아집니다.

시퀀스 다이어그램

BE-->>LOG: 파일 Blob → 저장 OP->>LOG: CSV 내보내기 LOG->>LOG: CSVLink (react-csv)

흐름. 탭에 따라 file-metas 또는 report-historys를 조회하고, 행 단위 파일은 files/download를 fetch해 Blob으로 저장합니다. 테이블 데이터는 react-csv CSVLink로 내보냅니다.

관계. BatchReport가 탭에 따라 LogReport/EtcReport를 소유하고, 각각 ParameterApiManager의 서로 다른 엔드포인트를 호출합니다. 상세는 BatchReportDetail이 getBatchReport로 처리합니다.

핵심 코드

pages/monitoring/batchReport.tsx — 탭에 따라 LogReport/EtcReport 분기
{tabState === 'LOG' && <LogReport tabState={tabState}></LogReport>}
{tabState !== 'LOG' && <EtcReport tabState={tabState}></EtcReport>}
pages/monitoring/tabs/Log.tsx — 리포트 파일 다운로드 URL 구성 후 fetch
const donwloadUrl =
  `${process.env.REACT_APP_RMS_BE_SERVER_URL}/api/v1/files/download?objectName=${row.filePath}`;
// downloadFile(): fetch(url) → Blob → a.download = fileName 으로 저장
ParameterApiManager.getFileMetaLast((result, data) => { /* 목록 렌더 */ });
pages/monitoring/tabs/Etc.tsx — Report/Failure 행 다운로드 아이콘 버튼 (Authorization 헤더 fetch)
const customFileComponet = (row: any) => {
  if (row.fileName) {
    const donwloadUrl = `${process.env.REACT_APP_RMS_BE_SERVER_URL}/api/v1/files/download?objectName=${row.filePath}`;
    return (
      <IconButton onClick={(evt) => { evt.stopPropagation(); downloadFile(donwloadUrl, row.fileName); }}>
        <DownloadIcon />
      </IconButton>
    );
  }
  // downloadFile(): fetch(url, { headers: { Authorization: sessionStorage.getItem('accessToken') } }) → Blob 저장
};
pages/monitoring/tabs/Etc.tsx — Failure 탭 전용 컬럼 분기 (fail type 컬럼 추가)
<CustomTable
  dataSource={tabState === 'FAIL' ? failureColumns : reportColumns}
  rows={rows}
  setRows={setRows}
  selectedRows={selectedRows}
  ...
/>
// failureColumns: no / reportTime / reportPeriodType / thresholdType(items.failure_type) / count / filePath
// reportColumns:  no / reportTime / reportPeriodType / count / filePath
