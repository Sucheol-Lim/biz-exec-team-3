기능 개요

RMS FrontEnd는 하나의 코드베이스를 KT·OBE·TTG·GLOBAL 등 여러 사이트에 공통 배포하는 멀티 타깃 구조입니다. 그 중심이 src/utils/env.ts입니다. 이 모듈은 빌드 시 주입된 REACT_APP_TARGET(기본값 GLOBAL)을 읽어 IS_KT·IS_NOT_KT 같은 불리언과, 화면 노출/동작을 결정하는 여러 분기 객체를 export 합니다. 사이트별 환경값은 .env.kt·.env.obe·.env.ttg 등 사이트별 .env 파일과 build.js 인자로 주입됩니다.

주요 분기는 네 가지입니다. modulePermissions는 터미널(OBE/TTG)·고급 메시지(비-KT)·런처 리셋(TTG)·챗봇(CHATBOT=Y)·WiFi 메뉴(TTG) 노출을 제어합니다. widgetPermissions는 대시보드의 위치 지도·브랜드 모델·네트워크 인터페이스 위젯을 OBE/TTG에서 숨기고 KT는 편집 모드를 막습니다(disableEditMode). stpPolicyPeriodMin은 정책 주기 기본값을 KT 10분/그 외 5분으로 둡니다. ID_FIELD는 KT면 deviceSiteId, 그 외면 deviceId로 단말 식별자 필드를 바꿉니다. 라우팅에서도 MainRoutes.tsx가 IS_KT로 메일 리포트를 알림 설정으로 분기합니다.

한 코드, 여러 사이트
각 화면이 if/else를 흩뿌리지 않고 env.ts의 분기 값을 import 해 참조하므로, 타깃별 차이가 한곳에 모입니다. 신규 사이트 대응이나 권한 변경이 env.ts 한 파일과 .env.* 조정으로 수렴합니다.

관계. env.ts가 modulePermissions·widgetPermissions를 보유하고, App·MainRoutes·DashboardRms 등 소비자가 이를 import 해 사이트별로 분기합니다.

핵심 코드

src/utils/env.ts — 타깃 기반 모듈/위젯 권한·식별자 분기
export const TARGET = process.env.REACT_APP_TARGET || 'GLOBAL';
export const IS_KT = TARGET === 'KT';

export const modulePermissions = {
  terminal: TARGET === 'OBE' || TARGET === 'TTG',
  advancedMesage: TARGET !== 'KT',
  launcherReset: TARGET === 'TTG',
  chatbot: REACT_APP_CHATBOT === 'Y',
  enbaleWifi: TARGET === 'TTG'
};
export const widgetPermissions = {
  deviceLocationMap: TARGET !== 'OBE' && TARGET !== 'TTG',
  deviceBrandModel:  TARGET !== 'OBE' && TARGET !== 'TTG',
  networkInterface:  TARGET !== 'OBE' && TARGET !== 'TTG',
  disableEditMode:   TARGET === 'KT'
};
export const stpPolicyPeriodMin = TARGET === 'KT' ? 10 : 5;
export const useRegionalId = TARGET === 'KT';
export const ID_FIELD = useRegionalId ? 'deviceSiteId' : 'deviceId';
