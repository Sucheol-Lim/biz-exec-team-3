기능 개요

RMS FrontEnd는 하나의 코드베이스를 KT·OBE·TTG·XLSmart·IBC·GLOBAL 등 여러 사이트에 공통 배포하는 멀티 타깃 구조입니다. 그 중심이 src/utils/env.ts입니다. 이 모듈은 빌드 시 주입된 REACT_APP_TARGET(기본값 GLOBAL)을 읽어 IS_KT·IS_NOT_KT 같은 불리언과, 화면 노출/동작을 결정하는 여러 분기 객체를 export 합니다. 사이트별 환경값은 .env.kt·.env.obe·.env.ttg·.env.xl·.env.xl_prod·.env.eu·.env.local 등 사이트별 .env 파일과 build.js/buildProd.js 인자로 주입됩니다(buildProd.js --target=<name>이 .env.<name>을 로드). XLSmart 운영 빌드는 도메인 이관에 맞춰 .env.rmsai_one이 .env.xl_prod로 이름이 바뀌었고, 바라보는 호스트도 rmsai.one에서 xlsmart.rmsai.one으로 옮겨졌습니다 — infra/helm/xlsmart/rms-ui-app/buildspec.yml의 빌드 커맨드가 yarn buildProd --target=xl_prod로, values-prod.yaml의 ingress host가 xlsmart.rmsai.one으로 함께 갱신되었습니다(REACT_APP_TARGET=XLSmart는 유지). 이후 IBC 개발용이던 .env.ai는 삭제되었고, 개발자 로컬용 .env.local의 기본 타깃도 IBC에서 XLSmart로 바뀌어(BE는 rms-cloud-xl) 로컬 기동이 XLSmart 기준이 되었습니다. XLSmart 빌드 두 벌(.env.xl·.env.xl_prod)의 REACT_APP_VERSION은 2.3.9로 올라가 있습니다.

주요 분기는 다섯 가지입니다. modulePermissions는 터미널(OBE/TTG/XLSmart/IBC)·고급 메시지(비-KT)·런처 리셋(TTG)·챗봇(IBC 전용 — 종전 REACT_APP_CHATBOT 환경변수 분기는 제거)·WiFi 메뉴(TTG)·펌웨어 설치 명령(installFw, TTG 제외)·Microsoft SSO 로그인(ssoLogin, XLSmart 전용)에 더해, IBC 타깃 전용 이상 감지(anomalyDetect) 노출을 제어합니다 — quickOperationMain.tsx가 이 값으로 Quick Operation 화면 대신 AnomalyDetect 컴포넌트(pages/monitoring/anomalyDetect로 승격)를 렌더합니다. widgetPermissions는 대시보드의 위치 지도·브랜드 모델·네트워크 인터페이스 위젯을 OBE/TTG/XLSmart/IBC에서 숨기고 KT는 편집 모드를 막습니다(disableEditMode). illegalDevices 위젯 노출, KPIWidgetCount 5(그 외 4), widgetCols 20(그 외 16)은 XLSmart 전용으로 축소되었습니다(IBC 제외). 지도 위젯의 경도 시작값 mapBoundsLngStart()는 OBE/TTG/IBC에서 -180, 그 외 0을 반환하고, 앱 정책 탭 노출은 신설된 appPolicyTabs(managedApp/defaultApp)가 제어합니다. adminPermissions는 관리자 화면을 분기해 KT는 승인 대기 탭(pendingApprovalTab)과 LDAP 항목(usingLDAPItems)을 쓰고, 비-KT는 관리자 등록(regist)·비밀번호 초기화(resetPassword)를 노출합니다. stpPolicyPeriodMin은 정책 주기 기본값을 KT 10분/그 외 5분으로 둡니다. 단말 식별자 분기는 값 하나짜리 ID_FIELD(KT면 deviceSiteId, 그 외 deviceId)에서 id와 표시명 name을 함께 갖는 DEV_MAIN_KEY로 확장되었습니다. KT는 deviceSiteId/SAID, XLSmart는 serial/S/N, 그 외는 deviceId이며 타입은 macAddress까지 허용합니다. 표시명은 i18n.t()로 뽑기 때문에 utils/env.ts가 i18next를 직접 import 합니다. 이 값은 단말·앱·OTA·VoC·모니터링의 컬럼 정의와 검색 옵션(management.columns.ts·voc.columns.ts·ota.columns.ts 등)에서 컬럼 id/label로 그대로 쓰이며, 일괄 명령 이력(getCommandHistoryColumns)의 Target 컬럼도 대표 식별자가 serial/macAddress인 사이트에서는 그 필드의 배열(serials/macAddresses)을 보여주도록 이번 범위에서 분기가 보강되었습니다. Master 정책 액션 체크박스에는 새 policyActionPermissions가 추가되어(TTG는 restartApp·closeBackgroundApps 제외) types/devicePolicy.ts의 actions 배열 자체를 사이트별로 필터링합니다. 디바이스 상세 모달(detailWrapper.tsx)은 DEV_MAIN_KEY.id에 따라 제목에 표시할 값을 고릅니다. 기존 ID_FIELD는 devices.tsx·lockDevices.tsx의 잠금 처리에만 남아 있습니다. 한편 MainRoutes.tsx의 IS_KT 기반 메일 리포트/알림 설정 분기는 제거되어 mailreport 라우트가 AlertSetting으로 고정되었고, App.tsx는 REACT_APP_ENV_NAME이 local일 때 문서 타이틀에 현재 REACT_APP_TARGET을 표시해 어떤 타깃으로 떠 있는지 바로 보이게 합니다. XL Smart 대응으로 추가된 설문 설정 라우트는 surveySetting → SurveySetting, surveySetting/register → SurveyCreate, surveySetting/:id → SurveyDetail로 확장되었고, 임시로 SurveySetting을 렌더하던 operationHistory 경로는 정식 OperationHistory 컴포넌트로 복원되었습니다. quickOperation 라우트는 QuickOperationMain이 받아 anomalyDetect 여부로 분기하며, 컴포넌트의 :detectId 파라미터 소비는 제거되었습니다.

여기에 화면 단위가 아닌 세부 동작을 가르는 플래그가 더해졌습니다. menuPermissions.excludedMenuCodes는 IBC에서 WORKFLOW 메뉴 코드를 걸러내며, JWTContext가 로그인 직후 getMenu 응답의 elements를 이 목록으로 필터한 뒤 첫 페이지 경로와 내비게이션 목록을 만듭니다. useIsoTimestamp(XLSmart·IBC)는 utils/dateFormat.ts의 formatToIsoDateTime()이 toISOString()을 쓸지 YYYYMMDDHHmmss 문자열을 쓸지 결정해 서버로 보내는 시각 포맷을 사이트별로 맞춥니다. quickOperationInprogress(OBE)는 Quick Operation 목록에서 디바이스 상세 모달을 열 때 issueId를 함께 실을지 정해, 명령을 보내면 그 이슈가 진행 중으로 올라가게 합니다. hasSerialNumber(XLSmart)도 함께 정의되어 있습니다(현재는 정의만 있고 참조하는 화면은 없습니다).

로그인 화면도 타깃으로 갈립니다. modulePermissions.ssoLogin이 켜진 XLSmart에서만 AuthLogin.tsx가 'Continue with Microsoft' 버튼을 그리고, 누르면 ${REACT_APP_RMS_BE_SERVER_URL}/oauth2/authorization/entra로 이동합니다. 인증을 마치고 ?code=를 달고 돌아오면 pages/auth/login.tsx가 UserApiManager.ssoLogin(cb, code)(POST /api/v1/auth/sso/exchange)로 토큰을 교환해 useAuth().login()을 호출하고, 교환이 진행되는 동안에는 AuthWrapper에 hideCard를 넘겨 로그인 카드가 깜빡이지 않게 합니다. 미등록 계정이면 not_registered_popup 모달로 관리자 등록을 안내합니다.

고정 플래그로 표현하기 어려운 지엽적 분기는 술어 함수 isTarget(only, except)가 맡습니다. 이 함수는 원래 hooks/useTarget.ts 훅이 감싸고 있었지만, 훅일 필요가 없는 순수 함수라 utils/env.ts로 승격되고 훅 파일은 삭제되었습니다. 덕분에 컴포넌트 밖(컬럼 정의·권한 목록 같은 모듈 스코프)에서도 같은 판정을 쓸 수 있습니다. 사용은 두 갈래입니다. 값이 필요한 곳은 isTarget('TTG')처럼 직접 호출하고(rolePermission.tsx의 LAUNCHER_RESET 권한 추가, screenShareModal.tsx의 TTG 전용 리모컨, managementDevices.tsx의 OBE·TTG 전용 영역), JSX를 통째로 숨길 때는 선언적 래퍼 components/TargetGuard.tsx를 씁니다(<TargetGuard only="KT">, <TargetGuard except="KT">). TargetGuard도 이제 훅 대신 utils/env의 isTarget을 직접 import 합니다.

한 코드, 여러 사이트
각 화면이 if/else를 흩뿌리지 않고 env.ts의 분기 값을 import 해 참조하므로, 타깃별 차이가 한곳에 모입니다. 신규 사이트 대응이나 권한 변경이 env.ts 한 파일과 .env.* 조정으로 수렴합니다.

관계. env.ts가 modulePermissions·widgetPermissions·adminPermissions와 술어 isTarget()을 보유하고, App·DashboardRms·AdministratorList·QuickOperationMain 등 소비자가 이를 import 해 사이트별로 분기합니다. JSX 단위 분기는 TargetGuard가 isTarget으로 판정해 자식을 그리거나 null을 반환합니다. MainRoutes.tsx의 IS_KT 라우트 분기는 제거되었습니다.

핵심 코드

src/utils/env.ts — 타깃 기반 모듈/위젯/관리자 권한·식별자 분기
import i18n from 'i18next';

export const TARGET = process.env.REACT_APP_TARGET || 'GLOBAL';
export const IS_KT = TARGET === 'KT';

export const isTarget = (only?: string | string[], except?: string | string[]) => {
  const onlyList = only ? (Array.isArray(only) ? only : [only]) : [];
  const exceptList = except ? (Array.isArray(except) ? except : [except]) : [];
  if (exceptList.length > 0 && exceptList.includes(TARGET)) return false;
  if (onlyList.length > 0 && !onlyList.includes(TARGET)) return false;
  return true;
};

export const modulePermissions = {
  installFw: TARGET !== 'TTG',
  terminal: ['OBE', 'TTG', 'XLSmart', 'IBC'].includes(TARGET),
  advancedMesage: TARGET !== 'KT',
  launcherReset: TARGET === 'TTG',
  chatbot: TARGET === 'IBC',
  enbaleWifi: TARGET === 'TTG',
  anomalyDetect: TARGET === 'IBC',
  ssoLogin: TARGET === 'XLSmart'
};
export const widgetPermissions = {
  deviceLocationMap: !['OBE', 'TTG', 'XLSmart', 'IBC'].includes(TARGET),
  deviceBrandModel: !['OBE', 'TTG', 'XLSmart', 'IBC'].includes(TARGET),
  networkInterface: !['OBE', 'TTG', 'XLSmart', 'IBC'].includes(TARGET),
  networkInterfaceSwitch: !['OBE', 'TTG', 'XLSmart', 'IBC'].includes(TARGET),
  disableEditMode: TARGET === 'KT',
  illegalDevices: TARGET === 'XLSmart',
  KPIWidgetCount: TARGET === 'XLSmart' ? 5 : 4,
  widgetCols: TARGET === 'XLSmart' ? 20 : 16
};
export const stpPolicyPeriodMin = TARGET === 'KT' ? 10 : 5;
export const ID_FIELD = IS_KT ? 'deviceSiteId' : 'deviceId';
export const mapBoundsLngStart = () => {
  if (TARGET === 'OBE' || TARGET === 'TTG' || TARGET === 'IBC') {
    return -180;
  } else {
    return 0;
  }
};
export const appPolicyTabs = {
  managedApp: false,
  defaultApp: true // TARGET === 'TTG',
};
export const menuPermissions = {
  excludedMenuCodes: TARGET === 'IBC' ? ['WORKFLOW'] : []
};
export const adminPermissions = {
  pendingApprovalTab: TARGET === 'KT',
  regist: TARGET !== 'KT',
  usingLDAPItems: TARGET === 'KT',
  resetPassword: TARGET !== 'KT'
};
export const useIsoTimestamp = TARGET === 'XLSmart' || TARGET === 'IBC';
export const quickOperationInprogress = TARGET === 'OBE';
export const hasSerialNumber = TARGET === 'XLSmart';

// Master 정책 액션(sendLog/restartApp/closeBackgroundApps/clearCache) 노출 — TTG는 restartApp·closeBackgroundApps 제외
export const policyActionPermissions = {
  sendLog: true,
  restartApp: TARGET !== 'TTG',
  closeBackgroundApps: TARGET !== 'TTG',
  clearCache: true
};

// id/식별자 표시명을 함께 갖는 확장형 — 종전 ID_FIELD를 대체
type MainKeyId = 'deviceSiteId' | 'serial' | 'deviceId' | 'macAddress';
export const DEV_MAIN_KEY: { id: MainKeyId; name: string } =
  TARGET === 'KT'
    ? { id: 'deviceSiteId', name: i18n.t('mcDs:detail.column.SAID') }
    : TARGET === 'XLSmart'
    ? { id: 'serial', name: 'S/N' }
    : { id: 'deviceId', name: i18n.t('mcDs:detail.column.deviceId') };
components/TargetGuard.tsx — JSX 단위 선언적 분기 (useTarget 훅 제거 후 env 직접 참조)
import { isTarget } from 'utils/env';

export const TargetGuard = ({ only, except, children }: Props) => {
  // 조건에 맞지 않으면 null 반환
  if (!isTarget(only, except)) return null;

  return <>{children}</>;
};

// 사용 예 — pages/management/deviceEdit.tsx
<TargetGuard only={'KT'}>{/* 지역 ID 등 KT 전용 입력 */}</TargetGuard>
<TargetGuard only={'TTG'}>{/* MAC Address 입력 */}</TargetGuard>
