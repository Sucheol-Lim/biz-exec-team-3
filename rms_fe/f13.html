국제화(i18n)

locales/i18n.ts가 i18next + react-i18next를 초기화해 en·fr·tr·du 로케일을 14개 네임스페이스로 묶고, 저장된 언어(localStorage)를 기본값으로 적용해 글로벌 사이트 다국어를 지원합니다.

기능 개요

국제화는 src/locales/i18n.ts 한 파일이 중심입니다. 이 파일은 네 로케일(en·tr·fr·du)의 JSON 번역 묶음을 도메인별 네임스페이스로 import 합니다. 네임스페이스는 cm(common)·mcDs(monitoring dashboard)·mcEtc·st(statistics)·dc(devices)·go(groupOperation)·ms(masterSetting)·au(auth)·hp(help)·md(modal)·am(appManagement)·ota·cd(connectingDevice)·as(advanceSearch) 등 14개입니다.

resources 객체를 구성한 뒤 ns는 resources.en의 키에서 languageTitle을 제외해 자동 산출하고, 기본 언어 savedLang은 localStorage.getItem('language')이 있으면 그 값, 없으면 en입니다. i18n.use(initReactI18next).init()으로 fallbackLng: 'en', defaultNS: 'cm', interpolation.escapeValue: true를 설정합니다. 컴포넌트는 useTranslation()의 t('ns:key') 형태로 번역을 가져오며(예: t('nav.menu9'), t('mcEtc:tab.log')), 언어를 바꾸면 localStorage에 저장된 값이 다음 진입 시 기본값으로 반영됩니다.

번역 리소스는 새 화면·위젯이 추가될 때마다 네 로케일에 같은 키 구조로 병행 확장됩니다. 최근에는 단말 그룹 상세의 IP/MAC 범위 검색 라벨(groupOperation.json의 group_edit — min_ip·max_mac 등), 메시지 발송 위치 옵션(devices.json의 msg_typs.msg_position·position_types1~3 — Middle/Top/Bottom), Network Offline Alert 도입에 따른 문구(masterSetting.json의 alert_setting.tab.network_offline, common.json의 monitoring_window·offlineDeviceRatio), XLSmart 대시보드 신규 위젯 명칭(monitoringCenter_dashboard.json의 Illegal Devices·Top Installed Apps·Top Deleted Apps·HDMI Connection Status), Report/Failure 도움말과 Import Completed·설치 중지(install_stop) 팝업 문구(help.json·modal.json) 등이 en·fr·tr·du 전 로케일에 함께 추가·갱신되었습니다. 이어서 KT 로그인 사용자 등록 팝업 문구(auth.json의 user_registration·reg_popup — Username/E-mail/Team·Division/취소·확인 안내), 단말 잠금 사유(groupOperation.json의 lock — lock_desc와 Illegal/Unactive/Suspended/IP Range/Model/ETC), 설문 설정 관련 문구(common.json의 nav.menu7_5 'Survey Setting'과 survey_title·target_group·questions·response_rate 항목, masterSetting.json의 survey 섹션·create_survey, help.json의 SURVEY_SETTING 가이드)도 네 로케일에 병행 추가되었습니다. 가장 최근에는 잠금 단말 관리 문구(groupOperation.json의 list.locked_devices, common.json의 lock_reason·last_access_date, modal.json의 delete_locked_device_modal·import_lock_device_list_modal, help.json의 Locked Devices 탭 가이드), KT 관리자 승인 대기 문구(masterSetting.json의 administratorList.tab과 admin_reject·admin_approve, help.json의 ADMINISTRATOR_KT 가이드), KT LDAP 로그인 라벨(auth.json의 kt_id·LDAP_pw), XLSmart Auto Launch 정책(masterSetting.json의 auto_launch_on_boot·card_title.auto_launch)과 HDCP Level·RMS First Access Time 표시(monitoringCenter_dashboard.json의 hdcpLevel, connectingDevice.json의 firstAccessTime), 설문 운영 문구(masterSetting.json survey의 survey_status·response_rate·stop_survey 등), 데이터 없음 안내(monitoringCenter_etc.json의 empty.log·empty.no_report_data, monitoringCenter_dashboard.json의 emptyList)가 네 로케일에 함께 반영되었습니다. 이때 Administration 메뉴 재편으로 nav.menu7_4는 'Operation History'가 되었습니다. 이후에는 앱 정책 Exception 탭 도입에 따른 예외 로그 수집 문구(appManagement.json의 app_exception — Exception/Exception Count/Edit Exception 팝업, masterSetting.json의 app_policy_label.exception·empty.exception_list, help.json의 App Policy Exception 가이드와 탭 번호 재정렬), STB 정책의 Reboot Automation·Retry Policy 항목(masterSetting.json의 label.reboot_automation·retry_policy·from/to/recheck_interval과 stb_policy_tooltip 설명, help.json의 STB 정책 검색 조건에 Auto Launch on Boot·Reboot Automation 추가), 설치 재개 라벨 변경(common.json items의 restart → resume 'Resume'), 블루투스 단말 삭제 확인 문구(connectingDevice.json의 bluetooth.confirm), 기간 입력 검증 문구(modal.json의 enter_valide_peroid)가 en·fr·tr·du 네 로케일에 병행 반영되었습니다.

가장 최근 갱신은 AI Quick Operation(이상탐지)·접속 이력·데이터 마스킹 세 축입니다. 첫째, monitoringCenter_dashboard.json의 quickOperation.ai 블록이 fr·tr·du에도 통째로 이식되어(각 로케일 +67줄) 이슈 목록·상위 재발 이슈·명령 발송/중지 모달·대상 단말 선택 문구가 네 로케일에서 모두 번역됩니다. 같은 블록에서 info는 단일 문자열이 아니라 all·cpu·memory·network·crash 하위 키를 갖는 객체로 바뀌었고, anomalyDetect/index.tsx가 t(`mcDs:quickOperation.ai.info.${tabValue}`)처럼 현재 탭 값을 키로 이어 붙여 조회합니다. 화면 명칭 변경에 따라 go_to_quick도 'Go to AI Quick Operation'으로 바뀌었습니다.

둘째, 관리자 접속 이력(Access History) 탭 신설로 common.json의 items에 account_type·event·detail이, masterSetting.json에 administratorList.tab.history가, modal.json에 download_excel.access_history가 추가되고 help.json의 ADMINISTRATOR 가이드가 '1. Administrator List / 2. Access History' 2단 구성으로 다시 쓰였습니다. 셋째, 마스킹 도입으로 items.data_masking이 프로필 메뉴 라벨로 추가되었습니다. 그 밖에 단말 편집의 그룹 선택 요약(masterSetting.json의 label.device_groups_selected와 0건 전용 _zero 키), 타 계정이 점유 중인 단말 안내(modal.json의 device_in_use_modal), 메시지 모달의 비디오 권장 해상도 안내(devices.json의 msg_typs.video_resolution_recommend·video_resolution_desc)가 네 로케일에 함께 반영되었습니다.

그 뒤 갱신은 Microsoft SSO 로그인·자동 복구(Self-Recovered)·엑셀 다운로드 단복수 세 갈래입니다. 첫째, XLSmart의 Microsoft 계정 로그인 도입으로 auth.json에 login_card_title('RMS')·account_email·continue_with_microsoft와 미등록 계정 안내 not_registered_popup(title·desc)이 네 로케일에 추가되었습니다. desc는 줄바꿈 태그를 문자열 안에 품고 있어 AuthLogin.tsx가 t() 대신 <Trans i18nKey="au:not_registered_popup.desc" />로 렌더합니다. 같은 파일에서 영어 forgot_popup.title·otp_popup.title 문구도 'Forget password'로 정리되었습니다.

둘째, AI Quick Operation의 자동 복구 표시가 들어오면서 monitoringCenter_dashboard.json의 quickOperation.ai에 i18next 복수형 접미사 키 self_recovered_label_one/_other와 self_recovered_desc_one/_other가 {{count}} 보간과 함께 추가되고, 이슈 목록 초기화 확인(reset_issue_list_confirm)·복구 완료 토스트(recovery_completed) 문구가 네 로케일에 병행 반영되었습니다. 같은 파일의 tooltip.appCrashLabel은 'Devices with App Crashes'로 다듬어지고 illegalDevicesLabel·new·usageTime·lastBootReason이 더해졌습니다.

셋째, 엑셀 다운로드 안내가 선택 건수에 따라 갈라지도록 modal.json의 download_excel 배열이 [안내 문구, 단수, 복수] 3원소로 확장되고 confirm_downloads가 추가되었으며, download_all_modal에도 단수 문구가 붙었습니다. 그 밖에 단말 상세의 VOC 히스토리 탭 문구(connectingDevice.json의 reload와 voc — title·connected_time·total_time·agent·issue·result·no_data), 공통 라벨 정리(common.json의 nav.menu1_2 'Report' → 'Reports', items.date_registered 'Date Registered', items.file_size에서 (KB) 제거, addedDate·submit 추가), 그룹 편집의 added_device와 설문 입력 검증(masterSetting.json의 question_required·date_required), 목록 전체 선택(devices.json의 select_all), Locked Devices 도움말의 컬럼 안내를 S/N에서 MAC으로 정정한 help.json 수정이 함께 반영되었습니다.

가장 최근 범위(~868b6160)에서는 이번 보고서가 다루는 기능 변경에 맞춰 네 로케일에 문구가 함께 추가·수정되었습니다. auth.json에는 새 operation_history_filter 블록(Menu/Device Command/Group Command/Create/Modify/Remove/Role Change/Password Change)이 Operation History 화면의 History Type select 라벨로 추가되었고, common.json의 control_rms 라벨은 'Control RMS'에서 'Disable RMS'로(XLSmart 7.2 Role setting 명령어 표기 변경) 다듬어졌습니다. connectingDevice.json의 command_type 블록에는 Command Transaction 검색 필터가 실제로 쓰는 코드(TURN_ON_RMS_APP/TURN_OFF_RMS_APP·HIDDEN_WIFI/SHOW_WIFI·DELETE_BLUETOOTH·TERMINAL_COMMAND·PACKET_CAPTURE·SURVEY·FIRM_OTA_UPDATE_STOP/PAUSE/RESUME)에 맞춰 라벨이 채워지고, 앱 업데이트 완료/실패 토스트 문구(msg28·msg29)가 붙었습니다. monitoringCenter_dashboard.json에는 PieChart 툴팁이 쓰는 installedDevices·deletedCount 라벨과, Crash App Devices 위젯의 warningDate를 대신할 crashDate 라벨이 추가되었습니다. 이 문구들은 en·fr·tr·du 네 로케일에 병행 반영되었습니다.

네임스페이스 자동 산출
네임스페이스 목록을 따로 하드코딩하지 않고 Object.keys(resources.en).filter(k => k !== 'languageTitle')로 산출합니다. 따라서 새 도메인 JSON을 resources에 추가하면 네임스페이스가 자동으로 등록되어 누락이 줄어듭니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant APP as App 부트스트랩 participant I18N as locales/i18n.ts participant LS as localStorage participant CMP as 화면 컴포넌트 APP->>I18N: import (모듈 로드) I18N->>I18N: resources 구성 (en/tr/fr/du × 14 ns) I18N->>LS: getItem('language') LS-->>I18N: savedLang (없으면 'en') I18N->>I18N: i18n.init({ lng: savedLang, fallbackLng: 'en', defaultNS: 'cm' }) CMP->>I18N: useTranslation() → t('ns:key') I18N-->>CMP: 로케일 문자열 Note over CMP: 동적 키 조합·count 보간·배열 인덱스 조회 CMP->>LS: 언어 변경 시 setItem('language', lng)

흐름. 모듈 로드 시 네 로케일·14개 네임스페이스로 resources를 구성하고, 저장된 언어를 기본값으로 init합니다. 컴포넌트는 t('ns:key')로 번역을 받고, 언어 변경은 localStorage에 저장됩니다.

클래스 다이어그램

classDiagram class i18nModule { +resources +ns +savedLang +init(options) } class LocaleBundle { +cm +mcDs +ms +ota +cd +as } class useTranslation { +t(key) +i18n } class localStorage { +getItem(language) +setItem(language) } i18nModule o-- LocaleBundle : en/tr/fr/du i18nModule --> localStorage : savedLang useTranslation ..> i18nModule : 번역 조회

관계. i18nModule이 로케일별 번들(LocaleBundle)을 묶고 localStorage로 기본 언어를 결정하며, 화면은 useTranslation의 t()로 번역을 소비합니다.

핵심 코드

src/locales/i18n.ts — 네임스페이스 자동 산출과 초기화
const ns = Object.keys(resources.en).filter((key) => key !== 'languageTitle');
const savedLang = localStorage.getItem('language') || 'en';

i18n.use(initReactI18next).init({
  resources,
  lng: savedLang,
  fallbackLng: 'en',
  ns,
  defaultNS: 'cm',
  interpolation: { escapeValue: true }
});
src/locales/i18n.ts — 로케일별 도메인 번들 등록 (en 예시)
const resources = {
  en: {
    languageTitle: 'English',
    cm: cm_en, mcDs: mcDs_en, mcEtc: mcEtc_en, st: st_en, dc: dc_en,
    go: go_en, ms: ms_en, au: au_en, hp: hp_en, md: md_en,
    am: am_en, ota: ota_en, cd: cd_en, as: as_en
  },
  tr: { languageTitle: 'Türkçe', /* ...동일 14 ns... */ },
  fr: { languageTitle: 'Français', /* ... */ },
  du: { languageTitle: 'Nederlands', /* ... */ }
};
