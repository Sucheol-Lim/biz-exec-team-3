관리자 · 역할(Role) 관리

administratorList는 Admin List·Pending Approval(KT 전용) 탭으로 관리자 계정과 등록 신청 승인을, rolelist는 역할(Role) 기반 권한을 UserApiManager로 관리합니다. mailreport 경로는 사이트 공통으로 AlertSetting(단말 상태·OTT 버전(KT 전용)·네트워크 오프라인 탭)을 렌더합니다.

기능 개요

관리자 영역은 RMS 운영자 계정과 권한 체계를 다룹니다. administratorList는 Admin List·Pending Approval 두 탭을 가진 컨테이너로 재편되어, Admin List 탭(administer/adminList.tsx)이 UserApiManager.getList()(/api/v1/users)로 관리자 목록(역할명·Role Level 포함)을 조회하고, 등록/상세/수정은 create·getDetail·update로 처리합니다. 비밀번호 초기화(resetUserPassword)와 사용자명/이메일 중복 검사(checkUserName/checkEmail)도 같은 매니저에 있습니다. KT 사용자 등록 신청 흐름은 로그인 화면의 User Registration 팝업(UserRegistrationModal)이 registLdap(/api/v1/auth/ldap/register/verify, KT User ID + LDAP Password 검증)과 submitLdap(/api/v1/auth/ldap/register/submit)으로 신청을 제출하면, 관리자가 Pending Approval 탭(administer/pendingApprovalList.tsx, adminPermissions.pendingApprovalTab — KT 타깃 전용)에서 getRegistrationList(/api/v1/registration-users)로 신청 목록을 확인하고, 신청 행을 눌러 진입한 상세 화면(administer/adminDetail.tsx)에서 approveUser(roleId 지정 승인)/rejectUser(거절)로 처리합니다.

역할(Role)은 rolelist가 getRoleList(/api/v1/roles)·createRole·updateRole로 관리하며, 목록·상세에 Role Level(Level1~Level3)이 뱃지 형태로 표시되고 권한 편집 UI는 공용 컴포넌트(administer/components/permissionShared.tsx)로 정리되었습니다. 여기서 정의한 역할이 PermissionContext+PermissionGuard를 통해 화면 접근 권한으로 적용됩니다. 운영 이력 화면(operationHistory.tsx)은 라우트에 다시 연결되어 operationHistory 경로가 DevicesApiManager.getOperationHistory 기반의 운영 이력 화면을 렌더하고, 설문 설정은 surveySetting(목록)·surveySetting/register(SurveyCreate)에 상세/수정 경로 surveySetting/:id(SurveyDetail)가 추가되었습니다. 설문 상세 화면(administer/surveyDetail.tsx)은 대상 그룹명·설문 문항·응답 옵션 텍스트가 표시 영역을 넘으면 여러 줄로 줄바꿈(flexWrap·wordBreak, 고정 높이 대신 minHeight)해 보여주고, 응답 비율/건수 표기는 nowrap으로 한 줄을 유지하도록 다듬어졌습니다. 알림 설정은 라우트 정의(MainRoutes.tsx)에서 mailreport 경로가 사이트 구분 없이 <AlertSetting />을 렌더하고, 탭 단에서 OTT 버전(OTT_VER) 탭만 IS_KT일 때 노출됩니다.

네트워크 오프라인 알림 — 전용 API 연동 (XLsmart Network Offline api 반영)
AlertSetting은 단말 상태(DeviceAlert)·OTT 버전(OttVersion, KT 전용)·네트워크 오프라인(NetworkOffline) 세 탭으로 구성됩니다. 네트워크 오프라인 알림은 MailApiManager의 전용 엔드포인트 /api/v1/network-offline-alert/policy(목록/생성/상세/수정/삭제)와 템플릿 API(/api/v1/network-offline-alert/template)로 연동되었으며, 편집은 networkoffline/:id 경로의 NetworkOfflineEdit 화면이 담당합니다.

흐름. 관리자 화면이 Admin List·Pending Approval 탭으로 재편되어 계정 조회와 KT 등록 신청 승인/거절을 한 화면에서 처리하고, rolelist에서 정의한 Role이 PermissionGuard를 통해 접근 통제에 반영됩니다. 메일 리포트 메뉴는 사이트 공통으로 알림 설정 화면을 렌더하고, OTT 버전 탭만 KT 전용으로 노출됩니다.

관계. 관리자 화면(AdministratorList)이 Admin List·Pending Approval 탭 컨테이너로 재편되어 하위 목록 컴포넌트와 상세(AdminDetail)가 UserApiManager를 공유하고, KT 사용자 등록 팝업(UserRegistrationModal)도 같은 매니저로 신청을 제출합니다. MainRoutes의 mailreport 경로는 항상 AlertSetting을 렌더하며(OTT 버전 탭은 IS_KT 전용), 네트워크 오프라인 탭은 MailApiManager의 network-offline-alert API를 사용하고 편집은 networkoffline/:id의 NetworkOfflineEdit가 담당합니다. operationHistory 경로는 운영 이력 화면으로 복구되었고, surveySetting 경로는 목록·등록(SurveyCreate)·상세(SurveyDetail)를 렌더합니다.

핵심 코드

_api/User.tsx — 관리자와 역할(Role) 엔드포인트
getList: (callback, data) => { request('get', '/api/v1/users', callback, data); },
create: (callback, data) => { request('post', '/api/v1/users', callback, data); },
// Roles
getRoleList: (callback, page, size, name?) => {
  const data = { page, size, ...(name != null && name !== '' ? { name } : {}) };
  request('get', `/api/v1/roles`, callback, data);
},
createRole: (callback, data) => { request('post', '/api/v1/roles', callback, data); },
// KT 사용자 등록 신청 (registration-users)
getRegistrationList: (callback, data) => { request('get', '/api/v1/registration-users', callback, data); },
approveUser: (callback, id, roleId) => { request('post', `/api/v1/registration-users/${id}/approve`, callback, { roleId }); },
rejectUser: (callback, id) => { request('post', `/api/v1/registration-users/${id}/reject`, callback); },
// LDAP — KT User ID / LDAP Password 검증 후 신청 제출
registLdap: async (callback, userId, password) =>
  request('post', '/api/v1/auth/ldap/register/verify', callback, { ktUserId: userId, ldapPassword: password }),
submitLdap: async (callback) => request('post', '/api/v1/auth/ldap/register/submit', callback)
pages/administrator/administratorList.tsx — Admin List / Pending Approval 탭 컨테이너
