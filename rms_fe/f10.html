기능 개요

실시간 원격 제어는 두 채널을 함께 씁니다. 첫째는 화면 공유(Screen Share)로, 디바이스 상세 모달에서 운영자가 화면 공유를 누르면 DevicesApiManager.specialCommands(..., 'SCREEN_SHARE')가 호출되어 서버로부터 channelId를 받습니다. 이 채널 ID로 screenShareModal이 REACT_APP_SIGNAL_BE_WS WebSocket에 접속하고, RTCPeerConnection(TURN 서버 turn:<domain>:3478)을 만들어 시그널링(join/offer/answer/ice-candidate)을 거쳐 단말의 화면 스트림을 WebRTC로 수신합니다. 수신한 MediaStream은 비디오 엘리먼트에 바인딩되며 캡처/리코딩도 지원합니다.

둘째는 상태 구독(SSE)으로, useSSEController가 /api/v1/notifications/subscribe에 EventSourcePolyfill로 연결해 NOTIFICATION 이벤트를 받습니다. 디바이스 상세 모달은 이 SSE 메시지로 단말 연결/상태 변화를 실시간 반영하고, 보조적으로 폴링도 사용합니다(개발 이력에서 디바이스 모달 폴링 주기를 5초에서 10초로 조정). 연결되지 않은 단말은 모달이 dim 처리되어 원격 명령이 막히고, 필요 시 createDeviceConnection으로 connection을 먼저 맺습니다. 원격 명령 페이로드 타입(_api/Devices.tsx의 CommandType)에는 단말 잠금(LOCK) 명령용 사유 필드 lockReason이 추가되어, 디바이스 모달에서 잠금 시 선택한 사유(Unactive·Suspended·IP Range·Model·ETC, XLSmart는 Illegal 포함)가 명령과 함께 전송됩니다.

connection 선행 + dim 처리
Screen Share·Terminal 등 실시간 기능은 단말이 connection 된 상태(currSectionStatus CONNECTED)에서만 동작합니다. 디바이스 모달은 isConnected와 편집 권한(isPermission.isEdit)을 보고 dim 여부를 결정하며, dim 상태에서 화면 공유를 누르면 토스트로 막습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant OP as 운영자 (Browser) participant DD as deviceDetail.tsx participant DM as DevicesApiManager participant SS as screenShareModal.tsx participant WS as Signal 서버 (WebSocket) participant STB as 단말 (RMS Client) OP->>DD: 화면 공유 클릭 DD->>DM: specialCommands(id, 'SCREEN_SHARE') DM-->>DD: channelId DD->>SS: 모달 열기 (channelId) SS->>WS: new WebSocket(SIGNAL_BE_WS) SS->>WS: send {type: join, channelId} WS->>STB: device-joined 통지 WS-->>SS: device-joined SS->>WS: send {type: connect-request} STB-->>SS: offer (via WS) SS->>WS: answer SS->>WS: ice-candidate 교환 Note over SS,STB: RTCPeerConnection 연결 (TURN) STB-->>SS: ontrack → MediaStream SS->>SS: 비디오 렌더 / 녹화

흐름. 화면 공유 명령으로 채널을 받고, WebSocket 시그널링(join → offer/answer → ICE)을 거쳐 WebRTC ontrack으로 단말 화면 스트림을 수신·표시합니다. 단말 상태 변화는 별도 SSE(useSSEController)로 갱신됩니다.

관계. DeviceDetail이 화면 공유 모달과 SSE 구독을 소유하고, ScreenShareModal은 WebSocket+RTCPeerConnection으로 WebRTC 스트림을 처리합니다. 명령/연결은 DevicesApiManager를 거칩니다.

핵심 코드

deviceDetailModal/screenShare/screenShareModal.tsx — WebSocket + WebRTC(TURN) 초기화·시그널 분기
socketRef.current = new WebSocket(wss_url);  // REACT_APP_SIGNAL_BE_WS
webRTC.current = new RTCPeerConnection({
  iceServers: [{ username: 'rms', credential: '****', urls: [`turn:${domain}:3478`] }]
});
socketRef.current.onmessage = async function (msg) {
  let message = JSON.parse(msg.data);
  switch (message.type) {
    case 'device-joined': await sendToServer({ type: 'connect-request', channelId }); break;
    case 'offer':         await handleOfferMessage(message.payload); break;
    case 'ice-candidate': handleNewICECandidateMessage(message.payload); break;
    case 'answer':        handleAnswerMessage(message); break;
  }
};
webRTC.current.ontrack = (ev) => { remoteVideoRef.current.srcObject = ev.streams[0]; };
components/deviceDetailModal/deviceDetail.tsx — SSE 구독 + 화면 공유 채널 획득
const { connect, disconnect, message } = useSSEController({
  url: `${process.env.REACT_APP_RMS_BE_SERVER_URL}/api/v1/notifications/subscribe`,
  eventType: 'NOTIFICATION',
  headers: { authorization: sessionStorage.getItem('accessToken') ?? '' }
});

const handleScreenShareOpen = () => {
  if (isDimmed) { toast(`check currSectionStatus = ${currSectionStatus}`, { variant: 'error' }); return; }
  DevicesApiManager.specialCommands((result, data, code, message) => {
    if (message === 'OK' && data?.channelId) { setChannelValue(data.channelId); setScreenShareOpen(true); }
  }, id, 'SCREEN_SHARE');
};
