실시간 원격 제어 · 화면 공유

screenShareModal이 WebSocket 시그널 서버와 RTCPeerConnection(TURN, 도메인 이중화)으로 단말 화면을 WebRTC 스트리밍하고, useSSEController가 단말 상태 이벤트를 SSE로 구독해 디바이스 상세 모달(pages/device/detailWrapper.tsx)을 실시간 갱신합니다. 모달의 제어 가능 여부는 TaskContext가 들고 있는 연결 정보와 마지막 접속자 비교로 판정합니다.

기능 개요

실시간 원격 제어의 진입점은 작업 표시줄(components/TaskBar.tsx)이 띄우는 디바이스 상세 모달 pages/device/detailWrapper.tsx이고, 그 안의 명령 패널(pages/device/commands.tsx)이 원격 명령을 발행합니다. 첫째 채널은 화면 공유(Screen Share)로, 운영자가 화면 공유를 누르면(단말이 잠금 상태면 먼저 잠금 안내 모달) DevicesApiManager.specialCommands(..., 'SCREEN_SHARE')가 호출되어 서버로부터 channelId를 받습니다. 이 채널 ID로 screenShareModal이 REACT_APP_SIGNAL_BE_WS WebSocket에 접속하고, RTCPeerConnection을 만들어 시그널링(join/offer/answer/ice-candidate)을 거쳐 단말의 화면 스트림을 WebRTC로 수신합니다. TURN 서버는 REACT_APP_WEBSOCKET_DOMAIN 외에 보조 도메인 REACT_APP_WEBSOCKET_DOMAIN2가 설정된 사이트(XLSmart prod)에서는 두 개를 iceServers에 함께 등록해 이중화되며, 리모컨 UI는 isTarget('TTG') 여부로 RemoconTTG/Remocon이 갈립니다. 수신한 MediaStream은 비디오 엘리먼트에 바인딩되며 캡처/리코딩도 지원합니다.

둘째는 상태 구독(SSE)으로, useSSEController가 /api/v1/notifications/subscribe에 EventSourcePolyfill로 연결해 NOTIFICATION 이벤트를 받습니다. 디바이스 상세 모달은 이 SSE 메시지로 단말 연결/상태 변화를 실시간 반영하고, 보조적으로 1분 주기 getDeviceInfo 재조회도 겁니다. 연결되지 않았거나 내가 잡은 연결이 아니면 명령 패널이 dim 처리되어 원격 명령이 막히고, 필요 시 createDeviceConnection으로 connection을 먼저 맺습니다. 원격 명령 페이로드 타입(_api/Devices.tsx의 CommandType)의 단말 잠금(LOCK_DEVICE) 사유 필드는 lockScreenReason으로 정리되어, 잠금 시 공용 컴포넌트 LockReasonRadioGroup(getLockReasons)에서 선택한 사유(Illegal·Unactive·Suspended·IP Range·Model·ETC, XLSmart는 Illegal 제외)가 명령과 함께 전송됩니다. 제어 명령 계열(controlCommand, /device-connections/:id/commands/control)에는 DELETE_BLUETOOTH가 추가되어(OBE 대응), 디바이스 상세의 Bluetooth 박스(bluetoothBox.tsx)에서 페어링된 기기의 address를 담아 삭제 명령을 보내고 결과는 transactionId가 일치하는 SSE 메시지로 수신해 화면을 갱신합니다.

제어 가능 여부 판정 시나리오가 정리되었습니다. 예전에는 모달을 열기 전에 계산한 isMine 프로퍼티를 그대로 내려받았지만, 지금은 모달이 뜬 뒤 getDeviceInfo 응답의 lastConnectUserId와 로그인 사용자(useAuth().userInfo.id)를 비교해 isConnectedByMe를 세웁니다. Controllable/View Only 뱃지, 탭 이동 시 변경사항 경고, 새로고침 버튼의 동작(refreshDevice 또는 단순 getDeviceInfo)이 모두 이 값을 기준으로 하며, 첫 조회에서 이미 다른 사용자가 연결 중이면 사용 중 안내 모달(md:device_in_use_modal)을 띄웁니다. 모달 제목의 단말 ID도 사이트 분기 유틸 대신 ID_FIELD(KT는 deviceSiteId, 그 외 deviceId)로 뽑습니다.

연결 명령을 먼저 보내고 상세 모달을 여는 경로를 위해 isCommandSent 폴링이 추가되었습니다. 오프라인으로 보이는 단말을 목록에서 클릭하면 commandDevices(..., 'DEVICE_CONNECTION')을 먼저 던지고 isCommandSent: true로 모달을 여는데(pages/management/devices.tsx 등), 이 플래그가 서 있으면 1초 간격으로 최대 20회 getDetail을 호출해, 단말이 다른 사용자에게 CONNECTED된 경우에는 폴링을 끝내고, STANDBY로 돌아오면 createDeviceConnection으로 연결을 새로 만든 뒤 TaskContext의 updateCurrDeviceDetailModalConnectionId로 현재 모달의 connectionId·상태를 갱신하고 정보를 다시 읽습니다. 폴링 중에는 새로고침 버튼 자리에 진행 표시가 나옵니다. TaskContext 자체도 디바이스 상세 모달 전용임이 드러나도록 modals→deviceDetailModals, currModal→currDeviceDetailModal, openModal/closeModal→openDeviceDetailModal/closeDeviceDetailModal로 이름이 정리되었고, 닫기·작업 제거 시 isConnected 조건 없이 connectionId만 있으면 closeDeviceIssueReport를 호출하며 콜백에 connectionId·currSectionStatus를 넘겨 호출 측이 뒷정리를 할 수 있게 했습니다.

명령 모달 정비
앱 제어 확인 모달(RequestedModal)은 isLoading 동안 실행/취소 버튼을 비활성화하고 실행 버튼에 스피너를 띄워 중복 요청을 막습니다. 메시지 전송 모달(messageModal)은 YOUTUBE 타입일 때 screenSize·position·autoClose를 보내지 않고 url만 전달하도록 페이로드를 분기했고, 패킷 캡처 모달(PacketModal)은 응답 payload.duration이 없으면 캡처 진행 상태를 false로 되돌려 잘못된 진행 표시가 남지 않게 했습니다.
connection 선행 + dim 처리
Screen Share·Terminal 등 실시간 기능은 단말이 connection 된 상태(currSectionStatus CONNECTED)에서만 동작합니다. 명령 패널은 isConnected와 isMine(= 상위의 isConnectedByMe)을 보고 dim 여부를 결정합니다.

흐름. 상세 모달은 열린 뒤 단말 정보를 받아 제어 가능 여부를 판정하고, 연결 명령이 선행된 경우 STANDBY 전환을 폴링해 연결을 새로 맺습니다. 이어 화면 공유 명령으로 채널을 받고 WebSocket 시그널링(join → offer/answer → ICE)을 거쳐 WebRTC ontrack으로 단말 화면 스트림을 수신·표시합니다. 단말 상태 변화는 별도 SSE(useSSEController)로 갱신됩니다.

관계. TaskProvider가 현재 열린 디바이스 상세 모달을 들고, DetailWrapper가 SSE 구독·연결 상태 판정·명령 선행 폴링을 담당하며, 실제 명령은 Commands 패널이 발행합니다. ScreenShareModal은 WebSocket+RTCPeerConnection으로 WebRTC 스트림을 처리하고, 명령/연결은 모두 DevicesApiManager를 거칩니다.

pages/device/modal/screenShareModal.tsx — WebSocket + WebRTC(TURN 이중화) 초기화·시그널 분기
socketRef.current = new WebSocket(wss_url);  // REACT_APP_SIGNAL_BE_WS
const domain = process.env.REACT_APP_WEBSOCKET_DOMAIN;
const domain2 = process.env.REACT_APP_WEBSOCKET_DOMAIN2;   // 보조 TURN (XLSmart prod)
webRTC.current = new RTCPeerConnection({
  iceServers: [{
    username: 'rms', credential: '****',
    urls: domain2 ? [`turn:${domain}:3478`, `turn:${domain2}:3478`] : [`turn:${domain}:3478`]
  }]
});
socketRef.current.onmessage = async function (msg) {
  let message = JSON.parse(msg.data);
  switch (message.type) {
    case 'device-joined': await sendToServer({ type: 'connect-request', channelId }); break;
    case 'offer':         await handleOfferMessage(message.payload); break;
    case 'ice-candidate': handleNewICECandidateMessage(message.payload); break;
    case 'answer':        handleAnswerMessage(message); break;
  }
};
webRTC.current.ontrack = (ev) => { remoteVideoRef.current.srcObject = ev.streams[0]; };
pages/device/detailWrapper.tsx — SSE 구독 + 모달이 뜬 뒤 제어 가능 여부 판정
const { connect, disconnect, message } = useSSEController({
  url: `${process.env.REACT_APP_RMS_BE_SERVER_URL}/api/v1/notifications/subscribe`,
  eventType: 'NOTIFICATION',
  headers: { authorization: sessionStorage.getItem('accessToken') ?? '' },
  onError: (e) => { console.error('[SSE] Error:', e); }
});

const getDeviceInfo = (isReload?: boolean) => {
  DevicesApiManager.getDeviceInfo((result, data, code, message) => {
    if (result && code === '200000') {
      const isMine = data.lastConnectUserId === userInfo.id;      // 모달이 뜬 뒤 판정
      if (deviceCallCountRef.current === 0 && data.isConnected && !isMine) {
        setOpenAlarm(true);                                        // 다른 사용자가 사용 중 안내
      }
      setConnectedByMe(isMine);
      setDetailTitleId(data[ID_FIELD]);                            // KT: deviceSiteId, 그 외: deviceId
    }
    deviceCallCountRef.current = deviceCallCountRef.current + 1;
  }, id);
};
pages/device/detailWrapper.tsx — 연결 명령 선행 시 STANDBY 전환 폴링 후 connection 생성
useEffect(() => {
  if (!isCommandSent) return;
  setIsCommandSentPolling(true);

  let count = 0;
  const interval = setInterval(() => {
    count += 1;
    if (count >= 20) { clearInterval(interval); setIsCommandSentPolling(false); }

    DevicesApiManager.getDetail((result, data) => {
      if (!result || !data) return;

      if (data.status === DEVICE_SECTION_STATUS.CONNECTED &&
          data.modifiedBy !== sessionStorage.getItem('clientId')) {
        clearInterval(interval); setIsCommandSentPolling(false); return;   // 타인이 잡은 연결
      }

      if (data.status === DEVICE_SECTION_STATUS.STANDBY) {
        clearInterval(interval); setIsCommandSentPolling(false);
        DevicesApiManager.createDeviceConnection((result, connectionData) => {
          if (result && connectionData?.id) {
            updateCurrDeviceDetailModalConnectionId(connectionData.id);    // TaskContext 갱신
            getDeviceInfo();
          }
        }, id);
      }
    }, id);
  }, 1000);

  return () => { clearInterval(interval); setIsCommandSentPolling(false); };
}, [isCommandSent, id, updateCurrDeviceDetailModalConnectionId]);
contexts/TaskContext.tsx — 디바이스 상세 모달 전용 상태로 이름 정리 + connectionId 갱신
const [deviceDetailModals, setDeviceDetailModals] = useState<ModalProps[]>([]);
const [currDeviceDetailModal, setCurrDeviceDetailModal] = useState<ModalProps | null>(null);

const closeDeviceDetailModal = (target: ModalProps) => {
  if (target?.connectionId) {                       // isConnected 조건 제거
    VocApiManager.closeDeviceIssueReport(() => {
      target.callback(target?.connectionId, target?.currSectionStatus);
    }, target?.connectionId);
  }
  setCurrDeviceDetailModal(null);
};

const updateCurrDeviceDetailModalConnectionId = useCallback((connectionId: number) => {
  setCurrDeviceDetailModal((prev) =>
    prev ? { ...prev, connectionId, isCommandSent: false, currSectionStatus: DEVICE_SECTION_STATUS.CONNECTED } : prev
  );
}, []);
