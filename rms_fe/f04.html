기능 개요

VoC(Voice of Customer) 영역은 상담원이 고객 문의를 받았을 때 해당 가입자 단말의 상태를 빠르게 확인하도록 돕습니다. 핵심 화면 agentDevicelist.tsx는 마운트 시 VocApiManager.getVOCAgentOverview()(/api/v2/voc/agent/overview)로 상담원 응대 요약(기간별 통계)을 받고, getIssueList·getVOCHistory로 이슈 분포와 응대 이력을 채웁니다. 통계는 ActiveDeviceDonutChart·CustomizedBarchart로 시각화됩니다.

화면 하단의 단말 테이블은 상담원이 조회한 가입자 단말 목록을 보여주며, 행 단위로 단말 정보 버튼(AgentDevicelistInfoButton)을 제공합니다. 상담원이 응대를 시작하면 InitiatedVOCSessionModal이 열려 단말 식별자를 입력하고 VoC 세션을 개시합니다. VoC 대시보드 영역은 VocApiManager의 voc-overview/voc-connection-status 계열 엔드포인트로 활성 단말 수, 모델/OS 분포, 연결 사유 통계 등을 집계합니다.

agent 파라미터
VoC agent 화면에서는 조회 시 상담원(agent)을 필수 파라미터로 추가합니다(소스 주석 명시). 즉 같은 단말 조회 API라도 VoC 컨텍스트에서는 "누가 응대 중인가"를 함께 식별합니다.

흐름. 화면 진입 시 상담원 응대 요약·이슈·이력을 조회해 차트로 표시하고, 단말 행에서 정보를 확인한 뒤 InitiatedVOCSessionModal로 응대 세션을 시작합니다.

핵심 코드

_api/Voc.tsx — VoC 상담원 응대 요약 조회 (v2 엔드포인트)
getVOCAgentOverview: (callback: CallbackFunction, from: string, to: string) => {
  const data = { from, to };
  request('get', `/api/v2/voc/agent/overview`, callback, data);
},
// voc agent 에서는 조회 시 agent 를 필수로 추가
pages/voc/agentDevicelist.tsx — 응대 통계 수집 후 VoC 세션 모달 트리거
VocApiManager.getVOCAgentOverview((result, data) => { /* overview 차트 */ }, from, to);
VocApiManager.getIssueList((result, data) => { /* 이슈 분포 */ });
VocApiManager.getVOCHistory((result, data) => { /* 응대 이력 */ });
// ...
{openVOCSession && <InitiateVOCSessioModal open={openVOCSession} setOpen={setOpenVOCSession} />}
