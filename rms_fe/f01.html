기능 개요

모니터링 대시보드는 운영자가 RMS에 로그인하면 처음 마주하는 화면으로, 현장에 배포된 단말의 온라인 수·모델별 분포·임계치 초과 추이 등을 위젯 단위로 보여줍니다. 화면 본체인 dashboardRms.tsx는 react-grid-layout의 Responsive를 WidthProvider로 감싼 ResponsiveGridLayout을 렌더링하며, 각 칸이 하나의 DashboardItem 위젯이 됩니다. 레이아웃 컬럼 수는 widgetPermissions.widgetCols로 분기되어 XLSmart 타깃은 20, 그 외는 16 컬럼을 사용합니다. XLSmart에서 KPI 위젯을 5개(KPIWidgetCount) 나란히 표시하기 위한 확장으로, IBC 타깃은 이 확장 대상에서 제외되어 기본 16컬럼·KPI 4개를 사용합니다.

위젯 데이터는 서버 상태로 관리됩니다. 마운트 시 initialize()가 getLayout()·getWidget()·getOnlineDevice()를 Promise.all로 병렬 실행합니다. getWidget()은 내부에서 loadWidget()으로 위젯 목록(/api/v1/dashboard-config/widgets)을 가져온 뒤, 위젯별로 getWidgetDetailInfos(t)에 정의된 개별 API를 Promise.allSettled로 병렬 호출해 성공한 응답만 parsing()으로 차트 데이터로 변환합니다. 이어서 모듈 레벨 헬퍼 buildLayouts()가 서버 레이아웃(/api/v1/dashboard-config/layouts)과 위젯을 결합해 그리드를 구성합니다. 운영자가 편집 모드에서 위젯을 드래그하면 onLayoutChange가 상태를 갱신하며 sessionStorage에 임시 저장하고(재진입 시 복원 확인 모달), 저장 시 saveLayout()·saveWidget()이 변경된 레이아웃과 위젯 구성을 서버에 POST 합니다.

XLSmart 타깃 대응으로 위젯이 확장되었습니다. KPI 위젯 Illegal Devices(/api/v3/dashboard/illegal-device)가 widgetPermissions.illegalDevices 조건(XLSmart 전용)으로 초기 위젯 목록(types/dashboard/init.ts)에 추가되고, 차트 위젯 Top Installed Apps(install-app)·Top Deleted Apps(delete-app)·HDMI Connection Status(hdmi-connection)가 widgetDetailInfos(types/dashboard/data.ts)에 정의되었습니다. 각 위젯에는 topInstall·topDelete·hdmi 전용 아이콘도 부여되었습니다. 지도 위젯(DashboardItem/map/Map.tsx)에는 단말 상태(All/Active/Crash App/Warning/Illegal)를 고르는 CustomSelect 셀렉트가 지도 우상단 position: absolute 오버레이(top 48px·폰트 13px·높이 32px, 총계 문구 아래로 위치 조정)로 표시되며, 선택한 상태는 onMapChange를 거쳐 getDeviceStatusParam()(components/CustomizedMap.tsx)으로 변환되어 지도 데이터 조회 파라미터에 실제 반영됩니다. 위젯 상세 모달(dashboardDetailModal.tsx)도 isShowDeviceStatus 플래그로 같은 상태 필터를 노출하며, Illegal Devices 위젯의 테마 컬러는 #93ACFF로 조정되었습니다(types/dashboard/data.ts의 themeColor).

위젯 상세(2depth) 화면도 강화되었습니다. widgetDetailInfos의 각 위젯에 기본 정렬 옵션 defaultSortTarget·defaultSortType이 추가되어 상세 테이블이 위젯 성격에 맞는 컬럼(threshold 계열은 cpuUsage/memoryUsage/networkUsage, 단말 목록 계열은 IS_KT ? 'deviceSiteId' : 'deviceId')으로 정렬된 채 열립니다. App Crash·CPU/Memory/Network Threshold 위젯에는 isAiCause: modulePermissions.anomalyDetect 플래그가 붙어 IBC 타깃에서 이상 감지(AI 원인 분석) 기능과 연동됩니다. 또한 별도 팝업으로 뜨는 위젯 상세(components/DashboardItemDetail)에서 Device Details를 클릭하면 window.opener.openDeviceDetailModal(deviceId)로 부모 대시보드에 등록된 콜백이 호출되고, dashboardRms가 DevicesApiManager.getList()로 단말을 조회한 뒤 단말 관리 화면(devices.tsx)의 행 클릭과 동일한 연결 상태 분기를 수행합니다. DISCONNECTED+ONLINE이면 DEVICE_CONNECTION 명령 후 DEVICE_CONNECTION_TIME_LEFT(30초) 동안 BackdropLoading을 띄우고 1초 간격으로 세션 상태를 폴링하며, STANDBY면 createDeviceConnection으로 연결을 만든 뒤 useTask().openModal()로 device_info 모달을 엽니다.

사이트별 위젯 분기
utils/env.ts의 widgetPermissions에 따라 단말 위치 지도(deviceLocationMap)·브랜드 모델·네트워크 인터페이스 위젯은 OBE/TTG/XLSmart/IBC 타깃에서 숨겨지고, KT 타깃은 disableEditMode로 편집 자체가 비활성화됩니다. XLSmart에서는 illegalDevices 위젯이 켜지고 KPIWidgetCount 5·widgetCols 20이 적용됩니다. IBC는 위젯 확장 대상에서 빠지는 대신 modulePermissions에서 anomalyDetect·chatbot·terminal이 켜지는 별도 프로파일로 정리되었습니다. 즉 같은 코드가 사이트에 따라 다른 위젯 구성을 노출합니다.

흐름. 마운트 시 레이아웃·위젯·온라인 수를 병렬 조회해 그리드를 재구성하고, 위젯별 개별 API로 차트를 채웁니다. 드래그/리사이즈는 onLayoutChange로 반영되고 저장 시 saveLayout()이 서버에 POST 합니다. 위젯 상세 팝업의 Device Details는 window.opener 콜백으로 부모 대시보드에 위임되어 단말 연결 상태 분기 후 device_info 모달로 열립니다.

관계. DashboardRms가 ResponsiveGridLayout을 렌더하고 다수의 DashboardItem을 소유하며, dashboardAxios로 설정/데이터를 주고받습니다. 위젯 크기·상세 정의(기본 정렬 defaultSortTarget, AI 원인 분석 isAiCause 포함)는 widgetInfos/widgetDetailInfos, 사이트별 노출·그리드 컬럼 수(widgetCols)·XLSmart 전용 위젯(illegalDevices)은 widgetPermissions에서 결정됩니다. 팝업의 Device Details 요청은 DevicesApiManager 연결 분기를 거쳐 TaskContext.openModal()로 이어집니다.

const [layoutsData, widgetsData, onlineDevice] = await Promise.all([
  getLayout(),
  getWidget(),
  getOnlineDevice()
]);
const rebuildLayoutsData = buildLayouts(widgetsData, layoutsData);
setLayouts(rebuildLayoutsData);
pages/monitoring/dashboardRms.tsx — 편집 후 레이아웃 저장 (드래그/리사이즈 메타 제거 후 POST)
const saveLayout = async () => {
  const resizeLayout = mapValues(layouts, (layout) => {
    return layout.map(({ isDraggable, isResizable, moved, static: staticValue, ...postLayout }: Layout) => {
      return postLayout;
    });
  });
  await dashboardAxios.post('api/v1/dashboard-config/layouts', resizeLayout);
};
