기능 개요

모니터링 대시보드는 운영자가 RMS에 로그인하면 처음 마주하는 화면으로, 현장에 배포된 단말의 온라인 수·모델별 분포·임계치 초과 추이 등을 위젯 단위로 보여줍니다. 화면 본체인 dashboardRms.tsx는 react-grid-layout의 Responsive를 WidthProvider로 감싼 ResponsiveGridLayout을 렌더링하며, 각 칸이 하나의 DashboardItem 위젯이 됩니다. 레이아웃 컬럼 수는 widgetPermissions.widgetCols로 분기되어 XLSmart·IBC 타깃은 20, 그 외는 16 컬럼을 사용합니다. XLSmart·IBC에서 KPI 위젯을 5개(KPIWidgetCount) 나란히 표시하기 위한 확장입니다.

위젯 데이터는 서버 상태로 관리됩니다. 마운트 시 initialize()가 getLayout()·getWidget()·getOnlineDevice()를 Promise.all로 병렬 실행합니다. getWidget()은 내부에서 loadWidget()으로 위젯 목록(/api/v1/dashboard-config/widgets)을 가져온 뒤, 위젯별로 getWidgetDetailInfos(t)에 정의된 개별 API를 Promise.allSettled로 병렬 호출해 성공한 응답만 parsing()으로 차트 데이터로 변환합니다. 이어서 모듈 레벨 헬퍼 buildLayouts()가 서버 레이아웃(/api/v1/dashboard-config/layouts)과 위젯을 결합해 그리드를 구성합니다. 운영자가 편집 모드에서 위젯을 드래그하면 onLayoutChange가 상태를 갱신하며 sessionStorage에 임시 저장하고(재진입 시 복원 확인 모달), 저장 시 saveLayout()·saveWidget()이 변경된 레이아웃과 위젯 구성을 서버에 POST 합니다.

XLSmart·IBC 타깃 대응으로 위젯이 확장되었습니다. KPI 위젯 Illegal Devices(/api/v3/dashboard/illegal-device)가 widgetPermissions.illegalDevices 조건으로 초기 위젯 목록(types/dashboard/init.ts)에 추가되고, 차트 위젯 Top Installed Apps(install-app)·Top Deleted Apps(delete-app)·HDMI Connection Status(hdmi-connection)가 widgetDetailInfos(types/dashboard/data.ts)에 정의되었습니다. 각 위젯에는 topInstall·topDelete·hdmi 전용 아이콘도 부여되었습니다. 지도 위젯(DashboardItem/map/Map.tsx)에는 단말 상태(All/Active/Crash App/Warning/Illegal)를 고르는 CustomSelect 셀렉트가 지도 우상단 position: absolute 오버레이(폰트 13px·높이 32px)로 표시되며, 선택한 상태는 onMapChange를 거쳐 getDeviceStatusParam()(components/CustomizedMap.tsx)으로 변환되어 지도 데이터 조회 파라미터에 실제 반영됩니다. 위젯 상세 모달(dashboardDetailModal.tsx)도 isShowDeviceStatus 플래그로 같은 상태 필터를 노출하며, Illegal Devices 위젯의 테마 컬러는 #93ACFF로 조정되었습니다(types/dashboard/data.ts의 themeColor).

사이트별 위젯 분기
utils/env.ts의 widgetPermissions에 따라 단말 위치 지도(deviceLocationMap)·브랜드 모델·네트워크 인터페이스 위젯은 OBE/TTG/XLSmart/IBC 타깃에서 숨겨지고, KT 타깃은 disableEditMode로 편집 자체가 비활성화됩니다. XLSmart·IBC에서는 illegalDevices 위젯이 켜지고 KPIWidgetCount 5·widgetCols 20이 적용됩니다. 즉 같은 코드가 사이트에 따라 다른 위젯 구성을 노출합니다.

흐름. 마운트 시 레이아웃·위젯·온라인 수를 병렬 조회해 그리드를 재구성하고, 위젯별 개별 API로 차트를 채웁니다. 드래그/리사이즈는 onLayoutChange로 반영되고 저장 시 saveLayout()이 서버에 POST 합니다.

관계. DashboardRms가 ResponsiveGridLayout을 렌더하고 다수의 DashboardItem을 소유하며, dashboardAxios로 설정/데이터를 주고받습니다. 위젯 크기는 widgetInfos, 사이트별 노출·그리드 컬럼 수(widgetCols)·XLSmart 전용 위젯(illegalDevices)은 widgetPermissions에서 결정됩니다.

const [layoutsData, widgetsData, onlineDevice] = await Promise.all([
  getLayout(),
  getWidget(),
  getOnlineDevice()
]);
const rebuildLayoutsData = buildLayouts(widgetsData, layoutsData);
setLayouts(rebuildLayoutsData);

const saveLayout = async () => {
  const resizeLayout = mapValues(layouts, (layout) => {
    return layout.map(({ isDraggable, isResizable, moved, static: staticValue, ...postLayout }: Layout) => {
      return postLayout;
    });
  });
  await dashboardAxios.post('api/v1/dashboard-config/layouts', resizeLayout);
};
