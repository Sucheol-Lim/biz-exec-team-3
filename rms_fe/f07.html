OTA(펌웨어) 관리

fwList가 펌웨어 이미지를 등록·관리하고, fwInstall이 FirmwareApiManager.install()로 대상 단말 그룹에 펌웨어 OTA 업데이트를 예약·전파합니다. 설치 상세 모달에서는 Retry·Pause/Restart·Stop으로 진행 중인 배포를 제어합니다.

기능 개요

OTA(펌웨어) 관리는 단말 펌웨어 이미지를 등록하고 무선으로(Over-The-Air) 업데이트를 배포합니다. fwList는 FirmwareApiManager.getList()(/api/v1/firmwares)로 등록된 펌웨어 목록을 보여주고, 등록은 create(FormData + isForm)로 펌웨어 이미지 파일을 multipart/form-data 전송합니다. 이름/버전 중복은 checkName으로 사전 검증합니다.

실제 OTA 배포는 fwInstall 화면이 담당합니다. 운영자가 펌웨어·대상 그룹·설치 시각·모드를 지정하면 install()(/api/v1/firmware-installs)에 firmware·mode·installTime·deviceGroupIds(필요 시 rescueId)를 묶어 POST 합니다. 배포 후에는 getInstallList로 설치 작업 목록을, getInstallDetailHistroy로 단말별 설치 진행/결과 이력을 추적합니다. 설치 작업 행에는 대상 그룹과 예약 시각이 사람이 읽기 쉬운 텍스트로 요약 표시되며, 목록에 OS 컬럼이 추가되었습니다.

설치 상세 모달(FwInstallModal)에는 배포 제어 버튼이 추가되었습니다. handleRetry는 getInstallRetry(/firmware-installs/{id}/retry)로 실패 단말 재시도를 요청하고, handlePauseToggle은 getInstallPause/getInstallRestart(/pause·/restart)로 배포 일시정지/재개를 토글합니다(실패 단말이 있을 때 활성화). Stop은 확인 다이얼로그를 거쳐 중지 상태와 중지 시각을 표시합니다. 기존의 설치 이력 엑셀 다운로드 버튼은 이 제어 버튼들로 대체되었습니다.

그룹 단위 OTA
펌웨어 OTA는 개별 단말이 아니라 단말 그룹(deviceGroupIds) 단위로 배포 대상을 지정합니다. 즉 단말 관리에서 만든 그룹이 펌웨어 배포의 단위가 되어, 모델·지역별 단계적 롤아웃이 가능합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant OP as 운영자 (Browser) participant FL as fwList.tsx participant FI as fwInstall.tsx participant FM as FirmwareApiManager (_api/Firmware) participant BE as RMS BE 서버 participant GRP as 대상 단말 그룹 OP->>FL: 펌웨어 등록 (이미지 업로드) FL->>FM: checkName(name, version) FL->>FM: create(FormData) FM->>BE: POST /firmwares (multipart) OP->>FI: OTA 설치 예약 FI->>FM: install(firmware, mode, installTime, groupIds) FM->>BE: POST /firmware-installs BE->>GRP: 펌웨어 OTA 전파 loop 설치 이력 추적 FI->>FM: getInstallDetailHistroy(installId) FM->>BE: GET /firmware-install-historys BE-->>FI: 단말별 진행/결과 end opt 배포 제어 (설치 상세 모달) FI->>FM: getInstallRetry / getInstallPause / getInstallRestart(id) FM->>BE: POST /firmware-installs/:id/retry·pause·restart end

흐름. 펌웨어를 검증·등록한 뒤 대상 그룹·시각·모드로 install을 호출해 OTA를 배포하고, 설치 히스토리로 단말별 결과를 추적합니다. 설치 상세 모달에서는 retry/pause/restart 엔드포인트로 진행 중인 배포를 제어합니다.

관계. FwList가 펌웨어 등록·목록을, FwInstall(+FwInstallModal)이 OTA 배포·이력·배포 제어(Retry/Pause/Restart/Stop)를 처리하며 모두 FirmwareApiManager를 통합니다.

핵심 코드

_api/Firmware.tsx — 펌웨어 등록(FormData)·그룹 단위 OTA 설치·배포 제어
create: (callback, data: FormData) => {
  request('post', `/api/v1/firmwares`, callback, data, true);  // isForm = multipart
},
install: (callback, firmware, mode, installTime, deviceGroupIds, rescueId) => {
  const data = { firmware, mode, installTime, deviceGroupIds,
    ...(rescueId != null && rescueId !== '' ? { rescueId } : {}) };
  request('post', `/api/v1/firmware-installs`, callback, data);
},
getInstallRetry: (callback, id: number) => {
  request('post', `/api/v1/firmware-installs/${id}/retry`, callback);
},
getInstallRestart: (callback, id: number) => {
  request('post', `/api/v1/firmware-installs/${id}/restart`, callback);
},
getInstallPause: (callback, id: number) => {
  request('post', `/api/v1/firmware-installs/${id}/pause`, callback);
}
pages/ota/fwInstall.tsx — 설치 목록 조회 후 대상 그룹 텍스트 요약
FirmwareApiManager.getInstallList((result, data) => {
  // installTime / 대상 그룹(targetDeviceGr) / status 를 행으로 매핑
});
const getDeviceText = (deviceGroups) =>
  deviceGroups[0].name + (deviceGroups.length > 1 ? ` + ${deviceGroups.length - 1}` : '');
pages/ota/FwInstallModal.tsx — 배포 일시정지/재개 토글
const handlePauseToggle = () => {
  if (paused) {
    apiManager.getInstallRestart((result) => {   // Restart
      if (result) setPaused(false);
    }, reqId);
  } else {
    apiManager.getInstallPause((result) => {     // Pause
      if (result) setPaused(true);
    }, reqId);
  }
};
