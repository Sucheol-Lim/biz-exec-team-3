앱(App) 관리

packageList/packageInstall/defaultPackage/appPolicy가 AppApiManager로 APK 패키지 업로드·설치·기본 패키지·앱 정책을 다루며, OBE 사이트에서는 패키지명 대신 앱 이름(appName) 컬럼을 표시합니다.

기능 개요

앱 관리는 단말에 배포할 APK 패키지의 등록부터 설치, 정책 적용까지를 다룹니다. packageList는 AppApiManager.getList()(/api/v1/app-packages)로 패키지 목록을 조회하고, 업로드는 create(FormData + isForm=true)로 APK를 multipart/form-data 전송하며 사전에 getApkInfo(analyze-apk)로 APK 메타를 분석합니다. 실제 단말 설치는 packageInstall이 install()(/api/v1/app-package-installs)에 packageIds·mode·installTime·대상 deviceGroupIds를 넘겨 예약/즉시 배포합니다. 진행 상태는 getInstallDetailHistroyStatus로 추적합니다.

defaultPackage는 단말 초기 구성에 들어갈 기본 패키지(/api/v1/default-packages)와 관리 앱(managed-app) XML 업로드를 다루고, appPolicy는 화이트리스트/블랙리스트 등 앱 정책을 등록·수정합니다. OBE 타깃에서는 운영자에게 친숙한 표시를 위해 목록 컬럼이 패키지명 대신 appName으로 표시되도록 분기되어 있습니다(appmanagement.columns.ts).

OBE 앱 이름 표시
최근 작업으로 OBE 사이트에서 패키지명을 앱 이름(appName)으로 바꿔 표시하도록 컬럼·업로드 모달·화이트리스트 설명이 정비되었습니다(개발 이력 74f7d919 등). 코드베이스는 동일하지만 사이트별로 사용자에게 보이는 라벨이 달라집니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant OP as 운영자 (Browser) participant PU as packageFileUpload participant PI as packageInstall.tsx participant AM as AppApiManager (_api/App) participant BE as RMS BE 서버 participant GRP as 대상 단말 그룹 OP->>PU: APK 선택 PU->>AM: getApkInfo(FormData) AM->>BE: POST /app-packages/analyze-apk BE-->>PU: APK 메타 (name/version) OP->>PU: 업로드 PU->>AM: create(FormData) AM->>BE: POST /app-packages (multipart) OP->>PI: 설치 예약 (group/time/mode) PI->>AM: install(packageIds, mode, time, groupIds) AM->>BE: POST /app-package-installs BE->>GRP: 설치 전파 loop 설치 상태 추적 PI->>AM: getInstallDetailHistroyStatus(id) AM->>BE: GET 상태 BE-->>PI: 단말별 설치 진행/결과 end

흐름. APK를 분석·업로드한 뒤 대상 그룹·시각·모드를 지정해 install로 배포하고, 설치 히스토리 상태를 폴링해 단말별 결과를 확인합니다.

클래스 다이어그램

classDiagram class PackageList { +getList() } class PackageInstall { +install() } class DefaultPackage { +getDefaultPkgList() +uploadManagedApp() } class AppPolicy { +register() +update() } class AppApiManager { +getList(cb, page, size, name) +create(cb, FormData) +getApkInfo(cb, FormData) +install(cb, packageIds, mode, time, groupIds) +getInstallDetailHistroyStatus(cb, id) +getDefaultPkgList(cb, ...) } PackageList --> AppApiManager : 목록 PackageInstall --> AppApiManager : 설치·상태 DefaultPackage --> AppApiManager : 기본 패키지·managed-app AppPolicy --> AppApiManager : 정책 등록/수정

관계. 앱 관리 하위 화면들이 AppApiManager 하나를 공유해 패키지 CRUD·설치·정책을 처리합니다. APK 업로드와 managed-app XML은 FormData(isForm)로 전송됩니다.

핵심 코드

_api/App.tsx — APK 업로드(FormData)와 그룹 단위 설치 요청
create: (callback, data: FormData) => {
  request('post', `/api/v1/app-packages`, callback, data, true);  // isForm = multipart
},
install: (callback, packageIds, mode, installTime, deviceGroupIds: number[]) => {
  request('post', `/api/v1/app-package-installs`, callback,
    { packageIds, mode, installTime, deviceGroupIds });
}
pages/appmanagement/appmanagement.columns.ts — OBE 등에서 appName 컬럼 사용
{
  id: 'appName',
  // OBE 사이트: 패키지명 대신 앱 이름(appName)을 목록 컬럼으로 표시
  // ...
}
