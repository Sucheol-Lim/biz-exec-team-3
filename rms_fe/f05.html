단말(Device) 관리

Management 메뉴가 단말 목록/상세/편집·그룹·단말 정책(STB Policy)을 다루며, deviceImportDialog가 Excel 파일을 multipart/form-data로 업로드해 단말을 일괄 등록하고 DevicesApiManager가 그룹 단위 운영을 지원합니다.

기능 개요

단말 관리(Management)는 RMS 운영의 기반이 되는 영역입니다. managementDevices/devicelist가 DevicesApiManager.getList()(/api/v1/devices)로 단말 목록을 조회하고, deviceDetailInfo/deviceEdit가 getDetail·update(/api/v1/devices/:id/update)로 상세 조회와 편집을 처리합니다. 그룹은 groups/groupEdit가 getGroupList·changeGroup·moveDevices 등으로 단말을 그룹 단위로 묶어 운영하고, 단말 정책은 devicePolicy가 getPolicyList(/api/v1/device-policies)로 STB Policy를 다룹니다.

대량 등록은 Excel import로 이뤄집니다. deviceImportDialog가 downloadExcel('/api/v1/devices/download-upload-template', ...)로 템플릿을 내려주고, 운영자가 작성한 파일을 FormData에 담아 uploadDeviceExcelFileResult로 multipart/form-data 전송합니다. 이렇게 서버에 단말 정보가 등록되면, 단말 부팅 시 RMS Client가 해당 정보로 인증하고 목록/상세에 연동 단말로 나타납니다.

사이트별 식별자 필드
utils/env.ts의 ID_FIELD는 KT 타깃이면 deviceSiteId, 그 외에는 deviceId로 분기됩니다(useRegionalId). 같은 단말 화면도 KT에서는 지역 식별자 기준으로 표시·검색됩니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant OP as 운영자 (Browser) participant ID as deviceImportDialog.tsx participant DL as managementDevices / devicelist participant DM as DevicesApiManager (_api/Devices) participant BE as RMS BE 서버 participant STB as 단말 (RMS Client) OP->>ID: 템플릿 다운로드 ID->>BE: GET /devices/download-upload-template OP->>ID: 작성한 Excel 업로드 ID->>ID: FormData.append('file', file) ID->>DM: uploadDeviceExcelFileResult(formdata) DM->>BE: POST (multipart/form-data) BE-->>ID: 등록 결과 (성공/거부) STB->>BE: 부팅 후 등록 정보로 인증·상태 보고 OP->>DL: 단말 목록 조회 DL->>DM: getList(page, size, search) DM->>BE: GET /api/v1/devices BE-->>DL: 단말 목록 (연동 단말 포함) OP->>DL: 단말 편집 저장 DL->>DM: update(data) DM->>BE: POST /devices/:id/update

흐름. Excel 템플릿을 받아 작성·업로드하면 FormData로 일괄 등록되고, 단말이 부팅·인증하면 목록에 나타납니다. 상세 편집은 update로 서버에 저장됩니다.

클래스 다이어그램

관계. Management 하위 화면들이 모두 DevicesApiManager 한 객체를 공유해 단말·그룹·정책·Excel 업로드를 처리합니다. 도메인은 분리되지만 API 게이트웨이는 하나입니다.

formdata.append('file', values.file[0]);

DevicesApiManager.uploadDeviceExcelFileResult((result, data, code, message) => {
  // 등록 결과 처리 (성공 건수 / 거부 파일)
}, formdata);
// 템플릿: downloadExcel('/api/v1/devices/download-upload-template', 'template.xlsx');
_api/Devices.tsx — 단말 목록/상세/수정 엔드포인트
getList: (callback, page, size, searchItems?) => {
  request('get', `/api/v1/devices`, callback, data);
},
getDetail: (callback, id) => {
  request('get', `/api/v1/devices/${id}`, callback);
},
update: (callback, data) => {
  request('post', `/api/v1/devices/${data.id}/update`, callback, data);
}
