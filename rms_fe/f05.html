단말(Device) 관리

Management 메뉴가 단말 목록/상세/편집·그룹·단말 정책(STB Policy)·잠금 단말(Locked Devices)을 다루며, deviceImportDialog가 Excel 파일을 multipart/form-data로 업로드해 단말을 일괄 등록하고 DevicesApiManager가 그룹 단위 운영을 지원합니다.

기능 개요

단말 관리(Management)는 RMS 운영의 기반이 되는 영역입니다. managementDevices/devicelist가 DevicesApiManager.getList()(/api/v1/devices)로 단말 목록을 조회하고, deviceDetailInfo/deviceEdit가 getDetail·update(/api/v1/devices/:id/update)로 상세 조회와 편집을 처리합니다. 그룹은 groups/groupEdit가 getGroupList·changeGroup·moveDevices 등으로 단말을 그룹 단위로 묶어 운영하고, 단말 정책은 devicePolicy가 getPolicyList(/api/v1/device-policies)로 STB Policy를 다루며, 정책 목록에 재부팅 자동화(standbyRebootEnabled, Reboot Automation) 컬럼이 추가되고 검색 옵션이 management.searchOption.ts의 getDevicePolicySearchOptionList로 분리되어 임계치·자동 실행과 함께 재부팅 자동화 On/Off 검색을 지원합니다. 단말 관리 탭 컨테이너(managementDevices.tsx)에는 Locked Devices 탭이 추가되어 Device List · Locked Devices · Command History · (OBE/TTG 한정) Advance Search 구성이 되었고, 같은 탭을 다시 클릭하면 refreshKey를 증가시켜 하위 컴포넌트의 key를 바꿔 리마운트하는 방식으로 목록을 새로고침합니다. Locked Devices 탭(lockDevices.tsx)은 getLockedDeviceList가 lockScreenEnable: true 파라미터로 /api/v1/devices를 조회해 화면 잠금된 단말만 보여주고, 선택 단말 일괄 삭제(deleteBulk)와 잠금 단말 Excel 일괄 등록을 지원합니다. Device List와 마찬가지로 잠금 단말 목록도 등록일(createdAt) 내림차순이 기본 정렬로 지정되어 최근 등록 단말부터 표시되고, 단말 연결 대기 카운트다운 값은 utils/constants.ts의 상수(DEVICE_CONNECTION_TIME_LEFT·DEVICE_CONNECTION_COUNTDOWN_INTERVAL)로 정리되었습니다.

대량 등록은 Excel import로 이뤄집니다. deviceImportDialog가 downloadExcel('/api/v1/devices/download-upload-template', ...)로 템플릿을 내려주고, 운영자가 작성한 파일을 FormData에 담아 uploadDeviceExcelFileResult로 multipart/form-data 전송합니다. 이렇게 서버에 단말 정보가 등록되면, 단말 부팅 시 RMS Client가 해당 정보로 인증하고 목록/상세에 연동 단말로 나타납니다. 잠금 단말 등록 시에는 같은 다이얼로그가 type="lock"으로 열려 공용 컴포넌트 LockReasonRadioGroup에서 고른 잠금 사유를 lockScreenReason으로 FormData에 함께 첨부합니다. 단말·그룹 일괄 명령 API(commandDevices·commandDevicesAll·commandDeviceGroups 등)의 CommandType에는 잠금 사유(lockScreenReason) 필드가 있어, LOCK 명령 시 명령 모달에서 선택한 사유(Illegal·Unactive·Suspended·IP Range·Model·ETC, XLSmart 타깃은 Illegal 제외)가 함께 전송됩니다. 또한 연결 단말 실시간 제어 명령 controlCommand(/api/v1/device-connections/:id/commands/control)에 DELETE_BLUETOOTH 명령 타입이 추가되어, OBE 단말 상세의 블루투스 삭제 버튼(device/comp/bluetoothBox.tsx)이 삭제할 기기 address를 함께 전송합니다.

사이트별 식별자 필드
utils/env.ts의 ID_FIELD는 KT 타깃이면 deviceSiteId, 그 외에는 deviceId로 분기됩니다(useRegionalId). 같은 단말 화면도 KT에서는 지역 식별자 기준으로 표시·검색됩니다.

흐름. Excel 템플릿을 받아 작성·업로드하면 FormData로 일괄 등록되고, 단말이 부팅·인증하면 목록에 나타납니다. 상세 편집은 update로 서버에 저장됩니다.

핵심 코드

pages/management/deviceImportDialog.tsx — Excel 파일을 FormData로 업로드
var formdata = new FormData();
formdata.append('file', values.file[0]);
if (type === 'lock') {
  formdata.append('lockScreenReason', lockScreenReason); // 잠금 단말 등록 시 사유 첨부
}

DevicesApiManager.uploadDeviceExcelFileResult((result, data, code, message) => {
  // 등록 결과 처리 (성공 건수 / 거부 파일)
}, formdata);
// 템플릿: downloadExcel('/api/v1/devices/download-upload-template', 'template.xlsx');
_api/Devices.tsx — 단말 목록/상세/수정·제어 명령 엔드포인트
getList: (callback, page, size, searchItems?) => {
  request('get', `/api/v1/devices`, callback, data);
},
getLockedDeviceList: (callback, page, size, searchItems?) => {
  const data = { lockScreenEnable: true, page, size, ...searchItems };
  request('get', `/api/v1/devices`, callback, data);
},
getDetail: (callback, id) => {
  request('get', `/api/v1/devices/${id}`, callback);
},
update: (callback, data) => {
  request('post', `/api/v1/devices/${data.id}/update`, callback, data);
},
controlCommand: (callback, id, commandType, params?) => {
  const data = {
    commandType,
    ...(commandType === 'SET_VOLUME' && params?.volume && { volume: params.volume }),
    ...(commandType === 'INPUT_KEYEVENT' && params?.inputKeyEvent && { inputKeyEvent: params.inputKeyEvent }),
    ...(commandType === 'DELETE_BLUETOOTH' && params?.address && { address: params.address })  // OBE 블루투스 삭제
  };
  request('post', `/api/v1/device-connections/${id}/commands/control`, callback, data);
}
