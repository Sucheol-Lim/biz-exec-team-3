AI 챗봇

ChatPopup이 사내 패키지 @altimedia/rms-chatbot-ui의 ChatBot을 마운트하고, ChatContext가 registOnChatbot/sendToFrontend로 챗봇과 프론트엔드 사이의 요청(REQ_INFO/REQ_NAV)·응답 전문을 중계합니다. modulePermissions.chatbot(REACT_APP_CHATBOT=Y) 사이트에서만 노출됩니다.

기능 개요

AI 챗봇은 사내 패키지 @altimedia/rms-chatbot-ui(vendor 로컬 tgz)의 ChatBot 컴포넌트를 RMS 화면에 끼워 넣은 것입니다. App.tsx는 modulePermissions.chatbot(즉 REACT_APP_CHATBOT=Y)이고 로그인한 사용자가 있을 때만 챗봇 버튼을 노출하며, 버튼을 누르면 ChatPopup이 ChatBot을 렌더합니다. ChatBot은 endpoint/apiKey(REACT_APP_CHATBOT_API*)를 받아 백엔드 AI 에이전트와 통신합니다.

챗봇과 RMS 프론트엔드의 양방향 통신은 ChatContext가 중계합니다. ChatPopup은 마운트 시 onRegister={registOnChatbot}으로 챗봇 수신 콜백을 등록하고, 챗봇이 호스트에 보내는 메시지는 onSendToHost={sendToFrontend}로 전달됩니다. 요청 타입은 REQ_INFO(디바이스/사용자 정보 조회)와 REQ_NAV(화면 네비게이션)이며, nav 값(SCREEN_SHARE·INSTALL_PACKAGE·CLEAR_CACHE·NETWORK_STATUS·PACKET_CAPTURE·FIRM_OTA_UPDATE·TERMINAL_COMMAND·MESSAGE 등)으로 화면 공유·앱 설치·펌웨어 OTA 같은 기능으로 분기합니다. 디바이스 모달이 떠 있지 않을 때 REQ_INFO는 세션 스토리지의 사용자/토큰 정보로 직접 응답합니다.

두 개의 콜백 ref
ChatContext는 chatbotRef(챗봇 → FE 응답 수신)와 frontendRef(FE → 챗봇 요청 수신) 두 ref를 두어, 디바이스 모달이 마운트되었는지에 따라 요청을 모달이 처리할지 컨텍스트가 기본 응답할지 결정합니다. 모달 미마운트 시에는 "Connection device modal is not mounted" 같은 결과를 회신합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant OP as 운영자 (Browser) participant CP as ChatPopup (ChatBot) participant CC as ChatContext participant FE as Device Modal / FE 화면 participant SS as sessionStorage OP->>CP: 챗봇 열기 (CHATBOT=Y) CP->>CC: onRegister → registOnChatbot(cb) OP->>CP: 질의 입력 CP->>CC: onSendToHost → sendToFrontend(ChatRequestType) alt frontendRef 등록됨 (모달 마운트) CC->>FE: frontendRef(data) FE-->>CC: ChatResponseType (result/message/data) else REQ_INFO 기본 처리 CC->>SS: user/accessToken/role/lang 조회 CC-->>CP: chatbotRef(ChatResponseType) end Note over FE: REQ_NAV → nav 값으로 화면 공유/앱 설치/OTA 등 분기

흐름. 챗봇이 sendToFrontend로 요청을 보내면, 모달이 떠 있으면 frontendRef가 처리하고 아니면 REQ_INFO를 세션 정보로 직접 응답합니다. REQ_NAV는 nav 값으로 해당 기능 화면으로 네비게이션합니다.

클래스 다이어그램

classDiagram class ChatPopup { +onRegister +onSendToHost } class ChatProvider { -chatbotRef -frontendRef +registOnChatbot(cb) +registOnFrontend(cb) +sendToChatbot(data) +sendToFrontend(ChatRequestType) } class ChatBot { +endpoint +apiKey } class ChatRequestType { +type REQ_INFO|REQ_NAV +nav ChatNav +target } class ChatResponseType { +result +message +data ChatResponseData } ChatPopup --> ChatBot : 마운트 ChatPopup --> ChatProvider : useChat (regist/send) ChatProvider ..> ChatRequestType : 수신 ChatProvider ..> ChatResponseType : 회신

관계. ChatPopup이 ChatBot을 마운트하고 useChat으로 ChatProvider에 콜백을 등록·전송합니다. 요청/응답은 ChatRequestType/ChatResponseType 전문으로 표준화되어 있습니다.

핵심 코드

chatbot/ChatPopup.tsx — 사내 ChatBot 컴포넌트 마운트·콜백 연결
import { ChatBot } from '@altimedia/rms-chatbot-ui';
const { registOnChatbot, sendToFrontend } = useChat();
return (
  <ChatBot
    onSendToHost={sendToFrontend}
    onRegister={registOnChatbot}
    endpoint={process.env.REACT_APP_CHATBOT_API || undefined}
    apiKey={process.env.REACT_APP_CHATBOT_API_KEY || undefined}
    position="bottom-right"
  />
);
contexts/ChatContext.tsx — 모달 미마운트 시 REQ_INFO 기본 응답
const sendToFrontend = (data: ChatRequestType) => {
  if (frontendRef.current) { frontendRef.current?.(data); return; }   // 모달이 처리
  if (data.type === 'REQ_INFO') {
    const user = sessionStorage.getItem('user');
    chatbotRef.current?.({
      type: 'REQ_INFO', result: true, message: 'Success',
      data: {
        accessToken: sessionStorage.getItem('accessToken') || '',
        user: user ? JSON.parse(user).username : '',
        role: sessionStorage.getItem('role') || '',
        lang: localStorage.getItem('language') || 'en'
      }
    });
    return;
  }
  chatbotRef.current?.({ type: data.type, nav: data.nav, result: false, message: 'Connection device modal is not mounted' });
};
