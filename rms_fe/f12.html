AI 챗봇

ChatPopup이 사내 패키지 @altimedia/rms-chatbot-ui(현재 0.1.58)의 ChatBot을 마운트하고, ChatContext가 registOnChatbot/sendToFrontend로 챗봇과 프론트엔드 사이의 요청(REQ_INFO/REQ_NAV/REQ_DEVICES/REQ_OPEN_MODAL)·응답 전문을 중계합니다. 여기에 화면이 챗봇으로 컨텍스트를 밀어 넣는 DEVICE_MODAL_STATUS·ISSUE_INFO가 더해졌고, modulePermissions.chatbot(IBC 타깃 전용) 사이트에서만 노출됩니다.

기능 개요

AI 챗봇은 사내 패키지 @altimedia/rms-chatbot-ui(vendor 로컬 tgz)의 ChatBot 컴포넌트를 RMS 화면에 끼워 넣은 것입니다. App.tsx는 modulePermissions.chatbot(현재 TARGET === 'IBC' — 종전의 REACT_APP_CHATBOT=Y 환경변수 분기는 제거)이고 로그인한 사용자가 있으며 대시보드 상세 팝업 경로가 아닐 때만 챗봇 버튼을 노출하며, 버튼을 누르면 ChatPopup이 ChatBot을 렌더합니다. ChatBot은 endpoint/apiKey(REACT_APP_CHATBOT_API*)를 받아 백엔드 AI 에이전트와 통신합니다. 컴포넌트 트리에서는 ChatProvider가 TaskProvider 바깥(최상위)으로 이동해, TaskContext가 useChat의 sendToChatbot으로 디바이스 모달 열림/닫힘을 DEVICE_MODAL_STATUS(OPEN/CLOSE) 전문으로 챗봇에 통지합니다. 이때 TaskContext의 상태·함수명이 디바이스 상세 모달 전용임을 드러내도록 modals→deviceDetailModals, openModal/closeModal→openDeviceDetailModal/closeDeviceDetailModal로 정리되었고, 모달이 뜬 뒤 연결이 성립하면 updateCurrDeviceDetailModalConnectionId()가 현재 모달의 connectionId를 갱신합니다. 챗봇 UI 패키지는 0.1.42에서 0.1.58까지 연속 갱신되었습니다(vendor/altimedia-rms-chatbot-ui-0.1.58.tgz).

챗봇과 RMS 프론트엔드의 양방향 통신은 ChatContext가 중계합니다. ChatPopup은 마운트 시 onRegister={registOnChatbot}으로 챗봇 수신 콜백을 등록하고, 챗봇이 호스트에 보내는 메시지는 onSendToHost={sendToFrontend}로 전달됩니다. 요청 타입은 REQ_INFO(디바이스/사용자 정보 조회) · REQ_NAV(화면 네비게이션) · REQ_DEVICES(디바이스 정보 일괄 조회) · REQ_OPEN_MODAL(단말 관리 화면으로 이동해 디바이스 모달 오픈) 네 가지이며, REQ_NAV는 nav 값(SCREEN_SHARE·APP_CONTROL·INSTALL_PACKAGE·CLEAR_CACHE·NETWORK_STATUS·PACKET_CAPTURE·FIRM_OTA_UPDATE·TERMINAL_COMMAND·MESSAGE 등)으로 화면 공유·앱 설치·펌웨어 OTA 같은 기능으로 분기합니다. REQ_DEVICES는 디바이스 모달 마운트 여부와 무관하게 ChatProvider가 target(단건 또는 목록)별로 DevicesApiManager.getDeviceInfo를 호출해 deviceInfos 배열로 일괄 응답하고(target이 없으면 No target 회신), REQ_OPEN_MODAL은 useNavigate로 /management/devices에 targetId state를 실어 이동시킵니다. 디바이스 모달이 떠 있지 않을 때 REQ_INFO는 세션 스토리지의 사용자/토큰 정보에 sessionScope: 'general'(디바이스 미선택 일반 세션)과 roleLevel·isConnected: false·isMine: false를 더해 직접 응답합니다.

이상탐지(AI Quick Operation) 도입과 함께 전문 타입에 ISSUE_INFO가 추가되었습니다. anomalyAccordionList.tsx는 운영자가 이슈 아코디언을 펼칠 때 modulePermissions.chatbot && sendToChatbot 조건에서 그 이슈 객체(item)를 { type: 'ISSUE_INFO', result: true, message: 'Success', data: item }로 챗봇에 그대로 밀어 넣어, 사용자가 따로 설명하지 않아도 챗봇이 현재 보고 있는 이슈를 컨텍스트로 삼게 합니다. 이렇게 화면이 임의 도메인 객체를 실어 보내게 되면서 ChatResponseType.data의 타입도 ChatResponseData에서 any로 완화되었습니다(REQ_INFO 응답은 여전히 ChatResponseData 형상을 따릅니다).

표시 측면에서는 챗봇 플로팅 버튼과 토스트가 겹치는 문제를 components/third-party/Notistack.tsx에서 보정합니다. modulePermissions.chatbot이 켜진 사이트에서만 GlobalStyles로 .SnackbarContainer-right를 right: 100px만큼 왼쪽으로 밀고, 공통으로 .SnackbarContainer-bottom을 bottom: 24px로 띄웁니다.

두 개의 콜백 ref
ChatContext는 chatbotRef(챗봇 → FE 응답 수신)와 frontendRef(FE → 챗봇 요청 수신) 두 ref를 두어, 디바이스 모달이 마운트되었는지에 따라 요청을 모달이 처리할지 컨텍스트가 기본 응답할지 결정합니다. 단 REQ_DEVICES·REQ_OPEN_MODAL은 ref 분기보다 먼저 ChatProvider가 단독 처리하며, 모달 미마운트 시 나머지 요청에는 "Connection device modal is not mounted" 같은 결과를 회신합니다. 반대로 sendToChatbot은 챗봇이 미마운트면 "Chatbot is not mounted"를 frontendRef로 되돌립니다.

흐름. 반대 방향으로는 디바이스 모달 열림/닫힘(DEVICE_MODAL_STATUS)과 이상탐지 이슈 펼침(ISSUE_INFO)을 화면이 sendToChatbot으로 밀어 넣습니다. 챗봇이 sendToFrontend로 요청을 보내면, REQ_DEVICES는 모달과 무관하게 ChatProvider가 getDeviceInfo를 target별로 호출해 deviceInfos로 응답하고, REQ_OPEN_MODAL은 navigate로 단말 관리 화면에 targetId를 실어 이동시킵니다. 그 외에는 모달이 떠 있으면 frontendRef가 처리하고 아니면 REQ_INFO를 세션 정보(sessionScope: 'general'·roleLevel 포함)로 직접 응답합니다. REQ_NAV는 nav 값으로 해당 기능 화면으로 네비게이션합니다.

관계. ChatPopup이 ChatBot을 마운트하고 useChat으로 ChatProvider에 콜백을 등록·전송합니다. 요청/응답은 ChatRequestType/ChatResponseType 전문으로 표준화되어 있고, TaskProvider는 디바이스 상세 모달 열림/닫힘을 DEVICE_MODAL_STATUS로, AnomalyAccordionList는 펼친 이슈를 ISSUE_INFO로 챗봇에 통지합니다.

import { ChatBot } from '@altimedia/rms-chatbot-ui';
const { registOnChatbot, sendToFrontend } = useChat();
return (
  <ChatBot
    onSendToHost={sendToFrontend}
    onRegister={registOnChatbot}
    onClose={onClose}
    endpoint={process.env.REACT_APP_CHATBOT_API || undefined}
    apiKey={process.env.REACT_APP_CHATBOT_API_KEY || undefined}
    position="bottom-right"
  />
);
contexts/ChatContext.tsx — REQ_DEVICES/REQ_OPEN_MODAL 직접 처리 · 모달 미마운트 시 REQ_INFO 기본 응답
const sendToFrontend = (data: ChatRequestType) => {
  log.debug('[sendToFrontend] ', data);
  if (data.type === 'REQ_DEVICES') {                                   // 모달 무관, ChatProvider 단독 처리
    const targets = Array.isArray(data?.target) ? data.target : data?.target != null ? [data.target] : [];
    targets.forEach((targetId) => {
      DevicesApiManager.getDeviceInfo((result, responseData, code, message) => {
        // ... target별 결과 수집 후 마지막에 일괄 회신
        if (completed === targets.length) {
          sendToChatbot({ type: 'REQ_DEVICES', result: !hasError,
            message: hasError ? errorMessage : 'Success', deviceInfos: deviceInfos });
        }
      }, targetId);
    });
    return;
  } else if (data.type === 'REQ_OPEN_MODAL') {                         // 단말 관리 화면으로 이동해 모달 오픈
    navigate('/management/devices', { state: { targetId: data.deviceId } });
    return;
  }
  if (frontendRef.current) { frontendRef.current?.(data); return; }   // 모달이 처리
  if (data.type === 'REQ_INFO') {
    const user = sessionStorage.getItem('user');
    chatbotRef.current?.({
      type: 'REQ_INFO', result: true, message: 'Success',
      data: {
        sessionScope: 'general',                                       // 디바이스 미선택 일반 세션
        deviceId: '',
        accessToken: sessionStorage.getItem('accessToken') || '',
        user: user ? JSON.parse(user).username : '',
        role: sessionStorage.getItem('role') || '',
        roleLevel: sessionStorage.getItem('roleLevel') || '',
        isConnected: false,
        isMine: false,
        lang: localStorage.getItem('language') || 'en'
      }
    });
    return;
  }
  chatbotRef.current?.({ type: data.type, nav: data.nav, result: false, message: 'Connection device modal is not mounted' });
};
pages/monitoring/anomalyDetect/anomalyAccordionList.tsx — 이슈 펼침을 ISSUE_INFO로 챗봇에 통지
const { sendToChatbot } = useChat();
// ...
onChange={() => {
  const nextExpanded = isExpanded ? false : itemId;
  setExpandedId(nextExpanded);

  if (nextExpanded && modulePermissions.chatbot && sendToChatbot) {
    const result: ChatResponseType = {
      type: 'ISSUE_INFO',       // 챗봇이 현재 이슈를 컨텍스트로 삼도록 push
      result: true,
      message: 'Success',
      data: item                // 이상탐지 이슈 객체 그대로 (data 타입은 any 로 완화)
    };
    sendToChatbot(result);
  }
}}
