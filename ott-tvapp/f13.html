3rd Party 앱 모드 제어

assets/app_packages.properties에 normal/hotel/ott 모드별 허용 패키지(YouTube·Netflix·TVING·wavve·Disney+ 등)를 정의하고, PropertiesLoader가 읽어 DeviceAPI에 모드별 패키지 배열로 보관합니다.

기능 개요

운영 시나리오(일반/호텔/OTT)에 따라 단말에서 노출·관리할 3rd Party 앱 목록이 다릅니다. 이 목록은 코드가 아니라 자산 파일 app/src/main/assets/app_packages.properties에 normal.packages·hotel.packages·ott.packages 세 줄의 콤마 구분 패키지명으로 정의됩니다. 예를 들어 ott 모드는 YouTube·Netflix·TVING·Coupang Play·wavve·watcha·Disney+·AppleTV·YouTube Kids를 포함합니다.

PropertiesLoader가 AssetManager로 이 파일을 열어 모드별 프로퍼티를 읽고 split(",")로 배열을 만듭니다. getPackagesFromProperties()(normal)·getHotelPackagesFromProperties()(hotel)·getOttPackagesFromProperties()(ott) 세 메서드가 각각 대응합니다.

로딩 시점은 DeviceAPI.init()(관리 API 연결)으로, 결과를 정적 필드 NORMAL_PACKAGES·HOTEL_PACKAGES·OTT_PACKAGES에 보관합니다. 이후 단말 관리 동작(예: clearApplicationUserData()가 인자 없이 호출되면 OTT_PACKAGES 전체 캐시를 정리)에서 이 배열을 모드 기준으로 사용합니다. 운영 모드(SDP.isHotel/isNormal)에 따라 어떤 목록을 적용할지가 결정됩니다.

ctrl/PropertiesLoader.java · ott/DeviceAPI.java — 모드별 목록 로딩
// PropertiesLoader: assets에서 모드별 프로퍼티를 읽어 배열로 반환
public static String[] getOttPackagesFromProperties(Context context) {
    Properties properties = new Properties();
    InputStream is = context.getAssets().open("app_packages.properties");
    properties.load(is);
    String packagesString = properties.getProperty("ott.packages");
    return packagesString != null ? packagesString.split(",") : null;
}

// DeviceAPI.init(): 연결 시 모드별 목록을 정적 필드에 적재
OTT_PACKAGES    = PropertiesLoader.getOttPackagesFromProperties(activity);
NORMAL_PACKAGES = PropertiesLoader.getPackagesFromProperties(activity);
HOTEL_PACKAGES  = PropertiesLoader.getHotelPackagesFromProperties(activity);
