RCU·블루투스 연동

ctrl/IETP가 JNI 기반 RCU 프로토콜(IetpManager, libtvcoietp.so)로 리모컨 디바이스 등록·메시지를 처리하고, ctrl/Bluetooth가 BLE 스캔·페어링·연결로 블루투스 RCU/단말을 연동합니다.

기능 개요

IETP는 IetpMessageHandler를 구현한 RCU 프로토콜 처리기입니다. init()에서 IetpManager.init() 후 자기 자신을 핸들러로 등록(addHandler)합니다. 단말과 모바일/리모컨 간 통신은 디바이스 등록(onRegister)·해제(onUnregister)와 메시지 메서드(getStbStatus·tuneChannel·pushVodDetail·reserveProgram)로 이뤄지며, 등록 시 hint/암호화 검증과 내 디바이스 목록 확인을 거쳐 IetpClientInfo를 추가하고 암호화된 client id를 돌려줍니다. 암복호는 JNI 라이브러리(libtvcoietp.so, libAesJni.so)가 수행합니다.

Bluetooth는 BLE 기반 RCU/단말 연동을 담당합니다. init()으로 BluetoothAdapter를 준비하고, startScanning()이 BluetoothLeScanner.startScan()으로 KCTV BLE RCU를 탐색합니다. 페어링(startPairing)·연결(connectGatt)을 거쳐 디바이스 정보(소프트웨어 버전)·배터리 레벨 GATT 서비스를 읽고, 연결된 디바이스 목록을 관리합니다. 디바이스 삭제(deleteDevice/deleteAllDevices)도 지원합니다.

흐름. IETP가 JNI 매니저에 핸들러를 등록해 RCU 등록/메시지를 처리하고, Bluetooth가 BLE 스캔·연결로 물리적 RCU/단말을 연동합니다.

관계. IETP는 IetpMessageHandler를 구현해 IetpManager(JNI)에 등록되고, Bluetooth는 BluetoothAdapter/BluetoothLeScanner로 BLE 디바이스를 연동합니다.

핵심 코드

ctrl/IETP.java — JNI RCU 매니저에 핸들러 등록 / 디바이스 등록 처리
public static void init(Handler handler) {
    if (ietpHandler == null) ietpHandler = new IETP();
    IETP.handler = handler;
    IetpManager.init();
    IetpManager.getInstance().addHandler(ietpHandler);
}

public IetpRegisterResult onRegister(byte[] hint, byte[] encrypted) {
    String deviceId = new String(hint);
    byte[] sharedKey = getSharedKey(hint);
    if (!isValidDeviceId(hint, encrypted, sharedKey))
        return new IetpRegisterResult(false, IETP_ERROR_ENC_VALUE, -1);
    if (!isInMyDeviceList(deviceId))
        return new IetpRegisterResult(false, IETP_ERROR_NOT_REGISTER_DEVICE, -1);

    int clientId = (int) (SystemClock.uptimeMillis() % Integer.MAX_VALUE);
    IetpManager.getInstance().addClientInfo(new IetpClientInfo(clientId, sharedKey));
    clientIDs.put(hint, clientId);
    return new IetpRegisterResult(true, IETP_SUCCESS, getEncryptClientId(clientId, sharedKey));
}
ctrl/Bluetooth.java — BLE 스캐너로 RCU 탐색
public static void startScanning() {
    BluetoothLeScanner bluetoothLeScanner = btAdapter.getBluetoothLeScanner();
    // ... 필터/설정 구성
    bluetoothLeScanner.startScan(scanCallback);   // KCTV BLE RCU 탐색
}
