CAS(수신제한)

ctrl/CAS가 Digicap 계열 수신제한 시스템(MCAS)을 처리합니다. KctvPlayerManager로 단말 인증서를 검증·발급하고, 가입 상태에 따라 시청 제한을 적용하며 PKDialog 등으로 사용자 인증을 안내합니다.

기능 개요

CAS는 MCASErrorCode를 상속한 정적 컨트롤러입니다. createClient()에서 KctvPlayerManager.getInstance().initialize(...)로 CAS 엔진을 초기화하면서 EMM 주소(BuildConfig.EMM_BASE)와 이벤트 리스너(MCasEventListener)를 등록합니다. 초기화가 성공하면 isCasReady=true가 되고, 오디오 언어 등 기본 설정을 적용합니다.

init()은 전용 HandlerThread("CAS")에서 인증 절차를 수행합니다. SXCS_dci_CertVerify()로 단말 인증서 유효성을 확인하고, 오류면 doCertIssue()로 STB 인증서를 발급받은 뒤 authorize()로 CAS 가입 권한을 받습니다. 결과는 CERT_VERIFY 등 메시지로 UI에 통지됩니다.

채널 시청 시 CAS 상태(STATUS)는 MCAS_STATUS_NORMAL/MCAS_STATUS_SUSPENDED/MCAS_STATUS_NOTSUBSCRIBED 등으로 분류되며, notsubscribed()·suspended()·requestReboot() 판정에 따라 재시작·제한 안내로 이어집니다. PIN 입력이 필요한 구매/시청 제한 상황에서는 PKDialog가 표시되고, 가입 정보(SUBSCRIBE_ID)는 WebView 브릿지의 getContractId()로도 노출됩니다.

관계. CAS가 KctvPlayerManager MCAS 엔진을 초기화·인증하고, 내부 MCasEventListener로 상태를 받으며 PIN 입력은 PKDialog가 처리합니다.

핵심 코드

ctrl/CAS.java — createClient: MCAS 엔진 초기화
String emmUrl = BuildConfig.EMM_BASE;
Results result = KctvPlayerManager.getInstance().initialize(
        context, 32, deviceId, new MCasEventListener(),
        emmUrl, KctvPlayerManager.MAX_PROCESS_PRIORITY);

if (result == Results.ERROR) {
    // 초기화 실패 처리
} else {
    PlayerConfigs.getInstance().set(PlayerConfigs.KEY_AUDIO_LANGUAGE, "kor");
    isCasReady = true;
}
ctrl/CAS.java — init: 인증서 검증 → 발급/권한
MCAS_RESULT_T mcasResult = KctvPlayerManager.getInstance()
        .SXCS_dci_CertVerify(System.currentTimeMillis());
isIsCASCertified = true;
handler.sendMessage(handler.obtainMessage(CERT_VERIFY,
        "인증서 유효성 확인: " + SXC_ERROR_EN.toString(mcasResult.result)));

if (mcasResult.result != MCAS_ERROR_EN.NO_ERROR) {
    doCertIssue();          // STB 인증 요청
} else {
    isSTBCertified = true;
    authorize();            // CAS 인증 요청
}
