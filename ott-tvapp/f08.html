클라우드 연동

mod/cloud 어댑터/프록시 추상화 위에 Apex 구현(ApexCloudAdaptor·ApexCloudProxy)을 두어, Alticast 클라우드 SDK(cloud-sdk, ApexCloudManager)로 클라우드 UI/서비스를 연동합니다.

기능 개요

클라우드 연동은 추상 계층과 벤더 구현으로 분리되어 있습니다. CloudAdaptor(추상)는 클라우드 세션 상태(STATE_*)와 startCloud()·stopCloud()·keyEvent() 같은 공통 흐름을 정의하고, CloudProxy(추상)는 개별 클라우드 화면 세션을 표현합니다. CloudAdaptorFactory.getInstance(APEX)가 구현체로 ApexCloudAdaptor를 생성·캐시합니다.

실제 SDK 호출은 ApexCloudProxy가 담당합니다. init()에서 ApexCloudManager·ApexCloudDoc을 만들고 리스너를 등록한 뒤 ApexCloudView와 연결합니다. ApexCloudAdaptor.activateCloudApp()은 메인 스레드가 아닌 별도 Executor에서 apexCloudManager.start()를 호출해 클라우드 세션을 시작하고, 리모컨 입력은 sendKeyEvent()가 HotKey.map()으로 변환해 onEvent()로 전달합니다.

앱 단의 진입점은 ctrl/Cloud로, CloudAdaptorFactory로 어댑터를 얻어 startCloud()를 호출하고 홈키(homeKey())·시작 여부(isStarted()) 등을 PlaybackActivity와 연계합니다.

흐름. Cloud가 팩토리로 Apex 어댑터를 얻어 startCloud()를 호출하면 프록시가 ApexCloudManager 세션을 시작하고, 키 입력은 어댑터를 거쳐 SDK로 전달됩니다.

핵심 코드

mod/cloud/CloudAdaptorFactory.java — Apex 어댑터 생성/캐시
public static CloudAdaptor getInstance(String name) {
    if (!instances.containsKey(name)) {
        switch (name) {
            case APEX:
                instances.put(name, new ApexCloudAdaptor());
                break;
        }
    }
    return (CloudAdaptor) instances.get(name);
}
mod/cloud/apex/ApexCloudAdaptor.java — Apex SDK 세션 시작/키 전달
protected CloudProxy activateCloudApp(Object surface, Object menu, Object params, boolean isFHD) {
    ApexCloudProxy proxy = new ApexCloudProxy();
    proxy.init(menu.toString(), (ApexCloudView) surface, mProp, isFHD);
    activateCloudApp(proxy);            // Executor 스레드에서 apexCloudManager.start()
    return proxy;
}

protected void sendKeyEvent(CloudProxy cloudProxy, int keyCode, int type) {
    short code = (short) HotKey.map(keyCode);
    ApexCloudProxy proxy = (ApexCloudProxy) cloudProxy;
    if (proxy.apexCloudManager.isConnecting()) {
        if (type == 0 || type == 2) proxy.apexCloudManager.onEvent(KeyEvent.ACTION_DOWN, code, true);
        if (type == 1 || type == 2) proxy.apexCloudManager.onEvent(KeyEvent.ACTION_UP, code, true);
    }
}
