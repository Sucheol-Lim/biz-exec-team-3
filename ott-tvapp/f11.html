푸시 티커

ctrl/Push가 푸시 서버에 단말을 등록하고 메시지를 수신하면, 추상 comp/TickerView를 상속한 comp/PushTickerView가 공지·자막 티커를 화면 하단에 스크롤 애니메이션으로 표시합니다.

기능 개요

Push는 HTTP를 상속한 정적 컨트롤러입니다. register()가 백그라운드 스레드에서 가입자 ID(SDP.accountId)·그룹 ID·MAC·IP·수신 포트(PUSH_PORT=8081)를 JSON으로 만들어 PUSH_BASE 서버에 등록 요청을 보내고, 응답이 "OK"면 수신 서버(startServer())를 띄웁니다. 실패 시 일정 시간 뒤 재등록을 시도합니다.

수신 메시지는 종류별 상수(MSG_SIMPLE·MSG_NORMAL·MSG_EMERGENCY·MSG_TICKER·MSG_IMAGE·MSG_CHANNEL)로 구분됩니다. 티커 메시지는 PlaybackActivity 핸들러를 거쳐 PushTickerView로 전달됩니다. 티커 외에 sys.checkin·sys.checkout 같은 호텔 운영 명령도 처리하는데, 체크인/아웃 시 수신 서버를 멈추고 설정 초기화·HDMI CEC 비활성화(DeviceAPI.setHdmiCecState(false))·계정 데이터 정리를 거쳐 계정을 갱신합니다.

PushTickerView는 추상 TickerView(FrameLayout 기반)의 구현체로, setContent(parentHandler, text, repeat, interval, speed, licenseEnd, font, key)에서 텍스트·폰트 크기를 설정하고 TranslateAnimation으로 우→좌 스크롤 애니메이션을 만들어 반복 표시합니다. 새 티커가 들어오면 기존 티커를 정리하고 교체합니다.

흐름. Push가 서버에 등록·수신을 시작하고, 티커 메시지가 도착하면 UI 핸들러를 거쳐 PushTickerView가 스크롤 애니메이션으로 표시합니다.

관계. Push는 HTTP 기반 등록/수신을 맡고, 추상 TickerView를 PushTickerView(및 AVTickerView)가 구현해 스크롤 표시를 담당합니다.

핵심 코드

ctrl/Push.java — register: 단말 정보로 푸시 서버 등록
JSONObject param = new JSONObject();
param.put("ssid", SDP.accountId);
param.put("group_id", SDP.groupId());
param.put("device_id", DeviceAPI.getEthernetMacAddress());
param.put("ip", ip);
param.put("port", PUSH_PORT);     // 8081

String resp = post(BuildConfig.PUSH_BASE, URL_CREATE, null, param);
if ("OK".equals(resp)) {
    registeredIP = ip;
    register = true;
    startServer();                // 푸시 수신 서버 기동
} else {
    register(10);                 // 재시도
}
comp/PushTickerView.java — setContent: 텍스트 스크롤 애니메이션 구성
ticker = findViewById(R.id.push_ticker_view);
ticker.setTextSize(TypedValue.COMPLEX_UNIT_PX, 30);
if (font > 0) ticker.setTextSize(TypedValue.COMPLEX_UNIT_PX, font);
ticker.setText(text);

int startX = 1210 + DELAYSPACE;
int textWidth = getTextWidth(ticker, text);
animation = new TranslateAnimation(startX, -textWidth - XTODELTA, 0, 0);  // 우→좌 스크롤
long duration = makeDuration(speed, startX + textWidth + XTODELTA);
animation.setDuration(duration);
animation.setInterpolator(new LinearInterpolator());
