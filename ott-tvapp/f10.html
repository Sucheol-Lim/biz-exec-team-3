NMS 단말 관리

ott/Agent와 ott/AgentController가 nms·qi 패키지를 통해 CPU·메모리·네트워크·SI 등 단말 상태를 수집해 NMS 서버로 리포트하고, 관리 앱의 제어 액션을 처리합니다.

기능 개요

Agent는 NMS(Network Management System) 리포팅의 중심입니다. 전용 ThreadPoolExecutor에서 MgmtManager(mgmt 라이브러리)와의 세션을 맺고, 네트워크 변경·서비스 상태 변경 등 이벤트가 오면 DataBuilder로 항목별 데이터(공통/CPU/메모리/플래시/네트워크/IO/설정/RCU/시스템/SI/HDMI/Google/VOD/IPTV)를 조립합니다. 각 이벤트는 NMSEventID(KE04, KH02, KH05~KH07 등) 코드로 식별됩니다.

조립된 메시지는 sendData(eventId, msg)가 NmsDataSender(mgmtcli)의 sendNmsData()로 전송합니다. 실제 패킷 전송은 nms/NMSDataSender(UDP 소켓 send)가 담당하고, 재생 품질 정보(QI)는 qi/QIDataSendThread가 별도 포트(BuildConfig.QI_PORT)로 전송합니다. QI 데이터는 QIHandler의 주기/실시간 콜백으로 수집됩니다.

AgentController는 관리 앱(com.kctvjeju.mgmt)에서 내려오는 제어 액션을 정의·처리합니다. 주기 상태 리포트(periodicStatus), 서비스 변경 리포트, 구매 PIN 초기화·등급 초기화·해상도/HDMI-CEC 설정 등 다양한 원격 제어 액션 문자열을 보유합니다.

sequenceDiagram autonumber participant ACT as PlaybackActivity participant AG as ott/Agent participant MG as MgmtManager participant DB as nms/DataBuilder participant SND as NmsDataSender / NMSDataSender participant NMS as NMS 서버 participant QI as qi/QIDataSendThread ACT->>AG: init(activity) AG->>MG: startClientSessionReconnect() MG-->>AG: nmsDataSenderClientStart(NmsDataSender) Note over AG: 이벤트 발생 (네트워크/서비스 상태 변경) AG->>DB: makeCommonData / makeCPUData / makeNetData ... DB-->>AG: 항목 데이터 AG->>SND: sendData(eventId, msg) → sendNmsData() SND->>NMS: UDP 패킷 전송 QI->>NMS: QI(품질) 데이터 전송 (QI_PORT)

흐름. Agent가 mgmt 세션을 맺고, 이벤트마다 DataBuilder로 상태 데이터를 조립해 NmsDataSender로 NMS에 전송하며 QI는 별도 스레드가 보냅니다.

관계. Agent가 DataBuilder로 상태를 모아 NMS로 보내고, AgentController가 원격 제어 액션을, QIHandler/QIDataSendThread가 품질 정보를 담당합니다.

핵심 코드

ott/Agent.java — 이벤트별 상태 데이터 조립 후 전송
case MSG_NETWORK_CONNECTED:
    buildData(builder, dataBuilder.makeCommonData(NMSEventID.KE04));
    buildData(builder, dataBuilder.makeCPUData());
    buildData(builder, dataBuilder.makeMemoryData());
    buildData(builder, dataBuilder.makeFlashData());
    buildData(builder, dataBuilder.makeNetData());
    buildData(builder, dataBuilder.makeConfigData());
    buildData(builder, dataBuilder.makeSIData());
    buildData(builder, dataBuilder.makeVODData());
    buildData(builder, dataBuilder.makeIPTVData());
    sendData(NMSEventID.KE04, builder.toString());
    break;
ott/Agent.java — sendData: mgmt 클라이언트로 NMS 전송
private static void sendData(String eventId, String msg) {
    if (inmsSender != null) {
        inmsSender.sendNmsData(eventId, msg);   // NmsDataSender (mgmtcli)
        Log.d(TAG, "inmsSender: sendNMSData");
    }
}
