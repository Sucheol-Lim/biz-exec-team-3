WebView 하이브리드 UI

서버에서 내려받은 iframe 웹 UI를 WebView로 로딩하고, ott/WebServiceHandler가 @JavascriptInterface 브릿지(androidTvLocal)로 단말 정보·재생·CAS 기능을 웹에 노출합니다.

기능 개요

화면 UI 대부분은 서버에서 내려받은 iframe(웹 UI 패키지)을 WebView로 로딩해 표현합니다. 싱글턴 WebServiceHandler가 WebView와 네이티브를 잇는 핵심으로, init()으로 컨테이너·WebView·부모 핸들러를 받아두고 startAction(url)에서 JavaScript를 활성화한 뒤 URL을 로드하고 javascript:onStart()를 호출해 웹 앱을 기동합니다.

initWebView()는 addJavascriptInterface(new AndroidBridge(), "androidTvLocal")로 네이티브 브릿지를 주입합니다. 웹은 이 인터페이스를 통해 getCustomerId()(가입자 ID = SDP.accountId), getContractId()(CAS.SUBSCRIBE_ID), getStbModel()·getMacAddress()·getIP()·getResolution() 같은 단말/가입자 정보와 resizeScreen()·checkPurchasePin() 등 재생·인증 기능을 호출합니다.

웹 앱 시작/종료는 WEB_APP_STARTED·WEB_APP_CLOSED 메시지로 부모(PlaybackActivity) 핸들러에 통지됩니다. 종료 시 stopWebService()가 폼 데이터·캐시를 비우고 about:blank로 전환해 자원을 회수합니다.

관계. 싱글턴 WebServiceHandler가 내부 AndroidBridge를 JS 인터페이스로 주입하고, 브릿지 메서드가 SDP·CAS 등 네이티브 상태를 웹에 전달합니다.

핵심 코드

ott/WebServiceHandler.java — startAction: WebView 로드 + onStart 호출
public void startAction(String url) {
    initWebView();
    parentHandler.sendMessage(parentHandler.obtainMessage(WEB_APP_STARTED));
    rootContainer.setVisibility(View.VISIBLE);
    rootContainer.requestFocus();

    webView.post(() -> {
        webView.getSettings().setJavaScriptEnabled(true);
        webView.setBackgroundColor(Color.TRANSPARENT);
        webView.loadUrl(url);
        webView.setVisibility(View.VISIBLE);
        webView.loadUrl("javascript:onStart()");
    });
}
ott/WebServiceHandler.java — AndroidBridge: 네이티브 정보를 웹에 노출
webView.addJavascriptInterface(new AndroidBridge(), ANDROID_TV_LOCAL); // "androidTvLocal"

private class AndroidBridge {
    @JavascriptInterface
    public boolean resizeScreen(int x, int y, int width, int height) {
        Config.resize(new Rect(x, y, x + width, y + height));
        return true;
    }
    @JavascriptInterface
    public String getCustomerId() { return SDP.accountId; }       // 가입자 ID
    @JavascriptInterface
    public String getContractId() { return CAS.SUBSCRIBE_ID; }    // 계약/가입 ID
    @JavascriptInterface
    public String getIP() { return NetworkStateManager.getInstance().getHostAddress(); }
}
