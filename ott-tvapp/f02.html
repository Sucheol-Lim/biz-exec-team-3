실시간 채널 시청

ctrl/Player가 SoorynPlayer 계열 KctvLivePlayer로 멀티캐스트 라이브 채널을 재생하고, 채널 맵·프로그램 정보는 ctrl/Channels ContentProvider(com.alticast.kctv.provider)로 관리합니다.

기능 개요

라이브 채널 재생은 ctrl/Player가 총괄합니다. Player.init()이 내부 Live 객체와 이벤트 리스너(KctvPlayerEventListenerImpl)·결과 콜백(KctvPlayerResultCallbackImpl)을 만들고, SurfaceView가 유효해지는 시점에 KctvLivePlayer를 생성합니다. 사내 SoorynPlayer AAR을 임베드해 멀티캐스트 라이브 스트림을 받아 그립니다.

채널 전환은 Player.tuneLiveChannel(EPGChannel toGo, ...)이 입구입니다. 같은 채널이면 무시하고, 오디오 채널 전환·시청 차단(Block)·호텔 프로모·CH-VOD 여부를 점검한 뒤 Live.setDataSource()가 채널 스트림 URI와 서비스 ID로 livePlayer.playback()을 호출합니다. 채널 요청/변경은 CHANNEL_REQUEST·CHANNEL_CHANGED 메시지로 UI 핸들러에 통지됩니다.

채널·편성 데이터는 ctrl/Channels가 ContentProvider로 노출합니다. 매니페스트에 authorities="com.alticast.kctv.provider"로 등록되어 있고, query()가 키즈/일반 모드에 따라 채널 맵(ChannelMap)을 순회하며 번호·이름·아이콘(차단/선호/유료/오디오/VOD) 컬럼을 MatrixCursor로 반환합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant UI as PlaybackActivity (키 입력) participant PL as ctrl/Player participant LV as Player.Live participant KP as KctvLivePlayer (SoorynPlayer) participant CH as ctrl/Channels participant H as MyHandler (UI) UI->>PL: tuneLiveChannel(toGo, needStop) PL->>PL: 같은 채널 / Block / 호텔프로모 / CH-VOD 점검 PL->>H: obtainMessage(CHANNEL_REQUEST, toGo) PL->>LV: setDataSource(toGo, needStop, msgDelay) LV->>KP: playback(Uri, serviceId, true, audioMode) KP-->>PL: KctvPlayerEventListener 이벤트 PL->>H: obtainMessage(CHANNEL_CHANGED, msgObj) H->>CH: query(provider Uri, selection) CH-->>H: MatrixCursor (번호/이름/아이콘) H->>UI: OSD / 채널 정보 갱신

흐름. 키 입력이 tuneLiveChannel()로 들어와 차단·모드 점검 후 Live.setDataSource() → playback()으로 스트림을 시작하고, 채널 메타는 Channels ContentProvider가 공급합니다.

관계. Player가 내부 Live를 소유하고 KctvLivePlayer로 재생하며, Channels ContentProvider가 ChannelMap의 EPGChannel을 커서로 노출합니다.

핵심 코드

ctrl/Player.java — Live.setDataSource: 채널 URI로 playback 시작
if (livePlayer == null) {
    playerLive.init(context, mSurfaceView, mSubtitleView);
}
if (livePlayer != null) {
    if (needStop) livePlayer.stop();

    String uri = toGo.getStream();
    if (uri == null) uri = "";
    livePlayer.setRestartPlayerWhenErrorOccurs(true);
    setAudioLanguage();
    boolean audioMode = Config.getAudioOutput() == Config.AUDIO_OUTPUT_AC3;
    livePlayer.playback(Uri.parse(uri), (short) toGo.getServiceId(), true, audioMode);
}
ctrl/Channels.java — ContentProvider.query: 채널 맵을 커서로 노출
public Cursor query(Uri uri, String[] projection, String selection,
                    String[] selectionArgs, String sortOrder) {
    MatrixCursor cursor = new MatrixCursor(new String[]{ BaseColumns._ID, "num", "name", "icon" });
    ChannelMap target = Config.isKids ? surfableKids : accessible;
    for (EPGChannel ch : target.values()) {
        if (!skipChannel.containsKey(ch.getNumber())
            && String.valueOf(ch.getNumber()).startsWith(selection)) {
            // 아이콘 우선순위: 시청제한 > 선호 > 홍보/CH-VOD/오디오/유료
            int icon = 0;
            if (isBlocked(ch)) icon = 1;
            else if (isFav(ch)) icon = 2;
            else if (isPromo(ch)) icon = 3;
            else if (isChVod(ch)) icon = 4;
            else if (isAudio(ch)) icon = 5;
            else if (isPay(ch)) icon = 6;
            cursor.addRow(new Object[]{ ch.getServiceId(),
                String.format("%03d", ch.getNumber()), ch.getName(), icon });
        }
    }
    return cursor;
}
