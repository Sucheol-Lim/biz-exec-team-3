OOB / Inband SI 수신

ott/OOBService가 MulticastOOBTunnel 멀티캐스트 OOB 터널로 채널·EIT·앱 정보 등 서비스 정보(SI)를 수신하고, ctrl/Inband가 인밴드 데이터(부팅 이미지·iframe·곡 정보 등)를 처리합니다.

기능 개요

SI(Service Information)는 OOB(Out-Of-Band)와 Inband 두 경로로 들어옵니다. OOBService는 매니페스트에 등록된 Service로, runService()에서 별도 스레드를 띄워 사내 OobServiceInfo SDK를 초기화합니다. 이때 라이브/개발 서버 구분(BuildConfig.LIVE_SVR)과 TS 머지 여부(OOB.IS_MERGE_TS)에 따라 SI1/AEIT01~4/SI2/SI3/DST용 MulticastOOBTunnel 배열(PID·멀티캐스트 IP·포트·타입)을 구성해 등록합니다.

OOB 서비스가 기동되면(onOobServiceStarted) ChannelManager에 채널 목록 갱신 리스너를 붙여 채널 맵 변경을 받아옵니다. EIT/ETT 개수 등은 getEitCnt()·getEttCnt()로 조회됩니다.

Inband는 인밴드 데이터를 다룹니다. init()이 ScheduledExecutorService로 일정 시간 뒤 readToFile()을 실행해 부팅 이미지(boot_normal.jpg/boot_hotel.jpg), iframe, 라디오 곡 정보(loadAudioInfo) 등을 받아 단말 로컬 파일로 저장·플랫폼에 적용합니다. 호텔 모드 여부에 따라 부팅 이미지를 분기합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant ACT as PlaybackActivity participant OOB as ott/OOBService participant OSI as OobServiceInfo (SDK) participant TUN as MulticastOOBTunnel participant CM as ChannelManager participant IB as ctrl/Inband ACT->>OOB: runService(playbackActivity) OOB->>OSI: initListener(OobServiceStartedListener) OOB->>TUN: new MulticastOOBTunnel(pid, ip, port, type) x N OOB->>OSI: setIpTunnels(tunnels, n) + init("") OSI-->>OOB: onOobServiceStarted() OOB->>CM: addChanelListUpdateListener(...) CM-->>OOB: onChannelListUpdated() (채널 맵 갱신) ACT->>IB: Inband.init(handler, context) IB->>IB: schedule readToFile() (부팅이미지/iframe/곡정보)

흐름. OOBService가 멀티캐스트 터널을 구성·기동해 채널 SI를 받고, Inband가 지연 스케줄로 인밴드 리소스를 읽어 단말에 반영합니다.

관계. OOBService가 OobServiceInfo SDK에 MulticastOOBTunnel 배열을 등록해 OOB SI를 받고, Inband는 스케줄러로 인밴드 리소스를 처리합니다.

핵심 코드

ott/OOBService.java — 멀티캐스트 OOB 터널 구성 후 등록
OobServiceInfo.getInstance().initListener(new OobServiceStartedListener() {
    public void onOobServiceStarted() {
        oobServiceStarted = true;
        ChannelManager.getInstance().addChanelListUpdateListener(channelListUpdateListener);
        handler.sendEmptyMessageDelayed(0, WAITING_TIME);
    }
});

MulticastOOBTunnel[] tunnels = new MulticastOOBTunnel[7];
tunnels[0] = new MulticastOOBTunnel(0x1ffc, "239.50.2.1", 4240, MulticastOOBTunnel.TUNNEL_TYPE_SI1);
tunnels[1] = new MulticastOOBTunnel(0x1dd0, "239.50.2.2", 4241, MulticastOOBTunnel.TUNNEL_TYPE_AEIT01);
// ... AEIT23 / AEIT4 / SI2 / SI3 / DST
OobServiceInfo.getInstance().setIpTunnels(tunnels, tunnels.length);
OobServiceInfo.getInstance().init("");
ctrl/Inband.java — init: 지연 스케줄로 인밴드 리소스 읽기
public static void init(Handler handler, Context context) {
    Inband.handler = handler;
    Inband.context = context;
    scheduledExecutorService = Executors.newSingleThreadScheduledExecutor();
    scheduledExecutorService.schedule(() -> {
        readToFile(false);   // 부팅 이미지/iframe/곡 정보 등 인밴드 데이터 처리
    }, 20, TimeUnit.SECONDS);
}
