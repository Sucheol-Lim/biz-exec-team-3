자동 재부팅 스케줄

reboot 패키지의 RebootScheduler가 WorkManager로 새벽 시간대 재부팅 작업을 예약하고, RebootWorker가 시각을 확인해 PlaybackActivity에 팝업 브로드캐스트를 보내며, RebootCheckWorker가 주기 점검을 담당합니다.

기능 개요

장시간 켜져 있는 셋톱박스의 안정성을 위해 일정 주기마다 단말을 새벽 시간대에 자동 재부팅합니다. RebootScheduler.scheduleRebootIfNeeded()는 최초 실행 시각(Config.KEY_FIRST_LAUNCH)을 기록하고, 기준 일수(상용 5일/개발 1일)가 지났으면 새벽 3~5시(개발 시 다른 값) 사이 랜덤 시각을 골라 그 시각까지의 지연을 계산합니다.

계산된 지연으로 OneTimeWorkRequest(RebootWorker.class)를 만들어 WorkManager.enqueue()에 등록합니다. RebootWorker.doWork()는 실행 시점이 유효한 시간대(START_TIME ~ START_TIME+END_TIME)인지 다시 확인한 뒤, PlaybackActivity.ACTION_SHOW_POPUP 브로드캐스트를 보내 액티비티가 재부팅 안내 팝업을 띄우도록 합니다.

PlaybackActivity는 ACTION_SHOW_POPUP 리시버에서 RebootDialog를 띄워 시청 중이 아닐 때 사용자 안내 후 재부팅을 진행합니다. 별도로 RebootCheckWorker는 PeriodicWorkRequest(1일 주기)로 등록되어 재부팅 필요 여부를 주기적으로 점검합니다.

흐름. 기준 일수 경과 시 새벽 랜덤 시각으로 RebootWorker를 예약하고, 워커가 시간대를 재확인해 팝업 브로드캐스트 → RebootDialog → 재부팅으로 이어집니다.

핵심 코드

reboot/RebootScheduler.java — 기준 일수 경과 시 새벽 랜덤 시각 예약
long fiveDaysMillis = TimeUnit.DAYS.toMillis(CHECK_DAY);   // 상용 5일 / 개발 1일
if (now - firstLaunch >= fiveDaysMillis) {
    Random random = new Random();
    randomHour   = START_TIME + random.nextInt(END_TIME); // 새벽 3~5시(상용)
    randomMinute = random.nextInt(60);
    randomSecond = random.nextInt(60);
    long targetTime = getNextTriggerTime(randomHour, randomMinute, randomSecond);
    long delay = targetTime - now;

    OneTimeWorkRequest workRequest = new OneTimeWorkRequest.Builder(RebootWorker.class)
            .setInitialDelay(delay, TimeUnit.MILLISECONDS)
            .build();
    WorkManager.getInstance(context).enqueue(workRequest);
}
reboot/RebootWorker.java — 시간대 재확인 후 팝업 브로드캐스트
public Result doWork() {
    Calendar now = Calendar.getInstance();
    int currentHour = now.get(Calendar.HOUR_OF_DAY);
    if (currentHour < RebootScheduler.START_TIME
            || currentHour >= (RebootScheduler.START_TIME + RebootScheduler.END_TIME)) {
        return Result.success();   // 유효 시간대 아니면 취소
    }
    Intent intent = new Intent(PlaybackActivity.ACTION_SHOW_POPUP);
    intent.putExtra("title", "시스템 알림");
    intent.addFlags(Intent.FLAG_INCLUDE_STOPPED_PACKAGES);
    getApplicationContext().sendBroadcast(intent);
    return Result.success();
}
