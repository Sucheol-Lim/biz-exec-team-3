VOD / CH-VOD 재생

ctrl/VOD가 KctvPlayer 계열 KctvVoDPlayer로 HLS(playlist.m3u8) 기반 VOD·채널형 VOD를 재생합니다. Legacy의 RTSP 전송 방식을 HLS로 전환한 결과입니다.

기능 개요

VOD 재생은 라이브와 별도의 ctrl/VOD 클래스가 담당합니다. VOD.createPlayer()로 SurfaceView 홀더를 준비한 뒤, 실제 재생 시점에 KctvVoDPlayer(KctvPlayer OTT 엔진) 인스턴스를 만들어 HLS 스트림을 재생합니다. 일반 VOD는 playVOD(), 홍보/예고편은 playPromoVOD()·startPromoVOD()가 진입점입니다.

재생 URL은 VODInfo.makeUrl(BuildConfig.HLS_BASE)로 만들어지며, 자산명·요청 ID·재생 위치 등을 담은 VODInfo가 /kctv/ott/playlist.m3u8 형태의 HLS 플레이리스트 주소를 구성합니다. 이 base 주소는 빌드 플레이버(livePublish/develop)에 따라 BuildConfig로 주입됩니다.

채널형 VOD(CH-VOD)는 라이브 채널 목록 안에 존재하지만 재생 매체는 VOD입니다. 라이브 튜닝 흐름(Player.tuneLiveChannel)에서 Channels.isChVod()로 판별되면 라이브 플레이어를 멈추고 VOD 재생 경로로 넘어가, 라이브와 VOD 재생기가 동일 Surface를 번갈아 사용합니다.

흐름. 라이브 재생을 멈추고 VODInfo로 HLS URL을 만든 뒤 KctvVoDPlayer.playback()으로 VOD를 재생합니다. CH-VOD도 동일 경로로 합류합니다.

클래스 다이어그램

관계. VOD가 VODInfo로 HLS URL을 만들고 KctvVoDPlayer로 재생하며, 진입 시 Player.stop()으로 라이브를 양보받습니다.

핵심 코드

ctrl/VOD.java — playVOD: HLS URL 구성 후 KctvVoDPlayer 재생
releasePlayer();
Player.stop(isTrailer ? false : true);   // 라이브 정지(또는 트레일러용)

m_vodInfo = new VODInfo(assetName, requestIDs, file, posInSec * 1000L, vodType);
String url = m_vodInfo.makeUrl(BuildConfig.HLS_BASE);   // .../playlist.m3u8

try {
    vodPlayer = new KctvVoDPlayer(ID_VOD, mContext, mSurfaceHolder.getSurface(), VOD::onResultReceived);
    vodPlayer.addKctvPlayerListener(playerEventListener);
    vodPlayer.setEosTime(EOS_TIME);
    boolean audioMode = Config.getAudioOutput() == Config.AUDIO_OUTPUT_AC3;
    Results result = vodPlayer.playback(url, m_vodInfo.getPosition(), audioMode);
} catch (KctvPlayerException e) {
    e.printStackTrace();
}
ott/VODInfo.java — makeUrl: HLS 플레이리스트 주소 조립
public String makeUrl(String base) {
    return base + "/kctv/ott/playlist.m3u8" + /* 자산/요청 파라미터 부가 */ ...;
}
