미니 EPG

comp/MiniEpgBar가 현재 채널과 주변 편성 정보를 화면 하단 오버레이로 표시하고, comp/MiniEpgDialog가 예약·리마인더·키즈 잠금·부팅 등 다양한 타입의 미니 EPG 다이얼로그를 제공합니다.

기능 개요

MiniEpgBar는 RelativeLayout을 상속한 네이티브 오버레이 뷰입니다. 시청 중 OK/방향키 입력에 반응해 show()·showByOk()가 호출되며, Player.currentCh를 기준으로 Programs.getPrograms(channel)로 현재·이전·다음 편성(EPGProgram[])을 가져와 좌우 화살표로 둘러볼 수 있게 표시합니다. 노출 시간은 Config.miniEpgDur()로 제어합니다.

MiniEpgDialog는 Dialog 기반으로, 생성 시 전달하는 타입 상수에 따라 화면이 달라집니다. TYPE_BOOTING(부팅 진행), TYPE_RESERVE_OK/TYPE_REMINDER(시청 예약·알림), TYPE_KIDS_LOCK/TYPE_KIDS_ALERT(키즈 모드 제한), TYPE_WELCOME/TYPE_HOTEL_PROMO(호텔 환영·홍보) 등 다수의 시나리오를 한 클래스가 담당합니다.

설계 포인트
미니 EPG는 WebView UI와 별개로 동작하는 네이티브 오버레이입니다. 빠른 채널 둘러보기에 필요한 편성 정보를 웹 라운드트립 없이 즉시 그리기 위해, 편성 데이터(Programs)와 직접 결합한 경량 뷰로 구현되어 있습니다.

핵심 코드

comp/MiniEpgBar.java — 현재 채널 편성으로 미니 EPG 표시
public EPGProgram showByOk() {
    duration = Config.miniEpgDur();
    return show(Player.currentCh, true);
}

private EPGProgram show(EPGChannel channel, boolean byOk) {
    miniEpgByOk = byOk;
    if (channel == null) return null;
    miniEpgCh = channel;
    progs = Programs.getPrograms(channel);     // 이전/현재/다음 편성
    progIdx = 0;
    findViewById(R.id.arrow_miniepg_popular_r)
        .setVisibility((Config.isKids || SDP.isHotel) ? INVISIBLE : VISIBLE);
    // ... 편성 정보 렌더 + 자동 숨김 타이머
}
