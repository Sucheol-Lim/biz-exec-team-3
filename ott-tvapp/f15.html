기능 개요

다국어 지원은 Android 리소스 한정자로 구성됩니다. 기본 res/values/strings.xml 외에 영어(values-en)·일본어(values-ja)·중국어(values-zh) strings.xml을 두어 외국인 시청자가 많은 호텔 등 환경에 대응합니다.

언어 적용은 PlaybackActivity.updateLang()이 담당합니다. Config.locale()로 선택 언어를 읽어 현재 로케일과 비교하고, 달라졌으면 Configuration.setLocale()과 함께 Android 13+ LocaleManager.setApplicationLocales()로 앱 로케일을 바꾸고, DeviceAPI.setDeviceLocale()로 단말(시스템) 언어까지 동기화합니다. 최근 커밋(2026-04-17)에서 "언어 변경 시 Android 설정까지 변경"되도록 보강된 부분입니다.

호텔 모드는 부팅 직후 afterBooting()에서 분기됩니다. 키즈 모드 제한이면 TYPE_KIDS_LOCK 다이얼로그를, 호텔 welcome iframe 표시 설정(HOTEL_SHOW_WELCOME_IFRAME_YN)이 켜져 있으면 TYPE_WELCOME 다이얼로그(환영 화면)를 띄운 뒤 플래그를 끕니다. 호텔/키즈 여부(SDP.isHotel·Config.isKids)는 채널 노출·OSD·홍보 iframe 등 앱 전반의 동작에 영향을 줍니다.

핵심 코드

PlaybackActivity.java — updateLang: 앱·시스템 언어 동기화
private void updateLang() {
    Locale locale = Config.locale();
    Resources res = getResources();
    Locale cur = res.getConfiguration().getLocales().get(0);
    if (cur.equals(locale)) return;          // 변경 불필요

    Configuration config = new Configuration(res.getConfiguration());
    config.setLocale(locale);

    LocaleManager localeManager = getSystemService(LocaleManager.class);
    if (localeManager != null) {
        localeManager.setApplicationLocales(LocaleList.forLanguageTags(locale.toLanguageTag()));
    }
    DeviceAPI.setDeviceLocale(locale.getLanguage());   // 시스템(단말) 언어까지 변경
}
PlaybackActivity.java — afterBooting: 키즈/호텔 welcome 분기
Channels.checkKidsMode();
if (Config.isKids && Config.is(Config.KIDS_MODE_RESTRICTION_ON, Config.ON)) {
    Config.isKidsLock = true;
    new MiniEpgDialog(this, MiniEpgDialog.TYPE_KIDS_LOCK).show();
} else if (Config.is(Config.HOTEL_SHOW_WELCOME_IFRAME_YN, Config.YES)) {
    welcome = new MiniEpgDialog(this, MiniEpgDialog.TYPE_WELCOME);
    welcome.show();
    Config.set(Config.HOTEL_SHOW_WELCOME_IFRAME_YN, Config.NO);
}
