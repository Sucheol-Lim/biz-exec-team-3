기능 개요

검색은 Android의 검색 제안(Search Suggestion) 메커니즘 위에 구현되어 있습니다. LocalSearchProvider는 권한 com.kctvjeju.tvapp.search로 exported 등록된 ContentProvider로, 메타데이터 SupportedSwitchActionType=CHANNEL|TVINPUT을 선언해 시스템(및 음성 검색)에서 "N번 채널로 전환" 같은 액션형 질의를 받을 수 있습니다.

query()는 URI 마지막 세그먼트에서 검색어를 추출하고, URI 파라미터로 액션 타입(SUGGEST_PARAMETER_ACTION)과 결과 제한을 읽습니다. 채널 전환 액션이면서 질의가 "번"으로 끝나면 숫자만 잘라낸 뒤, TvProviderSearch.search()로 결과를 모아 SearchManager 표준 컬럼(SUGGEST_COLUMN_*)으로 구성된 MatrixCursor를 반환합니다.

TvProviderSearch는 SearchInterface를 구현하며 액션에 따라 채널(searchChannels)·입력(searchInputs)·VOD(searchVod)·프로그램(searchPrograms)을 순차 검색합니다. 모호한 통합 검색일 때는 채널을 먼저 찾고, 제한이 1이면 입력을, 마지막으로 TvContract.Programs 제목/설명을 검색합니다.

search/LocalSearchProvider.java — query: 질의 파싱 후 검색 위임
String query = uri.getLastPathSegment();
if (query == null || "dummy".equals(query)) return null;

SearchInterface search = new TvProviderSearch(getContext());
int action = getQueryParamater(uri, SUGGEST_PARAMETER_ACTION, DEFAULT_SEARCH_ACTION);
int limit  = getQueryParamater(uri, SearchManager.SUGGEST_PARAMETER_LIMIT, DEFAULT_SEARCH_LIMIT);

List<SearchResult> results = new ArrayList<>();
if (!TextUtils.isEmpty(query)) {
    if (action == TvProviderSearch.ACTION_TYPE_SWITCH_CHANNEL && query.endsWith("번")) {
        query = query.substring(0, query.indexOf("번"));   // "7번" → "7"
    }
    results.addAll(search.search(query, limit, action));
}
return createSuggestionsCursor(results, action);
search/TvProviderSearch.java — 액션별 통합 검색
public List<SearchResult> search(String query, int limit, int action) {
    List<SearchResult> results = new ArrayList<>();
    Set<Integer> channelsFound = new HashSet<>();
    if (action == ACTION_TYPE_SWITCH_CHANNEL) {
        results.addAll(searchChannels(query, channelsFound, 1));
    } else {
        results.addAll(searchChannels(query, channelsFound, 1));   // 채널 우선
        if (limit == 1) results.addAll(searchInputs(query, limit));
        results.addAll(searchPrograms(query, null,
            new String[]{ TvContract.Programs.COLUMN_TITLE,
                          TvContract.Programs.COLUMN_SHORT_DESCRIPTION }, channelsFound, 1));
    }
    return results;
}
