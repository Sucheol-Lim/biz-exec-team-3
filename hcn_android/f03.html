라이브 채널 재생 · 튜닝

TaurusLiveTuneManager가 채널 전환 요청을 받아 튜닝 스레드로 정규화하고, TaurusPlayerManager가 CSP 플레이어(csp-module)로 실제 라이브 영상을 출력합니다.

기능 개요

채널 재생은 튜닝(어떤 채널로 갈지 결정)과 플레이(영상 디코드/출력)로 나뉩니다. 튜닝은 epg-module의 TaurusLiveTuneManager가 담당합니다. 채널 번호 입력, 채널 업/다운, 즐겨찾기 이동, EPG에서 채널 선택, 부팅 직후 마지막 채널 진입 등 모든 경로가 tuneCh·tuneChUp·tuneChDown·tuneChDefault 같은 진입 메서드로 들어오며, 내부적으로 모두 tuneChannelImpl(tuneType, ...) 한 곳으로 모입니다. tuneType은 TUNE_CHANNEL_OBJECT·TUNE_CHANNEL_UP·TUNE_CHANNEL_BOOT 등으로 구분됩니다.

tuneChannelImpl은 RxJava 경로(preChProcessor.onNext(...))와 스레드 경로(ChannelTuneThread) 두 가지로 채널 전환을 비동기 직렬화합니다. 진행 중인 튜닝이 있으면 취소하고 새 요청만 처리해, 빠른 연속 채널 전환에서 중간 채널을 건너뛰도록 설계되어 있습니다. 결정된 목적지 채널은 TaurusPlayerManager.tuneLiveChannel(uri, needStop, handler)로 넘어가고, 여기서 CSP 플레이어(com.sk.csplayer)로 라이브 스트림을 열어 영상을 출력합니다. HCN은 FCC(Fast Channel Change)를 사용하지 않으므로 관련 매니저는 stop 처리됩니다.

설계 포인트
모든 채널 전환 진입점이 tuneChannelImpl 하나로 수렴하는 단일 게이트 구조입니다. 덕분에 튜닝 취소·재시도(retune) 타이머, 미니EPG 표시 여부, 채널 저장(save) 정책을 한 지점에서 일관되게 적용할 수 있습니다.

관계. 튜닝 매니저는 ChannelTuneThread로 전환을 직렬화하고 TaurusPlayerManager(싱글턴)에 재생을 위임하며, 플레이어 매니저는 CsPlayer 인터페이스로 실제 디코딩/출력을 수행합니다.

핵심 코드

epg-module/.../playback/manager/TaurusLiveTuneManager.java — 단일 튜닝 게이트
public void tuneCh(ExChannel toGoChannel, @NonNull PlaybackHandler handler) {
    tuneChannelImpl(currentChannel == null ? TUNE_CHANNEL_BOOT : TUNE_CHANNEL_OBJECT,
            toGoChannel, handler, true, true);
}

private void tuneChannelImpl(int tuneType, Object targetChannel,
                             PlaybackHandler handler, boolean saveChannel, boolean showingMiniEpg) {
    if (USE_RXJAVA) {
        ExChannel toGoChannel = getToGoChannel(tuneType, targetChannel, handler);
        preChProcessor.onNext(ContEventChannel.create(tuneType, toGoChannel, handler, saveChannel, showingMiniEpg));
    } else {
        stopRetuneTimer();
        if (mTuneThread != null) { mTuneThread.setCancelled(true); mTuneThread = null; }
        mTuneThread = new ChannelTuneThread(this, targetChannel, handler, saveChannel, showingMiniEpg);
        mTuneThread.execute(tuneType);   // 진행 중 튜닝 취소 후 새 요청만 처리
    }
}
