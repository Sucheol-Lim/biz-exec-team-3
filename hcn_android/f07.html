기능 개요

PVR(Personal Video Recorder)은 라이브 프로그램을 단말 저장소에 녹화하는 기능입니다. pvr-module(com.altimedia.alaska.pvr)의 PvrMain이 외부에서 호출하는 진입 싱글턴이며, 즉시 녹화(startRecord)와 예약 녹화(reserveRecord), 취소(cancelReservedRecord)를 제공합니다. 즉시 녹화도 내부적으로는 reserveRecord를 호출하는 단일 경로로 모입니다.

reserveRecord(PvrProgram)은 예약을 받기 전에 여러 충돌·유효성 검사를 거칩니다. 먼저 PvrDataUtil.isValidProgram()으로 프로그램 유효성을 확인하고, 현재 진행 중인 프로그램이면 PvrSessionManager.getExistPvrSession(srcId)로 이미 같은 소스에 녹화 세션이 있는지 봅니다. 녹화 중이면 후처리 시간(isPostRecordingTime())이면 기존 세션을 정리하고, 아니면 FAIL_TO_START_RECORDING_FOR_ALREADY_RECORDING 예외로 거절합니다. 동일 예약 아이템이 이미 있으면 except 값 처리 또는 중복 예약(FAIL_TO_BE_DUPLICATED_SCHEDULE_ITEM) 예외로 분기합니다. 통과하면 PvrScheduleItemManager.addScheduleItem()으로 예약 아이템을 생성합니다. 저장 공간은 StorageManager가 자동 관리(isHddAutoManagement 시 오래된 녹화 삭제)·포맷 등을 담당합니다.

설계 포인트
모든 녹화 요청이 reserveRecord로 수렴하고, 충돌은 코드화된 PvrExceptionCode(이미 녹화 중·중복 예약·유효하지 않은 프로그램 등)로 표현됩니다. 호출 측은 예외 코드를 받아 사용자에게 적절한 안내/대체 동작을 보여줄 수 있습니다.

핵심 코드

pvr-module/.../pvr/PvrMain.java — 예약 충돌 검사와 스케줄 아이템 생성
public ExScheduleItem reserveRecord(PvrProgram program) throws PvrException {
    if (!PvrDataUtil.isValidProgram(program)) {
        throw new PvrException(PvrExceptionCode.INVALID_PROGRAM_INFO);
    }
    if (PvrDataUtil.isCurrentProgram(program)) {
        PvrSession session = PvrSessionManager.getInstance().getExistPvrSession(program.getSrcId());
        if (session != null) {
            if (session.isPostRecordingTime()) {
                PvrActionManager.getInstance().stopPvrSession(program.getSrcId(), true);
            } else {
                throw new PvrException(PvrExceptionCode.FAIL_TO_START_RECORDING_FOR_ALREADY_RECORDING);
            }
        }
    }
    ExScheduleItem reservedItem = PvrScheduleItemManager.getInstance().getScheduleItem(program);
    if (reservedItem != null) {
        if (program.getRecordingType() == RecordingType.CUSTOMIZED) {
            throw new PvrException(PvrExceptionCode.FAIL_TO_BE_DUPLICATED_SCHEDULE_ITEM);
        }
        throw new PvrException(PvrExceptionCode.INVALID_REQUEST);
    }
    int recType = getRecordType(program, program.isRequestedByGroup());
    return PvrScheduleItemManager.getInstance().addScheduleItem(program, recType);
}
