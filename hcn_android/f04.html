CAS 수신제한

CaManager가 NDS JCAS 서비스와 연동해 가입자 상품 정보를 수신하고, 채널별 시청 권한·스크램블 상태·OTP·핑거프린트(FingerPrint)를 제어하는 수신제한(Conditional Access) 처리를 담당합니다.

기능 개요

CAS(수신제한)는 가입자가 결제한 상품 범위 내에서만 채널을 시청하도록 제어하는 보안 기능으로, HCN은 NDS(현 Synamedia) JCAS를 사용합니다. cas-module의 CaManager가 진입점 싱글턴이며, 내부적으로 일반 CA 서비스(NormalCaService)와 미디어 CA 서비스(MediaCaService)를 추상화한 curCaService에 위임합니다. 부팅 시 init(CasEventHandler)로 초기화하고 requestCaInformation()으로 가입 상품/권한 정보를 요청합니다.

채널 튜닝이 일어나면 JCAS 엔진이 해당 소스의 시청 가능 여부를 판정해 CaChannelListener.notifyCaChannel(...)로 통보합니다. status 비트마스크에는 STATUS_NOT_SCRAMBLED(Clean), STATUS_VIEWABLE(시청 가능), STATUS_BLACKOUT, STATUS_NOT_SUBSCRIBE_CHANNEL(미가입), STATUS_PURCHASABLE_PRODUCT(구매 가능), STATUS_PREVIEW 등이 정의되어 있어, EPG는 이 상태에 따라 영상 출력·미가입 안내·미리보기 타이머를 분기합니다. OTP는 requestOtp()로 발급받아 CaOtpListener.notifyCaOtp(...)로 수신하고, 화면에는 가입자 식별용 핑거프린트(FingerPrint)가 오버레이됩니다.

설계 포인트
AIDL 기반 NDSJcasBaseApiService가 JCAS 베이스 API(INdsJCasBaseApi)와 OSD 메시지·PIN 리셋·리전 비트 리스너를 연결합니다. 채널 시청 가능 여부는 push 형태로 CaChannelListener에 통보되므로, EPG는 직접 폴링하지 않고 콜백으로 권한 상태를 받아 처리합니다.

시퀀스 다이어그램

흐름. 부팅 시 CaManager가 JCAS를 초기화·상품 조회하고, 튜닝 때마다 CaChannelListener.notifyCaChannel()로 시청 상태 비트마스크가 push 되어 EPG가 영상 출력/미가입 안내를 분기합니다. OTP는 요청-콜백 쌍으로 발급됩니다.

관계. CaManager는 일반/미디어 CA 서비스를 추상화해 위임하고, 시청 상태는 CaChannelListener, OTP는 CaOtpListener로 통보됩니다. JCAS 엔진과는 AIDL 서비스로 연결됩니다.

핵심 코드

cas-module/.../manager/CaManager.java — 초기화·상품 조회·OTP 요청 위임
public void init(CasEventHandler casHandler) {
    curCaService.init(casHandler);
}

public void requestCaInformation() {
    curCaService.requestCaInformation();
}

public void requestOtp() {
    if (LogUtil.DBG) Log.d(TAG, "called requestOtp()");
    curCaService.requestOtp();      // OTP 발급 요청 → CaOtpListener.notifyCaOtp 로 수신
}
cas-module/.../listener/CaChannelListener.java — 시청 상태 비트마스크 정의
public interface CaChannelListener {
    long STATUS_NOT_SCRAMBLED          = 0x01;   // Clean 채널
    long STATUS_VIEWABLE               = 0x02;   // 시청 가능
    long STATUS_BLACKOUT               = 0x04;   // Black Out
    long STATUS_NOT_SUBSCRIBE_CHANNEL  = 0x10;   // 미가입 채널
    long STATUS_PURCHASABLE_PRODUCT    = 0x40;   // 구매 가능 상품
    long STATUS_PREVIEW                = 0x8000; // 미리보기

    void notifyCaChannel(short transactionId, int sourceId, long status,
                         CaProduct[] caProducts, CaAttrPreviewInfoStructure preview);
}
