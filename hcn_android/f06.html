VOD 재생

UmpManager가 Castis UMP 서비스(com.castis.vod_service)에 바인딩해 UnitedMediaPlayer AIDL로 VOD를 재생합니다. HCN 정합상 SO Code와 TSID 스캔 목록을 setNetworkInfo()로 전달합니다.

기능 개요

VOD 재생은 EPG가 직접 디코딩하지 않고 외부 Castis UMP(United Media Player) 서비스 앱에 위임합니다. TaurusVodTuneManager.tuneVod(...)가 진입점이며 내부적으로 UmpManager(싱글턴)에 위임합니다. UmpManager는 Intent("com.castis.ump.umpService")에 setPackage("com.castis.vod_service")를 지정해 bindService(..., BIND_AUTO_CREATE)로 UMP 서비스에 연결하고, 연결되면 IBinder를 UnitedMediaPlayer.Stub.asInterface(iBinder)로 받아 AIDL 미디어 플레이어를 획득합니다.

HCN 정합의 핵심은 네트워크 정보 전달입니다. readyVodPlayer()는 EpgVod의 TsScanData에서 TSID 스캔 배열(tsId)을 꺼내고, SO Code(vodInfo.getSoCode())와 함께 mediaPlayer.setNetworkInfo(soCode, -1, tsId)로 UMP에 넘깁니다. 즉 노드그룹 단일 값 대신 SO Code와 TSID 스캔 전체 목록을 전달하는 방식으로 정합되어 있습니다. 이어 단말 MAC(setTerminalId)·광고 ID(setAdId)를 설정하고 play(fileName, offset)을 호출하며, 정상 VOD(FP·일반 VOD)면 demandVODRequestID(categoryId, assetId)를 추가로 요청합니다. VOD 종료 시에는 라이브 기본 이동 채널로 복귀하도록 처리됩니다.

설계 포인트
UMP 연동은 ServiceConnection 기반 AIDL 바인딩입니다. onServiceConnected에서 네트워크 정보 설정 → play 순으로 진행하고, onServiceDisconnected에서 removeUMPEventListener·stop으로 자원을 정리합니다. 이미 연결(umpConnection != null)되어 있으면 중복 바인딩을 막습니다.

핵심 코드

epg-module/.../playback/manager/UmpManager.java — UMP 바인딩 후 네트워크 정보 전달과 재생
public void readyVodPlayer(Context context, final EpgVod vodInfo, final UmpManagementListener callback) {
    if (umpConnection != null) return;                 // 중복 바인딩 방지
    TsScanData tsScanData = vodInfo.getTsScanData();
    final int[] tsId = (tsScanData != null) ? tsScanData.getTsId() : null;

    umpConnection = new ServiceConnection() {
        @Override public void onServiceConnected(ComponentName cn, IBinder iBinder) {
            mediaPlayer = UnitedMediaPlayer.Stub.asInterface(iBinder);
            mediaPlayer.setUMPEventListener(new UmpSessionListener(vodInfo, callback));
            mediaPlayer.setNetworkInfo(vodInfo.getSoCode(), -1, tsId);   // SO Code + TSID 스캔 목록
            mediaPlayer.setTerminalId(vodInfo.getHostMac().toLowerCase());
            int iResult = mediaPlayer.play(vodInfo.getFileName(), offset);
        }
    };

    Intent castisIntent = new Intent("com.castis.ump.umpService");
    castisIntent.setPackage("com.castis.vod_service");
    context.bindService(castisIntent, umpConnection, Context.BIND_AUTO_CREATE);
}
