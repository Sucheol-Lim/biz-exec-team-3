자동 재부팅 · 슬립 타이머

RebootAlarmReceiver가 HCN 7일 주기 자동 재부팅을 AlarmManager(setExactAndAllowWhileIdle)로 예약·실행하고, SleepTimerAlarmReceiver가 사용자 슬립 타이머와 제조사별 대기모드(standby) 진입을 처리합니다.

기능 개요

케이블 STB는 장시간 무중단 동작으로 메모리 누수·시스템 불안정이 누적될 수 있어, HCN 정책(OCAP과 동일)으로 7일 주기 자동 재부팅을 둡니다. RebootAlarmReceiver는 부팅 완료(BOOT_COMPLETED/LOCKED_BOOT_COMPLETED)·재부팅(ACTION_REBOOT)·리셋(ACTION_RESET) 등을 수신하는 BroadcastReceiver입니다. 알람 주기는 7 * TimeUtil.DAY_IN_MILLSEC로 정의되어 있습니다.

대기모드에서도 정확히 동작하도록 setRebootAlarm()은 AlarmManager.setExactAndAllowWhileIdle(RTC_WAKEUP, triggerTime, sender)를 사용합니다(반복 알람은 doze 모드에서 누락될 수 있어 단발 정확 알람으로 재예약). ACTION_REBOOT이 오면 needToReboot()로 실제 재부팅 조건(자동 재부팅 설정 on, VOD 재생 중 아님, 오디오 채널 아님, 최소 경과 시간 등)을 확인합니다. 조건 미충족이면 카운트만 올리고 알람을 다시 겁니다. 조건 충족 시 화면이 켜져 있고 앱이 포그라운드면 사용자에게 재부팅 안내 팝업(showRebootAlarmDialog)을 띄우고, 화면이 꺼져 있으면 TaurusSystemController.reboot()로 바로 재부팅합니다. 슬립 타이머는 SleepTimerAlarmReceiver가 ACTION_SET_ALARM_SLEEP으로 사용자가 설정한 분(min) 뒤에 알람을 걸고, 만료 시 제조사별 대기모드 인텐트(가온 PM_REQUEST_STANDBY, 이노피아 SET_DOZE_STANDBY)로 standby에 진입합니다.

설계 포인트
재부팅은 즉시 실행이 아니라 조건부입니다. needToReboot 가드(VOD·오디오 채널·설정 off 등)로 시청 중인 사용자를 방해하지 않고, 화면 on/foreground 여부에 따라 팝업 안내 또는 무음 재부팅으로 분기합니다. 미충족 시 단발 알람을 매일(INTERVAL_DAY) 재예약해 재시도합니다.

핵심 코드

ui/controller/receiver/RebootAlarmReceiver.java — 7일 주기 정확 알람과 조건부 재부팅
// HCN 정책(ocap과 동일)에 따라 7일로 함.
private long getRebootInterval() {
    return DebugConfig.TEST_REBOOT_ALARM2 ? 1*60*1000 : 7 * TimeUtil.DAY_IN_MILLSEC;
}

private void setRebootAlarm(Context context, boolean isStart) {
    long triggerTime = isStart ? getTriggerTime()
            : TvSingletons.SystemClock().currentTimeMillis() + AlarmManager.INTERVAL_DAY;
    Intent intent = new Intent(context, RebootAlarmReceiver.class);
    intent.setAction(ACTION_REBOOT);
    PendingIntent sender = PendingIntent.getBroadcast(context, REQUEST_ALARM_CODE, intent,
            PendingIntent.FLAG_IMMUTABLE | PendingIntent.FLAG_CANCEL_CURRENT);   // AOS12
    AlarmManager am = (AlarmManager) context.getSystemService(Context.ALARM_SERVICE);
    am.setExactAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, triggerTime, sender);  // doze에서도 정확 동작
}
ui/controller/receiver/RebootAlarmReceiver.java — 화면 상태에 따른 분기
} else if (action.equalsIgnoreCase(ACTION_REBOOT)) {
    if (!needToReboot(context)) {                  // VOD/오디오/설정 off 가드
        rebootCheckCount++;
        setRebootAlarm(context, false);            // +1일 재예약
        return;
    }
    if (EpgApplication.isInteractive()) {          // 화면 ON
        if (EpgApplication.isAppInForeground(context)) showRebootAlarmDialog(context, intent);
    } else {                                       // 화면 OFF → 즉시 재부팅
        TaurusSystemController.getInstance().reboot(0, context);
    }
}
