USB 재생 · 외부 저장소

UsbPlayActivity가 USB 미디어를 비디오/오디오/이미지 타입에 따라 전용 플레이어 프래그먼트로 재생하고, exteranlStorage/ 유틸이 외부 저장소 검색·미디어 목록 구성을 담당하며, 마운트 해제/화면 오프 시 안전하게 종료합니다.

기능 개요

USB 재생은 사용자가 꽂은 외부 저장소(USB 메모리/HDD)의 미디어 파일을 STB에서 재생하는 기능입니다. exteranlStorage/ 패키지의 유틸(ExternalStorageUtils·ExternalStorageFileSearchUtils)이 마운트된 볼륨을 탐색해 파일을 검색하고, 각 파일을 ExternalMediaItem(Parcelable)으로 모델링합니다. 재생 화면은 UsbPlayActivity가 담당하며, 파일 탐색 콜백(OnFileExplorerListener)과 프래그먼트 상호작용(UsbFragmentInteractionCallback)을 구현합니다.

재생 요청은 인텐트의 KEY_ITEM(ExternalMediaItem)과 KEY_PLAYER_TYPE(Type.Video/Audio/Image)을 담아 들어오고, initMediaPlayer(type, item)이 타입에 따라 전용 프래그먼트(VideoMediaPlayerFragment·AudioMediaPlayerFragment·ImageMediaPlayerFragment)를 mediaPlayLayout 컨테이너에 replace합니다. 액티비티는 재생 중 화면이 꺼지지 않도록 FLAG_KEEP_SCREEN_ON을 걸고, ACTION_MEDIA_UNMOUNTED(USB 분리)·ACTION_SCREEN_OFF·EPG의 ACTION_KILL_OTHERS(다른 화면 진입)를 수신하면 finishAction()으로 안전하게 종료합니다.

설계 포인트
재생을 단일 액티비티 + 타입별 프래그먼트로 분리해, 비디오/오디오/이미지의 서로 다른 재생 UI와 컨트롤을 각 프래그먼트가 캡슐화합니다. USB 분리·화면 오프 같은 외부 상태 변화는 브로드캐스트로 받아 즉시 종료하므로, 매체가 사라진 뒤에도 재생 화면이 남는 문제를 막습니다.

핵심 코드

ui/activity/UsbPlayActivity.java — 타입별 플레이어 프래그먼트 분기와 안전 종료
private void initMediaPlayer(Type mediaType, ExternalMediaItem mediaItem) {
    FragmentTransaction ft = getSupportFragmentManager().beginTransaction();
    switch (mediaType) {
        case Video:
            ft.replace(R.id.mediaPlayLayout,
                       VideoMediaPlayerFragment.newInstance(mediaItem),
                       VideoMediaPlayerFragment.CLASS_NAME);
            break;
        case Audio:
            ft.replace(R.id.mediaPlayLayout,
                       AudioMediaPlayerFragment.newInstance(mediaItem),
                       AudioMediaPlayerFragment.CLASS_NAME);
            break;
        case Image:
            ft.replace(R.id.mediaPlayLayout,
                       ImageMediaPlayerFragment.newInstance(mediaItem),
                       ImageMediaPlayerFragment.CLASS_NAME);
            break;
    }
    ft.commitAllowingStateLoss();
}

// USB 분리 / 화면 오프 시 즉시 종료
private BroadcastReceiver mBroadcastReceiver = new BroadcastReceiver() {
    @Override public void onReceive(Context context, Intent intent) {
        switch (intent.getAction()) {
            case Intent.ACTION_MEDIA_UNMOUNTED:
            case Intent.ACTION_SCREEN_OFF:
                finishAction();
                break;
        }
    }
};
