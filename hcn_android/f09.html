기능 개요

setting-module은 STB 설정 도메인을 모아 둔 모듈입니다. 사용자 선호도(UP, User Preference)는 TaurusUserPreferenceManager 싱글턴이 담당하며, 내부적으로 HcnSettings를 통해 시스템 설정 저장소에 키-값을 읽고(readUserPreference(key, default)) 씁니다(writeUserPreference(key, value)). 값이 없거나 파싱 실패 시 기본값을 돌려주는 방어 코드를 두고, 설정이 바뀌면 등록된 OnUserPreferenceChangedListener.onUpChanged(key, value)로 관심 있는 컴포넌트에 통지합니다.

시스템 제어는 SystemController 인터페이스와 그 구현 TaurusSystemController가 맡아 STB 재부팅(reboot(bOn, context), active/quiescent 모드 구분)·비디오 화면비·해상도 등을 제어합니다. 시청 보호는 PRLevelController가 담당해 시청등급 인덱스(PR_INDEX_ALL~PR_INDEX_19)와 연령(PR_AGE_7·12·15·19)을 매핑하고 PIN 검사로 제한을 적용합니다. 펌웨어 업데이트는 OTAManagerCommon이 OTA 다운로드/적용을 처리합니다.

설계 포인트
UP는 일반 SharedPreferences가 아니라 시스템 설정(HcnSettings)을 백엔드로 사용합니다. 시스템 앱 권한(WRITE_SECURE_SETTINGS)을 전제로 하므로, 부팅·재부팅을 거쳐도 STB 전역에서 사용자 환경이 유지되고 다른 시스템 컴포넌트와 값을 공유할 수 있습니다.

흐름. 설정 변경은 TaurusUserPreferenceManager가 시스템 설정에 기록하고 리스너로 통지하며, 읽기는 기본값 방어를 거칩니다. 재부팅·화면비 등 시스템 제어는 TaurusSystemController가 수행합니다.

관계. UP 매니저는 HcnSettings를 저장소로 쓰고 변경을 리스너로 통지하며, TaurusSystemController는 SystemController 구현, PRLevelController·OTAManagerCommon은 각각 시청등급·OTA 도메인을 담당합니다.

핵심 코드

setting-module/.../up/TaurusUserPreferenceManager.java — 시스템 설정 기반 UP 읽기/쓰기
public int readUserPreference(String key, int defaultValue) {
    String value = mSettings.get(key);
    if (value == null || value.trim().length() == 0) {
        return defaultValue;                 // 없으면 기본값
    }
    int ret = defaultValue;
    try { ret = Integer.parseInt(value); }
    catch (Exception e) { /* 파싱 실패 시 기본값 유지 */ }
    return ret;
}

public void writeUserPreference(String key, String value) {
    if (value == null) value = "";
    mSettings.set(key, value);               // HcnSettings(시스템 설정)에 기록
}

public static final int PR_AGE_ALL = 0, PR_AGE_7 = 7, PR_AGE_12 = 12,
                        PR_AGE_15 = 15, PR_AGE_19 = 19;
