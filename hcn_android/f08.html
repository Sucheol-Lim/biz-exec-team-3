케이블 백엔드 연동 (OOB/SDV/MGW)

oob-module의 DataManager가 편성·상품·다운로드 데이터를 섹션 필터로 수신하고, sdv-module의 SdvMain이 스위치드 비디오 세션을, mgw-module의 MgwReceiver/MgwSender가 미디어 게이트웨이 메시지를 UDP로 송수신합니다.

기능 개요

케이블 STB는 IP 외에 방송망 고유 채널로 사업자 백엔드와 통신합니다. HCN 앱은 이를 세 모듈로 분리합니다. OOB(Out-Of-Band)는 oob-module의 DataManager가 담당하며, 부팅 시 init(ctx, reqParam, handler)로 다수의 도메인 핸들러(채널 로고·SO 맵 ID·히든 채널·가상 채널·키즈 채널·트리거·긴급 공지 등)를 초기화하고, 각 핸들러가 DMTableSectionFilter로 해당 테이블을 수신해 편성·상품·다운로드 데이터를 갱신합니다.

SDV(Switched Digital Video)는 모든 채널을 동시 송출하지 않고 시청 요청이 있을 때만 주파수를 할당하는 케이블 기술입니다. sdv-module의 SdvMain이 진입 싱글턴이며 SdvClientSessionManager.createSdvClientSession(SdvInfo)로 요청 소스에 튜너 ID를 예약·세션을 만들고, sendSdvServerTuneMessage(SdvInfo)로 CSRM 서버에 튜닝을 요청합니다. MGW(Media Gateway)는 mgw-module의 MgwReceiver(UDP 수신 스레드)가 게이트웨이 메시지를 받아 MgwMain.sendCommandMessage(new MgwMessage(jsonStr))로 디스패치하고, 응답은 MgwSender.sendResultToMgw(...)로 회신합니다(음성 UX 페어링·SVC_CD 등).

설계 포인트
세 채널 모두 이벤트 핸들러(ResourceEventHandler·SdvEventHandler·MgwEventHandler)를 통해 EPG 본체와 느슨하게 결합됩니다. OOB는 섹션 필터 push, SDV는 세션-요청/응답, MGW는 UDP 메시지 송수신으로 각자 비동기 통지하므로, EPG는 결과만 핸들러 콜백으로 받습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant BM as BootManager participant DM as DataManager (OOB) participant H as 도메인 핸들러들 participant SDV as SdvMain participant MGWR as MgwReceiver (UDP) participant MGW as MgwMain / MgwSender BM->>DM: init(ctx, reqParam, handler) DM->>H: 각 핸들러 init() (섹션 필터 등록) H-->>DM: 편성/상품/다운로드 데이터 갱신 DM-->>BM: EVENT_DATA_MANAGER_INITIALIZED Note over SDV: 시청 요청 시 SDV->>SDV: createSdvClientSession(SdvInfo) SDV->>SDV: sendSdvServerTuneMessage(SdvInfo) Note over MGWR,MGW: 게이트웨이 메시지 MGWR->>MGW: sendCommandMessage(new MgwMessage(json)) MGW->>MGW: sendResultToMgw(reqMsg, responseJson)

흐름. 부팅 시 OOB DataManager가 핸들러를 초기화해 방송 데이터를 수신하고, SDV는 시청 요청 시 세션·튜닝 메시지를, MGW는 UDP로 들어온 메시지를 MgwMain이 디스패치하고 결과를 회신합니다.

클래스 다이어그램

classDiagram class DataManager { +getInstance() DataManager +init(ctx, reqParam, handler) +getDataRepository() File } class ResourceEventHandler { <<interface>> +sendResourceUpdateMessage(msg) } class SdvMain { +getInstance() SdvMain +init(handler, ltsReq) +sendSdvServerTuneMessage(SdvInfo) +sendMcDataTuneMessage(SdvInfo) } class SdvClientSessionManager { +createSdvClientSession(SdvInfo) SdvClientSession +disposeSdvClientSession(srcId) } class MgwReceiver { +UDP 수신 스레드 } class MgwMain { +getInstance() MgwMain +sendCommandMessage(MgwMessage) } class MgwSender { +getInstance() MgwSender +sendResultToMgw(reqMsg, json) } DataManager ..> ResourceEventHandler : 갱신 통지 SdvMain --> SdvClientSessionManager : 세션 생성 MgwReceiver --> MgwMain : 메시지 디스패치 MgwMain --> MgwSender : 응답 회신

관계. OOB DataManager는 핸들러로 데이터를 받아 ResourceEventHandler로 통지하고, SdvMain은 세션 매니저로 튜닝을, MgwReceiver→MgwMain→MgwSender로 게이트웨이 메시지를 처리합니다.

핵심 코드

mgw-module/.../service/MgwReceiverService.java — UDP 수신 후 MgwMain 디스패치
String jsonStr = getMgwMessageBody(bData, packetLength);
if (!TextUtils.isEmpty(jsonStr)) {
    MgwMain.getInstance().sendCommandMessage(new MgwMessage(jsonStr));
}
sdv-module/.../SdvClientSessionManager.java — 튜너 예약과 SDV 세션 생성
public SdvClientSession createSdvClientSession(SdvInfo reqSdvInfo) {
    int tunerId = TunerIdManager.getInstance().reserveTunerId(reqSdvInfo.getSrcId());
    reqSdvInfo.setTunerId(tunerId);
    SdvClientSession sdvClientSession = new SdvClientSession(reqSdvInfo);
    putSdvClientSession(sdvClientSession);
    return sdvClientSession;
}
