음성 UX (VUX)

STTManager가 외부 음성 클라이언트 라이브러리(voiceclientlib-0.9.24의 VoiceableClient)를 빌더로 구성하고 오디오 상태(AudioState)에 따라 음성 세션을 열고 닫으며, VuxMain·프롬프트 UI가 음성 UX를 조율합니다.

기능 개요

VUX(Voice UX)는 음성으로 STB를 제어하는 기능입니다. vux-module의 핵심은 STTManager 싱글턴으로, 외부 음성 클라이언트 AAR(voiceclientlib-0.9.24, 패키지 com.alticast.mmux.voiceclientlib)의 VoiceableClient를 사용합니다. 생성자에서 VoiceableClient.with(ctx) 빌더에 상태 콜백(setVoiceableStateCB(this))·사용자 ID(setUserID(subscribeId))·접속 환경(setConnection(...))·언어(KO_KR)·페어링 코드(setPassThroughInfo)를 설정해 클라이언트를 빌드합니다. 접속 환경은 임차망 여부·테스트벤치 여부에 따라 VUX_LIVE_PUB·VUX_TB_DIR·VUX_LIVE_STB_LB 등으로 분기합니다.

음성 인식 시작/종료는 현재 오디오 상태(AudioState)를 기준으로 동작합니다. startListening()은 상태가 STOPPED·PHRASE_SPOTTING·PHRASE_SPOTTED일 때 openVoiceSession()으로 세션을 열고, 그 외에는 closeVoiceSession()으로 정리합니다. closeListening()은 STARTED·LISTENING 상태에서 세션을 닫습니다. 상태 변화는 VoiceableStateCB 콜백으로 돌아오고, 화면에는 프롬프트 토스트/다이얼로그(PromptToast·PromptDialogFragment)가 표시됩니다. 음성 키 매핑은 MgwMappingTable·VoiceKeyReceiver가 담당합니다.

설계 포인트
음성 세션은 상태 기계(AudioState)로 제어됩니다. STTManager가 직접 마이크를 다루지 않고 VoiceableClient에 위임하며, 현재 상태에 따라 open/close를 선택하므로 호출 측이 상태를 추적하지 않아도 안전하게 세션을 토글할 수 있습니다.

흐름. 음성 키가 들어오면 STTManager가 현재 AudioState에 따라 VoiceableClient의 세션을 열거나 닫고, 상태 콜백을 받아 프롬프트 UI를 갱신합니다.

관계. STTManager는 VoiceableStateCB를 구현하고 VoiceableClient(외부 AAR)에 세션을 위임하며, AudioState로 open/close를 분기합니다. 키 트리거는 VoiceKeyReceiver가 전달합니다.

핵심 코드

vux-module/.../STTManager.java — VoiceableClient 빌드와 상태 기반 세션 토글
public STTManager(Context ctx, String subscribeId) {
    sessionInfo = subscribeId;
    VoiceableEnv.Connection conValue =
        (DebugConfig.isTestbed) ? VoiceableEnv.Connection.VUX_TB_LB
                                : VoiceableEnv.Connection.VUX_LIVE_STB_LB;
    VoiceableClientBuilder builder = VoiceableClient.with(ctx)
            .setVoiceableStateCB(this)
            .setUserID(sessionInfo)
            .setConnection(conValue)
            .setLanguage(VoiceableEnv.Language.KO_KR);
    voiceableClient = builder.build();
}

public void startListening() {
    AudioState state = voiceableClient.getAudioState();
    switch (state) {
        case STOPPED: case PHRASE_SPOTTING: case PHRASE_SPOTTED:
            voiceableClient.openVoiceSession();   // 세션 시작
            break;
        default:
            voiceableClient.closeVoiceSession();  // 그 외 상태 정리
            break;
    }
}
