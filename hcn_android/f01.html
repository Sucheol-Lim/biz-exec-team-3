홈 런처 (HOME)

PlaybackActivity를 HOME/LAUNCHER 카테고리의 intent-filter priority 3으로 등록해 STB 부팅 시 Google TVLauncher(priority 2)보다 먼저 기동되는 홈 화면 역할을 하고, ALL_APPS 진입으로 설치 앱 목록을 띄웁니다.

기능 개요

HCN 셋톱박스는 별도 런처 앱을 두지 않고 EPG 앱이 홈 역할을 겸합니다. AndroidManifest.xml에서 PlaybackActivity를 action.MAIN + category.HOME / category.LAUNCHER intent-filter로 선언하고 android:priority="3"을 부여합니다. 주석에 적힌 대로 Google TVLauncher의 intent-filter priority가 2이므로, 그보다 큰 값(3)을 지정해 부팅 시 HCN 런처가 우선 기동되도록 정합되어 있습니다.

설치 앱 목록은 별도 화면이 아니라 다이얼로그로 표시됩니다. 리모컨의 KEYCODE_ALL_APPS 키나 ALL_APPS 인텐트로 AppListActivity가 진입하면, 이 액티비티는 화면을 그리지 않고 IntentDataManager.setShowAppListFlag(true)로 플래그만 세운 뒤 곧바로 finish()합니다. 이미 홈으로 떠 있는 PlaybackActivity가 onResume 시점에 플래그를 확인해 AppListDialogFragment를 띄우는 구조입니다. 또한 라이브 화면에서 KEYCODE_ALL_APPS를 직접 받으면 showAppListDialog()를 즉시 호출합니다.

설계 포인트
AppListActivity는 투명 테마(Theme.Transparent)로 떠서 플래그만 세우고 사라지는 얇은 진입점입니다. 실제 앱 목록 렌더링·실행은 항상 런처 본체인 PlaybackActivity가 담당하므로, 외부에서 ALL_APPS로 진입해도 단일 홈 화면 위에 다이얼로그가 일관되게 표시됩니다.

흐름. ALL_APPS 진입은 AppListActivity가 플래그만 세우고 종료하는 얇은 통로이며, 실제 목록 표시·앱 실행은 홈 본체 PlaybackActivity의 showAppListDialog()가 CspController로 설치 앱을 받아 처리합니다.

관계. PlaybackActivity는 NavigationActivity를 상속한 런처 본체이며, AppListActivity는 IntentDataManager 플래그만 세우는 진입점입니다. 앱 목록은 AppListDialogFragment로 표시되고 선택 결과는 CspController가 실행합니다.

핵심 코드

ui/activity/AppListActivity.java — 플래그만 세우고 종료하는 얇은 진입점
// 실행은 AndroidManifest에 정의되어 있다.
// 해당 Activity의 기능은 showAppListFlag를 true로 만들어 주는 기능만 존재하고,
// 실제 PlaybackActivity의 onResume시 해당 flag가 true이면 AppListDialog를 띄워주도록 처리하고 있다.
@Override
protected void onResume() {
    super.onResume();
    Log.d(TAG, "onResume: called");
    IntentDataManager.setShowAppListFlag(true);
    finish();
}
ui/activity/PlaybackActivity.java — ALL_APPS 키 처리와 앱 목록 다이얼로그 표시
case KeyEvent.KEYCODE_ALL_APPS:
    showAppListDialog();
    return true;

// ...
protected void showAppListDialog() {
    ArrayList<AppInfo> appList = cspController.getInstalledAppList(true);
    AppListDialogFragment fragment = AppListDialogFragment.newInstance();
    AppListDialogFragment.ItemSelectListener listener = new AppListDialogFragment.ItemSelectListener() {
        @Override public void itemSelected(String appId) {
            if (appId.indexOf("netflix") >= 0) {
                Intent netflixIntent = IntentDataManager.getNetflixIntent(
                        IntentDataManager.NEXFLIX_SRC_ID,
                        IntentDataManager.LAUNCH_TYPE_APPS_SECTION_NETFLIX_ICON);
                mContext.startActivity(netflixIntent);
            } else {
                cspController.launchAppDrawer(appId, false, null);
            }
        }
    };
    fragment.show(getSupportFragmentManager(), AppListDialogFragment.CLASS_NAME, appList, listener);
}
