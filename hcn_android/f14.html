외부 연동 · AIDL 서비스

IEpgAIDLService가 IEpgService AIDL 스텁으로 외부 앱(키즈랜드·스카이앨범 등)에 Map ID·SO Code·가입자 ID·시청등급 등 EPG/계정 정보를 제공하고, OpenPortalReceiver가 스카이라이프 오픈포털 인텐트(com.skylife.intent.*)를 수신합니다.

기능 개요

HCN STB에는 EPG 앱 외에도 키즈랜드·스카이앨범 같은 외부 사업자 앱이 함께 설치됩니다. 이 앱들은 채널 매핑·가입자 식별·시청등급 정보가 필요한데, 그 단일 진실 공급원이 EPG 앱입니다. IEpgAIDLService(android:exported="true")는 AIDL 인터페이스 IEpgService.Stub을 구현해 외부 프로세스가 바인딩으로 호출할 수 있는 RPC 엔드포인트를 제공합니다.

제공 메서드는 getMapId()(채널 매핑 ID), getSoCode()(SO Code, CaManager 위임), getNodeGroupId()(TS 스캔 노드그룹), getSubscriberId()(가입자 ID), getPrLevel()(시청등급 레벨, PRLevelController 위임, 0/7/12/15/19), 스마트카드 ID·SMS 태그 등입니다. 각 메서드는 내부 컨트롤러(UserConfigInfoController·CaManager·PRLevelController)에 위임하고 예외 시 -1/0 등 안전값을 돌려주는 방어 코드를 둡니다. 반대 방향으로는 OpenPortalReceiver가 스카이라이프 오픈포털 앱이 보내는 인텐트(com.skylife.intent.action.CH_APPS로 채널형 앱 목록 갱신, ...DCAKEY로 DCA 키 이벤트)를 수신해 EPG에 반영합니다.

설계 포인트
외부 연동은 두 방향으로 분리됩니다. 정보 제공은 동기 AIDL RPC(IEpgService)로, 이벤트 수신은 비동기 브로드캐스트(OpenPortalReceiver)로 처리합니다. AIDL 메서드는 모두 내부 컨트롤러에 위임해 EPG의 데이터 모델과 외부 노출 계약을 분리하고, 실패 시 안전값을 반환해 외부 앱 크래시를 방지합니다.

흐름. 외부 앱은 IEpgService에 바인딩해 Map ID·SO Code·가입자 ID·시청등급을 동기 호출로 받고, 스카이라이프 오픈포털 인텐트는 OpenPortalReceiver가 수신해 EPG에 반영합니다.

관계. IEpgAIDLService가 IEpgService 스텁을 구현해 내부 컨트롤러로 위임하고, OpenPortalReceiver는 별도 브로드캐스트로 오픈포털 인텐트를 수신합니다.

핵심 코드

ui/controller/service/IEpgAIDLService.java — AIDL 스텁이 내부 컨트롤러로 위임
private final IEpgService.Stub mBinder = new IEpgService.Stub() {
    public int getMapId() {
        int _mapId = -1;
        try { _mapId = UserConfigInfoController.getInstance().getMapId(); }
        catch (Exception e) { _mapId = -1; }     // 실패 시 안전값
        return _mapId;
    }
    public int getSoCode() {
        int _soCode = 0;
        try { _soCode = CaManager.getInstance().getSoNumber(); }
        catch (Exception e) { }
        return _soCode;
    }
    public String getSubscriberId() { return CaManager.getInstance().getSubscriberId(); }
    public int getPrLevel() { return PRLevelController.getInstance().getPRLevel(); }
};
