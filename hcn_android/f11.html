RCU OTA · 블루투스

OtaManager가 본딩된 RCU(블루투스 리모컨)를 찾아 선택하고, DfuManager가 GATT 연결 위에서 Realtek DFU(RealsilDfu)로 리모컨 펌웨어를 업데이트합니다. 리모컨/헤드셋 페어링은 BluetoothManager가 관리합니다.

기능 개요

블루투스 리모컨(RCU)은 펌웨어 업데이트가 필요할 때 STB가 무선으로 신규 바이너리를 내려줍니다. rcu_ota-module의 OtaManager가 진입점이며, startOta()에서 본딩된 BT 기기를 순회해 이름이 Config.DMC_NAME_SHORT로 시작하고 "RCU"를 포함하되 "HEADSET"은 제외하는 기기를 RCU로 식별합니다. 대상 RCU를 찾으면 OnDeviceSelectedListener.onDeviceSelected(device)로 통지합니다.

이 리스너는 DfuManager가 구현합니다. onDeviceSelected에서 기존 GATT를 모두 닫고 GlobalGatt.connect(address, callback)로 대상 RCU에 GATT 연결을 맺습니다. 연결되면 Realtek DFU 라이브러리(RealsilDfu)를 초기화하고, OTA 작업 모드(OTA_MODE_FULL_FUNCTION / OTA_MODE_LIMIT_FUNCTION)를 setWorkMode()로 설정한 뒤 펌웨어 바이너리(BinInputStream)를 전송하며 RealsilDfuCallback으로 진행 상태·완료를 통보받습니다. 일반 리모컨/헤드셋 페어링·연결 관리는 별도로 app/bt/의 BluetoothManager가 담당해 startPairing(listener)·기존 본딩 해제 등을 처리합니다.

설계 포인트
OTA 절차는 비동기 GATT 콜백 체인입니다. 기기 선택 → GATT 연결 → DFU 서비스 연결(RealsilDfuCallback.onServiceConnectionStateChange) → 작업 모드 설정 → 바이너리 전송 순으로, 각 단계 완료가 다음 단계를 트리거합니다. RCU는 BLE 특성상 연결 안정성이 낮아 실패 시 재시도/취소(cancelOta)로 GATT를 정리합니다.

핵심 코드

rcu_ota-module/.../ota/OtaManager.java — 본딩 목록에서 RCU 식별·선택
public void startOta() {
    BluetoothDevice device = getRcuBluetoothDevice();
    if (device != null) {
        mListener.onDeviceSelected(device);     // DfuManager 로 통지
    }
}

public BluetoothDevice getRcuBluetoothDevice() {
    Set<BluetoothDevice> devices = BluetoothAdapter.getDefaultAdapter().getBondedDevices();
    for (BluetoothDevice device : devices) {
        String dName = device.getName();
        if (dName != null && dName.startsWith(Config.DMC_NAME_SHORT)
                && dName.indexOf("RCU") >= 0 && dName.indexOf("HEADSET") < 0) {
            return device;                       // RCU 만 선별 (헤드셋 제외)
        }
    }
    return null;
}
rcu_ota-module/.../ota/DfuManager.java — GATT 연결로 DFU 시작
@Override
public void onDeviceSelected(final BluetoothDevice device) {
    mGlobalGatt.closeAll();
    mBtGatt = null;
    mSelectedDevice = device;
    mDeviceAddress = device.getAddress();
    mGlobalGatt.connect(mDeviceAddress, mBluetoothGattCallback);   // GATT 연결 → DFU
    mBtGatt = mGlobalGatt.getBluetoothGatt(mDeviceAddress);
}
