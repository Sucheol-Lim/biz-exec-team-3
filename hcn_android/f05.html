가입 상품별 채널 히든

DMHiddenChannelHandler가 OOB Table ID 85로 내려오는 상품별 히든 채널 목록을 수신·파싱해, 가입 상품과 매칭한 비가입 채널을 채널 링에서 제거(히든)하도록 ChannelUPHandler로 Rebuild 합니다.

기능 개요

HCN은 가입자가 결제한 상품에 따라 채널 라인업을 다르게 보여줍니다. 비가입 채널을 채널 목록에서 아예 숨기는(히든) 처리가 이 기능입니다. 히든 채널 목록은 케이블 백엔드에서 OOB(Out-Of-Band) Table ID 85로 내려오며, 이 값은 자산 설정 dm_config_hcn_live.ini의 OOB_TABLEID_HIDDEN=85로 정의되고 DMConfiguration이 기본값 85로 읽습니다.

oob-module의 DMHiddenChannelHandler는 DMTableSectionFilter(OOB_TABLEID_HIDDEN, OOB_TABLEIDEXT_HIDDEN, this)로 섹션 필터를 걸어 해당 테이블을 수신합니다. 테이블 확장 ID(OOB_TABLEIDEXT_HIDDEN)에는 가입자의 SO 코드가 매핑되어, 상품별 히든 목록을 선택적으로 받습니다. 수신한 JSON(hiddenChan / hiddenChList)을 파싱한 뒤, 파일에 저장된 기존 히든 목록은 제거(remove) 대상으로, OOB로 새로 받은 목록은 추가(add) 대상으로 정리해 ChannelUPHandler.updateDelChannelFromHidden(addSrcIds, removeSrcIds)로 채널 링(Channel Ring)을 Rebuild 합니다. 결과적으로 비가입 채널은 채널 업/다운·EPG에서 빠집니다.

설계 포인트
히든 적용은 add/remove 차집합 방식입니다. 새 OOB 목록을 통째로 덮어쓰지 않고 (이전 파일 목록 remove) + (새 OOB 목록 add)로 델타를 계산해 채널 링에 반영하므로, 상품 변경 시 기존에 숨겼던 채널이 다시 노출되고 새로 비가입된 채널만 추가로 숨겨집니다.

흐름. OOB Table 85가 섹션 필터로 들어오면 핸들러가 JSON을 파싱하고, 파일 기존 목록(remove)과 OOB 신규 목록(add)의 델타를 계산해 ChannelUPHandler로 채널 링을 Rebuild 하여 비가입 채널을 숨깁니다.

관계. DMHiddenChannelHandler는 공통 핸들러를 상속해 Table 85 섹션을 받고, DMConfiguration의 테이블 ID 설정으로 필터를 구성하며, 델타를 ChannelUPHandler에 넘겨 채널 데이터 매니저의 링을 Rebuild 합니다.

핵심 코드

oob-module/.../dm/handler/DMHiddenChannelHandler.java — Table 85 섹션 필터와 add/remove Rebuild
filter = new DMTableSectionFilter(DMConfiguration.OOB_TABLEID_HIDDEN,
                                  DMConfiguration.OOB_TABLEIDEXT_HIDDEN, this);
// ...
private void updateHiddenChannelFromOob(String oobJsonStr) {
    if (TextUtils.isEmpty(oobJsonStr)) return;

    // 1. 파일의 기존 히든 목록 → remove 대상
    ArrayList<ExChannel> hiddensFromFile = getHiddenChannelsFromFile();
    // 2. OOB 신규 히든 목록 → add 대상
    ArrayList<ExChannel> hiddensFromOob  = getHiddenChannels(oobJsonStr);

    // 3. 차집합으로 채널 링 Rebuild
    ChannelUPHandler.updateDelChannelFromHidden(
            getSrcIdList(hiddensFromOob),   // add
            getSrcIdList(hiddensFromFile)); // remove
}
common-module/.../info/DMConfiguration.java — Table ID 85 기본값
OOB_TABLEID_HIDDEN = FileUtil.getIntValue(dmConfig, "OOB_TABLEID_HIDDEN", 85);
// dm_config_hcn_live.ini → OOB_TABLEID_HIDDEN=85
