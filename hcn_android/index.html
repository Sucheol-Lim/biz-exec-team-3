개요

본 프로젝트는 HCN(현대HCN) 사업자향 Android TV 셋톱박스(STB)에서 동작하는 EPG(Electronic Program Guide) 겸 홈 런처 애플리케이션입니다. 라이브 방송 채널 편성표, 채널 시청(튜닝/재생), VOD, PVR(녹화), 설정, 히든 메뉴, RCU(리모컨) OTA 등 셋톱박스의 핵심 사용자 경험 전반을 담당합니다. 사내에서는 알티미디어의 클라우드 + EPG 서비스 제품군(코드명 Alaska)을 HCN에 제공하는 과제로 분류되며, EPG·TVCore·CAS는 알티미디어가, 클라우드 백엔드는 SKP가 담당하는 구도였습니다.

애플리케이션 ID는 com.altimedia.android.tv.epg이며, AndroidManifest.xml에서 PlaybackActivity를 HOME / LAUNCHER 카테고리(intent-filter priority 3)로 등록합니다. 단순 EPG가 아니라 STB의 기본 홈/런처 역할을 겸하며, Google TVLauncher(priority 2)보다 높은 우선순위로 동작하도록 설계되었습니다. 대상 플랫폼은 Android TV(Leanback) 기반 STB로, android.software.live_tv 하드웨어 기능을 필수로 요구하고 테마는 Theme.Leanback을 사용합니다.

대상 단말은 크게 두 갈래입니다. 이노피아테크 CMless(케이블 모뎀 미내장) Android 11 박스와 가온미디어 CM(케이블 모뎀 내장) Android 12 박스이며, 가온박스 AOS12를 감안해 compileSdk 32 / targetSdk 31로 설정되어 있습니다. 케이블 방송 백엔드 연동(OOB/SDV/MGW), 가입자 상품 기반 채널 히든 처리, 자동 7일 재부팅, 스카이라이프 RCU 정합 등 사업자/제조사 특화 요구사항이 다수 반영되어 있습니다.

시스템 앱 전제

이 앱은 WRITE_SECURE_SETTINGS, WRITE_EPG_DATA, signatureOrSystem 권한과 제조사 네이티브 라이브러리(libtauruscorerop, libtvclmediaplayer_jni)를 사용하므로, 실제 동작은 시스템 이미지에 프리로드된 셋톱박스 환경을 전제로 합니다. 일반 단말에서의 전체 기능 실행은 제한적입니다(추정).

소스는 대부분 Java로 작성되어 있으며(Kotlin 파일 없음), app 모듈에만 약 442개의 Java 소스가 있고 도메인별 라이브러리 모듈 13여 개로 분리되어 있습니다. JCN(전 CJ헬로) 환경 설정(dm_config_jcn_*.ini) 및 SITE = CJH 흔적이 자산에 일부 남아 있어, CJ헬로비전 형상을 기반으로 HCN 향으로 분기·확장된 코드베이스임을 알 수 있습니다.

주요 기능

홈 런처 (HOME)
PlaybackActivity를 기본 런처(intent priority 3)로 등록해 STB 부팅 시 홈 화면 역할을 합니다. 설치 앱 목록(AppListActivity, ALL_APPS) 진입을 제공합니다.
라이브 EPG · 채널 편성표
채널/프로그램 데이터 모델과 TIF(TvInputFramework) 연동을 기반으로 편성표·미니EPG를 표시합니다(epg-module, ui/fragment/miniepg).
라이브 채널 재생 · 튜닝
CSP 플레이어(csp-module)와 재생 매니저(epg-module/playback.manager)를 통해 채널 튜닝·전환과 영상 출력을 처리합니다.
CAS 수신제한
NDS JCAS 기반 수신제한을 처리합니다. 가입자 상품 정보를 수신해 채널 권한·OTP·핑거프린트(FingerPrint)·시청 가능 여부를 제어합니다(cas-module).
가입 상품별 채널 히든
OOB(table id 85)로 내려오는 상품별 히든 채널 목록과 CAS 가입 상품을 매칭해 채널 리스트를 Rebuild하고 비가입 채널을 히든 처리합니다.
VOD 재생
Castis UMP 앱 연동으로 VOD를 재생합니다. HCN은 TSID 스캔 전체 목록과 SO Code를 전달하는 방식으로 정합되어 있으며, VOD 종료 시 기본 이동 채널 처리를 포함합니다.
PVR 녹화 · 예약
녹화/예약, 예약 충돌 처리, 스토리지 관리를 담당합니다(pvr-module의 PvrMain, PvrSessionManager, StorageManager).
케이블 백엔드 연동 (OOB/SDV/MGW)
OOB(Out-Of-Band) 데이터·다운로드 매니저, SDV(Switched Digital Video) 세션, MGW(Media Gateway) 메시지 송수신으로 케이블 방송 인프라와 연동합니다.
설정 · 사용자 환경
사용자 선호도(UP), 시스템 컨트롤러, PR(시청등급) 레벨, OTA 매니저 등 설정 도메인을 제공합니다(setting-module).
히든 / 제조사 메뉴
엔지니어용 진단·정합 메뉴를 다수의 FragmentSub* 화면으로 제공합니다. MAP_ID 입력, WIFI Hotspot, 해상도 변경, SW 강제 다운로드 등이 포함됩니다(hidden_menu-module).
RCU OTA · 블루투스
리얼텍 DFU 기반 리모컨 펌웨어 OTA 업데이트(rcu_ota-module)와 블루투스 리모컨/헤드셋 연결 관리(bt/)를 처리합니다.
음성 UX (VUX)
음성 프롬프트·STT·음성 키 매핑을 처리하는 VUX 모듈과 외부 음성 클라이언트(voiceclientlib-0.9.24 AAR)를 연동합니다(vux-module).
자동 재부팅 · 슬립 타이머
HCN 7일 주기 자동 재부팅 시나리오와 슬립 타이머를 알람 리시버(RebootAlarmReceiver, SleepTimerAlarmReceiver)로 처리합니다.
외부 연동 · AIDL 서비스
IEpgService 등 AIDL로 키즈랜드·스카이앨범 등 외부 앱에 EPG/계정 정보를 제공하고, 스카이라이프 오픈포털 인텐트(com.skylife.intent.*)를 수신합니다.
USB 재생 · 외부 저장소
USB 미디어 검색·재생(UsbPlayActivity, exteranlStorage/)을 지원합니다.

계층 · 외부 연동 관계

UI/런처 계층(app)은 common-module의 공통 베이스·설정·로그 위에서 동작하며, epg-module을 통해 채널·프로그램·재생을 제어합니다. 재생은 csp-module(CS Player)와 제조사 네이티브 라이브러리로 연결되고, 권한·시청 제어는 cas-module(NDS JCAS, jcasaidl.jar)이 담당합니다. 케이블 인프라 쪽으로는 oob-module(편성·상품·다운로드 데이터), sdv-module(스위치드 비디오), mgw-module(미디어 게이트웨이)이 HTTP/섹션 필터로 백엔드와 통신합니다. 외부 앱과는 AIDL 서비스(IEpgService)와 인텐트(오픈포털, DCA, 스카이앨범 상품 조회 등)로 연동합니다.

사이트 분기

자산 설정(config.ini의 SITE, dm_config_hcn_*.ini / dm_config_jcn_*.ini)과 코드 내 Config.isKaonSTb() / isTechniColorSTb() 분기로 사업자·제조사·환경(LIVE/TESTBED/LAB)을 구분합니다. 가온·테크니컬러 등 제조사별 인텐트·키 정합 차이를 흡수하도록 설계되어 있습니다.

핵심 동작 흐름

부팅 · 초기화 시퀀스

  1. 부트 이벤트 수신RebootAlarmReceiver가 BOOT_COMPLETED / LOCKED_BOOT_COMPLETED를 수신하고, 런처 우선순위(priority 3)에 따라 PlaybackActivity가 홈으로 기동됩니다.
  2. 채널 초기화BootManager가 BootChannelLoader로 채널 데이터를 초기화하고 EVENT_CHANNEL_INITIALIZED를 통지합니다. Barker 채널 스크램블 여부에 대비해 CAS 사용 가능 여부를 확인합니다(소스 확인).
  3. CAS 초기화CAS 클라이언트 초기화가 완료되면 EVENT_CAS_INITIALIZED를, 실패 시 WHAT_CAS_NOT_WORKING을 통지합니다. 가입자 상품·권한 정보를 확보합니다.
  4. OOB / DataManager 초기화OOB 섹션 필터로 편성·상품·다운로드 데이터를 수신하면 EVENT_DATA_MANAGER_INITIALIZED를 통지합니다. 수신 실패 시 ER-01/ER-02 에러 팝업을 표시합니다(요구사항 확인).
  5. 홈 진입 · 라이브 표시초기화 완료 후 마지막 시청 채널(LCW/Active 기준)로 진입해 라이브 영상을 출력하고 EPG·미니바를 사용할 수 있게 됩니다.

채널 시청 · 가입 상품 히든 처리

  1. 채널 선택리모컨 채널 입력/전환 키 또는 EPG에서 채널을 선택하면 재생 매니저가 튜닝을 요청합니다.
  2. 상품 매칭 · 히든 판정OOB(table id 85)로 내려온 상품별 히든 채널 목록과 CAS 가입 상품을 매칭해, 비가입 채널은 채널 리스트 Rebuild 시 히든 처리됩니다.
  3. CAS 권한 확인 · 재생CSP 플레이어가 튜닝하고 CAS가 스크램블 해제·시청 권한을 확인하면 영상이 출력됩니다. 권한이 없으면 가입 안내/제한 화면을 표시합니다.

VOD 재생 흐름

  1. VOD 진입VOD 메뉴/딥링크에서 콘텐츠를 선택하면 EPG가 재생 파라미터를 구성합니다.
  2. UMP 연동 호출HCN 정합에 따라 TSID 스캔 전체 목록과 SO Code(externalSoId)를 Castis UMP 앱으로 전달해 재생을 요청합니다.
  3. 종료 · 채널 복귀VOD 종료 시 기본 이동 채널 처리로 라이브 화면에 복귀합니다(최근 수정 이력 확인).

빌드 · 실행

Gradle Wrapper(gradlew)를 사용합니다. 프로덕트 플레이버는 uhd 단일 차원이며, 빌드 타입은 debug / debug_TB / release / release_TB / release_OTA / release_3PL / release_3PL_TB로 구분됩니다. 따라서 빌드 variant는 uhd + 각 빌드 타입 조합으로 생성됩니다.

# 클린
./gradlew clean

# 디버그 빌드 (uhd 플레이버)
./gradlew assembleUhdDebug

# 릴리스 빌드
./gradlew assembleUhdRelease

# TB(테스트벤치) 릴리스
./gradlew assembleUhdRelease_TB

# OTA 릴리스
./gradlew assembleUhdRelease_OTA

# 3PL 릴리스
./gradlew assembleUhdRelease_3PL
  • 버전은 app/version.properties의 VERSION_MAJOR/MINOR/PATCH(현재 0/52/0)로부터 app/version.gradle에서 versionCode(=major×10000+minor×100+patch)와 versionName(v_0.52.00)을 계산합니다.
  • 출력 APK명은 EPG_ANDR_<빌드일자(yyyyMMdd)>_v_x.yy.zz<빌드타입접미사>.apk 형식입니다(예: release_OTA → _OTA_TB, 3PL → _3PL).
  • 모든 빌드 타입은 etc/hcn.jks(alias SkyHCN) 키스토어로 v2 서명됩니다(빌드 스크립트에 키 정보 하드코딩).
  • minifyEnabled false로 난독화는 비활성화되어 있으나 proguard-rules.pro는 지정되어 있습니다.
  • 환경 설정 자산은 app/src/main/assets/config/에 위치하며(config.ini, dm_config_hcn_live.ini/_test.ini, dm_config_jcn_*.ini 등) 사업자·환경별로 분기됩니다.
  • 시스템 권한(WRITE_SECURE_SETTINGS, WRITE_EPG_DATA 등)과 제조사 네이티브 라이브러리에 의존하므로, 실제 실행은 STB 시스템 이미지 프리로드 환경을 전제로 합니다(추정).
