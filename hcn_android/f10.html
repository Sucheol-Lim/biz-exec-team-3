히든 / 제조사 메뉴

MainActivity가 제조사(가온·테크니컬러·이노피아)별로 FragmentBasic 화면 맵을 구성하고, HiddenStatus 상태값으로 다수의 FragmentSub* 진단·정합 화면을 전환합니다. MAP_ID 입력, WIFI Hotspot, 해상도 변경 등 엔지니어 메뉴를 제공합니다.

기능 개요

히든 메뉴는 현장 엔지니어가 단말 진단·정합을 수행하는 비공개 메뉴로, hidden_menu-module의 MainActivity가 진입점입니다. onCreate에서 단말 제조사를 판별(Utils.isKaonStb()·isTechStb()·isInnopiaStb())해 해당 제조사용 화면 맵(kaonMap / techniColorMap / 이노피아)을 구성합니다. 각 맵은 HiddenStatus 상수(예: MAINMENU, SUBMENU_721, SUBMENU_76)를 키로, 해당 화면 FragmentBasic 구현(FragmentMain·FragmentSub5 등 47여 개의 FragmentSub*)을 값으로 담습니다.

메인 메뉴(FragmentMain)는 리스트에서 항목을 선택하면 changeMenu(event)를 호출하고, MainActivity는 changeFragment(event)로 다음 화면을 결정해 framemain 컨테이너에 replace합니다. 일부 항목은 자체 화면 대신 구글 시스템 설정으로 위임합니다. 예를 들어 HDMI/SPDIF 오디오 설정(SUBMENU_721/75)은 openGoogleSoundSetting(), WIFI Hotspot(SUBMENU_76)은 openGoogleWifiHotspot(), IP 설정(SUBMENU_51)은 openGoogleIPSetting()으로 분기합니다. MAP_ID는 FragmentSub5가 TaurusUserPreferenceManager의 KEY_MAP_ID를 읽어 표시하고 입력받습니다.

설계 포인트
화면 전환을 HiddenStatus 정수 상태값 + 제조사별 Map<Integer, FragmentBasic> 조합으로 다룹니다. 같은 메뉴 번호라도 제조사에 따라 다른 화면(또는 구글 설정 위임)으로 연결되므로, 가온·테크니컬러·이노피아 박스의 정합 차이를 한 액티비티에서 흡수합니다.

흐름. 진입 시 제조사를 판별해 화면 맵을 구성하고 메인 메뉴를 띄우며, 항목 선택은 changeMenu/changeFragment로 다음 FragmentSub* 또는 구글 시스템 설정으로 분기합니다.

핵심 코드

hidden_menu-module/.../MainActivity.java — 상태값 기반 화면 전환과 제조사 분기
public void changeMenu(int event) {
    status = event;
    changeFragment(event);
    if (currentFragment == null) return;
    FragmentTransaction ft = fm.beginTransaction();
    Bundle bundle = new Bundle();
    bundle.putInt("event", event);
    currentFragment.setArguments(bundle);
    ft.replace(R.id.framemain, currentFragment);
    ft.commitAllowingStateLoss();
}

private void changeFragment(int event) {
    if (Utils.isTechStb() || Utils.isInnopiaStb()) {
        if (event == HiddenStatus.SUBMENU_721 || event == HiddenStatus.SUBMENU_75) {
            openGoogleSoundSetting();
        } else if (event == HiddenStatus.SUBMENU_76) {
            openGoogleWifiHotspot();          // WIFI Hotspot → 구글 설정 위임
        } else if (event == HiddenStatus.SUBMENU_51) {
            openGoogleIPSetting();
        } else {
            currentFragment = techniColorMap.get(event);
        }
    }
    // ... isKaonStb() 분기
}
