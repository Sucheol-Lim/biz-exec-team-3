기능 개요

과천 관제센터는 config.ts의 SITE_LIST에서 별도 code: 'GWACHEON'으로 정의되지만 realcode는 Air Map과 동일한 001ENV301입니다. 즉 데이터 출처(단위서비스코드)는 Air Map과 같으면서 측정망 운영용 화면만 분리한 진입점입니다. 경로는 /gwacheon/...으로 시작합니다.

특화 화면은 pages/overview/gwacheon 아래에 모여 있습니다. 통신 상태(CommunicationStatus/CommunicationStatusDetail), 미수신(NoReception/NoReceptionDetail), 센싱 오류(SensingError), 전송 실패(TransmissionFailure)가 라우트로 등록되어 있습니다. 각 화면은 디바이스 유형(실내·실외·청정기·악취/소음 등)·사업 유형(BIZ/CSV) 필터와 지역(시도/군구/동) 검색을 제공하며, 지역 필터는 첫 항목을 자동 선택하지 않고 미선택(전체 조회) 상태로 시작합니다.

데이터는 gwacheonApi의 측정망 전용 엔드포인트(gwacheon/summary, gwacheon/collection-status, gwacheon/reception-fault, gwacheon/sensing-error, gwacheon/transmission-error)에서 조회합니다. 각 목록은 download 플래그로 같은 경로에 .csv를 붙여 CSV 다운로드를 겸하며, 미수신 화면은 HandlerStatusModal을 통한 조치 처리(gwacheonApi.action → reception-fault/action)를 함께 지원합니다. 조치상태(미조치/조치중/완료)·미조치사유(임시철거/장비이설/출입불가/기타)는 실제 운영 코드값으로 정의되어 있고, 미수신 상세 조회(receptionFaultDetail)는 응답의 lastMeasuredDate를 화면 필드 updateDate로 매핑해 정합성을 맞춥니다.

통신 상태 상세(CommunicationStatusDetail)는 목록 행 클릭 시 전달받은 deviceId(경로)·serviceTargetId(state)로 gwacheonApi.collectionStatusDetail을 호출해 제조사·국소명·모델명·운용센터·모국 ID·유지보수 담당 등 실제 장비 정보를 조회합니다(초기의 더미 데이터 표시에서 실 API 연동으로 전환). 담당자 이름·연락처는 maskValue로 마스킹하고, KT 지도(ktGms.Map)는 문자열 위경도를 숫자로 변환해 [경도, 위도] 순서의 center로 표출하며, 줌·최대 줌은 config.ts의 공용 상수 DEFAULT_MAP_CENTER·DEFAULT_MAX_ZOOM_LEVEL을 사용합니다.

설계 포인트
과천을 별도 사이트 코드로 두어 권한 전환 제어(기능 11)에서 Air Map ↔ 과천 전환을 명시적으로 허용하면서, 실제 데이터는 같은 realcode로 일관되게 조회합니다.

/** 지도 기본 좌표 (서비스 대상 위경도가 없을 때 fallback) */
export const DEFAULT_ZOOM_LEVEL = 16;
export const DEFAULT_MAX_ZOOM_LEVEL = 30;
export const DEFAULT_MAP_CENTER = { lng: DEFAULT_LONGITUDE, lat: DEFAULT_LATITUDE, zoom: DEFAULT_ZOOM_LEVEL };
src/api/gwacheon.ts — 측정망 전용 목록 + CSV 겸용 · 미수신 조치 · 상세 필드 매핑
export const gwacheonApi = {
  summary: (params, download?) =>
    apiClient.get(`/bff/monitor/gwacheon/summary${download ? '.csv' : ''}`, { /* responseType blob */ }),
  sensingError: (params, download?) =>
    apiClient.get(`/bff/monitor/gwacheon/sensing-error${download ? '.csv' : ''}`, { /* ... */ }),
  action: (params) =>
    apiClient.post(`/bff/monitor/gwacheon/reception-fault/action`, { ...params }),  // 미수신 조치

  receptionFaultDetail: async (serviceTargetId, deviceId) => {
    const res = await apiClient.get(
      `/bff/monitor/gwacheon/reception-fault/${serviceTargetId}/${deviceId}`,
    );
    if (res.data?.result) {  // 응답의 lastMeasuredDate를 화면 필드 updateDate로 매핑
      const { lastMeasuredDate, ...rest } = res.data.result;
      res.data.result = { ...rest, updateDate: lastMeasuredDate };
    }
    return res.data;
  },
};

// 목록(CommunicationStatus) — 행 클릭 시 deviceId 경로 + row의 serviceTargetId를 state로 전달

return res.result;   // manufacturer / deviceName / operationCenter / maint1 ...
