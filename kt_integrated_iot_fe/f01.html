멀티 사이트 통합 관제

기능 개요

본 콘솔은 KT가 개별 운영하던 여러 IoT 서비스를 하나의 React SPA로 통합합니다. 어떤 서비스에 진입했는지는 URL 첫 세그먼트(/:site)로 결정되며, config.ts의 SITE_LIST가 각 서비스의 path(air, dx, fire-detector, emergency-door, fire-monitoring, emergency-bell, ami, smart-green, gwacheon)와 단위서비스코드(code/realcode)를 매핑합니다.

라우터(routes/route.tsx)는 최상위 경로를 모두 /:site로 두고, SiteGuard가 URL의 site가 SITE_LIST에 존재하는지(ALLOWED_SITE_PATHS) 먼저 검사합니다. 유효하면 로그인 화면(AuthLayout) 또는 보호 화면(ProtectedRoute → MainLayout)으로 분기하고, 같은 화면 컴포넌트(예: Home, Summary, HistoryMain)가 세션의 site.code를 읽어 사이트별 위젯·테이블·차트를 다르게 렌더링합니다.

로그인 시 선택한 사이트의 realcode는 세션에 저장되어 이후 모든 API 요청의 unitServiceCode 헤더로 주입됩니다. 즉 같은 코드베이스가 사이트 코드에 따라 데이터·메뉴·외형을 분기하는 멀티 테넌트 구조입니다.

헤더의 사이트 전환 메뉴(SITE_MENU)에서 AI산업안전DX는 AIENVDX_SERVICE_TYPE_LIST(산업대기질·자원순환·산업환경·탄소중립·제조공정)를 매핑해 serviceType 단위 하위 메뉴로 전개됩니다. 보호 라우트에는 위젯 설정 페이지(widget-settings)가 추가되었고, 접근 허용 서비스타입은 WIDGET_SETTING_SERVICE_TYPES·isWidgetSettingServiceType으로 중앙 관리합니다(현재 제조공정 전용). 한편 SMS 수신 동의 페이지(/:site/sms-consent)는 SiteGuard·ProtectedRoute를 타지 않는 독립 공개 라우트로 추가되었으며, 이때 :site는 사이트 코드가 아니라 이 페이지 전용 브랜드 키(air/safemate)로만 판별됩니다.

설계 포인트
과천 관제센터(GWACHEON)는 별도 code를 갖지만 realcode는 Air Map과 동일한 001ENV301입니다. 즉 데이터 출처는 Air Map과 같되 화면(특화 관제)만 분리한 진입점입니다.

관계. config가 사이트 메타 목록을 보유하고, ThemeRoutes가 이를 근거로 SiteGuard를 통해 분기합니다. 각 화면은 SITE_CODES 상수로 사이트별 동작을 결정합니다.

핵심 코드

src/config.ts — 사이트 목록과 코드 상수 정의
export const SITE_LIST = [
  { code: '001ENV301', realcode: '001ENV301', title: 'Air Map', path: 'air' },
  { code: '001ENV302', realcode: '001ENV302', title: 'AI산업안전DX', path: 'dx' },
  { code: '001SAF100', realcode: '001SAF100', title: 'SafeMate', subTitle: '지능형 화재 감지기', path: 'fire-detector' },
  // ... SafeMate 4종 / 한전 AMI / SMART GREEN ...
  { code: 'GWACHEON', realcode: '001ENV301', title: 'Air Map', subTitle: '과천 관제센터', path: 'gwacheon' },
];

export const SITE_CODES = {
  AIRMAP: SITE_LIST.find((s) => s.path === 'air')?.code || '',
  DX: SITE_LIST.find((s) => s.path === 'dx')?.code || '',
  // ...
  GWACHEON: SITE_LIST.find((s) => s.path === 'gwacheon')?.code || '',
} as const;

// 헤더 사이트 전환 메뉴: AI산업안전DX 는 serviceType 하위 메뉴로 전개
export const SITE_MENU = [
  // ...
  {
    title: 'AI산업안전DX',
    children: AIENVDX_SERVICE_TYPE_LIST.map((item) => ({
      code: '001ENV302', realcode: '001ENV302',
      title: item.label,      // 산업대기질/자원순환/산업환경/탄소중립/제조공정
      path: 'dx', serviceType: item.id,
    })),
  },
  // ...
];
src/routes/route.tsx — 모든 경로를 /:site 아래에 두는 가드
const ALLOWED_SITE_PATHS = SITE_LIST.map((s) => s.path);

const SiteGuard = ({ children }: { children: React.ReactNode }) => {
  const { site } = useParams();
  if (!site || !ALLOWED_SITE_PATHS.includes(site)) {
    return <Error />;            // 미등록 사이트면 에러 화면
  }
  // ... 권한 기반 전환 검사(checkPermission) 후 children 렌더 ...
  return children;
};

// routes 최상위: { path: '/:site', element: <SiteGuard><Outlet /></SiteGuard> }

// SMS 수신 동의 페이지: SiteGuard/ProtectedRoute 를 타지 않는 독립 공개 라우트
{
  path: '/:site/sms-consent',
  element: <SmsConsentPage />,
},
