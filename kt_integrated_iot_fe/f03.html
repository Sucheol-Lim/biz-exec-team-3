기능 개요

DashboardMap은 react-grid-layout의 Responsive + WidthProvider를 사용해 위젯 카드를 격자에 배치합니다. 컨테이너 크기에 맞춰 cols와 maxRows를 동적으로 계산하고, config.ts의 GRID_LAYOUT_* 상수로 격자 단위·여백을 정합니다. 저장된 위젯 목록은 getSavedWidgets(site.code, 'map_' + serviceType, savedWidgets)로 사이트·서비스타입별로 불러옵니다. 저장분이 없으면 types/widget.ts의 사이트별 기본 배치(defaultAirmapAirCard·defaultAirmapAirMap 등)로 대체하고, Air Map 지도형에서는 normalizeWidgets가 message_stats_kpi 위젯의 높이를 고정 보정합니다. 위젯 추가 팝업 목록은 getAvailableWidgets(code, type)이 반환하며, 스마트그린의 '디바이스 생육 현황'(device_growth_status)은 카드형에서만 추가할 수 있도록 availableSmartGreenWidgetsCard로 분리했습니다(지도형 제외). 스마트그린 기본 배치의 위젯별 최소 크기(mW/mH)도 상향 조정되었습니다.

각 카드는 WidgetComp(components/widget)가 위젯 type에 따라 적절한 위젯 컴포넌트(예: OverAllStatus, EventOccurrence, DeviceStatus, WeatherInfo, AMI/SMART GREEN 위젯 등)를 골라 렌더링합니다. 위젯 목록과 배치는 commonApi.widgetList()로 조회하고 registWidget·editWidget·deleteWidget으로 영속화합니다. 이와 별개로 관리 메뉴에 위젯 설정 페이지(widget-settings)가 신설되어, config.ts의 WIDGET_SETTING_SERVICE_TYPES(isWidgetSettingServiceType)로 허용된 서비스타입 — 현재 AI산업안전DX 제조공정 전용 — 에서만 메뉴가 노출됩니다.

편집 모드(isEditMode)에서만 드래그·리사이즈가 허용되며, onLayoutChange가 변경된 좌표·크기를 위젯 상태에 반영합니다. limitBottom이 카드가 격자 최대 행(GRID_LAYOUT_MAX_ROWS)을 넘지 않도록 보정합니다. 편집 종료 시 WidgetControl이 변경 배치를 저장합니다.

설계 포인트
비편집 상태에서는 빈 격자 영역의 클릭이 아래 지도로 전달되도록 부모 Stack의 pointerEvents를 none으로 두고, 각 카드 Box만 auto로 두어 지도와 위젯이 한 화면에 공존합니다.

src/pages/home/DashboardMap.tsx — 위젯 → 그리드 레이아웃 매핑
const ResponsiveGridLayout = WidthProvider(Responsive);

const layout: Layout[] = widgets.map((w) => ({
  i: w.type, x: w.x, y: w.y, w: w.w, h: w.h,
  minW: w.mW ? w.mW : w.w,
  minH: w.mH ? w.mH : w.h,
}));

const handleLayoutChange = (newLayout: Layout[]) => {
  if (isEditMode) {
    const updated = widgets.map((w) => {
      const item = newLayout.find((l) => l.i === w.type);
      if (!item) return w;
      return { ...w, x: item.x, y: item.y, w: item.w, h: item.h };
    });
    setWidgets(updated);
  }
};
src/api/common.ts — 위젯 배치 저장 엔드포인트
widgetList: (serviceType?: string) =>
  apiClient.get('/bff/monitor/widgets', {
    params: { size: 100, page: 0, serviceType: serviceType?.trim() || undefined },
  }).then((res) => res.data),
registWidget: (params) =>
  apiClient.post('/bff/monitor/widgets', { ...params }).then((res) => res.data),
editWidget: (id, params) =>
  apiClient.put(`/bff/monitor/widgets/${id}`, { ...params }).then((res) => res.data),
deleteWidget: (id) =>
  apiClient.delete(`/bff/monitor/widgets/${id}`).then((res) => res.data),

export const getSavedWidgets = (code, type, widgetData, isDefault?) => {
  const normalizeWidgets = (widgets) => {
    if (!widgets) return widgets;
    if (code === SITE_CODES.AIRMAP && type.startsWith('map')) {
      return widgets.map((widget) =>
        widget.type === 'message_stats_kpi'
          ? { ...widget, h: 18, mH: widget.mH ?? 12 }
          : widget,
      );
    }
    return widgets;
  };

  const saved =
    widgetData && widgetData[code] && widgetData[code][type] ? widgetData[code][type] : null;
  if (saved && saved.length > 0 && !isDefault) {
    return normalizeWidgets(saved);
  } else {
    switch (code) {
      case SITE_CODES.AIRMAP:
        return normalizeWidgets(type.startsWith('card') ? defaultAirmapAirCard : defaultAirmapAirMap);
      // ... 사이트 코드별 기본 배치 분기
    }
  }
};

// 위젯 추가 팝업: 스마트그린 '디바이스 생육 현황'은 카드형에서만 추가 가능
export const getAvailableWidgets = (code: string, type: string): Widget[] => {
  switch (code) {
    case SITE_CODES.AIRMAP:
      return availableAirmapWidgets;
    case SITE_CODES.SMART_GREEN:
      return type.includes('card') ? availableSmartGreenWidgetsCard : availableSmartGreenWidgets;
    default:
      return getSavedWidgets(code, type, null, true) ?? [];
  }
};
