기능 개요

DashboardMap은 react-grid-layout의 Responsive + WidthProvider를 사용해 위젯 카드를 격자에 배치합니다. 컨테이너 크기에 맞춰 cols와 maxRows를 동적으로 계산하고, config.ts의 GRID_LAYOUT_* 상수로 격자 단위·여백을 정합니다. 저장된 위젯 목록은 getSavedWidgets(site.code, 'map_' + serviceType, savedWidgets)로 사이트·서비스타입별로 불러옵니다. 저장분이 없으면 types/widget.ts의 사이트별 기본 배치(defaultAirmapAirCard·defaultAirmapAirMap 등)로 대체하고, Air Map 지도형에서는 normalizeWidgets가 message_stats_kpi 위젯의 높이를 고정 보정합니다. 위젯 추가 팝업 목록은 getAvailableWidgets(code, type)이 반환하며, 스마트그린의 '디바이스 생육 현황'(device_growth_status)은 카드형에서만 추가할 수 있도록 availableSmartGreenWidgetsCard로 분리했습니다(지도형 제외). 스마트그린 기본 배치의 위젯별 최소 크기(mW/mH)도 상향 조정되었습니다.

각 카드는 WidgetComp(components/widget)가 위젯 type에 따라 적절한 위젯 컴포넌트(예: OverAllStatus, EventOccurrence, DeviceStatus, WeatherInfo, AMI/SMART GREEN 위젯 등)를 골라 렌더링합니다. Air Map에는 상태별 색상 범례 위젯(status_color_legend → StatusColorLegend)이 신설되어 지도형·카드형 기본 배치와 추가 가능 목록에 모두 포함되었습니다. 범례 색상은 hex를 직접 박지 않고 airQuality의 GRADE_CONFIG를 단일 소스로 참조하므로, 지도 마커·차트의 등급색과 항상 같은 값을 씁니다. 위젯 목록과 배치는 commonApi.widgetList()로 조회하고 registWidget·editWidget·deleteWidget으로 영속화합니다. 이와 별개로 관리 메뉴에 위젯 설정 페이지(widget-settings)가 신설되어, config.ts의 WIDGET_SETTING_SERVICE_TYPES(isWidgetSettingServiceType)로 허용된 서비스타입 — 현재 AI산업안전DX 제조공정 전용 — 에서만 메뉴가 노출됩니다.

편집 모드(isEditMode)에서만 드래그·리사이즈가 허용되며, onLayoutChange가 변경된 좌표·크기를 위젯 상태에 반영합니다. limitBottom이 카드가 격자 최대 행(GRID_LAYOUT_MAX_ROWS)을 넘지 않도록 보정합니다. 편집 종료 시 WidgetControl이 변경 배치를 저장합니다.

대시보드 위젯은 사용자가 새로고침하지 않아도 최신 값을 유지해야 하므로, modules/autoRefresh 모듈이 신설되어 5분 주기 배경 갱신을 담당합니다. 각 위젯은 createAutoRefreshQueryOptions({ scope, fetcher })로 React Query 옵션을 만들고, 이 팩토리가 queryFn(화면 조회)과 meta.autoRefresh.backgroundFetch(배경 갱신)를 같은 fetcher로 묶습니다. 덕분에 두 경로가 같은 API·같은 변환을 공유하고, 배경 경로만 requestMode: 'background'·skipError: true·30초 타임아웃(AUTO_REFRESH_REQUEST_TIMEOUT_MS)을 덧붙여 실패해도 오류 팝업을 띄우지 않습니다. meta는 해당 사이트가 자동 갱신 대상일 때만 붙이므로(isAirMapAutoRefreshTarget 등), 대상이 아닌 사이트에서는 위젯이 종전대로 동작합니다.

실제 스케줄러는 AutoRefreshBoundary입니다. 마운트 시 AUTO_REFRESH_INTERVAL_MS(5분) 타이머를 걸고, 발화하면 QueryCache에서 meta.autoRefresh.scope가 자신의 스코프와 같은 활성 Query만 모아 배경 갱신 배치를 돌립니다. 배치 직전에 commonApi.refreshToken으로 세션 토큰을 먼저 회전시키며, 응답의 access token JWT에서 뽑은 id(getTokenPayloadId)가 요청 당시 사용자와 다르면 커밋하지 않습니다. 갱신 결과를 캐시에 반영하기 전에는 canCommitBackgroundResult()가 dispose·pause 세대·사이트 일치·Query 인스턴스 동일성·활성 여부·foreground 진행 여부·dataUpdateCount/errorUpdateCount 불변을 모두 확인해, 늦게 도착한 응답이 최신 화면 데이터를 덮어쓰지 못하게 막습니다. 탭이 숨겨지거나 오프라인이면 타이머를 걷고 재예약하지 않습니다. 전체 기능은 VITE_AUTO_REFRESH_ENABLED 플래그로 켜고 끕니다.

위젯 편집 중에 화면이 갱신되면 편집 상태가 흔들리므로, DashboardMap·DashboardCard는 isEditMode가 켜지는 동안 pauseAutoRefresh()를 호출하고 편집이 끝나는 시점(effect cleanup)에 resumeAutoRefresh()로 새 5분을 시작합니다. 위젯 내부의 필터 변경처럼 사용자가 방금 조작한 직후에는 postponeAutoRefresh()로 유휴 타이머만 뒤로 미룹니다. useAutoRefreshActivity()는 바운더리 밖이나 플래그 OFF 상태에서도 항상 안전한 no-op 기본값을 돌려주므로 호출부에 분기가 필요 없습니다.

설계 포인트
비편집 상태에서는 빈 격자 영역의 클릭이 아래 지도로 전달되도록 부모 Stack의 pointerEvents를 none으로 두고, 각 카드 Box만 auto로 두어 지도와 위젯이 한 화면에 공존합니다. 자동 갱신 쪽에서는 pausedRef·hiddenRef 같은 상태를 모두 ref로 관리해, pause/resume이 일어날 때마다 바운더리가 재렌더되어 하위 위젯 트리 전체가 다시 그려지는 일을 피합니다.

export const getSavedWidgets = (code, type, widgetData, isDefault?) => {
  const normalizeWidgets = (widgets) => {
    if (!widgets) return widgets;
    if (code === SITE_CODES.AIRMAP && type.startsWith('map')) {
      return widgets.map((widget) =>
        widget.type === 'message_stats_kpi'
          ? { ...widget, h: 18, mH: widget.mH ?? 12 }
          : widget,
      );
    }
    return widgets;
  };

  const saved =
    widgetData && widgetData[code] && widgetData[code][type] ? widgetData[code][type] : null;
  if (saved && saved.length > 0 && !isDefault) {
    return normalizeWidgets(saved);
  } else {
    switch (code) {
      case SITE_CODES.AIRMAP:
        return normalizeWidgets(type.startsWith('card') ? defaultAirmapAirCard : defaultAirmapAirMap);
      // ... 사이트 코드별 기본 배치 분기
    }
  }
};

// 위젯 추가 팝업: 스마트그린 '디바이스 생육 현황'은 카드형에서만 추가 가능
export const getAvailableWidgets = (code: string, type: string): Widget[] => {
  switch (code) {
    case SITE_CODES.AIRMAP:
      return availableAirmapWidgets;
    case SITE_CODES.SMART_GREEN:
      return type.includes('card') ? availableSmartGreenWidgetsCard : availableSmartGreenWidgets;
    default:
      return getSavedWidgets(code, type, null, true) ?? [];
  }
};
src/modules/autoRefresh/createAutoRefreshQueryOptions.ts — foreground/background가 같은 fetcher를 공유
// foreground/background가 동일 API·동일 transform(fetcher)을 공유하도록 강제하는 factory.
// backgroundFetch는 select 이전의 raw shape을 그대로 반환해야 하므로, fetcher 자체가
// select 없는 순수 fetch+transform 함수여야 한다.
export function createAutoRefreshQueryOptions<TData>({ scope, fetcher, meta }) {
  return {
    queryFn: ({ signal }: { signal?: AbortSignal }) => fetcher({ mode: 'foreground', signal }),
    meta: {
      ...meta,
      autoRefresh: {
        scope,
        backgroundFetch: () => fetcher({ mode: 'background' }),
      },
    } satisfies QueryMeta,
  };
}

// 위젯 호출부 — 사이트가 자동 갱신 대상일 때만 meta 를 붙인다
const { data } = useQuery({

  queryFn: outdoorStatusAutoRefreshOptions.queryFn,
  ...(isAirMapAutoRefreshTarget ? { meta: outdoorStatusAutoRefreshOptions.meta } : {}),

src/modules/autoRefresh/AutoRefreshBoundary.tsx — 배경 갱신 커밋 가드
const canCommitBackgroundResult = ({ startedQuery, baselineDataUpdateCount,
                                     baselineErrorUpdateCount, pauseGeneration }) => {
  if (disposedRef.current) return false;
  if (pausedRef.current) return false;
  if (pauseGeneration !== pauseGenerationRef.current) return false;   // pause 이전 요청
  if (!isSiteSynchronized()) return false;                            // 사이트 전환됨

  const currentQuery = queryClient.getQueryCache()
    .find({ queryKey: startedQuery.queryKey, exact: true });

  if (!currentQuery || currentQuery !== startedQuery) return false;   // Query 인스턴스 교체
  if (!currentQuery.isActive()) return false;                         // 화면에서 사라짐
  if (currentQuery.state.fetchStatus === 'fetching') return false;    // foreground 진행 중

  // 요청 시작 이후 화면에서 이미 갱신됐다면 덮어쓰지 않는다
  return currentQuery.state.dataUpdateCount === baselineDataUpdateCount
      && currentQuery.state.errorUpdateCount === baselineErrorUpdateCount;
};
src/pages/home/DashboardMap.tsx — 편집모드 동안 자동 갱신 일시정지
const { pauseAutoRefresh, resumeAutoRefresh } = useAutoRefreshActivity();

// 위젯 편집모드 동안은 자동 갱신을 pause하고, 저장/취소로 편집모드가 끝나는 시점(effect cleanup)부터
// 새 5분을 시작한다. 초기화/이전/추가/drag/resize는 isEditMode 자체를 바꾸지 않으므로 pause가 유지된다.
useEffect(() => {
  if (!isEditMode) {
    return undefined;
  }

  pauseAutoRefresh();

  return () => {
    resumeAutoRefresh();
  };
}, [isEditMode, pauseAutoRefresh, resumeAutoRefresh]);
