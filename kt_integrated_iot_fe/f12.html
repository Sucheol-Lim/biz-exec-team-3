기능 개요

로그인 화면(pages/auth/Login.tsx)은 Formik 폼에 입력된 ID/비밀번호로 로그인합니다. 제출 시 먼저 commonApi.getRsakey(id)로 사용자별 RSA 공개키(modulus·exponent)와 randomString을 받아, encryptPassword(utils/rsa.ts)로 비밀번호를 PKCS#1 v1.5 패딩 후 RSA 암호화합니다. 이어 executeRecaptcha('login')으로 reCAPTCHA v3 토큰을 발급받습니다.

암호화된 비밀번호·randomString·reCAPTCHA 토큰을 묶어 commonApi.login()으로 전송하며, 토큰은 X-RECAPTCHA-TOKEN 헤더로 함께 전달됩니다. 응답이 OK이고 사용자가 해당 사이트 권한(플랫폼 관리자이거나 unitServiceCodes에 대상 코드 포함)을 가지면 accessToken·site를 세션에 저장하고 사용자 정보·서비스 대상을 세팅한 뒤 홈으로 이동합니다. 비밀번호 만료/임시 비밀번호면 약관·비밀번호 변경 모달을 거칩니다.

개인정보 마스킹은 maskValue(type, value) 유틸이 전화번호·ID·IP·이메일 타입별 규칙으로 일부 문자를 *로 가립니다. 마스킹 해제는 ChangeMask 모달로 사유·인증을 거쳐 평문을 조회하며(userDetail(..., mask, reason)), OTP(Otp)·비밀번호 변경(ChangePassword) 등 추가 인증 모달이 함께 제공됩니다.

설계 포인트
RSA 암호화는 외부 키 노출 없이 비밀번호 평문이 네트워크에 흐르지 않도록 클라이언트에서 수행합니다. rsa.ts는 BigInt 기반 modPowInt(Square-and-Multiply)로 모듈러 지수승을 구현해 별도 의존성 없이 동작합니다.

흐름. RSA 키 수신 → 비밀번호 암호화 → reCAPTCHA 토큰 발급 → 로그인 요청 → 권한 확인 후 세션 저장의 순서로 진행됩니다.

핵심 코드

src/pages/auth/Login.tsx — RSA 암호화 + reCAPTCHA 로그인
const { data: rsaResult } = await rsaQuery.refetch();
const { exponent, modulus, randomString } = rsaResult.result;
const encryptedPassword = encryptPassword(formik.values.password, modulus, exponent);
const recaptchaToken = await executeRecaptcha('login');
const payload = { id: formik.values.userId, password: encryptedPassword, randomString, recaptchaToken };
const loginResult = await loginMutation.mutateAsync(payload);
if (loginResult.message === 'OK') {
  if (loginResult.result.userRoleId === USER_ROLES[4].roleId
      || loginResult.result.unitServiceCodes.includes(target?.realcode)) {
    setSessionStorage('accessToken', loginResult.result.accessToken);
    setSessionStorage('site', target);
  }
}
src/utils/util.ts — 타입별 개인정보 마스킹
export function maskValue(type, value): string | null {
  if (type == null || value == null) return null;
  switch (type) {
    case 'phone': /* 6~8번째 자리를 * 로 */ return value.replace(/\d/g, ...);
    case 'id':    return value.length <= 3 ? '***' : value.slice(0, -3) + '***';
    case 'email': /* local 뒤 3자리 마스킹 */ return `${local.slice(0, -3)}***@${domain}`;
    default:      return value.length <= 1 ? '*' : value.slice(0, -1) + '*';
  }
}
