실시간 이벤트 수신

기능 개요

WebSocketProvider는 전역 컨텍스트로, connect() 호출 시 먼저 commonApi.subscription()으로 구독 큐 ID를 받아 세션에 저장합니다. 이후 @stomp/stompjs의 Client를 VITE_WEBSOCKET_SERVER 브로커로 활성화하고, 연결되면 해당 큐를 구독해 메시지 수신을 시작합니다. 재연결 지연·하트비트가 설정되어 있고, STOMP 오류는 최대 5회(MAX_RETRY)까지 재시도 후 connectionError를 세웁니다.

수신 메시지는 텍스트일 수도, 바이너리일 수도 있습니다. decodeBinaryMessage가 바이너리 페이로드를 Uint8Array로 변환하고, 앞 두 바이트가 0x1f 0x8b이면(GZIP 매직) pako.inflate로 해제한 뒤 UTF-8로 디코딩합니다. 디코딩 결과는 JSON.parse로 객체화됩니다.

라우팅 분기는 단순합니다. 파싱된 데이터에 threadId가 있고 AI 에이전트가 활성(isActiveAgent)이면 setLastMessage(에이전트 응답)로, 그 외에는 setLastEvent(관제 이벤트)로 보냅니다. lastEvent는 지도 마커·위젯·Alarm 등이 구독해 화면에 반영합니다.

여기에 더해 화면 데이터를 최신으로 유지하는 두 번째 경로로 5분 주기 배경 갱신(modules/autoRefresh)이 신설되었습니다. WebSocket이 이벤트 발생 시점에 밀어주는 신호를 담당한다면, 자동 갱신은 홈·종합현황 위젯의 집계·현황 값을 주기적으로 다시 끌어옵니다. 이벤트 목록 위젯이 쓰는 logEventApi.eventList는 이 배경 경로를 받도록 요청 옵션 인자를 추가로 받게 되었고, 노출 건수도 3건에서 5건으로 늘었습니다. 자세한 스케줄러 동작은 카드형 종합 현황 문서에 정리되어 있습니다.

배경 요청이 늘면서 공용 응답 인터셉터(ApiClient)도 두 군데 조정되었습니다. 첫째, TanStack Query가 화면 이탈·Query 교체 시 AbortSignal로 취소한 요청은 서비스 장애가 아니므로 axios.isCancel로 걸러 오류 팝업 없이 취소 상태를 그대로 전달합니다. 둘째, skipError 요청이 인터셉터 앞단에서 조기 반환되던 처리를 걷어내, 팝업만 억제하고 401 인증 오류 처리(세션 정리·로그인 이동)는 그대로 통과하도록 바꿨습니다.

설계 포인트
구독은 사용자 식별을 위해 헤더 USER_ID를 함께 보냅니다. disconnect()는 STOMP 클라이언트를 비활성화하고 재시도 카운트를 초기화하며, 권한 부적합 전환·로그아웃 시 호출됩니다.

핵심 코드

src/contexts/WebSocketProvider.tsx — GZIP 판별·해제
const isGzipCompressed = (bytes: Uint8Array) =>
  bytes.length >= 2 && bytes[0] === 0x1f && bytes[1] === 0x8b;

const decodeBinaryMessage = async (message: IMessage) => {
  if (typeof message.body === 'string') return message.body;
  const raw = message.binaryBody ?? (message as any)._binaryBody;
  const bytes = await toUint8Array(raw);
  const decoded = isGzipCompressed(bytes) ? pako.inflate(bytes) : bytes;
  return new TextDecoder('utf-8').decode(decoded);
};
src/contexts/WebSocketProvider.tsx — 구독·라우팅 분기
const subscriptionResult = await commonApi.subscription();
const queueId = subscriptionResult?.result?.queue;
// ...
client.subscribe(queueId, async (message) => {
  const decoded = await decodeBinaryMessage(message);
  const stompData = JSON.parse(decoded);
  if (stompData.threadId && isActiveAgent) {
    setLastMessage(stompData);      // AI 에이전트 응답
  } else if (stompData) {
    setLastEvent(stompData);        // 관제 이벤트
  }
}, { USER_ID: user?.id });
src/api/ApiClient.ts — 취소 요청 제외 · skipError 도 401 처리는 통과
apiClient.interceptors.response.use(
  (res) => res,
  (error) => {
    // TanStack Query가 화면 이탈·Query 교체 시 AbortSignal로 취소한 요청은
    // 서비스 장애가 아니므로 오류 팝업을 표시하지 않고 취소 상태를 그대로 전달한다.
    if (axios.isCancel(error)) {
      return Promise.reject(error);
    }

    const skipError = error.config?.skipError;
    const status = error?.response?.status ?? error?.status;

    // skipError 요청도 401 인증 오류 처리는 통과해야 하므로 기존 조기 반환을 제거했다.

    if (status === 401) {
      // ... 세션 정리 후 /:site 로그인으로 이동
    }
  },
);
