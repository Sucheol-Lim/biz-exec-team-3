통계 요약·분석

기능 개요

Summary 화면(pages/summary/index.tsx)은 세션의 site.code에 따라 사이트별 요약 컴포넌트(airmap/DashBoard, aidx/Overall, SafeMate 4종, smartgreen/overall)를 분기 렌더링합니다. 추가 분석 화면으로 AI산업안전DX 설비 이용률(EquipmentUtilization)·자원환경(ResourceEnvironment), SMART GREEN 생육 디바이스 분석(GrowthDevice), 측정소 분석(StationAnalysis) 등이 라우팅에 등록되어 있습니다.

차트는 components/chart 아래의 Nivo 래퍼들(NivoStackedBarChart, NivoGroupedBarChart, NivoLineChart, NivoPie, NivoComposedChart 등)을 사용합니다. 각 래퍼는 @nivo/bar·@nivo/line 등의 Responsive* 컴포넌트를 감싸고, useChartBar·useChartLine·useChartTheme 훅으로 데이터 가공과 라이트/다크 테마를 적용합니다. 게이지·일부 커스텀 시각화에는 D3가 함께 쓰입니다.

데이터는 React Query로 도메인 API(예: rooftopDoorApi, intFireDetectorApi, airmap·smartGreen 모듈 등)에서 조회합니다. 요약 화면의 다운로드 버튼은 downloadFileFromResponse로 Content-Disposition 기반 CSV 저장을 수행합니다.

설계 포인트
차트 데이터 가공 로직을 useChartBar/useChartLine 훅으로 분리해, 동일한 Nivo 래퍼를 여러 사이트·지표에서 재사용합니다. 라벨 한글화는 labelMap으로 키→라벨 매핑을 주입합니다.

흐름. 사이트별 요약 컴포넌트가 통계를 조회·가공해 Nivo 차트로 시각화하고, 필요 시 CSV로 다운로드합니다.

import { ResponsiveBar } from '@nivo/bar';
import useChartBar from '@/hooks/useChartBar';
import useChartTheme from '@/hooks/useChartTheme';

interface NivoStackedBarChartProps {
  data: { [key: string]: any }[];
  indexBy: string;
  keys: string[] | undefined;
  chartColors?: string[];
  labelMap?: { [key: string]: string }; // 키를 한글 라벨로 매핑

src/pages/summary/index.tsx — 통계 다운로드(CSV)
const rooftopDownloadMutation = useMutation({
  mutationFn: () =>
    rooftopDoorApi.summaryHistoryCollection(
      { size: MAX_DATA_ROW, page: 0, startDate, endDate,
        serviceTargetId: headerServiceTarget?.serviceTargetId ?? '' },
      true,
    ),
  onSuccess: (res) => {
    downloadFileFromResponse(res, `safemate_roof_summary_${dayjs().format('YYYYMMDD')}.csv`);
  },
});
