기능 개요

Home 화면은 viewType이 'M'(Map)일 때 지도형 대시보드를 렌더링합니다. ktGms.Map 인스턴스를 useRef로 보관하고, VITE_KT_MAP_API_KEY를 Bearer 토큰으로 넘겨 지도를 초기화합니다. 지도 스타일(styledata) 로드 시 라이트 모드면 틴트 레이어를 추가하고 불필요한 POI 레이어를 필터링합니다.

서비스 대상(headerServiceTarget)이 바뀌면 HomeMapState에 좌표·줌을 저장해 flyTo로 이동시킵니다. 마커 검색(MarkerSearch)으로 받은 markerList는 MarkerStateHandler가 감시하여, 특정 디바이스로 이동(flyTo)하거나 범위에 맞춰(fitBounds) 카메라를 옮기고, 필요 시 마커 다이얼로그(openMarkerDialog)를 띄웁니다.

지도 위에는 MapControllers(줌·내 위치 등 컨트롤), MapToolbar(지도/도면 전환, 커버리지·플래그 토글)가 오버레이됩니다. 그리기 기능은 전역 DrawControlContext가 ktGms.control.DrawControl 인스턴스를 보관해 폴리곤·라인 그리기 모드를 제어합니다. 도면 모드에서는 DrawingViewer가 시설 도면 위에 마커를 표시합니다.

설계 포인트
한전 AMI(SITE_CODES.AMI)는 지도 표출 대상이 아니어서 지도 DOM과 마커 검색을 렌더링하지 않고 카드형 화면으로만 동작합니다.

핵심 코드

src/pages/home/Home.tsx — KT 지도 SDK 초기화
import ktGms from 'kt-map-sdk-js';
const MAP_KEY = import.meta.env.VITE_KT_MAP_API_KEY;

map.current = new ktGms.Map({
  container: mapDOM.current,
  style: 'normal',
  center: [mapState.lng, mapState.lat],
  zoom: mapState.zoom,
  access_token: 'Bearer ' + MAP_KEY,
  ktLogo: false,
  geolocateControl: true,
});
map.current?.on('load', () => setIsMapLoaded(true));
map.current?.on('styledata', () => {
  if (mode === 'light') addTintLayer(map);
  filterPoiLayers(map);
});
src/pages/home/Home.tsx — 마커로 카메라 이동 후 상세 다이얼로그 표시
map.current?.flyTo({
  center: [Number(targetMarker.longitudeValue), Number(targetMarker.latitudeValue)],
  zoom: 16, speed: 2.5, essential: true,
});
if (mapState.marker?.modalType) {
  openMarkerDialog({
    properties: { ...targetMarker, openDetail: mapState.marker?.modalType === 'DETAIL' },
    coordinates: [Number(targetMarker.longitudeValue), Number(targetMarker.latitudeValue)],
  });
}
