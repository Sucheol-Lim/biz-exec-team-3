기능 개요

Home 화면은 viewType이 'M'(Map)일 때 지도형 대시보드를 렌더링합니다. ktGms.Map 인스턴스를 useRef로 보관하고, VITE_KT_MAP_API_KEY를 Bearer 토큰으로 넘겨 지도를 초기화합니다(maxZoom은 DEFAULT_MAX_ZOOM_LEVEL, geolocateControl은 비활성). 지도 스타일(styledata) 로드 시 라이트 모드면 틴트 레이어를 추가하고 불필요한 POI 레이어를 필터링합니다.

서비스 대상(headerServiceTarget)이 바뀌면 HomeMapState에 좌표·줌을 저장해 flyTo로 이동시킵니다. 좌표·줌 값은 parseFloatLatData/parseFloatLngData/parseFloatZoomData로 파싱하고, 값이 없거나 잘못되면 공용 상수 DEFAULT_MAP_CENTER로 fallback합니다. 마커 검색(MarkerSearch)으로 받은 markerList는 MarkerStateHandler가 감시하여, 특정 디바이스로 이동(flyTo)하거나 범위에 맞춰(fitBounds) 카메라를 옮기고, 필요 시 마커 다이얼로그(openMarkerDialog)를 띄웁니다. Air Map에서는 지역(시/도·시군구·읍면동) 선택 시 해당 영역의 측정기가 모두 보이도록 fitBounds로 자동 이동하며, 마커 상세 팝업의 시간대별 차트는 응답 date 기준으로 축을 구성하고 데이터 없는 시간은 막대를 표시하지 않습니다. 검색 셀렉트의 기본값은 Air Map·DX·SafeMate에 더해 과천 관제센터(GWACHEON)도 '전체'로 초기화하고, SMART GREEN은 코스 선택 여부와 무관하게 항상 전체로 초기화합니다.

지도 위에는 MapControllers(줌 슬라이더·그리기 컨트롤 — GPS 현재 위치 버튼은 임시 미노출), MapToolbar(지도/도면 전환, 커버리지·플래그 토글)가 오버레이됩니다. 플래그 토글 목록(isSpread)은 Air Map에서 기본 펼침 상태로 시작하고, 커버리지 버튼에는 "커버리지" 툴팁이 붙습니다. Air Map 플래그 종류는 실외 측정소·악취 측정소·국가 측정망 3종만 노출하며(실내 측정소·기상 관측망·기상 장치는 비노출 처리), 등급 범례 색상은 airQuality의 GRADE_CONFIG 공용 상수로 통일했습니다. 그리기 기능은 전역 DrawControlContext가 ktGms.control.DrawControl 인스턴스를 보관해 폴리곤·라인 그리기 모드를 제어합니다. 도면 모드에서는 DrawingViewer가 시설 도면 위에 마커를 표시합니다.

설계 포인트
한전 AMI(SITE_CODES.AMI)는 지도 표출 대상이 아니어서 지도 DOM과 마커 검색을 렌더링하지 않고 카드형 화면으로만 동작합니다.

핵심 코드

src/pages/home/Home.tsx — KT 지도 SDK 초기화
import ktGms from 'kt-map-sdk-js';
const MAP_KEY = import.meta.env.VITE_KT_MAP_API_KEY;

map.current = new ktGms.Map({
  container: mapDOM.current,
  style: 'normal',
  center: [mapState.lng, mapState.lat],
  zoom: mapState.zoom,
  access_token: 'Bearer ' + MAP_KEY,
  ktLogo: false,
  geolocateControl: false,
  maxZoom: DEFAULT_MAX_ZOOM_LEVEL,
  pitchWithRotate: false,   // MAP 기울기 조절 옵션
  dragRotate: false,        // MAP 회전 옵션
  fadeDuration: 0,          // 아이콘/텍스트 페이드인 효과 제거
  crossSourceCollisions: false,
});
map.current?.on('load', () => setIsMapLoaded(true));
map.current?.on('styledata', () => {
  if (mode === 'light') addTintLayer(map);
  filterPoiLayers(map);
});
src/pages/home/Home.tsx — 마커로 카메라 이동 후 상세 다이얼로그 표시
map.current?.flyTo({
  center: [Number(targetMarker.longitudeValue), Number(targetMarker.latitudeValue)],
  zoom: DEFAULT_MAP_CENTER.zoom, speed: 2.5, essential: true,
});
if (mapState.marker?.modalType) {
  openMarkerDialog({
    properties: {
      ...targetMarker,
      id: targetMarker.deviceId,
      name: targetMarker.deviceName,
      openDetail: mapState.marker?.modalType === 'DETAIL',
    },
    coordinates: [Number(targetMarker.longitudeValue), Number(targetMarker.latitudeValue)],
  });
}
src/pages/home/MarkerSearch.tsx — Air Map 지역 선택 시 측정기 전체가 보이도록 자동 이동
// AIRMAP: 시/도·시군구·읍면동 선택 시 해당 영역 측정기가 모두 보이도록 지도 이동
if (valid.length === 1) {
  const m = valid[0];
  onFlyToLocation?.(Number(m.latitudeValue ?? m.latitude), Number(m.longitudeValue ?? m.longitude));
  return;
}
const lats = valid.map((m: any) => Number(m.latitudeValue ?? m.latitude));
const lngs = valid.map((m: any) => Number(m.longitudeValue ?? m.longitude));
onFlyToBounds?.([
  [Math.min(...lngs), Math.min(...lats)],
  [Math.max(...lngs), Math.max(...lats)],
]);
