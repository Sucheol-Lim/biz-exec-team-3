기능 개요

Home 화면은 viewType이 'M'(Map)일 때 지도형 대시보드를 렌더링합니다. ktGms.Map 인스턴스를 useRef로 보관하고, VITE_KT_MAP_API_KEY를 Bearer 토큰으로 넘겨 지도를 초기화합니다(maxZoom은 DEFAULT_MAX_ZOOM_LEVEL, geolocateControl은 비활성). 지도 스타일(styledata) 로드 시 라이트 모드면 틴트 레이어를 추가하고 불필요한 POI 레이어를 필터링합니다.

서비스 대상(headerServiceTarget)이 바뀌면 HomeMapState에 좌표·줌을 저장해 flyTo로 이동시킵니다. 좌표·줌 값은 parseFloatLatData/parseFloatLngData/parseFloatZoomData로 파싱하고, 값이 없거나 잘못되면 공용 상수 DEFAULT_MAP_CENTER로 fallback합니다. 마커 검색(MarkerSearch)으로 받은 markerList는 MarkerStateHandler가 감시하여, 특정 디바이스로 이동(flyTo)하거나 범위에 맞춰(fitBounds) 카메라를 옮기고, 필요 시 마커 다이얼로그(openMarkerDialog)를 띄웁니다. Air Map에서는 지역(시/도·시군구·읍면동) 선택 시 해당 영역의 측정기가 모두 보이도록 fitBounds로 자동 이동하며, 마커 상세 팝업의 시간대별 차트는 응답 date 기준으로 축을 구성하고 데이터 없는 시간은 막대를 표시하지 않습니다. 검색 셀렉트의 기본값은 Air Map·DX·SafeMate에 더해 과천 관제센터(GWACHEON)도 '전체'로 초기화하고, SMART GREEN은 코스 선택 여부와 무관하게 항상 전체로 초기화합니다.

마커 표출 구조는 지도 스타일당 소스 1개로 통합되었습니다. 이전에는 마커 종류·등급별로 소스와 레이어를 나눴는데, 그러면 클러스터링도 그 단위로 갈려 종류가 다른 마커가 한 클러스터로 묶이지 않습니다. 지금은 getMarkerSourceId(mapStyle)이 반환하는 markers-{mapStyle} 소스 하나에 모든 마커를 buildMarkerPoints()로 넣고, 종류·등급은 feature 속성(flagId/flagIndex, levelId/levelIndex)으로 구분합니다. 소스의 clusterProperties가 minFlag/maxFlag/minLevel/maxLevel을 집계하고, isUniformCluster()가 이 값들로 동종(종류·등급이 모두 단일)과 이종(종류나 등급이 다름)을 판별합니다. 클러스터 반경(CLUSTER_RADIUS)은 통합 이후 뭉침이 심해져 50에서 25픽셀로 낮췄고, 개수 표기는 CLUSTER_COUNT_MAX를 넘으면 99+로 줄입니다.

통합 소스 위에는 레이어 3종(-point 개별 마커, -uniform 동종 클러스터, -mixed 이종 클러스터)만 붙습니다. icon-image가 data-driven 표현식이라 종류·등급마다 레이어를 만들 필요가 없고, 필터는 전부 표현식 문법으로 통일해야 합니다(레거시 필터와 섞이면 ['get', ...]이 속성 키로 해석되며 조용히 깨집니다). 동종 클러스터는 기존 합성 이미지(깃발 + 우상단 뱃지)를, 이종 클러스터는 깃발 없이 최악 등급색 마커 위 가운데에 총 개수를 흰 글자·같은 색 halo로 굵게 표시합니다. 클러스터 툴팁(getOnClusterMouseEnterListener)은 getClusterLeaves로 최대 TOOLTIP_MAX_ITEMS개를 받아 등급 심각도 내림차순 → 종류 → 이름 순으로 정렬하고, 이종 클러스터일 때만 항목 앞에 마커 유형 아이콘을 덧붙입니다. 이때 이종 여부는 leaves 표본이 아니라 클러스터 집계값으로 판정합니다(leaves로 세면 "등급만 다른" 이종을 놓칩니다).

지도 위에는 MapControllers(줌 슬라이더·그리기 컨트롤 — GPS 현재 위치 버튼은 임시 미노출), MapToolbar(지도/도면 전환, 커버리지·플래그 토글)가 오버레이됩니다. 줌 슬라이더는 핸들 조작 시 좌측에 현재 줌 레벨을 툴팁으로 노출하고(valueLabelDisplay="auto"), 플래그 토글 목록(isSpread)은 이제 전 사이트에서 기본 펼침으로 시작하며, 커버리지 버튼에는 "커버리지" 툴팁이 붙습니다. 마커 타입 on/off는 더 이상 레이어 visibility로 처리하지 않습니다 — 클러스터 개수와 동종/이종 판별이 소스 레벨에서 계산되므로 레이어만 숨기면 꺼진 종류가 카운트에 남기 때문에, 표시 대상만 모아 updateMarkerSourceData()로 소스 데이터를 다시 넣습니다. Air Map 플래그 종류는 실외 측정소·악취 측정소·국가 측정망 3종만 노출하며, 등급 범례 색상은 airQuality의 GRADE_CONFIG 공용 상수로 통일했습니다. 그리기 기능은 전역 DrawControlContext가 ktGms.control.DrawControl 인스턴스를 보관해 폴리곤·라인 그리기 모드를 제어하고, 도면 모드에서는 DrawingViewer가 시설 도면 위에 마커를 표시합니다.

마커 검색(MarkerSearch)의 조회 함수는 자동 갱신용 createAutoRefreshQueryOptions 팩토리로 재작성되어, 화면 조회(foreground)와 5분 주기 배경 갱신(background)이 같은 fetchMarkerList를 공유합니다. background에서는 requestMode: 'background'·skipError·타임아웃을 붙이고, Air Map 등급 병합(postDeviceLatestData)이 실패하면 등급 없는 마커로 기존 캐시를 덮어쓰지 않도록 그대로 reject합니다. 지역·구역 셀렉트 변경 시에는 postponeAutoRefresh()로 진행 중인 유휴 타이머를 미룹니다. 과천 관제센터는 시/도 미선택(전체) 상태에서도 areaId를 생략해 전체 마커를 조회하도록 가드를 걷어냈습니다.

설계 포인트
한전 AMI(SITE_CODES.AMI)는 지도 표출 대상이 아니어서 지도 DOM과 마커 검색을 렌더링하지 않고 카드형 화면으로만 동작합니다. 한편 등급 심각도 인덱스는 getSiteFlagLevel() 배열 순서를 그대로 쓰므로, 클러스터 대표 등급을 max로 뽑으려면 배열이 반드시 심각도 오름차순이어야 합니다.

  const isMixed = !isUniformCluster(features[0].properties);

  const sorted = [...leaves].sort((a: any, b: any) => {

    return (q.levelIndex ?? 0) - (p.levelIndex ?? 0)

      || String(p.name ?? '').localeCompare(String(q.name ?? ''));

});
