기능 개요

Home 화면은 viewType이 'M'(Map)일 때 지도형 대시보드를 렌더링합니다. ktGms.Map 인스턴스를 useRef로 보관하고, VITE_KT_MAP_API_KEY를 Bearer 토큰으로 넘겨 지도를 초기화합니다(maxZoom은 DEFAULT_MAX_ZOOM_LEVEL, geolocateControl은 비활성). 지도 스타일(styledata) 로드 시 라이트 모드면 틴트 레이어를 추가하고 불필요한 POI 레이어를 필터링합니다.

서비스 대상(headerServiceTarget)이 바뀌면 HomeMapState에 좌표·줌을 저장해 flyTo로 이동시킵니다. 좌표·줌 값은 parseFloatLatData/parseFloatLngData/parseFloatZoomData로 파싱하고, 값이 없거나 잘못되면 공용 상수 DEFAULT_MAP_CENTER로 fallback합니다. 마커 검색(MarkerSearch)으로 받은 markerList는 MarkerStateHandler가 감시하여, 특정 디바이스로 이동(flyTo)하거나 범위에 맞춰(fitBounds) 카메라를 옮기고, 필요 시 마커 다이얼로그(openMarkerDialog)를 띄웁니다. Air Map에서는 지역(시/도·시군구·읍면동) 선택 시 해당 영역의 측정기가 모두 보이도록 fitBounds로 자동 이동하며, 마커 상세 팝업의 시간대별 차트는 응답 date 기준으로 축을 구성하고 데이터 없는 시간은 막대를 표시하지 않습니다. 검색 셀렉트의 기본값은 Air Map·DX·SafeMate에 더해 과천 관제센터(GWACHEON)도 '전체'로 초기화하고, SMART GREEN은 코스 선택 여부와 무관하게 항상 전체로 초기화합니다.

마커 표출 구조는 지도 스타일당 소스 1개로 통합되었습니다. 이전에는 마커 종류·등급별로 소스와 레이어를 나눴는데, 그러면 클러스터링도 그 단위로 갈려 종류가 다른 마커가 한 클러스터로 묶이지 않습니다. 지금은 getMarkerSourceId(mapStyle)이 반환하는 markers-{mapStyle} 소스 하나에 모든 마커를 buildMarkerPoints()로 넣고, 종류·등급은 feature 속성(flagId/flagIndex, levelId/levelIndex)으로 구분합니다. 소스의 clusterProperties가 minFlag/maxFlag/minLevel/maxLevel을 집계하고, isUniformCluster()가 이 값들로 동종(종류·등급이 모두 단일)과 이종(종류나 등급이 다름)을 판별합니다. 클러스터 반경(CLUSTER_RADIUS)은 통합 이후 뭉침이 심해져 50에서 25픽셀로 낮췄고, 개수 표기는 CLUSTER_COUNT_MAX를 넘으면 99+로 줄입니다.

통합 소스 위에는 레이어 3종(-point 개별 마커, -uniform 동종 클러스터, -mixed 이종 클러스터)만 붙습니다. icon-image가 data-driven 표현식이라 종류·등급마다 레이어를 만들 필요가 없고, 필터는 전부 표현식 문법으로 통일해야 합니다(레거시 필터와 섞이면 ['get', ...]이 속성 키로 해석되며 조용히 깨집니다). 동종 클러스터는 기존 합성 이미지(깃발 + 우상단 뱃지)를, 이종 클러스터는 깃발 없이 최악 등급색 마커 위 가운데에 총 개수를 흰 글자·같은 색 halo로 굵게 표시합니다. 클러스터 툴팁(getOnClusterMouseEnterListener)은 getClusterLeaves로 최대 TOOLTIP_MAX_ITEMS개를 받아 등급 심각도 내림차순 → 종류 → 이름 순으로 정렬하고, 이종 클러스터일 때만 항목 앞에 마커 유형 아이콘을 덧붙입니다. 이때 이종 여부는 leaves 표본이 아니라 클러스터 집계값으로 판정합니다(leaves로 세면 "등급만 다른" 이종을 놓칩니다).

지도 위에는 MapControllers(줌 슬라이더·그리기 컨트롤 — GPS 현재 위치 버튼은 임시 미노출), MapToolbar(지도/도면 전환, 커버리지·플래그 토글)가 오버레이됩니다. 줌 슬라이더는 핸들 조작 시 좌측에 현재 줌 레벨을 툴팁으로 노출하고(valueLabelDisplay="auto"), 플래그 토글 목록(isSpread)은 이제 전 사이트에서 기본 펼침으로 시작하며, 커버리지 버튼에는 "커버리지" 툴팁이 붙습니다. 마커 타입 on/off는 더 이상 레이어 visibility로 처리하지 않습니다 — 클러스터 개수와 동종/이종 판별이 소스 레벨에서 계산되므로 레이어만 숨기면 꺼진 종류가 카운트에 남기 때문에, 표시 대상만 모아 updateMarkerSourceData()로 소스 데이터를 다시 넣습니다. Air Map 플래그 종류는 실외 측정소·악취 측정소·국가 측정망 3종만 노출하며, 등급 범례 색상은 airQuality의 GRADE_CONFIG 공용 상수로 통일했습니다. 그리기 기능은 전역 DrawControlContext가 ktGms.control.DrawControl 인스턴스를 보관해 폴리곤·라인 그리기 모드를 제어하고, 도면 모드에서는 DrawingViewer가 시설 도면 위에 마커를 표시합니다.

마커 검색(MarkerSearch)의 조회 함수는 자동 갱신용 createAutoRefreshQueryOptions 팩토리로 재작성되어, 화면 조회(foreground)와 1분 주기 배경 갱신(background)이 같은 fetchMarkerList를 공유합니다(AUTO_REFRESH_INTERVAL_MS가 5분에서 1분으로 단축되었습니다). background에서는 requestMode: 'background'·skipError·타임아웃을 붙이고, Air Map 등급 병합(postDeviceLatestData)이 실패하면 등급 없는 마커로 기존 캐시를 덮어쓰지 않도록 그대로 reject합니다. 지역·구역 셀렉트 변경 시에는 postponeAutoRefresh()로 진행 중인 유휴 타이머를 미룹니다. 과천 관제센터는 시/도 미선택(전체) 상태에서도 areaId를 생략해 전체 마커를 조회하도록 가드를 걷어냈습니다.

지도 위 위젯 On/Off 버튼도 MarkerSearch가 갖고 있는데, 이 값이 사이트 단위로 영속화되었습니다. HeaderProvider는 사용자 지역 관리 패널이 열려 있는 동안의 임시 강제 숨김(setHideWidgets → forceHideWidgets)과 사용자가 저장한 On/Off 선호값(setUserHideWidgets → userHideWidgets)을 별도 상태로 두고 hideWidgets를 둘의 OR로 계산하므로, 패널을 닫아도 사용자 선호값이 그대로 남습니다. 토글 시에는 ConfigContext.onChangeHideWidgets(siteCode, next)가 hiddenWidgetSites에 기록하고, Home은 마운트 시 hiddenWidgetSites[site.code]를 한 번 읽어 복원합니다. 사이트 전환은 AutoRefreshRoute의 key 변경으로 Home을 재마운트시키므로 mount 1회 로드로 충분합니다. 이와 함께 Home은 홈 진입 시 팝업 노출 대상 공지를 띄우는 NoticePopup을 함께 렌더링합니다.

Air Map 마커 유형에 소음 측정기가 새로 분리되었습니다. BFF 응답의 deviceTypeName·AIRMAP_DEV_TYPE은 소음 측정기도 실외(실외/OUTDOOR)로 내려주기 때문에, 실제 장치 유형은 extendedData.DEV_DIV_CD(0002 실외 / 0004 악취 / 0006 소음)로 한 번 더 보정해야 합니다. 이 보정을 getAirmapDeviceKind(deviceTypeName, extendedData) 한 곳으로 모아, 지도 마커 분류(getMarkerFlagType)·마커 상세 팝업(DetailDialogAirmap)·검색 결과 등급 계산(MarkerSearch)이 항상 같은 기준으로 소음 측정기를 가려냅니다. 신설된 flagNoise 플래그(전용 아이콘 flag-airmap-noise.svg)가 지도 위에 별도 마커로 표시되고, 소음 값은 PM10 대신 db 프로퍼티로 getNoiseGrade(0~35.9 좋음 / 36.0~50.9 보통 / 51.0~60.9 나쁨 / 61.0~ 매우나쁨 — 소수점 한 자리까지 흡수하도록 경계값을 정수 미만 비교로 정정)를 거쳐 등급이 매겨집니다.

마커 상세 팝업(DetailDialogAirmap)의 측정항목 탭 선택 상태는 예전엔 deviceId와 무관한 단일 selectedMeasurement state였습니다. 팝업이 열린 채로 다른 마커를 클릭하면 컴포넌트가 재사용되어 이전 장치에서 고른 탭이 새 장치에도 남는 결함이 있었는데, 지금은 { deviceId, key } 쌍으로 선택을 들고 있다가 deviceId가 바뀌면 유형별 기본 탭(DEFAULT_MEASUREMENT_BY_TYPE — 소음은 noise)으로 되돌립니다. '상세 더보기'로 측정소 상세(pages/station/airmapAir/DetailAirQuality) 화면으로 이동할 때도 보정된 deviceTypeName을 navigate state로 함께 넘겨, 상세 화면이 유형별 기본 측정항목(소음은 noise/조회 프로퍼티 db)으로 자동 조회되도록 다리를 놓습니다. 사용자가 상세 화면에서 직접 다른 기준으로 재조회하면 조회 항목은 다시 전체로 돌아갑니다.

설계 포인트
한전 AMI(SITE_CODES.AMI)는 지도 표출 대상이 아니어서 지도 DOM과 마커 검색을 렌더링하지 않고 카드형 화면으로만 동작합니다. 한편 등급 심각도 인덱스는 getSiteFlagLevel() 배열 순서를 그대로 쓰므로, 클러스터 대표 등급을 max로 뽑으려면 배열이 반드시 심각도 오름차순이어야 합니다.

src/pages/home/Home.tsx — KT 지도 SDK 초기화
import ktGms from 'kt-map-sdk-js';
const MAP_KEY = import.meta.env.VITE_KT_MAP_API_KEY;

map.current = new ktGms.Map({
  container: mapDOM.current,
  style: 'normal',
  center: [mapState.lng, mapState.lat],
  zoom: mapState.zoom,
  access_token: 'Bearer ' + MAP_KEY,
  ktLogo: false,
  geolocateControl: false,
  maxZoom: DEFAULT_MAX_ZOOM_LEVEL,
  pitchWithRotate: false,   // MAP 기울기 조절 옵션
  dragRotate: false,        // MAP 회전 옵션
  fadeDuration: 0,          // 아이콘/텍스트 페이드인 효과 제거
  crossSourceCollisions: false,
});
map.current?.on('load', () => setIsMapLoaded(true));
map.current?.on('styledata', () => {
  if (mode === 'light') addTintLayer(map);
  filterPoiLayers(map);
});

// AIRMAP: 시/도·시군구·읍면동 선택 시 해당 영역 측정기가 모두 보이도록 지도 이동
if (valid.length === 1) {
  const m = valid[0];
  onFlyToLocation?.(Number(m.latitudeValue ?? m.latitude), Number(m.longitudeValue ?? m.longitude));
  return;
}
const lats = valid.map((m: any) => Number(m.latitudeValue ?? m.latitude));
const lngs = valid.map((m: any) => Number(m.longitudeValue ?? m.longitude));
onFlyToBounds?.([
  [Math.min(...lngs), Math.min(...lats)],
  [Math.max(...lngs), Math.max(...lats)],
]);
src/utils/MapUtils.ts — 지도 스타일당 1개 소스 + 동종/이종 판별용 클러스터 집계
/** 마커 소스 ID. 종류·등급 구분 없이 지도 스타일당 하나만 만든다. */
export const getMarkerSourceId = (mapStyle: 'normal' | 'satellite' | 'hybrid') =>
  `markers-${mapStyle}`;

/** 동종 = 종류·등급이 모두 단일. 종류가 다르거나 등급(색)이 다르면 이종. */
export const isUniformCluster = (props: any) =>
  props?.minFlag === props?.maxFlag && props?.minLevel === props?.maxLevel;

const newSource = new ktGms.source.GeoJSONSource(sourceId, {
  data: buildMarkerPoints(flagData, site, visibleKeys),
  cluster: enableCluster,
  clusterRadius: CLUSTER_RADIUS,   // 통합 후 뭉침이 심해져 50 → 25px
  clusterMaxZoom: 18,
  // clusterMinPoints는 지정하지 않는다 — SDK가 this.maxzoom에 잘못 대입하는 버그가 있다.

// deviceTypeName/AIRMAP_DEV_TYPE 원본은 소음 측정기도 '실외'/OUTDOOR로 내려온다.
// DEV_DIV_CD(장치 구분 코드)로 보정한 유형명이 있으면 그것을 쓴다.
const AIRMAP_DEV_DIV_CD_NAME_MAP: Record<string, string> = {
  '0002': '실외', '0004': '악취', '0006': '소음',
};

export const getAirmapDeviceKind = (deviceTypeName?: string, extendedData?: any): string => {
  const devDivCd = extendedData?.DEV_DIV_CD;
  if (devDivCd && AIRMAP_DEV_DIV_CD_NAME_MAP[String(devDivCd)]) {
    return AIRMAP_DEV_DIV_CD_NAME_MAP[String(devDivCd)];
  }
  return deviceTypeName ?? '';
};
