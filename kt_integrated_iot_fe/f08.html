SMS 발송 및 알림 설정

이벤트 대상에 대한 SMS 발송(sms-send)과 공기질 알림 설정(sms-alert-settings)을 운영합니다. 발송 대상은 등록·수정·삭제하고, 알림 수신자 설정은 사이트별로 분기됩니다.

기능 개요

SMS 발송 화면(pages/smsSend/index.tsx)은 SMS 수신 대상자를 목록·검색·등록·수정·삭제합니다. 대상자 조회는 safemateApi.smsControl()·smsControlServiceTarget()로, 등록/수정/삭제는 registerSmsUser·updateSmsUser·deleteSmsUser로 처리합니다. 발송 설정은 updateSmsControlSetting으로 사용자별 설정을 저장합니다. 검색은 이름·전화번호 필터를 지원하고, 테이블(SmsSendTable)에서 대상자 행을 선택해 수정 다이얼로그를 엽니다.

개인정보(전화번호 등)는 기본적으로 마스킹되어 표시되며, 마스킹 해제는 별도 인증 모달(ChangeMask)을 거칩니다. 최근 KT 보안성 검증 반영으로 일부 사이트에서 마스킹 해제 버튼이 미노출 처리되었습니다.

알림 설정 화면(pages/smsAlarm/index.tsx)은 세션 site.code로 분기하며, 현재 Air Map(SITE_CODES.AIRMAP)에 대해 공기질 알림 SMS 설정(AirMapAlarm)을 제공합니다. 설정 조회·저장·초기화와 측정소·수신자 목록은 airmapApi의 push/sms/setting 계열 엔드포인트(getSmsSettingDetail·saveSmsSettings·resetSmsSetting·getSmsSettingDevices·getSmsReceivers·saveSmsReceiver 등)로 처리합니다. 라우팅상 발송은 /:site/sms-send, 알림 설정은 /:site/sms-alert-settings로 진입합니다.

AirMapAlarm은 공통 SMS 설정을 formik + Yup 폼으로 관리하며 저장 클릭 시점에만 검증합니다. SMS 발송 여부가 OFF면 나머지 필수값 검증을 생략해 OFF 상태 저장을 허용하고, ON일 때는 발송시간(평일/주말)·발신자 번호·발송 시작/종료 시간·재전송 주기·항목별 임계치/템플릿을 검증해 누락 항목을 RequiredFieldAlertPopup에 표시합니다. 저장 시 측정소를 선택하지 않았거나, 기준 측정소 사용 초과 비율 사용 시 기준 측정소가 없으면 StationSelectAlertPopup이 표시됩니다. 설정 초기화는 resetSmsSetting API와 연동됩니다. 하단의 측정소별 알림 수신 설정은 측정소 목록을 서버 페이지네이션(page·size)으로 조회하고, 측정소 선택 시 getSmsReceivers로 수신자 목록을 불러와 수신자(측정소당 최대 10명, 초과 시 MaxReceiverAlertPopup)별 SMS·미세/초미세먼지·온도·습도 수신 여부를 편집한 뒤 saveSmsReceiver로 템플릿 시퀀스와 함께 저장합니다. 서버가 오류 resultCode를 반환하면 ServerMessageAlertPopup으로 서버 메시지를 노출합니다.

측정소를 선택하면 getSmsSettingDetail로 그 측정소의 저장된 설정을 불러와 폼 전체에 반영합니다. 반영 규칙은 항목별로 다릅니다. 상단 검색 조건(발송 여부·발송요일·발신자 번호·발송 시간·재전송 주기·사용 초과 비율)은 응답에 값이 없으면 기존(서비스대상 기준) 값을 유지하고, 임계치·템플릿은 측정소별 값이므로 응답으로 덮어씁니다. 아직 설정을 저장한 적 없는 측정소는 응답이 없거나 값 필드가 모두 비어 있는데, 이를 SETTING_VALUE_KEYS 목록으로 검사하는 hasSmsSetting()이 판별해 폼을 초기값으로 되돌리고 기준 측정소만 선택한 측정소로 지정합니다. 또 이전 측정소의 응답이 새 측정소에 섞이지 않도록 keepPreviousData를 걷어내고 isFetching 동안에는 폼을 건드리지 않습니다.

입력·표시 편의도 보완되었습니다. 발신자 번호는 formatPhoneNumber()가 입력 즉시 하이픈을 넣어 주며, 서울 지역번호(02)와 10자리 번호의 국번 자릿수를 구분해 02-123-4567·031-123-4567·010-1234-5678을 모두 올바르게 끊습니다(숫자 11자리로 절삭). 화면이 좁아지면 SMS 설정 카드와 측정소·수신자 테이블이 카드 영역을 벗어나므로, horizontalScrollSx로 가로 스크롤을 주고 테이블 최소 너비(STATION_TABLE_MIN_WIDTH 480px · RECEIVER_TABLE_MIN_WIDTH 540px)와 카드 최소 너비(임계치 입력 280px + 좌우 여백)를 상수로 고정했습니다. 스크롤바 스타일은 NormalTable과 동일하게 맞춥니다.

설계 포인트
대상자 등록·수정은 다이얼로그(SmsTargetRegisterDialog/SmsTargetModifyDialog)로 분리해, 목록 화면은 조회·검색에 집중하고 입력 검증은 다이얼로그에서 처리합니다. 알림 설정 쪽에서는 "설정이 없는 측정소"와 "설정을 불러오는 중"을 서로 다른 상태로 구분하는 것이 핵심입니다. 전자는 초기값 리셋, 후자는 폼 미변경으로 처리해야 이전 측정소 값이 잔류하지 않습니다.

// 폼에 반영되는 설정 값 필드 (eventId/alarmId 같은 식별자는 제외)
const SETTING_VALUE_KEYS = [
  'smsSendStatus', 'sendDayType', 'senderPhoneNumber', 'sendStartTime', 'sendEndTime',
  'resendIntervalMin', 'usageOverRate',
  'pm10LimitRate', 'pm25LimitRate', 'temperatureLimitRate', 'humidityLimitRate',
  'pm10Template', 'pm25Template', 'temperatureTemplate', 'humidityTemplate',
] as const;

// 설정이 저장되지 않은 측정소는 응답이 없거나 값 필드가 모두 비어 있다
const hasSmsSetting = (detail?: AirmapSmsSettingDetailResponse): boolean =>
  Boolean(detail) &&
  SETTING_VALUE_KEYS.some((key) => {
    const value = detail?.[key];
    return value !== null && value !== undefined && value !== '';
  });

// 이전 측정소 응답이 새 측정소에 반영되지 않도록 조회 중에는 폼을 건드리지 않는다
useEffect(() => {
  if (!selectedStation || isSelectedStationDetailFetching) return;
  const detail = selectedStationSmsDetailData?.result;

  // 저장된 설정이 없는 측정소는 초기값으로 되돌리고, 기준 측정소만 선택한 측정소로 지정한다
  if (!detail || !hasSmsSetting(detail)) {
    formik.resetForm({ values: initialSmsAlarmSettings });
    setBaseStation({ id: selectedStation.id, name: selectedStation.name, /* ... */ });
    return;
  }

  formik.setValues((prev) => applySelectedStationDetailToSettings(prev, detail));
  const baseStationId = detail.deviceId || selectedStation.id;
  setBaseStation({ id: baseStationId, /* 응답에 측정소명이 없어 동일할 때만 이름 보관 */ });
}, [selectedStationSmsDetailData, isSelectedStationDetailFetching, selectedStation?.id]);
src/pages/smsAlarm/AirMapAlarm.tsx — 발신자 번호 자동 하이픈(지역번호/자릿수 구분)
const formatPhoneNumber = (value: string): string => {
  const numbers = value.replace(/[^0-9]/g, '').slice(0, 11);

  // 서울 지역번호는 국번이 2자리라 별도로 처리한다 (02-123-4567 / 02-1234-5678)
  if (numbers.startsWith('02')) {
    if (numbers.length <= 2) return numbers;
    if (numbers.length <= 5) return `${numbers.slice(0, 2)}-${numbers.slice(2)}`;
    if (numbers.length <= 9) return `${numbers.slice(0, 2)}-${numbers.slice(2, 5)}-${numbers.slice(5)}`;
    return `${numbers.slice(0, 2)}-${numbers.slice(2, 6)}-${numbers.slice(6, 10)}`;
  }

  if (numbers.length <= 3) return numbers;
  if (numbers.length <= 7) return `${numbers.slice(0, 3)}-${numbers.slice(3)}`;
  // 10자리는 국번이 3자리다 (031-123-4567 / 011-123-4567)
  if (numbers.length === 10) return `${numbers.slice(0, 3)}-${numbers.slice(3, 6)}-${numbers.slice(6)}`;
  return `${numbers.slice(0, 3)}-${numbers.slice(3, 7)}-${numbers.slice(7)}`;
};

// 숫자만 입력해도 하이픈이 자동으로 들어가도록 포맷팅한다
onChange={(e) => updateSettings('senderNumber', formatPhoneNumber(e.target.value))}
