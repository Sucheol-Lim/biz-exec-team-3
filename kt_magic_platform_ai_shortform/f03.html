대용량 청크 업로드

tus-js-client 기반 TUS 프로토콜로 /api/magic/tus/upload/files에 100MB 단위 청크 업로드를 수행하고, 이탈 후 재접속 시 이전 업로드를 이어올립니다(resume).

기능 개요

원본 영상은 수백 MB ~ 수 GB 규모가 될 수 있어, 단일 요청 업로드 대신 TUS(resumable upload) 프로토콜로 청크 단위 전송을 사용합니다. useUploadStore.uploadFile(data)가 tus.Upload 인스턴스를 생성하며, endpoint는 /api/magic/tus/upload/files, chunkSize는 100 * 1024 * 1024(100MB)로 설정됩니다.

인증 토큰은 headers.Authorization: Bearer ...로 청크 요청마다 실리고, metadata에 파일명·타입과 integrationServiceCode: 'shortform'을 담습니다. 업로드 시작 전에 findPreviousUploads()로 이전 업로드 기록을 조회해 있으면 resumeFromPreviousUpload()로 이어올립니다. 성공하면 응답에서 uploadFilePath를 추출해 생성 잡 요청의 입력 경로로 사용합니다.

여러 파일을 동시에 다룰 수 있도록 metaDatas 대기열과 uploadingFiles 진행 맵, uploadInstances 인스턴스 맵을 두고, startAutoUpload()가 3초 간격 인터벌로 대기열을 비웁니다. onProgress로 퍼센트를 갱신하고, cancelUpload()는 해당 인스턴스의 abort()를 호출합니다.

설계 포인트
removeFingerprintOnSuccess: true로 두어 업로드 성공 후 fingerprint를 지우므로 동일 파일을 중복 업로드할 수 있습니다. retryDelays: []는 자동 재시도를 끈 설정으로, 이어올리기는 사용자의 재접속 시 findPreviousUploads 경로로 처리됩니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant SU as ShortformUpload.vue participant UP as useUploadStore participant TUS as tus.Upload participant SVR as /api/magic/tus/upload/files SU->>UP: addData(meta) + startAutoUpload() loop 3초 간격 대기열 처리 UP->>UP: uploadFile(data) UP->>TUS: new tus.Upload(file, {endpoint, chunkSize 100MB, headers Bearer}) UP->>TUS: findPreviousUploads() alt 이전 업로드 존재 UP->>TUS: resumeFromPreviousUpload(prev) end UP->>TUS: start() loop 100MB 청크 전송 TUS->>SVR: PATCH (chunk) SVR-->>TUS: offset TUS-->>UP: onProgress(bytesUploaded, bytesTotal) end SVR-->>TUS: 완료 (uploadFilePath) TUS-->>UP: onSuccess → uploadFilePath 추출 end

흐름. 대기열의 파일마다 TUS 업로드 인스턴스를 만들고, 이전 기록이 있으면 이어올린 뒤 100MB 청크로 전송합니다. 완료 응답의 uploadFilePath가 생성 잡 입력으로 쓰입니다.

클래스 다이어그램

classDiagram class useUploadStore { +metaDatas +uploadingFiles +uploadInstances +uploadInterval +addData(data) +uploadFile(data) +cancelUpload(data) +startAutoUpload() +stopAutoUpload() +generateRequest(data, filePath) } class tusUpload { +endpoint +chunkSize +metadata +headers +findPreviousUploads() +resumeFromPreviousUpload() +start() +abort() } class useAuthStore { +token } useUploadStore o-- tusUpload : 인스턴스 생성/소유 useUploadStore --> useAuthStore : Bearer 토큰 주입

관계. useUploadStore가 파일별 tus.Upload 인스턴스를 소유·관리하고, useAuthStore.token을 청크 요청 헤더에 주입합니다.

핵심 코드

user/src/stores/upload.js — TUS 업로드 구성과 이어올리기
var upload = new tus.Upload(videoFile, {
  endpoint: '/api/magic/tus/upload/files',
  retryDelays: [],
  metadata: {
    filename: videoFile.name,
    filetype: videoFile.type,
    integrationServiceCode: 'shortform'
  },
  chunkSize: 100 * 1024 * 1024, // 100MB
  removeFingerprintOnSuccess: true,
  headers: { "Authorization": `Bearer ${token}` },
  onProgress: function (bytesUploaded, bytesTotal) {
    data.progress = ((bytesUploaded / bytesTotal) * 100).toFixed(0)
  },
  onSuccess: async function (payload) {
    let { lastResponse: { _xhr } } = payload
    let uploadFilePath = JSON.parse(_xhr.response).uploadFilePath  // 생성 잡 입력 경로
  },
})

upload.findPreviousUploads().then(function (previousUploads) {
  if (previousUploads.length) upload.resumeFromPreviousUpload(previousUploads[0]) // 이어올리기
  upload.start()
})
