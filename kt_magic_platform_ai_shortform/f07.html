BGM·내레이션 사운드

wavesurfer.js로 BGM 파형과 구간(Region)을 표시·조정하고, Typecast 음성 생성(voiceGenerationTypecast)으로 내레이션 오디오를 만들며 내레이션 샘플(성우) 목록을 활용합니다.

기능 개요

BGM은 wavesurfer.js로 파형을 그리고 RegionsPlugin으로 재생 구간을 잡습니다. setBgmWaveSurfer()가 WaveSurfer.create({ container, waveColor, progressColor, url, plugins:[bgmRegions] })로 인스턴스를 만들고, decode·timeupdate·play·pause 이벤트와 region-updated로 시작·종료 ms(selectedBgmStart/selectedBgmEnd)를 갱신합니다. 볼륨은 audioUtils.setBgmVolume()가 UI 0–100을 서버 0–1.0으로 변환해 적용합니다.

내레이션은 Typecast 기반 음성 합성으로 생성됩니다. EditNarration.editNarration()이 text·maxSeconds·actorId를 FormData로 묶어 api.api.shortform.voiceGenerationTypecast[1].requestJob(form)으로 잡을 요청하고, getJobResultApi(...)로 결과를 폴링합니다. 성공 시 result.voiceFilePath·durationSec를 받아 내레이션 구간의 종료 시각을 갱신하고 버퍼를 로드합니다.

성우(샘플) 목록은 getNarrationSample(api) → GET /nms/magic/shortform/narration-sample로 조회되어 NarrationEditTools.vue의 선택지로 쓰입니다. 음성 글자수가 가능 범위를 넘으면 사용자에게 잘림 경고를 띄우고 진행 여부를 확인합니다.

설계 포인트
내레이션 재수정 시 이전 잡(previousJobIdInfo[narrationIndex].jobId)을 api.narration.deleteNarration으로 정리해 서버 리소스를 누적시키지 않습니다. 오디오 로드 실패 시에는 이전 내레이션 오디오를 유지하도록 폴백합니다.

핵심 코드

user/src/views/common/api/edit/assets/js/narration/tab/EditNarration.js — Typecast 음성 생성 요청·폴링
let form = new FormData();
const param = { text: narrationObj.text, maxSeconds: 30 };
if (actorId) param.actorId = actorId;
form.append("param", JSON.stringify(param));

const { data: { jobId } } = await api.api.shortform.voiceGenerationTypecast[1].requestJob(form);

const callback = async ({ result, jobStatus }) => {
  if (JobStatus.SUCCESS.isStatus(jobStatus)) {
    data.narrationText[narrationIndex].endTime = millisecondsToTime(
      timeToMilliseconds(data.narrationText[narrationIndex].startTime) + result?.durationSec * 1000
    );
    await timeLine.editNarrationBufferAndLoad(narrationIndex, result?.voiceFilePath);
  }
};
getJobResultApi(api.api.voiceGenerationTypecast.getResultApi, jobId, callback);
user/src/views/common/api/edit/ShortformHighlightEditLegacy.vue — BGM wavesurfer 인스턴스 생성
bgmWs = WaveSurfer.create({
  container: '#bgmWaveform',
  waveColor: BGM_WAVE_COLOR, progressColor: BGM_PROGRESSCOLOR,
  url: selectedBgm.value.relativePath, plugins: [bgmRegions],
  height: 50, barWidth: 1, barRadius: 5, barHeight: 0.7,
})
bgmRegions.on('region-updated', (region) => {
  selectedBgmStart.value = Math.floor(region.start * 1000);
  selectedBgmEnd.value = Math.floor(region.end * 1000);
})
