인증·세션 관리

axios 인터셉터가 모든 요청에 Bearer 토큰을 주입하고, 4010 응답 시 토큰 재발급·재시도, 4011 시 로그인 페이지 이동을 처리합니다. 무활동 시 로그아웃되는 세션 타이머를 운용합니다.

기능 개요

인증은 axios 인스턴스 인터셉터(api/index.js)와 인증 스토어(stores/auth.js)로 구성됩니다. 요청 인터셉터는 매 요청에 config.headers.Authorization = `Bearer ${token}`를 주입하고, 응답 인터셉터는 비-2XX 응답에서 resultCode를 분기합니다. 4010(토큰 만료)이면 api.auth.reissueToken()으로 재발급한 토큰을 저장하고 원요청(config)을 재시도하며, 4011(세션 만료)이면 moveLoginPage()로 스토어를 비우고 로그인 페이지로 이동합니다.

네트워크·5xx 오류에는 axios-retry가 최대 2회(지연 1초) 재시도합니다. 재시도 조건은 isRetryableError이거나 status >= 500, 또는 응답이 없는 경우입니다.

세션 스토어는 sessionStorage의 ak(토큰)·user로 로그인 상태를 유지합니다. login()은 로그인 사용자 존재를 확인하고 LoginSessionTimer(300, { timeout: logout })를 시작해 무활동을 감시하며, 타임아웃 시 logout()이 서버 로그아웃 후 스토리지를 비우고 /login으로 이동합니다. 토큰 갱신은 setToken()이 처리합니다.

근거 메모 — 디버깅용 코드
auth.js의 ensureSafariCookies()는 Safari 쿠키 처리를 위해 작성됐으나 현재 if (true || isSafari)로 항상 실행되고, 주석에 "삭제해야함 - 디버깅용"이 명시되어 있습니다. 임시 refresh token을 클라이언트에서 생성하는 부분이 있어 운영 반영 전 정리가 필요한 디버깅 잔재로 보입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant C as 화면/스토어 participant REQ as axios 요청 인터셉터 participant SVR as 서버 participant RES as axios 응답 인터셉터 participant AUTH as api.auth / authStore C->>REQ: API 호출 REQ->>SVR: Authorization Bearer token 주입 후 전송 SVR-->>RES: 응답 (resultCode) alt resultCode 4010 (토큰 만료) RES->>AUTH: reissueToken() AUTH-->>RES: accessToken RES->>SVR: 원요청 재시도 (instance.request(config)) else resultCode 4011 (세션 만료) RES->>AUTH: moveLoginPage() → clearStore + /login else 네트워크/5xx RES->>SVR: axios-retry 최대 2회 재시도 end Note over AUTH: 무활동 시 LoginSessionTimer(300) → logout

흐름. 요청마다 Bearer 토큰을 주입하고, 응답 코드에 따라 재발급·재시도(4010), 로그인 이동(4011), 5xx 재시도를 처리하며 세션 타이머로 무활동을 감시합니다.

관계. 인터셉터가 인증 스토어의 토큰을 읽고 갱신하며 reissueToken으로 재발급하고, 스토어는 LoginSessionTimer를 소유해 무활동 로그아웃을 처리합니다.

핵심 코드

user/src/api/index.js — Bearer 주입 · 4010/4011 분기 · 재시도
instance.interceptors.request.use(config => {
  const token = useAuthStore().token
  config.headers.Authorization = `Bearer ${token}`
  return config
})

instance.interceptors.response.use(r => r, async error => {
  const { config, response } = error
  const resultCode = response?.data?.resultCode
  if (resultCode === 4010) {                                  // 토큰 만료 → 재발급·재시도
    const { data: { accessToken, resultCode } } = await api.auth.reissueToken()
    if (resultCode === 4011) { moveLoginPage(); return }
    useAuthStore().setToken(accessToken)
    return instance.request(config)
  }
  if (resultCode === 4011) { /* 재발급 시도 후 실패면 moveLoginPage() */ }
  throw error
})

axiosRetry(instance, { retries: 2, retryDelay: () => 1000,
  retryCondition: (e) => e.response ? axiosRetry.isRetryableError(e) || e.response.status >= 500 : true })
user/src/stores/auth.js — 세션 타이머 시작
function login() {
  if (loginUser.value) {
    if (loginUser.value.roleId === 1) { alert('운영관리자는 ...'); throw new Error() }
    loginSessionTimer = new LoginSessionTimer(300, { timeout: logout }).start()  // 무활동 300분 감시
    return 1
  } else {
    alert('로그인이 필요한 서비스입니다'); window.location = '/login'; throw new Error()
  }
}
