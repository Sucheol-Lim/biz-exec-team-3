기능 개요

편집 안정성은 네 개의 싱글턴 컴포저블로 구성됩니다. historyManager는 변경분만 { path: { before, after } } 형태로 스택에 쌓아 undo/redo를 지원하며, jobId → resultId → HistoryStack 구조로 영상별 독립 관리합니다. undo()/redo()는 적용 함수(applyFn)로 before/after 값을 되돌리거나 재적용하고, Vue 반응성은 historyVersion ref로 트리거합니다.

autoSaveManager는 기본 10분 주기로 saveImmediatelyIfChanged()를 호출해 historyVersion이 증가한 경우에만 localStorage(키 shortform_autosave_{jobId}_{resultId})에 저장합니다. 영상 전환 시 직전 영상을 즉시 저장하고, beforeunload에서 미저장 데이터가 있으면 이탈 경고를 띄웁니다.

sessionRecoveryManager는 새로고침 대비로 sessionStorage(키 shortform_session_{jobId})에 편집 데이터와 히스토리를 저장하고, 페이지 로드 시 loadAndRestoreSession()으로 복원 후 데이터를 정리합니다. editDataManager는 원본/편집 데이터 캐시와 수정 여부 판정(히스토리 기반)을 제공하고, elementClipboardManager는 요소 복사/붙여넣기와 공용 텍스트 스타일 모델을 담당합니다.

설계 포인트
자동 저장은 historyVersion 증가분을 비교(currentVersion > lastVersion)해 변경이 있을 때만 기록하므로 불필요한 저장을 줄입니다. 복구는 jobId 단위로 격리되어 여러 편집 창이 서로의 세션을 덮어쓰지 않습니다.

흐름. 편집은 히스토리 스택에 변경분으로 쌓이고(undo/redo), 주기적으로 변경 시에만 자동 저장되며, 새로고침 시 세션 복구가 편집 데이터와 히스토리를 되살립니다.

관계. autoSaveManager·sessionRecoveryManager가 historyManager·editDataManager의 직렬화·복원 메서드를 사용해 저장·복구하고, 수정 여부는 히스토리 카운트로 판정합니다.

핵심 코드

user/src/views/common/api/edit/composables/historyManager.js — undo로 before 값 복원
undo(jobId, resultId, applyFn) {
  const history = this.getHistoryStack(jobId, resultId)
  if (history.currentIndex < 0) return false
  this.isExecuting.value = true
  const historyItem = history.stack[history.currentIndex]
  Object.entries(historyItem.changes).forEach(([path, { before }]) => {
    applyFn(path, before)   // before 값으로 되돌리기
  })
  history.currentIndex--
  this.historyVersion.value++
  return true
}
user/src/views/common/api/edit/composables/autoSaveManager.js — 변경 시에만 저장
saveImmediatelyIfChanged(jobId, resultId, editDataManager, historyManager) {
  const currentVersion = historyManager.historyVersion.value
  const lastVersion = this.getLastSavedVersion(jobId, resultId)
  if (currentVersion > lastVersion) {                  // 변경분이 있을 때만
    const currentData = editDataManager.getCurrentData(resultId)
    if (currentData) {
      this.performAutoSave(jobId, resultId, currentData, editDataManager, historyManager)
      this.setLastSavedVersion(jobId, resultId, currentVersion)
    }
  }
}
