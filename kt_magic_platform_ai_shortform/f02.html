콘텐츠 유형별 생성 방식

기능 개요

콘텐츠 유형과 생성 방식의 매핑은 shortformContentValue.js에 데이터로 정의되어 있습니다. CONTENT_TYPES는 쇼핑·영화드라마·영화·드라마·예능·뉴스·기타를 value와 key로 정의하고, SHORTFORM_TYPES는 각 유형 키에 대응하는 생성 방식 배열을 둡니다. 예컨대 SHOPPING은 [summary, theme], MOVIE_DRAMA는 [clip, review, character, preview]입니다.

각 생성 방식 객체에는 화면 표기와 동작에 필요한 메타가 담깁니다. theme(테마형)는 "상품소개·상품강점·활용법·시연" 네 테마로 영상을 만들고 videoLimit: 1·videoRatioList: shoppingVideoRatio를 가지며, character(인물형)는 특정 인물만 찾아 videoLimit: 10·movieVideoRatio를, clip(클립형)은 videoLimit: 50을 갖습니다. 영상 비율 목록은 쇼핑(["ALL","half","full"])과 영화·드라마류(["ALL","1:1","3:4","3:5","4:3","9:16","16:9"])로 구분됩니다.

이 데이터는 contentValue·contentFn으로 가공되어 화면에서 라벨↔값 변환, 유형별 기본 스타일 생성(getContentDefaultStyle), 그리고 유형·방식 조합의 유효성 검증(checkGenreShortformRule)에 쓰입니다.

데이터 주도 설계
생성 방식·비율·개수 제한이 모두 한 파일의 상수 객체로 모여 있어, UI는 이 데이터를 읽어 셀렉트·라디오·도움말을 그립니다. 일부 방식(summary·review)은 disabled: true로 비활성 처리되어 있고, 주석 처리된 항목(highlight·SPORTS 등)은 현재 노출 대상에서 제외되어 있습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 사용자 participant SH as ShortformHighlight.vue participant CV as contentValue / contentFn participant CVAL as shortformContentValue.js participant UP as useUploadStore U->>SH: 콘텐츠 유형 선택 (예: 쇼핑) SH->>CV: getContentInfo(contentType) CV->>CVAL: SHORTFORM_TYPES[key] 조회 CVAL-->>CV: 생성 방식 배열 (summary, theme ...) CV-->>SH: 방식 목록 + videoRatioList + videoLimit U->>SH: 생성 방식 선택 (예: 테마형) SH->>CV: getContentDefaultStyle(contentType) Note over SH: 방식별 비율·개수 제한으로 입력 UI 구성 SH->>UP: generateRequest(data) (선택된 방식만 정렬)

흐름. 유형 선택 시 해당 유형의 생성 방식 배열과 비율·개수 제한을 데이터에서 읽어 입력 UI를 구성하고, 선택값은 생성 요청 조립으로 넘어갑니다.

클래스 다이어그램

classDiagram class ContentType { +value +label +key } class ShortformType { +value +label +videoLimit +videoRatioList +typeDescription +disabled } class contentValue { +SHORTFORM_CONTENT_TYPE +THEME +CLIP +CHARACTER } class contentFn { +getContentInfo(contentType) +getContentDefaultStyle(contentType) +getContentTypeAndShortformTypeLabel() +checkGenreShortformRule() } ContentType "1" o-- "*" ShortformType : SHORTFORM_TYPES 매핑 contentValue --> ContentType : SHORTFORM_CONTENT_TYPE contentFn ..> contentValue : 조회/가공

관계. 각 ContentType은 여러 ShortformType을 매핑으로 소유하고, contentValue가 이를 묶어 노출하며 contentFn이 라벨 변환·기본 스타일·유효성 검증 유틸을 제공합니다.

핵심 코드

user/src/assets/js/shortform/shortformContentValue.js — 유형·방식·비율 정의
const shoppingVideoRatio = ["ALL", "half", "full"]
const movieVideoRatio = ["ALL", "1:1", "3:4", "3:5", "4:3", "9:16", "16:9"]

const theme = { value: 1, label: '테마형', videoLimit: 1,
  help: 'o "상품소개", "상품강점", "활용법", "시연" 네가지 테마로 영상이 생성됨 ...',
  videoRatioList: shoppingVideoRatio }
const character = { value: 1, label: '인물형', videoLimit: 10,
  typeDescription: '콘텐츠 내의 특정 인물만 찾아서 숏츠로 만들어 줍니다.',
  videoRatioList: movieVideoRatio }
const clip = { value: 3, label: '클립형', videoLimit: 50, videoRatioList: movieVideoRatio }

const SHORTFORM_TYPES = {
  SHOPPING: [summary, theme],
  MOVIE_DRAMA: [clip, review, character, preview],
  MOVIE: [clip, review, character, highlight],
  // ...
}
