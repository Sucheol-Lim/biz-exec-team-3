AI 숏폼 자동 생성

원본 영상을 Magic 엔진에 보내 세로형 숏폼을 자동 생성합니다. 콘텐츠 유형·생성 방식·클립 수·인물 수·영상 비율 등을 설정해 aiShortformGenerationE2E 잡으로 요청합니다.

기능 개요

AI 숏폼 자동 생성은 본 애플리케이션의 진입 기능입니다. ShortformHighlight.vue 화면에서 사용자가 콘텐츠 유형·생성 방식·클립 수·인물 수·영상 비율·로고·자막·BGM·인트로 등을 설정하면, 그 설정과 업로드된 원본 영상이 KT AI 엔진(어뮤즈랩 연동)에 전달되어 세로형 숏폼 영상이 생성됩니다.

생성 요청은 useUploadStore.generateRequest()가 담당합니다. 화면에서 수집한 data를 서버 규약에 맞는 param(requestName·contentType·shortformTypeList·styleList·generationParam·encodingParam)으로 조립하고, 자막 파일이 있으면 함께 FormData로 묶어 api.api.shortform[1].requestJob(form, uploadFilePath)를 호출합니다. 이 호출은 결국 POST /api/magic/shortform/v1/aiShortformGenerationE2E?uploadFilePath=... 로 나갑니다.

요청이 접수되면 잡은 비동기로 처리되며, 결과는 별도의 결과 화면(ShortformHighlightResult.vue)에서 폴링·표시됩니다. 생성 파라미터는 contentType과 shortformType 인덱스 조합에 따라 numVideoClips·numPersons·clipShotTime 등이 선택적으로 채워지는 구조입니다.

설계 포인트
generateRequest()는 선택되지 않은 생성 방식(selectedStyle이 빈 객체)을 인덱스 단위로 걸러내어, 실제 선택된 방식만 shortformTypeList·styleList·generationParam·encodingParam 배열에 정렬해 보냅니다. 즉 하나의 요청으로 여러 생성 방식을 동시에 의뢰할 수 있습니다.

핵심 코드

user/src/stores/upload.js — 생성 파라미터 조립과 잡 요청
async generateRequest(data, filePath) {
  let param = {}
  param.requestName = data.name
  param.contentType = data.contentType
  param.contentName = data.contentName
  param.shortformTypeList = data.shortformType
    .map((shortform, index) => Object.keys(shortform.selectedStyle).length !== 0 ? index : null)
    .filter((index) => index !== null)
  // styleList / generationParam / encodingParam 도 선택된 방식만 정렬해 채움
  // ...
  let form = new FormData()
  form.append('param', JSON.stringify(param))
  if (data.useSubtitle) form.append('file', data.subtitleFile)

  let response = await api.api.shortform[1].requestJob(form, filePath)  // 잡 요청
}
user/src/api/api.js — shortform 도메인의 E2E 생성 잡 정의
shortform: {
  [1]: {
    requestJob(body, uploadFilePath) {
      return axios.post(`api/magic/shortform/v1/aiShortformGenerationE2E?uploadFilePath=${uploadFilePath}`, body);
    },
  },
  async getResult(jobId) {
    return request(axios, `/api/magic/shortform/jobs/${jobId}/aiShortformGenerationE2E`);
  },
  async getNmsResult(jobId) {
    return request(axios, `/nms/magic/shortform?jobId=${jobId}`);
  },
}
