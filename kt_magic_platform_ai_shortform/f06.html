텍스트·자막 편집

텍스트 박스 정렬, 화면 기준 정렬(가로·세로), 폰트·색상·라인하이트·박스 높이 등 자막/텍스트 스타일을 세밀하게 조정합니다. 최근 커밋 다수가 텍스트·자막 박스 로직 개선에 집중되어 있습니다.

기능 개요

텍스트·자막 편집은 우측 툴 패널의 TextEditTools.vue·SubtitleEditTools.vue와 박스 계산 유틸 boxUtils.js가 함께 담당합니다. 툴 패널에서는 텍스트 정렬(titleParam.align 0/1/2 = 좌/중앙/우), 화면 기준 가로·세로 위치 정렬, 폰트(FONT_SIZE 옵션), 색상, 라인하이트, 박스 높이 등을 조정하고 그 결과를 부모로 emit('update:titleParam', ...) 합니다.

정렬 계산은 boxUtils의 함수들이 원본 영상 해상도 기준으로 좌표를 산출합니다. updateAlign·updateBoxHorizontalAlign은 가로 정렬을, updateVerticalAlign은 세로 정렬(상단/중앙/하단)을 처리하며, 텍스트·자막·로고 각각에 대해 moveTitleBox/resizeTitleBox/moveSubtitleBox/resizeSubtitleBox·updateTitleBoxSize·updateSubtitleBoxPosition 등 세분화된 함수가 있습니다.

스타일 자체(하이라이트 폰트·색상)는 elementClipboardManager.js의 CommonHighlightTextStyle가 텍스트·자막 공용 모델로 다루어, 타이틀과 자막의 하이라이트 스타일 파라미터를 서로 변환합니다(convertTitleHighlightStyleParamToCommonHighlightStyleParam 등).

설계 포인트
텍스트/자막 박스의 높이·라인하이트·리사이즈는 영상 좌표계(videoSource.videoWidth/Height)와 박스 좌표(position[x,y,w,h])를 함께 다루므로, 정렬 함수들이 박스 폭/높이를 인자로 받아 중앙·우측·하단 위치를 정확히 재계산합니다.

핵심 코드

user/src/views/common/api/edit/assets/js/utils/boxUtils.js — 세로 정렬 좌표 계산
export function updateVerticalAlign(align, param, box, videoSource, boxHeight) {
  let [x, y, w, h] = param.position;
  if (boxHeight) h = boxHeight;
  switch (align) {
    case 0: param.position[1] = 0; break;                                   // 상단
    case 1: param.position[1] = Math.floor((videoSource.videoHeight - h) / 2); break; // 중앙
    case 2: param.position[1] = videoSource.videoHeight - h; break;         // 하단
  }
}
user/src/views/common/api/edit/components/tools/TextEditTools.vue — 정렬 토글과 업데이트 emit
