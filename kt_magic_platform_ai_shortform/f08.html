스타일 템플릿

템플릿 탭(TemplateTab.vue)에서 로고·자막·팝업 스타일이 적용된 템플릿을 미리보기하고 적용합니다. 현재 편집 스타일을 사용자 My 템플릿으로 추가하는 기능도 지원합니다.

기능 개요

템플릿 탭은 좌측 탭(MainTabs) 중 하나로, 스타일 템플릿을 "My 템플릿"과 "스타일 템플릿"으로 나누어 보여줍니다. 목록은 부모가 내려준 templateStyleList를 contentType·shortformType·videoRatio 조건으로 필터링하여 구성합니다. 사용자가 만든 것은 !style.isDefault(My 템플릿), 기본 제공은 style.isDefault로 구분합니다.

템플릿 카드는 DraggableMenuItemComponent로 감싸 미리보기 이미지(styleImgPath)를 드래그 가능하게 만들고, 클릭 시 handleTemplateClick(templateStyle)가 { type: 'template', data } 드롭 데이터를 만들어 editStateStore.processDataOperation(dropData, ..., OperateFrom.LEFT_PANEL)로 적용합니다. 즉 템플릿 적용은 타임라인 드롭과 같은 단일 데이터 경로로 처리됩니다.

사용자 스타일 추가는 AddStyleTemplatePopup.vue가 담당합니다. 현재 미리보기 영역을 html2canvas로 캡처해 썸네일을 만들고, 스타일명과 함께 FormData로 묶어 api.style.saveStyle(form)로 저장한 뒤 refresh-styles를 emit해 목록을 갱신합니다.

설계 포인트
새로 추가된 템플릿은 sessionStorage의 new-template-ids로 추적되어 카드에 NEW 배지를 표시합니다. 템플릿 적용·드롭은 좌측 패널 출처(OperateFrom.LEFT_PANEL)로 표시되어 편집 상태에 일관되게 반영됩니다.

흐름. 템플릿 클릭은 드롭 데이터로 변환되어 적용되고, 추가는 미리보기를 캡처해 스타일로 저장한 뒤 목록을 새로고침합니다.

관계. 템플릿 탭이 카드를 드래그 가능하게 래핑하고, 적용은 editStateStore로, 추가는 AddStyleTemplatePopup → api.style.saveStyle로 흐릅니다.

핵심 코드

user/src/views/common/api/edit/components/tabs/TemplateTab.vue — 템플릿 적용
function handleTemplateClick(templateStyle) {
  const dropData = { type: 'template', data: templateStyle }
  EditStateStore.processDataOperation(dropData, null, null, OperateFrom.LEFT_PANEL);
}

const myTemplateStyleList = computed(() =>
  props.templateStyleList.filter(style =>
    !style.isDefault && style.contentType === props.contentType &&
    style.shortformType === props.shortformType &&
    style.videoRatio === EditStateStore.videoParam.videoRatio));
user/src/views/common/api/edit/components/popups/AddStyleTemplatePopup.vue — 미리보기 캡처 후 스타일 저장
const captureCanvas = await html2canvas(previewRef.value, { backgroundColor: 'transparent', allowTaint: true });
// ... FormData 구성 (styleName, 썸네일, 파라미터)
const response = await api.style.saveStyle(form);
emit('refresh-styles');
emit('close');
