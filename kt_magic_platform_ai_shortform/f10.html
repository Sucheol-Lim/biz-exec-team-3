단일/멀티 편집기 분기

진입 래퍼 ShortformHighlightEdit.vue가 jobId 유무로 멀티/팝업 편집기와 단일(Legacy) 편집기를 지연 로딩하고, 팝업 모드에서는 좌측 메뉴를 숨기고 전체 화면을 점유합니다.

기능 개요

편집기 진입점은 ShortformHighlightEdit.vue 래퍼입니다. useRoute()로 route.query.jobId를 읽어 hasJobId를 계산하고, defineAsyncComponent로 두 편집기를 지연 로딩합니다. jobId가 있으면 멀티/팝업 편집기 ShortformHighlightEditMulti.vue를, 없으면 단일(Legacy) 편집기 ShortformHighlightEditLegacy.vue를 로드합니다.

결과 화면(ShortformHighlightResult.vue)의 편집 진입은 window.open(`/user/user/studio/shortform-highlight/edit?jobId=...&resultId=...`)로 새 창에서 열리므로, 이 경로의 jobId 쿼리가 멀티/팝업 편집기 분기를 트리거합니다. 즉 결과 영상의 편집은 팝업 창(멀티 편집기)에서, 직접 진입(legacy 경로)은 단일 편집기에서 동작하도록 설계되어 있습니다.

팝업 모드에서는 <html>·<body>에 popup-mode(및 no-scroll) 클래스를 부여해 전체 화면(100vw/100vh)으로 만들고 스크롤을 막으며, body.popup-mode .comp-leftmenu를 display:none으로 숨기고 컨테이너 여백을 제거합니다. 컴포넌트는 <Suspense>로 감싸 비동기 로딩을 처리합니다.

설계 포인트
두 편집기를 동적 import로 분리해 초기 번들을 가볍게 유지하고, 멀티 편집기에는 webpackPrefetch: true 힌트를 주어 선로딩을 유도합니다. 분기 키는 단순히 jobId 쿼리 유무 하나로 결정되어 라우팅이 단순합니다.

관계. 래퍼가 두 편집기 중 하나를 지연 로딩하며, 결과 화면이 jobId를 붙여 팝업으로 열어 멀티 편집기 진입을 유발합니다.

핵심 코드

user/src/views/common/api/edit/ShortformHighlightEdit.vue — jobId 기반 지연 로딩과 팝업 모드
const route = useRoute()
const hasJobId = computed(() => !!route.query.jobId)

const LazyComponent = computed(() =>
  defineAsyncComponent({
    loader: () => hasJobId.value
      ? import(/* webpackPrefetch: true */ './ShortformHighlightEditMulti.vue')
      : import('./ShortformHighlightEditLegacy.vue'),
    loadingComponent: () => null
  })
)

if (hasJobId) {
  document.documentElement.classList.add('popup-mode')
  document.body.classList.add('popup-mode', 'no-scroll')
}
user/src/views/common/api/result/ShortformHighlightResult.vue — 결과에서 팝업 편집 진입
async function goToEditPage(result) {
  window.open(
    `/user/user/studio/shortform-highlight/edit?jobId=${jobId}&resultId=${result.resultId}`,
    `edit_${jobId}`
  );
}
