기능 개요

대시보드(DashboardView.vue)는 로그인 사용자 기준으로 통계를 보여줍니다. 이번 달 범위(from~to)에 대해 api.user.getCountByStatusByParams로 상태별 잡 수(완료/대기/진행중/에러)를 집계하고, api.group.getTokenInGroup으로 잔여 토큰을, api.user.getUsageByParams로 사용량을 받아 BarChart·DoughnutChart로 시각화합니다. 상태 코드는 statusMap(-1 에러, 0 완료, 1 대기, 2 진행중)으로 라벨·순서가 정의됩니다.

분석 이력(AnalysisHistoryView.vue)은 검색 조건(searchType)에 따라 날짜·잡ID·서비스코드·상태·액세스키명·작업명으로 잡 이력을 조회합니다. 조건이 바뀌면 jobModel이 재구성되고 getJobsByParams()가 실행되며, 페이지네이션은 usePagination() 컴포저블이 관리합니다.

이력 데이터는 api/shortform.js의 job.getJobsByUserIdAndParams(userId, params)·job.getJobsByGroupIdAndParams(groupId, params)로 사용자/그룹 단위 잡 히스토리를 받아 표로 렌더링합니다. 관리자(admin/)와 사용자(user/)는 같은 화면 구성을 별도 디렉토리로 둡니다.

설계 포인트
대시보드의 모든 조회는 inject('$api')로 주입된 도메인 모듈을 사용하고, 날짜 범위는 CustomDate 유틸로 이번 달 1일~다음 달 1일로 계산됩니다. 상태별 카운트는 statusMap에 누적되어 차트 데이터로 변환됩니다.

핵심 코드

user/src/views/user/dashboard/DashboardView.vue — 상태별 잡 수 집계
const statusMap = ref(new Map())
statusMap.value.set(-1, { text: '에러', order: 4, count: 0 })
statusMap.value.set(0, { text: '완료', order: 1, count: 0 })
statusMap.value.set(1, { text: '대기', order: 3, count: 0 })
statusMap.value.set(2, { text: '진행중', order: 2, count: 0 })

const { data } = await api.user.getCountByStatusByParams(userId, { from, to })
data.result.countByStatus.forEach(e => {
  const value = statusMap.value.get(e.jobStatus)
  value.count = e.count
  jobTotalCount.value += e.count
})
user/src/api/shortform.js — 사용자·그룹별 잡 이력 조회
job: {
  async getJobsByUserIdAndParams(userId, params) {
    return axios.get(`nms/magic/shortform/user/users/${userId}/jobs/history`, { params });
  },
  async getJobsByGroupIdAndParams(groupId, params) {
    return axios.get(`nms/magic/shortform/user/groups/${groupId}/jobs/history`, { params });
  },
}
