Konva 미리보기 캔버스

Konva + vue-konva를 전역 등록해 편집 미리보기 레이어 렌더링에 활용하고, 실제 요소의 드래그·리사이즈는 vue3-draggable-resizable과 interactjs로 DOM/CSS 레이어 위에서 처리합니다.

기능 개요

미리보기 캔버스 스택은 main.js에서 전역 등록됩니다. app.use(VueKonva)로 Konva 컴포넌트를, app.use(Vue3DraggableResizable)로 드래그·리사이즈 컴포넌트를 등록하며, 편집 화면은 이들 위에 미리보기 레이어를 구성합니다.

편집기 미리보기 영역은 비디오 캡처 이미지 위에 배경·타이틀·자막·로고·이미지 레이어를 z-index로 쌓는 구조입니다. StylePreviewComponent.vue는 스타일 미리보기를, PreviewItemComponent.vue는 실제 편집 대상 요소를 렌더링하며, 요소 이동·리사이즈는 vue3-draggable-resizable(DraggableContainerComponent·EditableDraggableComponent)과 boxUtils의 move/resize 함수로 처리됩니다.

이동·리사이즈 결과는 요소의 position 배열(x·y·w·h)에 반영되고, 조작 출처는 OperateFrom.PREVIEW로 표시되어 editStateStore로 전달됩니다. 좌표는 원본 영상 해상도(videoSource.videoWidth/Height) 기준으로 계산되어 타임라인·인코딩 파라미터와 일관성을 유지합니다.

근거 메모
Konva·vue-konva는 전역 플러그인으로 등록되어 미리보기 렌더링 기반으로 사용됩니다. 다만 멀티/팝업 편집기의 미리보기 레이어(StylePreviewComponent·PreviewItemComponent)는 DOM/CSS 레이어와 vue3-draggable-resizable 기반으로 구현되어 있어, 요소 드래그·리사이즈의 직접적인 조작은 draggable-resizable·interactjs·boxUtils가 담당합니다.

시퀀스 다이어그램

흐름. 미리보기 위 드래그·리사이즈가 boxUtils의 박스 함수로 원본 해상도 좌표를 갱신하고, 출처 PREVIEW로 editStateStore에 반영되어 레이어가 다시 그려집니다.

클래스 다이어그램

classDiagram class main_js { +use(VueKonva) +use(Vue3DraggableResizable) +provide($api, factory) } class StylePreviewComponent { +videoCaptureInfo +titleBoxStyle +subtitleBoxStyle +logoTextBoxStyle } class PreviewItemComponent { +elementType +x +y +w +h } class DraggableContainerComponent { +draggable +resizable +onDrag() +onResize() } class boxUtils { +moveTitleBox() +resizeSubtitleBox() +moveLogoImageBox() +updateAlign() +updateVerticalAlign() } main_js ..> DraggableContainerComponent : 전역 등록 PreviewItemComponent o-- DraggableContainerComponent : 요소 래핑 PreviewItemComponent ..> boxUtils : 위치/크기 계산 StylePreviewComponent ..> boxUtils : 미리보기 박스 스타일

관계. 전역 등록된 draggable-resizable이 미리보기 요소를 감싸고, 박스 좌표 계산은 boxUtils가 전담합니다. StylePreviewComponent는 동일 박스 모델로 스타일 미리보기를 그립니다.

핵심 코드

user/src/main.js — Konva / Draggable 전역 등록
import VueKonva from "vue-konva";
import factory from "@/api/factory.js";
import Vue3DraggableResizable from 'vue3-draggable-resizable'
import 'vue3-draggable-resizable/dist/Vue3DraggableResizable.css'

app
  .use(VueKonva)
  .use(Vue3DraggableResizable);

app.provide("$api", factory);
user/src/views/common/api/edit/assets/js/utils/boxUtils.js — 미리보기 박스 정렬 계산
export function updateAlign(align, param, box, videoSource) {
  let [x, y, w, h] = param.position;
  switch (align) {
    case 0: param.position[0] = 0; break;                                  // 좌
    case 1: param.position[0] = Math.floor((videoSource.videoWidth - w) / 2); break;  // 중앙
    case 2: param.position[0] = videoSource.videoWidth - w; break;         // 우
  }
}
