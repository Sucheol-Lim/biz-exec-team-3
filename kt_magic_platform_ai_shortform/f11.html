기능 개요

결과 화면(ShortformHighlightResult.vue)은 history.state.jobId로 진입해 JobResultTemplate.vue의 getJobResult(getResult, jobId)로 잡 상태를 조회합니다. 잡이 완료/에러가 아니면 setTimeout으로 5초마다 재조회(폴링)하며, onGetJob 콜백으로 받은 job을 화면 상태에 반영합니다. 완료(jobStatus === 0) 시 getNmsResult(jobId)로 NMS 상세 결과(shortformResults)를 가져옵니다.

결과는 groupedResults computed가 shortformType 기준으로 그룹핑하고, 쇼핑(contentType === 0) 여부에 따라 shoppingResults/movieDramaResults의 shortformIndex를 매칭합니다. 카드별로 해시태그·설명을 인라인 편집(editHashTag/updateHashTag → putHashTagDescription)할 수 있고, 해시태그는 콤마↔#표기로 변환됩니다.

다운로드는 그룹별 전체 다운로드(downloadShortformTypeVideos)와 개별 다운로드를 제공합니다. resultFilePath를 절대 URL로 변환해 <a download>로 내려받으며, 파일명은 requestName의 금칙문자를 치환해 안전화합니다. 편집기 진입은 goToEditPage가 jobId·resultId 쿼리로 새 창을 엽니다.

설계 포인트
폴링 종료 조건은 JobStatus.SUCCESS/ERROR이며, 컴포넌트 unmount 시 clearJobTimeout()으로 타이머를 정리합니다. 재생성(regenerateShortform)은 원본 입력 경로를 추출해 생성 설정 화면으로 되돌립니다.

핵심 코드

user/src/components/common/api/result/JobResultTemplate.vue — 5초 폴링
const GET_JOB_INTERVAL = 5

export async function getJobResult (getResult, jobId) {
  result = await getResult(jobId)
  job = result.data.result.job
  typeof onGetJob._callback === 'function' && onGetJob._callback(job, result.data, result)

  if (JobStatus.SUCCESS.isStatus(job.jobStatus) || JobStatus.ERROR.isStatus(job.jobStatus)) {
    // 완료된 작업
  } else {
    getJobTimeout = setTimeout(() => getJobResult(getResult, jobId), GET_JOB_INTERVAL * 1000)
  }
}
user/src/views/common/api/result/ShortformHighlightResult.vue — 방식별 그룹핑
const groupedResults = computed(() => {
  return shortformResultData.value
    ? shortformResultData.value.shortformResults.reduce((acc, item, index) => {
        const type = item.shortformType;
        if (!acc[type]) acc[type] = [];
        acc[type].push(reactive({ ...item, shortformIndex: /* 쇼핑/영화드라마별 인덱스 */ }));
        return acc;
      }, {})
    : {};
});
