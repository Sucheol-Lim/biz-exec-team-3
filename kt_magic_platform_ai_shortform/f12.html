재인코딩 저장

편집 결과를 NMS에 저장(putEditParams)하고, 저장 성공 시 aiShortformEncoding으로 재인코딩을 요청해 최종 숏폼 영상을 산출합니다.

기능 개요

저장은 두 단계로 이뤄집니다. 먼저 편집기는 편집 상태를 서버 규약의 encodingParam(videoSectionList·background·intro·logo·audio·subtitle·title·overlayImages 등)으로 변환하고, editJs.validation.validateEncodingData()로 유효성을 검사합니다. 검증을 통과하면 api.shortform.putEditParams(resultId, putData) → PUT /nms/magic/shortform/result/{resultId}로 편집 파라미터를 NMS에 저장합니다.

저장 응답이 resultCode === 200이면 렌더 데이터(inputPath·resultId·param.encodingParam·srtFilePath·contentType)를 조립해 api.api.shortform.reqestEncoding(renderData) → POST /api/magic/shortform/v1/aiShortformEncoding으로 재인코딩 잡을 요청합니다. 인코딩 응답도 status === 0(연결 실패)·데이터 없음을 검증합니다.

멀티 편집기는 여러 결과를 한 번에 저장할 수 있어 saveMultipleVideos(resultIds)가 결과별 saveVideoById(resultId)를 순회하며, 진행 상황은 SaveProgressPopup으로 표시됩니다. 저장 중 발생한 오류는 단계별 메시지(저장 실패/인코딩 요청 실패)로 구분되어 사용자에게 통보됩니다.

설계 포인트
저장 → 인코딩 순서를 강하게 결합해, 파라미터 저장이 성공(200)했을 때만 인코딩을 요청합니다. 빈 값은 removeEmpty()로 제거하고 조건부 스프레드(...(Array.isArray(...) ? {...} : undefined))로 선택 항목만 인코딩 파라미터에 포함합니다.

핵심 코드

user/src/views/common/api/edit/ShortformHighlightEditMulti.vue — 저장 후 재인코딩
if (!editJs.validation.validateEncodingData(removeEmpty(encodingParam))) {
  throw new Error(`최종 인코딩 파라미터 유효성 검사 실패`)
}

let response = await api.shortform.putEditParams(resultId, putData)   // NMS 저장

if (response.data.resultCode == 200) {
  let renderData = {
    inputPath: totalResultData.inputPath,
    resultId: resultId,
    param: { contentType: contentType.value, srtFilePath: totalResultData.srtFilePath, encodingParam }
  }
  const encodingResponse = await api.api.shortform.reqestEncoding(renderData)  // 재인코딩
  response = encodingResponse;
}
user/src/api/shortform.js · user/src/api/api.js — 저장/인코딩 엔드포인트
// api/shortform.js
async putEditParams(resultId, data) {
  return await axios.put(`nms/magic/shortform/result/${resultId}`, data);
}

// api/api.js (shortform)
async reqestEncoding(data) {
  return axios.post('/api/magic/shortform/v1/aiShortformEncoding', data)
}
