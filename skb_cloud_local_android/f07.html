품질계측 · 로그 수집

TiMSManager가 주기/일별 수집 핸들러로 단말 품질 데이터를 모아 UDPClient로 TIMS/COQP 서버 또는 ADAMS 대체 서버에 전송하고, CoqpManager가 8VSB·스탠바이 이벤트를, QSMHandler·AgentHelper가 QSM 로그 수집을 수행합니다.

기능 개요

품질계측은 부팅 시 BootingFragment.onCreate()에서 TiMSManager.init()·start()로 시작됩니다. TiMSManager는 PeriodicCollectionHandler(주기 수집)와 DailyCollectionHandler(일별 수집), TiMSControlHandler(제어)를 보유하며, 두 수집 핸들러는 모두 추상 BaseCollectionHandler(DataUpdateListener)를 상속해 타이머로 collectInform()을 수행하고 UDPClient로 데이터를 전송합니다.

서버 IP·포트는 BuildConfig에 정의됩니다. TIMS는 TCP 8801·UDP 50000/50001(TIMS_TCP_PORT·TIMS_UDP_PORT1/2), COQP는 UDP/HTTP 50002~50005(COQP_SLEEP_HTTP_PORT·COQP_CHECK_UDP_PORT·COQP_8VSB_UDP_PORT·COQP_SLEEP_UDP_PORT)를 사용합니다. BaseCollectionHandler는 UDP 전송 대상으로 일반 서버 IP와 ADAMS 대체 서버 IP(adamsIp)를 모두 들고 있어, 비라이브향 로컬앱은 ADAMS 대체 수집 서버로 보냅니다.

CoqpManager는 채널 전환·신호·스탠바이·8VSB 이벤트를 받아 COQP 메시지를 만듭니다. PlaybackFragment.tune()이 8VSB 튠 후 msg8VSB()를, 스탠바이 진입 시 msgSleep()을 호출해 결과를 JSON으로 직렬화한 뒤 UDPClient로 전송합니다. QSM 로그는 QSMHandler가 qsm2lib.jar의 QSM2Report로 콜드부트·웨이크업 등 이벤트를 보고하고, AgentHelper가 SO 코드 등 부가 정보를 저장합니다.

ADAMS 대체 수집 서버
비라이브향 로컬앱은 ADAMS 대체 수집 서버(ADAMS_IP_TEST = 172.18.67.25 등)로 수집 데이터를 전송하도록 분석 기준 브랜치에서 전환되었습니다. BaseCollectionHandler는 일반 UDP 클라이언트와 ADAMS 클라이언트를 별도 스레드로 운용합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant BF as BootingFragment participant TM as TiMSManager participant PCH as PeriodicCollectionHandler participant UDP as UDPClient participant SRV as TIMS / ADAMS 서버 participant COQP as CoqpManager participant QSM as QSMHandler (qsm2lib) BF->>TM: init(context) / start() TM->>PCH: init / start (수집 타이머) loop 주기/일별 PCH->>PCH: collectInform() (JSON 구성) PCH->>UDP: new UDPClient(ip, port, data) UDP->>SRV: DatagramPacket 전송 end Note over COQP: 8VSB 튠 / 스탠바이 이벤트 COQP->>UDP: msg8VSB() / msgSleep() → UDP 전송 BF->>QSM: initialize(context) (QSM2Report) QSM->>SRV: 콜드부트/웨이크업 로그 보고

흐름. TiMSManager가 수집 핸들러 타이머를 돌려 UDPClient로 데이터를 보내고, CoqpManager가 이벤트성 메시지를, QSMHandler가 QSM 로그를 보고합니다.

관계. 두 수집 핸들러가 BaseCollectionHandler를 상속하고, TiMSManager가 이들을 소유하며, 전송은 UDPClient가 담당합니다. CoqpManager·QSMHandler는 이벤트/로그 경로입니다.
