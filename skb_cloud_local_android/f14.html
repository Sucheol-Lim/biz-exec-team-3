기능 개요

알림 수신은 TBNotificationListenerService(extends NotificationListenerService)가 담당합니다. onListenerConnected()로 연결되고 onNotificationPosted(StatusBarNotification)에서 시스템 알림을 받아, 스탠바이가 아니면 알림 제목·본문·서브텍스트를 추출하고 이미 확인한 알림 ID(SEEN_NOTIFICATION UserPreference)와 대조해 신규 알림만 처리합니다. 무거운 작업은 CompletableFuture.runAsync()로 비동기 처리합니다.

음성 안내(TTS)는 TTSHandler(implements TextToSpeech.OnInitListener)가 안드로이드 TextToSpeech 엔진을 초기화해 제공합니다. UserPreferenceManager에서 TTS on/off·속도를 읽어 적용하고, speakText()/speakFromEpg()/speakFromCsp()로 EPG·CSP 등 문맥별 발화를 합니다. 볼륨 변경은 VolumeChangeReceiver(android.media.VOLUME_CHANGED_ACTION)가 받아 TTSHandler.speakText("음량 N")으로 안내합니다.

예약은 ReserveManager가 세 리스트로 관리합니다. (1) 예약된 프로그램(reservedPrograms), (2) 정해진 시각에 트리거될 Reminder(extends Timer) 리스트, (3) 트리거 후 사용자 정의 동작을 수행할 RemindActor 리스트입니다. 예약 시각 도래·동작 시점은 AlarmEventListener(timeToAlarm·timeToAction·timerWentOff) 콜백으로 통지되며, 예약 데이터는 UserPreference(RESERVED_PROGRAMS)에 직렬화 저장됩니다(최대 MAX_RESERVE = 30).

예약 팝업 문구
분석 기준 브랜치에서 예약 및 중복 예약 팝업 문구·UI가 검수 반영되었습니다. 알림 시각 기본값은 프로그램 시작 60초 전(DEFAULT_ALARM_BEFORE = 60 * 1000L)입니다.

흐름. 알림은 리스너 서비스가 수신·중복 점검하고, 볼륨 변경은 TTS로 안내하며, 예약은 Reminder 타이머가 도래 시 AlarmEventListener로 통지합니다.

관계. 알림 서비스는 NotificationListenerService를 상속하고, VolumeChangeReceiver는 TTSHandler로 음량을 안내하며, ReserveManager는 Reminder 타이머와 AlarmEventListener로 예약을 운용합니다.

핵심 코드

module/tts/VolumeChangeReceiver.java — 볼륨 변경 음성 안내
public static final String VOLUME_CHANGED_ACTION = "android.media.VOLUME_CHANGED_ACTION";

public void onReceive(Context context, Intent intent) {
    if (!PowerModeManager.getInstance().isRunningMode()) return;
    if (intent.getAction().equals(VOLUME_CHANGED_ACTION)) {
        int value = (Integer) intent.getExtras().get(EXTRA_VOLUME_STREAM_VALUE);
        TTSHandler.getInstance().speakText("음량 " + value, true);   // TTS 발화
    }
}
module/reserve/AlarmEventListener.java — 예약 도래/동작 콜백
public interface AlarmEventListener {
    void timeToAlarm(Reminder reminder);     // 예약 시각 도래 알림
    void timeToAction(RemindActor reminder); // 트리거 후 사용자 동작
    void timerWentOff(Reminder reminder);    // 타이머 발화
}
