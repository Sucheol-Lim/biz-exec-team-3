SDV (Switched Digital Video)

module/sdv가 부팅 시 MC 데이터를 획득(McDataManager)하고, 채널 진입 시 SDV 서비스를 시작/종료(SdvSessionManager)하며, 412(NEED_GET_SG_CODE) 에러와 Rejoin을 처리해 스위치드 디지털 비디오 채널을 다룹니다.

기능 개요

SDV(Switched Digital Video)는 시청 요청이 있을 때만 채널을 스트림에 실어 주는 대역폭 절감형 디지털 방송입니다. 부팅 시 BootingFragment가 SdvManager.init()을 호출하면 McDataManager가 MC(Mini-Carousel) 데이터를 필터링·획득하고, 가용 여부를 isSdvAvailable()로 판단한 뒤 INITIALIZED(0x3005)를 통지합니다.

SDV 채널로 튠하면 SdvManager가 SdvInfo를 만들고 SdvSessionManager가 sourceId 단위로 SdvSession을 열거나(openSdvSession) 닫습니다(closeSdvSession). 세션은 SdvClientService를 통해 SDV 서버와 통신하며, 서버가 채널 그룹 코드를 다시 요구하면 NEED_GET_SG_CODE = 412 응답을 처리합니다. 채널이 사라진 경우(CONTENT_NOT_FOUND)에는 세션의 startRejoin()으로 재합류를 시도합니다.

다른 채널로 이동하거나 PlaybackFragment.tune()이 SDV 상태에서 비-SDV 채널로 전환될 때는 stopSDV()로 MC 필터링을 멈추고 세션을 정리합니다. 서버는 KeepAliveSender로 주기적 keep-alive를 받아 시청 중 세션을 유지하고, McSmartReclaim 타임아웃 정보로 자원 회수 타이밍을 관리합니다.

412 / Rejoin
SdvClientService.NEED_GET_SG_CODE = 412는 SG(Service Group) 코드 재요청을 의미합니다. 콘텐츠가 사라진 세션은 session.startRejoin()으로 재합류를 시도하며, 이미 rejoin 한 세션(getIsRejoined())은 중복 시도를 피합니다.

시퀀스 다이어그램

흐름. 부팅 시 MC 데이터로 SDV 가용성을 판단하고, 채널 진입 시 세션을 열며 412·콘텐츠 소실 시 SG 재요청·Rejoin으로 복구하고, 이탈 시 세션을 닫습니다.

관계. SdvManager가 진입점으로 SdvSessionManager(세션)와 McDataManager(MC 데이터)를 조율하고, 세션은 SdvClientService로 서버와 통신합니다.

핵심 코드

module/sdv/SdvManager.java — SDV 중단 시 MC 필터링·세션 정리
public void stopSDV() {
    Log.d(TAG, "stopSDV  isSDVState = " + getSDVState());
    if (!getSDVState()) {
        return;
    }
    SdvSessionManager.getInstance().clearAll();
    McDataManager.getInstance().stopFiltering();
    Log.d(TAG, "stopSDV end");
}
module/sdv/SdvManager.java — 콘텐츠 소실 세션 Rejoin (412/CONTENT_NOT_FOUND 흐름)
SdvSession session = SdvSessionManager.getInstance().getSdvSession(tunedUri);
// CONTENT_NOT_FOUND
if (/* !session.getIsRejoined() */ ...) {
    Log.d(TAG, "MainHandler_SDV onChannelEvent, CONTENT_NOT_FOUND startRejoin");
    session.startRejoin();   // SG 코드 재요청(412) 후 재합류
}
