기능 개요

미니 EPG는 EPG 레이어(LAYER_EPG_VIEW)에 올라가는 OSD 형태의 채널 가이드입니다. MiniEpgFragment가 채널 항목을 ChannelListView로 리스트업하고, 각 항목은 ChannelView/EpgItemView/ProgramView로 채널 번호·이름·현재 프로그램(ExProgram)을 표시합니다. 오디오 전용 채널은 AudioChannelFragment가 AudioDataManager.SongChangedListener로 곡 정보를 받아 시각화합니다.

DCA(Direct Channel Access, 채널 직접 입력)는 DcaFragment가 담당합니다. 사용자가 숫자를 입력하면 DcaItemView 자동완성 리스트가 표시되고, 입력이 완료되면 ChannelDataManager.findChannelByChannelNumber()로 대상 채널을 찾아 튠합니다. 자동완성 리스트에는 차단(파이/제한) 채널이 노출되지 않도록 필터링됩니다.

키 입력 처리는 MiniEpgFragment.onKeyPad()가 받습니다. ACTION_DOWN이 아닌 이벤트는 무시하며, 채널 항목이 isRestricted·PERM_CA_BLOCKED·NULL PROGRAM 상태인지 점검해 OSD 표시와 튠 동작을 분기합니다. UP/DOWN 키 롱프레스 중 발생하는 추가 이벤트는 키 처리 중 무시하도록 보정되어 있습니다.

UI 검수 반영 사항
분석 기준 브랜치에서 DCA 자동완성 리스트의 차단 채널 미표시, miniEpg up/down 롱프레스 시 키 처리 중 올라오는 이벤트 무시 등 UI 검수 항목이 반영되었습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant USR as 사용자 participant MEF as MiniEpgFragment participant CLV as ChannelListView participant CDM as ChannelDataManager participant CA as CaManagerImpl participant CC as ChannelController USR->>MEF: DPAD UP/DOWN / 숫자 입력 MEF->>MEF: onKeyPad() (ACTION_DOWN만 처리) Note over MEF: 롱프레스 중 추가 이벤트는 무시 MEF->>CLV: 채널 항목 갱신 / 포커스 이동 CLV->>CDM: 채널/프로그램 데이터 조회 MEF->>CA: isRestricted / PERM_CA_BLOCKED 점검 alt 차단 채널 MEF->>MEF: 차단 표시 / 튠 보류 else 정상 채널 USR->>MEF: 선택(OK) MEF->>CC: tune(선택 채널) end

흐름. onKeyPad()가 ACTION_DOWN만 처리하고 롱프레스 중복 이벤트를 무시하며, 차단 채널은 표시·튠을 분기한 뒤 정상 채널만 ChannelController.tune()으로 넘어갑니다.

public boolean onKeyPad(View v, int keyCode, KeyEvent event) {
    Log.d(TAG, "onKey: " + keyCode);
    if (event.getAction() != KeyEvent.ACTION_DOWN) {
        return false;                       // 롱프레스 중 올라오는 이벤트 등 비-DOWN 무시
    }
    // ...
    // onKey: CurrentChannel: isRestricted
    // onKey: CurrentChannel: PERM_CA_BLOCKED  → 차단 채널 분기
    // onKey: Different Channel                → 정상 채널 튠
}
