미디어 재생 연동(UMP)

UmpController가 UnitedMediaPlayer AIDL 인터페이스로 외부 미디어 플레이어 서비스(com.castis.ump.umpService)에 바인딩해 VOD를 재생하고, UMPEventListener 콜백으로 재생 이벤트를 수신합니다.

기능 개요

VOD/미디어 재생은 본 앱이 직접 디코딩하지 않고, 외부 미디어 플레이어 프로세스(com.castis.vod_service)에 AIDL로 위임합니다. 앱의 aidl/com/castis/ump에 정의된 UnitedMediaPlayer 인터페이스는 play·stop·setRate·setMediaOffset·demandVODRequestID·setECMGroup 등 재생 제어 메서드와, 결과 콜백용 UMPEventListener를 가집니다.

UmpController(싱글턴)가 연동의 핵심입니다. bindUmp()가 com.castis.ump.umpService 액션 인텐트(패키지 com.castis.vod_service)로 bindService()를 걸고, onServiceConnected()에서 UnitedMediaPlayer.Stub.asInterface(iBinder)로 원격 바인더를 얻습니다. 이어 setUMPEventListener()로 이벤트 리스너를 등록하고 setTerminalId()로 단말 MAC을 전달하며, 콘텐츠 암호화 키가 있으면 setECMGroup()으로 ECM을 주입합니다.

재생 이벤트는 UMPEventListenerImpl이 받아 VodEventCode로 매핑하고, VodManager가 VOD 상태(VodInfo)와 트릭모드(빨리감기/되감기)를 관리합니다. 라이브 시청과의 화면 점유 충돌은 UmpController.isStopped() 상태로 판단해 PlaybackFragment 튠 로직과 조율합니다. 서비스 연결이 끊기면(onServiceDisconnected) 세션 에러(EVENT_SESSION_ERROR)를 통보합니다.

EPG ↔ UMP 화면 점유
라이브 EPG와 외부 VOD 플레이어는 동일 비디오 평면을 공유하므로, UMP는 af.intent.action.EPG_STATE_SHOWING/EPG_STATE_STOPPED 브로드캐스트로 EPG 표시 상태를 외부 플레이어에 알려 화면 점유를 조율합니다.

핵심 코드

module/ump/UmpController.java — 외부 UMP 서비스 바인딩 및 AIDL 인터페이스 획득
umpConnection = new ServiceConnection() {
    public void onServiceConnected(ComponentName c, IBinder iBinder) {
        vodPlayer = UnitedMediaPlayer.Stub.asInterface(iBinder);   // AIDL 바인더
        umpEvtListenerImpl = new UMPEventListenerImpl();
        vodPlayer.setUMPEventListener(umpEvtListenerImpl);          // 이벤트 리스너 등록
        vodPlayer.setTerminalId(DeviceInfoManager.getInstance().getMacAddress());
        // 암호화 키 있으면 ECM 주입
    }
    public void onServiceDisconnected(ComponentName c) {
        if (!isStopped()) playFail(VodEventCode.EVENT_SESSION_ERROR);
    }
};
Intent intent = new Intent("com.castis.ump.umpService");
intent.setPackage("com.castis.vod_service");
mContext.bindService(intent, umpConnection, Context.BIND_AUTO_CREATE);
aidl/com/castis/ump/UnitedMediaPlayer.aidl — 외부 플레이어 제어 인터페이스(발췌)
interface UnitedMediaPlayer {
    void play(in int transactionId, in String fileName, in long offset);
    void stop(in int transactionId);
    void setRate(in int transactionId, in int rate);
    void setUMPEventListener(UMPEventListener umpEventListener);
    void setTerminalId(in String terminalId);
    void setECMGroup(in byte[] ecmGroup);
    int getUMPStatus();
}
