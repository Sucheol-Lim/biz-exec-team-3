핫키 입력 처리

GlobalKeyReceiver가 android.intent.action.GLOBAL_BUTTON·cab.intent.action.BYPASS_KEYEVENT 인텐트로 셋톱 전용 핫키를 수신해, 메뉴/검색/즐겨찾기 등은 GlobalKeyHandler로, 채널 UP/DOWN은 MainHandler 메시지로 라우팅합니다.

기능 개요

셋톱박스 리모컨에는 즐겨찾기·VOD·검색·키즈·날씨 등 전용 핫키가 있습니다. 이 키들은 일반 액티비티 키 이벤트가 아니라 시스템 브로드캐스트로 전달되므로, GlobalKeyReceiver(BroadcastReceiver)가 매니페스트에 android.intent.action.GLOBAL_BUTTON·cab.intent.action.BYPASS_KEYEVENT 액션으로 등록되어 이를 수신합니다.

onReceive()는 먼저 스탠바이 상태(!isRunningMode())면 즉시 무시합니다. GLOBAL_BUTTON의 경우 EXTRA_KEY_EVENT에서 KeyEvent를 꺼내 ACTION_DOWN만 처리하고, 즐겨찾기(KEY_FAV_CH)·TV 메뉴·채널 정보·키즈·VOD·날씨·검색 등 정의된 키코드는 GlobalKeyHandler.processGlobalKey()로 비동기 처리하며, 그 외 키는 WHAT_ANDROID_HOT_KEY 메시지로 MainHandler에 넘깁니다.

BYPASS_KEYEVENT의 경우 keyevent 엑스트라에서 KeyEvent를 꺼내 채널 UP/DOWN(KEY_CH_UP/KEY_CH_DOWN)을 WHAT_LIVE_CHANNEL_UP/DOWN 메시지로 보내 라이브 채널 전환을 트리거합니다. 무거운 처리는 ExecutorServiceHolder의 스레드 풀에서 CompletableFuture.runAsync()로 비동기 실행해 브로드캐스트 스레드를 막지 않습니다.

흐름. 스탠바이면 무시하고, GLOBAL_BUTTON은 키코드에 따라 GlobalKeyHandler 또는 MainHandler로, BYPASS_KEYEVENT의 채널 키는 라이브 채널 전환 메시지로 라우팅합니다.

관계. GlobalKeyReceiver가 BroadcastReceiver를 상속해 핫키를 받아 GlobalKeyHandler와 MainHandler로 분기하며, 스탠바이 여부를 PowerModeManager로 확인합니다.

핵심 코드

module/globalkey/GlobalKeyReceiver.java — 핫키 수신 및 라우팅
public void onReceive(Context context, Intent intent) {
    String action = intent.getAction();
    if (!PowerModeManager.getInstance().isRunningMode()) {
        return;                                          // 스탠바이 → 무시
    }
    if (ACTION_GLOBAL_BUTTON.equals(action)) {
        KeyEvent event = intent.getParcelableExtra(Intent.EXTRA_KEY_EVENT);
        if (event.getAction() != KeyEvent.ACTION_DOWN) return;
        int keyCode = event.getKeyCode();
        switch (keyCode) {
            case KeyCodes.KEY_FAV_CH:
            case KeyCodes.KEY_CATEGORY_VOD:
            case KeyCodes.KEY_TEXT_SEARCH:
                CompletableFuture.runAsync(() ->
                    GlobalKeyHandler.getInstance().processGlobalKey(keyCode),
                    ExecutorServiceHolder.getExecutorService());
                return;
        }
        MainHandler.getInstance().sendMessage(MainHandler.getInstance()
            .obtainMessage(MainHandlerMessage.WHAT_ANDROID_HOT_KEY, keyCode));
    } else if (ACTION_BYPASS_KEYEVENT.equals(action)) {
        // KEY_CH_UP → WHAT_LIVE_CHANNEL_UP / KEY_CH_DOWN → WHAT_LIVE_CHANNEL_DOWN
    }
}
