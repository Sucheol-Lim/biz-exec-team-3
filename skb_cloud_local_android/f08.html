기능 개요

장시간 동작하는 셋톱박스의 안정성을 위해 주기적 자가 재부팅과 자가진단을 수행합니다. 부팅이 끝나면 BootReceiver(ACTION_BOOT_COMPLETED)가 StabilizerService를 띄우고, 서비스의 onStartCommand()가 StabilizerMain을 생성합니다. StabilizerMain은 전원·사용자 설정·채널·컬러키 이벤트를 듣는 리스너로서 안정화 조건을 추적합니다.

재부팅 타이밍은 StabilizerTimer가 알람으로 관리합니다. 시청 모드(TIMER_WATCH_MODE), 키 입력(TIMER_KEY_INPUT), 스탠바이(TIMER_STAND_BY/TIMER_STAND_BY_REBOOT), 전원 ON 지속시간(TIMER_POWER_ON_DURATION) 타이머가 정의되어 있습니다. 알람이 발화하면 StabilizerAlarmReceiver.onReceive()가 해당 액션을 받아 StabilizerMain.timerWentOff() 또는 다음 타이머 요청으로 연결합니다.

안정화 조건이 충족되면 StabilizerMain.rebootSTB(reason)가 사유 로그를 남기고 MainHandler에 WHAT_REBOOT 메시지를 보내 재부팅을 트리거합니다. 시청 중에는 재부팅 안내 팝업(STABILIZER_REBOOT)을 띄워 사용자 확인/취소를 받습니다. 전원 제어는 PowerModeManager가 담당하여 setScreenOn()으로 화면 on/off 상태를 바꾸고 PowerModeChangeListener들에 전파하며, isRunningMode()가 스탠바이 여부 판단의 기준이 됩니다.

리부팅·자가진단 제어
분석 기준 브랜치에서 리부팅·자가진단 제어 기능이 추가되었습니다. 스탠바이 재부팅(TIMER_STAND_BY_REBOOT) 경로가 StabilizerAlarmReceiver를 통해 동작하며, SDK 31 라이프사이클에서 부팅 단계 초기화 타이밍이 함께 보정되었습니다.

핵심 코드

module/stabilizer/main/StabilizerAlarmReceiver.java — 스탠바이 재부팅 알람 처리
public void onReceive(Context context, Intent intent) {
    String action = intent.getAction();
    switch (action) {
        case ACTION_TIMER_STAND_BY:
            StabilizerMain.getInstance().rebootReason =
                StabilizerTimer.REBOOT_REASON[StabilizerTimer.TIMER_STAND_BY];
            StabilizerTimer.getInstance().requestStartTimer(TIMER_STAND_BY_REBOOT);
            break;
        case ACTION_TIMER_STAND_BY_REBOOT:
            StabilizerMain.getInstance().timerWentOff(TIMER_STAND_BY_REBOOT);
            break;
    }
}
module/stabilizer/main/StabilizerMain.java — 재부팅 트리거
public void timerWentOff(int timer) {
    if (timer == StabilizerTimer.TIMER_STAND_BY_REBOOT) {
        rebootSTB(null);
    }
}
private void rebootSTB(String reason) {
    Message rebootMessage = Message.obtain(MainHandler.getInstance(),
            MainHandlerMessage.WHAT_REBOOT, ...);   // 단말 재부팅 요청
    MainHandler.getInstance().sendMessage(rebootMessage);
}
