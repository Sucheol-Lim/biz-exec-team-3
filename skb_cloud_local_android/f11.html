검색 (글로벌/프로그램)

LocalSearchProvider(authority com.android.tv.search)가 Android TV 글로벌 검색 쿼리를 받아 TvProviderSearch로 채널·인풋·VOD를 검색하고, ProgramSearchProvider·ProgramSearchActivity가 프로그램 검색을 제공합니다.

기능 개요

Android TV의 글로벌 검색(런처 검색 바)은 등록된 ContentProvider의 query()를 통해 추천 결과를 모읍니다. 본 앱은 LocalSearchProvider를 authority com.android.tv.search로, ProgramSearchProvider를 com.android.tv.search.program으로 매니페스트에 선언해 검색 결과를 공급합니다.

LocalSearchProvider.query()는 URI의 마지막 세그먼트에서 질의어를, 쿼리 파라미터에서 결과 개수(SUGGEST_PARAMETER_LIMIT)와 액션 타입을 추출한 뒤 SearchInterface.search()를 호출합니다. 기본 구현 TvProviderSearch(implements SearchInterface)는 TvContract 기반으로 채널(searchChannels)·TV 인풋(searchInputs)·VOD(searchVod)·콘텐츠(searchContent)를 액션 타입에 따라 검색하고, 결과를 GoogleSearchResult 리스트로 모아 추천 커서로 변환해 반환합니다.

프로그램 검색은 별도로 ProgramSearchProvider가 동일한 SearchInterface 경로로 처리하며, 검색 결과 화면은 ProgramSearchActivity(extends BaseActivity)가 담당합니다. 검색 설정은 SearchConfigManager(채널/콘텐츠 개수 제한 등)와 ServiceConfiguration로 관리됩니다.

핵심 코드

module/search/provider/LocalSearchProvider.java — 글로벌 검색 쿼리 처리
public static final String AUTHORITY = "com.android.tv.search";

public Cursor query(Uri uri, String[] projection, String selection,
                    String[] selectionArgs, String sortOrder) {
    SearchInterface search = mSearchInterface;
    if (search == null) {
        search = new TvProviderSearch(getContext());
    }
    String query = uri.getLastPathSegment();
    int limit = getQueryParamater(uri, SearchManager.SUGGEST_PARAMETER_LIMIT, DEFAULT_SEARCH_LIMIT);
    int action = getQueryParamater(uri, SUGGEST_PARAMETER_ACTION, DEFAULT_SEARCH_ACTION);
    List<GoogleSearchResult> results = new ArrayList<>();
    if (!TextUtils.isEmpty(query)) {
        results.addAll(search.search(query, limit, action, true));
    }
    return createSuggestionsCursor(results);
}
module/search/provider/TvProviderSearch.java — 액션 타입별 검색 분기
public List<GoogleSearchResult> search(String query, int limit, int action, boolean isVod) {
    // action에 따라 채널/인풋/VOD/콘텐츠 검색
    results.addAll(searchChannels(query, channelsFound, SearchConfigManager.LIMIT_CHANNEL));
    results.addAll(searchInputs(query, limit));
    // list = searchVod(query, limit) / searchContent(query, limit)
}
