라이브 채널 시청

ChannelController가 튠을 결정하고 PlaybackFragment/TvViewer가 TvView 세션으로 라이브 채널을 재생하며, FCC(Fast Channel Change)가 인접 채널을 미리 프라임하여 빠른 채널 전환을 지원합니다.

기능 개요

라이브 시청은 재생 레이어(LAYER_TV_VIEW)의 PlaybackFragment가 담당합니다. 내부 뷰 TvViewer(RelativeLayout)가 SurfaceHolder 기반의 TvView 세션을 들고 있으며, tune() 호출 시 tvViewSession.tune(TAURUS_TV_INPUT_ID, Uri, bundle)로 셋톱 TV 인풋에 실제 튠을 요청해 방송 스트림을 재생합니다.

채널 결정은 ChannelController가 주관합니다. UP/DOWN·번호 입력·EPG 선택·3rd party 요청을 받아 대상 ExChannel을 정하고, PlaybackFragment.tune()에 URI를 넘깁니다. 튠 직전 SDV 상태면 기존 SDV 세션을 정리하고, 8VSB 채널이면 1초 후 CoqpManager.msg8VSB()로 품질계측 메시지를 보냅니다.

빠른 채널 전환(FCC)은 module/fcc/FCC가 담당합니다. primeChannels()가 현재 채널 기준 다음/이전 채널을 미리 튜너 프라이머(ChannelPrimerProxy)에 prime 해 두어, 사용자가 채널을 넘길 때 이미 준비된 스트림으로 즉시 전환되도록 합니다. 8VSB 양쪽 채널이고 직전 prime 대상과 동일하면 중복 prime을 건너뛰고, 스탠바이 상태(!isRunningMode())에서는 prime/튠을 막습니다.

8VSB 중복 튠 방지
primeChannels()는 up/down 채널이 모두 8VSB(getModulationFormat() == 4)이고 직전 prime 채널(oldUp/oldDown)과 같으면 즉시 return 하여, 동일 8VSB 채널에서 FCC를 여러 번 시도할 때 불필요한 반복 prime을 차단합니다.

핵심 코드

ui/main/fragment/PlaybackFragment.java — TvView 세션 튠과 8VSB 품질계측
public void tune(String uri, boolean fromEPG, Bundle bundle) {
    if (uri == null) return;
    boolean is8VSB = false;
    if (bundle != null) {
        is8VSB = bundle.getBoolean(ExChannelParam.KEY_BOOLEAN_TUNE_BY_8VSB);
    }
    // SDV 상태면 기존 SDV 정리
    if (bundle == null || !bundle.getBoolean(ExChannelParam.KEY_BOOLEAN_IS_TUNE_BY_SDV)) {
        if (SdvManager.getInstance().getSDVState() && !SdvManager.getInstance().isDefaultChannelUri(uri)) {
            SdvManager.getInstance().stopSDV();
        }
    }
    ChannelController.getInstance().setLatestUri(uri);
    ChannelController.getInstance().setIs8VSB(is8VSB);
    tvViewSession.tune(TAURUS_TV_INPUT_ID, Uri.parse(uri), b);
    if (is8VSB) {
        // 1초 후 8VSB 품질계측 메시지 전송
        CoqpManager.getInstance().msg8VSB();
    }
}

public static void primeChannels(ExChannel cur, boolean navNextCh) {
    if (!PowerModeManager.getInstance().isRunningMode()) {
        Log.i(TAG, "primeChannels: it's standby, so return");   // 스탠바이 → prime 금지
        return;
    }
    ExChannel up = ChannelController.getInstance().getNextChannel();
    ExChannel down = ChannelController.getInstance().getPrevChannel();
    boolean both8Vsb = up.getModulationFormat() == 4 && up.getModulationFormat() == 4;
    if (both8Vsb) {
        if (up.equals(oldUp) || down.equals(oldDown)) {
            return;                                              // 직전과 동일 → 중복 prime 무시
        }

    }
}
