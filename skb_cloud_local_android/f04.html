SI · 채널맵 구성

module/oob가 Out-Of-Band 채널맵·캠페인·플랫폼 정보를 수신하고, module/si가 Service Information을 파싱해 ChannelDataManager의 채널 DB를 구성하며, module/inband가 오디오·로고·I-frame 인밴드 데이터를 채웁니다.

기능 개요

채널맵 구성은 부팅 시퀀스의 핵심 단계입니다. OOBManager가 4개 섹션 필터(OOB_MENU·OOB_CHANNEL_MAP·OOB_PLATFORM_INFO·OOB_CAMPAIGN)와 티커 필터를 통해 Out-Of-Band 스트림에서 메뉴·채널맵·플랫폼 정보·캠페인 데이터를 수신합니다. 수신 데이터는 DataCenter를 통해 등록된 리스너에게 DataUpdateListener로 통지됩니다.

채널맵 데이터가 들어오면 ChannelMapManager가 ChannelMapAsyncTask로 파싱해 OOB 채널과 티브로드 채널(ExChannel)을 sourceId 기준으로 매핑합니다. module/si의 ChannelDataManager는 JavaTV/OCAP SI 스택(CabChannelManager)의 채널 리스트로 채널 DB를 초기화하고, 완료되면 INITIALIZED(0x3001) 메시지를 부팅 핸들러에 보냅니다.

module/inband의 InbandManager는 인밴드 데이터(OCManager/OCDataManager)를 통해 부팅 I-frame, 채널 로고(LogoManager), 오디오 곡 정보(AudioDataManager), I-frame 캐러셀(IframeManager)을 로드합니다. 이렇게 모인 SI/OOB/Inband 메타가 라이브 시청·미니 EPG·OSD의 데이터 소스가 됩니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant BF as BootingFragment participant OOB as OOBManager participant DC as DataCenter participant CMM as ChannelMapManager participant CDM as ChannelDataManager participant SI as JavaTV/OCAP SI (CabChannelManager) participant IB as InbandManager BF->>OOB: init() / startRetrieving() OOB->>DC: addDataUpdateListener(OOB_CHANNEL_MAP ...) OOB-->>DC: 채널맵/플랫폼/캠페인 수신 DC->>CMM: dataUpdated(OOB_CHANNEL_MAP) CMM->>CMM: ChannelMapAsyncTask 파싱 (sourceId 매핑) BF->>CDM: init(bootHandler) CDM->>SI: getChannelList() SI-->>CDM: CabChannel[] CDM-->>BF: INITIALIZED (0x3001) BF->>IB: init() (로고/오디오/I-frame) Note over CDM,IB: 채널 DB + 인밴드 메타 구성 완료

흐름. OOBManager가 OOB 데이터를 수신해 ChannelMapManager가 매핑하고, ChannelDataManager가 SI 스택으로 채널 DB를 초기화한 뒤 InbandManager가 인밴드 메타를 채웁니다.

    this.handler = handler;
    hostVendorId = DeviceInfoManager.getInstance().getHardwareVendorId();
    UserPreferenceManager.getInstance().addUserPreferenceChangeListener(this);
    ProgramManager.getInstance().addProgramScheduleUpdateListener(this);
    // ... initChannelData() : CabChannelManager.getInstance().getChannelList()
    handler.sendEmptyMessage(INITIALIZED);   // 0x3001 → BootingFragment
}
