EPG 외부 노출(AIDL)

기능 개요

본 로컬 EPG 앱은 셋톱 위에서 동작하는 다른 3rd party 앱(VOD·부가 서비스 등)에 자신의 EPG/단말 기능을 IPC로 제공합니다. 이를 위해 IEpgService.aidl에 단말·사용자 관련 메서드를 정의하고, IEpgAIDLService(extends Service)가 IEpgService.Stub을 구현한 바인더를 onBind()로 반환합니다. 서비스는 AndroidManifest.xml에 com.alticast.android.tv.local.action.EPGService 액션과 exported="true"로 선언되어 외부에서 바인딩할 수 있습니다.

AIDL 인터페이스는 UserPreference 읽기/쓰기(readUserPreference/writeUserPreference), 사용자/구매 PIN 확인(checkUserPIN/checkPurchasePIN), SRM 주소(getSrmAddress), 채널 이동(selectChannel), 홈 메뉴 실행(showHomeMenu), 단말 정보(getStbModel·getSmartCardId·getSoCode·getCustomerId·getContractId)를 제공합니다.

구현은 내부 매니저로 위임합니다. readUserPreference/writeUserPreference·PIN 확인은 UserPreferenceManager로, selectChannel(srcId)은 ChannelDataManager.findChannelBySourceId()로 채널을 찾아 ChannelController.set3rdPartyTuneCh()로 설정한 뒤 앱을 포그라운드로 복귀(returnForeground)시키고, showHomeMenu()는 CloudHomeMain.showHomeMenu()로, 단말 정보는 DeviceInfoManager로 처리합니다. 즉 외부 앱은 EPG의 내부 구조를 몰라도 AIDL 한 인터페이스로 핵심 기능을 호출할 수 있습니다.

3rd party 채널 이동 패턴
selectChannel(srcId)은 외부 앱이 닫히면서 지정 채널로 이동하도록 설계되어, 즉시 튠 대신 set3rdPartyTuneCh()로 대상 채널을 예약하고 returnForeground()로 EPG를 전면 복귀시킵니다.

핵심 코드

module/ump/service/IEpgAIDLService.java — AIDL Stub 구현 · 3rd party 채널 이동
private final IEpgService.Stub mBinder = new IEpgService.Stub() {
    @Override
    public void selectChannel(int srcId) throws RemoteException {
        LastIdHolder.getInstance().clearLastId();
        ExChannel ch = ChannelDataManager.getInstance().findChannelBySourceId(srcId);
        ChannelController.getInstance().set3rdPartyTuneCh(ch);   // 채널 예약
        returnForeground(context);                                // EPG 전면 복귀
    }
    @Override
    public void showHomeMenu() throws RemoteException {
        returnForeground(context);
        CloudHomeMain.getInstance().showHomeMenu();
    }
};

@Override
public IBinder onBind(Intent arg0) {
    return mBinder;
}
aidl/com/alticast/epg/tbroad/android/IEpgService.aidl — 외부 노출 인터페이스(발췌)
interface IEpgService {
    String readUserPreference(String upName);
    boolean writeUserPreference(String upName, String value);
    boolean checkUserPIN(String pin);
    boolean checkPurchasePIN(String pin);
    void selectChannel(int srcId);   // 3rd party가 닫히며 채널 이동
    void showHomeMenu();
    String getStbModel();
    String getSmartCardId();
}
