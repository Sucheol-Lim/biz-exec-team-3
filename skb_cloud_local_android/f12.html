블루투스 RCU / HDMI

BluetoothManager가 리모컨(RCU) 페어링·디스커버리를 다루고 BluetoothEventListener로 결과를 통지하며, RcuFirmwareVersionController가 RCU 펌웨어 버전을 조회하고 HdmiManager가 HDMI EDID/핫플러그를 처리합니다.

기능 개요

블루투스 RCU(Remote Control Unit, 리모컨) 페어링은 BluetoothManager(싱글턴)가 담당합니다. init()으로 BluetoothEventHandler를 설정하고, startPairing()이 호출되면 RCU·헤드셋 등 디바이스 타입별 페어링 상태를 초기화하고 블루투스 리시버를 등록한 뒤 등록 안내 팝업(BLUETOOTH_DEVICE_REGISTER)을 띄웁니다. 디스커버리는 BluetoothAdapter.getDefaultAdapter()를 통해 수행되며, 페어링 결과(시작/성공/실패/종료)는 BluetoothEventListener 콜백으로 통지됩니다.

RCU 펌웨어 버전은 RcuFirmwareVersionController(extends BroadcastReceiver)가 관리합니다. requestRcuFirmwareVersion()이 외부 RCU 서비스(com.ohsungec.smartset.SmartSetService)에 조회 인텐트를 브로드캐스트하고, 응답 액션을 onReceive()로 받아 swVersion을 추출해 UserPreferenceManager의 KEY_RCU_FRIMWARE_VER에 저장합니다.

HdmiManager는 HDMI 연결을 다룹니다. init()에서 EDID 요청(ACTION_EDID_REQUEST) 리시버를 등록하고, Host.getInstance().getEdid()로 연결된 디스플레이의 EDID를 읽으며, HDMI 상태 변화 브로드캐스트를 받아 전원 모드(isRunningMode())에 따라 처리합니다.

페어링 타임아웃
시스템 앱이 처리하는 connection 타임아웃(30초)과 별개로, 블루투스 페어링 전체 타임아웃은 60초로 조정되어 있습니다(BluetoothManager.startPairing() 주석 기준).

관계. BluetoothManager가 BluetoothEventListener로 페어링 결과를 통지하고, RcuFirmwareVersionController는 BroadcastReceiver를 상속해 외부 RCU 서비스 응답을 받습니다.

핵심 코드

module/bluetooth/RcuFirmwareVersionController.java — RCU 펌웨어 조회·수신
public void requestRcuFirmwareVersion() {
    Intent intent = new Intent("com.ohsungec.smartset.SmartSetService");
    intent.setAction(REQUESTER_ACTION);
    intent.putExtra("class_name", RcuFirmwareVersionController.class.getName());
    mContext.sendBroadcast(intent);
}

public void onReceive(Context context, Intent intent) {
    if (intent.getAction().equals(RECEIVER_ACTION)) {
        String swVersion = intent.getStringExtra("swVersion");
        UserPreferenceManager.getInstance().set(UserPreferenceItem.KEY_RCU_FRIMWARE_VER, swVersion);
    }
}
module/bluetooth/BluetoothEventListener.java — 페어링 결과 콜백 인터페이스
public interface BluetoothEventListener {
    void notifyStartPairing(BluetoothDevice device);
    void notifySuccessParing(BluetoothDevice device);
    void notifyFailedPairing(BluetoothDevice device, int errCode);
    void stopPairing(BluetoothDevice device);
}
