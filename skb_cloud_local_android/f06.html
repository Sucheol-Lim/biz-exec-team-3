CAS (수신제한)

module/cas의 CaManagerImpl이 CaManager 인터페이스를 구현해 유료/제한 채널 시청 제어를 담당하고, CaHandler/CaRequester가 CAS 시스템에 채널·구매 요청을 보내 결과를 CaResultListener로 통지합니다.

기능 개요

CAS(Conditional Access System, 수신제한)는 유료·제한 채널의 시청 권한을 통제합니다. CaManagerImpl이 CaManager 인터페이스의 단일 구현체(싱글턴)로 동작하며, 부팅 시 BootingFragment가 CaManagerImpl.getInstance()를 호출해 CAS 서비스를 초기화합니다. 내부적으로 createCaHandler()로 추상 CaHandler의 구현(AltiCaHandler)을 만들고 CaResultListener를 등록합니다.

채널을 튠할 때 requestCaChannel(ExChannel)이 호출되어 CaHandler를 거쳐 CaRequester가 CAS 시스템에 권한을 조회합니다. 결과는 CaResult로 돌아와 CaResultListener.notifyCaEvent(channel, result)로 통지되며, 차단·미가입 상태면 미니 EPG/OSD가 PERM_CA_BLOCKED·isRestricted 분기로 차단 화면을 띄웁니다. 유료 구매는 requestCaPurchase()·requestCaPurchaseWithPrdId()로 처리합니다.

CAS는 스마트카드 상태(getSmartCardID()·isValidSmartCardStatus()), CAS 시스템 ID(getCasSystemId()), 만료 여부(getIsExpired()), 미리보기(PreviewInfo/previewStop())도 다룹니다. 저장소에는 별도 cas-module이 존재하나 settings.gradle에 포함되지 않아 현재 빌드에는 참여하지 않습니다.

cas-module 빌드 미참여
루트의 cas-module/은 settings.gradle 활성 모듈(:app, :wind3Lib-1.1.6)에 포함되지 않습니다. 실제 동작하는 CAS 로직은 앱 본체의 module/cas/CaManagerImpl입니다.

흐름. CaManagerImpl이 CaHandler를 생성·리스너 등록하고, 채널 튠 시 CaRequester가 CAS 시스템에 권한을 조회해 결과를 UI 리스너로 통지합니다.

관계. CaManagerImpl이 CaManager를 구현하고, 추상 CaHandler(구현 AltiCaHandler)를 소유하며, CaRequester로 요청을 위임하고 CaResultListener로 결과를 통지합니다.
