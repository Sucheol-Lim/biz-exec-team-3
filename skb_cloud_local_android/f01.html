기능 개요

본 앱은 셋톱박스의 First Screen(부팅 직후 첫 화면) 역할을 합니다. AndroidManifest.xml에서 MainActivity가 com.android.tv.action.FORCE_LAUNCH_ON_BOOT 액션과 android.intent.category.HOME·DEFAULT·LAUNCHER 카테고리를 가진 진입점으로 등록되어, 전원이 인가되면 시스템이 가장 먼저 이 액티비티를 띄웁니다.

앱 프로세스가 뜨면 EpgApplication.onCreate()가 먼저 실행되어 android-rop 네이티브 라이브러리를 로드하고 액티비티 라이프사이클 콜백을 등록합니다. MainActivity.onCreate()는 화면보호기 방지 플래그를 설정하고 권한을 점검한 뒤 WatchdogServiceMonitor를 초기화하며, UiLayerManager의 LAYER_NORMAL_VIEW에 BootingFragment를 올려 부팅 화면을 표시합니다.

BootingFragment는 onStart()에서 startBootingProcess()를 돌려 Windmill 서비스·TTS·OOB·Inband·ChannelDataManager·CAS·인증(TbroadAuthorization) 등 플랫폼 매니저를 순차 초기화합니다. 채널 DB 초기화가 끝나면(ChannelDataManager.INITIALIZED) 채널 필터링·FCC·SDV 초기화가 이어지고, 모든 초기화가 완료되면 PlaybackFragment(LAYER_TV_VIEW) 재생 화면으로 전환되어 라이브 시청 상태로 진입합니다.

UC500 / SDK 31 라이프사이클
TiMSManager 초기화는 BootingFragment.onCreate()에서, 부팅 작업 본체는 onStart()에서 수행됩니다. 스탠바이 재부팅 시 onStart 미호출로 TIMS 초기화가 누락되던 SDK 31 라이프사이클 타이밍 차이가 분석 기준 브랜치에서 보정되어 있습니다.

흐름. 시스템이 FORCE_LAUNCH_ON_BOOT로 MainActivity를 띄우면 부팅 화면을 표시하고, BootingFragment가 플랫폼 매니저와 채널 DB를 초기화한 뒤 재생 화면으로 인계합니다.

핵심 코드

ui/main/fragment/BootingFragment.java — 채널 DB 초기화 완료 후 FCC/SDV 연쇄 초기화
case ChannelDataManager.INITIALIZED: {
    isInitChannelDataManager = true;
    ChannelDataManager.getInstance().filterChannel();
    ChannelController.getInstance().init(MainHandler.getInstance());
    if (BuildConfig.FCC) {
        FCC.init();
    }
    SdvManager.getInstance().init(this);
    sendInitCompletedMessage();
    break;
}
MainActivity.java — 재생 프래그먼트 레이어 배치
UiLayerManager.getInstance().init(this);
if (fPlayback == null) {
    fPlayback = PlaybackFragment.newInstance();
}
UiLayerManager.getInstance().replaceFragment(LayerDef.LAYER_TV_VIEW, fPlayback);
