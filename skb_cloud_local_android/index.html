개요

본 과제는 티브로드(현 SK브로드밴드, 이하 SKB) 케이블/IPTV 셋톱박스에서 동작하는 Android TV용 로컬 EPG(전자 프로그램 가이드) 겸 메인 런처 애플리케이션입니다. 단말의 First Screen(부팅 직후 첫 화면) 역할을 수행하며, MainActivity가 HOME/LAUNCHER 카테고리를 가진 진입점으로 등록되어 셋톱박스 전원 인가 시 가장 먼저 실행됩니다.

Android Leanback 기반의 TV UI로 라이브 채널 시청, 미니 EPG, 채널 리스트, 오디오 채널, DCA(채널 직접 입력), 예약, 검색 등 방송 기능을 제공합니다. 동시에 SI(Service Information), OOB/Inband 채널맵, CAS(수신제한), QSM/TIMS(품질계측), Stabilizer(단말 안정화), TTS(음성 안내), 블루투스 RCU, SDV(Switched Digital Video) 등 셋톱박스 플랫폼 기능을 폭넓게 다루는 시스템 애플리케이션입니다.

로컬 모드와 클라우드 모드를 빌드 타입으로 전환할 수 있는 것이 특징으로, CLOUD/CLOUD_BARE/CLOUD_SAT 플래그와 module/cappl(클라우드 앱 플랫폼)·module/ccs(Cloud Home/PIP)·clad/cladimpl(Cloud App 인터페이스/구현)를 통해 클라우드 홈·앱 플랫폼 연동을 지원합니다.

UC500 / log 브랜치 맥락
분석 기준 브랜치 UC500_log_2025는 BKO UC-500 신규 셋톱(KAON 등)을 대상으로 Android 9(API 28)에서 Android 12(API 31)로 업그레이드한 코드 베이스에서, 품질계측·로그 수집 고도화(TIMS/COQP)와 관련 기능을 집중적으로 반영한 분기입니다. 단말 패키지명은 com.alticast.android.tv.local이며 INJECT_EVENTS, REBOOT, EPG provider 접근, taurus.cl_prj uses-library 등 셋톱박스 전용 시스템 권한을 사용합니다.

주요 기능

First Screen / 런처
MainActivity가 HOME·LAUNCHER·FORCE_LAUNCH_ON_BOOT intent-filter를 가진 진입점으로 부팅 직후 실행되어, 부팅 화면(BootingFragment) 표시 후 재생 화면으로 전환합니다.
라이브 채널 시청
ui/main/fragment의 TvViewer/PlaybackFragment로 라이브 채널을 재생하고, FCC(Fast Channel Change) 기반의 빠른 채널 전환을 지원합니다.
미니 EPG / 채널 리스트
ui/miniepg에서 미니 EPG, 채널 리스트, 오디오 채널, DCA(채널 직접 입력) 화면을 제공하며 키 롱프레스 처리·차단 채널 표시 등을 다룹니다.
SI · 채널맵 구성
module/si(Service Information), module/oob(Out-Of-Band 채널맵·캠페인·홈 광고), module/inband(오디오/로고/I-frame)로 채널 메타데이터와 스트림 정보를 수신·구성합니다.
SDV (Switched Digital Video)
module/sdv에서 부팅 시 MC 데이터 획득, SDV 서비스 시작/종료, 412 에러 처리, Rejoin 등 스위치드 디지털 비디오 채널을 처리합니다.
CAS (수신제한)
module/cas의 CaManagerImpl로 유료/제한 채널 시청 제어를 담당합니다. 별도 cas-module도 존재하나 현재 빌드 미참여입니다.
품질계측 · 로그 수집
module/tims·module/qsm(qsm2lib.jar)·module/qagent로 TIMS/COQP 품질계측과 로그 수집을 수행합니다. TCP/UDP 포트가 BuildConfig에 정의되어 있습니다.
단말 안정화 / 전원
module/stabilizer(StabilizerService·StabilizerAlarmReceiver·BootReceiver)로 스탠바이·재부팅·자가진단 알람을 관리하고, module/powermode로 전원 상태를 제어합니다.
클라우드 홈 / CAPPL
module/cappl(최대 모듈)과 module/ccs(CloudHomeMain·HomePIPManager), clad/cladimpl로 클라우드 홈·앱 플랫폼(Windmill) 연동을 처리합니다.
미디어 재생 연동(UMP)
aidl의 UnitedMediaPlayer/UMPEventListener와 module/ump로 외부 미디어 플레이어 서비스(com.castis.ump)와 AIDL 연동합니다.
검색 (글로벌/프로그램)
module/search의 LocalSearchProvider(authority com.android.tv.search)와 ProgramSearchProvider로 Android TV 글로벌 검색·프로그램 검색을 지원합니다(ProgramSearchActivity).
블루투스 RCU / HDMI
module/bluetooth의 BluetoothManager·RcuFirmwareVersionController·HdmiManager로 리모컨 페어링·펌웨어·HDMI를 다룹니다.
핫키 입력 처리
module/globalkey의 GlobalKeyReceiver가 GLOBAL_BUTTON·BYPASS_KEYEVENT 인텐트로 셋톱 핫키를 수신·처리합니다.
알림 / TTS / 예약
ui/notification의 TBNotificationListenerService(시스템 알림 수신), module/tts(음성 안내·VolumeChangeReceiver), module/reserve(시청·녹화 예약)를 제공합니다.
EPG 외부 노출(AIDL)
IEpgAIDLService(com.alticast.android.tv.local.action.EPGService 액션, IEpgService.aidl)로 타 앱에 EPG 기능을 노출합니다.

계층 · 외부 연동

UI 계층(ui/)은 미니 EPG·재생·다이얼로그·CCS 화면을 담당하고, 기능 모듈 계층(module/)은 방송·플랫폼 도메인 로직을 캡슐화하며, 그 아래 clad/cladimpl이 OCAP/JavaTV SI·미디어 스택과 클라우드 앱 인터페이스를 추상화합니다. 외부 연동은 (1) AIDL을 통한 외부 미디어 플레이어(com.castis.ump) 및 EPG 서비스 노출, (2) com.android.providers.tv EPG 프로바이더 접근, (3) taurus.cl_prj uses-library 및 android-rop 네이티브 라이브러리를 통한 셋톱 플랫폼(TIS/taurus) 제어, (4) okhttp3 기반의 TIMS/COQP/ADAMS 품질계측 서버 및 클라우드(Windmill/CAPPL) 서버 통신으로 이루어집니다. <queries>에는 watchdog·startset·vod_service·agent 등 협력 패키지가 선언되어 있습니다.

핵심 동작 흐름

부팅 시퀀스 (First Screen)

  1. 앱 기동 · 네이티브 로드EpgApplication.onCreate()에서 android-rop 네이티브 라이브러리를 로드하고 액티비티 라이프사이클 콜백을 등록합니다.
  2. MainActivity 진입 · 부팅 화면셋톱 전원 인가 시 HOME 런처인 MainActivity가 실행되어 로딩 시퀀스가 끝날 때까지 BootingFragment(activity_boot)를 표시합니다.
  3. 플랫폼 매니저 초기화채널맵(ChannelMapManager), 플랫폼 정보(PlatformInfoManager), CAS(CaManagerImpl), 전원 모드(PowerModeManager), 블루투스(BluetoothManager), Cloud Home(CloudHomeMain) 등 다수 매니저를 초기화합니다.
  4. SI / 채널맵 수신module/oob·module/si·module/inband으로 OOB/Inband 채널맵과 Service Information을 수신·구성하고, 필요 시 module/sdv로 MC 데이터를 획득합니다.
  5. 재생 화면 전환로딩이 완료되면 PlaybackFragment/TvViewer로 전환되어 라이브 채널 시청 상태로 진입합니다. (스탠바이 재부팅 시 BootingFragment 라이프사이클·TIMS 초기화 타이밍이 SDK 31에 맞춰 보정되어 있습니다.)

채널 전환 (FCC / 미니 EPG)

  1. 키 입력 수신GlobalKeyReceiver 또는 액티비티 키 핸들러가 채널 UP/DOWN·숫자(DCA) 입력을 수신합니다. 미니 EPG에서는 롱프레스 중 발생한 이벤트를 무시하도록 처리합니다.
  2. 채널 결정 · 차단 검사대상 채널을 결정하고 CAS(CaManagerImpl) 차단 여부를 확인합니다. DCA 자동완성 리스트에는 차단 채널이 표시되지 않습니다.
  3. FCC 튠FCC 플래그가 켜진 환경에서 빠른 채널 전환을 수행합니다. 8vsb 채널에서는 직전 FCC와 동일한 대상이면 중복 튠을 무시하고, 스탠바이 상태에서는 FCC 튠을 막습니다.
  4. 스트림 재생 · 메타 갱신TvViewer/PlaybackFragment가 새 채널을 재생하고, SI/Inband 데이터로 OSD·로고·미니 EPG 정보를 갱신합니다.

품질계측 · 로그 수집 (TIMS / COQP)

  1. 초기화부팅 시 module/tims·module/qsm이 BuildConfig에 정의된 TIMS(TCP 8801, UDP 50000/50001)·COQP(UDP 50002~50005) 포트와 서버 IP로 초기화됩니다.
  2. 상태 수집채널 전환·신호 상태·스탠바이·8vsb 등 단말 이벤트를 qsm2lib.jar 및 module/qagent가 수집합니다.
  3. 서버 전송수집 데이터를 TIMS/COQP 서버 또는 ADAMS 대체 수집 서버로 UDP/HTTP 전송합니다(비라이브향은 ADAMS 대체 서버 사용).

# 셋톱 단말 설치 (시스템 권한 필요)
adb install -r ../apks/uc500_tbroad_local_3.2.5.0050_<date>_DEV.apk

산출물은 ../apks/uc500_tbroad_local_<versionName>_<yyyyMMdd>_<variant>.apk 형식으로 출력됩니다(현재 versionName "3.2.5.0050", versionCode 3250050). 환경 설정은 assets/cloud.properties, windmill.properties, dm_config_live.ini/dm_config_test.ini, stabilizer*.properties로 관리합니다.

빌드 전 주의
signingConfigs.tbroad의 storeFile 경로가 C:/AndroidStudioProjects/...로 하드코딩되어 있습니다. 실제 빌드 시 저장소 내 cert/tbroad_signning_key.jks 경로로 맞춰야 합니다(macOS 경로 예시가 주석으로 존재). 시스템 권한이 필요하므로 일반 에뮬레이터에서는 정상 동작하지 않을 수 있습니다.
