검색

기능 개요

검색은 홈 서브 영역의 검색 화면(SearchView/TTSearchKeypad)과 SearchViewModel로 구성됩니다. ViewModel은 키워드 입력에 대한 추천 키워드(loadRecommendKeyword → getKeywordSearch), 실제 검색 결과(loadSearchData → getSearchData), 입력 전 정적 추천(loadStaticContent → getStaticRecommend)을 SI/도메인의 SearchRepository를 통해 가져옵니다. 결과는 필터(SearchFilter)와 함께 콘텐츠 리스트(SearchContent)로 화면에 노출됩니다.

검색 언어 처리는 이 화면의 핵심 작업이었습니다. ViewModel은 현재 UI 언어(getUILanguage() — 프로필 langData.uiLang, 기본 "tur")를 읽어 정적 추천·검색 요청 파라미터에 반영합니다. 과거에는 콘텐츠 검색 시 languageType = "tur|eng"로 터키어/영어를 함께 질의했으나, 검색 결과 콘텐츠명이 터키어로 표시되도록 현재 UI 언어만 전달하는 방식으로 변경되었습니다(VLTRANLAND-1855). 검색 실행 결과는 성공/실패 코드와 함께 DataCollectRepository.logSearch로 수집됩니다.

검색 결과에서 시리즈를 선택하면 검색 상세 화면(SearchDetailViewModel)이 seriesHeadId 기준으로 에피소드 목록을 조회합니다. 에피소드 정렬 파라미터는 sortType = "4"로 조정되었습니다(VLTRANLAND-1909, 에피소드 정렬 기준 변경).

검색 이력은 프로필 단위로 관리됩니다(saveSearchHistory/loadSearchHistory). SearchRepository가 로컬 저장(putSearchHistoryData)과 프로필별 삭제(deleteProfileSearchHistory)를 제공합니다.

설계 포인트
검색 API(SearchApi)는 반환값이 필요한 호출은 Single, 성공 여부만 확인하는 호출은 Completable로 구분한다는 규칙이 인터페이스 주석에 명시되어 있습니다. 각 메서드는 서버 인터페이스 번호(예. 3.19.2. Acquisition of Search List Data)와 매핑됩니다.

관계. SearchViewModel이 SearchRepository를 통해 검색·추천·이력을 처리하고, 구현은 Retrofit SearchApi로 서버에 도달합니다. 결과는 SearchFilter로 분류되어 화면에 표시됩니다.

핵심 코드

home/sub/search/SearchViewModel.kt — UI 언어 반영 질의 + 검색 로그 수집
fun loadSearchData(
    searchKeyword: String,
    category: SearchFilter,
) {
    val lang = getUILanguage()
    // ...
    searchRepository.getSearchData(
        condition = searchKeyword.trim(),
        // ...
        languageType = lang,   // [VLTRANLAND-1855] UI 언어만 질의 (구. "tur|eng")
        seriesType = "1|3",
        filterType = "2|8",
    ).subscribe(
        { result ->
            _searchContentList.postValue(getSearchContentList(result))
            dataCollectRepository.logSearch(
                resultCode = result.returnCode.ifBlank { "-1" },
                keyword = searchKeyword.trim(),
            )
        }, { error ->
            Timber.d("loadSearchData|getSearchData error=$error")
            dataCollectRepository.logSearch(resultCode = "-1", keyword = searchKeyword.trim())
        }
    ).apply { compositeDisposable.add(this) }
}

private fun getUILanguage(): String {
    return currentProfile?.langData?.uiLang ?: "tur"
}
