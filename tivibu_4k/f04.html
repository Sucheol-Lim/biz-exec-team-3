녹화(nPVR)

RecordCoordinator가 녹화 예약/취소/삭제를 조율하고 NPvrRepository → NPvrApi(Retrofit) 경로로 서버 네트워크 녹화(nPVR)를 호출하며, 녹화물 재생은 NPVRPlayHandler로 연결됩니다.

기능 개요

녹화는 단말 로컬이 아니라 네트워크 녹화(nPVR) 방식입니다. 라이브 TV(LiveTvScreen의 onRecord/onRecordCancel/onRecordRemove) 또는 편성표에서 녹화를 요청하면 LiveTvViewModel이 위임받은 RecordCoordinator를 통해 도메인 흐름으로 들어갑니다. RecordCoordinator는 데이터 가공과 네비게이션(예약 결과/에러 팝업)을 함께 담당합니다.

실제 서버 호출은 NPvrRepository 구현이 NPvrApi(Retrofit 인터페이스)를 통해 수행합니다. 단편 녹화 추가(addNPvr), 시리즈 녹화 추가(addNPvrSeries), 삭제(delNPvr/delNPvrSeries), 자동 삭제 갱신(updateNPvr), 녹화 제한 확인(limitNPvr), 잔여 녹화 시간(getNPvrTime), 녹화 상태 조회(checkNPvrStatus), 사용자/시리즈 녹화 목록(getUserNPvrList/getUserSeriesNPvrList)을 제공합니다.

녹화된 콘텐츠의 재생은 VOD 재생 파이프라인을 재사용합니다. PlayOrchestrator의 핸들러 딕셔너리에서 VodType.RECORD가 NPVRPlayHandler에 매핑되어 녹화물을 일반 VOD처럼 재생합니다.

설계 포인트
각 NPvrApi 메서드 주석에 서버 인터페이스 번호(예. 3.18.1. Addition of NPVR (Non-Series) Recording)가 명시되어 있어 Türk Telekom 백엔드 스펙과 1:1로 추적됩니다. 시리즈 녹화 추가 시 prevueCode를 의도적으로 생략하는 등 웹(QueryManager.js) 동작과 정합을 맞춘 흔적이 코드 주석에 남아 있습니다.

흐름. 녹화 요청이 ViewModel에 위임된 RecordCoordinator로 전달되면, 녹화 제한 확인 후 NPvrRepository→NPvrApi 경로로 서버에 예약을 요청합니다. 결과에 따라 완료 표시 또는 에러 팝업을 보입니다.

관계. RecordCoordinator가 도메인 NPvrRepository를 호출하고, 구현은 Retrofit NPvrApi로 서버에 도달합니다. 녹화물 재생은 PlayOrchestrator의 NPVRPlayHandler(VodType.RECORD)가 담당합니다.

핵심 코드

data/remote/api/NPvrApi.kt — nPVR Retrofit 인터페이스(서버 스펙 번호 매핑)
interface NPvrApi {
    // 3.18.1. Addition of NPVR (Non-Series) Recording
    @GET(DataConfig.API_ADD_NPVR)
    fun addNPvr(
        @Query("channelcode") channelCode: String,
        @Query("seriesheadid") seriesHeadId: String,
        @Query("prevuecode") prevueCode: String,
    ): Single<BaseResponseDto>

    // 3.18.5. Addition of NPVR (Series) Recording
    @GET(DataConfig.API_ADD_NPVR_SERIES)
    fun addNPvrSeries(
        @Query("channelcode") channelCode: String,
        @Query("seriesheadid") seriesHeadId: String,
        // prevueCode 생략: Web QueryManager.js - addNPvrSeries 참조
        @Query("istotalseason") isTotalSeason: String? = "1",
    ): Single<BaseResponseDto>

    // 4.2.2. User Recording Restriction Notification Interface
    @GET(DataConfig.API_LIMIT_NPVR)
    fun limitNPvr(...): Single<NPvrLimitDto>
}
