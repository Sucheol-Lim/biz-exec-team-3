기능 개요

설정 화면은 SettingScreen(ATVScreen)이 좌측 메뉴(SettingMenuAdapter)와 우측 서브 뷰를 조합하는 마스터-디테일 구조입니다. 메뉴 항목은 SettingMenuItem enum으로 정의되며(CHANNEL_CONTROL·RENTAL_PURCHASE_HISTORY·MY_RECORDS·MY_REMINDERS·PIN_TRANSACTIONS·CAMPAIGNS·PARENTAL_CONTROL·OTHER·LOGOUT), 각 항목을 선택하면 대응하는 SettingBaseView 자식 뷰(즐겨찾기/잠금·렌탈 이력·녹화·리마인더·핀·캠페인·자녀 보호·기타)가 childLayoutList 캐시를 거쳐 표시됩니다. 진입 시 SettingConfig.KEY_LINK_VIEW_TYPE 번들로 특정 메뉴로 바로 점프할 수 있어, MES 알림의 "캠페인 이동" 등 외부 진입과 연동됩니다.

프로필은 ProfileRepository가 담당합니다. 캐싱된 로그인 프로필(getCurrentProfile)과 프로필 목록(getCachedProfileList)을 제공하고, 프로필 로그인(login)·추가/수정/삭제·언어 설정(setLanguageData)을 수행하며, 부팅 시 서버에서 프로필 데이터를 강제 갱신(refreshProfileData(fromBoot=true))합니다. SettingScreen은 SettingViewModel의 프로필 LiveData를 관찰해 현재 사용자 정보를 표시합니다.

시스템 운영 UI는 LayerManager의 팝업 표출 API로 통합됩니다. showOtaUpdatePopup()은 OTA 업데이트 안내를 띄우고 10초 후 자동 진행하며(OtaUpdatePopup), 펌웨어/앱 다운로드는 AppUpdateMonitorRepository가 처리합니다. showGlobalErrorPopup()은 GlobalErrorNotifier가 통지한 에러 코드를 받아 전역 에러 팝업(GlobalErrorPopup, preventExit로 종료 차단 가능)을 표출하고, 인증/암호화 실패 등으로 정상 부팅이 불가하면 FailSafeRecoveryPopup으로 복구를 안내합니다.

FailSafe 복구와의 관계
FailSafe는 부팅 인증 실패 시에도 최소 기능으로 앱을 띄우는 폴백 모드입니다(로그인·프로비저닝 참고). FailSafe 진입 시 FailSafeInitializer가 설정 메뉴를 우선 노출(HomeConfig.IconMenuItem.SETTING)하고 전역 키를 차단(setGlobalKeyBlocked)하므로, 설정 화면은 장애 상황에서 사용자가 재시도·복구·로그아웃에 접근하는 통로가 됩니다.

timerDisposable = Observable.timer(10, TimeUnit.SECONDS)
    .subscribe({
        layerManager.deactivateLayer(this)
        onButtonClick?.invoke()          // 업데이트 진행
    }, {})

override fun onKeyDown(keyCode: Int, event: AltiKeyEvent): Boolean {
    when (keyCode) {
        ATVKeyCode.KEY_OK   -> { timerDisposable?.dispose(); layerManager.deactivateLayer(this); onButtonClick?.invoke() }
        ATVKeyCode.KEY_EXIT,
        ATVKeyCode.KEY_PREV -> { timerDisposable?.dispose(); layerManager.deactivateLayer(this) }
    }
    return true
}
