PIP · 모자이크

PipView는 별도 PipChannelAdapter로 보조 채널을 음소거 재생해 라이브 위에 오버레이하고, MosaicView는 모자이크 채널의 2×3 격자(MosaicItem)를 그려 여러 채널을 한 화면에서 탐색하게 합니다.

기능 개요

PIP와 모자이크는 모두 MainActivity가 소유하는 오버레이 뷰(getPipView()/getMosaicView())로, 메인 채널 재생 위에 떠서 동작하며 LiveTvScreen이 이를 가져와 제어합니다. PipView는 메인 재생과 충돌하지 않도록 전용 SI 어댑터(@PipChannelAdapter로 주입된 ChannelPlayerAdapter)를 사용합니다. 플레이바의 onSelectPip에서 show(channelId)가 호출되면 PIP 가용성(isChannelPipAvailable)을 확인하고, 볼륨을 0으로 낮춘 뒤(setVolume(0f)) 해당 채널을 튜닝합니다. 메인 오디오는 그대로 두고 보조 영상만 보여주는 구조입니다. 튜닝 실패 시 hide()로 정리하고 리스너에 오류를 통보합니다.

MosaicView는 모자이크 채널(여러 채널을 한 스트림에 합성한 특수 채널)을 위한 화면입니다. onAttachedToWindow에서 채널 어댑터의 현재 튜닝 채널 스트림을 스스로 구독하다가, 채널에 mosaicData가 있고 재생 중이면 setMosaicData와 show()를 직접 수행합니다. 서버가 내려준 TTChannelMosaicData.itemList의 각 항목 좌표(left/top)를 행·열로 환산해 2행 3열 GridLayout에 MosaicItem을 배치하고, 각 셀을 실제 채널 ID에 매핑합니다. 리모컨 입력(processKeyDown)으로 셀 간 포커스를 이동하고, 선택한 셀의 오디오 트랙을 활성화/비활성화(updateAudioTrack/disableAudioTrack)하며, OK 시 해당 채널로 튜닝합니다.

설계 포인트
PIP는 메인 플레이어를 침범하지 않도록 독립된 PipChannelAdapter 인스턴스로 분리되어 있고, 모자이크는 단일 모자이크 스트림 안에서 셀 좌표를 채널 ID로 역매핑해 "여러 채널을 보는 것처럼" 보이게 합니다. 둘 다 라이브 상태 머신(LiveTvUiState.Mosaic 등)과 연동해 표시/숨김을 관리합니다.

핵심 코드

ui/livetv/pip/PipView.kt — 가용성 확인 후 음소거 튜닝
fun show(channelId: ChannelId) {
    if (!isChannelPipAvailable(channelId = channelId)) return

    isVisible = true
    listener?.onVisible()
    isPlaying = false
    pipChannelAdapter.setVolume(0f)                 // 보조 영상만, 오디오는 메인 유지
    pipChannelAdapter.tune(channelId = channelId) { result ->
        when (result) {
            is PlayResult.Success -> if (isVisible) isPlaying = true
            is PlayResult.Fail -> { hide(); listener?.onError() }
        }
    }
}
ui/livetv/mosaic/MosaicView.kt — 서버 좌표를 2×3 격자로 환산
fun setMosaicData(mosaicData: TTChannelMosaicData) {
    clearMosaicData()
    val columnPositions = mosaicData.itemList.map { it.left }.distinct().sorted()
    val rowPositions    = mosaicData.itemList.map { it.top  }.distinct().sorted()

    binding.mosaicArea.apply { rowCount = 2; columnCount = 3 }

    mosaicData.itemList.forEachIndexed { index, data ->
        val row = rowPositions.indexOf(data.top)
        val col = columnPositions.indexOf(data.left)
        val mosaicItem = MosaicItem(context, index, row, col, /* ... */ channelId = data.id)
        // 셀을 격자에 추가하고 channelId 매핑
    }
}
