TV 가이드(편성표)

TvGuideView가 홈의 EPG 격자(EpgView)를 통해 채널별 편성 정보를 날짜·채널·프로그램 단위로 탐색하고, 과거 프로그램은 시청 진입(go to live)으로, 미래 프로그램은 예약/리마인더로 연결합니다.

기능 개요

TV 가이드는 홈 메뉴 하위의 서브 화면으로 진입하며, 좌측 날짜 선택 리스트(DateSelectListView)와 우측 EPG 격자(EpgView = 채널 리스트 + 프로그램 그리드)로 구성됩니다. TvGuideViewModel이 SI ProgramRepository·ChannelRepository와 GetProgramListByDateUseCase를 사용해 선택한 날짜/채널 범위의 편성 데이터를 로드합니다.

탐색은 전적으로 리모컨 포커스 이동으로 동작합니다. EpgView.Listener.requestLoadProgramList()가 이전/다음 채널, 이전/다음 프로그램, 이전/다음 날짜, 페이지 단위 채널 이동(RequestPolicy)을 ViewModel에 요청하고, 포커스 복원 규칙(FocusPolicy)에 따라 새로 로드된 격자에서 포커스를 재배치합니다.

프로그램을 선택(onClickProgram)하면 프로그램 시점에 따라 분기합니다. 현재/과거 방송이고 채널을 구독 중이면 시청 진입(go to live)으로, 미래 방송이면 리마인더 추가(AddReminderUseCase) 흐름으로 연결되며, PPV·미구독·빈 편성은 각각 별도 처리됩니다.

설계 포인트
EPG는 데이터 양이 많아 포커스가 격자의 끝에 닿을 때만 인접 구간을 추가로 로드하는 정책(EpgView.RequestPolicy)을 사용합니다. 화면 표시와 데이터 로딩을 분리해, 리모컨 연속 입력 시에도 격자가 끊기지 않도록 설계되어 있습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 리모컨 (User) participant EPG as EpgView participant TGV as TvGuideView participant VM as TvGuideViewModel participant PR as ProgramRepository (SI) participant CA as ChannelPlayerAdapter U->>EPG: 포커스 이동 (채널/프로그램/날짜) EPG->>TGV: requestLoadProgramList(RequestPolicy, FocusPolicy) TGV->>VM: getProgramListByDate(date, channels) VM->>PR: 편성 데이터 조회 PR-->>VM: List~Program~ VM-->>TGV: 편성 갱신 (currentSelectedProgram) TGV->>EPG: 격자 갱신 + FocusPolicy로 포커스 복원 U->>EPG: OK (프로그램 선택) EPG->>TGV: onClickProgram(channel, program) alt 현재/과거 + 구독 채널 TGV->>CA: tune(channelId) (go to live) else 미래 프로그램 TGV->>VM: AddReminderUseCase (예약/리마인더) end

흐름. 포커스 이동 시 EpgView가 로드 정책과 함께 추가 편성을 요청하고, ViewModel이 SI ProgramRepository로 데이터를 받아 격자를 갱신합니다. 프로그램 선택 시 방송 시점에 따라 시청 진입 또는 리마인더로 분기합니다.

핵심 코드

home/sub/tvguide/TvGuideView.kt — EpgView 로드 정책 라우팅
tvGuideEpg.listener = object : EpgView.Listener {
    override fun requestLoadProgramList(
        requestPolicy: EpgView.RequestPolicy,
        focusPolicy: EpgView.FocusPolicy,
    ) {
        when (requestPolicy) {
            EpgView.RequestPolicy.Current -> { /* 현재 가시 구간 로드 */ }
            EpgView.RequestPolicy.PrevChannel -> { /* 이전 채널 편성 */ }
            EpgView.RequestPolicy.NextChannel -> { /* 다음 채널 편성 */ }
            EpgView.RequestPolicy.PrevDay -> { /* 전날 + 마지막 포커스 복원 */ }
            EpgView.RequestPolicy.NextDay -> { /* 다음날 + 마지막 포커스 복원 */ }
            // ... PrevProgram / NextProgram / Prev,NextPageChannel
        }
    }
}
