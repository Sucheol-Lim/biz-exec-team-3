TV 가이드(편성표)

TvGuideView가 홈의 EPG 격자(EpgView)를 통해 채널별 편성 정보를 날짜·채널·프로그램 단위로 탐색하고, 현재 방송은 라이브 시청 진입으로, 과거·미래 프로그램은 프로그램 상세(리마인더 진입점)로 연결합니다.

기능 개요

TV 가이드는 홈 메뉴 하위의 서브 화면으로 진입하며, 좌측 날짜 선택 리스트(DateSelectListView)와 우측 EPG 격자(EpgView = 채널 리스트 + 프로그램 그리드)로 구성됩니다. TvGuideViewModel이 SI ProgramRepository·ChannelRepository와 GetProgramListByDateUseCase를 사용해, 현재 채널이 포함된 5채널 묶음 × 페이지 시간 범위 단위(getChannelMap)로 편성 데이터를 로드합니다.

탐색은 전적으로 리모컨 포커스 이동으로 동작합니다. EpgView.Listener.requestLoadProgramList()가 이전/다음 채널, 이전/다음 프로그램, 이전/다음 날짜, 페이지 단위 채널 이동(RequestPolicy)을 View에 요청하고, 포커스 복원 규칙(FocusPolicy/FocusFallbackPolicy)에 따라 새로 로드된 격자에서 포커스를 재배치합니다. 날짜/프로그램 이동은 설정 기반 이동 가능 일수(guideMovableMaxDays) 범위 안에서만 허용됩니다.

프로그램을 선택(onClickProgram)하면 프로그램 시점에 따라 분기합니다. 현재 방송 중이면 showLiveTv로 라이브 시청에 진입하고, 과거 방송은 구독 채널이면 프로그램 상세로, 미구독이면 안내 팝업(확인 시 라이브 진입)으로 처리합니다. 미래 방송과 PPV는 프로그램 상세(goToDetail)로 이동하며, 상세 화면의 리마인더 팝업(ReminderAddPopup)이 AddReminderUseCase로 예약을 등록합니다. 빈 편성은 무시됩니다.

설계 포인트
EPG는 데이터 양이 많아 포커스가 격자의 끝에 닿을 때만 인접 구간을 추가로 로드하는 정책(EpgView.RequestPolicy)을 사용합니다. 화면 표시와 데이터 로딩을 분리해, 리모컨 연속 입력 시에도 격자가 끊기지 않도록 설계되어 있습니다. 최근 홈 화면 메모리 최적화로 destroyView()에서 포커스 리스너 해제와 Rx 구독 정리를 명시적으로 수행하도록 보강되었습니다.

흐름. 포커스 이동 시 EpgView가 로드 정책과 함께 추가 편성을 요청하고, ViewModel이 GetProgramListByDateUseCase로 채널별 편성 Map을 받아 격자를 갱신합니다. 프로그램 선택 시 방송 시점·구독 여부에 따라 라이브 진입 또는 프로그램 상세로 분기합니다.

핵심 코드

home/sub/tvguide/TvGuideView.kt — EpgView 로드 정책 라우팅
tvGuideEpg.listener = object : EpgView.Listener {
    override fun requestLoadProgramList(
        requestPolicy: EpgView.RequestPolicy,
        focusPolicy: EpgView.FocusPolicy,
    ) {
        when (requestPolicy) {
            EpgView.RequestPolicy.Current -> setScheduleData(focusPolicy = focusPolicy)
            EpgView.RequestPolicy.NextChannel -> setScheduleData(
                nextChannelId = viewModel.setNextChannelIdInRing(viewModel.currentChannelIdValue),
                focusPolicy = focusPolicy,
            )
            EpgView.RequestPolicy.NextDay -> {
                val (startTime, isWithin15DaysRange) = viewModel.setNextDateTime()
                setScheduleData(
                    nextStartTime = startTime,
                    focusPolicy = EpgView.FocusPolicy(
                        fallbackPolicy = EpgView.FocusFallbackPolicy.LastFocusedProgramOrFirst,
                    ),
                )
            }
            // ... PrevChannel / PrevProgram / NextProgram / PrevDay / Prev,NextPageChannel
        }
    }
}
home/sub/tvguide/TvGuideView.kt — 프로그램 선택 분기 (onClickProgram)
if (program.isEmptyProgram) {
    // 빈 편성 — 무시
} else if (program.funcSwitch.isNotBlank() && program.isPPV && channelIsSubscribed) {
    goToDetail(program = program)          // PPV — 프로그램 상세
} else if (program.isCurrentProgram) {
    homeScreen.viewModel.showLiveTv(       // 현재 방송 — 라이브 진입
        channelNumber = channelNumber,
        entryPageID = DataCollectConfig.PageID.E_PAGE_TVGUIDE,
    )
} else if (program.isPastProgram) {
    if (channelIsSubscribed) goToDetail(program = program)
    else viewModel.showCommonPopup(...)    // 미구독 — 안내 팝업(확인 시 라이브 진입)
} else {
    goToDetail(program = program)          // 미래 — 상세(리마인더 진입점)
}
