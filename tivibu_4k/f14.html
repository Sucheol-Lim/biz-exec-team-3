기능 개요

분기 빌드의 중심은 composite build인 build-logic의 PlatformFlavor enum입니다. 단일 차원(FlavorDimension.platform) 아래에 4개 flavor를 정의하며, 각 항목이 빌드 키와 applicationId를 들고 있습니다. tivibuEv(기본 flavor, tivibu.android.stb)·tivibuGo(tivibu.android.stb.ott)·stvOtt(com.ttnet.tivibutv)·zteAosp(com.zte.aosp)입니다. getFlavor(fullName)은 변형(variant) 이름 문자열에서 flavor를 역추적하는 유틸로, 버전 산출 등 빌드 스크립트가 활용합니다.

configureFlavors() 확장 함수는 모든 모듈이 동일한 flavor 차원·항목을 갖도록 productFlavors를 일괄 등록합니다. 애플리케이션 모듈에서는 flavor별 applicationId·versionName·versionCode를 적용하고(버전은 readVersion(flavor) 콜백으로 auto-version-*.gradle에서 산출), 라이브러리 모듈에서는 VERSION_NAME/VERSION_CODE를 buildConfigField로 노출합니다. 이렇게 모든 모듈의 flavor 차원을 일치시켜야 flavor별 소스셋(app/src/tivibuEv 등)과 flavor 한정 의존성이 충돌 없이 결합됩니다.

플랫폼 종속 구현은 빌드 시점에 flavor별로 주입됩니다. app/build.gradle.kts는 공통으로 player:impl-tt4k·si:impl-tt4k를 runtimeOnly로 넣고, 플랫폼 의존성은 tivibuEvRuntimeOnly/tivibuGoRuntimeOnly는 dependency:platform:tt4k를, stvOttRuntimeOnly는 dependency:platform:smarttv를 연결하는 flavor 한정 configuration을 사용합니다. Smart TV용 staging 빌드는 androidComponents.beforeVariants에서 stvOtt flavor일 때만 활성화하여 다른 flavor에는 staging 변형이 생성되지 않도록 막습니다. 또한 productFlavors 블록에서 flavor별 manifestPlaceholders로 launcherDataProviderAuthority를 주입해, 같은 dependency:platform:tt4k를 공유하는 tivibuEv(tivibu.android.stb.data.provider)와 tivibuGo(tivibu.android.stb.ott.data.provider)가 서로 다른 LauncherDataProvider authority로 설치되도록 하여 EV/GO 런처 동시 설치 시 provider 충돌을 방지합니다. provider 쪽은 attachInfo()에서 실제 배정된 authority를 받아 UriMatcher를 구성합니다.

설계 포인트 — 단일 차원 + flavor 한정 configuration
플랫폼 차이를 코드 분기(if/when)가 아니라 빌드 의존성 주입으로 흡수합니다. 공통 코드는 인터페이스(player·si 추상화)에만 의존하고, 실제 구현은 flavor별 runtimeOnly로 갈아끼우므로 앱 코드는 어떤 단말로 빌드되는지 몰라도 됩니다. missingDimensionStrategy 없이도 모든 모듈이 같은 platform 차원을 공유하도록 configureFlavors()가 강제합니다.

흐름. flavor별 assemble 태스크가 실행되면 configureFlavors()가 flavor를 등록하고 버전 스크립트로 버전을 산출한 뒤, flavor 한정 configuration이 해당 단말의 플랫폼 구현을 주입하고 규칙에 맞는 파일명으로 APK를 출력합니다.

핵심 코드

build-logic/.../com/altimedia/buildlogic/Flavor.kt — flavor 정의(키·applicationId)
enum class PlatformFlavor(val dimension: FlavorDimension, val isDefault: Boolean = false,
                          val key: String, val applicationId: String? = null) {
    tivibuEv(FlavorDimension.platform, true, key = "PLATFORM_TIVIBU_EV", applicationId = "tivibu.android.stb"),
    tivibuGo(FlavorDimension.platform,       key = "PLATFORM_TIVIBU_GO", applicationId = "tivibu.android.stb.ott"),
    stvOtt  (FlavorDimension.platform,       key = "PLATFORM_STV_OTT",   applicationId = "com.ttnet.tivibutv"),
    zteAosp (FlavorDimension.platform,       key = "PLATFORM_ZTE_AOSP",  applicationId = "com.zte.aosp"),
    ;
}
build-logic/.../Flavor.kt — 전 모듈 공통 flavor 등록 + 버전 적용
fun CommonExtension<*, *, *, *, *, *>.configureFlavors(
    isApplication: Boolean = false, saveConfig: Boolean = false,
    readVersion: (PlatformFlavor) -> Pair<String, Int>,
) {
    FlavorDimension.values().forEach { flavorDimensions += it.name }
    productFlavors {
        PlatformFlavor.values().forEach { platformFlavor ->
            register(platformFlavor.name) {
                dimension = platformFlavor.dimension.name
                val (name, code) = readVersion(platformFlavor)
                if (this is ApplicationProductFlavor && isApplication && platformFlavor.applicationId != null) {
                    applicationId = platformFlavor.applicationId
                    versionName = name; versionCode = code
                }
            }
        }
    }
}

// Smart TV 전용 staging variant만 활성화
androidComponents {
    beforeVariants { variantBuilder ->
        val flavorName = variantBuilder.productFlavors.firstOrNull()?.second
        if (variantBuilder.buildType?.contains("staging") == true) {
            variantBuilder.enable = (flavorName == PlatformFlavor.stvOtt.name)
        }
    }
}
app/build.gradle.kts + dependency/platform/tt4k — flavor별 provider authority 분기
// app/build.gradle.kts — flavor별 manifestPlaceholders 주입
productFlavors {
    // LauncherDataProvider authority 는 flavor 별로 다르게 지정 (dependency:platform:tt4k manifest 참고)
    getByName(PlatformFlavor.tivibuEv.name) {
        manifestPlaceholders["launcherDataProviderAuthority"] = "tivibu.android.stb.data.provider"
    }
    getByName(PlatformFlavor.tivibuGo.name) {
        manifestPlaceholders["launcherDataProviderAuthority"] = "tivibu.android.stb.ott.data.provider"
    }
}

// dependency/platform/tt4k/src/main/AndroidManifest.xml — placeholder 치환
<provider
    android:name="com.altimedia.app.core.service.LauncherDataProvider"
    android:authorities="${launcherDataProviderAuthority}" ... />

// LauncherDataProvider.kt — 배정된 authority로 UriMatcher 구성
override fun attachInfo(context: android.content.Context?, info: android.content.pm.ProviderInfo?) {
    super.attachInfo(context, info)
    info?.authority?.let { authority ->
        // EV런처: tivibu.android.stb.data.provider, GO런처: tivibu.android.stb.ott.data.provider
        uriMatcher.addURI(authority, API_USER, USERS)
    }
}
