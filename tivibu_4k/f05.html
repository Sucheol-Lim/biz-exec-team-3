구매·결제

PurchaseCoordinator(구현 DefaultPurchaseCoordinator)가 상품·쿠폰·OTT·프로모션 구매를 조율하고, PIN 인증(PasswordPopup)·결제 API·완료 로딩 팝업(LoadingPopup)을 거치며 중복 요청을 disposable로 차단합니다.

기능 개요

구매 흐름은 PurchaseCoordinator 인터페이스로 추상화되어 있고, 공통 구현은 DefaultPurchaseCoordinator(추상 클래스)에 있으며 단말 종류에 따라 TTPurchaseCoordinator(IPTV)·StvPurchaseCoordinator(Smart TV)가 이를 확장합니다. startPurchaseProcess()는 입력(VOD/상품/번들/캠페인/쿠폰)에 따라 적절한 팝업(PurchasePopup / PurchaseCampaignPopup / 번들 선택)을 띄웁니다.

PIN 인증 여부는 needPin()이 프로필의 funcSwitch 비트(오른쪽에서 3번째 비트, 1 shl 2)를 검사해 결정합니다. PIN이 필요하면 PasswordPopup이 열리고, Smart TV/IPTV 양쪽에서 직접 키코드 입력(KEY_0~숫자 키)으로 PIN을 입력할 수 있도록 처리되어 있습니다(appendPinDigit / deletePinDigitLast).

PIN 통과 후 processPurchaseAfterPinVerification() → connectMPayApi()가 결제 API(getMPay / getPayResult)를 호출합니다. 진행 중에는 로딩 팝업을 띄우고, 모든 결제 요청은 mPayDisposable·payResultDisposable·passwordDisposable로 관리되어 동일 요청이 중복 발사되지 않도록 dispose로 차단합니다. 최근 스프린트에서는 OTT/SmartTV 구매 완료 로딩 팝업 갱신과 프로모션 데이터 잔존 문제, PIN 직접 입력 지원이 반영되었습니다.

설계 포인트
구매 시작 시점에 saveCurrentPurchaseInfo()로 현재 구매 컨텍스트(VOD/상품/캠페인/쿠폰/콜백)를 저장하고, 결제 API 진행 동안 disposable을 단일 보유합니다. 같은 disposable을 다시 호출하기 전 dispose()하므로 리모컨 연타로 인한 중복 결제 요청을 구조적으로 막습니다.

핵심 코드

dependency/feature/.../DefaultPurchaseCoordinator.kt — funcSwitch 비트로 PIN 필요 여부 판정
override fun needPin(): Boolean {
    try {
        val profileValue = profileRepository.getCachedLoginProfile().blockingFirst()
        val profileInfo = profileValue.value ?: return true

        val funcSwitch = profileInfo.funcSwitch?.toIntOrNull() ?: 0
        // 2번 비트가 0이면 true, 1이면 false를 리턴
        return (funcSwitch and (1 shl 2)) == 0
    } catch (e: Exception) {
        return true   // 오류 시 보안상 PIN 요구
    }
}
dependency/feature/.../DefaultPurchaseCoordinator.kt — 결제 API disposable 정리(중복 요청 차단)
override fun disposeGetMPay()     { mPayDisposable?.dispose() }
override fun disposeGetPayResult(){ payResultDisposable?.dispose() }
override fun disposeCheckPassword(){ passwordDisposable?.dispose() }
override fun disposeAll() {
    disposeGetMPay()
    disposeGetPayResult()
    disposeCheckPassword()
}
