채널 필터·즐겨찾기·잠금

채널 링(장르) 필터를 적용하면 필터 아이콘에 red dot이 표시되고, 설정 화면(FavoriteLockChannelView)에서 즐겨찾기(favorite)와 채널 잠금(block)을 SI ChannelRepository를 통해 관리합니다.

기능 개요

채널 필터는 채널 링(ChannelRing = 장르 그룹) 기반입니다. 라이브 화면에서 필터 팝업(ChannelFilterPopup)을 열면 ChannelFilterPopupViewModel이 채널 링 목록(TTChannelRing.Genre를 sortNum 순으로 정렬)을 제공하고, 선택한 링을 updateCurrentChannelRingId()로 현재 필터에 반영합니다. 전체(All) 링이 아닌 특정 링이 적용되어 있으면 필터 아이콘에 red dot을 노출하며, 최근 스프린트에서 이 red dot이 필터 리스트 열림/닫힘 상태와 무관하게 표시되도록 보정되었습니다.

즐겨찾기·잠금은 설정 화면의 FavoriteLockChannelView/FavoriteLockChannelViewModel에서 관리합니다. 진입 시 channelRepository.updateFavoriteChannelList()로 즐겨찾기 목록을 최신화하고, 전체 채널을 표시한 뒤 항목별로 즐겨찾기(setFavoriteChannel → addFavorite/removeFavorite)와 잠금(setBlockChannel → addBlock/removeBlock)을 토글합니다. 채널의 isFavorite/isBlocked 플래그가 현재 상태를 나타내며, 추가/제거는 SI 채널 레이어에 반영됩니다.

설계 포인트
필터·즐겨찾기·잠금은 모두 SI 모듈의 ChannelRepository 한 곳을 통해 채널 메타데이터를 갱신합니다. 필터는 "현재 적용된 채널 링"이라는 단일 상태로 표현되고, red dot 노출은 "All 링이 아닌가?"라는 단순 조건으로 파생되어 UI와 데이터의 결합을 최소화했습니다.

fun setBlockChannel(channel: Channel) {
    if (!channel.isBlocked) {
        channelRepository.addBlock(channel)
            .subscribe({ /* addBlock result */ }, { /* error */ })
    } else {
        channelRepository.removeBlock(channel)
            .subscribe({ /* removeBlock result */ }, { /* error */ })
    }
}

fun setFavoriteChannel(channel: Channel, callback: (Channel) -> Unit) {

ui/livetv/popup/channelfilter/ChannelFilterPopupViewModel.kt — 현재 채널 링 필터 갱신 / All 판정
fun updateCurrentChannelRingId(channelRingId: String?) {
    if (channelRingId != null) {
        _currentChannelRingId.onNext(channelRingId.asNullable())
    } else {
        _currentChannelRingId.onNext(
            (channelAdapter.getCurrentChannelRing()
                ?.getCurrentFilteredChannelRing() as? TTChannelRing)?.id.asNullable())
    }
}

fun isAllChannelRing(channelRing: ChannelRing?): Boolean {
    return channelRing == channelRepository.getAllChannelRing(contextProvider.getContext())
}
