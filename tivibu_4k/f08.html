기능 개요

핑거프린트는 불법 재배포 추적을 위해 화면 위에 단말/사용자 식별 문자열을 잠깐씩 띄우는 콘텐츠 보호 기법입니다. 본 앱에는 두 종류의 핑거프린트 뷰가 라이브 화면 위에 올라갑니다. 일반 핑거프린트(FingerPrintView)와 VMX CAS가 직접 지시하는 핑거프린트(VmxFingerPrintView)입니다.

두 뷰 모두 화면에 붙으면(onAttachedToWindow) 전역 이벤트 버스 GlobalErrorNotifier를 구독합니다. FingerPrintView는 observeFingerPrint()의 FingerPrintDescription.Show/Hide를 받아 startTimer()/stopTimer()로 전환합니다. startTimer()는 RxJava Observable.interval()로 showTime + interval 주기를 만들어, 각 주기마다 FingerPrintRepository.getFingerPrintText()로 받은 문자열을 showTime 동안만 노출하고 다시 숨깁니다. 표시 위치·색·폰트·크기는 FingerPrint 설정값을 따르되 오류 시 FingerPrint.Default로 폴백합니다.

VmxFingerPrintView는 추가로 채널 전환(getCurrentTuningChannelIdObservable)과 재생 상태(state) 변화를 함께 구독해, 채널이 바뀌거나 재생이 멈추면 즉시 hide()합니다. VMX 측 VmxFingerPrintDescription.Show는 메시지·노출 시간·표시 위치(VmxFingerPrintPosition: Center/North/East 등 9방위)를 담아 오버레이를 띄웁니다.

설계 포인트
두 뷰는 비즈니스 로직 없이 GlobalErrorNotifier가 흘려보내는 Show/Hide 명령만 따릅니다. 표시 정책(주기·텍스트)은 FingerPrintRepository가, VMX 지시는 CAS 연동 경로가 결정하므로 뷰는 표시 책임만 가지는 얇은 레이어로 유지됩니다.

관계. 두 뷰가 GlobalErrorNotifier를 구독해 Show/Hide 명령을 받습니다. 일반 핑거프린트는 FingerPrintRepository에서 텍스트·표시 설정을 가져오고, VMX는 위치 enum과 함께 메시지를 표시합니다.

핵심 코드

livetv/fingerprint/FingerPrintView.kt — Show/Hide 구독 후 주기 타이머
override fun onAttachedToWindow() {
    super.onAttachedToWindow()
    GlobalErrorNotifier.observeFingerPrint()
        .observeOn(AndroidSchedulers.mainThread())
        .subscribe { fingerPrint ->
            when (fingerPrint) {
                FingerPrintDescription.Show -> startTimer()
                FingerPrintDescription.Hide -> stopTimer()
            }
        }
        .addTo(disposables)
}

fun startTimer() {
    val fingerPrint = fingerPrintRepository.getFingerPrint()
    showHideDisposable = Observable
        .interval(0, fingerPrint.showTime + fingerPrint.interval, TimeUnit.MILLISECONDS)
        .flatMap { Observable.concatArray(
            Observable.just(true),                                    // 보이기
            Observable.just(false).delay(fingerPrint.showTime, MILLIS)) } // showTime 뒤 숨기기
        .concatMapSingle { isShow -> if (isShow) fingerPrintRepository.getFingerPrintText().map { true to it } else Single.just(false to "") }
        .subscribe { (isShow, text) -> if (isShow) showFingerPrint(text, fingerPrint) else hideFingerPrint() }
}
