재생 품질 모니터링(Conviva)

ConvivaAnalyticsService가 Conviva SDK로 재생 세션 품질(VSI)과 앱 사용성(DPI)을 측정하고, UserFrameConfig.convivaStatus가 켜진 경우에만 콘텐츠 메타데이터·비트레이트·오류를 Conviva 게이트웨이로 전송합니다.

기능 개요

Conviva 연동은 ConvivaAnalyticsRepository 인터페이스를 ConvivaAnalyticsService(@Singleton)가 구현하는 형태입니다. 부팅 초기화 단계에서 initialize()가 호출되며, 이때 두 가지 트래커를 세웁니다. DPI(앱 분석, ConvivaAppAnalytics.createTracker)와 VSI(영상 품질, ConvivaAnalytics.init)이며, 디바이스 정보(setDeviceInfo)에는 모델·OS·브랜드와 함께 단말 타입(Smart TV OTT면 SMARTTV, 그 외 SETTOP)을 담습니다.

모든 진입점은 isConvivaEnable 가드를 먼저 통과합니다. 이 값은 UserRepository의 UserFrameConfig.convivaStatus가 VALUE_YES일 때만 참이며, 서버 설정이 바뀌면 notifyUserFrameConfigUpdated() 스트림을 통해 BehaviorSubject로 반영됩니다. 따라서 Conviva 비활성 단말에서는 모든 보고 메서드가 즉시 반환하여 오버헤드와 불필요한 로그 전송을 막습니다.

영상 세션은 재생 키(key)별로 ConvivaVideoAnalytics를 캐시(videoAnalyticsMap)합니다. videoPlay()에서 플레이어를 연결하고 콘텐츠 메타맵(toContentInfoMap)으로 재생 요청을 보고하며, 재생 중 updateVideoBitRate/updateVideoFrameRate로 비트레이트·프레임레이트를, 오류 시 videoError로 ErrorSeverity.FATAL을 보고합니다. videoStop은 세션 종료를, videoRelease는 분석 객체 해제를 담당하고, 앱 포그라운드/백그라운드 전환은 reportAppForegrounded/Backgrounded로 전달합니다.

게이트웨이·커스터머 키 운영 정비
최근 스프린트에서 Conviva 게이트웨이 URL이 testonly 분기를 제거하고 운영 게이트웨이($convivaCustomerKey.csw.conviva.com)로 단일화되었으며, 커스터머 키는 서버 설정값(UserFrameConfig.vqmKey)을 우선 사용하고 없으면 운영 기본키로 폴백하도록 변경되었습니다. 코드 주석에 일자별(2026-05-20·05-26) 변경 사유가 명시되어 있습니다.

핵심 코드

app/core/service/ConvivaAnalyticsService.kt — 설정 게이트 + DPI/VSI 초기화
private val isConvivaEnable: Boolean
    get() = userFrameConfig.value?.value?.convivaStatus == DomainConfig.VALUE_YES

override fun initialize() {
    if (!isConvivaEnable) { Timber.d("initialize() conviva disabled."); return }
    initializeDPI(appName, id)      // ConvivaAppAnalytics.createTracker
    initializeVSI(id)               // ConvivaAnalytics.init + setDeviceInfo
}
app/core/service/ConvivaAnalyticsService.kt — 운영 게이트웨이·커스터머 키 단일화
private val convivaCustomerKey: String
    get() = userFrameConfig.value?.value?.vqmKey ?: DomainConfig.CONVIVA_CUSTOMER_KEY_PROD

private val convivaGatewayUrl: String
    get() {
        // testonly 미사용으로 변경 (Berkay 요청, 2026-05-26)
        return "https://$convivaCustomerKey.csw.conviva.com"
    }
app/core/service/ConvivaAnalyticsService.kt — 세션별 재생 보고
override fun videoPlay(key: String, player: Any, vodPlayParams: VodPlayParams) {
    if (!isConvivaEnable) return
    val videoAnalytics = getVideoAnalytics(key)          // key별 캐시
    videoAnalytics.setPlayer(player)
    videoAnalytics.reportPlaybackRequested(vodPlayParams.toContentInfoMap())
    vodPlayParams.logParam?.playUrl?.getOrigin()?.also {
        videoAnalytics.reportPlaybackMetric(ConvivaSdkConstants.PLAYBACK.CDN_IP, it)
    }
}

override fun videoError(key: String, errorMessage: String) {
    if (!isConvivaEnable) return
    getVideoAnalytics(key).reportPlaybackError(errorMessage, ConvivaSdkConstants.ErrorSeverity.FATAL)
}
