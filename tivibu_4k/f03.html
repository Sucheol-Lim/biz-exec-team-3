VOD 재생

PlayOrchestrator가 콘텐츠 종류(VodType)별 PlayHandler로 재생을 위임하고 Media3/ExoPlayer 기반 VodPlayerAdapter로 스트림을 재생하며, VodPlayBarScreen이 플레이바·해상도/자막/배속 선택·썸네일 미리보기·스타트오버 UI를 제공합니다.

기능 개요

VOD 재생은 PlayCoordinator(재생 요청 + 네비게이션 제어)로 시작됩니다. 화면(VOD 상세 등)이 playSingleVod()·playSeriesVod() 등을 호출하면, 대응하는 PlaySingleVodUseCase 계열 UseCase가 재생 파라미터(PlayInfo)를 만들고 이를 PlayOrchestrator로 넘깁니다.

PlayOrchestrator는 VodType(SINGLE / SERIES / PREVIEW / TRAILER / TS_TV / RECORD / PPV / PL_TV)을 키로 하는 핸들러 딕셔너리(playHandlerDict)를 보유합니다. PlayInfo.type에 맞는 BasePlayHandler를 찾아 startPlay()를 위임하고, 핸들러는 Media3/ExoPlayer 기반 VodPlayerAdapter로 실제 스트림을 재생한 뒤 observePlayStates()로 위치·상태를 관찰합니다(북마크 저장, 추천/다음 화 팝업 트리거 등).

재생 UI는 VodPlayBarScreen(ATVScreen)이 담당합니다. 플레이바 리스너가 일시정지/시킹, 해상도(VideoTrackUiInfo), 자막/오디오 트랙(TrackUiInfo), 배속(SpeedUiInfo), 썸네일 미리보기(ThumbnailList) 선택을 받아 VodPlayerAdapter에 반영합니다.

설계 포인트
재생 로직을 한 핸들러에 몰지 않고 VodType별로 분리한 뒤 PlayOrchestrator가 딕셔너리로 라우팅합니다. 핸들러는 DI 대신 함수 참조(::playJust, ::emitUiUpdateEvent 등)를 주입받아 직접 생성되며, 재생 화면(VodPlayBarScreen)의 표시 여부와 무관하게 리소스를 관리합니다(BasePlayHandler 주석).

흐름. 화면이 PlayCoordinator로 재생을 요청하면 UseCase가 PlayInfo를 만들고 PlayOrchestrator가 타입별 핸들러로 위임합니다. 핸들러가 VodPlayerAdapter로 재생하고 상태를 관찰하며, VodPlayBarScreen이 트랙/배속/썸네일 조작을 어댑터에 전달합니다.

관계. PlayOrchestrator가 PlayCoordinator를 구현하고 VodType별 BasePlayHandler 구현체를 딕셔너리로 보유합니다. 모든 핸들러는 Media3 기반 VodPlayerAdapter로 재생하며, 플레이바 화면은 같은 어댑터에 사용자 조작을 반영합니다.

핵심 코드

ui/play/PlayOrchestrator.kt — VodType별 핸들러 딕셔너리 라우팅
private val playHandlerDict by lazy {
    mapOf(
        VodType.SINGLE to SingleVodPlayHandler(::playJust, ::emitUiUpdateEvent, vodAdapter, ...),
        VodType.SERIES to SeriesVodPlayHandler(::playJust, ::setCurrentContent, ...),
        VodType.PREVIEW to PreviewPlayHandler(::playJust, vodAdapter, channelAdapter, navigator),
        VodType.TS_TV  to TsTvPlayHandler(::playJust, ::emitUiUpdateEvent, ...),
        // RECORD/PPV 공용 핸들러. NPVR 시청 완료 보고(addComplete)를 위해 vodRepository 주입
        VodType.RECORD to NPVRPlayHandler(::playJust, ::emitUiUpdateEvent, ..., vodRepository, ...),
        VodType.PL_TV  to PlTvPlayHandler(::setCurrentContent, startOverAdapter, ...),
    )
}

override fun setCurrentContent(playInfo: PlayInfo) {
    // ...
    playHandlerDict[playInfo.type]?.observePlayStates(playInfo)
}
ui/play/handler/SingleVodPlayHandler.kt — startPlay → requestPlay → 상태 관찰
override fun startPlay(playInfo: PlayInfo, stopCurrent: Boolean, onSuccessPlay: () -> Unit) {
    if (playInfo !is PlayInfo.Single) return

    requestPlay(playInfo, VodLogParam(/* contentCode, definition, playUrl, ... */),
        stopCurrent,
        { error -> terminate() }
    ) { result ->
        if (result is PlayResult.Fail) { terminate(); return@requestPlay }
        observePlayStates(playInfo)   // 위치/상태 관찰: 북마크·추천 팝업
        onSuccessPlay()
    }
}
