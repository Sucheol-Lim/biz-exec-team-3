라이브 TV 시청

기능 개요

라이브 TV 시청은 단말이 부팅·홈 진입을 끝낸 뒤 가장 빈번하게 사용하는 핵심 화면입니다. LiveTvScreen은 단일 액티비티(MainActivity) 위에 show/hide 방식으로 올라가는 Fragment(ATVScreen)이며, 화면 레이아웃 안에 미니 가이드(MiniGuideView), 채널 OSD(ChannelOsdView), 채널 플레이바(ChannelPlayBar)를 직접 보유합니다. PIP(PipView)와 모자이크(MosaicView)는 MainActivity가 소유하며, 화면에서 getPipView()/getMosaicView()로 참조해 위치·키 처리를 조정합니다.

초기 튜닝은 화면 진입(onCreate()) 시 LiveTvViewModel.startChannel()이 수행합니다. 채널 데이터 상태(DataState)가 Updated가 될 때까지 대기한 뒤 대상 채널(진입 채널 번호 → 현재 채널 → 채널 링 → 첫 채널 순)을 해석해 SI 채널 어댑터(ChannelPlayerAdapter.tune())로 튜닝을 지시합니다. 이후 채널 전환은 리모컨 키 입력에서 시작합니다. onKeyDown()이 processChannelKey() / processHotKey()로 분기해, 채널 업/다운은 HotKeyCoordinator 위임 메서드(pressChannelUpKey()/pressChannelDownKey())를 통해 어댑터의 channelUp()/channelDown()을 호출하고, 숫자 키는 pressNumberKey()가 DCA(직접 채널 입력) 팝업을 띄웁니다. 튜닝 결과는 currentTuningChannel 스트림으로 관찰되어 채널 종류(일반/모자이크)에 따라 LiveTvUiState를 갱신해 미니 가이드 또는 모자이크 화면을 노출합니다.

설계 포인트
LiveTvViewModel은 RecordCoordinator·HotKeyCoordinator를 위임(by) 받아 녹화·핫키 기능을 합성하고, PlayCoordinator는 주입받아 재생 제어에 사용합니다. 화면 상태는 LiveTvUiState(MiniGuide / Mosaic / PlayBar / CleanAV / FailSafeMode 등)로 단일화해, 키 입력과 비동기 튜닝 결과가 동일한 상태 머신을 통해 화면에 반영되도록 했습니다. 최근 스프린트에서는 채널 리스트 팝업 복귀 시 미니 가이드 채널 초기화(setMiniGuideChannelId()), 팝업·플레이어 정리(cleanup)와 플레이어 리사이즈 방어 로직, 미니 가이드·채널 리스트 GUI 개편이 반영되었습니다.

흐름. 화면 진입 시 startChannel()이 채널 데이터 준비를 기다렸다가 대상 채널을 해석해 SI 어댑터로 튜닝합니다. 이후 리모컨 키는 onKeyDown() → processChannelKey()에서 분류되어 채널 업/다운은 HotKeyCoordinator 위임을 거쳐 어댑터의 channelUp()/channelDown()으로, 숫자 키는 DCA 팝업으로 이어집니다. 튜닝 결과는 currentTuningChannel 스트림으로 관찰되어 LiveTvUiState를 모자이크/미니가이드로 전환하고 화면이 이를 관찰해 오버레이를 그립니다.

관계. LiveTvScreen이 미니 가이드·OSD·플레이바 뷰를 소유하고 LiveTvViewModel을 구독하며, PIP·모자이크 뷰는 MainActivity를 통해 참조합니다. ViewModel은 HotKeyCoordinator를 by 위임으로 구현해 채널 업/다운·숫자 키를 처리하고, SI ChannelPlayerAdapter와 ChannelRepository를 통해 튜닝·채널 조회를 수행하며 결과를 LiveTvUiState로 단일화합니다.

핵심 코드

ui/livetv/LiveTvViewModel.kt — startChannel(): 채널 해석 → 튜닝 → 상태 전환
val channelId = startChannelNumber?.run { channelRepository.getChannelList().find { it.number == this }?.id }
    ?: channelAdapter.getCurrentChannelId()
    ?: channelAdapter.getCurrentChannelRingChannelList().firstOrNull()?.id
    ?: channelList.firstOrNull()?.id

channelId?.apply {
    channelAdapter.tune(channelId = this@apply) {        // SI 어댑터로 실제 튜닝
        Timber.d("startChannel() tune result: $it")
    }

    val channel = channelRepository.getChannel(id = channelId)
    if (showPlayBarFirst) {
        setUiState(LiveTvUiState.PlayBar(showAnimation = false), forced = true)
    } else if (hideMiniGuideFirst) {
        // do nothing                                     // 미니가이드 숨김 진입
    } else if (channel?.isMosaic == true) {
        setUiState(LiveTvUiState.Mosaic, forced = true)   // 모자이크 채널
    } else {
        setUiState(LiveTvUiState.MiniGuide, forced = true) // 일반 채널
    }
}
