라이브 TV 시청

LiveTvScreen과 LiveTvViewModel이 리모컨 키 입력으로 채널을 튜닝하고, SI 채널 어댑터(ChannelPlayerAdapter)로 실시간 방송을 재생하며, OSD·미니 가이드·채널 리스트·5채널 보기 등 라이브 화면 요소를 호스팅합니다.

기능 개요

라이브 TV 시청은 단말이 부팅·홈 진입을 끝낸 뒤 가장 빈번하게 사용하는 핵심 화면입니다. LiveTvScreen은 단일 액티비티(MainActivity) 위에 show/hide 방식으로 올라가는 Fragment(ATVScreen)이며, 화면 안에 미니 가이드(MiniGuideView), 채널 OSD(ChannelOsdView), 채널 플레이바(ChannelPlayBar), PIP(PipView), 모자이크(MosaicView) 등 라이브 시청 요소를 직접 보유합니다.

채널 전환은 리모컨 키 입력에서 시작합니다. onKeyDown()이 숫자 키·채널 업/다운·핫키를 받아 processChannelKey() / processHotKey()로 분기하고, LiveTvViewModel.startChannel()이 대상 채널 번호를 해석해 SI 채널 어댑터(ChannelPlayerAdapter.tune())로 실제 튜닝을 지시합니다. 튜닝이 끝나면 채널의 종류(일반/모자이크/MyTV)에 따라 LiveTvUiState를 갱신해 미니 가이드 또는 모자이크 화면을 노출합니다.

설계 포인트
LiveTvViewModel은 PlayCoordinator·RecordCoordinator·HotKeyCoordinator를 위임(by) 받아 재생·녹화·핫키 기능을 합성합니다. 화면 상태는 LiveTvUiState(MiniGuide / Mosaic / PlayBar / FailSafeMode 등)로 단일화해, 키 입력과 비동기 튜닝 결과가 동일한 상태 머신을 통해 화면에 반영되도록 했습니다.

sequenceDiagram autonumber participant U as 리모컨 (User) participant SCR as LiveTvScreen participant VM as LiveTvViewModel participant CR as ChannelRepository participant CA as ChannelPlayerAdapter (SI) participant UI as LiveTvUiState U->>SCR: onKeyDown(숫자/CH+/-) SCR->>SCR: processChannelKey(keyCode) SCR->>VM: startChannel() VM->>CR: getChannelList() / getChannel(id) CR-->>VM: 채널/현재 채널 ID VM->>CA: tune(channelId) { result } CA-->>VM: tune result alt channel.isMosaic VM->>UI: setUiState(Mosaic) else 일반 채널 VM->>UI: setUiState(MiniGuide) end UI-->>SCR: uiState 갱신 관찰 SCR->>SCR: 미니가이드/OSD/플레이바 표시

흐름. 리모컨 키가 LiveTvScreen.onKeyDown()으로 들어오면 채널 키를 분류해 startChannel()을 호출하고, ViewModel이 채널을 해석해 SI 어댑터로 튜닝합니다. 결과에 따라 LiveTvUiState를 모자이크/미니가이드로 전환하고 화면이 이를 관찰해 오버레이를 그립니다.

관계. LiveTvScreen이 라이브 오버레이 뷰들을 소유하고 LiveTvViewModel을 구독합니다. ViewModel은 SI ChannelPlayerAdapter와 ChannelRepository를 통해 튜닝·채널 조회를 수행하며 결과를 LiveTvUiState로 단일화합니다.

핵심 코드

ui/livetv/LiveTvViewModel.kt — startChannel(): 채널 해석 → 튜닝 → 상태 전환
val channelId = startChannelNumber?.run {
        channelRepository.getChannelList().find { it.number == this }?.id
    }
    ?: channelAdapter.getCurrentChannelId()
    ?: channelAdapter.getCurrentChannelRingChannelList().firstOrNull()?.id
    ?: channelList.firstOrNull()?.id

channelId?.apply {
    channelAdapter.tune(channelId = this@apply) {        // SI 어댑터로 실제 튜닝
        Timber.d("startChannel() tune result: $it")
    }
    val channel = channelRepository.getChannel(id = channelId)
    if (showPlayBarFirst) {
        setUiState(LiveTvUiState.PlayBar(showAnimation = false), forced = true)
    } else if (channel?.isMosaic == true) {
        setUiState(LiveTvUiState.Mosaic, forced = true)   // 모자이크 채널
    } else {
        setUiState(LiveTvUiState.MiniGuide, forced = true) // 일반 채널
    }
}
