녹화(Recording)

RecordingController가 nPVR(네트워크 PVR) 기반으로 프로그램·시리즈 녹화 예약을 처리하고, 녹화 가능 여부·잔여 용량·상태를 QueryManager로 조회·관리합니다.

기능 개요

녹화는 네트워크 기반 PVR(nPVR)로, 실제 저장은 서버 측에서 이루어지고 STB은 예약·상태 조회·삭제 요청을 보냅니다. RecordingController는 프로그램 단위 녹화(recordProgram)와 시리즈 단위 녹화(addNPvrSeries)를 모두 처리하며, 녹화 상태는 예약(REC_SCHEDULED=0)·녹화됨(REC_RECORDED=1)·진행중(REC_ONGOING=999)·미등록(REC_NOT_ADDED=-2) 등의 코드로 구분합니다.

녹화 요청 전에는 여러 조건을 점검합니다. 프로그램·채널이 녹화 가능한지(isRecordable()), 녹화 가능 시간 용량이 남았는지(getNPvrTime의 총/사용 용량), 채널·시리즈별 동시 녹화 한도를 초과하지 않는지(isExceedLimit)를 확인합니다. 통과하면 QueryManager.addNPvr()/addNPvrSeries()로 서버에 예약을 등록하고, 실패 시 RecordingUtil.showRecordingError()로 안내합니다. 상태 조회는 checkNPvrStatus()로 prevuecode·시간 구간·시리즈ID 기준으로 수행합니다.

설계 포인트
녹화 동작은 모두 비동기 콜백으로 결과 코드(REC_SUCCESS/REC_FAIL_*)를 돌려주며, 데이터 수집(_logRecording)으로 요청 시각·결과를 기록합니다. 최근 스프린트(Jira VLTRANLAND-1310)에서 녹화 목록의 "Recorded" 텍스트를 에피소드 표기로 개선했습니다.

관계. RecordingController가 정책 점검과 결과 코드를 관리하고, 실제 예약·조회는 QueryManager의 nPVR API로, 에러 표시는 RecordingUtil로 위임합니다.

핵심 코드

controller/RecordingController.js — 프로그램 녹화 예약
recordProgram: function(programDetail, callback) {
    var prevuecode = programDetail.prevuecode;
    var channelcode = programDetail.channelcode;
    var channel = SYSAPP.ChannelController.getChannelByChannelCode(channelcode);

    if (!programDetail.isRecordable() || !channel.isRecordable()) {
        RecordingUtil.showRecordingError(SYSAPP.RecordingController.REC_FAIL_NOTRECORDABLE);
        callback(SYSAPP.RecordingController.REC_FAIL_NOTRECORDABLE);
        return;
    }
    this.isExceedLimit(channelcode, programDetail.getSeriesHeadId(), prevuecode, function(limit) {
        var addNPVRProgram = function() {
            SYSAPP.QueryManager.addNPvr(prevuecode, channelcode, 1, function(res) {
                if (res && res.success && res.response && res.response.returncode == '0') {
                    callback(_self.REC_SUCCESS);
                } else {
                    callback(_self.REC_FAIL_UNKNOWN, res && res.response);
                }
            });
        };
        ...
    });
}
