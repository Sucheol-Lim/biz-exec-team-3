예약 · 리마인더

기능 개요

리마인더는 향후 방송될 프로그램을 예약해 두면 시작 시각에 알림 팝업을 띄워 주는 기능입니다. ReminderController는 내부에 reminderList를 두고, QueryManager.addReminder()로 서버에 예약을 등록한 뒤 목록을 갱신합니다. 핵심은 checkReminder()로, 현재 목록을 순회하며 가장 가까운 미래 예약을 찾아 그 시작 시각까지 남은 지연(delay)을 계산하고 단일 setTimeout 타이머를 겁니다.

지연 계산에는 미리 알림 시간(aheadtime, 초 단위)이 반영되어 시작 N초 전에 알릴 수 있습니다. 이미 종료된 예약은 건너뛰고, 시작 전 미래 예약 중 가장 가까운 것 하나에 타이머를 설정합니다. 타이머가 만료되면 showReminder()가 reminder.isRead = true로 표시한 뒤 버튼이 있는 팝업을 띄웁니다. 팝업 자체는 ReminderPopupController(ui/popup/ReminderPopupFrame)가 별도 프레임으로 렌더링합니다. VK_POWER 키는 팝업이 가로채지 않고 전원 처리로 흐르게 둡니다.

설계 포인트
여러 타이머를 동시에 돌리지 않고, 목록을 정렬·순회해 "다음에 도래할 하나"에만 setTimeout을 거는 단일 타이머 방식을 씁니다. 예약을 추가·삭제하거나 목록이 갱신될 때마다 clearReminderTimer() 후 checkReminder()를 다시 호출해 타이머를 재설정합니다.

관계. ReminderController가 예약 목록·타이머를 관리하고, 서버 등록은 QueryManager, 도래 알림 팝업은 ReminderPopupController가 담당합니다.

핵심 코드

controller/ReminderController.js — 다음 도래 예약에 타이머 설정
checkReminder: function() {
    var now = new Date();
    for (let idx = 0; idx < this.reminderList.length; idx++) {
        const reminder = this.reminderList[idx];
        var beginTime = new Date(reminder.begintime);
        var endTime   = new Date(reminder.endtime);

        if (endTime < now) {                          // 이미 종료
            continue;
        } else if (!reminder.isRead && beginTime >= now) {  // 미래 예약
            let delay = beginTime - now;
            delay = delay - reminder.aheadtime * 1000;       // aheadtime 보정
            this.clearReminderTimer();
            this.reminderTimer = setTimeout(() => {
                _self.showReminder(reminder);
            }, delay > 0 ? delay : 0);
            break;                                    // 최근접 1건만 설정
        }
    }
}
controller/ReminderPopupController.js — 도래 알림 팝업 프레임
init: function init(type) {
    this.frameName = 'ReminderPopupFrame';
    this.frame = new PopupFrame(this.frameName, Priority.POPUP);
    SYSAPP.RootWindow.addFrame(this.frame);
},

onKeyDown: function(keyEvent) {
    switch (keyEvent.keyCode) {
        case KeyEvent.VK_POWER:
            break;                       // 전원 키는 가로채지 않음
        default:
            this.frame.dispatchKeyDown(keyEvent);
            keyEvent.stopPropagation();
            break;
    }
}
