기능 개요

하트비트는 STB이 서버와 정상 연결되어 있는지 주기적으로 확인하고, 그 응답으로 채널·편성 데이터의 변경 여부를 함께 파악하는 운영 기능입니다. HeartbeatController는 초기화 시 한 번 하트비트를 보내 기준 타임스탬프를 잡은 뒤 AppConfig.HEARTBEAT_INTERVAL_TIME 간격으로 setInterval 폴링을 시작합니다. 각 하트비트(QueryManager.sendHeartbeat)의 응답에는 channelstamp·programstamp·clientip가 담겨 있어, 값이 바뀌면 채널 목록 재구성(startChannelRebuild)이나 편성 정보 갱신(ProgramCacheManager.getInfobarProgram)을 트리거합니다. 단, 채널 재구성은 활성 모드(PowerController.isActiveMode())일 때만 즉시 수행하고, 대기 모드면 stamp만 기록해 다음 로그인 때 반영합니다.

LogUploadController는 진단을 위한 로그 수집을 켜고(ExtensionInterface.logOn()), 15분 자동 종료 타이머를 걸어 일정 시간 후 로그를 끄고 업로드(logUpload())합니다. MobileAccessController는 모바일 단말 연동(DIAL/SSDP)을 제어하며, ServerManager.requestQueue()로 명령을 보내고 연결 상태를 관리합니다. 이 모든 API 요청은 ServerManager가 큐로 직렬화·재시도·에러 처리합니다.

설계 포인트
하트비트는 단순 keep-alive를 넘어 서버 측 변경(stamp)을 클라이언트에 푸시하는 역폴링 채널로 활용됩니다. 비싼 채널 재구성은 활성 모드에서만 즉시 수행하고 대기 모드에서는 미뤄, 불필요한 부하를 피합니다.

관계. HeartbeatController가 연결·stamp를 관리하고, 로그 업로드·모바일 접속은 각각 전용 컨트롤러가 ServerManager 큐를 통해 수행합니다.

핵심 코드

controller/HeartbeatController.js — 하트비트 폴링과 stamp 점검
startHeartbeat: function() {
    this.heartbeatInterval = setInterval(() => {
        self.sendHeartbeat();
    }, AppConfig.HEARTBEAT_INTERVAL_TIME);
},

sendHeartbeat: function() {
    SYSAPP.QueryManager.sendHeartbeat(function(result) {
        self.connectedStatus = !!result.success;
        if (result.success && result.response.returncode == '0') {
            if (!self.channelstamp) {                 // 최초엔 기준값만 보관
                self.channelstamp = result.response.channelstamp;
                self.programstamp = result.response.programstamp;
            } else {
                self.checkChannelStamp(result.response.channelstamp);
                self.checkProgramStamp(result.response.programstamp);
            }
        }
    });
}
controller/HeartbeatController.js — 활성 모드에서만 채널 재구성
checkChannelStamp: function(newChannelStamp) {
    if (self.channelstamp != newChannelStamp) {
        self.stopRebuildChannelTimer();
        if (SYSAPP.PowerController.isActiveMode()) {
            self.rebuildChannelTimer = setTimeout(() => {
                self.startChannelRebuild();           // 채널 목록 재구성
                self.channelstamp = newChannelStamp;
            }, self.getIntervalTime());
        } else {
            self.channelstamp = newChannelStamp;      // 대기 모드: 다음 로그인 반영
        }
    }
}
