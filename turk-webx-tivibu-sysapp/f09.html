기능 개요

PPV(Pay Per View)는 특정 이벤트·콘텐츠를 건별로 구매해 시청하는 모델입니다. PPVController는 채널·이벤트의 구매 상태를 패키지(super/basic)와 시간 구간(시작 전/이벤트 중/종료 후), 구매 여부에 따라 분기해 적절한 포스터·OSD를 표시합니다. super 패키지는 이미 구매한 것으로 간주해 일반 채널처럼 바로 재생하고, basic 패키지는 "PPV 구매됨" 또는 "PPV 구매 필요" 포스터를 띄웁니다. 인증 상태는 PPVAuthData(isPurchased(), canPlayPostBuffer())로 판정합니다.

실제 결제는 PurchaseManager.rentPPV()가 담당합니다. 콘텐츠의 PPV 상품(getPPVProduct() 또는 번들 상품)을 골라 QueryManager.getMPay()로 결제를 요청하며, 쿠폰이 있으면 결제 타입을 쿠폰(paytype=23)으로 바꿉니다. 결과 코드가 정상이면 성공 콜백을, 아니면 실패 콜백을 호출하고, _logPayment()로 결제 요청·결과를 데이터 수집에 기록합니다. 캠페인·쿠폰 팝업은 별도 컨트롤러(CampaignPopupController·CampaignCouponPopupController)가 함께 동작합니다.

설계 포인트
구매 "상태 판정"(PPVController)과 "결제 실행"(PurchaseManager)을 분리해, 화면은 상태에 따라 무엇을 보여줄지에 집중하고 결제 API 호출·쿠폰 처리·로깅은 매니저가 담당합니다. PPV 상품 정보는 콘텐츠 상세 모델에서 가져옵니다.

흐름. PPVController가 구매 상태에 따라 OSD를 띄우고, 구매 시 PurchaseManager.rentPPV()가 getMPay()로 결제(쿠폰이면 paytype 23)를 처리합니다.

관계. PPVController가 PPVAuthData로 상태를 판정하고, 결제는 PurchaseManager가 QueryManager.getMPay()로 수행합니다.

핵심 코드

controller/PurchaseManager.js — 쿠폰 분기와 결제 요청
rentPPV: function (programDetail, couponCode, isBundle, callback) {
    var paytype = 0;
    if (couponCode != null) {
        paytype = 23;                       // 쿠폰 결제
    }
    if (programDetail && programDetail.isPPV()) {
        var product = isBundle ? programDetail.getPPVBundleProduct()
                               : programDetail.getPPVProduct();
        if (product) {
            var requestTime = new Date();
            SYSAPP.QueryManager.getMPay(
                18,                          // programtype for IPPV
                SYSAPP.SystemInterface.getSerialNumber(),
                paytype, product.productcode, programDetail.prevuecode,
                couponCode, null,
                function(result) {
                    var ok = result.success && result.response
                          && result.response.returncode == "0" && result.response.mpay;
                    callback(!!ok);
                    _self._logPayment(product, requestTime, result);
                });
        }
    }
}
