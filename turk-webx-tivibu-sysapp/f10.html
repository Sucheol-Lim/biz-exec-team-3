부모 잠금 / 핀 관리

LockManager가 연령 등급(비트마스크)·채널 잠금을 판정하고, PinController가 PIN 입력을, CreatePasswordController가 PIN 생성을, ParentalLockChController가 채널 잠금 설정을 담당합니다.

기능 개요

부모 잠금은 두 축으로 구성됩니다. (1) 연령 등급 잠금은 콘텐츠 등급이 사용자 시청 등급 임계값을 넘으면 잠그는 것으로, LockManager.isPRLock(contentLevel)이 현재 프로필 등급(ProfileManager.getCurrentProfileUserLevel())과 콘텐츠 등급을 비트 AND로 비교해 판정합니다. (2) 채널 잠금은 LockManager.isChannelLock(channel)이 채널의 isLockChannel() 플래그로 판정합니다. PC 브라우저 디버그 모드에서는 두 검사 모두 잠금 없음으로 우회합니다.

잠긴 콘텐츠·채널에 접근하면 PIN 입력 화면(PinController → ui/pin/PinFrame)이 떠 비밀번호를 요구합니다. PIN이 아직 설정되지 않았다면 CreatePasswordController(ui/createPassword/CreatePasswordFrame)로 새 PIN을 만들도록 유도합니다. 채널 단위 잠금 설정·해제는 ParentalLockChController(ui/lock/ParentalLockChFrame)에서 관리합니다. 현재 프로필의 시청 등급 임계값은 UserPreference.getParentalRatingThreshold()에 저장되며, 서버에서 updateUserLevel()로 동기화됩니다.

설계 포인트
등급 판정은 비트마스크 AND 연산((userLevel & contentLevel) > 0)으로 이루어져, 등급 체계를 비트 플래그로 유연하게 표현합니다. 잠금 "판정"은 LockManager가 전담하고, PIN 입력·생성·채널 잠금 UI는 각각 별도 컨트롤러로 분리되어 있습니다.

핵심 코드

controller/LockManager.js — 등급/채널 잠금 판정
isChannelLock: function (channel) {
    if (AppConfig.PC_BROWSER) return false;
    return channel.isLockChannel();          // 채널 잠금 플래그
},

// contentLevel : ProgramDetail.ratingid 또는 VODDetail.ratingid
isPRLock: function (contentLevel) {
    if (AppConfig.PC_BROWSER) return false;
    var userLevel = SYSAPP.ProfileManager.getCurrentProfileUserLevel();
    var isLock = (userLevel & contentLevel) > 0;   // 비트마스크 AND
    return isLock;
}
data/ProfileManager.js — 시청 등급 임계값 동기화
getCurrentProfileUserLevel: function() {
    return SYSAPP.UserPreference.getParentalRatingThreshold();
},

updateUserLevel: function(callback, ignoreErrorPopup = false) {
    SYSAPP.QueryManager.getInitialUserInfo(function(result) {
        if (result && result.success && result.response.returncode == '0'
            && result.response.userlevel) {
            SYSAPP.UserPreference.setParentalRatingThreshold(result.response.userlevel);
        }
        if (callback) callback(result.success);
    }, ignoreErrorPopup);
}
