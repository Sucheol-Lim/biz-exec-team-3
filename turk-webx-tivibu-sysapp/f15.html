기능 개요

CAS(Conditional Access System, 조건부 접근)는 가입자 권한이 있는 콘텐츠만 복호화·시청하도록 통제합니다. CAManager는 초기화 시 SystemInterface.getCASystemObject()로 OIPF CA System 객체를 얻어 connect()하고 CAEvent 리스너를 등록합니다. CA 이벤트가 오면 receiveCAEvent()가 에러 코드(e.code)를 검사해, 양수면 에러 메시지·코드를 매핑해 OSDConstant.CAS OSD를 띄우고, 0 이하면 CAS OSD를 닫습니다. 에러 코드는 errorNotAvailable(1)·errorBlackOut(2)·errorDenied(3) 등으로 정의되어 있고, 화면용 CAS OSD는 CasController(ui/cas/CasFrame)가 렌더링합니다.

핑거프린트는 화면에 사용자 식별 표식을 띄워 불법 재배포를 추적하는 보안 기능으로, FingerprintController(ui/fingerprint/FingerprintFrame)가 표시를 담당합니다. HDCPController는 출력 보호(HDCP) 인증 상태를 감시해, 인증 실패(미인증) 콜백이 오면 HDCP 에러 OSD를 띄우고 인증 성공 시 닫습니다. 이를 위해 SystemInterface.addHDCPListener(authenticated, unauthenticated)로 인증/미인증 콜백을 등록합니다.

설계 포인트
보안 기능들은 모두 SystemInterface(OIPF/미들웨어)가 추상화한 이벤트·콜백에 반응하는 구조입니다. CAS는 CA 이벤트, HDCP는 인증 상태 콜백을 받아 OSD를 띄우거나 닫는 방식으로 동작해, 하드웨어 보안 상태를 사용자 화면과 일관되게 동기화합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant SI as SystemInterface (OIPF CA) participant CA as CAManager participant OSD as OSDController participant CAS as CasController participant HDCP as HDCPController CA->>SI: getCASystemObject() → connect() CA->>SI: addEventListener('CAEvent', receiveCAEvent) SI-->>CA: CAEvent (ccid, casType, code) alt code > 0 (에러) CA->>CA: getCAErrorMessage(code) / getCACode(code) CA->>OSD: setOSD(CAS, {msg, code}) OSD->>CAS: CAS 화면 표시 else code <= 0 CA->>OSD: resetOSD(CAS) end Note over HDCP,SI: 출력 보호 HDCP->>SI: addHDCPListener(auth, unauth) SI-->>HDCP: unauthenticated → showHDCPError() SI-->>HDCP: authenticated → hideHDCPError()

흐름. CA 이벤트의 에러 코드에 따라 CAS OSD를 띄우거나 닫고, HDCP 인증 상태 변화에 따라 출력 보호 에러를 표시/해제합니다.

클래스 다이어그램

classDiagram class CAManager { -caSystem +initialize() +receiveCAEvent(e) +getCAErrorMessage(code) string +getCACode(code) int } class CasController { -casFrame CasFrame +show(param) +hide(param) } class FingerprintController { -fingerprintFrame FingerprintFrame +show(param) +hide(param) } class HDCPController { +initialize() +addHDCPListener() +showHDCPError() +hideHDCPError() } class SystemInterface { +getCASystemObject() +addHDCPListener(auth, unauth) } CAManager --> SystemInterface : CA System 객체 CAManager ..> CasController : CAS OSD 표시 HDCPController --> SystemInterface : HDCP 인증 리스너

관계. CAManager가 CA 이벤트를, HDCPController가 HDCP 인증을 처리하며, 둘 다 SystemInterface가 추상화한 보안 API에 의존합니다.

핵심 코드

controller/CAManager.js — CA 이벤트 처리
receiveCAEvent: function(e) {
    if (e.code > 0) {
        var msg  = _self.getCAErrorMessage(e.code);
        var code = _self.getCACode(e.code);
        if (msg) {
            SYSAPP.OSDController.setOSD(OSDConstant.CAS, {msg: msg, code: code});
        }
    } else {
        SYSAPP.OSDController.resetOSD(OSDConstant.CAS, null, false);
    }
}

// 에러 코드: errorNotAvailable=1, errorBlackOut=2, errorDenied=3, ...
controller/HDCPController.js — HDCP 인증 리스너
addHDCPListener: function() {
    let unauthenticatedCallback = function() {
        _self.showHDCPError();          // 미인증 → HDCP 에러 OSD
    };
    let authenticatedCallback = function() {
        _self.hideHDCPError();          // 인증 → 에러 해제
    };
    SYSAPP.SystemInterface.addHDCPListener(authenticatedCallback, unauthenticatedCallback);
}
