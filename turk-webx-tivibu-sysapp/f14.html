기능 개요

광고는 Google 광고 스택을 사용합니다. index.html이 GPT(securepubads.g.doubleclick.net/tag/js/gpt.js)와 IMA SDK(imasdk.googleapis.com/js/sdkloader/ima3.js)를 외부 로드합니다. AdController는 GPT 슬롯에 렌더링된 광고 크리에이티브의 메타데이터를 읽어 클릭 시 어디로 보낼지(컬럼/VOD/채널)를 해석합니다. 구체적으로 슬롯 iframe 안 이미지의 alt 속성을 |로 분리해, 타입 코드(0=컬럼, 1=VOD, 2=채널)와 대상 코드를 추출합니다. 배너 광고 화면은 AdBannerController(ui/ads/AdBannerFrame)가 담당합니다.

캠페인·쿠폰은 PPV 구매 흐름과 연계되는 프로모션으로, CampaignPopupController·CampaignCouponPopupController가 팝업을 띄웁니다. 알림은 두 갈래입니다. NotificationController(ui/notification/NotificationFrame)는 앱 내 알림 UI를, NotificationFrameController는 외부 알림 페이지(NOTIFICATION_PAGE_URL)를 별도 iframe(frmNotificationElm)으로 띄우는 프레임 기반 알림을 관리합니다.

설계 포인트
광고 클릭 타깃을 별도 API가 아니라 크리에이티브 이미지의 alt 메타데이터에 인코딩해 전달하는 방식이라, 광고 시스템이 콘텐츠 딥링크(컬럼/VOD/채널)를 유연하게 지정할 수 있습니다. 알림은 앱 내 UI와 외부 iframe 페이지를 분리해 운영 알림을 독립적으로 갱신합니다.

핵심 코드

index.html — Google 광고 SDK 로드
<script type="text/javascript" src="//securepubads.g.doubleclick.net/tag/js/gpt.js"></script>
<script type="text/javascript" src="//imasdk.googleapis.com/js/sdkloader/ima3.js"></script>
controller/AdController.js — 광고 크리에이티브 메타데이터 파싱
getGoogleAdInfo: function(slotName) {
    var info = { type: 'none' };
    var alt = document.getElementById(slotName)
        .getElementsByTagName('iframe')[0]
        .contentWindow.document
        .getElementsByTagName('img')[0].alt;

    var data = alt.split('|');
    if (data.length > 1) {
        switch (data[0]) {
            case "0": info.type = 'column';  info.columncode  = data[1]; break;
            case "1": info.type = 'vod';     info.programcode = data[1]; break;
            case "2": info.type = 'channel'; info.channelcode = data[1]; break;
        }
    }
    return info;
}
