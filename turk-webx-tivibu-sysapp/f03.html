미니가이드 / 인포 배너

MiniGuideController가 MiniGuideFrame을 띄워 시청 중 채널·현재/다음 프로그램 정보를 인포 배너로 표시하고, 무동작 타이머(addIdleListener)로 자동 숨김을 제어합니다.

기능 개요

미니가이드(인포 배너)는 Live TV 시청 중 채널을 바꾸거나 INFO 키를 누를 때 화면 하단에 잠시 떠오르는 정보 띠입니다. 현재 채널 번호·이름과 현재/다음 프로그램 제목·시간을 보여 줍니다. MiniGuideController는 생성 시 MiniGuideFrame을 만들어 RootWindow에 등록하고, 표시·갱신·숨김을 프레임 lifecycle로 처리합니다.

채널 전환 시 LiveTVController가 NavSIMain.showMiniGuide(channel, ...)를 호출하면 미니가이드가 갱신되며 표시됩니다. 숨김은 guideFrame.hideAnimation()으로 애니메이션을 재생한 뒤 RootWindow.hideFrame으로 프레임을 내립니다. 일정 시간 입력이 없으면 자동으로 사라지도록 KeyEventManager.addIdleListener 기반의 무동작 타이머(setNoActionTimer)를 두며, 타임아웃 기본값은 AppConfig.MINIGUIDE_TIMEOUT입니다.

설계 포인트
자동 숨김은 OSD를 직접 끄는 대신 OSDController.resetOSD(OSDConstant.MINIGUIDE)를 호출해, OSD 우선순위 관리 체계 안에서 일관되게 닫히도록 합니다. 표시·숨김 모두 KeyEventManager의 idle listener를 등록/해제하여 자원 누수를 막습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant LTV as LiveTVController participant NAV as NavSIMain participant MGC as MiniGuideController participant MGF as MiniGuideFrame participant KEM as KeyEventManager participant OSD as OSDController LTV->>NAV: showMiniGuide(channel, true) NAV->>MGC: show(param) / update(param) MGC->>MGF: RootWindow.showFrame('miniGuideFrame') MGC->>KEM: addKeyListener(this) MGC->>KEM: addIdleListener(MINIGUIDE_TIMEOUT) Note over MGF: 채널·현재/다음 프로그램 표시 alt 타임아웃 도래 (무동작) KEM->>MGC: idle 콜백 MGC->>OSD: resetOSD(OSDConstant.MINIGUIDE) MGC->>MGF: hideAnimation() → RootWindow.hideFrame else 키 입력 KEM->>MGC: onKeyDown(keyEvent) MGC->>MGF: dispatchKeyDown(keyEvent) end

흐름. 채널 전환으로 showMiniGuide()가 호출되면 배너가 뜨고 무동작 타이머가 시작됩니다. 타임아웃이 지나면 resetOSD로 OSD 체계를 통해 자동으로 닫힙니다.

클래스 다이어그램

classDiagram class MiniGuideController { -guideFrame MiniGuideFrame -frameName string -noActionTimer +show(param) +update(param) +hide(param) +setNoActionTimer(time) +clearNoActionTimer() +onKeyDown(keyEvent) +reset() } class MiniGuideFrame { +dispatchKeyDown(keyEvent) +hideAnimation(cb) +reset() +isVisible() bool } class KeyEventManager { +addKeyListener(l) +addIdleListener(time, keys, cb) +removeIdleListener(t) } class OSDController { +resetOSD(constant) } MiniGuideController --> MiniGuideFrame : 소유 · 키 위임 MiniGuideController --> KeyEventManager : idle 타이머 MiniGuideController --> OSDController : 자동 숨김

관계. MiniGuideController가 MiniGuideFrame을 소유하고, KeyEventManager의 idle listener로 타임아웃을 관리하며, 만료 시 OSDController를 통해 닫습니다.

핵심 코드

controller/MiniGuideController.js — 무동작 타이머
setNoActionTimer: function(time) {
    this.clearNoActionTimer();
    var self = this;
    this.noActionTimer = SYSAPP.KeyEventManager.addIdleListener(
        time == undefined ? AppConfig.MINIGUIDE_TIMEOUT : time * 1000,
        [],
        function() {
            SYSAPP.OSDController.resetOSD(OSDConstant.MINIGUIDE);   // 타임아웃 → 자동 숨김
        });
},

clearNoActionTimer: function() {
    if (this.noActionTimer) {
        SYSAPP.KeyEventManager.removeIdleListener(this.noActionTimer);
        this.noActionTimer = null;
    }
}
controller/MiniGuideController.js — 표시·숨김 lifecycle
show: function show(param) {
    SYSAPP.RootWindow.showFrame(this.frameName, param);
    this.addKeyEventListener();
},

hide: function hide(param) {
    this.removeKeyEventListener();
    var self = this;
    this.guideFrame.hideAnimation(function() {
        SYSAPP.RootWindow.hideFrame(self.frameName, param);   // 애니메이션 후 프레임 내림
    });
    this.clearNoActionTimer();
}
