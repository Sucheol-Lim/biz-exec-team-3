프로필 / 사용자 설정

기능 개요

프로필은 한 가구의 여러 사용자(성인·키즈 등)를 구분해 시청 등급과 환경을 분리합니다. ProfileController는 ProfileFrame을 띄워 프로필 목록을 보여주고 선택을 받습니다. 선택된 프로필은 ProfileManager.setCurrentProfile(profile)로 저장되며, UserPreference.setLastProfile()에 직렬화되어 영속화되고, 필요 시 updateUserLevel()로 서버에서 시청 등급(userlevel)을 다시 받아 동기화합니다.

프로필 전환 시 PIN 보호가 걸려 있으면(hasPassword()) 확인이 필요하고, PIN이 없는 관리자(admin) 프로필이면 checkNeedCreatePassword()가 PIN 생성 OSD(CREATE_PW)를 띄웁니다. UserConfigManager는 부팅 시 QueryManager.getUserFrameConfig()로 서버 사용자 설정을 받아, TV/VOD 컬럼 코드, 페이지 점프, framecode, 수집 에이전트 URL, Widevine 라이선스 URL, 정상/키즈 프로필 ID 등 앱 전반의 구성 값을 제공합니다.

설계 포인트
"프로필 화면"(ProfileController), "현재 프로필·등급 상태"(ProfileManager), "서버 사용자 구성"(UserConfigManager)을 분리합니다. 프로필 전환이 곧 시청 등급 변경으로 이어지므로, setCurrentProfile은 기본적으로 updateUserLevel을 함께 호출해 부모 잠금 판정과 일관성을 유지합니다.

핵심 코드

data/ProfileManager.js — 현재 프로필 저장과 등급 동기화
setCurrentProfile: function(profile, needUpdateUserLevel = true) {
    SYSAPP.UserPreference.setLastProfile(safeStringify(profile));
    this.lastProfile = null;             // refresh 유도
    if (needUpdateUserLevel) {
        this.updateUserLevel();          // 프로필 전환 → 시청 등급 재동기화
    }
},

hasPassword: function() {
    var masterProfile = this.getMasterProfile();
    return !(masterProfile && masterProfile.havepwd == 0);
}

QueryManager.getUserFrameConfig(function(result) {
    if (result && result.success) {
        if (_self.getDebugFtpIpList())
            SYSAPP.UserPreference.setStorageUrl(_self.getDebugFtpIpList());
        // getTvColumn / getWidevineLicenseUrl / getFramecode /
        // getNormalProfileId / getKidsProfileId 등으로 앱 전반에 설정 제공
    }
});
