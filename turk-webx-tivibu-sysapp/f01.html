Live TV 시청

LiveTVController가 채널 전환 요청을 받아 구독·잠금·동시시청 조건을 점검하고, SystemInterface의 OIPF Video Broadcast Object로 방송 채널을 튜닝·출력합니다.

기능 개요

Live TV는 STB의 기본 화면으로, 사용자가 채널을 전환하면 해당 채널의 방송을 출력합니다. 리모컨 키 입력은 core/controller/KeyEventManager를 거쳐 ChannelController에서 다음 채널을 결정하고, 그 결과(Channel 객체)가 LiveTVController.processChannel()로 전달됩니다. 컨트롤러는 채널 종류와 상태에 따라 분기 처리한 뒤, 실제 방송 튜닝은 SystemInterface가 관리하는 OIPF Video Broadcast Object(VBO)로 위임합니다.

setChannel()은 채널을 선택하기 전에 여러 권한·상태 조건을 순서대로 점검합니다. PPV 채널이면 구매 OSD를, 미가입 채널이면 UNSUBSCRIBED_CH OSD를, 잠긴 채널이면 CHANNEL_LOCK OSD를 띄우고 방송 출력을 보류합니다. 정상 채널이면 현재 편성 프로그램(ProgramCacheManager.getPresentProgram())을 조회해 부모 등급 잠금(LockManager.isPRLock()) 여부를 확인하고, 통과 시 ChannelController.setChannel(param, true)로 방송을 켭니다.

동시 시청 제한이 있는 고등급(High Level) 채널은 ConcurrentChannelManager로 다른 단말의 시청 여부를 확인하고, 충돌 시 "계속/취소" 선택 팝업을 띄웁니다. 채널이 변경되면 NavSIMain.showMiniGuide()로 미니가이드를 표시합니다.

설계 포인트
방송 출력은 LiveTVController가 직접 수행하지 않고 ChannelController → SystemInterface(OIPF VBO)로 단계적으로 위임합니다. 컨트롤러는 "이 채널을 틀어도 되는가"의 정책 판단(구독·잠금·PPV·부모등급·동시시청)에 집중하고, 하드웨어에 가까운 튜닝은 core 레이어가 담당합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant KEM as KeyEventManager participant CHC as ChannelController participant LTV as LiveTVController participant LM as LockManager participant PCM as ProgramCacheManager participant SI as SystemInterface (OIPF VBO) participant OSD as OSDController KEM->>CHC: 채널 업/다운 · 숫자 입력 CHC->>LTV: processChannel(channel) alt 고등급(High Level) 채널 LTV->>LTV: ConcurrentChannelManager.isWatchingOthers() Note over LTV,OSD: 충돌 시 BUTTON_POPUP(계속/취소) end LTV->>LTV: setChannel(channel) alt PPV / 미가입 / 잠금 LTV->>OSD: setOSD(PPV / UNSUBSCRIBED_CH / CHANNEL_LOCK) Note over LTV: select = false (출력 보류) else 정상 채널 LTV->>PCM: getPresentProgram(code) PCM-->>LTV: curProgram LTV->>LM: isPRLock(ratingid) alt 부모등급 잠김 LTV->>OSD: setOSD(PARENTAL_LOCK) else 통과 LTV->>SI: ChannelController.setChannel(ch, true) SI-->>LTV: 방송 출력 end end

흐름. 키 입력으로 채널이 결정되면 processChannel()이 동시시청을 점검하고, setChannel()이 구독·잠금·PPV·부모등급 조건을 차례로 검사한 뒤 통과한 채널만 VBO로 튜닝합니다.

관계. LiveTVController가 정책 판단을 맡고, ChannelController·SystemInterface가 실제 OIPF VBO 튜닝을, LockManager·ProgramCacheManager가 잠금·편성 정보를 제공합니다.

핵심 코드

controller/LiveTVController.js — setChannel 권한·상태 점검
setChannel: function (param) {
    requestChannelCode = param.code;
    var select = true;
    var isPPV = false;

    // 1.Subscription/PPV 2.Locked channel 3.Parental error
    if (param.isPPV()) {                 // PPV 채널
        isPPV = true;
        select = false;
    } else if (!param.isSubscribed()) {  // 미가입
        SYSAPP.OSDController.setOSD(OSDConstant.UNSUBSCRIBED_CH);
        select = false;
    } else if (SYSAPP.LockManager.isChannelLock(param)) {  // 채널 잠금
        SYSAPP.OSDController.setOSD(OSDConstant.CHANNEL_LOCK);
        select = false;
    }
    ...
    SYSAPP.ProgramCacheManager.getPresentProgram(param.code, function (curProgram) {
        if (curProgram && SYSAPP.LockManager.isPRLock(curProgram.ratingid) && !isPPV) {
            SYSAPP.OSDController.setOSD(OSDConstant.PARENTAL_LOCK);  // 부모등급 잠금
            select = false;
        }
        SYSAPP.ChannelController.setChannel(param, select);          // 방송 출력
    }, true);
}
controller/LiveTVController.js — 오디오/자막 컴포넌트 제어 (OIPF VBO)
getAudioComponents: function() {
    return SYSAPP.SystemInterface.getLiveAudioComponents();
},
selectSubtitleComponent: function(subtitleComp) {
    SYSAPP.SystemInterface.getVBOMain().selectComponent(subtitleComp);
},
setOffSubtitleComponent: function() {
    var vboMain = SYSAPP.SystemInterface.getVBOMain();
    var currentComponent = vboMain.getCurrentActiveComponents(2); // 2 : Subtitle
    if (currentComponent.length > 0) {
        vboMain.unselectComponent(currentComponent[0]);
    }
}
