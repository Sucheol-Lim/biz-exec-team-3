기능 개요

설정·시스템 관리는 사용자 설정 화면과 그 뒤에서 동작하는 시스템 관리 기능을 묶습니다. SettingController는 SettingFrame을 띄워 언어·화면 등 환경설정 UI를 제공합니다. 시스템 측에서는 펌웨어 업그레이드(OTA), 전원 상태 관리, 시계 표시가 백그라운드 컨트롤러로 동작합니다.

OTAController는 부팅 시 단말 모델·MAC·현재 펌웨어 버전으로 업그레이드 확인 URL을 만들고(checkOperaFW_UI_GET.do), 서버 응답의 requestInterval에 맞춰 주기적으로 폴링합니다. 펌웨어 버전이 테스트값(9.9.9)이면 OTA를 끄고, 재시도 횟수가 3회 이상이면 다음 점검을 3시간 뒤로 미룹니다. PowerController는 SystemInterface.addPowerStateListener()로 전원 상태 변화를 받아 ACTIVE_STANDBY(3)이면 대기 모드, ON(1)이면 활성 모드로 전환합니다. ClockController는 ClockFrame으로 시계를 표시하고 숨김 애니메이션을 처리합니다.

설계 포인트
OTA는 서버가 내려준 requestInterval과 재시도 횟수(UserPreference.getFWCheckRetries())를 조합해 폴링 주기를 적응적으로 조절합니다. 전원·시계·OTA는 화면이 아니라 시스템 추상화(SystemInterface·ExtensionInterface)와 통신하는 백그라운드 관리자에 가깝습니다.

관계. SettingController는 설정 UI를, OTAController·PowerController·ClockController는 시스템 관리를 담당하며, 전원·하드웨어 정보는 SystemInterface로 추상화됩니다.

핵심 코드

controller/OTAController.js — 펌웨어 점검 초기화·폴링
initialize: function() {
    this.fwVersion = SYSAPP.ExtensionInterface.getSWVersion();
    this.macId     = SYSAPP.SystemInterface.getMacAddressNumber();
    this.stbModel  = SYSAPP.ExtensionInterface.getHwModel() + '_ZTE';
    this.requestURL = this.makeURL();

    if (this.fwVersion == "9.9.9") {
        AppConfig.USE_OTA = false;                 // 테스트 빌드는 OTA 비활성
    } else {
        this.retryCount = parseInt(SYSAPP.UserPreference.getFWCheckRetries());
        if (this.retryCount >= 3) {
            this.startTimer(3 * 60 * 60 * 1000);   // 3시간 뒤 재점검
            SYSAPP.UserPreference.setFWCheckRetries(0);
        } else {
            this.startTimer(1);
        }
    }
}
controller/PowerController.js — 전원 상태 전환
initialize: function() {
    SYSAPP.SystemInterface.addPowerStateListener(this.onPowerStateChange);
},

onPowerStateChange: function (powerState) {
    if (powerState.state == SysConfig.POWER_STATE_ACTIVE_STANDBY) {   // 3
        _self.runStandbyMode();
    } else if (powerState.state == SysConfig.POWER_STATE_ON) {        // 1
        _self.runActiveMode(false);
    }
}
