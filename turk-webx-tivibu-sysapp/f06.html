VOD / 시리즈 상세 · 재생

기능 개요

VOD·시리즈 상세는 콘텐츠 정보(포스터·줄거리·등급)와 시즌/에피소드 목록, 재생/구매/녹화 버튼을 보여주는 화면입니다. TVDetailController가 2022 리뉴얼 상세 프레임(ui2022/tvdetail/TVDetailFrame)을 띄우며, 시리즈인 경우 SeriesUtil이 QueryManager를 통해 SeriesHeader·Season·Episode 모델을 구성해 시즌 전환과 에피소드 선택을 지원합니다.

재생은 VodPlayController가 담당합니다. 생성 시 SystemInterface.getVideoPlayer()로 HTML5 <video>(videoPlayer DOM)를 가져오고, loadedmetadata 이벤트에 자막 트랙 초기화를 연결합니다. startPlay(param)은 재생 모드(VOD/PLTV)에 따라 재생 URL을 만들고, DRM이 필요한 경우 updatePlayerConfig()에서 Widevine 라이선스 URL과 CustomData(시리얼·usertoken 기반)를 구성합니다. 재생 위치(북마크)는 QueryManager로 조회·저장하며, 시리즈는 다음 에피소드 자동 재생을 처리합니다.

레거시 STB(SystemInterface.isLegacy())에서는 상세·검색 등 화면 전환 시 LegacyPlayController가 라이브/VOD 정지(stopPlay)·재개(startPlay)를 지연 스케줄로 중계하는데, VOD 재생 시작 시점에 이 대기 상태가 남아 있으면 재생이 되돌려질 수 있습니다. 이를 막기 위해 VodPlayController.startPlay()가 먼저 LegacyPlayController.resetPendingResume()를 호출해 예약된 stop/start 전환과 suspend 상태를 초기화합니다.

설계 포인트
라이브 방송이 OIPF VBO를 쓰는 것과 달리, VOD/PLTV 재생은 HTML5 <video> 요소와 Widevine DRM 경로를 사용합니다. 최근 스프린트(Jira VLTRANLAND-1918)에서 레거시 STB의 일부 과거 프로그램이 재생되지 않던 문제를 resetPendingResume 도입으로 수정했습니다.

관계. TVDetailController가 상세 화면을, SeriesUtil이 시리즈 모델을, VodPlayController가 SystemInterface의 HTML5 <video>로 재생을 담당합니다. 레거시 STB에서는 재생 시작 전 LegacyPlayController의 대기 상태를 초기화합니다.

initPlayerConfig: function() {
    this.customData = 'CustomData: ' + EncryptUtils.customData(
        "TIVIBU", SYSAPP.SystemInterface.getSerialNumber(), "ZTE",
        SYSAPP.SystemInterface.getConfiguration('usertoken'));
    this.dashDrmUrl = SYSAPP.UserConfigManager.getWidevineLicenseUrl()

VodPlayController.js · LegacyPlayController.js — 레거시 STB 재생 대기 상태 초기화 (VLTRANLAND-1918)
// VodPlayController.startPlay — 레거시 STB면 대기 중인 stop/start 전환을 먼저 초기화
startPlay: function(param) {
    ...
    if (SYSAPP.SystemInterface.isLegacy()) {
        SYSAPP.LegacyPlayController.resetPendingResume('VodPlayController.startPlay');
    }
    this.updatePlayerConfig();
    ...
},

// LegacyPlayController — 예약된 전환 타이머를 취소하고 suspend 상태를 리셋
resetPendingResume: function(reason) {
    this._clearPendingTransition('resetPendingResume');
    this.suspendDepth = 0;
    this.resumeTarget = null;
}
