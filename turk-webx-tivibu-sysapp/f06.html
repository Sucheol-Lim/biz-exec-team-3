VOD / 시리즈 상세 · 재생

TVDetailController가 VOD·시리즈 상세를 보여주고, SeriesUtil로 시즌/에피소드 모델을 구성하며, VodPlayController가 HTML5 <video>로 재생합니다.

기능 개요

VOD·시리즈 상세는 콘텐츠 정보(포스터·줄거리·등급)와 시즌/에피소드 목록, 재생/구매/녹화 버튼을 보여주는 화면입니다. TVDetailController가 2022 리뉴얼 상세 프레임(ui2022/tvdetail/TVDetailFrame)을 띄우며, 시리즈인 경우 SeriesUtil이 QueryManager를 통해 SeriesHeader·Season·Episode 모델을 구성해 시즌 전환과 에피소드 선택을 지원합니다.

재생은 VodPlayController가 담당합니다. 생성 시 SystemInterface.getVideoPlayer()로 HTML5 <video>(videoPlayer DOM)를 가져오고, loadedmetadata 이벤트에 자막 트랙 초기화를 연결합니다. startPlay(param)은 재생 모드(VOD/PLTV)에 따라 재생 URL을 만들고, DRM이 필요한 경우 updatePlayerConfig()에서 Widevine 라이선스 URL과 CustomData(시리얼·usertoken 기반)를 구성합니다. 재생 위치(북마크)는 QueryManager로 조회·저장하며, 시리즈는 다음 에피소드 자동 재생을 처리합니다.

설계 포인트
라이브 방송이 OIPF VBO를 쓰는 것과 달리, VOD/PLTV 재생은 HTML5 <video> 요소와 Widevine DRM 경로를 사용합니다. 최근 스프린트(Jira VLTRANLAND-1738/1760/1779)에서 VOD 리모컨 사용성, 썸네일 롱프레스 점프, 스크롤 리셋 로직이 개선되었습니다.

흐름. 상세 화면에서 시리즈는 SeriesUtil로 에피소드 모델을 받아 표시하고, 재생 시 VodPlayController가 DRM 설정을 구성한 뒤 HTML5 <video>로 재생합니다.

클래스 다이어그램

관계. TVDetailController가 상세 화면을, SeriesUtil이 시리즈 모델을, VodPlayController가 SystemInterface의 HTML5 <video>로 재생을 담당합니다.

initPlayerConfig: function() {
    this.customData = 'CustomData: ' + EncryptUtils.customData(
        "TIVIBU", SYSAPP.SystemInterface.getSerialNumber(), "ZTE",
        SYSAPP.SystemInterface.getConfiguration('usertoken'));
    this.dashDrmUrl = SYSAPP.UserConfigManager.getWidevineLicenseUrl()
        .concat('?deviceId=').concat(SYSAPP.SystemInterface.getSerialNumber())
        .concat('&terminaltype=').concat(QueryConstants.VALUE_TERMINAL_FLAG_STB);
}
