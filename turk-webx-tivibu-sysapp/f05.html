검색 / 검색 상세

SearchController가 화상 키보드(OSK)로 입력받은 키워드를 QueryManager.getKeywordSearch()로 질의하고, 결과 선택 시 SearchDetailController가 상세 화면을 띄웁니다.

기능 개요

검색은 콘텐츠명·채널을 키워드로 찾는 기능입니다. SearchController는 SearchFrame을 생성·등록하고, 프레임 안의 화상 키보드(OSK, ui/search/SearchOsk·SearchOskPanel)로 사용자가 글자를 입력하면 검색어를 만듭니다. OSK는 공용 베이스인 app/osk/BaseOsk를 확장합니다. 입력된 키워드는 QueryManager.getKeywordSearch()로 서버에 질의되어 결과가 그리드(SearchResultGrid·SearchResultPanel)에 표시됩니다.

검색 결과에서 항목을 선택하면 SearchDetailController가 2022 리뉴얼 상세 프레임(ui2022/searchdetail/SearchDetailFrame)을 띄웁니다. 검색 상세는 프로그램/VOD 상세 정보를 보여주며, 거기서 재생·녹화·예약 등 후속 동작으로 연결됩니다. 두 컨트롤러 모두 표시 시 KeyEventManager에 자신을 키 리스너로 등록하고, 프레임 lifecycle은 RootWindow가 관리합니다.

설계 포인트
검색과 검색 상세를 별도 컨트롤러·프레임으로 분리해, 결과 목록과 상세 화면의 우선순위(Priority.SETTING vs Priority.SEARCH_DETAIL)와 키 입력을 독립적으로 관리합니다. OSK는 BaseOsk 공통 로직을 재사용해 입력 문자열(oskString)과 최대 길이를 다룹니다.

관계. SearchController가 검색 프레임과 OSK를, SearchDetailController가 상세 프레임을 담당하며, 검색 질의는 QueryManager.getKeywordSearch()로 수행됩니다.

핵심 코드

controller/SearchController.js — 검색 프레임 표시·키 위임
init: function init(type) {
    this.frameName = 'searchFrame';
    this.searchFrame = new SearchFrame(this.frameName, Priority.SETTING);
    SYSAPP.RootWindow.addFrame(this.searchFrame);
    SYSAPP.SearchController = this;
},

show: function show(param, entrance) {
    this.addKeyEventListener();
    SYSAPP.RootWindow.showFrame(this.frameName, param, entrance);
},

onKeyDown: function(keyEvent) {
    this.searchFrame.dispatchKeyDown(keyEvent);   // OSK·결과 그리드로 위임
}
controller/SearchDetailController.js — 2022 검색 상세 프레임
init: function init(type) {
    SYSAPP.SearchDetailController = this;
    this.frameName = 'searchDetailFrame2022';
    this.searchDetailFrame = new SearchDetailFrame2022(this.frameName, Priority.SEARCH_DETAIL);
    SYSAPP.RootWindow.addFrame(this.searchDetailFrame);
},

show: function show(param, entrance) {
    this.addKeyEventListener();
    SYSAPP.RootWindow.showFrame(this.frameName, param, entrance);   // 결과 선택 → 상세
}
