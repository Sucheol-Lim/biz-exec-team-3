채널 리스트 · 필터

기능 개요

채널 리스트는 시청 중 화면에 띄우는 채널 목록 OSD로, 채널을 빠르게 탐색하고 장르·즐겨찾기로 필터링할 수 있습니다. ChannelListController는 컨트롤러 층의 래퍼로 ChannelListFrame을 생성·등록하고, 표시·갱신·숨김을 RootWindow 프레임 lifecycle로 처리합니다. 숨김 시에는 hideAnimation() 애니메이션 후 프레임을 내리고 무동작 타이머를 정리합니다.

UI는 ui/channelList의 데이터 피드/포매터 위젯들이 분담합니다. 채널 목록은 ChannelListDataFeed·ChannelListFormatter·ChannelListVerticalCarousel이, 채널별 편성 정보는 ChannelListProgramDataFeed가, 좌측 필터 패널은 ChannelFilterDataFeed·ChannelFilterFormatter가 담당합니다. 필터 항목은 GenreManager.getAllGenreList()가 제공하는 장르 목록을 기반으로 구성됩니다.

최근 스프린트(sprint/LS0526/channellistfilter, Jira VLTRANLAND-1797)에서 필터링 규칙과 디자인이 개선되었습니다. GenreManager는 부팅 시 QueryManager.getColumnList()로 TV 컬럼(장르) 목록을 받아 캐싱하고, 사용자 환경설정 변경에 반응하도록 UserPreference에 리스너를 등록합니다. 숫자 키(VK_0~VK_9)는 채널 직접 입력을 위해 리스트 자체 키 처리에서 제외되어 상위로 전파됩니다.

설계 포인트
필터 패널과 채널 목록이 슬라이드 애니메이션으로 함께 움직이도록 ChannelListFrame에서 필터 버튼과 목록의 위치를 동기화합니다(_pendingOpenFilter). 장르 목록은 서버 컬럼 데이터를 캐싱해 화면 전환마다 재요청하지 않습니다.

흐름. 리스트가 열리면 GenreManager의 장르 목록으로 필터 패널을 구성하고, 사용자가 필터를 선택하면 채널 목록이 해당 기준으로 갱신됩니다. 숫자 키는 채널 직접 입력을 위해 상위로 전파됩니다.

핵심 코드

controller/ChannelListController.js — 숫자키 전파 · EXIT 처리
onKeyDown: function(keyEvent) {
    if (KeyEvent.VK_0 <= keyEvent.keyCode && keyEvent.keyCode <= KeyEvent.VK_9) {
        keyEvent.stopPropagation();   // 채널 직접 입력은 리스트가 가로채지 않음
        return;
    }
    switch (keyEvent.keyCode) {
        case KeyEvent.VK_EXIT:
            SYSAPP.OSDController.resetOSD(OSDConstant.CHANNEL_LIST, true);
            keyEvent.stopPropagation();
            break;
        default:
            this.channelListFrame.dispatchKeyDown(keyEvent);
    }
}
controller/GenreManager.js — 장르(TV 컬럼) 목록 초기화·캐싱
initGenre: function () {
    this.genreList = [];
    var parentCode = SYSAPP.UserConfigManager.getTvColumn();
    SYSAPP.QueryManager.getColumnList(parentCode, '1', '30', 5, function(result) {
        if (result.success && result.response) {
            if (result.response.returncode == "0" && result.response.totalcount > 0) {
                _self.makeGenreList(result.response.data);   // 필터용 장르 목록 캐싱
            }
        }
    }, true);
}
