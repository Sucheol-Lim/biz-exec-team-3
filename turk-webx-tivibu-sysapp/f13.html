기능 개요

다중 영상 화면은 메인 방송과 별도로 추가 영상을 동시에 보여 줍니다. 기반은 SystemInterface가 메인 VBO(getVBOMain)와 서브 VBO(getVBOSub)를 분리 관리한다는 점입니다. 서브 VBO는 video-pip DOM에 붙어 PIP(화면 속 화면)로 출력되며, 대부분의 VBO 제어 메서드가 isSub 플래그로 메인/서브를 구분해 같은 코드 경로를 공유합니다. PIP의 표시·프레임은 core/pip/PIPController·PIPFrame이 담당합니다.

모자이크 채널은 한 화면에 여러 채널 썸네일을 격자로 보여 주는 특수 채널입니다. LiveTVController가 모자이크 채널을 감지하면 OSDConstant.MOSAIC_CHANNEL을 띄우고, MosaicChannelController(ui/mosaic/MosaicChFrame)가 격자 렌더링과 키 입력을 처리합니다. 5채널 뷰는 리모컨으로 555를 입력하면 진입하는 카테고리형 VOD 화면으로, FiveChannelController가 메인 VOD를 구간별(인트로/카테고리 1~6)로 재생하고 숫자 키(0~6: 카테고리 점프, 7~47: 개별 VOD)에 대응합니다.

설계 포인트
PIP는 메인/서브 VBO를 isSub 인자 하나로 분기해 튜닝·컴포넌트 제어 코드를 재사용합니다. 5채널은 단일 메인 VOD를 시간 구간으로 나눠 카테고리 화면을 전환하는 방식으로, 별도 영상 다중 디코딩 대신 하나의 VOD 타임라인을 활용합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant KEM as KeyEventManager participant LTV as LiveTVController participant SI as SystemInterface participant PIP as PIPController participant MOS as MosaicChannelController participant FIVE as FiveChannelController alt 모자이크 채널 선택 LTV->>SI: isMosaicChannel(channel) LTV->>MOS: setOSD(MOSAIC_CHANNEL) MOS-->>MOS: 격자 채널 렌더링 end alt PIP 표시 PIP->>SI: getVBOSub() SI-->>PIP: video-pip 서브 VBO PIP-->>PIP: 서브 영상 튜닝(isSub=true) end alt 555 입력 KEM->>FIVE: '555' → show(param) FIVE->>FIVE: playVod(url) (메인 VOD 구간 재생) Note over FIVE: 숫자 0~6 카테고리 점프 / 7~47 개별 VOD end

흐름. 모자이크는 격자 채널을, PIP는 서브 VBO로 화면 속 화면을, 5채널은 555 입력으로 카테고리형 VOD를 재생합니다.
