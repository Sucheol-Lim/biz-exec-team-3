EPG / TV 가이드

GuideController가 2022 리뉴얼 UI(ui2022/guide/GuideFrame)를 띄우고 키 입력을 위임하며, 채널·시간·요일·장르 캐러셀과 프로그램 데이터 피드가 전체 편성표를 렌더링합니다.

기능 개요

TV 가이드는 전체 채널을 세로로, 시간대를 가로로 배치한 격자형 편성표(EPG)입니다. GuideController는 컨트롤러 층의 얇은 래퍼로, 생성 시 2022 리뉴얼 UI 위젯인 GuideFrame(app/ui2022/guide/GuideFrame)을 만들어 RootWindow에 프레임으로 등록합니다. 화면 표시·갱신·숨김은 RootWindow.showFrame/updateFrame/hideFrame으로 처리하고, 리모컨 키 이벤트는 KeyEventManager에 자신을 리스너로 등록한 뒤 guideFrame.dispatchKeyDown/Up/Press로 위임합니다.

편성 데이터 렌더링은 ui2022/guide 디렉토리의 여러 위젯이 분담합니다. 채널은 ChannelContainer·ChannelDataFeed가, 프로그램은 ProgramCarousel·ProgramDataFeed·ProgramDataManager가, 시간/요일/장르 축은 각각 TimeCarousel·DayCarousel·GenreCarousel이 담당합니다. 현재 시각을 표시하는 NowLine과 선택 프로그램의 상세를 보여주는 InfoPanel도 포함됩니다.

가이드에서 프로그램을 선택하면 프로그램 상세(TVDetail)로 연결되고, VK_EXIT 키는 OSDUtil.hideOSDRelatedWithMenu()로 메뉴 관련 OSD를 닫습니다. 상하좌우 방향키는 1.5초 이상 길게 누르면 300ms 간격으로 반복 스크롤되도록 getLongKeyInfo()에 정의되어 있습니다.

설계 포인트
가이드 UI는 데이터 피드(DataFeed) + 포매터(Formatter) + 캐러셀(Carousel) 조합으로 구성되어, 대량의 편성 데이터를 지연 로딩·가상화하면서 채널·시간·요일·장르 축을 독립적으로 스크롤할 수 있게 합니다. 컨트롤러는 키 위임과 프레임 lifecycle만 책임집니다.

흐름. GuideController.show()가 프레임을 띄우고 키 리스너를 등록하면, GuideFrame이 데이터 피드를 통해 편성표를 렌더링하고 방향키 입력에 따라 셀을 이동하며 정보 패널을 갱신합니다.

관계. GuideController는 GuideFrame을 소유하고 키 입력을 위임하며, 프레임은 ProgramDataFeed·ProgramDataManager로 편성 데이터를 받아 InfoPanel까지 렌더링합니다.

핵심 코드

controller/GuideController.js — 프레임 생성과 키 위임
init: function init(type) {
    this.frameName = 'guideFrame2022';
    this.guideFrame = new GuideFrame2022(this.frameName, Priority.GUIDE);
    SYSAPP.RootWindow.addFrame(this.guideFrame);
    SYSAPP.GuideController = this;
},

show: function show(param, entrance) {
    this.addKeyEventListener();
    SYSAPP.RootWindow.showFrame(this.frameName, param, entrance);
},

onKeyDown: function(keyEvent) {
    switch(keyEvent.keyCode) {
        case KeyEvent.VK_EXIT:
            SYSAPP.OSDUtil.hideOSDRelatedWithMenu();
            keyEvent.stopPropagation();
            break;
        default:
            this.guideFrame.dispatchKeyDown(keyEvent);   // 프레임으로 위임
    }
}
controller/GuideController.js — 방향키 롱프레스 정의
getLongKeyInfo: function() {
    return [
        { keyCode: KeyEvent.VK_UP,    duration: 1500, interval: 300 },
        { keyCode: KeyEvent.VK_DOWN,  duration: 1500, interval: 300 },
        { keyCode: KeyEvent.VK_LEFT,  duration: 1500, interval: 300 },
        { keyCode: KeyEvent.VK_RIGHT, duration: 1500, interval: 300 },
    ];
}
