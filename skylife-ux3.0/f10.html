시청예약 · 타이머

ProgramScheduleHandler가 편성 기반 시청예약·편성 조회(lookup/next/list)를, TimerHandler·TimerOverlay가 "N분 뒤 끄기" 타이머와 확인 카드·active pill을 처리합니다.

기능 개요

ProgramScheduleHandler는 program_schedule payload(spec §2.4)의 action을 분기합니다. lookup은 특정 시각·채널의 방송을, next는 채널의 다음 방송을 응답 카드로 안내하고, list는 편성표 화면(UI_GUIDE)으로 진입시킵니다. 채널은 번호 정확 매치/이름 정확·부분 매치/현재 채널 순으로 해석하고(resolveChannel), 시각은 ISO-8601 → 자연어 키워드(오늘/내일/지금) + query에서 한국어 시각("저녁 6시" 등) 추출 휴리스틱으로 보정합니다(parseWhen). 실제 편성은 EpgChannel.getPrograms()를 재사용합니다.

TimerHandler는 timer payload의 action(set/start → 설정, cancel/stop/end → 취소)을 처리합니다. duration 문자열("30m", "1h30m" 등)을 정규식으로 총 초로 변환해 TimerOverlay.showConfirmed(totalSec)를 호출하면, 상단 확인 카드가 약 4초 표시된 뒤 좌측 상단 active pill(TimerRingView 링 카운트다운)로 자동 전환됩니다. 발화 키워드 기반 로컬 타이머는 LocalIntentMatcher가 LLM을 거치지 않고 즉시 처리하기도 합니다.

설계 포인트
음성 패널(VoiceListeningOverlay)과 타이머 카드는 별도 lifecycle을 가집니다. 음성 패널은 ANSWER 상태로 발화 echo 후 사라지고, 타이머 카드는 자체적으로 확인 카드 → active pill 전환을 관리합니다. 실제 sleep 시점의 전원 off(AlarmManager 연결)는 Phase 2/3로 명시되어 있습니다.

흐름. timer는 duration을 초로 환산해 확인 카드/pill을 띄우고, program_schedule은 편성 조회 결과를 응답 카드로 안내합니다.

핵심 코드

assistant/handler/TimerHandler.java — duration 파싱 후 확인 카드
private static final Pattern DURATION_PATTERN =
        Pattern.compile("(?:(\\d+)h)?(?:(\\d+)m)?(?:(\\d+)s)?");

private static void handleSet(Context ctx, JsonObject body) {
    Integer totalSec = parseDurationToSeconds(optStr(body, "duration"));   // "1h30m" → 초
    if (totalSec == null || totalSec <= 0) {
        AnswerHandler.fallback(ctx, "시간을 알아듣지 못했어요.");
        return;
    }
    TimerOverlay.get(ctx).showConfirmed(totalSec);          // 확인 카드 → active pill
    String spoken = formatHMS(totalSec) + " 후에 꺼드릴게요";
    SpeechManager.get().speak(spoken);
}
assistant/handler/ProgramScheduleHandler.java — 편성 lookup 응답
private static void handleLookup(Context ctx, JsonObject body) {
    EpgChannel ch = resolveChannel(body);                   // 번호/이름/현재 채널
    long t = parseWhen(optStr(body, "when"), optStr(body, "query"));
    Program[] progs = ch.getPrograms(t, t + 1L);
    if (progs == null || progs.length == 0) {
        showAnswer(ctx, body, ch.getName() + " 채널의 그 시간 편성 정보가 없어요");
        return;
    }
    Program p = progs[0];
    String answer = String.format("%s 채널 %s '%s' 가 %s",
            ch.getName(), formatWindow(p.getStartTime(), p.getEndTime()), p.getTitle(), verb);
    showAnswer(ctx, body, answer);                          // AnswerCard + TTS
}
