STB 제어 명령

StbControlHandler가 채널(set/step)·볼륨(set/step/mute)·전원·미디어·녹화·내비게이션·앱 실행·자막·오디오 도메인의 음성 명령을 처리합니다. 채널/앱/화면 이동은 기존 TTUILinkManager.handleLink()를, 볼륨은 AudioManager를 재사용합니다.

기능 개요

StbControlHandler.handle(ctx, body)는 stb_control payload의 domain/action 조합을 매트릭스로 분기합니다(spec §9). 현재 Phase 1에서 실제 동작하는 도메인은 channel(set/step), volume(set/step/mute/unmute), app(open), navigation(open), search(open/query)이며, media·power·record·subtitle·audio는 안내 fallback과 함께 Phase 2/3로 예약되어 있습니다.

채널 set은 채널 번호를 받아 resolveChannelNumber()로 검증한 뒤 TTUILinkManager.handleLink(LINK_C, ...)로 튜닝합니다. LLM이 채널명을 모르고 환각 번호("MBC"→206506131 등)를 보내면 RING_ACCESSIBLE 목록을 STT prompt로 fuzzy 매치해 실제 번호로 교정합니다. 볼륨은 AudioManager의 setStreamVolume/adjustStreamVolume으로 처리하고, 앱 실행은 AppIdMapping(spec appId → 패키지명), 화면 이동은 DestinationMapping(destination → linkType/param)으로 매핑합니다.

설계 포인트
모든 UI 변경(채널/앱/화면 이동)은 new Handler(Looper.getMainLooper()).post(...)로 메인 스레드에서 handleLink를 호출합니다. 명령 실행 후에는 markResult()로 음성 패널을 RESULT 상태로 전환하고 STT transcript를 그대로 표시한 뒤 2.5초 후 자동 숨김 처리합니다.

assistant/handler/StbControlHandler.java — 채널명 fuzzy 매치(LLM 환각 번호 방어)
private static String resolveChannelNumber(String chno) {
    if (chno != null && chno.matches("\\d+")) {                 // 1. 정확 매치
        EpgChannel exact = EpgChannelManager.getInstance()
                .getValidChannel(EpgChannelRing.RING_ACCESSIBLE, Integer.parseInt(chno));
        if (exact != null) return chno;
    }
    String prompt = WakeStatusProvider.getLastSttText();        // 2. STT prompt fuzzy
    String norm = prompt.toLowerCase(Locale.KOREA).replaceAll("\\s+", "");
    for (EpgChannel c : EpgChannelManager.getInstance().getChannels(EpgChannelRing.RING_ACCESSIBLE)) {
        String cnLower = c.getName().toLowerCase(Locale.KOREA).replaceAll("\\s+", "");
        if (c.getName().length() >= 2 && norm.contains(cnLower)) return String.valueOf(c.getNumber());
    }
    return null;                                                // 3. 실패
}
