채널·편성표(EPG)

ui/channel과 controller/nav의 EpgChannelController·EpgChannelManager가 채널 링·편성표·프로그램 정보를 구성합니다. 채널 링(EpgChannelRing)으로 용도별 채널 집합을 구분하고, EpgChannel.getPrograms()로 시간대별 편성 정보를 제공합니다.

기능 개요

채널 데이터는 EpgChannelManager가 보유·관리합니다. 채널은 용도별 "링(ring)"으로 분류되어 EpgChannelRing에 상수로 정의됩니다. 예를 들어 RING_ACCESSIBLE(DCA·시청 가능 채널), RING_SURFABLE(채널 업/다운·미니 가이드), RING_SURFABLE_ALL(채널 가이드), RING_BLOCKED/RING_SKIPPED 등이 있습니다. getChannels(ringType)·getValidChannel(ringType, channelNum)로 링별 채널 목록과 특정 번호 채널을 조회합니다.

편성표 화면은 ui/channel의 TTCCChannelGuideFragment가 구성하며, 각 EpgChannel은 getPrograms(since, until)로 시간 구간의 af.epg.Program 배열을 제공합니다. 음성 어시스턴트의 program_schedule 명령(lookup/next/list)도 이 API를 그대로 재사용해 특정 시각·채널의 방송을 조회하거나 편성표 화면(UI_GUIDE)으로 진입시킵니다.

설계 포인트
음성 명령이 채널명을 부정확하게 전달해도(LLM hallucination 번호 등) RING_ACCESSIBLE 목록을 STT prompt로 fuzzy 매치해 실제 채널 번호로 교정합니다. 즉 채널 링은 시청 UI뿐 아니라 음성 라우팅의 신뢰 가능한 ground truth로도 쓰입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 사용자 / program_schedule participant GF as TTCCChannelGuideFragment participant ECC as EpgChannelController participant ECM as EpgChannelManager participant CH as EpgChannel participant P as Program (af.epg) U->>GF: 편성표 진입 (UI_GUIDE) GF->>ECM: getChannelsForGuide(RING_SURFABLE_ALL) ECM-->>GF: List~EpgChannel~ GF->>CH: getPrograms(since, until) CH-->>GF: Program[] (편성 정보) GF-->>U: 채널 x 시간 그리드 렌더링 Note over ECC,ECM: 현재 채널 / 링별 집합 제공

흐름. 편성표 fragment가 EpgChannelManager에서 가이드용 채널 링을 받아 각 채널의 프로그램을 조회해 그리드로 렌더링합니다.

관계. 싱글턴 EpgChannelManager가 링 상수(EpgChannelRing)로 채널 집합을 구분해 EpgChannel을 제공하고, 각 채널이 Program 편성을 반환합니다.

핵심 코드

controller/nav/channel/EpgChannelRing.java — 용도별 채널 링 상수
public static final String RING_ALL = "ALL";
public static final String RING_ACCESSIBLE = "ACCESSABLE";       // dca
public static final String RING_SURFABLE = "SURFABLE";           // ch up/down, miniguide
public static final String RING_SURFABLE_ALL = "SURFABLE_ALL";   // ch guide
public static final String RING_SURFABLE_SETTING = "SURFABLE_SETTING"; // ch setting
public static final String RING_BLOCKED = "BLOCKED";
public static final String RING_SKIPPED = "SKIPPED";
assistant/handler/ProgramScheduleHandler.java — 편성 lookup이 EPG API 재사용
EpgChannel ch = resolveChannel(body);                  // 번호/이름/현재 채널 해석
long t = parseWhen(optStr(body, "when"), optStr(body, "query"));
Program[] progs = ch.getPrograms(t, t + 1L);           // EpgChannel.getPrograms 그대로 사용
if (progs == null || progs.length == 0) {
    showAnswer(appContext, body, ch.getName() + " 채널의 그 시간 편성 정보가 없어요");
    return;
}
Program p = progs[0];
String answer = String.format("%s 채널 %s '%s' 가 %s",
        ch.getName(), formatWindow(p.getStartTime(), p.getEndTime()), p.getTitle(), verb);
