개요

본 과제는 KT 스카이라이프(SKYLIFE) Android TV 셋톱박스(STB)에 탑재되는 EPG(전자 프로그램 가이드) 겸 홈 런처 애플리케이션입니다. 실시간 방송(Live TV), VOD, 채널 편성표, 통합 검색, 마이페이지, 설정, 결제 등 STB의 메인 UI 전반을 담당합니다. 패키지명과 애플리케이션 ID는 모두 com.alticast.androidtv.epg이며, AndroidX Leanback 기반의 Android TV 앱으로 구현되어 있습니다.

이 앱은 단순한 일반 앱이 아니라 STB의 홈/런처로 동작합니다. 메인 화면인 MainActivity가 HOME·LAUNCHER 카테고리와 af.intent.action.KEY_TV_HOME 인텐트 필터를 가지고 singleInstance 모드로 기동되어, 단말 부팅 후 첫 화면과 홈 키 입력의 진입점이 됩니다. 단말 세대에 따라 second와 fifth 두 가지 STB flavor로 빌드되며, flavor별로 별도의 MainActivity·매니페스트·네이티브 라이브러리(jniLibs)·CAS 스텁을 사용합니다.

분석 기준 브랜치 feat/lw-voice-api에는 LW Voice 모바일-STB 음성 어시스턴트 기능이 추가되어 있습니다. 모바일 앱과 STB를 페어링하여 음성 명령(채널/볼륨 제어, 콘텐츠 검색·재생, 시청예약, 타이머, 날씨·뉴스 응답, 화면 제어 등)을 STB에서 실행하고, "헤이 스카이" wake-word와 STT를 통한 로컬 음성 입력도 지원합니다. 이 기능은 두 개의 사양 문서(newlwvoice-connect.pdf v1.3, stb_assistant_response_api_spec.pdf v1.3)를 근거로 구현되어 있습니다.

사업 맥락
LW Voice는 당초 터키 TurkCell 향 음성 제어 솔루션 PoC로 출발하였고, 이후 Altimedia(AX/DX Client Team)가 만드는 런처·앱의 차별화 수단으로 확장된 음성 어시스턴트입니다. 본 브랜치는 그 음성 어시스턴트를 스카이라이프 UX3.0 EPG 위에 통합한 작업 라인입니다. (배경은 Confluence "LWVoice 개요" 근거)

주요 기능

홈 런처
MainActivity가 HOME·LAUNCHER·KEY_TV_HOME 인텐트로 동작하는 STB 메인 화면입니다. 부팅 후 첫 화면과 홈 키 진입점을 담당하며 singleInstance로 기동됩니다.
실시간 방송(Live TV)
ui/livetv 화면에서 실시간 채널 시청과 채널 전환, 미니 가이드, 플레이바 등을 제공합니다.
VOD 재생
ui/vod에서 VOD 상세·시리즈·본편/예고편 재생, 이어보기, 구매(OPPV) 연동을 제공합니다. Media3(ExoPlayer) 1.2.0 기반입니다.
채널·편성표(EPG)
ui/channel과 controller/nav의 EpgChannelController가 채널 링·편성표·프로그램 정보를 구성합니다.
통합 검색
ui/search에서 보유 콘텐츠 검색을 제공하며, 음성 어시스턴트의 콘텐츠 검색 결과가 TTSearchFragment로 자동 입력·실행되도록 통합되어 있습니다.
설정 · 마이페이지
ui/setting(SettingMainActivity)과 ui/mypage에서 환경 설정, 시청시간 제한, 잠금/비밀번호, 가입 정보 등을 관리합니다.
LW Voice 음성 어시스턴트
모바일 앱과 STB를 페어링하여 음성 명령을 STB에서 실행합니다. NanoHTTPD WebSocket(8787 포트) 기반 릴레이 서버로 양방향 통신합니다.
STB 제어 명령
StbControlHandler가 채널(set/step)·볼륨(set/step/mute)·전원·미디어·녹화·내비게이션·앱 실행·자막·오디오 도메인의 음성 명령을 처리합니다.
콘텐츠 검색·재생 음성 명령
ContentSearchHandler·ContentPlayHandler가 음성으로 받은 검색어로 결과를 찾아 검색 화면 또는 VOD 상세·자동 재생으로 직행시킵니다.
시청예약 · 타이머
ProgramScheduleHandler가 편성 기반 시청예약을, TimerHandler·TimerOverlay가 "N분 뒤 끄기" 타이머와 알림음을 처리합니다.
날씨 · 뉴스 · 일반 응답
AnswerHandler가 weather/news/general 답변을 응답 카드로 표시합니다. WeatherType·WeatherSceneView로 날씨 유형별 애니메이션을 보여줍니다.
Hey Sky wake-word + STT
:wake-lib(sky-claw) 엔진이 wake-word 감지와 STT를 같은 프로세스에서 처리하고, SpeechManager가 결과를 라우팅합니다. 발화 중에는 LiveTvMuter로 본방송을 음소거합니다.
오버레이 UI
AssistantOverlayCoordinator가 외부 앱 위에 청취 오버레이·응답 카드·페어링·타이머·파형(HeySkyWaveformView) 등을 표시합니다.
FCM 푸시 · TTS
Firebase Messaging 기반 푸시(FCMService)를 처리하고, AndroidTtsEngine/RemoteQwenTtsEngine(TtsEngine 추상화)로 음성 응답을 발화합니다.

핵심 동작 흐름

음성 명령 처리 흐름 (모바일 페어링 경로)

  1. 디스커버리 · 페어링StbDiscoveryAdvertiser가 NSD(_lwcompanion._tcp.)와 UDP(LW_COMPANION_DISCOVER_V1)로 STB를 노출하고, 모바일 앱이 8787 포트의 /assistant-ws WebSocket으로 연결하여 MobileSession을 수립합니다.
  2. 음성 입력 · 서버 처리사용자 발화가 모바일/서버에서 인식·해석되어 assistant_response envelope(payload.type + body)로 STB에 전달됩니다.
  3. envelope 파싱 · 분기AssistantResponseDispatcher가 envelope.type을 검사하고 assistantReply를 JSON 파싱한 뒤 payload.type별 핸들러로 분기합니다. 파싱 실패·미지원 타입 등 5종 방어 케이스는 실행을 막고 자연어 fallback으로 처리합니다.
  4. 명령 실행예를 들어 stb_control은 StbControlHandler가 채널/볼륨 등을 EpgChannelManager·AudioManager로 실행하고, content_play는 검색어로 첫 결과를 찾아 VOD 상세 진입 후 자동 재생합니다.
  5. 응답 표시 · 피드백AssistantOverlayCoordinator가 응답 카드/오버레이를 외부 앱 위에 표시하고 TTS로 발화합니다. 발화 동안 LiveTvMuter가 본방송을 음소거하며, VOD 화면은 AssistantVodSnapshotSender가 모바일로 스냅샷을 전송합니다.

Hey Sky 로컬 음성 흐름 (On-device 경로)

  1. wake-word 감지:wake-lib(sky-claw) 엔진이 "헤이 스카이" wake-word를 감지하면 청취 상태로 전환하고 VoiceListeningOverlay·파형 뷰(HeySkyWaveformView)를 표시합니다.
  2. STT 변환동일 프로세스의 STT가 발화를 텍스트로 변환하고, SpeechManager가 결과를 라우팅합니다. 발화 화면에는 STT transcript가 그대로 노출됩니다.
  3. 로컬 매칭 또는 라우팅LocalIntentMatcher가 채널/볼륨 업·다운 등 로컬 키워드를 매칭해 즉시 실행하거나, 검색·콘텐츠 명령은 검색 화면(TTSearchFragment 자동 입력)·VOD 경로로 직행시킵니다.
  4. 결과 표시응답 카드 표시 시 발화 오버레이는 즉시 dismiss되고, 명령 결과가 화면에 반영됩니다.

홈 런처 부팅 · 진입 흐름

  1. Application 기동EpgApplication이 EPG 프로세스를 초기화하고 부팅·FW 설치 상태를 점검하며 전역 데이터 매니저와 wake-word 서비스를 준비합니다.
  2. MainActivity 진입HOME/LAUNCHER/KEY_TV_HOME 인텐트로 flavor별 MainActivity가 singleInstance로 표시되어 홈 화면(ui/tvhome)을 구성합니다.
  3. 데이터 로딩 · 네비게이션controller/communication의 서버 클라이언트로 편성·콘텐츠 데이터를 받아 채널 링·홈 행을 구성하고, 사용자 입력에 따라 Live TV·VOD·검색·설정 화면으로 전환합니다.

빌드 · 실행

루트에 gradlew 래퍼 스크립트는 커밋되어 있지 않으므로 Android Studio에서 열거나 시스템에 설치된 Gradle을 사용합니다. flavor 차원은 stb(second/fifth), cas(_nagra/_alti), server(_live 기본 / _test) 세 가지이며, deviceparam 프로퍼티로 특정 STB 세대만 빌드하도록 variant를 필터링합니다.

빌드 전제 조건
:wake-lib 모듈은 settings.gradle에서 ../stb-wake/wake-lib(별도 git repo, sky-claw)를 참조합니다. 본 저장소에는 포함되어 있지 않으므로 동일 상위 디렉토리에 stb-wake 저장소를 먼저 체크아웃해야 합니다. 릴리즈 서명 정보는 gradle.properties의 RELEASE_STORE_FILE(../app/keystore/skylife_lte_android.jks) 등으로 지정됩니다. 
# 전체 디버그 빌드 (가능한 variant 조합 전부)
./gradlew assembleDebug

# fifth STB만 빌드하도록 device 파라미터 지정
./gradlew assembleDebug -Pdeviceparam=fifth

# 예: fifth + nagra + live 서버 릴리즈 빌드
./gradlew assembleFifthNagra_liveRelease -Pdeviceparam=fifth

# 클린
./gradlew clean

# Releaseworks: changelog / release note 생성
./gradlew :Releaseworks:generateAll

주요 환경 설정 파일은 다음과 같습니다. 버전은 app/version.properties의 VERSION(현재 03.00.02.022)을 기준으로 auto-version.gradle이 증가시키며, 형식은 UX버전.송출버전.revision 계열입니다. Firebase 설정은 app/google-services.json, 서명 키는 app/keystore/, flavor별 벤더 라이브러리는 app/libs/{second,fifth}/에 위치합니다.

산출물 APK 파일명은 skylife_epg_<versionName>_<flavor>_<buildType>.apk 규칙으로 생성됩니다.
