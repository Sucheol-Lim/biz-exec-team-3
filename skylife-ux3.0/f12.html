Hey Sky wake-word + STT

:wake-lib(sky-claw) 엔진이 "헤이 스카이" wake-word 감지와 STT를 같은 프로세스에서 처리하고, WakeStatusProvider.SttResultListener(AssistantRequestPump)가 결과를 로컬 명령·LLM으로 라우팅합니다. 발화 중에는 LiveTvMuter로 본방송을 음소거합니다.

기능 개요

로컬 음성 입력은 외부 git repo :wake-lib(sky-claw)의 WakeWordService가 담당합니다. EpgApplication이 메인 프로세스에서 이 서비스를 foreground로 기동하면 wake-word("헤이 스카이") 감지와 STT가 같은 프로세스 안에서 동작합니다(IPC 불필요). STT 결과는 WakeStatusProvider.SttResultListener 콜백으로 ux3.0 측에 전달됩니다.

라우팅은 AssistantRequestPump가 등록한 리스너가 수행합니다. wake-lib의 1차 필터(CommandMatcher)가 매칭한 명령은 onCommandMatched로 즉시 실행(LLM 0회), 미매칭(onUnknownStt) 텍스트는 ux3.0의 2차 필터 LocalIntentMatcher로 넘겨 채널·볼륨·앱·타이머·화면 등 로컬 키워드를 즉시 처리하고, 그것도 안 되면 모바일 LLM(assistant_request)으로 forward합니다. 모바일 세션이 없으면 LLM 라우팅을 건너뛰고 "LLM이 연결되어 있지 않아요" 오류를 표시합니다.

설계 포인트
onWake 시점부터 LiveTvMuter.acquire(STT_REASON)로 본방송을 음소거하고, onUnknownStt/onCommandMatched/onSttError에서 release합니다. STT와 TTS의 mute reason이 다르므로 STT→TTS 연속 발화에서도 음소거가 끊기지 않습니다. STT race로 같은 prompt가 ms 차로 두 번 와도 1.5초 dedupe 윈도우로 중복 송신을 막습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant WL as wake-lib (sky-claw) participant L as SttResultListener (AssistantRequestPump) participant MUT as LiveTvMuter participant LIM as LocalIntentMatcher participant PUMP as AssistantRequestPump.send participant VO as VoiceListeningOverlay WL->>L: onWake() L->>MUT: acquire(STT) WL->>L: onSttReady() L->>VO: setListeningReady() WL->>L: onUnknownStt(text) L->>MUT: release(STT) alt LocalIntentMatcher 매칭 L->>LIM: tryDispatch(text) → 즉시 실행 L->>VO: RESULT (Route LOCAL) else 모바일 LLM L->>PUMP: send(text) (assistant_request) L->>VO: PROCESSING (Route LLM) end

흐름. wake → STT 준비 → 결과 콜백에서 로컬 명령을 즉시 처리하거나 모바일 LLM으로 forward하며, 발화 동안 본방송을 mute합니다.

클래스 다이어그램

classDiagram class WakeWordService { <<wake-lib>> } class WakeStatusProvider { <<wake-lib>> +setSttListener(listener) +getLastSttText() String } class SttResultListener { <<interface>> +onWake() +onSttReady() +onUnknownStt(text) +onCommandMatched(text, cmd, label, ok) +onSttError(reason) } class AssistantRequestPump { +start(ctx) -send(prompt) +invalidateCurrent() } class LocalIntentMatcher { +tryDispatch(ctx, text) boolean } class LiveTvMuter { +acquire(reason) +release(reason) } WakeStatusProvider --> SttResultListener : 콜백 AssistantRequestPump ..|> SttResultListener : 구현 등록 AssistantRequestPump --> LocalIntentMatcher : 2차 필터 AssistantRequestPump --> LiveTvMuter : STT mute WakeWordService --> WakeStatusProvider : STT 결과 push

관계. wake-lib가 WakeStatusProvider로 결과를 push하고, AssistantRequestPump가 리스너로 받아 로컬/LLM 라우팅과 본방송 mute를 조율합니다.

핵심 코드

assistant/AssistantRequestPump.java — STT 결과 라우팅(로컬 → LLM)
@Override
public void onUnknownStt(String text) {
    LiveTvMuter.release(STT_REASON);
    if (LocalIntentMatcher.tryDispatch(appContext, text)) {       // 2차 필터 — 로컬 즉시 처리
        VoiceListeningOverlay.setState(VoiceListeningOverlay.State.RESULT);
        VoiceListeningOverlay.setRoute(VoiceListeningOverlay.Route.LOCAL);
        return;
    }
    if (!isMobileSessionReady()) {                                // 모바일 미연결 → 즉시 ERROR
        VoiceListeningOverlay.setErrorMessage("LLM이 연결되어 있지 않아요",
                "QR 코드로 LLM에 연결한 뒤 다시 말씀해주세요");
        return;
    }
    VoiceListeningOverlay.setState(VoiceListeningOverlay.State.PROCESSING);
    VoiceListeningOverlay.setRoute(VoiceListeningOverlay.Route.LLM);
    send(text);                                                   // 모바일 LLM forward
}
assistant/util/LiveTvMuter.java — reason 기반 refcount mute
public static void acquire(String reason) {
    synchronized (LOCK) {
        boolean wasEmpty = reasons.isEmpty();
        if (reasons.add(reason) && wasEmpty) doMute(true);        // STT/TTS reason 합산
    }
}
public static void release(String reason) {
    synchronized (LOCK) {
        if (reasons.remove(reason) && reasons.isEmpty() && muted) doMute(false);
    }
}
