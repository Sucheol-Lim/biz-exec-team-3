VOD 재생

ui/vod에서 VOD 상세·시리즈·본편/예고편 재생, 이어보기, 구매(OPPV) 연동을 제공합니다. TTVodDetailFragment가 상세 화면과 권한 분기를, TTVodPlayFragment가 Media3(ExoPlayer) 1.2.0 기반 재생을 담당합니다.

기능 개요

VOD 흐름은 상세 화면(TTVodDetailFragment)에서 출발합니다. 단편은 CMSDefV3.LINK_CD, 시리즈는 LINK_SD 링크로 진입하며, TTVodViewModel이 VodMasterContent(본편·회차·구매 상태)를 로드합니다. 사용자가 재생 버튼을 누르면 권한(구매/월정액/무료)을 판정해 readyToPlay() 또는 이어보기 흐름으로 진입하고, 미구매면 OPPV(One-time Pay-Per-View) 구매 버튼을 노출합니다.

실제 재생은 vod/play/TTVodPlayFragment가 맡고 AndroidX Media3(ExoPlayer) 1.2.0을 사용합니다. 예고편은 TTVodPreviewDialogFragment, 광고는 TTAdPlayer, 등급 안내는 TTRatingBoardPlayer, 재생바는 TTVodPlayBarComp가 담당합니다. 음성 어시스턴트의 content_play 명령은 이 상세 화면을 재사용해 자동 재생을 트리거합니다.

설계 포인트
음성 "content_play" 자동 재생은 ContentPlayHandler.PENDING_AUTO_PLAY(AtomicBoolean) 신호를 detail 진입 직전에 set 합니다. TTVodDetailFragment는 데이터 로드 완료 시점에 tryLwVoiceAutoPlayHook()으로 이 신호를 1회 consume 하고, 권한이 OK(buyYN != "N" 또는 price 0 또는 월정액 포함)면 readyToPlayAuto()로 자동 재생, NG면 detail 화면을 그대로 노출해 사용자 결정에 맡깁니다.

핵심 코드

ui/vod/TTVodDetailFragment.java — content_play 자동 재생 권한 판정
private boolean tryLwVoiceAutoPlay() {
    VodMasterContent vmc = viewModel.getVodMasterContent();
    if (vmc == null) return false;                 // 데이터 미로드 → 호출자가 retry
    ContentV3 main = vmc.getMainContent();
    if (main == null) return true;                 // 시리즈 등 — detail 노출

    // 권한 판정 — 구매했거나 무료(price 0) 또는 월정액 포함일 때만 자동 재생.
    String buyYN = main.buyYN == null ? "" : main.buyYN.toUpperCase();
    boolean isPurchased = !buyYN.isEmpty() && !"N".equals(buyYN);
    boolean isFree = "0".equals(main.contentPrice);
    boolean seriesBought = "Y".equalsIgnoreCase(vmc.buySeries)
            || "P".equalsIgnoreCase(vmc.buySeries);
    if (!(isPurchased || isFree || seriesBought)) return true;  // 미구매 → detail 노출

    viewModel.setSelectedContent(main);
    viewModel.readyToPlayAuto();                   // 이어보기 jumpingPoint 자동
    return true;
}
