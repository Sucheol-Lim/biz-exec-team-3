실시간 방송(Live TV)

ui/livetv 화면이 실시간 채널 시청과 채널 전환, 미니 가이드(MiniEPG), 플레이바를 제공합니다. 영상 표면은 MainFragment의 main_video_layer가 담당하고, 실제 튜닝·재생은 EpgChannelController와 MediaPlayerHandler가 수행합니다.

기능 개요

실시간 방송 화면은 ui/livetv 패키지가 구성합니다. MainFragment가 main_video_layer 레이아웃을 inflate해 전체화면·홈화면용 iframe 레이어를 제공하고, 미니 가이드(miniepg/fragment/MiniEpgFragment), 채널 변경 시 잠깐 뜨는 DCA(livetv/dca/DcaComp), 플레이 정보(PlayInfoFragment), 타임시프트(TimeShiftFragment) 등의 컴포넌트가 함께 배치됩니다.

채널 전환은 채널 키(CH +/−)나 번호 입력, 미니 가이드 선택을 통해 일어나며, 실제 튜닝은 EpgChannelController의 changeChannel()/changeChannelForce()로 위임됩니다. 컨트롤러는 위성(SAT)·DCS·IP backup 모드를 관리하며 튜닝 이벤트(onTuningEvent)·채널 이벤트(onChannelEvent)를 받아 화면을 갱신합니다. IP FCC 환경에서는 stop → start → fcc prime을 하나의 메인 UI 스레드에서 처리하면서 채널 키 밀림을 줄이는 튜닝 최적화(TUNING_IPFCC_FAST_CHUD_*)가 들어 있습니다.

설계 포인트
음성 어시스턴트의 본방송 음소거(LiveTvMuter)는 시스템 볼륨이 아니라 MediaPlayerHandler.setMute()(SkyChannelPlayer)를 직접 호출합니다. Skylife STB에서 STREAM 분리가 안 되기 때문에 player 컴포넌트 자체를 mute 하는 경로만 동작합니다. 실시간 방송 재생 컴포넌트를 직접 제어하는 이 단일 진입점 덕분에 STT/TTS 발화 동안 본방송이 깔끔하게 음소거됩니다.

흐름. 채널 키 입력이 EpgChannelController.changeChannel로 전달되어 MediaPlayerHandler가 튜닝하고, 성공 이벤트를 받아 미니 가이드와 플레이바가 갱신됩니다.
