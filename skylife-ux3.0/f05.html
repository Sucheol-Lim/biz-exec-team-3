통합 검색

ui/vod/search의 TTSearchFragment가 보유 콘텐츠 검색을 제공하며, 음성 어시스턴트의 content_search 결과가 applyLwVoiceQuery()를 통해 검색 화면에 자동 입력·실행되도록 통합되어 있습니다.

기능 개요

검색 화면은 ui/vod/search/TTSearchFragment(TTDataLoadFragment 상속)가 담당합니다. 사용자가 입력한 검색어로 TTSearchViewModel.loadSearchVodListV3()를 호출해 VOD/콘텐츠 라이브러리를 조회하고, 결과는 TTSearchResultListFragment로 표시됩니다. 최근 검색어, 키워드 리스트, 결과 리스트 사이의 포커스 전환을 자체적으로 관리합니다.

음성 어시스턴트의 content_search payload는 ContentSearchHandler가 처리합니다. 검색 화면이 이미 top이면 새 인스턴스를 push하지 않고 applyLwVoiceQuery()로 query만 갱신하고(결과창 중첩 방지), 아니면 TTUIManager.goToScreen(UI_UTIL_SEARCH_M, args)로 진입하며 lwvoice_query 인자를 전달합니다. fragment는 진입 시 이 인자를 읽어 자동 입력 + 검색을 1회 실행하고 회전·재진입 중복을 막기 위해 즉시 인자를 제거합니다.

설계 포인트
applyLwVoiceQuery()는 입력 필드에 검색어를 채우되 IME(소프트 키보드)가 자동으로 뜨지 않도록 focusHide로 포커스를 옮기고 IME를 강제 hide합니다. 음성 진입이므로 화면 키보드가 불필요하기 때문이며, 포커스를 FOCUS_KEYWORD_LIST 단계로 두어 결과 도착 시 자동으로 결과 리스트로 전환되게 합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant ARD as AssistantResponseDispatcher participant CSH as ContentSearchHandler participant UIM as TTUIManager participant SF as TTSearchFragment participant VM as TTSearchViewModel ARD->>CSH: handle(body) (payload content_search) CSH->>UIM: getVisibleTopFragment() alt 검색 fragment 가 이미 top CSH->>SF: applyLwVoiceQuery(query) else 다른 화면 CSH->>UIM: goToScreen(UI_UTIL_SEARCH_M, {lwvoice_query}) UIM->>SF: 진입 + args 읽어 applyLwVoiceQuery end SF->>SF: searchInput.setText + IME hide SF->>VM: loadSearchVodListV3(query, true) VM-->>SF: 검색 결과 (자동 결과 리스트 전환)

흐름. 음성 검색어가 검색 화면으로 라우팅되어 자동 입력·실행되며, 화면이 이미 떠 있으면 query만 갱신해 결과창 중첩을 막습니다.

클래스 다이어그램

관계. ContentSearchHandler가 TTUIManager로 검색 화면을 띄우거나 떠 있는 TTSearchFragment에 직접 query를 주입하고, fragment는 TTSearchViewModel로 검색을 수행합니다.

핵심 코드

ui/vod/search/TTSearchFragment.java — 음성 검색어 자동 입력 + 실행
public void applyLwVoiceQuery(String query) {
    if (query == null || query.isEmpty()) return;
    if (searchInputTextView != null) searchInputTextView.setText(query);
    strSearchKeyWord = query;
    updateSearchInputTextUi();                 // placeHolder 숨겨 입력어 노출
    // 음성 진입 — IME 불필요. focusHide 로 옮기고 키보드 강제 hide.
    if (binding != null && binding.focusHide != null) binding.focusHide.requestFocus();
    nCurrentFocusItem = FOCUS_KEYWORD_LIST;     // 결과 도착 시 결과 리스트로 자동 전환
    if (viewModel != null) viewModel.loadSearchVodListV3(query, true);
}
assistant/handler/ContentSearchHandler.java — 떠 있으면 재사용, 아니면 진입
Fragment top = TTUIManager.getInstance().getVisibleTopFragment();
if (top instanceof TTSearchFragment) {
    ((TTSearchFragment) top).applyLwVoiceQuery(finalQuery);   // refresh — 결과창 중첩 방지
} else {
    Bundle args = new Bundle();
    args.putString("lwvoice_query", finalQuery);
    TTUIManager.getInstance().goToScreen(TTUIManager.UI_UTIL_SEARCH_M, args);
}
