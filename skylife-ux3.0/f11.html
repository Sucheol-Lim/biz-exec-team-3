날씨 · 뉴스 · 일반 응답

AnswerHandler가 weather/news/general 답변을 응답 카드(AnswerCardOverlay)로 표시하고 TTS로 발화합니다. weather는 WeatherType enum으로 분류해 WeatherSceneView가 날씨 유형별 애니메이션을 그립니다.

기능 개요

대화형 답변(날씨·뉴스·일반 지식)은 AnswerHandler.handle(ctx, type, body)가 처리합니다. body.answer 텍스트를 응답 카드로 띄우고 SpeechManager.speak()로 발화한 뒤 발화 종료 시점에 카드를 잠깐 더 보여주고 숨깁니다(hideAfter(800L)). 답변이 비어 있으면 ERROR fallback으로 처리합니다.

weather payload는 추가로 body.weather_type을 WeatherType enum(CLEAR/CLOUDY/RAIN/SNOW/UNKNOWN)으로 파싱합니다. AnswerCardOverlay.finishStreamingAnswer()가 최종 텍스트와 함께 WeatherSceneView에 weather_type을 넘겨 맑음/흐림/비/눈 별 장면 애니메이션을 그립니다. weather/news/general은 assistant_progress로 스트리밍 중 이미 같은 카드를 띄워두므로, 최종 응답에서는 카드를 다시 새로 띄우지 않고 같은 카드의 텍스트·날씨 장면만 확정해 "갈아엎히는" 느낌을 줄입니다. assistantReply가 JSON이 아닌 자연어로 오면 freeFormAnswer()로 그대로 카드에 표시합니다.

설계 포인트
WeatherType.fromString()은 알 수 없는 값을 모두 UNKNOWN으로 정규화해 LLM이 비표준 문자열을 보내도 화면이 깨지지 않게 합니다. 응답 카드 표시 시 음성 패널(VoiceListeningOverlay)도 ANSWER 상태로 함께 유지해 "말씀드리는 중" 표시 표면을 보존합니다.

핵심 코드

assistant/handler/AnswerHandler.java — 답변 카드 + 날씨 장면 + TTS
private static void finishStreamingAnswer(Context ctx, String answer, WeatherType weatherType) {
    String question = WakeStatusProvider.getLastSttText();
    AssistantOverlayCoordinator.beforeAnswer(ctx);
    VoiceListeningOverlay.setState(VoiceListeningOverlay.State.ANSWER);
    VoiceListeningOverlay.setTranscript(null, question);
    AnswerCardOverlay overlay = AnswerCardOverlay.get(ctx);
    // assistant_progress 로 이미 떠 있는 같은 카드를 최종 텍스트 + weather scene 으로 확정.
    overlay.finishStreamingAnswer(question, answer, AssistantUiTokens.ACCENT_ANSWER, true, weatherType);
    SpeechManager.get().speak(answer, () -> overlay.hideAfter(800L));
}
assistant/handler/WeatherType.java — weather_type 정규화
public enum WeatherType {
    CLEAR, CLOUDY, RAIN, SNOW, UNKNOWN;
    public static final String FIELD = "weather_type";

    public static WeatherType fromString(String s) {
        if (s == null) return UNKNOWN;
        switch (s.trim().toLowerCase(Locale.ROOT)) {
            case "clear":  return CLEAR;
            case "cloudy": return CLOUDY;
            case "rain":   return RAIN;
            case "snow":   return SNOW;
            default:       return UNKNOWN;   // 비표준 값 방어
        }
    }
}
