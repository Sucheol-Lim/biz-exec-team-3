콘텐츠 검색·재생 음성 명령

ContentSearchHandler·ContentPlayHandler가 음성으로 받은 검색어로 결과를 찾아 검색 화면 또는 VOD 상세·자동 재생으로 직행시킵니다. content_play는 첫 결과를 골라 권한이 되면 본편을 자동 재생합니다.

기능 개요

content_search는 검색 화면 진입(콘텐츠 목록 탐색)을, content_play는 한 작품을 찾아 곧바로 재생까지 가는 명령입니다. ContentSearchHandler는 body.query로 TTSearchFragment를 자동 검색 상태로 띄웁니다(통합 검색 문서 참조). ContentPlayHandler는 CMSApiManagerV3.searchVodV3()로 1차 검색한 뒤 pickFirstContent()로 첫 결과를 고르고, 단편이면 LINK_CD, 시리즈면 LINK_SD 링크로 VOD 상세에 진입합니다.

결과 선택은 VOD 컬렉션 우선 + 본편 우선 규칙을 따릅니다. 즉 "[예고편]·[캐치온 커밍쑨]" 같은 prefix 항목보다 정확 제목 일치 본편을 우선합니다. 1차 검색이 0건이면 extractKeywordFromPrompt()로 발화에서 동사/조사를 제거한 핵심 키워드(예: "프로텍터 재생해 줘"→"프로텍터")로 재검색하고, 보정한 검색어를 응답 카드로 안내합니다. 둘 다 실패하면 "검색 결과가 없어요" 카드를 표시합니다.

설계 포인트
detail 진입 직전 PENDING_AUTO_PLAY(AtomicBoolean)를 set 하면 TTVodDetailFragment가 데이터 로드 완료 후 이 신호를 1회 consume 해 권한 OK면 자동 재생, NG면 detail 화면 노출로 분기합니다. 핸들러는 검색·매칭만 책임지고 실제 재생 권한 판정은 detail fragment가 수행하는 역할 분리 구조입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant DSP as AssistantResponseDispatcher participant CPH as ContentPlayHandler participant CMS as CMSApiManagerV3 participant LM as TTUILinkManager participant DF as TTVodDetailFragment DSP->>CPH: handle(body, prompt) (content_play) CPH->>CMS: searchVodV3(query) CMS-->>CPH: SearchResultV3 CPH->>CPH: pickFirstContent (VOD/본편 우선) alt 결과 없음 CPH->>CMS: searchVodV3(promptKeyword) 재검색 end CPH->>CPH: PENDING_AUTO_PLAY.set(true) CPH->>LM: handleLink(LINK_CD / LINK_SD, param) LM->>DF: 상세 진입 → 권한 OK면 자동 재생

흐름. 검색어로 첫 결과를 고른 뒤(없으면 prompt 키워드 재검색) detail에 진입하고, auto-play 신호로 권한이 되면 본편을 자동 재생합니다.

관계. ContentPlayHandler가 CMS 검색으로 첫 결과를 고르고 TTUILinkManager로 detail에 진입시키며, auto-play 신호는 detail fragment가 소비합니다.

핵심 코드

assistant/handler/ContentPlayHandler.java — 검색 → 첫 결과 → detail 진입(auto-play)
private static void openDetail(Context ctx, SearchResultV3.Content first) {
    boolean isSeries = "S".equalsIgnoreCase(first.contentType);
    String linkType = isSeries ? CMSDefV3.LINK_SD : CMSDefV3.LINK_CD;
    String linkParam = buildLinkParam(first, isSeries);
    if (TextUtils.isEmpty(linkParam)) return;

    TTUILinkManager link = getLinkHandler(ctx);
    if (link == null) return;
    // detail 진입 직전 auto-play signal — TTVodDetailFragment 가 로드 완료 후 1회 consume.
    PENDING_AUTO_PLAY.set(true);
    new Handler(Looper.getMainLooper()).post(() ->
            link.handleLink(linkType, linkParam, null, "lwvoice-content-play"));
}
assistant/handler/ContentPlayHandler.java — 0건 시 prompt 키워드 재검색
if (first == null) {
    if (!retried) {
        String fromPrompt = extractKeywordFromPrompt(prompt);   // 동사/조사 제거
        if (!TextUtils.isEmpty(fromPrompt) && !fromPrompt.equals(keyword)) {
            showAdjustedQueryNotice(ctx, fromPrompt, prompt);   // "‘X’로 검색했어요"
            search(ctx, fromPrompt, prompt, true);              // 재검색
            return;
        }
    }
    showNoResultCard(ctx, "“" + keyword + "” 검색 결과가 없어요.", prompt);
    return;
}
