FCM 푸시 · TTS

FCMService가 Firebase Cloud Messaging 데이터 메시지로 원격 STB 제어 명령(채널·전원·업그레이드·리부트·RCK 키 등)을 받아 실행하고 결과를 CEMS로 회신합니다. 음성 응답 발화는 TtsEngine 추상화 아래 시스템 AndroidTtsEngine과 원격 RemoteQwenTtsEngine 두 구현을 두고, SpeechManager가 SharedPreference 설정대로 선택합니다.

기능 개요

이 페이지는 성격이 다른 두 기능을 함께 다룹니다. 하나는 FCM 원격 제어입니다. FCMService는 FirebaseMessagingService를 상속하고 매니페스트(app/src/fifth/AndroidManifest.xml, app/src/second/AndroidManifest.xml)에 com.google.firebase.MESSAGING_EVENT 인텐트 필터로 등록되어 있어 flavor별로 동일하게 동작합니다. onMessageReceived()가 데이터 메시지의 controlKey를 읽어 채널 변경·부팅 채널 설정·전원/대기·해상도 변경·리부트·공장 초기화·앱 실행·OTA·STB 정보 조회·RCK(원격 키 입력) 등으로 분기하고, 처리 결과를 notifyResult()로 CemsManager.sendRCResult()를 통해 헤드엔드(CEMS)에 회신합니다. onNewToken()은 갱신된 FCM 토큰을 FileHandler에 저장합니다.

다른 하나는 TTS(음성 응답 발화)입니다. 음성 어시스턴트의 답변·확인 멘트는 SpeechManager를 통해 발화됩니다. SpeechManager는 TtsEngine 인터페이스(init/speak/stop/shutdown) 아래 두 구현을 둡니다. AndroidTtsEngine은 시스템 TextToSpeech 기반으로 인터넷 없이 동작하며 ko-KR voice를 명시 고정합니다. RemoteQwenTtsEngine은 GB10 단말의 Qwen3-TTS REST API로 더 자연스러운 음성을 받아 AudioTrack(USAGE_ASSISTANT)으로 재생합니다. 기본 엔진은 SharedPreferences "lwvoice"."tts_engine"에 저장된 값이고 미설정이면 ANDROID이며, setEngine()으로 런타임 전환됩니다.

SpeechManager.speak()는 발화 시작 시 SpeechStateListener로 UI에 알리고 LiveTvMuter로 본방송을 음소거한 뒤, 엔진의 onDone 콜백에서 음소거를 해제합니다. 발화 시작/종료 이벤트만 노출하고 실제 화면 전환은 UI(VoiceListeningOverlay) 쪽 리스너가 담당해, util 계층이 ui 계층을 직접 참조하지 않도록 결합을 끊습니다.

설계 포인트
RemoteQwenTtsEngine은 기본이 스트리밍 모드(/api/tts/stream)입니다. 4바이트 길이 prefix가 붙은 PCM chunk를 받는 즉시 AudioTrack(MODE_STREAM)으로 재생을 시작해 첫 음성까지의 지연을 줄이고, 비스트리밍(/api/tts)은 전체 WAV를 받아 MODE_STATIC으로 한 번에 재생합니다. 두 경로 모두 PCM 길이로 재생 시간을 계산해 종료 시점에 onDone을 정확히 한 번 fire 하고 AudioTrack을 release 합니다.

FCMService.java — controlKey 기반 원격 제어 분기 + 결과 회신
@Override
public void onMessageReceived(@NonNull RemoteMessage remoteMessage) {
    super.onMessageReceived(remoteMessage);
    Map<String, String> dataMap = remoteMessage.getData();
    if (dataMap == null) { return; }
    String command = dataMap.get("controlKey");
    if (command == null) { return; }
    sessionId = dataMap.get("sessionId");

    switch (command) {
        case "stbReboot":
            notifyResult(sessionId, command, "success", null, dataMap.get("value"));
            SettingHandler.reboot();
            return;
        case "channel":
            String chNum = dataMap.get("value");
            EpgChannel epgChannel = EpgChannelManager.getInstance()
                    .getValidChannel(EpgChannelRing.RING_ACCESSIBLE, Integer.parseInt(chNum));
            if (epgChannel != null) MainController.changeChannel(true, epgChannel);
            else { notifyResult(sessionId, command, "failure", "No such channel " + chNum, chNum); return; }
            break;
        // ... bootCh / stbPowerMode / screenRatio / appName / RCK / stbInfo ...
        default:
            return;
    }
    notifyResult(sessionId, command, "success", null, msg);
}
assistant/util/SpeechManager.java — 엔진 선택 + 발화 동안 본방송 mute
public void speak(String text, Runnable onDone) {
    if (engine == null || text == null || text.isEmpty()) {
        if (onDone != null) onDone.run();
        return;
    }
    final long token = nextSpeechToken();
    notifySpeechStarted(text);          // VoiceListeningOverlay 등 UI 리스너 통보
    LiveTvMuter.acquire(MUTE_REASON);   // TTS 동안 라이브 TV mute
    final Runnable userCb = onDone;
    engine.speak(text, () -> {
        try {
            LiveTvMuter.release(MUTE_REASON);
            notifySpeechFinished(token);
        } finally { if (userCb != null) userCb.run(); }
    });
}
assistant/util/RemoteQwenTtsEngine.java — 스트리밍 PCM chunk를 받아 AudioTrack 재생
private void doSpeakStream(String text) {
    AudioTrack track = null;
    String json = "{\"text\":" + jsonString(text) + ",\"voice_id\":\"" + voiceId + "\"}";
    Request req = new Request.Builder().url(BASE_URL + TTS_STREAM_PATH)
            .post(RequestBody.create(json, MediaType.get("application/json"))).build();
    try (Response resp = client.newCall(req).execute()) {
        BufferedSource source = resp.body().source();
        while (true) {
            if (!source.request(4)) break;
            int length = source.readIntLe();          // 4-byte uint32 LE 길이 prefix
            if (length == 0) break;                   // end marker
            if (!source.request(length)) break;
            byte[] chunk = source.readByteArray(length);
            if (track == null) {                      // 첫 chunk 도착 → 즉시 재생 시작
                track = createStreamTrack();          // USAGE_ASSISTANT, MODE_STREAM
                track.play();
                currentTrack = track;
            }
            track.write(chunk, 0, chunk.length);
        }
        // PCM 길이로 잔여 재생시간 계산 → 그 후 onDone fire + release
        mainHandler.postDelayed(scheduledDone, remainMs + DONE_GRACE_MS);
    }
}
assistant/util/AndroidTtsEngine.java — 시스템 TextToSpeech 초기화 + ko 음성 고정
tts = new TextToSpeech(context.getApplicationContext(), status -> {
    if (status != TextToSpeech.SUCCESS) return;
    tts.setLanguage(Locale.KOREAN);
    pickAndSetVoice();          // default 가 발화마다 남/여 swap 되는 문제 fix — ko voice 명시
    tts.setSpeechRate(1.05f);
    tts.setPitch(1.0f);
    tts.setOnUtteranceProgressListener(new UtteranceProgressListener() {
        @Override public void onStart(String id) { }
        @Override public void onDone(String id) { fireDone(id); }
        @Override public void onError(String id) { fireDone(id); }
        @Override public void onStop(String id, boolean i) { fireDone(id); }
    });
    ready.set(true);
});
