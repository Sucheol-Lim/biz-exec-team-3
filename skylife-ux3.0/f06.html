기능 개요

설정 화면은 ui/setting/fragment의 CommonSettingFragment(TTListViewSupportFragment 상속)를 베이스로 하는 다수의 화면으로 구성됩니다. 환경 설정(preference)으로 해상도(TTSettingResolutionFragment), 사운드(TTSettingSoundFragment), 자동 전원/대기(TTSettingAutoPower·AutoStandby), 언어(BasicLanguage·AudioLanguage), 시스템 정보·업그레이드 등을 제공하고, 자녀보호(parental)로 성인 메뉴, 채널/시간 차단, 시청 등급, PIN 변경(TTSettingPinChangeFragment)을 관리합니다. 설정 진입점인 SettingMainActivity는 매니페스트에 선언되어 있으며, 앱 내부에서는 TTUIManager.goToScreen(UI_UTIL_SETTINGS) → showSettingFragment() 경로로도 진입합니다.

마이페이지는 ui/mypage의 TTMyPageFragment2(+TTMyPageViewModel2)가 담당합니다. TTMyPageMenuType enum으로 VOD 구매내역·소장용·찜·무비초이스·쿠폰·VOD/TV 포인트·가입내역(PRODUCTS)·시청예약 목록(RESERVATIONS)·녹화 목록(RECORDINGS)·공지(NOTICES) 메뉴를 정의합니다.

설계 포인트
잠금/비밀번호와 자녀보호는 PIN 기반으로 동작하며, FCM 푸시(FCMService)나 음성 명령으로 트리거되는 시스템 동작(재부팅·해상도 변경·전원)도 결국 SettingHandler를 거칩니다. 즉 사용자 설정 UI와 원격 제어가 동일한 SettingHandler 진입점을 공유합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 사용자 participant UIM as TTUIManager participant SF as CommonSettingFragment participant VM as TTSettingViewModel participant SH as SettingHandler U->>UIM: goToScreen(UI_UTIL_SETTINGS) UIM->>SF: showSettingFragment() SF->>VM: 설정 항목 로드 VM-->>SF: 현재 값 (해상도/사운드/잠금 등) U->>SF: 항목 변경 (예: 해상도) SF->>SH: setVideoResolution(...) / PIN 검증 SH-->>SF: 적용 결과 SF-->>U: UI 갱신

흐름. 설정 진입 후 항목을 변경하면 SettingHandler가 실제 시스템 설정을 적용하고 화면이 갱신됩니다.

클래스 다이어그램

classDiagram class TTListViewSupportFragment class CommonSettingFragment { <<abstract>> } class TTSettingResolutionFragment class TTSettingPinChangeFragment class TTSettingViewModel class TTMyPageFragment2 class TTMyPageMenuType { <<enumeration>> VOD_BUYS PRODUCTS RESERVATIONS RECORDINGS NOTICES } class SettingHandler { +setVideoResolution(int) +reboot() +poweroff() } CommonSettingFragment --|> TTListViewSupportFragment TTSettingResolutionFragment --|> CommonSettingFragment TTSettingPinChangeFragment --|> CommonSettingFragment CommonSettingFragment --> TTSettingViewModel : 데이터 CommonSettingFragment --> SettingHandler : 시스템 설정 적용 TTMyPageFragment2 --> TTMyPageMenuType : 메뉴 구성

관계. 설정 화면들이 CommonSettingFragment를 공통 베이스로 두고 SettingHandler로 시스템 설정을 적용하며, 마이페이지는 TTMyPageMenuType으로 메뉴를 구성합니다.

ui/mypage/TTMyPageMenuType.java — 마이페이지 메뉴 enum
public enum TTMyPageMenuType {
    VOD_BUYS(R.string.mp_vod_buy, R.drawable.icon_my_menu_buyvod),
    VOD_COLLECTIONS(R.string.mp_vod_collection, R.drawable.icon_my_menu_collection),
    VOD_LIKES(R.string.mp_vod_like, R.drawable.icon_my_menu_likevod),
    COUPON(R.string.mp_coupon, R.drawable.icon_coupon),
    VOD_POINT(R.string.mp_vod_point, R.drawable.icon_point),
    PRODUCTS(R.string.mp_products, R.drawable.icon_my_menu_join),       // 가입내역
    RESERVATIONS(R.string.mp_reservations, R.drawable.icon_my_menu_reserve), // 시청예약

    NOTICES(R.string.mp_notices, R.drawable.icon_my_menu_noti);
}
