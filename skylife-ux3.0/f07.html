LW Voice 음성 어시스턴트

모바일 앱과 STB를 페어링하여 음성 명령을 STB에서 실행합니다. StbRelayServer(NanoHTTPD/NanoWSD WebSocket, 8787 포트)가 릴레이 서버로 양방향 통신하고, NSD/UDP 디스커버리와 MobileSession으로 단일 모바일 연결을 관리합니다.

기능 개요

LW Voice는 모바일 앱이 STB를 발견·페어링하고 음성 명령을 STB로 보내 실행시키는 음성 어시스턴트입니다. 전송 계층은 StbRelayServer(NanoWSD 상속)가 8787 포트 단일 listen으로 제공하며 두 가지 사양 PDF(newlwvoice-connect.pdf v1.3, stb_assistant_response_api_spec.pdf v1.3)를 근거로 구현되어 있습니다. HTTP 경로로는 GET /health(헬스 체크)와 POST /assistant-response(legacy fallback), WebSocket 경로 /assistant-ws로는 mobile_hello·ping/pong·assistant_response·assistant_progress 프레임을 처리합니다.

모바일은 NSD(mDNS, _lwcompanion._tcp.)와 UDP(LW_COMPANION_DISCOVER_V1) 디스커버리로 STB를 찾고 WebSocket으로 연결합니다. 연결마다 AssistantWebSocket이 생성되어 MobileSession을 수립하며, mobile_hello를 받으면 그 세션을 활성(active) 세션으로 등록하고 우측 상단에 연결 토스트(MobileConnectionOverlay)를 띄웁니다. STB가 STT로 받은 발화는 AssistantRequestPump가 assistant_request envelope으로 이 세션에 송신하고, 모바일/서버의 LLM이 만든 assistant_response가 돌아오면 AssistantResponseDispatcher가 payload.type별 핸들러로 분기합니다.

설계 포인트
socket read timeout은 60초로 두되 30초마다 ping/pong heartbeat를 보내 idle 끊김을 막습니다(AssistantRequestPump). 활성 세션은 1개만 유지(마지막 hello를 보낸 세션이 활성)하며, 늦게 도착한 옛 응답이 새 발화 흐름을 덮어쓰지 않도록 dispatcher가 requestId 기반 stale guard로 거릅니다.

핵심 코드

assistant/server/StbRelayServer.java — 8787 단일 listen, HTTP/WS 분기
public class StbRelayServer extends NanoWSD {
    @Override
    public Response serve(IHTTPSession session) {
        if (isWebsocketRequested(session)) return super.serve(session);  // WS upgrade
        String uri = session.getUri();
        if (Method.GET == session.getMethod()
                && AssistantConstants.HEALTH_PATH.equals(uri)) return responseHealth();
        if (Method.POST == session.getMethod()
                && AssistantConstants.LEGACY_RESPONSE_PATH.equals(uri))
            return responseLegacyAssistant(session);                     // legacy fallback
        return newFixedLengthResponse(Response.Status.NOT_FOUND, "text/plain", "Not Found");
    }
    @Override
    protected WebSocket openWebSocket(IHTTPSession handshake) {
        return new AssistantWebSocket(appContext, handshake);            // /assistant-ws
    }
}
assistant/server/AssistantWebSocket.java — 프레임 타입 분기
switch (type) {
    case AssistantConstants.TYPE_MOBILE_HELLO:
        session.markHelloReceived();
        AssistantVodSnapshotSender.sendLatestTo(session);   // VOD 스냅샷 전송 시도
        break;
    case AssistantConstants.TYPE_PING:  session.markHeartbeat(); sendJsonPong(); break;
    case AssistantConstants.TYPE_PONG:  session.markHeartbeat(); break;
    case AssistantConstants.TYPE_ASSISTANT_RESPONSE:
        AssistantResponseDispatcher.dispatch(appContext, env); break;
    case AssistantConstants.TYPE_ASSISTANT_PROGRESS:
        AssistantProgressDispatcher.dispatch(appContext, env); break;
}
