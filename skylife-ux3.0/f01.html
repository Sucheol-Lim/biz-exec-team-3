홈 런처

MainActivity가 HOME·LAUNCHER·af.intent.action.KEY_TV_HOME 인텐트로 동작하는 STB 메인 화면입니다. 단말 부팅 후 첫 화면과 홈 키 진입점을 담당하며 singleInstance 모드로 기동되고, EpgApplication이 프로세스 초기화와 음성 어시스턴트·wake-word 서비스 기동을 수행합니다.

기능 개요

이 앱은 일반 앱이 아니라 STB의 홈/런처로 동작합니다. 매니페스트의 메인 화면 MainActivity가 android.intent.category.HOME·android.intent.category.LAUNCHER 카테고리와 af.intent.action.KEY_TV_HOME·android.intent.action.SCREEN_ON 인텐트 필터를 android:priority="2"로 가지고 android:launchMode="singleInstance"로 기동됩니다. 따라서 단말 부팅 후 첫 화면과 홈 키 입력의 진입점이 됩니다.

MainActivity는 flavor별(second·fifth)로 별도 구현되며 공통 베이스 CommonMainActivity를 상속합니다. 애플리케이션 엔트리 EpgApplication은 BaseApplication을 확장하고 Window.Callback·TvSingletons를 구현하며, onCreate()에서 라이프사이클 콜백 등록, 메인 프로세스 판정(isMainProcess()), wake-word 서비스 기동(startWakeWordService()), LW Voice 어시스턴트 API 기동(startAssistantApi())을 순차 수행합니다. ux3.0는 멀티 프로세스 구조라 8787 릴레이 서버와 마이크는 메인 프로세스에서만 기동됩니다.

설계 포인트
singleInstance + REORDER_TO_FRONT 조합으로 외부 앱(유튜브 등)이 떠 있어도 홈 키나 음성 "홈" 명령이 EPG 태스크를 깔끔하게 끌어올립니다. 시스템 ACTION_MAIN + CATEGORY_HOME 인텐트는 라이프사이클을 흔들어 EpgChannelController race와 충돌하므로, 자기 태스크 복귀에는 FLAG_ACTIVITY_REORDER_TO_FRONT를 사용합니다(ScreenControlHandler.dispatchHome 근거).

app/src/fifth/AndroidManifest.xml — MainActivity 런처 인텐트 필터
<activity
    android:exported="true"
    android:launchMode="singleInstance"
    android:name=".ui.MainActivity"
    android:theme="@style/MainTheme"
    android:banner="@drawable/app_banner">

        <category android:name="android.intent.category.DEFAULT"/>
        <category android:name="android.intent.category.HOME"/>
    </intent-filter>
</activity>
EpgApplication.java — 프로세스 기동 시 메인 프로세스에서만 음성·wake 기동
@Override
public void onCreate() {
    super.onCreate();
    mAppicationContext = getApplicationContext();
    TvSingletons.setSingletons(this);
    registerActivityLifecycleCallbacks(new LifecycleCallbacks());

    // ux3.0 는 multi-process — 8787 / 마이크는 메인 process 에서만 기동.
    if (isMainProcess()) {
        startWakeWordService();   // wake-lib (sky-claw) foreground service
        startAssistantApi();      // 8787 listen + NSD/UDP discovery + STT pump
        dumpMicrophoneInfo();
    } else {
        Logger.i(TAG, " ## sub-process — wake/assistant 기동 skip");
    }
}
