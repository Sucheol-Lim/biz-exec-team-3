오버레이 UI

AssistantOverlayCoordinator가 외부 앱(유튜브·VOD 등) 위에 TYPE_APPLICATION_OVERLAY 윈도우로 청취 화면·응답 카드·모바일 연결·개인화 페어링·타이머 오버레이를 띄우고, 발화 단계마다 어떤 오버레이를 먼저 치울지 한 곳에서 조율합니다. 청취 화면의 파형은 HeySkyWaveformView가 3겹 SVG path 애니메이션으로 그립니다.

기능 개요

음성 어시스턴트는 EPG 홈뿐 아니라 유튜브 같은 외부 앱이 떠 있을 때도 화면 위에 떠야 합니다. 그래서 모든 어시스턴트 UI는 액티비티가 아니라 WindowManager에 직접 붙는 시스템 오버레이(TYPE_APPLICATION_OVERLAY, O 미만은 TYPE_SYSTEM_ALERT)로 구현되어 있습니다. assistant/ui 패키지의 각 오버레이는 싱글턴이며, FLAG_NOT_FOCUSABLE·FLAG_NOT_TOUCHABLE로 포커스/입력을 가로채지 않고 표시만 합니다.

문제는 청취 화면(VoiceListeningOverlay, 풀스크린), 응답 카드(AnswerCardOverlay, 화면 상단), 모바일 연결 토스트(MobileConnectionOverlay, 우측 상/하단), 개인화 페어링 카드(PersonalizedPairingOverlay)가 각자 윈도우에 붙는 구조라, 조율이 없으면 wake·청취·응답·개인화 카드가 동시에 남아 시각적으로 겹친다는 점입니다. AssistantOverlayCoordinator는 아직 큰 상태 머신을 도입하기 전 단계에서, 화면 전환의 입구마다 "어떤 오버레이를 먼저 치울지"를 한 곳에 모아 겹침과 오래된 TTS를 줄이는 조율 지점입니다.

코디네이터는 세 진입점을 제공합니다. onListeningStarted()는 새 발화(wake) 진입 시 응답 카드·개인화 카드·모바일 연결 토스트를 모두 닫고 진행 중이던 SpeechManager TTS를 중단합니다. beforeAnswer()는 답변 표시 직전 개인화 카드만 정리하되, 청취 오버레이는 TTS 상태 콜백이 "말씀드리는 중" 화면으로 전환하도록 일부러 남겨둡니다. beforeLocalEnvelope()는 로컬 envelope(개인화) 표시 직전 응답 카드를 닫습니다.

설계 포인트
청취 화면과 응답 카드는 각각 풀스크린 하단 panel과 화면 상단 카드라 의도적으로 동시에 표시할 수 있습니다. 그래서 beforeAnswer()에서 청취 오버레이를 닫지 않습니다. 닫아버리면 TTS가 도착해도 "말씀드리는 중" 상태를 보여줄 표면이 사라지기 때문입니다. 반대로 wake 진입(onListeningStarted())은 화면 전체를 잡는 최우선 상태라 우측에 남은 연결 토스트까지 함께 치워 새 발화 UI와 겹치지 않게 합니다.

흐름. wake가 트리거되면 VoiceListeningOverlay가 코디네이터의 onListeningStarted()로 다른 오버레이를 정리한 뒤 풀스크린 청취 화면을 띄웁니다. 응답이 도착하면 beforeAnswer()로 개인화 카드만 닫고 응답 카드를 상단에 추가해 청취 화면과 함께 표시합니다.

관계. AssistantOverlayCoordinator는 상태를 갖지 않는 정적 조율 지점으로, 다른 싱글턴 오버레이의 hide()와 SpeechManager.stop()만 호출합니다. VoiceListeningOverlay는 진입 시 코디네이터를 부르고 HeySkyWaveformView를 소유하며 SpeechManager의 발화 상태 콜백을 받습니다.

핵심 코드

assistant/ui/AssistantOverlayCoordinator.java — 발화 단계별 오버레이 정리
public static void onListeningStarted(Context context) {
    if (context == null) return;
    try { AnswerCardOverlay.get(context).hide(); } catch (Exception ignored) {}
    try { PersonalizedPairingOverlay.get(context).hide(); } catch (Exception ignored) {}
    // wake/listening overlay는 화면 전체를 잡는 최우선 상태라, 우측에 남던
    // 모바일 연결/elapsed 토스트도 함께 치워 새 발화 UI와 겹치지 않게 한다.
    try { MobileConnectionOverlay.get(context).hide(); } catch (Exception ignored) {}
    try { SpeechManager.get().stop(); } catch (Exception ignored) {}
}

public static void beforeAnswer(Context context) {
    if (context == null) return;
    try { PersonalizedPairingOverlay.get(context).hide(); } catch (Exception ignored) {}
    // 답변 카드는 상단, VoiceListeningOverlay는 하단 panel이라 동시 표시 가능.
    // voice overlay는 TTS listener가 ANSWER 상태로 전환하도록 남겨둔다.
}
assistant/ui/VoiceListeningOverlay.java — wake 진입 시 코디네이터 호출 + 오버레이 추가
private void showListening() {
    ui.post(() -> {
        buildIfNeeded();
        if (transcript != null) transcript.setText("");   // 이전 발화 transcript 초기화
        ttsSpeaking = false;
        applyRoute(Route.NONE);
        AssistantOverlayCoordinator.onListeningStarted(appContext);   // 다른 overlay 정리
        try { AssistantRequestPump.invalidateCurrent(); } catch (Exception ignored) {}
        applyState(State.LISTENING);
        if (root.getParent() == null) {
            wm.addView(root, makeParams());   // TYPE_APPLICATION_OVERLAY 풀스크린
            fadeInRoot();
        }
        ui.postDelayed(autoHide, AUTO_HIDE_MS);   // 7s 발화 없음 보호
    });
}
assistant/ui/HeySkyWaveformView.java — 3겹 SVG path를 Canvas로 옮긴 파형 + state 애니메이션
public enum State { LISTENING, PROCESSING, RESULT, ERROR }

private void applyState(State s) {
    currentState = s;
    cancelAnimators();
    switch (s) {
        case LISTENING:   // 3 layer 가 서로 다른 주기로 drift (scaleY + translateX 보간)
            backAnim  = drift(5500, 1.0f, 0.85f, 0f, 8f, this::setBackTransform);
            midAnim   = drift(4000, 1.05f, 0.92f, 0f, -6f, this::setMidTransform);
            frontAnim = drift(3000, 1.0f, 1.10f, 0f, 4f, this::setFrontTransform);
            backAnim.start(); midAnim.start(); frontAnim.start();
            break;
        case PROCESSING:  // 1.4s sin pulse, layer 마다 150ms stagger
            backAnim = pulse(1400, 0L, this::setBackPulse);  /* ... */ break;
        case RESULT:      // 2.4s breathe (scaleY 1↔1.04)
            backAnim = breathe(2400, this::setBackBreathe);  /* ... */ break;
        case ERROR:       // 정적 — scaleY 0.8, alpha 0.5
            backScaleY = midScaleY = frontScaleY = 0.8f;
            backAlpha = midAlpha = frontAlpha = 0.5f;
            invalidate();
            break;
    }
}
assistant/handler/AnswerHandler.java — 답변 직전 beforeAnswer 호출 후 카드 표시 + TTS
private static void showAnswer(Context appContext, String answer) {
    String question = WakeStatusProvider.getLastSttText();
    AssistantOverlayCoordinator.beforeAnswer(appContext);            // 개인화 카드만 정리
    VoiceListeningOverlay.setState(VoiceListeningOverlay.State.ANSWER);
    VoiceListeningOverlay.setTranscript(null, question);
    AnswerCardOverlay overlay = AnswerCardOverlay.get(appContext);
    overlay.show(question, answer, AssistantUiTokens.ACCENT_ANSWER, true);  // keepUntilExternal
    SpeechManager.get().speak(answer, () -> overlay.hideAfter(800L));        // 발화 끝나면 잔존 후 hide
}
