기능 개요

이 키오스크 앱은 Android 태블릿 WebView 안에서 구동되므로, 브라우저 마이크 직접 인식 외에 단말의 네이티브 STT 기능에 위임하는 경로를 함께 갖추고 있습니다. useSTT 훅이 userAgent에 Android가 있고 window.android 인터페이스가 존재하면 Android 경로를 선택해 AzureSTTManager.azureMicOpenAndroid를 호출합니다.

Android 경로의 핵심은 startSpeechRecognitionAndroid()입니다. 먼저 window.android.setSpeechConfiguration(apiKey, region, customEndpoint)으로 단말 측 Azure Speech 설정을 주입한 뒤, 언어에 맞춰 window.android.requestSpeechToText("ko-KR" 또는 "en-US", timeout)로 단말에 인식을 요청합니다. 단말이 인식한 결과는 앱이 initialize() 시점에 등록해 둔 전역 콜백 window.handleSTTResult(text, mode)로 되돌아옵니다.

handleSTTResult의 mode는 단말 측 인식 상태를 나타냅니다. 1은 중간 인식(recognizing)으로 텍스트를 스토어에 실시간 반영하고, 2는 최종 인식(recognized)으로 window.android.stopSpeechToText()를 호출해 마이크를 닫고 결과를 콜백에 전달합니다. 0은 타임아웃으로 빈 결과를 돌려줍니다. 등록 자체는 window.android.setSTTCallback("handleSTTResult")로 단말에 콜백 이름을 알려 이뤄집니다.

설계 포인트
JS↔네이티브는 두 방향 브리지로 동작합니다. JS→Android는 window.android.* 메서드 호출, Android→JS는 window.handleSTTResult 같은 전역 함수 호출입니다. 매니저는 this.handleSTTResult.bind(this)로 컨텍스트를 고정해 전역에 노출합니다.

흐름. Android 단말에서는 매니저가 네이티브 설정을 주입하고 requestSpeechToText로 인식을 위임합니다. 단말은 handleSTTResult(text, mode)로 결과를 되돌리고, mode 2(최종)에서 마이크를 닫습니다.

핵심 코드

src/voice/AzureSTTManager.js — 콜백 등록과 결과 수신
initialize: function() {
    window.handleSTTResult = this.handleSTTResult.bind(this);   // 전역 노출
    if (window.android && window.android.setSTTCallback) {
        window.android.setSTTCallback("handleSTTResult");        // 단말에 콜백명 등록
    }
},

handleSTTResult: function (text, mode) {
    if (mode === 2) {                          // 최종 인식
        window.android.stopSpeechToText();
        voiceStore.actions.setSTTText(text);
        if (self.callback) { self.callback(true, text); self.callback = null; }
    } else if (mode === 1) {                   // 중간 인식
        voiceStore.actions.setSTTText(text);
    } else if (mode === 0) {                   // 타임아웃
        window.android.stopSpeechToText();
        if (self.callback) { self.callback(true, ""); self.callback = null; }
    }
},
src/voice/AzureSTTManager.js — 단말에 인식 요청
startSpeechRecognitionAndroid: async (timeout) => {
    if (i18n.language == "en") {
        window.android.setSpeechConfiguration(
            import.meta.env.APP_AZURE_SPEECH_API_KEY_IBC,
            import.meta.env.APP_AZURE_SPEECH_REGION_IBC,
            import.meta.env.APP_AZURE_SPEECH_CUSTOM_ENDPOINT_URL);
        window.android.requestSpeechToText("en-US", timeout);
    } else {
        window.android.setSpeechConfiguration(
            import.meta.env.APP_AZURE_SPEECH_API_KEY,
            import.meta.env.APP_AZURE_SPEECH_REGION,
            import.meta.env.APP_AZURE_SPEECH_CUSTOM_ENDPOINT_URL);
        window.android.requestSpeechToText("ko-KR", timeout);
    }
},
