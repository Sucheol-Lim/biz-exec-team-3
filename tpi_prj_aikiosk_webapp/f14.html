디버그 오버레이

Debugger 컴포넌트가 STT·TTS·LLMAgent 처리 상태를 화면 상단 오버레이로 표시하고, debug-store가 각 단계 상태와 표시 여부를 보관하며, CommonLog 로그 레벨은 빌드 인자로 제어합니다.

기능 개요

키오스크는 마우스·콘솔이 없는 단말에서 단독으로 동작하므로, 음성 파이프라인(STT → LLM → TTS) 어디서 막혔는지 현장에서 눈으로 확인할 수단이 필요합니다. 이를 위해 App.jsx가 라우터와 함께 항상 <Debugger />를 렌더하고, Debugger는 react-dom의 createPortal로 index.html의 #debug-area에 오버레이를 그립니다. 오버레이는 STT·TTS·LLMAgent 세 단계의 현재 상태를 한 줄씩 보여주는 검은 반투명 막대(opacity: 0.4)이며, 우측에 SETTING 버튼이 있어 Speech 리전·한국어 TTS 서버를 바꾸는 설정 팝업을 엽니다.

상태값은 debug-store(zustand)가 보관합니다. StatusType은 Unknown·Pending·Error·OK 네 가지이며, 각 단계의 훅이 처리 진행에 맞춰 상태를 갱신합니다. useSTT는 인식 시작 시 Pending, 결과 수신 시 OK, 오류 시 Error로 setSTTStatus를 호출하고, useTTS·useLLMQuerySequence도 각각 setTTSStatus·setLLMAgentStatus로 동일한 흐름을 반영합니다. 따라서 운영자는 오버레이만 보고 "STT는 OK인데 LLMAgent가 Pending에서 안 넘어간다" 같은 상황을 즉시 진단할 수 있습니다.

오버레이 표시 여부 showDebugger는 기본 false이며, 운영 중 실수로 노출되지 않도록 숨겨진 제스처로만 켭니다. 언어 선택 팝업의 스페인어 버튼(ButtonLanugageBig, 비활성 항목)을 10회 이상 연속 탭하면 toggleShowDebugger()가 호출되어 오버레이가 켜집니다. 한편 콘솔 로그 상세도는 별개로, CommonLog.setLevel(import.meta.env.APP_LOG_LEVEL)로 결정되며 이 환경변수는 빌드 인자로 주입됩니다.

설계 포인트
화면 오버레이(Debugger)와 콘솔 로그(CommonLog)는 별도 채널입니다. 오버레이는 숨겨진 10회 탭 제스처로만 켜지는 런타임 진단용이고, 로그 레벨은 빌드 시 log=true(DEBUG)/log=false(INFO) 인자로 고정됩니다. 릴리스 빌드는 log=false로 INFO 레벨이 적용됩니다.

핵심 코드

src/component/Debug/Debugger/Debugger.jsx — 포털 오버레이와 단계별 상태 행
const { sttStatus, ttsStatus, llmAgentStatus } = useDebugStore();
const showDebugger = useDebugStore(showDebuggerSeletor);
return (
  showDebugger &&
  createPortal(
    <div className={classes.debuggerWrapper}>
      <Status type={"STT"} status={sttStatus} />
      <Status type={"TTS"} status={ttsStatus} />
      <Status type={"LLMAgent"} status={llmAgentStatus} />
      <div className={classes.settingButton}
           onTouchEnd={() => openPopup(PopupStateType.SETTING)}>
        SETTING
      </div>
    </div>,
    document.getElementById("debug-area")
  )
);
src/store/debug-store.js — 상태 enum과 토글·갱신 액션
export const StatusType = {
  Unknown: "Unknown", Pending: "Pending", Error: "Error", OK: "OK",
};
const initialState = {
  showDebugger: false,
  sttStatus: StatusType.Unknown,
  ttsStatus: StatusType.Unknown,
  llmAgentStatus: StatusType.Unknown,
};
// actions: toggleShowDebugger / setSTTStatus / setTTSStatus / setLLMAgentStatus
src/component/Common/Button/ButtonLanguageBig/ButtonLanugageBig.jsx — 숨겨진 10회 탭 토글
if (lang == "spa") {
  if (touchCount < 10) {
    setTouchCount((prev) => prev + 1);
  } else {
    toggleShowDebugger();   // 오버레이 표시 토글
    closePopup();
  }
}
