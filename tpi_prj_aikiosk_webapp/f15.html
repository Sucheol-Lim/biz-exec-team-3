기능 개요

키오스크 단말의 WebView는 정적 웹 번들을 file 프로토콜 등으로 로드하므로, 빌드 산출물을 한 덩어리로 묶어 배포하는 단계가 필요합니다. npm run release는 vite build --mode release -- log=false live=true를 실행합니다. 추가 인자 log=false는 vite.config.js에서 APP_LOG_LEVEL=INFO로, live=true는 APP_NETWORK=Prod로 환산되어 빌드 환경변수에 주입됩니다. 동시에 APP_UPDATE_DATE가 dayjs().format("YYYYMMDDHHmm")로 빌드 시각으로 갱신됩니다.

mode === "release" 분기에서는 빌드 옵션을 조정합니다. cssCodeSplit: false·cssMinify: true로 CSS를 한 파일로 모아 압축하고, manualChunks로 src/assets/ 경로의 리소스를 별도 assets 청크로 분리하며, assetFileNames를 assets/[name].[ext]로 고정해 파일명 해시 없이 안정적인 경로를 만듭니다. assetsInlineLimit: 0으로 에셋 인라인을 끄고 항상 별도 파일로 출력합니다. 이는 폰트·메뉴 이미지·PNG 시퀀스 같은 대용량 정적 리소스를 WebView에서 예측 가능한 경로로 참조하기 위함입니다.

빌드가 끝나면 플러그인 배열에 zipPack이 추가되어 후처리로 동작합니다. inDir: "dist"의 결과물을 통째로 outDir: "release"에 ZIP으로 묶고, 파일명은 APP_UPDATE_DATE 앞 8자리(날짜)·APP_NAME·APP_VERSION·APP_NETWORK·APP_LOG_LEVEL을 밑줄로 이어 붙입니다. 예를 들어 20241121_AIKioskWebApp_0.0.0_Prod_INFO.zip 형태가 되어, 산출물 파일명만으로 빌드 일자와 환경 설정을 식별할 수 있습니다. 같은 분기에서 svgLoader도 함께 등록됩니다.

설계 포인트
ZIP 파일명에 환경 메타(네트워크·로그레벨·버전·날짜)를 인코딩해 배포물의 추적성을 확보합니다. base: "./"와 no-crossorigin 플러그인이 file 프로토콜·크로스오리진 제약을 고려한 산출물을 만들고, 그 위에서 release 모드가 청크·압축·패키징을 마무리합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant DEV as 개발자 participant NPM as npm run release participant CFG as vite.config.js participant VITE as Vite 빌드 participant ZIP as vite-plugin-zip-pack DEV->>NPM: npm run release NPM->>CFG: vite build --mode release -- log=false live=true CFG->>CFG: log=false → APP_LOG_LEVEL=INFO CFG->>CFG: live=true → APP_NETWORK=Prod CFG->>CFG: APP_UPDATE_DATE = dayjs(YYYYMMDDHHmm) CFG->>VITE: build (cssMinify, manualChunks assets, inlineLimit 0) VITE-->>CFG: dist/ 산출물 CFG->>ZIP: zipPack(inDir=dist, outDir=release) ZIP->>ZIP: 파일명 = 날짜_APP_NAME_VERSION_NETWORK_LOGLEVEL.zip ZIP-->>DEV: release/...zip 생성

흐름. release 스크립트가 빌드 인자를 환경변수로 환산하고, Vite가 청크·압축한 dist/를 만든 뒤 zip-pack이 메타가 담긴 파일명으로 release/에 ZIP을 출력합니다.

관계. release 스크립트가 모드와 인자를 넘기면 vite.config.js가 빌드 옵션과 zipPack·svgLoader 플러그인을 release 분기에서 추가하고, ZIP 파일명은 환경변수로 조립됩니다.

핵심 코드

vite.config.js — 빌드 인자 → 환경변수 환산과 빌드 시각
const argv = parseArgv(process.argv.slice(4));
process.env.APP_UPDATE_DATE = dayjs().format("YYYYMMDDHHmm");

if (argv["log"] == "false")      process.env.APP_LOG_LEVEL = "INFO";
else if (argv["log"] == "true")  process.env.APP_LOG_LEVEL = "DEBUG";
if (argv["live"] == "true")      process.env.APP_NETWORK = "Prod";
else if (argv["live"] == "false") process.env.APP_NETWORK = "Stag";
vite.config.js — release 모드 빌드 옵션과 ZIP 패키징
if (mode === "release") {
  config.build = {
    cssCodeSplit: false,
    cssMinify: true,
    rollupOptions: {
      output: {
        manualChunks: (id) =>
          id.includes("src/assets/") ? "assets" : "",
        assetFileNames: `assets/[name].[ext]`,
      },
    },
    assetsInlineLimit: 0,
  };
  config.plugins = config.plugins.concat([
    zipPack({
      inDir: "dist",
      outDir: "release",
      outFileName:
        process.env.APP_UPDATE_DATE.substr(0, 8) + "_" +
        process.env.APP_NAME + "_" +
        process.env.APP_VERSION + "_" +
        process.env.APP_NETWORK + "_" +
        process.env.APP_LOG_LEVEL + ".zip",
    }),
    svgLoader({ defaultImport: "url" }),
  ]);
}
package.json — release npm 스크립트
"release": "vite build --mode release -- log=false live=true"
