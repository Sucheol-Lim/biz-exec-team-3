LLM 자연어 질의

LLMManager가 발화 텍스트를 queryManager를 통해 kiosk.altimedia.com/api의 LLM 에이전트 서버에 POST하여 주문 의도·메뉴 안내·일반 질문을 해석합니다. 현재 auto_query 엔드포인트 하나로 의도 분류까지 위임합니다.

기능 개요

STT로 얻은 발화 텍스트는 LLM 에이전트 서버가 해석합니다. useLLMQuerySequence 훅이 사용자 발화와 직전 대화 이력(queryList)을 합쳐 LLMManager.querySequence()를 호출하면, 매니저 내부에서 autoQuery()가 이전 대화(previous)와 신규 발화(user)를 JSON으로 직렬화해 queryManager.autoQuery()로 넘깁니다.

queryManager는 SERVER_URL = https://kiosk.altimedia.com/api/의 엔드포인트들(default_query·order_query·beverage_query·other_query·auto_query)을 정의하고 있지만, 현재 운영 경로는 의도 분류까지 서버에 위임하는 auto_query 한 곳입니다. 응답은 rxjs ajax 래퍼(axios-observable 기반, 2회 재시도)로 받아 subscribe 콜백에 전달됩니다.

응답 JSON에는 type(new/edit/mix/order/suggestion 등)·message(음성 안내용 문구)·response(주문 메뉴 목록)가 담깁니다. useLLMQuerySequence는 주문류 응답이면 validateOrderQuery로 메뉴 카탈로그에 존재하는 항목만 걸러 queryList에 누적하고, useTTS가 true이면 message를 음성으로 안내합니다.

설계 포인트
가장 최근 커밋(modify llm agent server url)이 이 서버 URL을 변경한 작업입니다. LLMManager에는 defaultQuery/orderQuery/beverageQuery/otherQuery도 남아 있으나 현재 querySequence는 autoQuery만 사용하도록 단순화되어 있습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant HK as useLLMQuerySequence participant LLM as LLMManager participant QM as queryManager participant AJ as ajax-rxjs (axios-observable) participant SRV as LLM 에이전트 서버 participant TTS as TTSManager HK->>LLM: querySequence(newQueryList, null, useTTS, cb) LLM->>LLM: autoQuery() — previous+user JSON 직렬화 LLM->>QM: autoQuery(query, resultCallback) QM->>AJ: ajax.send(SERVER_URL+auto_query, post) AJ->>SRV: POST /api/auto_query SRV-->>AJ: 응답 JSON (type/message/response) AJ-->>QM: x.data QM-->>LLM: result alt useTTS && result.message LLM->>TTS: handleTts(result.message) end LLM-->>HK: callback(true, data, 'auto') HK->>HK: validateOrderQuery → queryList 누적

흐름. 훅이 누적 대화와 신규 발화를 매니저에 넘기면 autoQuery가 JSON을 만들어 auto_query 엔드포인트로 POST합니다. 응답 message는 TTS로 안내되고, 주문 응답은 검증 후 대화 이력에 쌓입니다.

클래스 다이어그램

classDiagram class useLLMQuerySequence { +asyncQuerySequence(content, useTTS) Promise -validateOrderQuery(data) -createUserQuery(content) -convertCartToServerData(cartItem) } class LLMManager { -running +initialize() +querySequence(newQuery, prevQuery, useTTS, cb) +autoQuery(newQuery, prevQuery, useTTS, cb) +defaultQuery(...) +orderQuery(...) } class queryManager { +autoQuery(query, subscriber) +defaultQuery(query, subscriber) +orderQuery(query, subscriber) +beverageQuery(query, subscriber) +otherQuery(query, subscriber) } class ajax { +send(url, method, data) Observable } class TTSManager { +handleTts(text) } useLLMQuerySequence --> LLMManager : querySequence LLMManager --> queryManager : autoQuery LLMManager --> TTSManager : message 음성 안내 queryManager --> ajax : POST 요청

관계. 훅 → LLMManager → queryManager → ajax 순으로 위임되며, 응답 message는 TTSManager로 음성 안내됩니다. 의도 분류는 서버의 auto_query가 담당합니다.

핵심 코드

src/voice/LLMManager.js — auto_query 직렬화와 응답 처리
querySequence: function(newQuery, prevQuery, useTTS, callback) {
    var sequenceCallback = function(result, data, type) {
        if (callback) callback(result, data, type);
    }
    self.autoQuery(newQuery, prevQuery, useTTS, sequenceCallback);
},

autoQuery: function(newQuery, prevQuery, useTTS, callback) {
    var query;
    if (prevQuery) {
        query = JSON.stringify({previous: prevQuery}) + "," + JSON.stringify({user: newQuery});
    } else {
        query = newQuery;
    }
    queryManager.autoQuery(query, async function(result) {
        if (typeof result == 'string') result = JSON.parse(result);
        if (useTTS && result.message) {
            await TTSManager.handleTts(result.message);   // 응답 음성 안내
        }
        if (result.message == 'ERROR') callback(false, result, 'auto');
        else                          callback(true,  result, 'auto');
    });
},
src/api/queryManager.js — 엔드포인트 정의와 rxjs ajax POST
const SERVER_URL = "https://kiosk.altimedia.com/api/";

autoQuery: function (query, subscriber) {
    log.debug('autoQuery');
    return ajax.send(SERVER_URL + 'auto_query', 'post', query, null, null, null)
               .subscribe(subscriber);
},
