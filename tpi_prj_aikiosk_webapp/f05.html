기능 개요

Data.js는 키오스크가 다루는 모든 메뉴와 옵션의 단일 출처입니다. 최상위 data.menus 배열에 메뉴 객체들이 들어 있고, 각 메뉴는 name(한글명)·name_key(i18n 키)·category(coffee/juice/tea 등)·options·imgSrc·price·price_ibc·similars(STT 유사 오인식어)를 갖습니다.

옵션은 OptionType 열거(Temperature·Other·Blend)와 세부 타입(TempType HOT/ICE, otherType DECAFFEINE/SYRUP, BlendType MILD/THICK)으로 구성됩니다. 각 메뉴의 options 항목은 { name, detail, default } 형태이며, 예컨대 아메리카노는 온도(HOT 기본)·기타(디카페인/시럽)·블렌드를 갖고, 벌크업 아메리카노는 온도 ICE 단일 옵션만 가집니다. 단일 옵션 메뉴의 default 값은 음성 주문 시 기본 적용 로직(f06)의 근거가 됩니다.

메뉴 이미지는 빌드 시점에 Vite의 import.meta.glob("@assets/MenuImage/Coffee/*", { eager: true })로 폴더별 일괄 import한 뒤, getImgSrcArrayFromImagesObj로 .default(URL) 배열을 만들어 메뉴 인덱스에 매핑합니다. 벌크업 샘플 이미지처럼 개별 import도 일부 사용합니다.

활용처
이 카탈로그는 메뉴 화면 렌더링뿐 아니라 부팅 시 STT PhraseList 생성(f09)과 음성 주문 검증(validateOrderQuery가 menus에 존재하는 메뉴만 통과)에도 쓰입니다. 즉 화면·음성 인식·주문 검증이 모두 같은 메뉴 정의를 참조합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant V as Vite (빌드/로드) participant DATA as Data.js participant MENU as MenuList / MenuListItem participant STT as main.jsx (PhraseList) participant VAL as useLLMQuerySequence V->>DATA: import.meta.glob(MenuImage/*) eager DATA->>DATA: getImgSrcArrayFromImagesObj → imgSrc 매핑 MENU->>DATA: data.menus 구독/렌더 STT->>DATA: menus.forEach → name_key로 PhraseList 구성 VAL->>DATA: menus.find(name) — 주문 메뉴 검증

흐름. 빌드 시 이미지가 glob으로 로드되어 메뉴에 매핑되고, 정의된 data.menus는 화면 렌더·STT PhraseList·주문 검증 세 곳에서 공통 참조됩니다.

클래스 다이어그램

classDiagram class Data { +data -coffeeImageArray -juiceImageArray -teaImageArray +getImgSrcArrayFromImagesObj(obj) } class Menu { +name +name_key +category +options +imgSrc +price +price_ibc +similars } class MenuOption { +name +detail +default } class OptionType { <<enumeration>> TEMPERATURE OTHER BLEND } class TempType { <<enumeration>> HOT ICE } Data o-- Menu : data.menus Menu o-- MenuOption : options MenuOption ..> OptionType MenuOption ..> TempType

관계. Data가 Menu 목록을 소유하고, 각 Menu는 MenuOption들을 가집니다. 옵션 이름·세부값은 OptionType·TempType 등 열거를 참조합니다.

핵심 코드

src/Data.js — 이미지 glob 로드와 옵션 열거
const CoffeeImagesObj = import.meta.glob("@assets/MenuImage/Coffee/*", { eager: true });

const getImgSrcArrayFromImagesObj = (obj) => {
    let arr = [];
    for (const key in obj) { arr.push(obj[key].default); }
    return arr;
};
let coffeeImageArray = getImgSrcArrayFromImagesObj(CoffeeImagesObj);

export const TempType   = { HOT: "option.hot", ICE: "option.cold" };
export const otherType  = { DECAFFEINE: "option.decaffeine", SYRUP: "guide.syrup" };
export const BlendType  = { MILD: "guide.mild", THICK: "guide.thick" };
export const OptionType = { TEMPERATURE: "Temperature", OTHER: "Other", BLEND: "Blend" };
src/Data.js — 메뉴 정의 (아메리카노 예시)
{
    name: "아메리카노",
    name_key: "menu.coffee_americano",
    category: "coffee",
    options: [
        { name: TEMPERATURE, detail: [HOT, ICE], default: HOT },
        { name: OTHER,       detail: [DECAFFEINE, SYRUP] },
        { name: BLEND,       detail: [MILD, THICK] },
    ],
    imgSrc: coffeeImageArray[0],
    price: 3500,
    price_ibc: 1.5,
    similars: [" 메리카노", " 매리카노", " 아매리카노", " 아메리카누"],
}
