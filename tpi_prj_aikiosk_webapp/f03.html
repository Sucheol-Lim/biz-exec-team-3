음성 안내 (TTS)

TTSManager.handleTts가 LLM 응답 메시지를 음성으로 합성합니다. 언어와 Config.APP_KOR_TTS 설정에 따라 KT GiGA Genie TTS와 Azure TTS(ko-KR-SunHiNeural / en-US-JaneNeural)로 분기합니다.

기능 개요

음성 안내(TTS)는 LLM 응답의 message 문구를 사람이 듣는 음성으로 합성하는 단계입니다. 진입점은 TTSManager.handleTts(text) 하나이며, 내부에서 현재 언어(i18n)와 Config.APP_KOR_TTS 토글을 보고 두 엔진 중 하나로 분기합니다.

영어(en)이거나 한국어 TTS 서버가 AZURE로 설정된 경우 AzureTTSManager.handleTts를 사용합니다. 이때 언어에 맞춰 음성 모델을 바꾸는데, 영어는 en-US-JaneNeural(speed 20), 한국어는 ko-KR-SunHiNeural(speed 5)을 적용하고 SSML prosody/mstts:express-as로 속도·스타일을 지정한 뒤 speakSsmlAsync로 합성합니다. 합성된 오디오는 풀 스트림으로 받아 SingletonAudioPlayer로 재생합니다.

그 외(현재 기본값인 한국어 + KT)에는 KTTTSManager.handleTts를 사용합니다. KT 경로는 GiGA Genie OpenAPI 인증(UUID 발급/재사용)을 거쳐 시그니처가 포함된 헤더로 TTS 요청을 보내고, 응답 WAV 버퍼를 재생합니다. Config.js의 현재 기본값은 APP_AZURE_SPEECH_REGION = KOREA, APP_KOR_TTS = KT입니다.

설계 포인트
handleTts는 입력 텍스트에서 줄바꿈(\n)을 제거해 합성합니다(remove \n on tts text 커밋). 새 발화가 들어오면 이전 합성/재생을 AbortController와 handleStopAudio로 중단해 음성이 겹치지 않게 합니다.

흐름. handleTts 단일 진입점이 언어·설정을 보고 Azure 또는 KT 엔진으로 분기합니다. 두 엔진 모두 합성 결과 오디오를 플레이어로 재생합니다.

관계. TTSManager가 Config와 언어를 보고 AzureTTSManager 또는 KTTTSManager로 위임합니다. KT 경로는 KtApi로 OpenAPI를 호출합니다.

핵심 코드

src/voice/TTSManager.js — 언어/설정 기반 엔진 분기
handleTts : async (_inputText) => {
    if (i18n.language == "en" || Config.APP_KOR_TTS == "AZURE") {
        if (Config.APP_KOR_TTS == "AZURE") {
            if (i18n.language == "en") {
                AzureTTSManager.handleChangeVoice("en-US-JaneNeural");
                AzureTTSManager.setSpeed(20);
            } else {
                AzureTTSManager.handleChangeVoice("ko-KR-SunHiNeural");
                AzureTTSManager.setSpeed(5);
            }
        }
        await AzureTTSManager.handleTts(_inputText?.replace("\n", ""));
    } else {
        await KTTTSManager.handleTts(_inputText);
    }
},
src/voice/AzureTTSManager.js — SSML 합성
var ssml = `<speak version="1.0" xml:lang="ko-KR">
    <voice name='${selectedVoice}'>
        <prosody rate="${selectedSynthesizeRate}%" volume="${selectedSynthesizeVolume}" pitch="${selectedVoicePitch}">
            <mstts:express-as style="${selectedVoiceStyle}" styledegree="2">
                ${text}
            </mstts:express-as>
        </prosody>
    </voice>
</speak>`;
synthesizer.speakSsmlAsync(ssml, complete_cb, err_cb);
