STT 인식 보정 (PhraseList)

메뉴명과 "아아", "뜨아", "한잔", "시럽 추가" 같은 카페 구어체를 Azure STT PhraseList에 등록하고, 인식 결과는 STTModifier로 오인식어를 치환해 한국어 주문 인식 정확도를 높입니다.

기능 개요

카페 주문 발화는 메뉴명·수량·구어체가 섞여 한국어 STT가 자주 오인식합니다. 이 앱은 두 단계로 정확도를 끌어올립니다. 첫째는 인식 전 단계인 PhraseList(사전 힌트)이고, 둘째는 인식 후 단계인 STTModifier(치환 보정)입니다.

PhraseList는 부팅 시 main.jsx에서 구성됩니다. data.menus를 ko/en으로 각각 순회하며 메뉴명을 추출해 세미콜론으로 이은 뒤, 한국어에는 "하나·한개·둘·한잔·두잔·시럽·시럽 추가·아아·뜨아" 같은 카페 구어체를 덧붙입니다. 완성된 문자열을 AzureSTTManager.setPhraseListKR/EN으로 매니저에 보관해 두고, 인식 시작 시 PhraseListGrammar.fromRecognizer(recognizer).addPhrase(...)로 Azure SDK 인식기에 적용합니다(언어별 분기).

STTModifier는 인식이 끝난 텍스트를 정규식으로 치환합니다. "실험/시업/취업"→"시럽", "환전/한전/운전"→"한잔", "코드브루/골드브루"→"콜드브루", "벌컥/벌컵/베컴"→"벌크업"처럼 100여 개의 오인식 보정 세트가 정의되어 있고(add stt modification sets 커밋), 메뉴별 similars도 함께 적용됩니다. useSTT가 최종 결과에 이 보정을 걸어 LLM 질의로 넘깁니다.

설계 포인트
PhraseList는 Azure 엔진이 후보 단어를 우선 인식하도록 돕는 사전 힌트이고, STTModifier는 그래도 남은 오인식을 사후 규칙으로 교정합니다. 두 단계가 보완 관계로 동작해 카페 도메인 발화 인식률을 높입니다.

핵심 코드

src/main.jsx — 메뉴명 + 구어체로 PhraseList 구성
i18n.changeLanguage("en");
data.menus.forEach((m) => { enPhrase += i18n.t(m.name_key) + ";"; });

i18n.changeLanguage("ko");
data.menus.forEach((m) => { krPhrase += i18n.t(m.name_key) + ";"; });
krPhrase += "하나;한개;둘;두개;세개;네개;다섯;한잔;두잔;세잔;네잔;시럽;시럽 추가;아아;뜨아;";

AzureSTTManager.setPhraseListEN(enPhrase);
AzureSTTManager.setPhraseListKR(krPhrase);
src/util/STTModifier.js — 오인식어 사후 치환
const modifications = [
    new ModificationSet("실험", "시럽"),
    new ModificationSet("환전", "한잔"),
    new ModificationSet("코드브루", "콜드브루"),
    new ModificationSet("벌컵", "벌크업"),
    /* ...100여 개의 보정 세트... */
];

export const STTModifier = (sttText) => {
    let result;
    [...similars, ...modifications].forEach((item) => {
        result = (result ? result : sttText).replace(new RegExp(item.asIs, "g"), item.toBe);
    });
    return result;
};
