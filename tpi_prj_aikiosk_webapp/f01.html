음성 주문 (STT)

Azure Cognitive Services Speech SDK로 마이크 입력을 받아 "아메리카노 한 잔" 같은 자연어 발화를 텍스트로 변환합니다. 타임아웃 기반 연속 인식(startSpeechRecognition)과 1회 인식(startSpeechRecognitionOnce) 두 방식을 제공합니다.

기능 개요

음성 주문의 첫 단계는 사용자의 발화를 텍스트로 옮기는 STT(Speech-to-Text)입니다. 메뉴 화면에서 마이크 버튼을 누르면 useSTT 훅의 startSTTAsync()가 호출되고, 이 훅은 단말이 Android WebView인지에 따라 AzureSTTManager.azureMicOpen(브라우저 마이크) 또는 azureMicOpenAndroid(네이티브 브리지)를 선택해 호출합니다. 브라우저 경로에서는 Azure Speech SDK의 SpeechRecognizer가 기본 마이크 입력을 받아 인식합니다.

AzureSTTManager는 두 가지 인식 방식을 제공합니다. startSpeechRecognition(timeout)은 startContinuousRecognitionAsync로 연속 인식을 시작하고, 중간 결과(recognizing)와 최종 결과(recognized)를 받을 때마다 타임아웃을 갱신하다가 발화가 인식되면 azureMicClose()로 마이크를 닫고 콜백에 텍스트를 넘깁니다. startSpeechRecognitionOnce(timeout)은 recognizeOnceAsync로 한 문장만 인식하는 단발 모드입니다. 인식 언어는 i18n 현재 언어에 따라 ko-KR 또는 en-US로 설정됩니다.

인식 결과 텍스트는 voice-state-store의 setSTTText로 화면에 실시간 반영되고, 최종 결과는 useSTT에서 STTModifier로 오인식을 보정한 뒤 LLM 질의로 넘어갑니다.

설계 포인트
마이크 시작 직전 onBeforeRecordStartAsync 콜백이 실행되어 "삐" 안내음(siri_open.wav)을 재생합니다. 인식이 일정 시간 무음이면 타임아웃이 발동해 azureMicClose()로 마이크를 자동 종료하고 자원을 회수합니다.

흐름. 마이크 버튼 → useSTT → AzureSTTManager가 SDK 인식기를 만들고 PhraseList를 적용한 뒤 연속 인식을 시작합니다. 중간/최종 결과가 스토어에 반영되고, 최종 텍스트는 보정 후 다음 단계(LLM 질의)로 넘어갑니다.

관계. useSTT가 진입점이 되어 싱글턴 AzureSTTManager를 제어하고, 매니저는 Azure SDK의 SpeechRecognizer를 직접 다루며 결과를 voice-state-store에 반영합니다. 최종 텍스트는 STTModifier로 보정됩니다.

핵심 코드

src/voice/AzureSTTManager.js — 연속 인식 시작과 언어/PhraseList 적용
recognizer = new SpeechRecognizer(speechConfig, audioConfig);

phraseListGrammar = PhraseListGrammar.fromRecognizer(recognizer);
if (i18n.language == "en") {
    phraseListGrammar.addPhrase(phraseListEN);
} else {
    phraseListGrammar.addPhrase(phraseListKR);
}

recognizer.recognizing = (s, e) => processRecognizingTranscript(e);
recognizer.recognized  = (s, e) => processRecognizedTranscript(e);

recognizer.startContinuousRecognitionAsync(
    () => {
        timeoutId = setTimeout(() => {
            self.azureMicClose();          // 무음 타임아웃 시 마이크 종료
            if (self.callback) { self.callback(false); self.callback = null; }
        }, timeout);
    },
    (err) => console.error("Error starting recognition(CONTINOUS):", err)
);
src/hook/useSTT.jsx — 마이크 개폐 선택과 결과 보정
const isAndroid = /Android/i.test(window.navigator.userAgent) && window.android;
const azureMicOpen  = isAndroid ? AzureSTTManager.azureMicOpenAndroid  : AzureSTTManager.azureMicOpen;

azureMicOpen((result, data) => {
    if (result) {
        let newSTTText = STTModifier(data);          // 오인식 보정
        setSTTText(newSTTText ? STTModifier(data) : "");
        resolve(newSTTText);
    } else if (getSTTText()) {
        setSTTText(STTModifier(getSTTText()));
        resolve(getSTTText());
    } else {
        reject("voice recog result false");
    }
});
