다국어 (i18n) 지원

i18next/react-i18next로 한국어·영어를 지원합니다. 기본 한국어, 폴백 영어이며, 현재 언어(i18n.language)에 따라 STT 인식 언어(ko-KR/en-US)와 TTS 음성이 함께 전환됩니다.

기능 개요

국제화는 locales/i18n.js가 i18next에 react-i18next 플러그인을 붙여 초기화합니다. 번역 리소스는 assets/locales/ko/common.json과 en/common.json이고, 기본 언어 lng: "ko", 폴백 fallbackLang: "en"입니다. returnObjects·returnEmptyString·returnNull 옵션을 켜 객체 형태 번역과 빈 문자열 반환을 허용하고, react.useSuspense: false로 서스펜스 없이 동기 렌더링합니다.

i18n은 단순 화면 문구 전환을 넘어 음성 파이프라인 전체의 언어를 결정합니다. STT는 AzureSTTManager가 i18n.language == "en"이면 en-US, 아니면 ko-KR로 인식 언어를 설정하고 언어별 PhraseList를 적용합니다. TTS는 TTSManager.handleTts가 영어이면 Azure en-US-JaneNeural, 한국어이면 KT TTS(또는 Azure ko-KR-SunHiNeural)로 분기합니다. 부팅 시 PhraseList 구성도 ko/en을 번갈아 changeLanguage하며 양쪽 메뉴명을 추출합니다.

번역 데이터(common.json)는 운영 도구 spreadsheet.js로 관리됩니다. 구글 서비스 계정으로 스프레드시트를 읽어 ko/en JSON을 생성하는 npm run i18n 스크립트가 별도로 제공됩니다(빌드와 분리된 단계).

설계 포인트
언어 전환의 단일 진실은 i18n.language입니다. 화면 텍스트(t())·STT 인식 언어·TTS 음성이 모두 이 값을 참조하므로, 언어 버튼 하나로 입력·출력·UI가 일관되게 바뀝니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant BTN as LanguageButton participant I18N as i18next participant UI as 화면 컴포넌트 (t) participant STT as AzureSTTManager participant TTS as TTSManager BTN->>I18N: changeLanguage("en" / "ko") I18N-->>UI: 리렌더 (t로 문구 갱신) Note over STT: 인식 시작 시 i18n.language 참조 STT->>STT: ko-KR / en-US + 언어별 PhraseList Note over TTS: handleTts 시 i18n.language 참조 TTS->>TTS: ko KT/Azure · en Azure(JaneNeural)

흐름. 언어 변경 한 번이 화면 문구, STT 인식 언어, TTS 음성을 모두 전환합니다. STT·TTS는 각 시점에 i18n.language를 읽어 분기합니다.

클래스 다이어그램

관계. i18next가 ko/en 리소스를 로드하고, STT·TTS 매니저가 i18n.language를 참조해 분기합니다. 번역 JSON은 spreadsheet.js가 외부 시트에서 생성합니다.

핵심 코드

src/locales/i18n.js — i18next 초기화 (ko 기본, en 폴백)
const resources = {
    en: { translation: translationEN },
    ko: { translation: translationKO },
};

i18n.use(initReactI18next).init({
    resources,
    lng: "ko",
    fallbackLang: "en",
    interpolation: { escapeValue: false },
    returnObjects: true,
    returnEmptyString: true,
    returnNull: true,
    react: { useSuspense: false },
});
src/voice/AzureSTTManager.js — 언어에 따른 STT 인식 언어 전환
if (i18n.language == "en") {
    speechConfig = SpeechConfig.fromSubscription(subscriptionKey, region);
    speechConfig.speechRecognitionLanguage = 'en-US';
} else {
    speechConfig = customUrl
        ? SpeechConfig.fromEndpoint(customUrl, subscriptionKey)
        : SpeechConfig.fromSubscription(subscriptionKey, region);
    speechConfig.speechRecognitionLanguage = 'ko-KR';
}
