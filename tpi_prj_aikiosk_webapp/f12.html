볼륨 제어

VolumeManager가 Android 단말 볼륨 브리지를 호출하고 volume-store가 현재/최대 볼륨을 보관하며, useAndroidVolume 훅이 증감·효과음 재생을 제공합니다.

기능 개요

음성 안내(TTS)가 핵심인 키오스크이므로 단말 볼륨을 다룰 수 있어야 합니다. 볼륨 제어는 세 계층으로 나뉩니다. VolumeManager(브리지), volume-store(상태), useAndroidVolume(UI 로직)입니다.

VolumeManager는 window.android 네이티브 인터페이스를 감싼 어댑터입니다. getVolume·getMaxVolume·setVolume으로 단말 볼륨을 읽고 쓰며, initialize() 때 window.android.setVolumeCallback("volumeChangeCallback")로 단말의 하드웨어 볼륨 변경 콜백을 등록합니다. 단말이 볼륨을 바꾸면 volumeChangeCallback(volume)이 호출되어 스토어에 반영되므로, 물리 볼륨 버튼 조작과 앱 상태가 동기화됩니다.

volume-store는 currentVolume(기본 7)과 maxVolume(기본 15)을 보관합니다. setVolume은 스토어 값을 갱신하면서 VolumeManager.setVolume(volume / maxVolume)로 0~1 정규화 비율을 단말에 전달합니다. useAndroidVolume 훅은 increaseVolume/decreaseVolume로 0~최대 범위 내 증감을 처리하고, 변경 시 "blop" 효과음(MP_Blop.mp3)을 재생해 사용자에게 피드백을 줍니다. 화면에서는 VolumeControl 컴포넌트가 이 훅을 사용합니다.

설계 포인트
앱 상태(volume-store)와 단말 볼륨은 양방향 동기화됩니다. 앱에서 바꾸면 브리지로 단말에 반영되고, 단말 하드웨어 키로 바꾸면 콜백으로 스토어에 반영됩니다. 정규화 비율(0~1)로 단말과 통신해 단말 최대 볼륨 스케일에 의존하지 않습니다.

클래스 다이어그램

관계. 훅이 스토어를, 스토어가 매니저를 호출하고, 매니저가 Android 브리지를 다룹니다. 단말 콜백은 매니저를 거쳐 다시 스토어로 반영됩니다.

핵심 코드

src/util/VolumeManager.js — 단말 볼륨 브리지와 콜백 등록
initialize: function () {
    window.VolumeManager = this;
    window.volumeChangeCallback = this.volumeChangeCallback.bind(this);
    if (window.android && window.android.setVolumeCallback) {
        window.android.setVolumeCallback("volumeChangeCallback");   // 하드웨어 키 콜백
    }
},
setVolume: function (volume) { return window?.android?.setVolume(volume); },
volumeChangeCallback: function (volume) {
    useVolumeStore.getState().setVolume(volume);                    // 단말 → 스토어
},
src/store/volume-store.js — 정규화 비율로 단말에 전달
setVolume: (volume) => {
    set((state) => {
        VolumeManager.setVolume(volume / state.maxVolume);   // 0~1 정규화
        return { currentVolume: +volume };
    });
},
