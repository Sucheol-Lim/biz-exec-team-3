세로 대화면 줌 보정

main.jsx가 window.onload 시점에 window.innerHeight / 1480 비율을 계산해 body의 CSS zoom을 설정하고, 924x1480 고정 레이아웃을 세로형 키오스크 단말 화면에 맞춥니다.

기능 개요

이 앱은 모든 화면을 924px × 1480px 고정 픽셀 기준으로 그립니다. src/index.css의 body는 width: 924px; height: 1480px;로 고정되어 있고 position: fixed로 스크롤 없이 한 화면에 배치됩니다. 대상 단말인 삼성 갤럭시 탭 S8의 세로형 표시 영역과 정확히 일치하는 좌표계입니다. 그러나 실제 WebView·브라우저의 표시 높이는 단말·환경마다 달라서, 고정 1480px 레이아웃을 그대로 두면 화면이 잘리거나 여백이 생깁니다.

이를 보정하기 위해 부트스트랩 단계인 main.jsx가 window.onload 콜백으로 InitializeWindow()를 등록합니다. 이 함수는 현재 표시 높이 window.innerHeight를 디자인 기준 높이 1480으로 나눠 백분율을 만들고, modifyWindowZoom()이 document.body.style["zoom"]에 그 값을 적용합니다. 예를 들어 표시 높이가 1184px이면 (1184 / 1480) × 100 = 80%로 축소되어 1480px 레이아웃 전체가 화면 안에 들어옵니다. 폭이 아니라 높이를 기준으로 잡는 이유는 세로형(portrait) 키오스크에서 세로가 잘리지 않는 것이 우선이기 때문입니다.

CSS zoom 속성은 레이아웃 좌표계 전체를 비율로 확대·축소하므로, 화면 내 모든 컴포넌트가 924x1480 기준 좌표를 그대로 쓰면서도 단말 해상도에 자동으로 맞춰집니다. 별도의 반응형 미디어쿼리나 컴포넌트별 스케일 처리 없이 한 줄의 zoom 보정으로 전체 화면을 단말에 적합화하는 단순한 방식입니다.

설계 포인트
보정 기준은 innerWidth가 아니라 innerHeight입니다. 세로형 키오스크에서는 세로 길이가 핵심 제약이므로, 높이 비율로 zoom을 잡으면 1480px 세로 콘텐츠가 단말 높이에 정확히 맞춰지고 가로는 동일 비율로 따라 줄어듭니다. zoom 계산과 로그 출력은 CommonLog debug 레벨로 남깁니다.

관계. 부트스트랩 모듈이 window.innerHeight를 읽어 zoom 비율을 산출하고 body에 적용합니다. index.css가 정한 924x1480 고정 좌표계가 zoom 보정의 기준이 됩니다.

핵심 코드

src/main.jsx — onload 시 높이 비율로 body zoom 보정
function InitializeWindow() {
  log.debug(`window innerHeight = ${window.innerHeight}`);
  modifyWindowZoom(document.body, (window.innerHeight / 1480) * 100);
}

function modifyWindowZoom(domElement, percentage) {
  log.debug(`window zoom to ${percentage}%`);
  domElement.style["zoom"] = percentage + "%";
}

window.onload = InitializeWindow;
src/index.css — 924x1480 고정 레이아웃 기준
body {
  margin: 0;
  position: fixed;
  display: flex;
  place-items: center;
  width: 924px;
  height: 1480px;
  background-color: #fff;
  user-select: none;
}
