기능 개요

장바구니는 cart-store(zustand) 하나로 관리됩니다. 상태는 담긴 항목 배열 cartList와 매장/포장 여부 hereTogo로 단순하게 구성됩니다. 각 항목은 CartListItem 인스턴스로, 고유 id(crypto.randomUUID())·메뉴(item)·수량(quantity)·옵션(ClientOption)을 가집니다.

담기(addCart/addCartItems)는 같은 메뉴이면서 옵션까지 동일한지(cartItem.options.isEqual(item.options))를 확인해, 동일하면 기존 항목의 수량을 더하고 다르면 새 항목으로 추가합니다. 수량은 setQuantity에서 최대 99로 제한됩니다. 매장/포장은 setHereTogo로 지정하며, 이 값은 음성으로 "매장에서/포장이요"라고 말하거나 HereTogoPopup 터치로 정해집니다.

총합 계산은 getTotalPrice(매장 가격 price)·getTotalPriceIBC(IBC 데모 가격 price_ibc)·getTotalQuantity가 각각 cartList.reduce로 합산합니다. Cart 화면이 이 값들을 구독해 합계와 항목 목록을 표시하고, 결제 단계로 넘어갑니다.

설계 포인트
옵션 비교 isEqual은 디카페인(no) 미선택과 시럽(yes) 미선택을 "같은 것"으로 묶는 느슨한 동등 비교를 적용합니다. 즉 옵션을 명시하지 않은 두 주문이 불필요하게 별도 항목으로 쪼개지지 않게 합니다.

흐름. 음성 주문 항목이 CartListItem으로 변환되어 스토어에 담기고, 동일 항목은 수량 합산됩니다. 매장/포장 여부와 합계는 Cart 화면에서 표시됩니다.

관계. cart-store가 CartListItem 목록을 소유하고, 각 항목은 ClientOption을 가집니다. 합계는 항목들의 getTotalPrice를 reduce해 구합니다.

핵심 코드

src/store/cart-store.js — 담기(동일 항목 수량 합산)와 합계
addCart: (item) => {
    return set((state) => {
        let existingItem = state.cartList.find((cartItem) => {
            const isSameItem   = cartItem.item.name == item.item.name;
            const isSameOption = cartItem.options.isEqual(item.options);
            return isSameItem && isSameOption;
        });
        let newCartList;
        if (existingItem) {
            existingItem.setQuantity(+existingItem.quantity + +item.quantity);
            newCartList = [...state.cartList];
        } else {
            newCartList = [...state.cartList, item];
        }
        return { cartList: newCartList };
    });
},
getTotalPrice: () => get().cartList.reduce((acc, item) => acc + item.getTotalPrice(), 0),
setHereTogo: (value) => set({ hereTogo: value }),
src/util/CartList.js — 장바구니 항목 모델
export default class CartListItem {
    constructor(item, quantity = 1, options = new ClientOption()) {
        this.id = window.crypto.randomUUID();
        this.item = item;
        this.quantity = quantity;
        this.options = options;
    }
    setQuantity = (quantity) => { this.quantity = quantity > 99 ? 99 : quantity; return this; };
    getTotalPrice = () => this.item?.price * this.quantity;
}
