기능 개요

실제 결제 단말 연동 대신, 이 키오스크는 카드 삽입·영수증 출력 과정을 PNG 시퀀스 애니메이션으로 시뮬레이션해 데모 흐름을 완성합니다. 결제 화면(/purchase/pay)에서 시작해 카드 삽입 화면(/purchase/card, InsertCard)으로 진입하면, 한국어 환경에서는 CardSequence가 카드 삽입 애니메이션 프레임을 순환 재생합니다.

CardSequence는 import.meta.glob("...Animation/Paying/01_카드삽입/*", { eager: true })로 프레임 이미지를 일괄 로드해 배열로 만든 뒤, setTimeout 100ms 간격으로 인덱스를 증가시키며 img의 src를 교체합니다. 끝에 도달하면 인덱스를 0으로 되돌려 루프 재생합니다. 음성 인식 파형 같은 다른 시퀀스는 공용 훅 usePNGSequence가 담당하지만, 카드 삽입은 단발 루프이므로 컴포넌트 내부에서 자체 타이머를 돌립니다.

InsertCard 화면은 마운트 시 useTTS로 안내 문구(info.helpCard)를 읽어 주고, 음성 안내가 끝나면 2초 뒤 setIsTimeout(true)를 통해 영수증 화면(/purchase/receipt)으로 자동 이동합니다. 사용자가 이전 버튼을 만지면 진행 타이머를 취소합니다. 영어 환경에서는 카드 태그 이미지(img_purchase_cardtap.png)를 정적으로 보여 줍니다.

설계 포인트
애니메이션 프레임은 폴더 단위 glob import라서 프레임을 추가/교체할 때 코드 수정 없이 에셋만 바꾸면 됩니다. 릴리스 빌드는 이 에셋들을 assets 청크로 분리하고 인라인 없이 패키징합니다(f15 참조).

흐름. 결제 화면에서 카드 삽입 화면으로 진입하면 안내 음성과 함께 카드 삽입 PNG 시퀀스가 루프 재생되고, 안내 종료 후 2초 뒤 영수증 화면으로 자동 진행합니다.

관계. InsertCard 화면이 CardSequence 애니메이션과 useTTS 안내를 함께 띄우고, 일정 시간 후 영수증 단계로 이동합니다.

핵심 코드

src/component/Purchase/CardSequence/CardSequence.jsx — 프레임 루프 재생
const CardInsertImgsObj = import.meta.glob(
    "../../../assets/Animation/Paying/01_카드삽입/*", { eager: true });
for (const img in CardInsertImgsObj) CardInsertArray.push(CardInsertImgsObj[img].default);

useEffect(() => {
    let timeout = setTimeout(() => {
        let index = currentSourceIndex + 1;
        if (index >= currentSequence.length) index = 0;   // 끝이면 루프
        setCurrentSourceIndex(index);
    }, 100);
    return () => clearTimeout(timeout);
}, [currentSourceIndex, currentSequence]);
src/page/Purchase/InsertCard/InsertCard.jsx — 안내 후 영수증 자동 진행
useEffect(() => {
    startTTS("info.helpCard").then(() => {
        if (isMounted()) {
            timeout = setTimeout(() => setIsTimeout(true), 2000);
        }
    });
    return () => clearTimeout(timeout);
}, [t]);

useEffect(() => { isTimeout && navigate("/purchase/receipt"); }, [isTimeout]);
