주문 옵션 처리

온도(HOT/ICE)·블렌드·디카페인·시럽 등 옵션을 음성과 터치로 선택합니다. voice-order-store가 음성 주문 항목의 옵션 충족 여부를 추적하고, 옵션이 하나뿐이면 기본값을 자동 적용해 주문을 보정합니다.

기능 개요

LLM 응답은 주문 메뉴와 함께 온도·디카페인·시럽·농도(블렌드) 등의 옵션을 담습니다. 서버 응답의 옵션 문자열은 ServerOption이 받아 "unknown"을 undefined로 정규화한 뒤 ClientOption으로 변환합니다. voice-order-store는 이렇게 만들어진 주문 항목 배열을 받아 메뉴·온도·수량이 모두 채워졌는지(isMenuOk·isTempOk·isQuantityOk)를 계산하고, 주문 상태를 DEFAULT·PARTIAL·OPTION·FINISH로 전이시킵니다.

옵션 선택은 음성과 터치 두 경로를 가집니다. 음성으로 "디카페인", "시럽 추가", "진하게" 등을 말하면 스토어의 setDecaffeineOption·setSyrupOption·setDepthOption이 해당 옵션이 정의된 메뉴 항목에만 값을 채웁니다(메뉴가 그 옵션을 갖는지 hasDecaffeineOption 등으로 확인). 터치 경로에서는 OptionChipList가 화면에 옵션 칩을 띄워 같은 스토어 액션을 호출합니다.

옵션이 사실상 하나뿐인 메뉴(예: 벌크업 아메리카노의 온도 ICE)는 사용자가 따로 고르지 않아도 되도록 default 값을 자동 적용합니다. 이 보정은 modify voice order logic, apply default temp if there is only one option 커밋으로 도입되었고, 메뉴 정의(Data.js)의 default 필드를 근거로 합니다.

설계 포인트
옵션 충족 여부에 따라 VoiceArea UI가 달라집니다. 모든 필수 옵션이 차면 FINISH로 전이해 장바구니 담기 흐름으로 이어지고, 부족하면 OptionChipList로 추가 선택을 유도합니다.

흐름. 응답 옵션이 정규화되어 스토어에 들어가면 충족 여부가 계산됩니다. 단일 옵션은 기본값을 자동 적용하고, 부족하면 칩으로 추가 선택을 받은 뒤 FINISH에서 장바구니로 넘어갑니다.

핵심 코드

src/store/voice-order-store.js — 옵션 충족 계산과 상태 전이
setStateWithItemArray: (newItemArray) => {
    let menuAllExist = true, tempAllExist = true, quantityAllExist = true;
    newItemArray.forEach((newItem) => {
        if (!newItem.item)          menuAllExist = false;
        if (!newItem.options.temp)  tempAllExist = false;
        if (!newItem.quantity)      quantityAllExist = false;
    });
    let newOrderState;
    if (menuAllExist && tempAllExist && quantityAllExist) {
        newOrderState = VOICE_ORDER_STATE_TYPE.FINISH;
    } else if (!menuAllExist && !tempAllExist && !quantityAllExist) {
        newOrderState = VOICE_ORDER_STATE_TYPE.DEFAULT;
    } else {
        newOrderState = VOICE_ORDER_STATE_TYPE.PARTIAL;
    }
    return set({ orderState: newOrderState, orderedItemArray: newItemArray,
        isTempOk: tempAllExist, isMenuOk: menuAllExist, isQuantityOk: quantityAllExist });
},
src/store/voice-order-store.js — 옵션 보유 메뉴에만 값 적용
setSyrupOption: (isSyrup) => {
    const newArray = [...get().orderedItemArray];
    newArray.forEach((item) => {
        const otherOption = item.item.options.find(
            (option) => option.name === OptionType.OTHER);
        if (!otherOption || !otherOption.detail.includes(otherType.SYRUP)) return;
        item.options.syrup = isSyrup ? "yes" : undefined;
    });
    return set({ orderedItemArray: [...newArray] });
},
