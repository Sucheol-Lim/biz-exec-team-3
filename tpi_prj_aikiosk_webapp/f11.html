미조작 타이머 · 도움말

기능 개요

무인 키오스크는 사용자가 도중에 떠나면 다음 손님을 위해 초기 상태로 돌아가야 합니다. 메뉴 화면(Menu.jsx)은 이를 위한 inactivity 타이머를 두 단계로 운용합니다. 1단계로 팝업이 닫혀 있고 시퀀스 재생 중이 아니며 경로가 /menu이면, popupTimeRef에 20초 타이머를 걸어 만료 시 도움말 팝업(PopupStateType.HELP, helpAccessibility 타입)을 엽니다.

2단계로 그 도움말 팝업이 열린 상태에서도 응답이 없으면, homeTimeRef에 7초 타이머를 걸어 만료 시 홈(/)으로 자동 이동시켜 세션을 초기화합니다. 사용자 터치(touchstart)가 발생하면 forceUpdate로 컴포넌트가 다시 렌더되며 clearInactivityTimeout()이 두 타이머를 모두 해제하고 다시 설정해, 조작이 있는 동안에는 팝업/홈 복귀가 미뤄집니다.

한편 VoiceArea는 별도의 10초 타이머(timerRef)로 추천 메뉴 도움 가이드(HelpGuide)를 띄우고 추천 안내 음성(speech_ai.recommendMenu)을 재생합니다. 이 가이드는 팝업이 없고 시퀀스가 재생 중이 아니며 음성 주문 상태가 DEFAULT일 때만 동작하고, 시퀀스가 시작되면 즉시 해제됩니다.

설계 포인트
두 화면 모두 useRef에 타이머 핸들을 보관하고 cleanup에서 clearTimeout으로 정리합니다. 페이지 경로(location.pathname)·팝업 여부·시퀀스 재생 여부를 조건으로 두어, 결제 등 다른 화면이나 음성 처리 중에는 타이머가 작동하지 않습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 사용자 participant MENU as Menu 화면 participant POP as popup-state-store participant NAV as Router Note over MENU: /menu, 팝업 닫힘, 시퀀스 미재생 MENU->>MENU: popupTimeRef = setTimeout(20s) alt 20초 무조작 MENU->>POP: openPopup(HELP, helpAccessibility) MENU->>MENU: homeTimeRef = setTimeout(7s) alt 다시 7초 무응답 MENU->>NAV: navigate("/") 홈 복귀 end else 사용자 터치 발생 U->>MENU: touchstart → forceUpdate MENU->>MENU: clearInactivityTimeout() 후 재설정 end

흐름. 20초 무조작이면 도움말 팝업, 이어 7초 무응답이면 홈 복귀입니다. 터치가 들어오면 타이머가 해제·재설정되어 복귀가 미뤄집니다.

클래스 다이어그램

관계. Menu 화면이 inactivity 타이머로 popup-state-store를 통해 도움말 팝업을 열고 홈 복귀를 트리거합니다. VoiceArea는 별도 가이드 타이머를 운용합니다.

핵심 코드

src/page/Menu/Menu.jsx — 도움말 팝업·홈 복귀 2단 타이머
useEffect(() => {
    clearInactivityTimeout();
    if (isPopupOpen) {
        if (popupLLMResult && popupLLMResult.type == "helpAccessibility") {
            homeTimeRef.current = setTimeout(() => {
                navigate("/");                       // 7초 무응답 → 홈 복귀
            }, 7000);
        }
    } else {
        if (!isSequencePlaying && location.pathname == "/menu") {
            popupTimeRef.current = setTimeout(() => {
                openPopup(PopupStateType.HELP, null, { type: "helpAccessibility" }); // 20초
                clearInactivityTimeout();
            }, 20000);
        }
    }
});
src/component/Menu/VoiceArea/VoiceArea.jsx — 추천 가이드 10초 타이머
const setTimer = () => {
    clearTimer();
    if (location.pathname !== "/menu") return;
    timerRef.current = setTimeout(() => {
        if (!showHelpGuide && isMounted() && !isSpoken) setShowHelpGuide(true);
        else setShowHelpGuide(false);
    }, 10000);
};
