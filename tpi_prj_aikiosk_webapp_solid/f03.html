TTS(음성 합성) 분기

한국어는 KT GiGA Genie OpenAPI TTS(기본 보이스 "다솜"), 영어는 Azure TTS로 분기합니다. 화면 안내 문구는 IBC TTS 경로로 음성 파일을 재생합니다.

기능 개요

응답 메시지의 음성 합성은 현재 언어(i18next.language)에 따라 서버가 갈립니다. TTSManager.handleTts가 진입점으로, 영어면 AzureTTSManager, 그 외(한국어)면 KTTTSManager로 위임합니다. 한국어 TTS는 KT GiGA Genie OpenAPI를 사용하며 기본 보이스는 "다솜"입니다. 영어 TTS는 Azure Speech의 SSML 합성을 사용해 en-US-JaneNeural 보이스로 재생합니다.

KT 경로는 호출 전 인증이 필요합니다. KTTTSManager.handleTts는 localStorage의 UUID를 확인해 없으면 newUUID로 새로 발급(getAuth → AddUser 엔드포인트)하고, 있으면 재사용합니다. 이후 runTextToSpeech가 HMAC-SHA256 서명(createSig)과 타임스탬프 헤더를 붙여 KT TTS 엔드포인트에 POST하고, 응답 arraybuffer(WAV)를 AudioPlayer로 디코딩·재생합니다. 화면 안내 문구는 별도로 IBCTTSManager.handleTts가 처리하는데, 영어이고 에셋 음성 파일이 있으면 @assets/voice/*에서 사전 녹음 파일을 재생하고, 그 외에는 다국어 키를 번역해 TTSManager.handleTts로 넘깁니다.

설계 포인트
KT TTS는 AbortController로 진행 중 합성을 취소할 수 있고, 응답 버퍼가 RIFF/WAVE 헤더를 갖췄는지 검증한 뒤에야 재생합니다. UUID 캐싱으로 매 요청마다 인증을 반복하지 않습니다.

핵심 코드

src/voices/TTSManager.js — 언어별 TTS 서버 분기
const TTSManager = {
  handleTts: async (_inputText) => {
    if (i18n.language == "en") {
      await AzureTTSManager.handleTts(_inputText);
    } else {
      await KTTTSManager.handleTts(_inputText);   // 기본 보이스 "다솜"
    }
  },
  handleStopAudio: () => {
    if (i18n.language == "en") AzureTTSManager.handleStopAudio();
    else KTTTSManager.handleStopAudio();
  },
};
src/voices/KTTTSManager.js — UUID 인증 후 KT TTS 요청
handleTts: async (_inputText) => {
  if (abortController) abortController.abort();
  stopTextToSpeech();
  abortController = new AbortController();
  const uuid = localStorage.getItem("UUID");
  inputText = _inputText;

  let kParams;
  if (!uuid) {                                   // UUID 신규 발급
    const params = { clientSecret: clientInfo.clientSecret, userId: clientInfo.userId,
                     clientId: clientInfo.clientId, clientKey: clientInfo.clientKey, uuid: "" };
    const newUuid = await newUUID(params, abortController.signal);
    kParams = { text: inputText, voiceModel: selectedVoice,
                sigParams: { ...params, uuid: newUuid }, speed: selectedSynthesizeRate };
  } else { /* UUID 재사용 */ }

  if (kParams) {
    const result = await runTextToSpeech(kParams, abortController.signal);  // WAV 재생
  }
},
