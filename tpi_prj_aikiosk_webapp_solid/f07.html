기능 개요

CartStore는 장바구니 목록(cartList)과 매장/포장 선택(hereTogo)을 시그널로 보관하는 전역 스토어입니다. 항목이 하나라도 있는지(hasCart), 총금액(totalPrice)·IBC 총금액(totalPriceIBC)·총수량(totalQuantity)은 createMemo로 목록에서 파생됩니다. 합계는 각 항목의 getTotalPrice()를 reduce로 합산해 구합니다.

장바구니 항목은 CartList.js의 CartListItem 클래스입니다. 생성 시 crypto.randomUUID()로 고유 id를 부여하고, 메뉴(item)·수량(quantity)·옵션(ItemOption)을 갖습니다. 수량은 1~99 범위로 증감(increaseQuantity·decreaseQuantity·setQuantity)되고, getTotalPrice는 메뉴 단가 × 수량으로 항목 금액을 계산합니다. 스토어는 항목 추가(addCartItems)·교체(setCartItems)·삭제(deleteItem, id 기준)·초기화(resetCart)를 제공하며, 옵션 팝업이나 음성 주문 응답이 이 API로 장바구니를 갱신합니다.

설계 포인트
삭제는 항목 id로 필터링하므로 같은 메뉴를 옵션만 다르게 여러 번 담아도 개별 삭제가 가능합니다. 소스 주석에 "같은 아이템이면 수량만 늘리기"가 TODO로 남아 있어, 현재는 동일 메뉴를 별도 항목으로 추가합니다.

핵심 코드

src/stores/CartStore.jsx — 합계 파생 + 항목 조작
const totalPrice = createMemo(() => {
  if (!hasCart()) return 0;
  return cartList().reduce((acc, item) => acc + item?.getTotalPrice?.(), 0);
});
const totalQuantity = createMemo(() => {
  if (!hasCart()) return 0;
  return cartList().reduce((acc, item) => +acc + +item?.quantity, 0);
});

const addCartItems = (itemArray) => setCartItems((prev) => [...prev, ...itemArray]);
const deleteItem = (item) =>
  setCartItems(cartList().filter((cartItem) => cartItem.id != item.id));
src/utils/CartList.js — 장바구니 항목 · 수량/합계
export default class CartListItem {
  constructor(item, quantity = 1, options = new ItemOption()) {
    this.id = window.crypto.randomUUID();
    this.item = item;
    this.quantity = quantity;
    this.options = options;
  }
  increaseQuantity = () => { if (this.quantity < 99) this.quantity++; return this; };
  decreaseQuantity = () => { if (this.quantity > 1) this.quantity--; return this; };
  getTotalPrice = () => this.item?.price * this.quantity;
}
