기능 개요

음료를 고르면 옵션 팝업(OptionPopup)이 열려 온도·기타(디카페인/시럽)·농도 옵션을 선택합니다. 옵션 정의는 메뉴 데이터(data.js)의 각 항목 options에 들어 있고, OptionPopup은 그중 온도 옵션이 단일 선택지면 화면에서 숨기고 나머지를 OptionSelect로 렌더링합니다. 옵션 종류는 OptionType(TEMPERATURE/OTHER/BLEND)으로 구분합니다.

각 OptionSelect는 옵션 종류에 따라 동작을 다르게 구성합니다. 온도는 단일 선택·필수이고, 기타(디카페인·시럽)는 다중 선택, 농도는 단일 선택입니다. 선택/해제는 장바구니 항목이 들고 있는 ItemOption 객체의 세터(setTemperature·setCaffeine·setSyrups·setBlend)를 호출해 값을 갱신합니다. ItemOption은 허용 값(예: 온도 hot/ice/unknown)만 받아들이고 그 외에는 UNKNOWN으로 보정합니다. 확정 버튼을 누르면 온도가 미지정이면 메뉴 기본값으로 채운 뒤 CartStore.addCartItems로 장바구니에 추가하고 장바구니 팝업으로 전환합니다.

설계 포인트
옵션 세터가 입력값을 화이트리스트로 검증하기 때문에, 음성 주문이 잘못 해석한 옵션 문자열이 들어와도 UNKNOWN으로 정규화되어 장바구니 상태가 깨지지 않습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 사용자 participant OP as OptionPopup participant OS as OptionSelect participant IO as ItemOption participant CS as CartStore OP->>OP: selectedItem 옵션 필터링 (단일 온도 숨김) OP->>OS: 옵션별 OptionSelect 렌더 U->>OS: 옵션 탭 터치 (touchEnd) alt 온도 / 농도 OS->>IO: setTemperature / setBlend else 기타 (디카페인 / 시럽) OS->>IO: setCaffeine / setSyrups end U->>OP: 확정 버튼 (completeButtonHandler) opt 온도 미지정 OP->>IO: setTemperature(메뉴 기본값) end OP->>CS: addCartItems([menuItem]) OP->>OP: openPopup(Cart)

흐름. 메뉴 옵션 정의로 선택 UI를 구성하고, 탭 선택이 ItemOption을 갱신하며, 확정 시 기본값 보정 후 장바구니에 담습니다.

클래스 다이어그램

classDiagram class OptionPopup { +completeButtonHandler(menuItem) +cancelButtonHandler() } class OptionSelect { -data +touchEndHandler(index, option) +getSelectedOptions() } class ItemOption { +caffeine +temperature +syrups +blend +setTemperature(t) +setCaffeine(c) +setSyrups(s) +setBlend(b) } class CartStore { +addCartItems(itemArray) } class OptionType { <<enumeration>> TEMPERATURE OTHER BLEND } OptionPopup --> OptionSelect : 옵션별 렌더 OptionSelect --> ItemOption : 세터 호출 OptionSelect ..> OptionType OptionPopup --> CartStore : addCartItems

관계. OptionPopup이 옵션별 OptionSelect를 띄우고, 각 선택은 장바구니 항목의 ItemOption 세터를 호출하며, 확정 시 CartStore로 항목을 추가합니다.

핵심 코드

src/components/Popup/OptionPopup/OptionSelect/OptionSelect.jsx — 종류별 선택 동작 구성
switch (name) {
  case OptionType.TEMPERATURE:
    data = { option_key: "option.temp", options: detail, required: true, multi: false,
      selectOption: (option) => {
        if (Object.values(TemperatureType).includes(option)) optionObject.setTemperature(option);
      },
      deselectOption: () => { if (detail.length != 1) optionObject.setTemperature(TemperatureType.UNKNOWN); } };
    break;
  case OptionType.OTHER:
    data = { option_key: "option.option", options: detail, required: false, multi: true,
      selectOption: (option) => {
        if (option === OtherOptionType.DECAFFEINE) optionObject.setCaffeine(CaffeineType.NO);
        else if (option === OtherOptionType.SYRUP) optionObject.setSyrups(SyrupType.YES);
      }, /* ... */ };
    break;
  case OptionType.BLEND: /* setBlend */ break;
}
src/components/Popup/OptionPopup/OptionPopup.jsx — 확정 시 기본값 보정 후 장바구니 추가
const completeButtonHandler = (menuItem) => {
  if (menuItem?.options?.temperature == TemperatureType.UNKNOWN) {
    if (menuItem?.item?.options[0].default) {
      menuItem?.options?.setTemperature(menuItem.item.options[0].default);  // 기본값 보정
    } else { log.error("no temperature option"); return; }
  }
  if (popupState() == PopupType.Option) addCartItems([menuItem]);
  openPopup(PopupType.Cart);
};
