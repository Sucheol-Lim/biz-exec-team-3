STT(음성 인식) 이중 경로

Android WebView에서는 window.android 네이티브 STT로 위임하고, 일반 브라우저에서는 Azure Speech SDK의 SpeechRecognizer를 직접 사용해 마이크 발화를 텍스트로 변환합니다.

기능 개요

키오스크 단말(Android WebView)과 일반 개발용 브라우저는 마이크 접근 방식이 다릅니다. 이 앱은 실행 환경을 판별해 STT 경로를 두 갈래로 분기합니다. STTStore가 navigator.userAgent의 Android 여부와 window.android 인터페이스 존재를 검사해, 단말이면 AzureSTTManager.azureMicOpenAndroid(네이티브 위임)를, 그 외에는 azureMicOpen(Azure SDK 직접)을 선택합니다.

네이티브 경로에서는 window.android.setSpeechConfiguration으로 키·리전·커스텀 엔드포인트를 전달하고 requestSpeechToText(언어, timeout)로 인식을 요청합니다. 단말이 인식 결과를 window.handleSTTResult(text, mode) 콜백으로 되돌려 주며, mode가 1이면 중간 결과, 2면 최종 결과로 처리합니다. 브라우저 경로에서는 Azure SpeechRecognizer를 생성해 startContinuousRecognitionAsync로 연속 인식을 돌리고, recognizing/recognized 이벤트로 텍스트를 받습니다. 언어(i18next.language)에 따라 ko-KR/en-US와 리전·구독 키가 분기되며, PhraseListGrammar로 인식 정확도를 보강합니다.

설계 포인트
두 경로 모두 인식 시작 전 onBeforeRecordStartAsync 훅으로 시작 효과음(siri_open.wav)을 재생합니다. 브라우저 경로는 setTimeout 기반 타임아웃(기본 5000ms)으로 일정 시간 무발화 시 마이크를 자동으로 닫고 실패 콜백을 호출합니다.

흐름. STTStore가 환경을 판별해 네이티브/브라우저 경로 중 하나를 고르고, 각 경로가 인식 텍스트를 동일한 callback(result, transcript) 형태로 되돌립니다.

관계. STTStore가 환경별 함수 포인터(azureMicOpen vs azureMicOpenAndroid)를 선택하고, AzureSTTManager가 네이티브 인터페이스 또는 Azure SDK 둘 중 하나로 인식을 수행합니다.

핵심 코드

src/stores/STTStore.jsx — 환경 판별로 마이크 함수 선택
const isAndroid =
  /Android/i.test(window.navigator.userAgent) && window.android;
const azureMicClose = isAndroid
  ? AzureSTTManager.azureMicCloseAndroid
  : AzureSTTManager.azureMicClose;
const azureMicOpen = isAndroid
  ? AzureSTTManager.azureMicOpenAndroid
  : AzureSTTManager.azureMicOpen;
src/voices/AzureSTTManager.js — 네이티브 STT 콜백 + 브라우저 SDK 분기
// 네이티브: Android가 결과를 되돌려 주는 콜백
handleSTTResult: function (text, mode) {
  if (mode === 2) {                      // 최종 결과
    window.android.stopSpeechToText();
    self.updateTranscriptCallback?.(text);
    if (self.callback) { self.callback(true, text); self.callback = null; }
  } else if (mode === 1) {               // 중간 결과
    self.updateTranscriptCallback?.(text);
  }
},

// 브라우저: 언어별 리전/엔드포인트 분기 후 SpeechRecognizer 사용
startSpeechRecognition: async (timeout) => {
  if (i18next.language == "en") {
    speechConfig = SpeechConfig.fromSubscription(getSubscriptionKey(), getRegion());
    speechConfig.speechRecognitionLanguage = "en-US";
  } else {
    speechConfig = customUrl
      ? SpeechConfig.fromEndpoint(customUrl, getSubscriptionKey())
      : SpeechConfig.fromSubscription(getSubscriptionKey(), getRegion());
    speechConfig.speechRecognitionLanguage = "ko-KR";
  }
  recognizer = new SpeechRecognizer(speechConfig, audioConfig);
  phraseListGrammar = PhraseListGrammar.fromRecognizer(recognizer);
  recognizer.startContinuousRecognitionAsync(...);
},
