다국어(i18n)

i18next 기반으로 한국어/영어 리소스를 제공하며, LanguagePopup으로 언어를 전환합니다. 언어 설정에 따라 STT 인식 언어와 TTS 서버가 함께 바뀝니다.

기능 개요

다국어는 i18next를 SolidJS용 래퍼(@mbarzda/solid-i18next)로 구성합니다. index.jsx가 TransProvider로 앱을 감싸고, 한국어(locales/ko/common.json)·영어(locales/en/common.json) 리소스를 등록하며 초기 언어를 한국어(ISO639CODE.Korean)로 설정합니다. 화면 문구는 컴포넌트에서 useTransContext의 t(key)로 번역 키를 해석해 표시합니다.

언어 전환은 LanguagePopup이 제공합니다. 한국어·영어·독일어·프랑스어·네덜란드어·스페인어 6개 버튼을 렌더하지만, ButtonLanguage에서 한국어·영어만 활성화(disabled=false)되고 나머지는 비활성입니다. 버튼을 누르면 actions.changeLanguage(lang)로 i18next 언어를 바꾸고 팝업을 닫습니다. 언어가 바뀌면 STT·TTS도 함께 따라갑니다. STT는 i18next.language로 인식 언어(en-US/ko-KR)와 리전을 분기하고(기능 02), TTS는 영어=Azure·한국어=KT로 서버를 분기합니다(기능 03). 화면 안내 음성도 IBCTTSManager가 영어일 때 에셋 음성을, 그 외에는 번역 키를 합성합니다.

설계 포인트
언어 코드가 STT 인식 언어와 TTS 서버 선택의 단일 기준이 되어, 언어를 한 번 바꾸면 텍스트·음성 인식·음성 합성이 일관되게 따라옵니다. 미지원 언어 버튼은 UI에는 노출하되 disabled로 막아 향후 확장 여지를 남겨 둡니다.

관계. index.jsx가 i18next Provider를 구성하고, LanguagePopup의 ButtonLanguage가 활성 언어를 changeLanguage로 전환합니다.

핵심 코드

src/index.jsx — i18next Provider 구성
const resources = {
  en: { translation: translationEN },
  ko: { translation: translationKO },
};
const initialLanguage = ISO639CODE.Korean;

render(
  () => (
    <TransProvider
      options={{ resources, lng: initialLanguage }}
      children={<App />}
    />
  ),
  root
);
src/components/Popup/LanguagePopup/ButtonLanguage/ButtonLanguage.jsx — 활성 언어만 전환
switch (lang) {
  case ISO639CODE.Korean:  icon = KorIcon; text = "한국어";   disabled = false; break;
  case ISO639CODE.English: icon = EngIcon; text = "English";  disabled = false; break;
  case ISO639CODE.German:  icon = GerIcon; text = "Deutsch";  disabled = true;  break;
  /* French / Nederlands / Spanish: disabled = true */
}

const touchEndHandler = () => {
  if (!disabled && !isSelected()) {
    closePopup();
    actions.changeLanguage(lang);          // STT/TTS 분기 기준 변경
  }
};
