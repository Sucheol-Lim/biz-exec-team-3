레벨별 로깅

기능 개요

로깅은 경량 유틸 CommonLog가 전담합니다. ERROR·WARN·INFO·DEBUG 4단계 레벨을 두고, getLog(name)이 모듈 이름을 태그로 박은 로거 객체(debug/info/warn/error)를 반환합니다. 거의 모든 매니저·스토어·컴포넌트가 const log = CommonLog.getLog("모듈명") 패턴으로 자기 로거를 만들어, 출력에 시각·레벨·모듈 태그가 함께 찍히도록 합니다.

각 로그 메서드는 현재 레벨(this.level)이 자기 레벨 이상일 때만 출력합니다. 즉 레벨이 INFO면 DEBUG 로그는 무시되고, DEBUG면 모두 출력됩니다. 출력 형식은 레벨별로 콘솔 색상 스타일을 달리 적용하고, 객체 인자는 JSON 문자열로, 에러는 스택을 우선 표시합니다. 레벨 자체는 앱 시작 시 index.jsx가 CommonLog.setLevel(import.meta.env.APP_LOG_LEVEL)로 환경변수에서 읽어 설정합니다. 이 환경변수는 빌드 인자가 결정합니다. vite.config.js가 커맨드라인 인자 log=false면 APP_LOG_LEVEL을 INFO로, log=true면 DEBUG로 세팅하므로, 릴리스(log=false)는 조용히, 개발(log=true)은 상세히 동작합니다.

설계 포인트
로거 인스턴스를 모듈마다 만들어 태그를 고정하면, 콘솔에서 어느 매니저/스토어가 찍은 로그인지 한눈에 구분됩니다. 레벨 게이트가 메서드 진입부에 있어, 비활성 레벨의 로그는 문자열 포매팅 비용 없이 건너뜁니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant BUILD as vite.config.js (빌드) participant IDX as index.jsx participant CL as CommonLog participant MOD as 모듈 (Manager/Store) BUILD->>BUILD: argv.log == "false" ? INFO : DEBUG BUILD->>BUILD: process.env.APP_LOG_LEVEL 설정 IDX->>CL: setLevel(APP_LOG_LEVEL) MOD->>CL: getLog("모듈명") CL-->>MOD: { debug, info, warn, error } MOD->>CL: log.debug("...") alt level >= DEBUG CL->>CL: print(DEBUG, name, obj) (콘솔 출력) else 레벨 미달 CL->>CL: 무시 end

흐름. 빌드 인자가 레벨 환경변수를 정하고, 앱 시작 시 setLevel로 반영되며, 각 모듈 로거는 현재 레벨 이상일 때만 콘솔에 출력합니다.

클래스 다이어그램

classDiagram class CommonLog { +ERROR +WARN +INFO +DEBUG +level +setLevel(lvlStr) +getLog(name) +print(type, name, obj) } class Logger { +debug(...obj) +info(...obj) +warn(...obj) +error(...obj) } class viteConfig { +argv log = true / false +APP_LOG_LEVEL } class indexJsx { +setLevel(APP_LOG_LEVEL) } CommonLog --> Logger : getLog 반환 viteConfig ..> CommonLog : APP_LOG_LEVEL 결정 indexJsx --> CommonLog : setLevel

관계. CommonLog가 모듈별 Logger를 발급하고, 빌드 설정(vite.config.js)이 정한 레벨을 index.jsx가 setLevel로 적용합니다.

핵심 코드

src/utils/CommonLog.js — 레벨 게이트 + 태그 로거
const CommonLog = {
  ERROR: 0, WARN: 1, INFO: 2, DEBUG: 3, level: 3,
  setLevel(lvlStr) { this.level = this[lvlStr.toUpperCase()] || this.level; },
  getLog(name) {
    return {
      debug: (...obj) => { if (this.level >= this.DEBUG) this.print(this.DEBUG, name, obj); },
      info:  (...obj) => { if (this.level >= this.INFO)  this.print(this.INFO,  name, obj); },
      warn:  (...obj) => { if (this.level >= this.WARN)  this.print(this.WARN,  name, obj); },
      error: (...obj) => { if (this.level >= this.ERROR) this.print(this.ERROR, name, obj); },
    };
  },
};
vite.config.js + src/index.jsx — 빌드 인자로 레벨 결정 후 적용
// vite.config.js — 커맨드라인 인자로 레벨 세팅
if (argv["log"] == "false")      process.env.APP_LOG_LEVEL = "INFO";
else if (argv["log"] == "true")  process.env.APP_LOG_LEVEL = "DEBUG";

// index.jsx — 시작 시 환경변수에서 레벨 적용
CommonLog.setLevel(import.meta.env.APP_LOG_LEVEL);
const log = CommonLog.getLog("index.jsx");
