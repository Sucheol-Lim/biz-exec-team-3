기능 개요

LLM 질의 시퀀스는 발화 텍스트를 주문 의도로 바꾸는 서버 통신 계층입니다. LLMManager는 여러 질의 종류(autoQuery·defaultQuery·orderQuery·beverageQuery·otherQuery)를 제공하지만, 음성 주문 메인 경로는 autoQuery를 사용합니다. 이전 대화(previous)가 있으면 신규 발화(user)와 묶어 직렬화한 쿼리를 만들고, 없으면 신규 발화만 보냅니다.

실제 송신은 queryManager.autoQuery가 담당합니다. 질의 서버(https://qz7d803.glddns.com:11591/api/)의 auto_query 엔드포인트로 POST하며, 통신은 ajax-rxjs의 send가 axios-observable과 rxjs retry(2)를 적용해 처리합니다. 응답이 문자열이면 JSON 파싱한 뒤, useTTS가 참이고 message가 있으면 TTSManager.handleTts로 음성 안내합니다. message가 "ERROR"면 실패 콜백을, 그 외에는 성공 콜백을 호출합니다. 콜백을 받은 LLMStore는 응답 type이 order/new/edit/mix면 validateOrderQuery로 실제 메뉴에 존재하는 항목만 남기고, suggestion이면 이전 추천 질의를 정리합니다.

설계 포인트
autoQuery는 응답 형태가 문자열/객체 모두 올 수 있다고 가정하고 typeof result == "string"일 때만 JSON.parse 합니다. 주문 검증은 응답 response 항목이 data.js의 메뉴명과 일치하는지로 걸러, 서버가 잘못 해석한 항목이 장바구니에 들어가는 것을 막습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant LS as LLMStore participant LM as LLMManager participant QM as queryManager participant AX as ajax-rxjs participant SRV as 질의 서버 (auto_query) participant TM as TTSManager LS->>LM: querySequence(newQueryList, null, useTTS, cb) LM->>LM: previous + user 직렬화 LM->>QM: autoQuery(query, subscriber) QM->>AX: send(.../auto_query, "post", query) AX->>SRV: POST (retry 2회) SRV-->>AX: 응답 (message / type / response) AX-->>QM: x.data QM-->>LM: result opt useTTS 이고 result.message LM->>TM: handleTts(result.message) end alt message == "ERROR" LM-->>LS: callback(false, result, "auto") else 정상 LM-->>LS: callback(true, result, "auto") end LS->>LS: type 분기 (order/new/edit/mix/suggestion)

흐름. 대화 목록을 직렬화해 auto_query로 POST하고, 응답을 TTS로 안내한 뒤 type에 따라 주문/추천을 정리합니다.

클래스 다이어그램

classDiagram class LLMStore { +asyncQuerySequence(content, useTTS, usePrevious) +validateOrderQuery(data) +clearSuggestionQuery() } class LLMManager { +querySequence(newQuery, prevQuery, useTTS, callback) +autoQuery(newQuery, prevQuery, useTTS, callback) +defaultQuery(...) +orderQuery(...) +beverageQuery(...) +otherQuery(...) } class queryManager { +autoQuery(query, subscriber) +defaultQuery(query, subscriber) +orderQuery(query, subscriber) +beverageQuery(query, subscriber) +otherQuery(query, subscriber) } class ajaxRxjs { +send(url, method, data, timeout, headers, responseType) } class TTSManager { +handleTts(inputText) } LLMStore --> LLMManager : querySequence LLMManager --> queryManager : autoQuery LLMManager --> TTSManager : 응답 음성 안내 queryManager --> ajaxRxjs : send POST

관계. LLMStore가 대화 목록을 LLMManager에 넘기고, LLMManager는 queryManager(엔드포인트별 POST)와 TTSManager(음성 안내)를 호출하며, 송신은 ajax-rxjs.send가 retry와 함께 처리합니다.

핵심 코드

src/voices/LLMManager.js — previous/user 묶어 autoQuery + 응답 분기
autoQuery: function (newQuery, prevQuery, useTTS, callback) {
  var query;
  if (prevQuery) {
    query = JSON.stringify({ previous: prevQuery }) + "," +
            JSON.stringify({ user: newQuery });
  } else {
    query = newQuery;
  }
  queryManager.autoQuery(query, async function (result) {
    if (result) {
      if (typeof result == "string") result = JSON.parse(result);
      if (useTTS && result.message) await TTSManager.handleTts(result.message);
      if (result.message == "ERROR") callback && callback(false, result, "auto");
      else callback && callback(true, result, "auto");
    } else {
      callback && callback(false, null, "auto");
    }
  });
},
src/api/queryManager.js — auto_query 엔드포인트 POST
const SERVER_URL = "https://qz7d803.glddns.com:11591/api/";

autoQuery: function (query, subscriber) {
  return ajax
    .send(SERVER_URL + "auto_query", "post", query, null, null, null)
    .subscribe(subscriber);
},
