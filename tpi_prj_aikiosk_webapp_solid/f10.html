기능 개요

효과음 재생은 Web Audio API 기반의 싱글턴 AudioPlayer가 담당합니다. 생성자가 인스턴스를 한 번만 만들어(instance 캐시) window.AudioPlayer로 노출하므로, STT 효과음·TTS 음성·KT WAV 재생이 모두 같은 플레이어를 공유합니다. 효과음 파일은 siri_open.wav(인식 시작), siri_close.mp3(종료), siri_failure.wav(인식 실패)로, STTStore가 에셋으로 import해 사용합니다.

대화 시작 시점은 STT 흐름과 묶여 있습니다. STTStore.startSTTAsync가 마이크를 열기 직전 AzureSTTManager.setOnBeforeRecordStartAsync 훅에 시작 효과음 재생을 등록하고, 인식 시작 직전에 이 훅이 호출되어 playSiriOpenSound가 siri_open.wav를 재생합니다. 재생은 playAudioFile이 파일을 fetch해 arraybuffer로 받은 뒤 playAudioBuffer로 디코딩·재생하며, 재생 완료(source.onended)를 Promise로 알려 후속 단계가 이어지도록 합니다.

설계 포인트
AudioPlayer는 새 재생을 시작하기 전 기존 소스를 stop()으로 끊어 효과음·TTS가 겹치지 않게 합니다. 싱글턴이라 인식 효과음과 KT TTS WAV가 동일한 오디오 컨텍스트 자원을 두고 충돌 없이 직렬화됩니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant ST as STTStore participant AM as AzureSTTManager participant AP as AudioPlayer participant SND as siri_open.wav ST->>AM: setOnBeforeRecordStartAsync(playSiriOpenSound) ST->>AM: azureMicOpen(callback) AM->>AM: onBeforeRecordStartAsync 실행 AM->>ST: playSiriOpenSound() ST->>AP: playAudioFile(siriOpen) AP->>SND: fetch → arrayBuffer AP->>AP: decodeAudioData → source.start(0) AP-->>ST: Promise(onended) resolve Note over ST,AM: 효과음 종료 후 STT 인식 시작

흐름. 마이크 열기 직전 훅으로 시작 효과음을 재생하고, 재생 완료 Promise를 받은 뒤 실제 음성 인식으로 넘어갑니다.

클래스 다이어그램

classDiagram class AudioPlayer { -audioContext -source -isPlaying +playAudioBuffer(buffer) +playAudioFile(file) +stop() +getIsPlaying() } class STTStore { -player +playSiriOpenSound() +playSiriCloseSound() +playSiriFailureSound() +startSTTAsync() } class AzureSTTManager { +setOnBeforeRecordStartAsync(callback) } STTStore o-- AudioPlayer : player (싱글턴) STTStore --> AzureSTTManager : onBeforeRecordStart 훅 등록

관계. STTStore가 싱글턴 AudioPlayer로 효과음을 재생하고, 시작 효과음은 AzureSTTManager의 인식 직전 훅에 등록되어 호출됩니다.

핵심 코드

src/stores/STTStore.jsx — 인식 시작 직전 효과음 등록
import siriOpen from "@assets/siri_open.wav";
import siriClose from "@assets/siri_close.mp3";
import siriFailure from "@assets/siri_failure.wav";
const player = new AudioPlayer();

const playSiriOpenSound = async () => player.playAudioFile(siriOpen);

const startSTTAsync = async () => {
  AzureSTTManager.setOnBeforeRecordStartAsync(async () => {
    await playSiriOpenSound();            // 마이크 열기 직전 시작음
  });
  setIsMicOpen(true);
  azureMicOpen((result, data) => { /* ... */ });
};
src/voices/AudioPlayer.js — 싱글턴 + 파일 재생
let instance = null;
export class AudioPlayer {
  constructor() {
    if (!instance) {
      this.audioContext = new (window.AudioContext || window.webkitAudioContext)();
      this.isPlaying = false;
      instance = this;
    }
    return instance;                       // 싱글턴 보장
  }
  async playAudioFile(audioFile) {
    const response = await fetch(audioFile);
    const arrayBuffer = await response.arrayBuffer();
    return this.playAudioBuffer(arrayBuffer);
  }
}
window.AudioPlayer = AudioPlayer;
