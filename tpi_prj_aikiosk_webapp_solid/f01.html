기능 개요

음성 주문 대화는 이 키오스크의 핵심 입력 경로입니다. 화면 하단의 음성 버튼(VoiceButton)을 누르면 음성 입력 시퀀스가 시작되어, 마이크가 열리고 발화가 STT로 텍스트화됩니다. 인식이 끝난 텍스트는 대화 누적 목록(role user/assistant)에 추가되어 LLM 질의 서버로 전송되고, 서버가 해석한 주문 의도와 응답 메시지가 TTS로 음성 안내됩니다.

이 흐름은 여러 스토어와 매니저가 협력해 동작합니다. VoiceButton.startSequence가 진입점이며, VoiceSequenceStore.repeatSequenceWhileSTT가 파형 애니메이션과 STT(STTStore.startSTTAsync)를 동시에 돌리고, STT 결과 텍스트를 LLMStore.asyncQuerySequence로 넘깁니다. LLMStore는 LLMManager.querySequence → queryManager.autoQuery로 질의 서버에 POST하고, 응답 type(order/new/edit/mix/suggestion 등)에 따라 주문을 검증·정리합니다. TTS 재생은 useTTS가 참일 때 TTSManager.handleTts가 담당합니다.

설계 포인트
STT 인식과 음성 파형 애니메이션이 별개 Promise로 동시에 진행되며, 둘 다 끝나야(isSTTFinished · isSequenceFinished) 결과 텍스트를 resolve 합니다. 파형은 STT가 끝날 때까지 물결 구간을 반복(recursiveRepeatSequence)해 사용자에게 "듣고 있음" 상태를 시각적으로 유지합니다.

흐름. 버튼 터치로 시작해 파형·STT를 동시에 돌리고, 인식 텍스트를 asyncQuerySequence에 넘긴 뒤 autoQuery 응답을 받아 주문을 정리하고 TTS로 안내합니다.

핵심 코드

src/components/Common/Voice/VoiceButton/VoiceButton.jsx — 음성 주문 시퀀스 진입점
const startSequence = async () => {
  try {
    await startVoiceSequence();
    await runCurrentSequence();
    await updateSequenceState();
    const sttResult = await repeatSequenceWhileSTT();   // 파형 + STT 동시 실행
    await updateSequenceState();
    await runCurrentSequence();
    await asyncQuerySequence(sttResult);                // 인식 텍스트로 LLM 질의
  } catch (e) {
    log.error(e);
  }
};
src/stores/LLMStore.jsx — 대화 누적 + 질의 + 응답 분기
const asyncQuerySequence = async (content, useTTS, usePrevious = true) => {
  const newClientQuery = createUserQuery(content);
  const newQueryList = [...queryList(), newClientQuery];

  return new Promise((resolve, reject) => {
    LLMManager.querySequence(newQueryList, null, useTTS, (result, data, type) => {
      if (result && data?.message?.toLowerCase?.() != "error"
              && data?.type?.toLowerCase?.() != "error") {
        if (["order", "new", "edit", "mix"].includes(data?.type)) {
          validatedOrderQuery = validateOrderQuery(data);  // 주문 검증
          setQueryList([...newQueryList, createAssistentQuery(validatedOrderQuery)]);
        }
        setResult(data);
        resolve(data);
      } else {
        setIsError(true);
        reject("asyncQuerySequence fail!");
      }
    });
  });
};
