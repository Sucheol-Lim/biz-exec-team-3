기능 개요

팝업은 화면 트리와 분리된 전역 영역(#popup-area)에 띄웁니다. popup.jsx의 Popup 컴포넌트가 SolidJS의 Portal로 document.getElementById("popup-area")에 PopupLayout을 마운트하며, Show로 팝업 열림 상태(isPopupOpen)일 때만 렌더합니다. Portal을 쓰므로 어느 화면에서 열어도 항상 같은 전역 레이어 위에 표시됩니다.

팝업 상태는 PopupStore가 관리합니다. 열림 여부(isPopupOpen), 현재 팝업 종류(popupState), 선택 항목(selectedItem), LLM 결과(llmResult)를 시그널로 두고, openPopup(state, selectedItem, llmResult)·closePopup()으로 제어합니다. 어떤 팝업을 그릴지는 PopupLayout이 popupState() 값에 따라 Switch/Match로 결정합니다. PopupType.Language면 LanguagePopup, Option/Edit면 OptionPopup, Cart면 CartPopup, Help면 HelpPopup을 띄웁니다. 옵션 선택을 마치면 openPopup(PopupType.Cart)로 장바구니 팝업으로 자연스럽게 이어집니다.

설계 포인트
팝업 종류를 PopupType 열거 한 곳에서 정의하고 PopupStore의 단일 상태로 관리하므로, 어디서든 openPopup(PopupType.X) 한 줄로 팝업을 전환할 수 있습니다. Portal 마운트 지점이 고정이라 z-index·레이아웃 충돌도 줄어듭니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant CALLER as 호출부 (메뉴/헤더 등) participant PS as PopupStore participant POP as Popup (popup.jsx) participant PL as PopupLayout participant TARGET as 개별 팝업 CALLER->>PS: openPopup(PopupType.Option, selectedItem) PS->>PS: setPopupState / setIsPopupOpen(true) POP->>POP: Show when isPopupOpen() POP->>PL: Portal mount(#popup-area) PL->>PL: Switch(popupState()) PL->>TARGET: 해당 팝업 렌더 (Option/Cart/Help/Language) TARGET->>PS: closePopup() PS->>PS: setIsPopupOpen(false)

흐름. 호출부가 openPopup으로 종류를 지정하면 Portal이 전역 영역에 PopupLayout을 마운트하고, 레이아웃이 종류에 맞는 개별 팝업을 그립니다.

클래스 다이어그램

관계. Popup이 Portal로 PopupLayout을 전역 영역에 띄우고, PopupLayout은 PopupStore.popupState에 따라 개별 팝업을 선택해 렌더합니다.

핵심 코드

src/popup.jsx — Portal 기반 전역 마운트
const Popup = () => {
  const { isPopupOpen } = PopupStore;
  return (
    <Show when={isPopupOpen()}>
      <Portal mount={document.getElementById("popup-area")}>
        <PopupLayout />
      </Portal>
    </Show>
  );
};
src/popups/PopupLayout/PopupLayout.jsx — 종류별 팝업 스위치
<Switch>
  <Match when={popupState() == PopupType.Language}>
    <LanguagePopup />
  </Match>
  <Match when={[PopupType.Option, PopupType.Edit].includes(popupState())}>
    <OptionPopup />
  </Match>
  <Match when={popupState() == PopupType.Cart}>
    <CartPopup />
  </Match>
  <Match when={popupState() == PopupType.Help}>
    <HelpPopup />
  </Match>
</Switch>
