기능 개요

메뉴 데이터는 src/data.js의 data.menus 배열 하나에 모두 정의됩니다. 각 항목은 메뉴명(name)·다국어 키(name_key)·카테고리(coffee/tea/juice)·옵션 정의·가격(price, IBC용 price_ibc)·이미지(imgSrc)·STT 인식 보정용 유사어(similars)를 가집니다. 카테고리별 이미지는 import.meta.glob("@assets/MenuImage/Coffee/*") 형태로 빌드 타임에 일괄 로드해 인덱스 순서대로 각 메뉴에 매핑합니다.

화면 표시는 MenuStore가 담당합니다. 현재 카테고리(currentCategory)와 현재 페이지(currentPage) 시그널을 두고, createMemo로 카테고리 항목·현재 페이지 항목·페이지 길이·다음/이전 가능 여부를 파생시킵니다. 페이지네이션 단위는 상수 ITEM_PER_PAGE(=8)이며, getPageItems가 카테고리 항목을 slice(8*page, 8*(page+1))로 잘라 한 페이지를 만듭니다. 카테고리 전환(changeCategory·goNextCategory·goPrevCategory)과 페이지 이동(goNextPage·goPrevPage)이 시그널을 갱신하면 SolidJS 반응성으로 화면이 자동 재계산됩니다.

설계 포인트
카테고리 인덱스는 Map(0=coffee, 1=tea, 2=juice)으로 관리해 다음/이전 카테고리 이동을 인덱스 산술로 처리합니다. 이전 카테고리로 넘어갈 때는 getCategoryPageLength - 1로 마지막 페이지에 위치시켜 자연스러운 좌우 탐색감을 줍니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant D as data.js participant MS as MenuStore participant UI as MenuList (화면) participant U as 사용자 Note over D: import.meta.glob 으로 카테고리 이미지 로드 MS->>D: data.menus 읽기 UI->>MS: currentPageItems() MS->>MS: getPageItems(category, page) = slice(8*page, 8*(page+1)) MS-->>UI: 현재 페이지 8개 항목 U->>MS: goNextPage() / changeCategory() MS->>MS: setCurrentPage / setCurrentCategory Note over MS,UI: createMemo 반응성으로 화면 자동 재계산 MS-->>UI: 갱신된 currentPageItems()

흐름. data.menus를 카테고리로 거른 뒤 8개 단위로 잘라 표시하고, 사용자 입력으로 페이지·카테고리 시그널이 바뀌면 메모가 다시 계산됩니다.

관계. data.menus(메뉴 항목 배열)를 MenuStore가 카테고리·페이지 단위로 파생시키며, 페이지 크기와 카테고리 종류는 constants/menu.js에서 가져옵니다.

핵심 코드

src/data.js — 카테고리 이미지 일괄 로드 + 메뉴 항목 정의
const CoffeeImagesObj = import.meta.glob("@assets/MenuImage/Coffee/*", { eager: true });
let coffeeImageArray = getImgSrcArrayFromImagesObj(CoffeeImagesObj);

export const data = {
  menus: [
    {
      name: "아메리카노",
      name_key: "menu.coffee_americano",
      category: "coffee",
      options: [
        { name: TEMPERATURE, detail: [HOT, ICE], default: HOT },
        { name: OTHER, detail: [DECAFFEINE, SYRUP] },
        { name: BLEND, detail: [MILD, THICK] },
      ],
      imgSrc: coffeeImageArray[0],
      price: 3500, price_ibc: 1.5,
      similars: [" 메리카노", " 매리카노", " 아매리카노", " 아메리카누"],
    },
    /* ... 커피 / 주스 / 티 */
  ],
};
src/stores/MenuStore.jsx — 페이지당 8개 페이지네이션
function getCategoryItems(category) {
  return menuData.filter((item) => item.category === category);
}
function getPageItems(category, page) {
  const categoryItems = getCategoryItems(category);
  return categoryItems.slice(ITEM_PER_PAGE * page, ITEM_PER_PAGE * (page + 1));
}
const currentPageItems = createMemo(() =>
  getPageItems(currentCategory(), currentPage())
);
