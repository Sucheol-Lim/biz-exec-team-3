기능 개요

키오스크 단말은 Android WebView에 빌드 산출물을 패키징해 띄우므로, 앱이 웹 서버 없이 file:// 프로토콜에서 그대로 동작해야 합니다. 이를 위해 vite.config.js는 두 가지를 설정합니다. 첫째, base: "./"로 모든 에셋 참조를 상대 경로로 빌드해 절대 경로(/)에 의존하지 않게 합니다. 둘째, 커스텀 플러그인 noCrossorigin이 transformIndexHtml에서 생성된 HTML의 모든 crossorigin 속성을 제거합니다. file://에서는 CORS가 적용되어 crossorigin 속성이 스크립트/스타일 로드를 막기 때문입니다.

화면 스케일도 이 운용 방식과 맞물립니다. index.jsx가 window.onload에서 window.innerHeight / 1480 비율로 body의 zoom을 조정해, 924x1480 고정 설계를 단말 해상도에 맞춰 확대/축소합니다. 라우팅도 HashRouter를 써서 해시 기반으로 동작하므로 서버 측 경로 매칭이 필요 없습니다(기능 08). 빌드 모드(release/production)는 에셋 인라인 제한(assetsInlineLimit: 0)과 파일명 규칙(assets/[name].[ext])을 다르게 두지만, 상대 경로·crossorigin 제거 원칙은 공통입니다.

설계 포인트
noCrossorigin은 Vite가 모듈 스크립트에 자동으로 붙이는 crossorigin을 일괄 제거하는 후처리입니다. 이 한 줄 플러그인이 없으면 file:// WebView에서 모듈/스타일이 로드되지 않아 화면이 비게 됩니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant DEV as 빌드 (vite build) participant CFG as vite.config.js participant NC as noCrossorigin 플러그인 participant DIST as dist/index.html participant WV as Android WebView (file://) DEV->>CFG: base "./" 적용 (상대 경로 빌드) CFG->>NC: transformIndexHtml(html) NC->>NC: html.replaceAll("crossorigin", "") NC-->>DIST: crossorigin 제거된 HTML 출력 WV->>DIST: file:// 로 로드 Note over WV,DIST: 상대 경로 + crossorigin 없음 → 정상 로드 WV->>WV: window.onload → zoom = innerHeight/1480

흐름. 빌드 시 상대 경로로 묶고 crossorigin을 제거한 HTML을 만들어, WebView가 file://로 열어도 모듈·에셋이 정상 로드되고 화면 스케일이 단말 해상도에 맞춰집니다.

클래스 다이어그램

classDiagram class viteConfig { +base "./" +plugins +build (release / production) +envPrefix "APP_" } class noCrossorigin { +name "no-crossorigin" +transformIndexHtml(html) } class indexJsx { +InitializeWindow() +modifyWindowZoom(el, percentage) } viteConfig --> noCrossorigin : plugins 포함 viteConfig ..> indexJsx : base "./" 산출물 로드

관계. vite.config.js가 상대 경로 빌드와 noCrossorigin 후처리를 적용하고, 실행 시 index.jsx가 단말 해상도에 맞춰 zoom을 조정합니다.

핵심 코드

vite.config.js — base "./" + crossorigin 제거 플러그인
// disable crossorigin for work on file protocol
const noCrossorigin = () => {
  return {
    name: "no-crossorigin",
    transformIndexHtml(html) {
      return html.replaceAll("crossorigin", "");
    },
  };
};

const config = {
  base: "./",                       // 상대 경로 빌드
  plugins: [ solid(), /* ... */ noCrossorigin() ],
  envPrefix: "APP_",
};
src/index.jsx — 단말 해상도 대응 zoom
function InitializeWindow() {
  modifyWindowZoom(document.body, (window.innerHeight / 1480) * 100);
}
function modifyWindowZoom(domElement, percentage) {
  domElement.style["zoom"] = percentage + "%";
}
window.onload = InitializeWindow;
