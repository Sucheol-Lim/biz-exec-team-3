기능 개요

음성을 듣는 동안 화면에는 원이 물결로, 물결이 직선으로, 다시 원으로 변하는 파형 애니메이션이 재생됩니다. 프레임 이미지는 src/assets/Animation/UserSpeak 아래 4개 시퀀스 폴더(원에서물결 · 물결반복 · 물결에서직선 · 직선에서원)에 PNG로 들어 있고, import.meta.glob으로 빌드 타임에 일괄 로드해 각 시퀀스 배열로 채웁니다.

VoiceSequenceStore가 현재 시퀀스 상태(sequenceState)와 프레임 인덱스(currentSourceIndex)를 시그널로 들고, currentVoiceSequenceImg 메모가 현재 표시할 프레임을 산출합니다. VoiceSequence 컴포넌트는 이 이미지를 img 태그에 바인딩만 합니다. 한 시퀀스는 runCurrentSequence가 updateIndex(50ms 간격)로 인덱스를 증가시키며 끝까지 돌리고, updateSequenceState로 다음 상태(원에서물결→물결반복→물결에서직선→직선에서원→원에서물결)로 전환합니다. STT와 함께 쓰일 때는 repeatSequenceWhileSTT가 인식이 끝날 때까지 물결 구간(repeatSequence)을 반복해 "듣는 중" 상태를 유지합니다.

설계 포인트
애니메이션과 STT가 별개 비동기 흐름이라, 파형(runCurrentSequence)과 STT(startSTTAsync)가 동시에 끝나는 시점을 isSequenceFinished·isSTTFinished 플래그로 맞춥니다. 한쪽이 먼저 끝나면 다른 쪽이 끝날 때까지 물결을 반복해 끊김 없이 이어집니다.

관계. VoiceSequenceStore가 4개 프레임 배열과 상태 전이를 관리하고, VoiceSequence는 현재 프레임만 표시하며, STT와의 동기화는 repeatSequenceWhileSTT가 담당합니다.

핵심 코드

src/stores/VoiceSequenceStore.jsx — 프레임 로드 + 인덱스 순환
const CircleToWaveObj = import.meta.glob(
  "../assets/Animation/UserSpeak/01_원에서물결/*", { eager: true });
for (const img in CircleToWaveObj) CircleToWave.push(CircleToWaveObj[img].default);

const currentVoiceSequenceImg = createMemo(
  () => currentSequence()[currentSourceIndex()]
);

const updateIndex = async () => new Promise((resolve, reject) => {
  if (!isSequencePlaying()) reject("Sequence is not playing.");
  timeout = setTimeout(() => {
    let index = currentSourceIndex() + 1;
    if (index >= currentSequence().length || !isSequencePlaying()) resolve(0);
    else resolve(index);
  }, 50);
});
src/components/Common/Voice/VoiceSequence/VoiceSequence.jsx — 현재 프레임 표시
const VoiceSequence = () => {
  const { currentVoiceSequenceImg } = VoiceSequenceStore;
  return (
    <div>
      <div className={classes.voiceSquenceBg} />
      <img className={classes.voiceSquence} src={currentVoiceSequenceImg()} />
    </div>
  );
};
