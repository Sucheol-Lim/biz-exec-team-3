호출어(KWS) 감지

KwsDetector가 단말 내장 kwsrnet 엔진과 GiGA Genie Inside SDK로 마이크 입력을 상시 감시해 호출어(Keyword Spotting)를 감지하고, 감지 시 음성 인식 세션을 시작합니다.

기능 개요

AAOS 차량 단말에서 음성비서는 사용자가 버튼을 누르지 않아도 호출어("지니야" 등)만으로 깨어나야 합니다. 이를 위해 GVoiceInteractionService(:interactor 프로세스)가 상시 동작하며, 싱글턴 KwsDetector가 별도 스레드(KwsDetectThread)에서 AudioRecord로 16kHz PCM 오디오를 끊임없이 읽어 GiGA Genie Inside SDK의 kws_detect()에 프레임 단위로 전달합니다.

엔진이 호출어를 인식하면(kws_detect() 반환값 4 = detect complete) AudioRecord를 즉시 해제하고 OnKwsDetectListener.onKwsDetect(DETECTED) 콜백을 호출합니다. 서비스는 이 콜백을 받아 InsideVoiceManager.startSpeechRecognition()으로 실제 발화 인식 세션을 시작합니다. 마이크 권한이 없으면 PERM_ERROR를 통보해 권한 요청 화면을 띄웁니다.

설계 포인트
호출어 감지용 AudioRecord는 THREAD_PRIORITY_URGENT_AUDIO 우선순위로 동작하며, 감지 직후 곧바로 release 하여 후속 발화 인식 단계가 마이크를 점유할 수 있도록 자원을 넘겨줍니다.

관계. GVoiceInteractionService가 OnKwsDetectListener를 구현해 콜백을 수신하고, 싱글턴 KwsDetector는 내부 KwsDetectThread를 소유하며 Inside SDK로 감지를 수행합니다.

핵심 코드

inside/KwsDetector.java — 감지 루프와 완료 처리
recorder.startRecording();
while (!stop) {
    short[] buffer = buffers[ix % buffers.length];
    minBufferSize = recorder.read(buffer, 0, buffer.length);
    if (minBufferSize <= 0) { sleep(1); continue; }
    ix++;
    if (0 != inside.kws_error()) break;

    int ret = inside.kws_detect(buffer, minBufferSize);   // 호출어 엔진에 프레임 투입
    if (ret == 4) {                                        // detect complete
        recorder.stop();
        recorder.release();
        recorder = null;
        if (listener != null) {
            listener.onKwsDetect(DetectType.DETECTED);     // 서비스로 통보
        }
        stop = true;
    }
}
service/GVoiceInteractionService.java — 콜백 처리 후 인식 세션 위임
@Override
public void onKwsDetect(KwsDetector.DetectType type) {
    if (type == KwsDetector.DetectType.DETECTED) {
        InsideVoiceManager.getInstance().startSpeechRecognition();   // 발화 인식 시작
    } else {
        startMainActivityForPermission();                            // RECORD_AUDIO 권한 요청
    }
}
