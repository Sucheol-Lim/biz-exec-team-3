앱 실행/제어

GVoiceAppManager가 service intent를 대상 패키지로 매핑하고 설치 여부를 확인한 뒤, avis:// 딥링크 인텐트(ACTION_FROM_VOICE)로 차량 내 앱(내비게이션·일반 앱)을 음성으로 실행·제어합니다.

기능 개요

DialogKit이 앱 타입(APP_TYPE_AAOS_NAVIGATION 또는 APP_TYPE_COMMON)으로 라우팅하면 GVoiceAppManager.doAppAction(commandInfo)가 호출됩니다. 매니저는 commandInfo의 service intent를 GVoiceDataManager.getTargetAppPackage()로 패키지명으로 변환하고, PackageManager로 설치 여부를 확인합니다.

설치되어 있으면 앱 이름을 담은 안내 TTS("OO 앱을 실행 할게요")를 먼저 재생한 뒤, avis 스킴·대상 패키지를 authority로 하고 service intent·파라미터를 쿼리로 담은 딥링크 Uri를 만들어 ACTION_FROM_VOICE 인텐트로 대상 앱을 시작합니다. 미설치 시 "설치되어 있는지 확인해 주세요" 안내를 제공합니다. 이 매니저는 DSS 상태·TTS·STT용 브로드캐스트 리시버도 함께 등록합니다.

설계 포인트
앱 실행 인텐트는 표준 launcher 인텐트가 아니라 avis://<packageName>?serviceIntent=...&params=... 형태의 커스텀 딥링크입니다. 이를 통해 대상 앱이 단순 실행을 넘어 명령(검색어·재생 옵션 등)까지 파라미터로 전달받아 처리할 수 있습니다.

관계. GVoiceAppManager는 CommandInfo·GVoiceDataManager로 실행 대상을 결정하고, AppConstants의 키로 딥링크 Uri를 조립하며, 결과 안내는 InsideVoiceManager.startTTS로 위임합니다.

핵심 코드

dialogkit/app/GVoiceAppManager.java — 설치 확인 후 안내·실행
public void doAppAction(@NonNull CommandInfo commandInfo) {
    String serviceIntent = commandInfo.getServiceIntent();
    if (serviceIntent != null) {
        String applicationId = GVoiceDataManager.getInstance().getTargetAppPackage(serviceIntent);
        if (applicationId != null) {
            if (isPackageInstalled(applicationId)) {
                sendFeedback(applicationId, true);                 // 실행 안내 TTS
                new Handler(Looper.getMainLooper()).postDelayed(
                        () -> runTargetApp(commandInfo, applicationId), 500L);
            } else {
                sendFeedback(applicationId, false);                // 미설치 안내
            }
        }
    }
}
dialogkit/app/GVoiceAppManager.java — avis 딥링크 인텐트로 대상 앱 시작
Intent startIntent = new Intent();
startIntent.setAction(VoiceConstants.ACTION_FROM_VOICE);
Uri uri = new Uri.Builder()
        .scheme(VoiceConstants.COMMON_SCHEME)              // "avis"
        .authority(applicationId)
        .appendQueryParameter(AppConstants.QUERY_KEY_SERVICE_INTENT, commandInfo.getServiceIntent())
        .appendQueryParameter(AppConstants.QUERY_KEY_PARAMS,
                commandInfo.isCustomDialog() ? commandInfo.getAppInfo().toString()
                                             : commandInfo.getParams().toString())
        .build();
startIntent.setData(uri);
startIntent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
mContext.startActivity(startIntent);
