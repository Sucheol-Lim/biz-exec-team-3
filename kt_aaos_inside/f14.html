코드 난독화(Allatori)

빌드 시 build.gradle의 runAllatori 함수가 컴파일된 클래스를 allatori.xml 설정에 따라 Allatori로 난독화하고, 결과물로 원본 클래스 디렉터리를 교체합니다(커밋 6c315d77).

기능 개요

이 기능은 런타임 클래스가 아니라 빌드 파이프라인에 삽입된 후처리 단계입니다. 각 product flavor(dev·tb·production)의 빌드 변형(variant) 구성에서 variant.javaCompileProvider.get().doLast { runAllatori(variant) }를 등록해, Java 컴파일이 끝난 직후 난독화를 수행하도록 합니다.

runAllatori(variant) 함수는 allatori.xml을 빌드 중간 디렉터리로 복사하면서 입력 클래스 경로(classesRoot)·classpath·android.jar·로그 파일 경로를 expand()로 치환합니다. 이어 javaexec로 com.allatori.Obfuscate를 allatori/allatori.jar 클래스패스에서 실행하고, 산출된 -obfuscated 디렉터리를 원본 클래스 디렉터리 자리에 교체해 후속 패키징이 난독화 결과를 사용하게 합니다. allatori.xml의 keep-names는 Activity·Service·BroadcastReceiver·Parcelable·R 클래스·Enum 등을 난독화 예외로 보호합니다.

설계 포인트
Android 기본 R8/ProGuard 대신 Allatori를 컴파일 직후(doLast) 단계에 끼워 넣습니다. keep-names로 프레임워크가 이름으로 접근하는 컴포넌트(어시스턴트 서비스·리시버·Parcelable Creator)를 보호해, 난독화 후에도 AAOS 음성비서 등록·인텐트 처리가 깨지지 않도록 합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant G as Gradle (assemble<Flavor>Release) participant JC as javaCompile (variant) participant RA as runAllatori(variant) participant CFG as allatori.xml (expand) participant AL as Allatori (allatori.jar) G->>JC: Java 컴파일 수행 JC->>RA: doLast { runAllatori(variant) } RA->>CFG: copy + expand(classesRoot, classpathJars, androidJar) RA->>AL: javaexec com.allatori.Obfuscate (allatoril<variant>.xml) AL-->>RA: classes-obfuscated 생성 RA->>RA: 원본 classes 삭제 → obfuscated 를 원본 자리로 rename RA-->>G: 난독화된 클래스로 패키징 계속

흐름. 컴파일 직후 runAllatori가 설정을 치환·실행하고, 난독화 산출물로 원본 클래스 디렉터리를 교체해 이후 단계가 난독화 결과를 패키징합니다.

구성 다이어그램

classDiagram class build_gradle { +productFlavors dev / tb / production +variant.javaCompileProvider.doLast +runAllatori(variant) +getBuildDate() } class runAllatori { +copy allatori.xml + expand(...) +javaexec com.allatori.Obfuscate +deleteDir / renameTo } class allatori_xml { +input dir(classesRoot) +classpath androidJar / classpathJars +keep-names Activity / Service / Receiver } class allatori_jar { +com.allatori.Obfuscate } build_gradle --> runAllatori : doLast 등록 runAllatori --> allatori_xml : 설정 expand runAllatori --> allatori_jar : javaexec 실행

구성. build.gradle이 variant별로 runAllatori를 등록하고, 이 함수가 allatori.xml 설정과 allatori.jar 실행기를 결합해 난독화를 수행합니다.

핵심 코드

car-custom-voice-app/build.gradle — 컴파일 직후 난독화 후처리 등록
// for allatori
variant.javaCompileProvider.get().doLast {
    runAllatori(variant)
}
// ...
variant.outputs.all {
    outputFileName = "avis_voice_" + variant.getFlavorName() + "_" + versionNameValue
            + versionNameSuffix + "_" + getBuildDate() + ".apk"
}
car-custom-voice-app/build.gradle — runAllatori 함수 본체
def runAllatori(variant) {
    copy {
        from "$rootDir/allatori.xml"
        into "$buildDir/intermediates/classes/"
        expand(classesRoot: variant.javaCompileProvider.get().destinationDir,
               androidJar: "${android.sdkDirectory}/platforms/${android.compileSdkVersion}/android.jar ",
               classpathJars: variant.javaCompileProvider.get().classpath.getAsPath(),
               logFile: "allatorillogl${variant.name}.xml")
        rename('allatori.xml', "allatoril${variant.name}.xml")
    }
    javaexec {
        main = 'com.allatori.Obfuscate'
        classpath = files("$rootDir/allatori/allatori.jar")
        args "$buildDir/intermediates/classes/allatoril${variant.name}.xml"
    }
    // 원본 classes 삭제 후 obfuscated 디렉터리를 원본 자리로 교체
    new File("${variant.javaCompileProvider.get().destinationDir}").deleteDir()
    new File("${...}-obfuscated").renameTo(new File("${...}"))
}
