SP 미수신 재연동 로직

SP(서비스 플랫폼)에서 앱/명령 데이터를 받지 못한 상태로 발화 요청이 들어오면, 즉시 처리하는 대신 안내 TTS를 제공한 뒤 SP 연동을 재시도해 데이터를 갱신합니다(커밋 3904ef6b).

기능 개요

앱/의도 매핑 데이터는 AVIS 서비스 플랫폼(SP)에서 받아 GVoiceDataManager의 인메모리 맵에 로드됩니다. 그러나 부팅 직후나 SP 일시 장애로 데이터가 비어 있는 상태에서 사용자가 발화하면 명령을 라우팅할 매핑이 없습니다. 커밋 3904ef6b는 이 fail-over 시나리오를 추가했습니다.

InsideDialogKitManager.getCommandInfoFromPayload()에서 inside intent에 대한 service intent나 dssMsg가 없으면 CommandInfo를 만들지 못합니다. 이때 InsideVoiceManager.startErrorNoticeTTS(ERROR_CODE_SP_DATA_NOT_READY)로 "데이터 준비 중" 성격의 안내 TTS를 재생하고, 상위 processDialogKit()에서 카테고리가 null인 경우 GVoiceDataManager.getServiceData()를 호출해 SP 데이터를 다시 조회합니다. 지원하지 않는 DialogKit 타입은 ERROR_CODE_SP_DATA_NOT_SUPPORT TTS로 구분 안내합니다.

설계 포인트
getServiceData()는 상태가 AGENT_READY 이상이고 LOADING_DATA가 아닐 때만 재조회 메시지를 보내, 중복 로딩을 방지합니다. 즉시 실패 대신 "안내 → 재연동"으로 회복 가능한 사용자 경험을 제공하는 것이 이 로직의 목적입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant IVM as InsideVoiceManager participant DK as InsideDialogKitManager participant DM as GVoiceDataManager participant SP as AVIS SP 서버 IVM->>DK: processDialogKit(payload) DK->>DM: getServiceIntentFormInsideIntent(intent) DM-->>DK: null (데이터 미수신) DK->>IVM: startErrorNoticeTTS(SP_DATA_NOT_READY) Note over IVM: 안내 TTS 재생 DK->>DM: getServiceData() DM->>SP: getAppInfoList / getIntentInfoList SP-->>DM: AppInfo / IntentInfo DM->>DM: 인메모리 맵 갱신 → COMPLETE

흐름. 매핑 부재 감지 → 안내 TTS → SP 재조회 → 맵 갱신. 다음 발화부터 정상 라우팅이 가능해집니다.

관계. DialogKit이 데이터 부재를 감지하면 InsideVoiceManager로 안내하고 GVoiceDataManager로 재연동하며, 재조회 여부는 GVoiceDataState로 제어합니다.

핵심 코드

dialogkit/InsideDialogKitManager.java — 데이터 부재 시 안내·재연동
if (dssMsg != null && serviceIntent != null) {
    // ... 정상 CommandInfo 생성
} else {
    // 데이터가 준비되지 않은 상태로 판단 → TTS 제공
    InsideVoiceManager.getInstance().startErrorNoticeTTS(ErrorCodes.ERROR_CODE_SP_DATA_NOT_READY);
}
// processDialogKit(): category == null 인 경우
InsideVoiceManager.getInstance().startErrorNoticeTTS(ErrorCodes.ERROR_CODE_SP_DATA_NOT_READY);
GVoiceDataManager.getInstance().getServiceData();        // SP 재연동
manager/GVoiceDataManager.java — 상태 가드로 중복 로딩 방지
public void getServiceData() {
    if (gVoiceDataState.ordinal() >= GVoiceDataState.AGENT_READY.ordinal()) {
        if (gVoiceDataState.ordinal() != GVoiceDataState.LOADING_DATA.ordinal()) {
            sendEmptyMessage();              // GET_APP_INFO → GET_INTENT_INFO 재조회
        }
    }
}
