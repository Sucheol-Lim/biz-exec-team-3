사용 로그 수집

UsageCollectionManager가 사용자 발화(uword)와 처리된 의도(intent)를 묶어 음성 사용 로그를 수집하고, 사내 AVISSystemLibrary.voiceLog()(Service Agent Library)를 통해 BO 서버로 전송합니다.

기능 개요

사용 로그는 두 시점의 데이터를 결합합니다. 발화 인식이 끝나 InsideVoiceManager.agent_onCommand(ACTION_TYPE_STOP_VOICE)로 사용자 발화 텍스트(uword)가 오면 UsageCollectionManager.set(uword)로 보관하고, 이어서 DialogKit 명령 처리 시 write(intent)로 그때의 의도 문자열과 함께 로그를 확정·전송합니다.

실제 전송은 사내 Service Agent Library인 AVISSystemLibrary.voiceLog(ContentLogType.VOICE_RECOGNITION, userWord, intent)로 수행됩니다. init()에서 앱 패키지명·버전·APP_KEY·최대 로그 수(LOG_MAX_COUNT)로 로거를 초기화합니다. 한편 저장소에는 Retrofit 기반 REST 클라이언트 GVoiceApiClient도 함께 제공되어, SP/BO 서버와의 REST 데이터 송수신(앱·의도 데이터 조회 등) 기반으로 쓰입니다.

근거 메모
과제 카드는 사용 로그가 GVoiceApiClient(Retrofit)로 BO에 전송된다고 안내하지만, 실제 UsageCollectionManager 구현은 사내 AVISSystemLibrary.voiceLog()(avis-system-sdk)를 사용합니다. GVoiceApiClient는 동일 BO/SP 백엔드 연동의 REST 계층으로 코드베이스에 존재하므로, 본 페이지는 실제 코드 기준(AVISSystemLibrary)으로 흐름을 기술하고 REST 클라이언트도 함께 표기합니다.

관계. InsideVoiceManager가 발화·의도를 UsageCollectionManager에 공급하고, 실제 업로드는 AVISSystemLibrary.voiceLog가 수행합니다. GVoiceApiClient는 동일 백엔드와의 REST 연동 계층입니다.

핵심 코드

manager/UsageCollectionManager.java — 발화·의도 결합 후 로그 전송
public void write(@Nullable String intent) {
    if (this.userWord == null) {
        Log.d(TAG, "write(), userWord is null. return");
    } else {
        avisSystemLibrary.voiceLog(
                AVISSystemLibrary.ContentLogType.VOICE_RECOGNITION,
                this.userWord,
                intent);                      // BO 서버로 사용 로그 전송
        clear();
    }
}
inside/InsideVoiceManager.java — 인식 결과·의도 수집 트리거
case Inside.ACTION_TYPE_STOP_VOICE:
    String userWord = payload.cmdOpt.uword;
    if (userWord != null) UsageCollectionManager.getInstance().set(userWord);
    break;
case Inside.ACTION_TYPE_EXEC_DIALOGKIT:
    UsageCollectionManager.getInstance()
        .write(InsideDialogKitManager.getInstance().getInsideIntentFromPayload(payload));
    break;
