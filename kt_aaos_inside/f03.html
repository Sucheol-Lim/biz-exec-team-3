발화 음성 인식

VoiceRecorder가 AudioRecord로 16kHz PCM 오디오를 캡처하고, InsideVoiceManager가 GiGA Genie Inside SDK 음성 세션(agent_startVoice / agent_sendVoice)으로 프레임을 서버에 스트리밍해 발화를 인식합니다.

기능 개요

호출어가 감지되면 서비스는 InsideVoiceManager.startSpeechRecognition()을 호출합니다. 이 메서드는 먼저 AUDIOFOCUS_GAIN_TRANSIENT_EXCLUSIVE 오디오 포커스를 획득하고, 상태가 READY이면 시작 효과음(Sound2_Marimba.mp3)을 재생한 뒤 voiceStart()로 Inside SDK의 agent_startVoice()를 요청합니다.

SDK가 agent_onCommand(ACTION_TYPE_START_VOICE)로 마이크 On을 통보하면 VoiceRecorder가 생성되어 VOICE_RECOGNITION 소스의 AudioRecord로 PCM을 읽습니다. ProcessVoice 스레드는 진폭 임계치(AMPLITUDE_THRESHOLD)로 발성 여부를 판단해 onVoice(data, size) 콜백을 발생시키고, 콜백 안에서 insideSDK.agent_sendVoice(data, size)로 프레임을 서버에 스트리밍합니다. 인식이 끝나면 SDK가 ACTION_TYPE_STOP_VOICE로 사용자 발화 텍스트(uword)를 돌려주고, 호출어 감지가 다시 시작됩니다.

설계 포인트
발화 인식용 AudioRecord는 호출어 감지(KwsDetector)와 마이크가 충돌하지 않도록, 녹음 시작 전 stopKwsDetect()로 호출어 스레드를 멈춥니다. 인식 종료 후에는 startKwsDetect()로 다시 상시 대기 상태로 복귀합니다.

핵심 코드

inside/InsideVoiceManager.java — 마이크 On 콜백에서 녹음 시작, 프레임 스트리밍
case Inside.ACTION_TYPE_START_VOICE:
    mIsRecording = true;
    if (voiceState == InsideVoiceState.STT_GAIN_AUDIO_FOCUS) {
        GVoiceAppManager.getInstance().startSpeechToText();
    }
    startVoiceRecord();                       // VoiceRecorder 생성·start
    break;
// ...
private final VoiceRecorder.Callback mVoiceCallback = new VoiceRecorder.Callback() {
    @Override public void onVoice(short[] data, int size) {
        insideSDK.agent_sendVoice(data, size); // 서버로 PCM 스트리밍
    }
};
inside/VoiceRecorder.java — 발성 판정 후 콜백 발생
final int size = mAudioRecord.read(mBuffer, 0, mBuffer.length);
if (isHearingVoice(mBuffer, size)) {              // 진폭 임계치 초과 시
    if (mLastVoiceHeardMillis == Long.MAX_VALUE) {
        mVoiceStartedMillis = now;
        mCallback.onVoiceStart();
    }
    mCallback.onVoice(mBuffer, size);
    mLastVoiceHeardMillis = now;
}
