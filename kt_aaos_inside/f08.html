TTS·사운드 안내

ViaGuidancePlayer·ViaMediaPlayer·ViaSoundPlayer가 Inside SDK가 합성한 TTS 응답과 시작 효과음(Sound2_Marimba.mp3)·종료음(ding.mp3)을 재생해 음성비서의 청각 피드백을 담당합니다.

기능 개요

안내 재생은 두 갈래입니다. 첫째, 호출어 감지 직후 InsideVoiceManager.playGuidance()가 ViaGuidancePlayer를 생성해 시작 효과음(Sound2_Marimba.mp3)을 AssetFileDescriptor로 재생합니다. 둘째, 응답 안내가 필요할 때 startTTS(msg)가 Inside SDK의 agent_getTTS(msg)로 합성 결과 문자열을 받아 ViaGuidancePlayer.initPlayer(ttsMsg)로 재생합니다.

TTS 데이터는 base64 인코딩 mp3 형태라 GVoiceMediaDataSource(커스텀 MediaDataSource)로 디코딩해 MediaPlayer.setDataSource()에 주입합니다. 재생이 끝나면 OnCompletionCallback.onGuidanceComplete(isTTS) 콜백이 발생해, TTS였으면 오디오 포커스를 해제하고 호출어 감지를 재시작합니다. 미디어 스트림(TTS mediastream)은 ViaMediaPlayer.playWav()가, 종료 효과음은 ViaSoundPlayer가 SoundPool로 재생합니다.

설계 포인트
효과음과 TTS는 AudioAttributes를 분리합니다. 효과음은 CONTENT_TYPE_MUSIC, TTS는 CONTENT_TYPE_SPEECH·USAGE_ASSISTANCE_ACCESSIBILITY로 재생해 차량 오디오 라우팅 정책과 일관되게 동작합니다.

관계. InsideVoiceManager가 재생을 조율하고, ViaGuidancePlayer(효과음/TTS)·ViaMediaPlayer(스트림)·ViaSoundPlayer(SoundPool)가 역할을 분담하며, base64 TTS는 GVoiceMediaDataSource로 디코딩됩니다.

핵심 코드

inside/InsideVoiceManager.java — TTS 합성 후 재생, 완료 시 후처리
public void startTTS(@NonNull String msg) {
    String ttsMsg = getTTS(msg);                  // insideSDK.agent_getTTS(msg)
    if (ttsMsg != null && !ttsMsg.isEmpty()) {
        voiceState = InsideVoiceState.REQ_TTS;
        requestAudioFocusForRecognition(true, msg, ttsMsg, false);
    }
}
@Override public void onGuidanceComplete(boolean isTTS) {
    if (isTTS) {
        releaseAudioFocus();
        if (insideSDK.isKwsStart) KwsDetector.getInstance().startKwsDetect();
    }
}
player/ViaGuidancePlayer.java — base64 TTS를 커스텀 DataSource로 재생
mediaPlayer.setAudioAttributes(new AudioAttributes.Builder()
        .setUsage(AudioAttributes.USAGE_ASSISTANCE_ACCESSIBILITY)
        .setContentType(AudioAttributes.CONTENT_TYPE_SPEECH).build());
mediaPlayer.setDataSource(new GVoiceMediaDataSource(msg));   // base64 mp3 디코딩
mediaPlayer.prepareAsync();
mediaPlayer.setOnPreparedListener(mp -> mp.start());
mediaPlayer.setOnCompletionListener(mp -> stopPlayer());     // 재생 완료 → onGuidanceComplete
