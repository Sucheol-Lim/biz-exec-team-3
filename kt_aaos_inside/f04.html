자연어 명령 처리(DialogKit)

InsideDialogKitManager가 Inside gRPC Payload의 의도(intent)/명령(command)을 분류하고 CommandInfo로 정규화한 뒤, 앱 타입에 따라 미디어·차량·앱 매니저로 라우팅합니다.

기능 개요

대화 서버가 발화를 해석하면 InsideVoiceManager.agent_onCommand(ACTION_TYPE_EXEC_DIALOGKIT)로 Payload가 전달되고, 이는 InsideDialogKitManager.processDialogKit()로 넘어옵니다. 매니저는 execType(vehicleHandler=common, dialogHandler=custom)에 따라 DialogKitType을 판정하고, dssMsg에서 inside intent를 꺼냅니다.

꺼낸 inside intent는 GVoiceDataManager가 보유한 매핑 테이블로 service intent와 대상 앱 타입(APP_TYPE_AAOS_MEDIA, APP_TYPE_AAOS_NAVIGATION, APP_TYPE_VOICE, APP_TYPE_COMMON)으로 변환됩니다. 정규화 결과인 CommandInfo는 service intent·파라미터·custom 여부를 담아, 앱 타입별 분기에서 GVoiceMediaManager.doMediaAction()·GVoiceVehicleManager.doVehicleAction()·GVoiceAppManager.doAppAction()으로 분배됩니다.

설계 포인트
앱 타입(category)이 null이면 SP 데이터가 준비되지 않은 상태로 보고 startErrorNoticeTTS(ERROR_CODE_SP_DATA_NOT_READY)로 안내한 뒤 getServiceData()로 SP 재연동을 시도합니다. 알 수 없는 DialogKit 타입은 ERROR_CODE_SP_DATA_NOT_SUPPORT TTS로 처리합니다.

핵심 코드

dialogkit/InsideDialogKitManager.java — 앱 타입별 라우팅
CommandInfo commandInfo = getCommandInfoFromPayload(payload);
if (commandInfo != null) {
    String category = GVoiceDataManager.getInstance()
            .getIntentTargetAppType(commandInfo.getInsideIntent());
    if (category != null) {
        switch (category) {
            case VoiceConstants.APP_TYPE_AAOS_MEDIA:
                GVoiceMediaManager.getInstance().doMediaAction(commandInfo);   break;
            case VoiceConstants.APP_TYPE_AAOS_NAVIGATION:
                GVoiceAppManager.getInstance().doAppAction(commandInfo);       break;
            case VoiceConstants.APP_TYPE_VOICE:
                GVoiceVehicleManager.getInstance().doVehicleAction(commandInfo); break;
            case VoiceConstants.APP_TYPE_COMMON:
                GVoiceAppManager.getInstance().doAppAction(commandInfo);       break;
        }
    } else {
        InsideVoiceManager.getInstance().startErrorNoticeTTS(ErrorCodes.ERROR_CODE_SP_DATA_NOT_READY);
        GVoiceDataManager.getInstance().getServiceData();        // SP 재연동
    }
}
dialogkit/InsideDialogKitManager.java — execType으로 DialogKit 타입 판정
String execType = payload.cmdOpt.execType;
if (execType.equals("vehicleHandler")) return DialogKitType.DIALOG_KIT_TYPE_COMMON;
else if (execType.equals("dialogHandler")) return DialogKitType.DIALOG_KIT_TYPE_CUSTOM;
