시스템 음성비서 등록

GVoiceInteractionService가 AAOS 표준 VoiceInteractionService를 구현하고, @xml/interaction_service 메타데이터(supportsAssist, supportsLocalInteraction)를 통해 단말의 기본 디지털 어시스턴트로 등록되어 부팅 후 상시 구동됩니다.

기능 개요

AAOS 단말이 음성비서를 인식하려면 앱이 Android 음성 인터랙션 프레임워크에 정식으로 등록되어야 합니다. 이 앱은 service/GVoiceInteractionService를 android.service.voice.VoiceInteractionService 인텐트 필터와 android.permission.BIND_VOICE_INTERACTION 권한으로 매니페스트에 선언하고, android:process=":interactor" 별도 프로세스에서 상시 동작하도록 구성합니다.

서비스 노드의 <meta-data android:name="android.voice_interaction">는 @xml/interaction_service를 가리키며, 이 XML이 sessionService(GVoiceInteractionSessionService), recognitionService(GRecognitionService), settingsActivity(GSettingsActivity)를 함께 지정합니다. supportsAssist="true"·supportsLocalInteraction="true" 속성으로 어시스트와 로컬 인터랙션을 지원함을 선언해, 사용자가 이 앱을 기본 어시스턴트로 설정하면 시스템이 부팅 시 서비스의 onReady()를 호출합니다.

설계 포인트
서비스는 3개의 협력 컴포넌트를 한 XML로 묶습니다. VoiceInteractionService(:interactor)는 호출어 대기·세션 트리거를, SessionService(:session)는 발화 세션 UI를, RecognitionService는 표준 STT 공급자 역할을 분담합니다. onReady()에서 권한 확인 후 네트워크 매니저를 초기화해, 네트워크가 준비되면 Inside SDK·호출어 감지로 이어집니다.

관계. GVoiceInteractionService는 AAOS VoiceInteractionService를 상속하면서 호출어·Inside·데이터 3개 콜백 인터페이스를 동시에 구현해, 등록 이후의 전체 음성 파이프라인 진입점을 담당합니다.

핵심 코드

src/main/AndroidManifest.xml — 서비스 선언과 메타데이터 등록
<service
    android:name=".service.GVoiceInteractionService"
    android:enabled="true"
    android:exported="true"
    android:permission="android.permission.BIND_VOICE_INTERACTION"
    android:process=":interactor">
    <meta-data
        android:name="android.voice_interaction"
        android:resource="@xml/interaction_service" />
    <intent-filter>
        <action android:name="android.service.voice.VoiceInteractionService" />
    </intent-filter>
</service>
res/xml/interaction_service.xml — 협력 컴포넌트와 지원 속성 선언
<voice-interaction-service
    android:sessionService="com.kt.avis.voice.service.GVoiceInteractionSessionService"
    android:recognitionService="com.kt.avis.voice.service.GRecognitionService"
    android:settingsActivity="com.kt.avis.voice.ui.GSettingsActivity"
    android:supportsAssist="true"
    android:supportsLaunchVoiceAssistFromKeyguard="false"
    android:supportsLocalInteraction="true" />
service/GVoiceInteractionService.java — onReady 진입과 권한·네트워크 초기화
@Override
public void onReady() {
    super.onReady();
    registerPermissionReceiver();
    if (!checkRequiredPermission()) {           // RECORD_AUDIO 보유 시
        NetworkStateManager.getInstance().init(getApplicationContext(), mNetworkStateHandler);
    }
}
