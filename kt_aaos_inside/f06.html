기능 개요

GVoiceMediaManager는 SP 데이터의 미디어 앱 목록과 단말의 MediaBrowserService 조회 결과를 결합해, 제어 가능한 미디어 앱마다 GVoiceMediaClient를 생성·보유합니다. CarMediaManager에 미디어 소스 변경 리스너를 등록해 현재 재생 중인 미디어 앱(mCurrMediaApp)으로만 MediaBrowserConnector 연결을 유지하고, 나머지는 disconnect 합니다.

DialogKit이 미디어 명령을 라우팅하면 doMediaAction(commandInfo)가 GVoiceMediaController.controlMediaApps()로 위임합니다. 컨트롤러는 service intent로 대상 MediaSource와 액션(ACTION_PLAY·ACTION_PAUSE·ACTION_SKIP_TO_NEXT 등)을 결정하고, MediaControllerCompat 트랜스포트 제어로 명령을 실행합니다. 재생 상태 변화(PlaybackStateCompat)는 processPlaybackState()에서 받아 대화 서버의 dssStatus를 set/clear 하고, 미디어 로그는 Inside SDK로 전송합니다.

설계 포인트
여러 미디어 앱이 동시에 연결되면 자원·이벤트가 충돌하므로, 미디어 소스가 바뀔 때마다 updateMediaClientConnectionStatus()로 현재 앱을 제외한 클라이언트를 모두 끊어 단일 연결을 유지합니다.

관계. 매니저가 앱별 GVoiceMediaClient를 보유하며 CarMediaManager로 현재 소스를 추적하고, 명령 실행은 GVoiceMediaController가, 트랜스포트 제어는 MediaControllerCompat가 담당합니다.

핵심 코드

dialogkit/media/GVoiceMediaController.java — 액션별 트랜스포트 제어 분기
String action = GVoiceDataManager.getInstance().getServiceIntentAction(serviceIntent);
switch (action) {
    case MediaConstants.ACTION_PLAY:
        // 파라미터가 있으면 FROM_VOICE_EXTRAS 로 검색·재생, 없으면 단순 재생
        doVoiceMediaAction(mediaSource, MediaConstants.V_MEDIA_PLAY);
        break;
    case MediaConstants.ACTION_PAUSE:
        doVoiceMediaAction(mediaSource, MediaConstants.V_MEDIA_PAUSE);          break;
    case MediaConstants.ACTION_SKIP_TO_NEXT:
        doVoiceMediaAction(mediaSource, MediaConstants.V_MEDIA_SKIP_NEXT);      break;
    case MediaConstants.ACTION_SKIP_TO_PREVIOUS:
        doVoiceMediaAction(mediaSource, MediaConstants.V_MEDIA_SKIP_PREV);      break;
}
dialogkit/media/GVoiceMediaManager.java — 현재 소스만 연결 유지
for (String key : mMediaClientMap.keySet()) {
    if (!key.equals(mCurrMediaApp)) {
        GVoiceMediaClient mediaClient = mMediaClientMap.get(key);
        if (mediaClient != null && mediaClient.isConnected()) {
            mediaClient.disconnectBrowser(true);     // 비활성 소스 disconnect
        }
    }
}
