차량 공조 제어

GVoiceVehicleManager가 android.car.permission.CONTROL_CAR_CLIMATE 권한과 CarPropertyManager로 HVAC 에어컨 등 차량 공조 프로퍼티를 음성 명령에 따라 set 하고, 결과를 TTS로 안내합니다.

기능 개요

차량 제어는 DialogKit이 APP_TYPE_VOICE 명령을 라우팅해 GVoiceVehicleManager.doVehicleAction(commandInfo)로 진입합니다. 매니저는 init()에서 Car.createCar()로 CarPropertyManager를 얻고, HVAC_TEMPERATURE_CURRENT 콜백을 등록해 현재 온도를 추적합니다.

doVehicleAction()은 service intent가 INTENT_AC_ON/INTENT_AC_OFF인지 판별해 changeAC(turnOn, message)를 호출합니다. changeAC()는 안내 메시지가 있으면 먼저 TTS로 재생하고, HVAC_AC_ON 프로퍼티 설정을 조회한 뒤 변경이 필요한 area id만 골라 setBooleanProperty(HVAC_AC_ON, areaId, turnOn)으로 에어컨을 켜거나 끕니다. 온도 증감(changeTemperature)·창문 잠금(changeWindowLock)·차속 조회(getSpeedInMetersPerSecond) 등 추가 제어 로직도 구현되어 있습니다.

설계 포인트
차량 프로퍼티는 단말마다 지원 여부가 다르므로, 제어 전 getPropertyList()로 해당 프로퍼티 설정을 확인하고 미지원이면 조용히 반환합니다. CONTROL_CAR_CLIMATE 등 차량 권한은 시스템/플랫폼 서명 환경에서만 부여됩니다.

핵심 코드

dialogkit/vehicle/GVoiceVehicleManager.java — service intent별 공조 분기
public void doVehicleAction(@NonNull CommandInfo commandInfo) {
    String serviceIntent = commandInfo.getServiceIntent();
    String message = commandInfo.getSystemMessage();
    switch (serviceIntent) {
        case VehicleConstant.INTENT_AC_ON:  changeAC(true, message);  break;
        case VehicleConstant.INTENT_AC_OFF: changeAC(false, message); break;
        default: break;
    }
}
dialogkit/vehicle/GVoiceVehicleManager.java — HVAC_AC_ON 프로퍼티 설정
private void changeAC(boolean turnOn, String feedbackMessage) {
    if (feedbackMessage != null) InsideVoiceManager.getInstance().startTTS(feedbackMessage);
    List<CarPropertyConfig> configs = mCarPropertyManager.getPropertyList(
            new ArraySet<>(Collections.singletonList(VehiclePropertyIds.HVAC_AC_ON)));
    if (configs == null || configs.size() != 1) return;       // 미지원 단말
    int[] areaIds = configs.get(0).getAreaIds();
    for (int areaId : areaIds) {
        boolean on = mCarPropertyManager.getBooleanProperty(VehiclePropertyIds.HVAC_AC_ON, areaId);
        if ((!on && turnOn) || (on && !turnOn)) {
            mCarPropertyManager.setBooleanProperty(VehiclePropertyIds.HVAC_AC_ON, areaId, turnOn);
        }
    }
}
