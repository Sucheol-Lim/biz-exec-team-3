RecognitionService 등록

GRecognitionService가 android.speech.RecognitionService 인텐트 필터와 @xml/recognition_service 메타데이터로 시스템 음성 인식 공급자(STT provider)로 등록되어, 표준 SpeechRecognizer 요청에 응답할 수 있습니다.

기능 개요

음성비서 등록(interaction_service.xml)이 recognitionService로 GRecognitionService를 지정하므로, 이 앱은 음성 인터랙션의 인식 공급자 역할도 함께 맡습니다. 매니페스트에서 GRecognitionService는 android.speech.RecognitionService 액션·DEFAULT 카테고리 인텐트 필터와 <meta-data android:name="android.speech">(@xml/recognition_service)로 선언되어, 시스템이 인식 공급자 목록에 노출합니다.

GRecognitionService는 Android 표준 android.speech.RecognitionService를 상속하며, onStartListening()·onCancel()·onStopListening() 콜백을 구현합니다. 현재 구현은 onStartListening()에서 callback.readyForSpeech(null)을 통보하는 기본 형태로, 실제 인식 본체는 Inside SDK 경로(InsideVoiceManager)가 담당하고 이 서비스는 표준 프레임워크와의 등록·연결 지점 역할을 합니다.

설계 포인트
recognition_service.xml은 settingsActivity만 지정하는 최소 메타데이터입니다. 인식 공급자로 "등록"되는 것이 핵심이며, 실제 발화→텍스트 변환은 GiGA Genie Inside 음성 세션이 수행합니다.

핵심 코드

src/main/AndroidManifest.xml — RecognitionService 인텐트·메타데이터 선언
<service
    android:name=".service.GRecognitionService"
    android:enabled="true"
    android:exported="true">
    <intent-filter>
        <action android:name="android.speech.RecognitionService" />
        <category android:name="android.intent.category.DEFAULT" />
    </intent-filter>
    <meta-data
        android:name="android.speech"
        android:resource="@xml/recognition_service" />
</service>
service/GRecognitionService.java — onStartListening 콜백
@Override
protected void onStartListening(Intent intent, Callback callback) {
    if (callback != null) {
        callback.getCallingUid();
        try {
            callback.readyForSpeech(null);     // 인식 준비 완료 통보
        } catch (RemoteException e) {
            e.printStackTrace();
        }
    }
}
