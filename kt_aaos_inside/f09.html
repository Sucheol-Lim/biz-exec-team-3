표준 STT 서비스 경로

feature/support_stt에서 추가된 받아쓰기 경로입니다. 외부 앱이 START_STT/STOP_STT 액션과 targetAppId로 받아쓰기를 요청하면, 인식 결과(RECOGNITION_RESULT)나 오류(RECOGNITION_ERROR/UNAVAILABLE)를 브로드캐스트로 돌려줍니다.

기능 개요

이 경로는 음성비서 자체 명령 처리와 별개로, 외부 앱이 단순 받아쓰기(STT) 결과만 받고 싶을 때 사용합니다. GVoiceAppManager가 ACTION_PLAY_STT(com.kt.avis.action.START_STT)·ACTION_STOP_STT 브로드캐스트를 수신해 handleSttRequest()에서 targetAppId를 꺼냅니다. 요청자 ID는 currentCallerAppId로 저장됩니다.

START 요청은 InsideVoiceManager.startSTT(target)를 호출해 상태를 REQ_STT로 전환하고 오디오 포커스를 확보한 뒤 STT_GAIN_AUDIO_FOCUS 상태에서 voiceToTextStart()(agent_startVoiceToText)로 받아쓰기 전용 인식을 시작합니다. SDK가 ACTION_TYPE_START_VOICE를 통보하면 startSpeechToText()가 요청자에게 START_RECOGNITION 신호를 보내고, ACTION_TYPE_STOP_VOICE로 인식 결과(uword)가 오면 stopSpeechToText(uword)가 RECOGNITION_RESULT를 JSON으로 담아 대상 앱에만 브로드캐스트합니다. 오류·서비스 불가 시 각각 RECOGNITION_ERROR·RECOGNITION_UNAVAILABLE로 응답합니다.

설계 포인트
모든 응답 브로드캐스트는 intent.setPackage(targetAppId)로 요청한 앱에만 전송됩니다. 일반 음성 명령 흐름과 STT 흐름은 voiceState(REQ_STT / STT_GAIN_AUDIO_FOCUS) 분기로 구분되어, 같은 인식 파이프라인을 공유하면서도 결과 라우팅만 달라집니다.

핵심 코드

dialogkit/app/GVoiceAppManager.java — STT 요청 수신·분기
String target = data.getQueryParameter(AppConstants.QUERY_KEY_APP_ID);  // targetAppId
switch (intent.getAction()) {
    case AppConstants.ACTION_PLAY_STT:                  // START_STT
        setCurrentCallerAppId(target);
        InsideVoiceManager.getInstance().startSTT(target);
        break;
    case AppConstants.ACTION_STOP_STT:                  // STOP_STT
        setCurrentCallerAppId(null);
        InsideVoiceManager.getInstance().stopSTT();
        break;
}
dialogkit/app/GVoiceAppManager.java — 인식 결과를 대상 앱에만 응답
JSONObject root = new JSONObject(), sttObject = new JSONObject();
sttObject.put("target", targetAppId);
sttObject.put("message", recognizedText);
root.put("stt", sttObject);
Intent intent = new Intent(VoiceConstants.ACTION_FROM_VOICE);
intent.putExtra("type", AppConstants.TYPE_KEY_RECOGNITION_RESULT);   // RECOGNITION_RESULT
intent.putExtra("data", root.toString());
intent.setPackage(targetAppId);                                       // 요청 앱에만
mContext.sendBroadcast(intent);
