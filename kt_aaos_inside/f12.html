네트워크 상태 모니터링

NetworkStateManager가 ConnectivityManager.NetworkCallback으로 연결 상태를 감시하고, NetworkStateHandler가 이벤트를 메인 루퍼로 전달해 네트워크가 준비되면 Inside SDK 초기화를 트리거합니다.

기능 개요

발화 인식·NLU·TTS는 모두 Inside 서버와의 네트워크 연동에 의존하므로, 앱은 부팅 직후 네트워크가 준비되기를 기다렸다가 초기화를 진행해야 합니다. GVoiceInteractionService.onReady()는 권한 확인 후 싱글턴 NetworkStateManager.init(context, handler)를 호출합니다.

NetworkStateManager는 ConnectivityManager.registerNetworkCallback()으로 네트워크 콜백을 등록하고, onAvailable()/onLost()에서 내부 상태(NETWORK_STATE_AVAILABLE/LOST)를 갱신한 뒤 NetworkStateHandler.sendStateChangeMessage()로 이벤트를 보냅니다. 핸들러는 메인 루퍼에서 메시지를 받아, NETWORK_EVENT_AVAILABLE이면서 아직 시작 전(isStarted=false)일 때 단 한 번 initInsideVoiceManager()를 실행해 Inside SDK 등록·호출어 감지 파이프라인을 가동합니다.

설계 포인트
NetworkStateManager는 initialized 플래그로 중복 등록을 막고, 서비스는 isStarted로 초기화를 1회만 수행합니다. NetworkStateHandler에는 5분 지연(DELAY_TIME) 메시지 전송 기능도 마련되어 재시도 정책에 활용할 수 있습니다.

관계. NetworkStateManager는 콜백을 받아 NetworkStateHandler로 메시지를 보내고, 서비스가 핸들러를 익명 구현해 가용 이벤트에서 초기화를 수행합니다.

핵심 코드

manager/NetworkStateManager.java — 네트워크 콜백 등록·상태 통보
mNetworkCallback = new ConnectivityManager.NetworkCallback() {
    @Override public void onAvailable(@NonNull Network network) {
        network_state = NETWORK_STATE_AVAILABLE;
        mHandler.sendStateChangeMessage(NetworkStateHandler.NETWORK_EVENT_AVAILABLE);
    }
    @Override public void onLost(@NonNull Network network) {
        network_state = NETWORK_STATE_LOST;
        mHandler.sendStateChangeMessage(NetworkStateHandler.NETWORK_EVENT_LOST);
    }
};
connectivityManager.registerNetworkCallback(builder.build(), mNetworkCallback);
service/GVoiceInteractionService.java — 가용 이벤트에서 최초 1회 초기화
case NetworkStateHandler.NETWORK_EVENT_AVAILABLE:
    if (!isStarted) {
        isStarted = true;
        initInsideVoiceManager();      // InsideVoiceManager.init → SDK 등록·KWS 시작
    }
    break;
