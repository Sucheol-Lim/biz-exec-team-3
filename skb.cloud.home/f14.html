기능 개요

세 부가 서비스가 여러 화면에서 공통으로 쓰입니다. 추천은 RCMDManager가 VOD 상세 연관 추천(getVodDetailRelatedContents)을 SDP /rcmd/so/recommend에서 받고, 노출/클릭 통계는 sendLog(loggingUrl, clickType, itemValue)로 보냅니다. 날씨는 WeatherManager.getWeather가 사용자 우편번호(W.User.ZIP_CODE, 없으면 기본 지역)로 날씨 API 를 호출해 지역·기온·미세먼지·생활지수를 받아 W.WEATHER에 보관하고, 같은 시(hour)에 다시 요청하면 캐시를 반환합니다.

쿠폰·포인트 캐싱은 CouponCacheManager가 담당합니다. 캐시(CASH), 할인권(DISCOUNT), T포인트(T_POINT), TV포인트(TV_POINT), 타깃 쿠폰 등을 모델로 들고 12시간(EXPIRE) 동안 유지합니다. KDMC·SDP 두 서버 응답을 합쳐(responseObj.KDMC`/`SDP) 캐시를 만들며, 화면은 requestCouponCache(listener)로 캐시를 요청합니다. 통신 중이면 리스너만 추가하고, 강제 갱신은 forceUpdate(listener)로 캐시를 비우고 재연동합니다. 이 캐시는 VOD 구매 등에서 쿠폰·포인트 적용에 재사용됩니다.

캐시 만료·중복 요청 가드
쿠폰 캐시는 12시간 만료와 "현재 서버 통신 중이면 새 요청을 만들지 않고 리스너만 등록" 가드를 둬 동일 데이터에 대한 중복 연동을 막습니다. 날씨도 시(hour) 단위 캐시로 호출 빈도를 줄입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant UI as 화면(홈/상세) participant CCM as CouponCacheManager participant SVR as KDMC / SDP 서버 participant WM as WeatherManager participant WAPI as 날씨 API UI->>CCM: requestCouponCache(listener) alt 통신 중 아님 CCM->>SVR: 쿠폰/포인트 연동(KDMC + SDP) SVR-->>CCM: 캐시/할인권/T·TV포인트 CCM-->>UI: listener(true, copyModel(cache)) else 통신 중 CCM->>CCM: 리스너만 추가 end UI->>WM: getWeather(callback) alt 같은 시(hour) 캐시 있음 WM-->>UI: W.WEATHER (캐시) else WM->>WAPI: GET 날씨(zipCode) WAPI-->>WM: 지역/기온/미세먼지 WM-->>UI: W.WEATHER end

흐름. 쿠폰 캐시는 통신 중복을 막으며 KDMC+SDP 응답을 합쳐 캐시를 제공하고, 날씨는 시 단위 캐시로 API 호출을 줄입니다.

관계. CouponCacheManager가 CouponManager·UPMSManager 응답을 합쳐 캐시를 제공하고, RCMDManager·WeatherManager는 각각 추천·날씨를 독립적으로 공급합니다.

common/CouponCacheManager.js — 캐시 요청(중복 통신 가드)
requestCouponCache: function (listener) {
    this.requestCouponCacheListener = (listener || null);
    // 현재 서버 통신 중이면 처리 하지 않는다.
    if (this.responseObj.KDMC.isRequest === false &&
        this.responseObj.SDP.isRequest === false) {
        this.doCheckUpdateAndFlush(this.couponCache);
    } else {
        this.W.Log.debug('[CouponCacheManager] Now connecting. So, added only listener');
    }
},
// EXPIRE = 1000 * 60 * 60 * 12  // 캐시 12시간 유지
common/interface/WeatherManager.js — 날씨 시(hour) 단위 캐시
function getWeather(callback) {
    let zipCode = W.User.ZIP_CODE ? W.User.ZIP_CODE : W.Config.DEFAULT_REGION_CD;
    if (W.WEATHER && W.WEATHER.hour && W.WEATHER.jisu) {
        let hour = W._Util.getFormatDate(new Date(), "yyyyMMddHH");
        if (W.WEATHER.hour != hour) {
            request = d.ajax.call2(W, "get", true, W.HE.WEATHER_URL + zipCode + "/type/json", ...);
        } else {
            callback(W.WEATHER);   // 같은 시(hour) → 캐시 반환
        }
    } else {
        request = d.ajax.call2(W, "get", true, W.HE.WEATHER_URL + zipCode + "/type/json", ...);
    }
}
