기능 개요

홍보채널/홈쇼핑은 일반 메뉴 진입과 다른 부트 경로를 갖습니다. 부팅 옵션 id가 doAction이고 action이 promotion_ch_7(홍보채널) 또는 homeshopping_ch(홈쇼핑)이면, Boot.js는 메뉴 동기화를 일반 흐름과 다르게 처리하면서 AppHandler.onMessage(id, bootOption, undefined, true)로 곧장 홍보채널 Scene 진입을 시도합니다.

AppHandler.doAction이 액션을 라우팅하고, 홍보채널/홈쇼핑 액션은 contentPromoCh Scene 으로 연결됩니다. 핵심 제어는 ContentPromoChCtrl이며 라이프사이클(OnCreate·OnStart·OnResume·OnStop·OnDestroy)과 입력(operate·executeAction), 등급 변경(changeRating), 예고편 제어(forceStopTrailer`/`forceStopTrailerAndAVSizeFull)를 담당합니다. 콘텐츠 뷰·홈쇼핑·포스터·암호입력은 controller/(ContentsViewCtrl`/`HomeshoppingController`/`PosterController`/`PasswordInputController)가, 예고편 재생은 service/(TrailerPlayer`/`TrailerPlayService`/`TrailerAjaxService)가 처리합니다.

중복 진입 방지
홍보채널은 키를 빠르게 누르거나 로컬 앱에서 hideApp 없이 doAction을 연거푸 보낼 때 이전 홍보채널 타이머를 정리하는 처리가 들어 있습니다. 또한 이미 홍보채널 Scene 진입 상태(ADD_CONTENT_PROMOCH_SCENE)면 점프 인텐트를 저장해 두고 중복 push 를 막습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant BOOT as Boot.js (onStart) participant APP as AppHandler participant SC as ContentPromoChScene participant CT as ContentPromoChCtrl participant TP as TrailerPlayer BOOT->>BOOT: bootOption.id == doAction alt action == promotion_ch_7 / homeshopping_ch BOOT->>APP: onMessage(id, bootOption, undefined, true) APP->>APP: doAction(message, currentScene) APP->>SC: 홍보채널/홈쇼핑 Scene push SC->>CT: OnCreate() / OnStart(view) opt 예고편 CT->>TP: 예고편 재생 end end

흐름. 부트 액션이 홍보채널/홈쇼핑이면 메뉴 일반 진입을 건너뛰고 AppHandler.doAction이 contentPromoCh Scene 을 띄웁니다. 예고편은 TrailerPlayer가 재생합니다.

클래스 다이어그램

classDiagram class AppHandler { +onMessage(id, message, params, isBoot) +doAction(message, currentScene) -ACTION_PROMOTION_CH_7 -ACTION_HOMESHOPPING_CH } class ContentPromoChScene { +onCreate(ctx) } class ContentPromoChCtrl { +OnCreate(callback, chGenre) +OnStart(view, options) +operate(keyCode) +changeRating() +forceStopTrailer(callback) } class HomeshoppingController { +load() } class TrailerPlayer { +play() +stop() } AppHandler --> ContentPromoChScene : doAction 라우팅 ContentPromoChScene o-- ContentPromoChCtrl ContentPromoChCtrl o-- HomeshoppingController ContentPromoChCtrl --> TrailerPlayer : 예고편 재생

관계. AppHandler.doAction이 홍보채널/홈쇼핑 액션을 ContentPromoChScene으로 라우팅하고, ContentPromoChCtrl이 콘텐츠/홈쇼핑/예고편 컴포넌트를 조율합니다.
