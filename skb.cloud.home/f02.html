편성표(EPG)

EPG Grid 기반 전체 편성표(scene/epg)를 제공합니다. 채널 리스트·타임라인·프로그램 셀을 그리드로 구성하고, 실시간 인기 채널·선호 채널·채널 안내와 미구매 채널 PIP 표시를 지원합니다.

기능 개요

전체 편성표는 EpgGridScene이 진입점입니다. onCreate에서 W.PM.pushStack으로 스택을 쌓고, ctx.getIntent().type(EPG 타입)을 확인합니다. 타입이 없으면 W.Config.MENU_TYPE.EPG_ALL(전체 편성)을 기본으로 사용하고, MenuDataManager.findMenuByTag로 EPG 루트 메뉴를 찾습니다. 이후 EpgGridViewStatic(정적 그리드 뷰)을 만들고 EpgGridViewManager(UI 캐시)를 통해 화면을 구성합니다.

그리드는 epg/grid 아래의 여러 Ctrl 로 분할됩니다. ChListCtrl(채널 목록), TimelineCtrl(시간축), ProgBarListCtrlStatic·ProgCtrlStatic(프로그램 바/셀), FocusCtrl(포커스), FocusedProgInfoCtrl(선택 프로그램 정보), ReserveCtrl(예약), PipIframeCtrl(PIP iframe)이 협력합니다. 채널·편성 데이터는 epg/manager/ChannelDataManager와 ScheduleDataManager가 공급하고, 미구매·시청제한 채널은 PipIframeCtrl이 미리보기 영역을 표시하거나 차단 안내로 대체합니다.

최근 변경 맥락
편성표 진입 시 미구매 채널 PIP 미표시 수정(CPM-469), 시청제한 채널 PIP 표시 타이밍 보정(lastpermission), 실시간 인기 채널 12개→20개 확대 등 PIP·인기채널 관련 작업이 최근 master 커밋에 반영되어 있습니다.

흐름. EpgGridScene이 EPG 타입과 루트 메뉴를 정하고 EpgGridViewStatic을 구성합니다. 채널은 ChannelDataManager, 편성은 ScheduleDataManager가 공급하고, PIP 미리보기는 PipIframeCtrl이 그립니다.

핵심 코드

scene/epg/EpgGridScene.js — 편성표 타입 결정과 뷰 생성
onCreate: function (ctx) {
    W.PM.pushStack(ctx, "EpgGridScene", W.PM.TYPE_NORMAL,
            ctx.getIntent().isClearHistory, {type: ctx.getIntent().type});

    let epgType = ctx.getIntent().type;
    let fromHome = ctx.getIntent().fromHome;
    this.epgMenu = W.MenuDataManager.findMenuByTag(
            W.MenuDataManager._menu, W.Config.MENU_TAG.EPG_ROOT);

    if (!epgType) { epgType = W.Config.MENU_TYPE.EPG_ALL; }   // 기본: 전체 편성
    let view = new d.EpgGridViewStatic(epgType, this.epgMenu, fromHome);
    // ...
}
