VOD 재생(UMP)

UMPMediaPlayer가 UMP 미디어 서비스(clad.media.ump.UmpMediaPlayerService)로 재생 설정·시작·중지·완료·이어보기를 제어하고, UmpEventListener로 광고·BOF/EOF 이벤트를 수신합니다(scene/watchingVod).

기능 개요

VOD 재생은 WatchingVodScene이 화면·라이프사이클을, UMPMediaPlayer가 단말 미디어 제어를 담당하는 구조입니다. UMPMediaPlayer는 cloud_adaptor.js의 clad.media.ump.UmpMediaPlayerService(전역 W.MediaPlayerService)를 래핑합니다. 재생 전 buildPlayInfo(meta)로 파일명·암호화·requestId·assetId·이어보기 offset 등을 Map 으로 구성하고, setPlayInfo(list)가 setMediaConfig('vod.play.info', list)로 단말에 재생 정보를 전달합니다.

재생 시작은 start() → playStart(), 채널 전환을 동반한 시작은 stopAndPlay(list) 로 처리됩니다. 중지는 stop()(playStop), 튜닝 유지 중지는 stopWithoutTune()(playStopWithoutTune), 채널 복귀가 필요하면 stopChChange()(playStopWithChChange), 예약 채널 복귀는 playStopWithReservedCh(sid) 입니다. 이벤트는 setUmpEventListener로 등록한 콜백이 VODEVENT_ADVERT_START/STOP, VODEVENT_BEGIN_OF_FILE, VODEVENT_END_OF_FILE, VODEVENT_SESSION_ERROR 등을 통보하면 WatchingVodScene의 onStarted·onVodCompleted·onStoped 콜백으로 라우팅됩니다.

재생 상태 머신
mediaPlayerStatus(UMP_PLAYER_STATUS_TYPE)로 재생 상태를 추적하고, 단말 어댑터 연결 전 호출은 EventQueue(runService)에 적재했다가 W.MediaPlayerService 연결 후 실행합니다. 모든 RPC 콜에는 AdaptorHandler.sendTestLog로 호출/수신 로그가 남습니다.

핵심 코드

common/adapter/UMPMediaPlayer.js — 재생 정보 전달과 재생 시작
setPlayInfo: function (list, callback) {
    if (this.W.MediaPlayerService) {
        this.W.MediaPlayerService.setMediaConfig('vod.play.info', list, function (ri, rv) {
            callback && callback(rv);
        });
    }
},
start: function (callback) {
    this.W.MediaPlayerService.playStart(function (ri, rv) {
        this.W.Log.debug('[UMPMediaPlayer] playStart ri=', ri, ', rv=', rv);
        callback && callback(rv);
    });
},
common/adapter/UMPMediaPlayer.js — 재생 메타 → playInfo 구성
buildPlayInfo : function (meta) {
    if (!meta) return null;
    let playInfo = new Map();
    if (!meta.hasOwnProperty('offset'))   meta.offset   = '0';   // 이어보기 시점
    playInfo.set('vodFileName', meta.vodFileName);
    playInfo.set('encryp',      meta.encryp);
    playInfo.set('requestId',   meta.requestId);
    playInfo.set('assetId',     meta.assetId);
    playInfo.set('categoryId',  meta.categoryId);
    // ...
    return playInfo;
}
