4방향 라이브

기능 개요

4방향 라이브는 한 화면에서 네 가지 방향(영역)을 동시에 탐색하는 기능입니다. 네 영역은 각각 독립 Scene/Ctrl 로 구성됩니다. FourWayChannelCtrl(실시간 인기 채널), FourWayContentsCtrl(연관 콘텐츠), FourWayMyMenuCtrl(마이메뉴), FourWaySearchCtrl(검색) 이며, 공통 시각 요소·포커스 바·그림자 스펙은 FourWayVisible이 제공합니다.

각 Ctrl 은 동일한 라이프사이클 메서드(OnCreate·OnStart·OnResume·OnPause·OnStop·OnDestroy)와 입력 처리(operate(keyCode)·executeAction)를 가집니다. 채널 영역은 즐겨찾기(getFavorites)와 실시간 인기 채널을 표시하고, 채널을 선택하면 TVServiceManager를 통해 실제 채널 전환을 수행합니다. 연관 콘텐츠는 추천 데이터를, 검색 영역은 SearchManager 경로를 재사용합니다. 최근 master 작업은 4방향 채널의 연령제한 프로그램 확인 동작 정교화에 집중되어 있습니다.

동일 라이프사이클 패턴
네 영역 Ctrl 은 같은 인터페이스(OnCreate/OnStart/operate 등)를 공유해 4분할 컨테이너가 영역 전환·포커스 이동을 일관되게 다룰 수 있습니다. 연령제한 채널은 선택 시 프로그램 정보 유무에 따라 시청 제한/연령 제한 문구를 분기 표시합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant U as 사용자(리모콘) participant FW as 4way 컨테이너 participant CH as FourWayChannelCtrl participant TSM as TVServiceManager participant CT as FourWayContentsCtrl FW->>CH: OnCreate() / OnStart(view) CH->>CH: getFavorites(isUpdateFocus) U->>FW: 방향 키 입력 FW->>CH: operate(keyCode) alt 채널 선택 CH->>TSM: selectChannelToWatchById(chId) TSM-->>CH: 채널 전환(이벤트는 TV 시청 흐름) else 영역 이동 FW->>CT: OnResume() (연관 콘텐츠 영역 활성) end

흐름. 4분할 컨테이너가 각 영역 Ctrl 의 라이프사이클을 제어하고, 채널 영역에서 채널을 고르면 TVServiceManager로 전환합니다. 방향 키로 영역 간 포커스를 전환합니다.

클래스 다이어그램

classDiagram class FourWayVisible { +getFocusBar() -SHADOW_HEIGHT_TOP } class FourWayChannelCtrl { +OnCreate(callback) +OnStart(view, options) +operate(keyCode) +getFavorites(isUpdateFocus) +executeAction(name, a0, a1) } class FourWayContentsCtrl { +OnCreate(callback) +operate(keyCode) } class FourWayMyMenuCtrl { +OnCreate(callback) +operate(keyCode) } class FourWaySearchCtrl { +OnCreate(callback) +operate(keyCode) } class TVServiceManager { +selectChannelToWatchById(chId) } FourWayChannelCtrl ..> FourWayVisible : 시각 요소 FourWayContentsCtrl ..> FourWayVisible FourWayMyMenuCtrl ..> FourWayVisible FourWaySearchCtrl ..> FourWayVisible FourWayChannelCtrl --> TVServiceManager : 채널 전환

관계. 네 영역 Ctrl 이 공통 FourWayVisible을 사용하고 동일 라이프사이클/입력 인터페이스를 공유하며, 채널 영역만 TVServiceManager로 채널을 전환합니다.

핵심 코드

scene/4way/channel/FourWayChannelCtrl.js — 영역 라이프사이클·입력 인터페이스
var FourWayChannelCtrl = W.Class.extend({
    __className: 'FourWayChannelCtrl',
    OnCreate: function (callback) { /* 채널 영역 뷰 생성 */ },
    OnStart:  function (view, options) { this.getFavorites(true); },
    operate:  function (keyCode) { /* 방향/확인 키 처리 */ },
    executeAction: function (commandName, arg0, arg1) { /* 액션 실행 */ },
    getFavorites: function (isUpdateFocus) { /* 즐겨찾기/인기 채널 구성 */ }
});
