기능 개요

실시간 TV 시청은 클라우드 UI 가 단말에 직접 채널 튜닝을 지시하는 대표적인 RPC 연동 기능입니다. WatchingTvScene이 시청 화면 라이프사이클을 담당하고, 실제 채널 제어는 TVServiceManager가 cloud_adaptor.js에 정의된 clad.tv.CladTVService 인터페이스를 호출해 수행합니다. 채널 선택은 selectChannel(sourceId, extraData) / selectChannelToWatchById(chId), 예약은 reserve·cancelReserve, 즐겨찾기는 addFavorite·removeFavorite 로 처리됩니다.

시청제한은 단말이 콜백으로 통보합니다. TVServiceManager.setChannelEventListener(listener)로 clad.tv.ChannelEventListener를 등록하면 onChannelEvent(chid, chNum, chName, perm)으로 권한 결과가 들어옵니다. 권한 값은 PERM_OK(0), PERM_PARENTAL_RATING_BLOCKED(2), PERM_CA_BLOCKED(3), PERM_ADULT_BLOCKED(4), PERM_WRONG_PIN(5) 등이며, TBroad 확장(ADULT_BLOCKED(10), WRONG_PIN(11))도 정의돼 있습니다. 연령/성인 제한 채널은 PIN 입력(PinManager)을 거치거나 시청 제한·연령 제한 문구를 표시하고, 최종 권한은 getFinalPermission으로 재확인합니다.

에뮬레이터 가드 · 지연 큐
모든 RPC 호출은 if (this.W.RCU.isemul) return;로 에뮬레이터를 차단하고, W.CladTVService가 아직 연결되지 않았으면 EventQueue에 호출을 적재했다가 어댑터 연결 후 실행합니다. 이 때문에 어댑터 연결 타이밍에 무관하게 채널 제어가 누락되지 않습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant WT as WatchingTvScene participant TSM as TVServiceManager participant TV as CladTVService (단말 RPC) participant L as ChannelEventListener participant PIN as PinManager WT->>TSM: setChannelEventListener(listener) TSM->>TV: setChannelEventListener(listener) WT->>TSM: selectChannelToWatchById(chId) TSM->>TV: selectChannelToWatchById(chId) TV-->>L: onChannelEvent(chid, chNum, chName, perm) alt perm == PERM_OK L->>WT: 정상 시청 else 연령/성인/CA 제한 L->>WT: 차단 통보 WT->>PIN: PIN 입력 요청 PIN-->>WT: 인증 결과 WT->>TSM: getFinalPermission(callback) TSM->>TV: getFinalPermission() TV-->>TSM: ri, rv end

흐름. 시청 화면이 채널 이벤트 리스너를 등록하고 채널을 선택하면, 단말이 onChannelEvent로 권한 결과를 통보합니다. 제한 채널은 PIN 인증 후 getFinalPermission으로 최종 권한을 확인합니다.

관계. TVServiceManager가 단말 RPC CladTVService를 래핑하고, ChannelEventListener 콜백으로 권한 결과를 수신해 제한 시 PinManager 인증을 거칩니다.

핵심 코드

common/adapter/TVServiceManager.js — 채널 선택(에뮬 가드 + 지연 큐)
selectChannel : function (sourceId, extraData) {
    if (this.W.RCU.isemul) { return; }
    var self = this;
    try {
        var cbFn = function () {
            self.W.CladTVService.selectChannel(sourceId, extraData);
        };
        if (self.W.CladTVService) { cbFn(); }       // 어댑터 연결됨 → 즉시 호출
        else { self.EventQueue.push(cbFn); }        // 미연결 → 큐에 적재
    } catch (e) {
        self.W.Log.debug("[TVServiceManager] failed selectChannel");
    }
},
common/adapter/TVServiceManager.js — 최종 시청권한 확인
getFinalPermission: function (callback) {
    if (this.W.RCU.isemul) { callback(false); return; }
    var self = this;
    var cbFn = function () {
        self.W.CladTVService.getFinalPermission(function (ri, rv) {
            self.W.Log.debug('[TVServiceManager] getFinalPermission ri=', ri, ', rv=', rv);
            callback(ri, rv);
        });
    };
    if (self.W.CladTVService) { cbFn(); }
    else { self.EventQueue.push(cbFn); }
},
