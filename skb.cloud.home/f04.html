VOD 탐색 · 상세

VOD 목록·카테고리·상세(단편/시리즈/패키지) 화면을 제공합니다(scene/vod, scene/vodDetail). 콘텐츠 메타와 연관 추천은 ACMSManager·RCMDManager로 받고 예고편·3분 미리보기를 지원합니다.

기능 개요

VOD 영역은 목록/탐색(scene/vod)과 상세(scene/vodDetail)로 나뉩니다. 상세는 콘텐츠 유형에 따라 vodDetail/single(단편), vodDetail/series(시리즈), vodDetail/package(패키지) 세 가지 Scene 으로 분기되며, 공통 요소(구매 버튼·연관 탭·스크롤바·팝업)는 vodDetail/common이 담당합니다.

상세 메타데이터는 ACMSManager가 SDP 에서 가져옵니다. getContent(contentId)로 콘텐츠 정보를, getProductsOfContent(contentId)로 구매 상품을, 시리즈는 getProgramsSeries(seriesId, season)으로 회차를 조회합니다. 연관 추천(같은 장르·배우·감독)은 RCMDManager.getVodDetailRelatedContents가 SDP /rcmd/so/recommend에서 받아 연관 탭에 채웁니다. 예고편/3분 미리보기는 UMPMediaPlayer.startVodTrailer·startTrailer로 재생합니다(상세 재생 흐름은 VOD 재생 기능 문서 참고).

상세 유형 분기
단편·시리즈·패키지는 화면 레이아웃과 구매 단위가 달라 각각 SingleScene·SeriesScene·PackageScene으로 분리되어 있습니다. 진입 시 콘텐츠 타입에 따라 적절한 Scene 을 push 합니다.

RCMD-->>DET: 연관 추천 목록 opt 예고편/미리보기 DET->>UMP: startVodTrailer() / startTrailer() end

흐름. 목록에서 콘텐츠를 고르면 유형별 상세 Scene 이 열리고, ACMSManager로 메타·상품을, RCMDManager로 연관 추천을 채웁니다. 예고편은 UMPMediaPlayer 트레일러 재생을 호출합니다.

핵심 코드

common/interface/RCMDManager.js — VOD 상세 연관 추천 조회
function getVodDetailRelatedContents(dp, titleid, adultyn, rating,
        max_items, genre, actor, director, callback, ...) {
    var requestData = {
        dp: dp, cust: W.User.USER_ID, pc: '',
        titleid: titleid, adultyn: adultyn, rating: rating,
        max_items: max_items, frmt: 'json'
    };
    if (genre)    requestData['genre']    = genre;
    if (actor)    requestData['actor']    = actor;
    if (director) requestData['director'] = director;

    return d.ajax.call2(W, "get", true,
        W._Util.getSDPUrl('/rcmd/so/recommend'), 'json',
        requestData, callback, cbParameter, catchCallback);
}
