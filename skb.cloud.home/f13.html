기능 개요

PIN 처리는 PinManager가 입구이고, 실제 검증은 단말 설정 서비스에 위임됩니다. PinManager는 성인 PIN(checkUserPin), 구매 PIN(checkPurchasePin), PIN 조회(getPin), 변경(changeUserPin`/`changePurchasePin)을 제공합니다. PIN 값은 base64 로 인코딩해 전달되고, 내부적으로 { id: 'checkUserPin', param: ... } 형태의 메시지를 만들어 ConfigServiceManager.managePin으로 넘깁니다.

ConfigServiceManager.managePin(message)`은 메시지를 JSON 문자열로 만들어 단말 RPC `CladConfigService.managePin에 전달하고, 콜백 응답(JSON)을 파싱해 id별로 결과를 분기합니다(checkUserPin`/`checkPurchasePin`/`getPin`/`changeUserPin`/`changePurchasePin). 10초 내 응답이 없으면 타임아웃으로 실패 처리합니다. 시청제한 정책은 CladConfigService의 setCloudPinMode(enable)(클라우드 PIN 모드), getParentalRating`/`setParentalRating(연령 등급)으로 다루며, 실시간 채널의 성인/CA/연령 차단 결과는 ChannelEventListener.onChannelEvent(권한 enum, 실시간 TV 시청 문서 참고)로 통보됩니다.

단말 위임 + 타임아웃
PIN 정답 자체를 클라우드가 들고 있지 않고 단말에 위임(managePin)하는 구조입니다. 응답 지연 시 DEFAULT_TIMEOUT(약 10초)으로 false 처리해 화면이 멈추지 않게 합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant UI as PIN 입력 화면 participant PIN as PinManager participant CSM as ConfigServiceManager participant CFG as CladConfigService (단말 RPC) UI->>PIN: checkUserPin(pin, callback) PIN->>PIN: pin = base64 인코딩 PIN->>CSM: managePin({id:'checkUserPin', param}) CSM->>CFG: managePin(JSON.stringify(message)) alt 정상 응답 CFG-->>CSM: ri, rv (JSON) CSM->>CSM: parse → id별 결과 분기 CSM-->>PIN: true / false else 10초 무응답 CSM->>CSM: 타임아웃 → false end PIN-->>UI: 인증 결과

흐름. PinManager가 base64 인코딩한 PIN 메시지를 ConfigServiceManager.managePin으로 넘기고, 단말 RPC 응답을 id별로 파싱해 결과를 돌려줍니다. 무응답 시 타임아웃 처리합니다.

핵심 코드

common/adapter/PinManager.js — 성인 PIN 체크(base64 + managePin 메시지)
checkUserPin : function (pin, callback) {
    pin = Buffer.from(pin).toString('base64');
    let sendData = { 'id': 'checkUserPin', 'param': pin };
    this.W.ConfigServiceManager.managePin(sendData, callback);
},
common/adapter/ConfigServiceManager.js — managePin RPC + id별 분기 + 타임아웃
managePin : function (message, callback) {
    if (this.W.RCU.isemul) { callback && callback(false); return; }
    var self = this;
    self.W.CladConfigService.managePin(JSON.stringify(message), function (ri, rv) {
        self.W.safeClearTimeout(self.connectionTimer);
        var jsonData = rv ? JSON.parse(rv) : {};
        if (jsonData.id == 'checkUserPin' && jsonData.response == true)        callback && callback(true);
        else if (jsonData.id == 'getPin' && jsonData.response)                 callback && callback(Buffer.from(jsonData.response, 'base64').toString('ascii'));
        else                                                                  callback && callback(false);
    });
    // 10초 무응답 → false
    self.connectionTimer = self.W.safeTimeoutSilently(function () {
        callback && callback(false); callback = null;
    }, self.W.Config.DEFAULT_TIMEOUT);
},
