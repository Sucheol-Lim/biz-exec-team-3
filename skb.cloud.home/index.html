개요

본 과제는 SK브로드밴드(SKB)가 운영하는 TBroad 케이블/IPTV 셋톱박스(STB)에서 동작하는 클라우드 기반 홈 포털 UI 애플리케이션입니다. 일반적인 단말 내장 앱과 달리 UI 로직이 서버 측 클라우드 컨테이너에서 구동되고, 셋톱박스에는 화면 출력과 키 입력을 위한 클라이언트만 존재하는 클라우드 UI(Cloud UI) 방식으로 설계되어 있습니다. 화면 구성·데이터 연동·비즈니스 로직은 모두 클라우드에서 처리되며, 채널 전환·미디어 재생·PIN·설정 같은 단말 고유 기능은 cloud_adaptor RPC 인터페이스를 통해 셋톱박스로 위임됩니다.

패키지명은 com.tbroad.cloud.ep3이며, 부트 로그에는 TBROAD CLOUD HOME으로 표기됩니다(src/Preload.js). 대상 단말은 TBroad STB로, 해상도 540(720p 계열) 및 1080(1080p) 두 가지 단말 프로파일을 지원합니다(src/env/STB-540.js, src/env/STB-1080.js). 실행 환경은 Alticast의 Wind.js(WCloud) 런타임이며, 앱은 WCloud.App.extend({...}) 형태로 정의됩니다(src/Boot.js).

주요 화면은 홈, 실시간 TV 시청 및 편성표(EPG), VOD 탐색·상세·구매·재생, 검색(텍스트·음성), 마이홈(최근 시청·구매목록·즐겨찾기·가입내역·쿠폰), 4방향 라이브, 홍보채널, 스마트 리모콘 페어링, TV 청구서 등으로 구성됩니다. 화면은 모두 src/scene/ 아래에 Scene 단위로 모듈화되어 있으며, 메뉴·채널·VOD 데이터는 SDP 서버에서 받아 구성합니다.

클라우드 UI 구조의 의미
이 앱의 코드는 셋톱박스가 아닌 서버 컨테이너(예 ccui_home_hp_ep2_540...)에서 Node.js 런타임으로 실행됩니다. 따라서 빌드 산출물은 단말에 설치되는 APK가 아니라, 클라우드 서버로 업로드되어 컨테이너로 서비스되는 소스/리소스 묶음입니다. 단말과의 모든 상호작용은 RPC(rop) 기반 clad.* 인터페이스를 거칩니다.

주요 기능

홈 / 큐레이션
메뉴·배너·추천 콘텐츠로 구성된 홈 화면과 큐레이션을 제공합니다(scene/home, scene/homeEx). PIP·홍보 영역을 포함합니다.
편성표(EPG)
EPG Grid 기반 전체 편성표를 제공합니다(scene/epg). 실시간 인기 채널, 선호 채널, 채널 안내, 미구매 채널 PIP 표시를 지원합니다.
실시간 TV 시청
채널 선택·전환·예약·즐겨찾기·시청제한(연령/CA) 처리를 단말 어댑터(TVServiceManager)와 연동해 수행합니다(scene/watchingTv).
VOD 탐색 · 상세
VOD 목록·카테고리·상세(단편/시리즈/패키지) 화면을 제공합니다(scene/vod, scene/vodDetail). 예고편·3분 미리보기를 지원합니다.
VOD 구매 · 결제
단편/시리즈/월정액 구매, 일반·단체 가입자 분기, 쿠폰·할인권·티켓·포인트 적용까지 구매 흐름을 처리합니다(scene/purchase, CouponManager, UPMSManager).
VOD 재생(UMP)
UMP 미디어 플레이어(UMPMediaPlayer, clad.media.ump.UmpMediaPlayerService)로 재생 시작·중지·완료·이어보기를 제어합니다(scene/watchingVod).
검색(텍스트 · 음성)
키보드 입력 검색과 음성 검색을 제공하며, 검색 결과 캐싱 처리를 포함합니다(scene/search, SearchManager).
4방향 라이브
실시간 인기 채널·연관 콘텐츠·마이메뉴·검색을 4분할 화면에서 동시 탐색하는 라이브 4방향 기능입니다(scene/4way).
마이홈
쿠폰·공지사항, 최근 시청 VOD, 구매목록, 즐겨찾기, 가입내역, 월정액 내역 조회·삭제를 제공합니다(scene/myHomeSub, scene/history).
홍보채널 / 홈쇼핑
홍보채널(VOD Asset·성인채널·PIP·데이터방송·예고편)과 홈쇼핑 모아보기를 별도 부트 액션으로 진입 처리합니다(scene/contentPromoCh).
스마트 리모콘 페어링
블루투스 스마트 리모콘 페어링 및 Companion OTP 연동을 지원합니다(PairingManager, ConfigServiceManager).
TV 청구서 / 고객만족도
TV 청구서 조회·미납요금 결제와 고객만족도 조사를 제공합니다(scene/customerSatisfaction, TvCsManager, CustomerSurveyManager).
PIN · 시청제한
클라우드 PIN 모드, 연령 등급(Parental Rating), 성인/CA 차단 등 시청제한과 PIN 입력을 처리합니다(PinManager, clad.config.CladConfigService).
추천 · 날씨 · 쿠폰 캐싱
추천 시스템 연동(RCMDManager), 날씨 정보(WeatherManager), 쿠폰·포인트 캐싱(CouponCacheManager) 등 부가 데이터 서비스를 제공합니다.

아키텍처 · 모듈 구조

소스는 부팅 계층(Boot.js·BootConfig.js·Preload.js), 단말 연동 계층(common/adapter + cloud_adaptor.js), 서버 데이터 계층(common/interface), 화면 계층(scene/*), 전역 공통(global/*)으로 나뉩니다. 모든 모듈은 W.Mod.define({의존성}, function(W, d){...}) 형식의 Wind 모듈로 정의되며, 전역 객체 W(모듈/리모콘/뷰/로그 등)에 의존합니다.

외부 연동 관계

앱은 두 방향으로 외부와 연동합니다. 아래로는 셋톱박스와 RPC(rop) 기반 cloud_adaptor로 통신해 채널 선택(selectChannel), VOD 재생(playStart·stopAndPlay), PIN 관리(managePin), 시스템 정보(getSystemInfo), 시청제한 처리 등을 수행합니다. 위로는 SDP/서비스 서버와 HTTP/HTTPS로 통신해 메뉴·채널·편성·VOD·쿠폰·추천·날씨·고객 데이터를 받아옵니다. 헤드엔드(HE) 서버 주소는 src/env/HE-*.js에 환경별로 정의되어 있으며(testbed/live/sat/suyu), 예를 들어 testbed 환경의 SDP 서버는 192.168.255.60입니다. 앱 코드 자체는 클라우드 서버 컨테이너에서 실행되어 화면을 단말로 스트리밍/전달하는 클라우드 UI 구조입니다.

핵심 동작 흐름

클라우드 앱 부팅 시퀀스 (Boot.js)

  1. 전역 W 초기화onStart(W, appConfig)에서 new W.CRoot()를 만들고 BootConfig.initializeGlobalW로 전역 모듈을 구성합니다.
  2. 부트 옵션 파싱에뮬레이터면 W.RCU.appOption, 실단말이면 appConfig.option(JSON)을 파싱합니다. 실단말의 경우 initializeAdaptor로 어댑터를 연결합니다.
  3. 부트 옵션 적용 · 세션 시작initializeBootOption으로 환경을 반영하고 HOST MAC·ACCESS TOKEN·USER ID·LOCAL VERSION을 로그로 남깁니다. 실패 시 terminateOnBootError(CL1000)로 에러 팝업을 띄웁니다.
  4. 진입 유형 분기옵션 id에 따라 doCloudInit(부트 캐싱), doAction(홍보채널/홈쇼핑), 일반 메뉴 진입으로 분기합니다.
  5. 메뉴 데이터 동기화일반 진입 시 MenuDataManager.syncData로 SDP 메뉴를 동기화합니다. 실패하면 terminateOnBootError(CL1001)로 종료합니다.
  6. 첫 화면 표시성공 시 AppHandler.onMessage(bootOption.id, ...)로 첫 Scene을 띄우고 SharedDataManager에 BOOT_COMPLETED를 기록합니다. 종료 시 onStop에서 세션 정리 후 W.PM.destroyApp()으로 앱을 파기합니다.

VOD 구매 · 재생 흐름

  1. VOD 상세 진입scene/vodDetail에서 단편·시리즈·패키지 유형별 상세 정보를 표시하고 예고편/3분 미리보기를 제공합니다.
  2. 구매 처리scene/purchase가 일반/단체 가입자, 단편/시리즈/월정액을 분기 처리하고 CouponManager·UPMSManager로 쿠폰·할인권·티켓·포인트를 적용합니다. 필요 시 PIN 인증(PinManager)을 거칩니다.
  3. 재생 시작UMPMediaPlayer가 UmpMediaPlayerService.setDataSourceUmp*와 playStart를 호출해 재생을 시작하고 UmpEventListener로 광고 시작/종료·BOF/EOF 등 이벤트를 수신합니다.
  4. 재생 중지 · 완료중지 시 playStop/playStopWithoutTune, 채널 복귀가 필요하면 playStopWithChChange를 호출합니다. 재생 완료(EndOfMedia) 후 시청 화면을 정리합니다.

실시간 채널 전환 · 시청제한 흐름

  1. 채널 선택편성표/4방향에서 채널을 고르면 TVServiceManager가 CladTVService.selectChannel(또는 selectChannelById)을 호출합니다.
  2. 채널 이벤트 수신ChannelEventListener.onChannelEvent로 PERM_OK·PERM_PARENTAL_RATING_BLOCKED·PERM_ADULT_BLOCKED·PERM_CA_BLOCKED·PERM_WRONG_PIN 등 권한 결과를 받습니다.
  3. 시청제한 처리연령/성인 제한 채널은 PIN 입력(PinManager)이나 시청 제한·연령 제한 문구를 표시하고, 미구매 채널은 PIP로 표시합니다. 최종 권한은 getFinalPermission으로 확인합니다.

빌드 · 실행

빌드는 grunt/ 디렉토리에서 수행합니다. 동봉된 래퍼 스크립트(grunt.sh / grunt.cmd)는 node_modules가 없으면 npm install을 먼저 실행한 뒤 grunt를 구동합니다. Node.js 4.5.0 환경을 전제로 합니다.

# grunt 디렉토리에서 의존성 설치 (최초 1회)
npm install

# 기본 태스크 — 소스를 빌드(dist 복사)하고 변경 감지(watch)
sh grunt.sh        # 또는 grunt

# 개발용 bare 서버에 이미지+소스 업로드
grunt lightbuild  --dev=6 --he-env=testbed --resolution=1080 --ver=1.1.6
# 소스만 업로드(경량)
grunt lightbuild2 --dev=6 --he-env=testbed --resolution=1080 --ver=1.1.6

# 정식 릴리즈
grunt releaseall --ver=1.10.2

# node_modules 포함 src 압축 릴리즈 / JSHint 정적 검사
grunt release
grunt hint

주요 Grunt 태스크 (Gruntfile.js)

  • default = buildcopy + watch — 소스 변경 시 자동 재빌드합니다.
  • buildtest / buildcopy — clean 후 소스·필터·리소스를 dist/로 복사합니다.
  • release(= product) — node_modules를 포함한 소스를 복사·압축(zip)합니다.
  • lightbuild / lightbuild2 — clean 후 빌드하여 Alti 클라우드 bare 서버(192.168.254.11)에 SFTP 업로드합니다(개발자별 인스턴스 경로 inst<dev>).
  • releaseall / releaseproduct — shell 태스크 기반 릴리즈입니다.

빌드 옵션

옵션기본값값 / 의미
--he-envtestbed헤드엔드 환경 — testbed / live / sat / suyu. src/env/HE-<env>.js 선택.
--resolution540단말 해상도 — 540 / 1080. STB-<res>.js·style-<res>·res-<res> 선택.

산출물은 ../dist/<패키지명> 경로에 생성되며, 패키지명은 해상도(및 sat 환경 여부)에 따라 com.tbroad.cloud.ep3.540, com.tbroad.cloud.ep3.1080.sat 등으로 조합됩니다. 빌드 시 grunt/Version.js가 템플릿 처리되어 버전과 업데이트 날짜(UPDATE)가 주입됩니다. 산출물은 단말 APK가 아니라 클라우드 서버 컨테이너로 배포되는 소스/리소스 묶음입니다.
