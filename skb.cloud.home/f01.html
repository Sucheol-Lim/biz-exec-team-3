홈 / 큐레이션

메뉴·배너·추천 콘텐츠로 구성된 홈 화면(scene/home)을 구성하고, CurationCtrl이 ACMS 큐레이션 데이터를 받아 추천 영역을 채웁니다. PIP·홍보 영역을 함께 제공합니다.

기능 개요

홈은 부팅 직후 AppHandler.onMessage가 띄우는 첫 Scene 입니다. HomeScene.onCreate는 먼저 W.MenuDataManager._menu(SDP 메뉴 데이터)가 있는지 확인하고, 없으면 MenuDataManager.syncData로 다시 동기화합니다. 동기화 실패 시 ErrorHandler.operate(CL9999)로 에러 처리합니다. 이후 HomeViewManager(UI 캐시 관리)와 HomeView를 만들어 SharedDataManager에 보관하고, initId(기본은 두 번째 메뉴, 점프 진입 시 hierarchy)에 따라 첫 포커스를 둡니다.

홈 화면의 좌측 1depth 메뉴는 Menu·PagingMenu가 MenuDataManager._menu를 페이지 단위로 그립니다. 우측 추천 영역은 CurationCtrl.getCurationMenu가 ACMSManager.getHomeCuration을 호출해 큐레이션 데이터를 받아 채우고, NVOD 편성(getNvodSchedule)도 함께 조회합니다. 배경 영상/PIP 는 home/pip/PIP.js·home/bg에서, 홈 프로모션 배너는 home/promotion/PromoCtrl.js에서 담당합니다.

설계 포인트
View 객체는 createCache 단계가 아니라 onCreate 시점에 무조건 먼저 만들어 SharedDataManager.HOME_VIEW에 달아 둡니다. onStart 시점이 언제 불리든 setView가 누락되지 않도록 하기 위한 처리입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant APP as AppHandler participant HS as HomeScene participant MDM as MenuDataManager participant HVM as HomeViewManager participant MENU as Menu / PagingMenu participant CUR as CurationCtrl participant ACMS as ACMSManager (SDP) APP->>HS: onCreate(ctx) HS->>HS: W.PM.pushStack("HomeScene") alt 메뉴 데이터 없음 HS->>MDM: syncData(callback) MDM-->>HS: isSuccess / error end HS->>HVM: new HomeViewManager() HS->>HS: SharedDataManager.set(HOME_VIEW, new HomeView()) HS->>MENU: create(view) (1depth 메뉴 페이징) MENU->>MDM: _menu 참조 HS->>CUR: new CurationCtrl(view) CUR->>ACMS: getHomeCuration(callback) ACMS-->>CUR: 큐레이션 데이터 CUR->>CUR: getNvodSchedule() Note over HS,CUR: 메뉴 + 추천 + PIP/홍보 구성 후 표시

흐름. 부팅 후 HomeScene이 메뉴 데이터를 확인·동기화하고 HomeView를 만든 뒤, 좌측 메뉴(Menu)와 우측 큐레이션(CurationCtrl → ACMSManager.getHomeCuration)을 채워 첫 화면을 구성합니다.

관계. HomeScene이 HomeView/Menu/CurationCtrl/PIP를 조합합니다. Menu는 MenuDataManager._menu를, CurationCtrl은 ACMSManager 큐레이션 데이터를 사용합니다.

핵심 코드

scene/home/HomeScene.js — 메뉴 데이터 보장 후 View 생성
// 메뉴가 없을 경우 메뉴를 다시 가져오도록 한다
if (!W.MenuDataManager._menu) {
    W.MenuDataManager.syncData(function (isSuccess, error) {
        if (isSuccess) {
            W.Log.debug("[HomeScene] menu data syncData ", isSuccess);
        } else {
            W.ErrorHandler.operate(W.TbroadErrorCode.CL9999, {"finishCtx": true});
            syncError = true;
        }
    });
    if (syncError) { return; }
}
// view는 무조건 먼저 만들어 SharedDataManager 에 달아 둔다
if (!W.SharedDataManager.get(W.SharedDataManager.HOME_VIEW)) {
    W.SharedDataManager.set(W.SharedDataManager.HOME_VIEW, new d.HomeView(), false);
}
scene/home/menu/CurationCtrl.js — ACMS 큐레이션 조회
getCurationMenu: function () {
    var self = this;
    d.acmsManager.getHomeCuration(function (isSuccess, result, api) {
        // 큐레이션 응답을 받아 추천 영역 데이터로 구성
        self.curationDatas = result;
        // ...
    }.bind(this), ['getHomeCuration']);
}
