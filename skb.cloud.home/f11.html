스마트 리모콘 페어링

블루투스 스마트 리모콘 페어링은 단말 설정 RPC(ConfigServiceManager)로, 모바일 Companion 앱 연동 여부는 PairingManager → UPMSManager.getCloudDevices로 확인합니다.

기능 개요

페어링은 두 갈래입니다. 첫째, 블루투스 스마트 리모콘 페어링은 단말 설정 서비스(clad.config.CladConfigService)를 통해 수행됩니다. ConfigServiceManager가 BT 등록 모드 진입(setBTRCUMode), 등록 모드 종료(setBTRCUModeOut), 기기 등록 모드(setBTDeviceRegistMode), 연결 기기 목록 모드(setConnectedBTDeviceListMode), 연결된 기기 개수(getBTConnectedDeviceCount)를 단말에 위임합니다. 모든 RPC 는 에뮬레이터 가드(W.RCU.isemul)와 콜백(ri, rv) 처리를 거칩니다.

둘째, 모바일 Companion(리모콘 앱) 연동 여부는 클라우드 서버 데이터로 확인합니다. PairingManager.update`가 `UPMSManager.getCloudDevices(USER_ID)로 사용자 디바이스 목록을 받아 device_type === 'handheld'이면서 paired === true인 기기가 있으면 페어링 여부(PAIR_YN)를 'Y'로 설정하고 SessionManager.setPairingYn`/`W.User.PAIR_YN에 저장합니다. 이 값으로 홈의 페어링 유도 영역을 분기합니다. OTP 기반 Companion 연동도 동일하게 디바이스 목록의 paired 상태로 귀결됩니다.

단말 위임 vs 서버 조회
BT 리모콘은 단말 하드웨어 작업이라 RPC 로 단말에 위임하고, Companion 앱 페어링은 클라우드 계정에 묶인 상태라 SDP userprofile API(/userprofile/api1/users/<id>/devices)로 조회합니다. 두 경로가 분리돼 있다는 점이 이 기능의 핵심 구조입니다.

관계. PairingManager는 Companion(서버) 페어링을, ConfigServiceManager는 단말 BT 리모콘 페어링(CladConfigService RPC)을 담당합니다.

핵심 코드

common/PairingManager.js — Companion 페어링 상태 판정
update: function () {
    d.upmsManager.getCloudDevices(this.W.User.USER_ID, function (isSuccess, result) {
        if (isSuccess && result && result.data) {
            var pairYn = 'N';
            for (var i = 0; i < result.data.length; i++) {
                if (result.data[i].device_type === 'handheld' && result.data[i].paired == true) {
                    pairYn = 'Y';   // 모바일 앱이 페어링됨
                }
            }
            this.W.SessionManager.setPairingYn(pairYn);
            this.W.User.PAIR_YN = pairYn;
        }
    }.bind(this));
}
common/adapter/ConfigServiceManager.js — BT 리모콘 등록 모드 진입
setBTRCUMode: function (callback) {
    if (this.W.RCU.isemul) { callback && callback(false); return; }
    var self = this;
    self.W.CladConfigService.setBTRCUMode(function (ri, rv) {
        self.W.Log.debug("[ConfigServiceManager] setBTRCUMode ri:", ri, ", rv:", rv);
        callback(rv);
    });
},
