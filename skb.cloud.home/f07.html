검색(텍스트 · 음성)

키보드 입력 검색과 음성 검색을 제공합니다(scene/search). SearchManager가 자동완성·인기·추천·이력·실제 검색 API 를 호출하고, 진행 중 요청 취소(ajaxStop)로 중복 연동을 막습니다.

기능 개요

검색은 입력 화면(search/main)과 결과 화면(search/result)으로 구성됩니다. SearchMainScene/SearchMainCtrl이 키보드 입력·음성 입력과 자동완성·인기·추천 키워드를 제공하고, SearchResultScene/SearchResultCtrl이 검색 결과를 보여 줍니다. 데이터 연동은 SearchManager가 담당합니다.

SearchManager는 자동완성(getComplete), 인기 키워드(getKeywordPopular), 추천 키워드(getKeywordRecommend), 검색 이력 조회/삭제(getKeywordHistory/deleteKeywordHistory), 실제 검색(getSearch/searchKeyword), 결과 프로그램 상세(getQueryPrograms)를 호출합니다. 모든 요청은 attachAssesToken으로 W.User.ACCESS_TOKEN을 붙이고, searchAjaxBrocker가 진행 중 요청을 추적해 새 검색 시 ajaxStop()으로 이전 요청을 취소합니다(중복 연동·레이스 방지). 결과 없음(total=0)은 안내 팝업으로 처리합니다.

캐싱 · 요청 취소
검색 결과/키워드는 searchAjaxBrocker 브로커 객체로 관리되어 새로운 검색이 들어오면 이전 요청을 중단합니다. 음성 검색도 동일한 SearchManager.searchKeyword 경로로 결과 화면으로 진입합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant MAIN as SearchMainCtrl participant SM as SearchManager participant SVR as 검색 서버 (SDP) participant RES as SearchResultScene MAIN->>SM: getComplete(keyword) (자동완성) SM->>SVR: GET 자동완성 SVR-->>SM: 후보 키워드 MAIN->>SM: searchKeyword(keyword, callback) SM->>SM: searchAjaxBrocker.ajaxStop() (이전 요청 취소) SM->>SVR: getSearch(getDefaultParameter(keyword)) SVR-->>SM: 검색 결과(hits) alt total == 0 SM->>MAIN: 결과 없음 팝업 else SM->>RES: SearchResultScene push (결과 표시) RES->>SM: getQueryPrograms(ids) (상세 보강) end

흐름. 입력 중에는 자동완성을 받고, 검색 실행 시 이전 요청을 취소한 뒤 getSearch로 결과를 받아 결과 화면으로 진입합니다. 단편/영화는 getQueryPrograms로 상세를 보강합니다.

클래스 다이어그램

classDiagram class SearchMainScene { +onCreate(ctx) } class SearchMainCtrl { +onInput(keyword) +onVoiceResult(text) } class SearchResultScene { +onCreate(ctx) } class SearchResultCtrl { +render(result) } class SearchManager { +getComplete(req, callback) +getKeywordPopular(req, callback) +getKeywordRecommend(req, callback) +getKeywordHistory(req, callback) +deleteKeywordHistory(keyword, callback) +getSearch(req, callback) +searchKeyword(keyword, callback, successCallback) +getQueryPrograms(ids, callback) } class searchAjaxBrocker { +querySearch +queryPrograms +ajaxStop() } SearchMainScene o-- SearchMainCtrl SearchResultScene o-- SearchResultCtrl SearchMainCtrl ..> SearchManager : 자동완성/검색 SearchResultCtrl ..> SearchManager : 결과/상세 SearchManager o-- searchAjaxBrocker : 요청 취소 관리

관계. 입력/결과 Scene 이 각 Ctrl 을 통해 SearchManager를 호출하고, SearchManager는 searchAjaxBrocker로 진행 중 요청을 취소·관리합니다.

핵심 코드

common/interface/SearchManager.js — 키워드 검색(이전 요청 취소 후 진입)
function searchKeyword(keyword, callback, successCallback) {
    W.Loading.justLock();
    getSearch(getDefaultParameter(keyword), function (isSuccess, responseData) {
        W.Loading.stopAll();
        if (isSuccess && responseData) {
            var total = 0;
            if (responseData.hasOwnProperty('hits')) total += responseData.hits.total;
            if (total == 0) {
                W.PM.pushPopup({ id: 'BasePopupScene', /* 결과 없음 안내 */ });
            }
            // 결과 화면(SearchResultScene)으로 진입
        }
    });
}
function getSearch(requestData, callback, cbParameter, catchCallback) {
    searchAjaxBrocker.ajaxStop();               // 진행 중 요청 취소
    var brocker = searchAjaxBrocker.querySearch;
    brocker.xhr = getQuerySearch(requestData, brocker.OnCallback, cbParameter, catchCallback);
    return searchAjaxBrocker;
}
common/interface/SearchManager.js — 액세스 토큰 부착
function attachAssesToken(requestData) {
    if (!requestData) {
        requestData = { access_token: W.User.ACCESS_TOKEN };
    } else {
        requestData.access_token = W.User.ACCESS_TOKEN;
    }
    return requestData;
}
