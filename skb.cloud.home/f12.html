기능 개요

이 기능은 성격이 다른 두 서버 연동을 묶습니다. TV 청구서는 TvCsManager가 담당합니다. 납부자 정보(getPayerInfo), 가입 상품(getCustProdInfo), 청구 내역(getBillInfo(monthCnt)), 청구 상세(getBillDetailInfo(yyyymm)), 기본 정보(getDefaultInfo)를 조회하고, 본인 확인이 필요할 때 휴대폰 인증(postMobileCert(hpNumber))을 거칩니다. 미납 요금 결제는 청구 내역을 바탕으로 진행됩니다.

고객만족도 조사는 CustomerSatisfactionScene이 화면을, CustomerSurveyManager가 서버 연동을 담당합니다. getSurvey(surveyNo)로 설문을 받아 표시하고(고객/서비스/STB MAC 식별자를 포함해 요청), 사용자가 답하면 postAnswer(surveyNo, answerArray)로 답변을 전송합니다. 설문조사 서버는 Content-type: application/json 헤더와 stringify 된 본문을 요구하는 점이 코드에 명시돼 있습니다. 화면은 질문(QuestionCtrl), 우측 박스(RightBoxCtrl), 완료 팝업(Popup)으로 구성됩니다.

식별자 구성
설문 요청에는 id_cust(W.User.CUST_ID), id_cust_svc(W.User.SSPT_ID), stb_mac(HOST_MAC에서 콜론 제거)이 포함됩니다. 동일 단말/가입자의 응답을 식별하기 위한 키입니다.

흐름. 청구서는 TvCsManager가 내역/상세/본인확인을, 만족도 조사는 CustomerSurveyManager가 설문 조회·답변 전송을 처리합니다.

관계. 청구서는 TvCsManager가, 만족도 조사 화면(CustomerSatisfactionScene + QuestionCtrl)은 CustomerSurveyManager가 서버 연동을 담당합니다.

핵심 코드

common/interface/CustomerSurveyManager.js — 설문 조회(식별자 + json 헤더)
function getSurvey (surveyNo, callback, isGetUrl) {
    let requestData = {
        survey: {
            id_cust:     W.User.CUST_ID,
            id_cust_svc: W.User.SSPT_ID,
            stb_mac:     W.User.HOST_MAC.replace(/:/g, ''),
            sno:         surveyNo,
        }
    };
    // 설문 서버는 'application/json' 헤더 + stringify 된 본문을 요구
    return d.ajax.call2(W, 'post', true,
        W.HE.CUSTOMER_SURVEY_SERVER + "searchSurvey.do", 'json',
        JSON.stringify(requestData), callback, undefined, undefined, undefined, undefined,
        "application/json");
}
