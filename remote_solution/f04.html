드래그 즐겨찾기 (찜하기)

포스터를 길게 눌러 잡은 뒤 하단 dragPopup 영역으로 드롭하면 즐겨찾기에 추가되는 인터랙션을 시연합니다. 드롭 시 Added to Favorite Movies/Series 토스트로 결과를 안내합니다.

기능 개요

드래그 즐겨찾기는 Motion Control 요구사항 중 "포스터를 잡고 움직여 찜한다"를 구현한 인터랙션입니다. 포스터 아이템을 길게 누르면(setOnLongClickListener) startDragAndDrop()으로 드래그가 시작되고, 동시에 onItemDragEventStarted 콜백이 HomeFragment로 올라가 하단 dragPopup 드롭 영역을 노출합니다.

HomeFragment.onVodItemDragStarted()가 dragPopup에 OnDragListener를 설치합니다. 드래그가 팝업 영역에 들어오면(ACTION_DRAG_ENTERED) AutoTransition으로 팝업을 확대하고 드래그 중인 포스터 이미지를 placeholder에 복사해 보여 줍니다. 영역을 벗어나면(ACTION_DRAG_EXITED) 원래 크기로 되돌립니다.

드롭(ACTION_DROP)이 발생하면 팝업을 숨기고 Added to Favorite Movies/Series 토스트를 띄워 찜 완료를 안내합니다. 드롭 없이 종료되면(ACTION_DRAG_ENDED이고 dropAccepted == false) 크기·이미지·배경을 모두 원상복구합니다.

데모용 처리
실제 즐겨찾기 저장소 갱신은 없고 토스트 노출까지만 구현된 PoC 인터랙션입니다. 특정 타이틀(Good Fortune·the family plan 2·zootopia 2)은 placeholder에 전용 포스터 리소스를 직접 매핑합니다.

흐름. 롱프레스로 드래그 시작 → 프래그먼트가 드롭 팝업 노출 → 진입 시 확대/이미지 복사 → 드롭 시 토스트, 미드롭 시 원복.

핵심 코드

ui/home/vod/PosterItemAdapter.kt — 롱프레스로 드래그 시작
itemView.setOnLongClickListener { _ ->
    onItemDragEventStarted.invoke(vod)
    val dragView = binding.root.findViewById<ImageView>(R.id.img)
    val clipdata = ClipData.newPlainText("title", vod.title)
    val sdw = View.DragShadowBuilder(dragView)
    dragView.startDragAndDrop(clipdata, sdw, dragView, View.DRAG_FLAG_OPAQUE)
    return@setOnLongClickListener true
}
ui/home/HomeFragment.kt — 드롭 수락 시 토스트 (발췌)
DragEvent.ACTION_DROP -> {
    dropAccepted = true
    binding.dragPopup.visibility = View.GONE
    animateSizes(/* 원래 크기로 복구 */)
    placeholderView.setImageDrawable(null)
    android.widget.Toast.makeText(
        requireContext(),
        "Added to Favorite Movies/Series",
        android.widget.Toast.LENGTH_SHORT
    ).show()
    return@setOnDragListener true
}
