휠 스크럽 탐색 (REW/FF)

기능 개요

휠 스크럽은 입력 장치의 휠(또는 Smart Air Ring 회전)을 굴려 영상을 되감기/빨리감기하는 Wheel 요구사항입니다. 휠 대상 콘텐츠에서는 VodFragment가 루트 뷰에 OnGenericMotionListener를 달아 제너릭 모션 스크롤(ACTION_SCROLL)을 받습니다. 휠 회전은 AXIS_VSCROLL 축 값으로 들어옵니다.

스크롤 방향(scrollY)에 따라 현재 재생 위치에서 1초(1_000L)를 빼거나 더해 다음 위치를 계산하고, player.seekTo()로 즉시 이동합니다. 위로 굴리면 REW(되감기), 아래로 굴리면 FF(빨리감기)이며, 0~영상 길이 범위로 클램프합니다. 동시에 showPlayerIcons(RW/FW)로 방향 아이콘을 잠깐 표시합니다.

탐색 위치를 시각화하기 위해 하단에 프레임 썸네일 리스트를 띄웁니다. initFrameList(title)이 타이틀별 프레임 개수·간격(frameFactor)으로 Frame 목록을 만들고, 각 썸네일은 file:///android_asset/<title>_frame/scene%05d.jpg 경로의 동봉 이미지입니다. VodFrameAdapter가 이를 Coil3로 로드하며, RSLinearLayoutManager(focusedCenter = true)로 선택 프레임을 중앙에 정렬합니다.

D-pad 좌우 소비
휠 재생 모드(isVodForWheelPlay)이고 Ring 미연결일 때는 D-pad LEFT/RIGHT를 받아도 시킹하지 않고 그대로 소비(consume)합니다. 휠 스크럽이 탐색을 전담하도록 일반 좌우 시킹과 충돌을 막는 처리입니다.

핵심 코드

ui/vod/VodFragment.kt — 휠 스크롤 1초 단위 탐색
binding.root.setOnGenericMotionListener { v, event ->
    if (event.action == MotionEvent.ACTION_SCROLL) {
        val scrollY = event.getAxisValue(MotionEvent.AXIS_VSCROLL)
        val currentPosition = player.currentPosition.coerceAtLeast(0L)
        val maxPosition = player.duration
        val nextPosition = if (scrollY > 0) {
            showPlayerIcons(PlayControl.RW)
            (currentPosition - 1_000L).coerceAtLeast(0L)
        } else {
            showPlayerIcons(PlayControl.FW)
            (currentPosition + 1_000L).coerceAtMost(maxPosition)
        }
        seekPlayerByFramePosition(nextPosition)
        true
    } else false
}
ui/vod/VodFragment.kt — 타이틀별 프레임 썸네일 목록 생성
fun initFrameList(title: String): List<Frame> {
    val frameNum = frameCount(title)
    val frameFactor = when (title) {
        TITLE_GOOD_FORTUNE, TITLE_THE_DEVIL_WEARS_PRADA_2 -> 25
        TITLE_ONE_BATTLE_AFTER_ANOTHER, TITLE_LILO_AND_STITCH -> 30
        else -> throw IllegalArgumentException("Unknown title: $title")
    }
    return List(frameNum) { index ->
        val frameTime = index * frameFactor + 1
        Frame(
            timeSeconds = frameTime,
            assetImageFileName = String.format("file:///android_asset/${title}_frame/scene%05d.jpg", frameTime),
        )
    }
}
