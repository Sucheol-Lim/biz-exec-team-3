기능 개요

Circle to Search는 영상 위에 원을 그려 그 안의 영역을 검색하는 Motion Control 요구사항입니다. VodFragment가 playerView의 터치를 받아, 누른 채 슬롭(touchSlop)을 넘게 움직이면 CircleInkView를 노출하고 원래 DOWN 이벤트부터 InkView로 전달해 획을 시작시킵니다. CircleInkView는 MotionEvent 좌표를 ML Kit Ink.Stroke로 수집하는 동시에 자체 currentPoints 리스트에도 적재합니다.

획이 끝나면(handleUp) maybeCommitCircle()이 "원에 가까운지"를 자체 기하 로직으로 판정합니다. 판정 기준은 다섯 가지입니다. (1) 바운딩 박스 종횡비(aspectOk, 0.7~1.4), (2) 평균 반지름 대비 표준편차로 본 반지름 안정성(radiusOk, < 0.50), (3) 시작점과 끝점의 거리로 본 경로 폐합(closureOk), (4) 둘레 대비 그린 길이(lengthOk, 60% 이상), (5) 최소 크기(sizeOk, 80px 초과).

다섯 기준을 모두 통과하면 평균 반지름을 정원의 반지름으로 삼아 startMorphToCircleThenDraw()가 비뚤어진 획의 각 점을 원주 위로 투영(atan2·cos·sin)하면서 450ms 모핑 애니메이션을 재생합니다. 모핑이 끝나면 1초간 정원을 보여 준 뒤 영역 캡처(다음 기능)로 넘어갑니다. 기준 미달이어도 시작/끝점이 매우 가깝고(tightClosureOk) 크기가 어느 정도면(sizeOkLoose) 관대하게 원으로 인정합니다.

ML Kit 역할 한정
ML Kit Digital Ink는 Ink/Ink.Stroke 타입으로 획을 수집하는 데만 쓰이고, 원 여부 판정은 ML 인식이 아니라 CircleInkView 내부의 순수 기하 계산(hypot·표준편차·경로 길이)으로 수행합니다.

흐름. 영상 위 드로잉 → 획 수집 → 기하 기준 다섯 가지 판정 → 통과 시 정원 모핑 후 캡처, 미달 시 ERROR 통보.

핵심 코드

ui/vod/CircleInkView.kt — 원 판정 기준 (발췌)
val aspect = if (height == 0f) Float.MAX_VALUE else width / height
val aspectOk = aspect in 0.7f..1.4f                   // 거의 정사각 바운딩 박스

val radiusStability = if (meanR == 0.0) Double.MAX_VALUE else stdR / meanR
val radiusOk = radiusStability < 0.50                  // 반지름 분산이 작을수록 원

val endGap = hypot((end.first - start.first).toDouble(), (end.second - start.second).toDouble())
val closureOk = meanR > 0 && endGap / meanR < 0.90      // 시작/끝점이 가까움(폐합)

val length = pathLength(currentPoints)
val lengthOk = length > (2 * Math.PI * meanR) * 0.6    // 둘레의 60% 이상 그림
val sizeOk = max(width, height) > 80f                  // 너무 작지 않음

if (aspectOk && radiusOk && closureOk && lengthOk && sizeOk) {
    post { startMorphToCircleThenDraw(cx, cy, meanR.toFloat(), currentPoints.toList()) }
}
ui/vod/CircleInkView.kt — 획을 정원 원주 위로 투영(모핑)
morphProj = points.map { (x, y) ->
    val ang = atan2((y - cy).toDouble(), (x - cx).toDouble())
    val px = cx + r * cos(ang).toFloat()
    val py = cy + r * sin(ang).toFloat()
    px to py
}
