라이브 채널 · 미니 EPG

라이브 채널 재생과 함께 미니 EPG(MiniEpgAdapter), 미니 가이드(MiniguideAdapter)를 제공하며, InfiniteAdapterWrapper로 무한 스크롤을 구현합니다.

기능 개요

라이브 채널 화면은 ExoPlayer로 채널 콘텐츠를 재생하면서, 세로 방향 미니 가이드(채널 목록, rvMiniguide)와 가로 방향 미니 EPG(프로그램 편성, rvMiniEpg)를 동시에 보여 줍니다. 데이터는 ChannelDataRepository가 ChannelDataSource(15개 채널)와 ProgramDataSource(채널별 편성)에서 만들어 옵니다.

ChannelViewModel은 화면 상태를 ChannelUiState(Loading / Success.ChannelUpdated / Success.ProgramUpdated / Error) StateFlow로 노출합니다. ChannelFragment는 flowWithLifecycle로 이 상태를 구독해, 채널이 바뀌면 미니 가이드를 갱신·스크롤하고 선택 채널의 편성을 미니 EPG에 반영하며 tuneContents()로 0.5초 디바운스 후 재생을 시작합니다.

채널 미니 가이드는 끝없이 위아래로 돌릴 수 있도록 InfiniteAdapterWrapper로 감싸집니다. 이 래퍼는 getItemCount()를 Int.MAX_VALUE로 반환하고 position % 실제크기로 데이터를 매핑해 순환 스크롤을 구현합니다. ViewModel은 시작 채널을 가운데(Int.MAX_VALUE / size / 2 부근)로 잡아 양방향 무한 스크롤이 자연스럽게 동작하게 합니다.

스로틀·디바운스
채널 전환은 updateSelectedChannelIndex에서 100ms 스로틀로 과도한 전환을 막고, 실제 재생 전환은 tuneContents에서 500ms 디바운스로 빠른 채널 넘김 중 불필요한 재생을 건너뜁니다. 미니 가이드/EPG는 D-pad 입력 후 5초 뒤 자동으로 숨겨집니다.

핵심 코드

ui/util/component/InfiniteAdapterWrapper.kt — 순환 매핑으로 무한 스크롤
override fun getItemCount(): Int =
    if (dataAdapter.currentList.isEmpty()) 0 else Int.MAX_VALUE

override fun onBindViewHolder(holder: RecyclerView.ViewHolder, position: Int) {
    val realIndex = position % dataAdapter.currentList.size
    dataAdapter.onBindViewHolder(holder, realIndex)
}
ui/channel/ChannelViewModel.kt — 시작 위치를 가운데로, 인덱스 모듈로 매핑
val selectedChannelIndex get() = channelScrollPosition % channelDataRepository.getAllChannels().size

init {
    val allChannels = channelDataRepository.getAllChannels()
    val firstChannelIndex = allChannels.indexOfFirst { it.channelCode == "256" }
    channelScrollPosition = firstChannelIndex * (Int.MAX_VALUE / allChannels.size / 2)
    getChannelRing("256")
}
