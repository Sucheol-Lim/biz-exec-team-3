스플래시 진입 흐름

단일 네비게이션 그래프(nav_graph_main.xml)의 시작 지점인 splash에서 home으로 전환합니다. SplashFragment/SplashViewModel이 담당합니다.

기능 개요

앱은 단일 Activity + 단일 네비게이션 그래프 구조입니다. nav_graph_main.xml의 startDestination이 @id/splash이므로 진입 시 항상 SplashFragment가 먼저 뜹니다. 그래프에는 splash → home, home → player(VOD), home → liveTv 액션이 정의되어 있습니다.

SplashViewModel은 init 블록에서 3초(delay(3000)) 뒤 MutableSharedFlow(replay = 1)에 전환 이벤트를 한 번 방출합니다. SplashFragment는 flowWithLifecycle로 이 이벤트를 구독하고, 현재 목적지가 여전히 splash일 때만 action_splash_to_home으로 내비게이션합니다.

splash → home 액션에는 popUpTo="@id/splash" + popUpToInclusive="true"가 걸려 있어, 홈으로 넘어가면서 백스택에서 splash가 제거됩니다. 따라서 홈에서 뒤로가기를 눌러도 스플래시로 돌아오지 않습니다. 화면 전환에는 enter/exit 애니메이션(anim_enter/anim_exit)이 적용됩니다.

replay = 1 의 이유
이벤트를 MutableSharedFlow(replay = 1)로 둬, 화면 회전 등으로 구독이 늦게 시작돼도 마지막 전환 이벤트를 받아 home 전환을 보장합니다. 동시에 "현재 목적지가 splash일 때만 navigate"하는 가드로 중복 전환을 방지합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant NAV as nav_graph_main (startDestination) participant SF as SplashFragment participant SVM as SplashViewModel participant NC as NavController NAV->>SF: splash 진입 (시작 목적지) SF->>SVM: navigationEvent 구독 SVM->>SVM: init { delay(3000) } SVM-->>SF: emit(Unit) (replay=1) SF->>NC: currentDestination == splash 확인 SF->>NC: navigate(action_splash_to_home) Note over NC: popUpTo splash inclusive → 백스택 제거

흐름. 시작 목적지 splash 진입 → ViewModel이 3초 후 이벤트 방출 → 현재 목적지 가드 확인 후 home으로 전환하며 splash를 백스택에서 제거.

클래스 다이어그램

classDiagram class SplashFragment { +onViewCreated() } class SplashViewModel { -MutableSharedFlow~Unit~ _navigationEvent +SharedFlow~Unit~ navigationEvent } class TvFragment~VB~ { <<abstract>> } class NavController { +navigate(actionId) +currentDestination } SplashFragment --|> TvFragment~VB~ SplashFragment --> SplashViewModel : viewModels() SplashFragment --> NavController : action_splash_to_home SplashViewModel ..> SplashFragment : navigationEvent 방출

관계. SplashFragment가 SplashViewModel의 navigationEvent를 구독해 NavController로 home 전환을 수행합니다.

핵심 코드

ui/splash/SplashViewModel.kt — 3초 후 전환 이벤트 방출
class SplashViewModel : ViewModel() {
    private val _navigationEvent = MutableSharedFlow<Unit>(replay = 1)
    val navigationEvent = _navigationEvent.asSharedFlow()

    init {
        viewModelScope.launch {
            delay(3000)
            _navigationEvent.emit(Unit)
        }
    }
}
ui/splash/SplashFragment.kt — 가드 후 home 전환
viewModel.navigationEvent
    .flowWithLifecycle(viewLifecycleOwner.lifecycle, Lifecycle.State.STARTED)
    .onEach { event ->
        if (findNavController().currentDestination?.id == R.id.splash) {
            findNavController().navigate(R.id.action_splash_to_home)
        }
    }
    .launchIn(viewLifecycleOwner.lifecycleScope)
