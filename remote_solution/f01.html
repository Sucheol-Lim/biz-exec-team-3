BLE 입력 장치 제어 (GATT)

본딩된 장치 이름으로 MN3/SMART_RING/DEFAULT를 판별하고, 커스텀 GATT 서비스(F3C5B4E1-…)의 TX/RX 캐릭터리스틱을 찾아 코루틴 작업 큐(CharacteristicWorker)로 쓰기를 직렬화합니다.

기능 개요

이 기능은 외부 입력 장치(Aero Pointer 계열 mn3 리모컨, Smart Air Ring)와 앱을 BLE GATT로 연결하고, 장치의 동작 모드를 제어 신호로 송신하는 핵심 경로입니다. MainActivity가 onStart()에서 BLUETOOTH_CONNECT 권한을 확인한 뒤 BluetoothViewModel.connectRemoteSolution()을 호출하면, 본딩(bonded)된 장치 목록을 순회하며 이름 접두사로 장치 종류를 판별합니다.

연결 성공 후 onServicesDiscovered() 콜백에서 커스텀 서비스 UUID(F3C5B4E1-6B72-4FC1-9E4D-0B4D9B7F5D1E)를 찾고, 그 안의 TX(…E2)/RX(…E3) 캐릭터리스틱을 확보합니다. RX는 setCharacteristicNotification과 CCCD(2902) 활성화로 알림을 켜고, 첫 제어 신호로 ControlMode.INIT을 큐에 넣은 뒤 CharacteristicWorker.start()로 작업 루프를 시작합니다.

BLE 쓰기는 비동기 콜백 기반이라 연속 호출이 충돌하기 쉽습니다. 이를 막기 위해 모든 쓰기/읽기/CCCD 작업을 BluetoothWork 객체로 큐에 적재하고, gattReady 플래그가 켜졌을 때만 하나씩 꺼내 처리하는 단일 코루틴(IO 디스패처) 워커로 직렬화합니다.

설계 포인트
onCharacteristicWrite/onDescriptorWrite/onCharacteristicRead 콜백마다 gattReady.set(true)로 다음 작업을 허용합니다. 즉 "직전 작업의 완료 콜백을 받은 뒤에야 다음 작업을 보낸다"는 흐름 제어로, 안드로이드 BLE 스택의 동시 쓰기 제약을 우회합니다.

관계. BluetoothViewModel이 GATT 핸들과 콜백·워커를 모두 소유합니다. 모든 입출력은 BluetoothWork 종류(TX 쓰기 / RX 읽기 / CCCD)로 큐에 쌓여 CharacteristicWorker 단일 루프에서 직렬 처리됩니다.

핵심 코드

ui/BluetoothViewModel.kt — 본딩 장치 판별 후 GATT 연결
bluetoothAdapter.bondedDevices.also {
    it.forEach { device ->
        val deviceName = device.name
        if (deviceName != null) {
            if (deviceName.startsWith("mn3", ignoreCase = true)) {
                deviceType = Device.MN3
                device.connectGatt(context, false, gattCallback)
                return
            } else if (deviceName.startsWith("Smart Air Ring", ignoreCase = true)) {
                deviceType = Device.SMART_RING
                return
            }
        }
    }
}
ui/BluetoothViewModel.kt — 워커 루프의 쓰기 직렬화 (발췌)
worker = CoroutineScope(Dispatchers.IO).launch {
    gattReady.set(true)
    workerReady.set(true)
    while (true) {
        if (!queue.isEmpty() && gattReady.getAndSet(false)) {  // 완료 콜백 전까지 잠금
            val char = queue.pop()
            if (char is BluetoothWork.TXCharacteristic) {
                gatt.writeCharacteristic(char.characteristic, char.value, char.writeType)
            } else if (char is BluetoothWork.RxCccdEnable) {
                char.characteristic.getDescriptor(UUID.fromString(UUID_CCCD))?.let { d ->
                    gatt.writeDescriptor(d, ENABLE_NOTIFICATION_VALUE)
                }
            }
        }
        delay(10)
    }
}
