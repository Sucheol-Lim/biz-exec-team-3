기능 개요

홈 런처는 두 축으로 구성됩니다. 화면 본문은 세로로 쌓인 콘텐츠 행(rvHome)이고, 각 행은 다시 가로로 스크롤되는 포스터 리스트입니다. 좌측에는 접고 펼 수 있는 네비게이션 레일(navView)이 있습니다. 행 데이터와 메뉴 항목은 모두 HomeDataRepository에 하드코딩되어 있고, HomeViewModel이 이를 중계합니다.

세로 방향은 HomeRowAdapter(행 어댑터)가, 행 내부 가로 방향은 각 행의 PosterItemAdapter가 담당하는 중첩 RecyclerView 구조입니다. 행은 첫 번째 행(FirstRowViewHolder, 배너 포함)과 기본 행(DefaultRowViewHolder)으로 viewType이 나뉩니다. 좌측 메뉴는 MenuAdapter가 펼침/접힘 상태(showLabel)에 따라 라벨 노출을 토글합니다.

포커스 이동은 HomeRowAdapter.onChildKeyDown()이 D-pad 키를 받아 처리합니다. 좌측 끝에서 LEFT를 누르면 onNavBarOpenRequest로 네비 레일이 열리고, 상/하 키로 행을 이동하면서 다음 행의 마지막 선택 위치를 복원합니다. 에어 포인터의 제너릭 모션 스크롤(AXIS_VSCROLL)도 D-pad UP/DOWN 키 이벤트로 변환해 같은 경로로 흘려보냅니다.

데모용 행 구성
HomeViewModel.getVodRows()는 0~4번 행을 두 번 반복해 10개 행을 만들어 스크롤 데모를 풍성하게 보이도록 합니다. 콘텐츠 목록은 실제 스트리밍이 아니라 R.drawable.poster_* 포스터 리소스로 채워진 하드코딩 데이터입니다.

핵심 코드

ui/home/vod/HomeRowAdapter.kt — 행 내 좌우/좌측 끝 네비 열기 (발췌)
} else if (keyEvent.keyCode == KeyEvent.KEYCODE_DPAD_LEFT) {
    val nextItemPosition = getHolderLastSelectedIndex() - 1
    if (nextItemPosition < 0) {
        onNavBarOpenRequest.invoke()          // 좌측 끝 → 네비게이션 레일 열기
    } else {
        getVodItemViewHolder(nextItemPosition)?.select()
        rv.smoothScrollToPosition(nextItemPosition)
    }
    true
} else if (keyEvent.keyCode == KeyEvent.KEYCODE_DPAD_RIGHT) {
    val nextItemPosition = getHolderLastSelectedIndex() + 1
    if (nextItemPosition <= posterItemAdapter.itemCount - 1) {
        getVodItemViewHolder(nextItemPosition)?.select()
        rv.smoothScrollToPosition(nextItemPosition)
    }
    true
}
ui/home/HomeFragment.kt — 에어 포인터 스크롤을 D-pad 키로 변환
binding.rvHome.setOnGenericMotionListener { v, event ->
    if (event.action == MotionEvent.ACTION_SCROLL) {
        val scrollY = event.getAxisValue(MotionEvent.AXIS_VSCROLL)
        if (scrollY > 0) {
            onKeyDown(KeyEvent(KeyEvent.ACTION_DOWN, KeyEvent.KEYCODE_DPAD_UP))
        } else {
            onKeyDown(KeyEvent(KeyEvent.ACTION_DOWN, KeyEvent.KEYCODE_DPAD_DOWN))
        }
    }
    true
}
