기능 개요

화면마다 필요한 입력 방식이 다릅니다. 홈에서는 에어 포인터와 D-pad 네비게이션이, VOD 휠 콘텐츠에서는 휠 스크럽이, Circle to Search 콘텐츠에서는 포인터 드로잉이, 라이브 채널에서는 플라잉 네비만 필요합니다. 이 기능은 화면 컨텍스트에 맞춰 입력 장치의 동작 모드를 전환해, 각 화면에서 의도한 인터랙션만 올라오도록 만듭니다.

모드는 ControlMode enum으로 정의되며, 각 항목은 1바이트 header와 1바이트 controlBits를 가집니다. controlBits는 MASK_POINTER(0x01)·MASK_WHEEL(0x02)·MASK_FLYING_NAVI(0x04)·MASK_FLYING_CLICK(0x08) 비트의 OR 조합입니다. 예를 들어 HOME은 포인터+플라잉 네비+플라잉 클릭, WHEEL은 휠+플라잉 클릭, LIVE_CHANNEL은 플라잉 네비+플라잉 클릭만 켭니다.

각 화면 Fragment는 onResume()에서 bluetoothViewModel.addWorkWrite(ControlMode.XXX)를 호출합니다. ViewModel은 enum에서 꺼낸 byteArrayOf(header, controlBits) 2바이트를 CharacteristicWorker 큐에 넣어 TX 캐릭터리스틱으로 씁니다.

비트 마스크 매핑
INIT header=0xF1, EXIT header=0xF0 (둘 다 controlBits=0x00)으로 시작/종료를 구분합니다. 화면 모드(HOME/WHEEL/CIRCLE_TO_SEARCH/LIVE_CHANNEL)는 모두 header=0x01을 쓰고 controlBits 조합으로만 구분합니다. HOME과 CIRCLE_TO_SEARCH는 동일한 비트 조합(포인터+네비+클릭)을 사용합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant F as 화면 Fragment (Home/Vod/Channel) participant VM as BluetoothViewModel participant CM as ControlMode (enum) participant W as CharacteristicWorker participant DEV as 입력 장치 (Aero Pointer / Ring) F->>VM: onResume() addWorkWrite(ControlMode.HOME) VM->>CM: header / controlBits 조회 CM-->>VM: 0x01, (POINTER or FLYING_NAVI or FLYING_CLICK) VM->>W: addWork(TXCharacteristic[header, controlBits]) W->>DEV: writeCharacteristic 2바이트 송신 Note over DEV: 포인터+네비+클릭 모드로 전환 F->>VM: (VOD 진입) addWorkWrite(ControlMode.WHEEL) VM->>W: addWork(TX[0x01, WHEEL or FLYING_CLICK]) W->>DEV: 휠 모드로 전환

흐름. 화면이 활성화될 때마다 자신의 ControlMode를 ViewModel에 요청하고, ViewModel은 해당 모드의 2바이트를 워커 큐를 통해 장치로 보내 동작 모드를 바꿉니다.

핵심 코드

ui/BluetoothViewModel.kt — ControlMode enum 과 비트 마스크
enum class ControlMode(val header: Byte, val controlBits: Byte) {
    INIT(0xf1.toByte(), 0x00),
    HOME(0x01.toByte(), (MASK_POINTER or MASK_FLYING_NAVI or MASK_FLYING_CLICK).toByte()),
    WHEEL(0x01.toByte(), (MASK_WHEEL or MASK_FLYING_CLICK).toByte()),
    CIRCLE_TO_SEARCH(0x01.toByte(), (MASK_POINTER or MASK_FLYING_NAVI or MASK_FLYING_CLICK).toByte()),
    LIVE_CHANNEL(0x01.toByte(), (MASK_FLYING_NAVI or MASK_FLYING_CLICK).toByte()),
    EXIT(0xf0.toByte(), 0x00)
}

const val MASK_POINTER = 0x01      // pointer
const val MASK_WHEEL = 0x02        // dpad wheel
const val MASK_FLYING_NAVI = 0x04  // dpad left/right/up/down
const val MASK_FLYING_CLICK = 0x08 // dpad_ok
ui/BluetoothViewModel.kt — 모드 요청을 2바이트 작업으로 큐잉
fun addWorkWrite(controlMode: ControlMode) {
    if (!this::gatt.isInitialized) return
    val work = BluetoothWork.TXCharacteristic(
        txCharacteristic,
        byteArrayOf(controlMode.header, controlMode.controlBits),
        BluetoothGattCharacteristic.WRITE_TYPE_DEFAULT
    )
    if (controlMode == ControlMode.INIT || characteristicWorker.workerReady.get()) {
        characteristicWorker.addWork(work)
    } else {
        characteristicWorker.addWorkAfterWorkerStarted(work)
    }
}
