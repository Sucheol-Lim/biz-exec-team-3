VOD 로컬 재생

Media3 ExoPlayer로 asset:///<title>.mp4 형태의 동봉 영상을 재생합니다. 콘텐츠 종류에 따라 휠 탐색 또는 Circle to Search 인터랙션으로 분기됩니다.

기능 개요

VodFragment는 홈에서 전달받은 title 인자로 재생할 콘텐츠를 결정합니다. 재생 URL은 getVodFileUrl(title)이 asset:///<title>.mp4 형태로 만들어 APK에 동봉된 로컬 영상을 가리킵니다. ExoPlayer는 1초 단위 시킹(setSeekBackIncrementMs/setSeekForwardIncrementMs = 1000ms)과 고정 버퍼(DefaultLoadControl)로 구성됩니다.

전달된 title이 휠/Circle 대상 4편(listAllVideos)에 없으면 isRandomPlay = true로 표시하고 그중 하나를 무작위로 재생합니다. 이 경우 일반 포스터로 진입해도 데모용 인터랙션 영상이 자동 재생됩니다.

재생 화면은 onResume()에서 콘텐츠 종류에 따라 입력 모드를 분기합니다. isVodForWheelPlay(title)이면 포인터 아이콘을 숨기고 ControlMode.WHEEL을, isVodForCircleToSearch(title)이면 ControlMode.CIRCLE_TO_SEARCH를 송신합니다. Smart Air Ring 연결 시에는 별도의 더미 클릭 뷰로 재생/일시정지를 처리합니다.

분기 기준 (실제 코드)
휠 대상은 Good Fortune·One Battle After Another(MN3 기준), Circle to Search 대상은 Lilo & Stitch·The Devil Wears Prada 2입니다. Smart Air Ring 연결 시에는 4편 모두 휠 재생으로 취급하고 Circle to Search는 비활성화됩니다.

관계. VodFragment는 공용 TvFragment를 상속해 bluetoothViewModel을 공유하며, getVodFileUrl로 만든 asset URI를 MediaItem으로 감싸 ExoPlayer에 넣습니다.

핵심 코드

ui/util/AssetExt.kt — 로컬 asset 재생 URL 생성
fun getVodFileUrl(title: String?): String {
    return "asset:///${title}.mp4"
}
ui/vod/VodFragment.kt — 플레이어 준비와 모드 분기 (발췌)
mediaItem = MediaItem.Builder().setUri(getVodFileUrl(title)).setMediaId(title).build()
player.addMediaItem(mediaItem)
player.prepare()

// onResume()
if (bluetoothViewModel.getGattDeviceType() == Device.MN3) {
    if (isVodForWheelPlay(title) || isRandomPlay) {
        bluetoothViewModel.addWorkWrite(BluetoothViewModel.ControlMode.WHEEL)
    } else if (isVodForCircleToSearch(title)) {
        bluetoothViewModel.addWorkWrite(BluetoothViewModel.ControlMode.CIRCLE_TO_SEARCH)
    }
}
