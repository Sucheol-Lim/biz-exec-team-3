GIF 썸네일 로딩

Coil3의 AnimatedImageDecoder로 라이브 채널/튜토리얼 영역의 애니메이션 GIF를 디코딩·표시합니다. ImageLoader.Builder에 디코더 팩토리를 등록해 load()로 재생합니다.

기능 개요

일반 정지 이미지는 Coil3의 기본 load() 확장으로 충분하지만, 애니메이션 GIF는 디코더를 명시적으로 등록해야 재생됩니다. 이 앱은 ImageLoader.Builder(context).components { add(AnimatedImageDecoder.Factory()) }.build()로 GIF 디코더를 포함한 전용 ImageLoader를 만들어, ImageView.load(resId, imageLoader)에 넘겨 GIF를 디코딩·재생합니다.

대표 사용처는 휠/링 인터랙션 튜토리얼(WheelTutorialView)입니다. 휠 모드면 tutorial_wheel_wheel_anim, 링 모드면 tutorial_wheel_ring_anim GIF를 로드하고, 화살표 GIF는 PorterDuffColorFilter로 색을 입혀 함께 재생합니다. 디코딩된 결과가 ScaleDrawable(내부에 AnimatedImageDrawable)이면 Animatable.start()로 재생을 시작하고, AnimationCallback.onAnimationEnd에서 모든 화살표 애니메이션이 끝났을 때 1초 후 다시 시작하도록 동기화합니다.

라이브 채널 화면(ChannelFragment)도 같은 디코더를 임포트하며, 채널 튜토리얼 이미지(tutorial_live_mn3/tutorial_live_wheel) 로딩에 활용합니다. Coil3 GIF 의존성은 버전 카탈로그에 coil-gif로 선언되어 있습니다.

근거 보정 — 카드 설명과 실제 코드 차이
매니페스트 카드는 "라이브 채널 썸네일의 GIF"라고 표현하지만, 실제 코드에서 채널/프로그램 썸네일(thumbnailSrc)은 정적 PNG 드로어블(channel_img_*)을 setImageResource로 표시합니다. Coil3 AnimatedImageDecoder가 실제로 쓰이는 곳은 WheelTutorialView의 휠/링/화살표 GIF와 ChannelFragment의 라이브 튜토리얼 이미지입니다. 본 페이지는 실제 코드 사용처를 기준으로 작성했습니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant V as WheelTutorialView / ChannelFragment participant IL as ImageLoader.Builder participant DEC as AnimatedImageDecoder participant IV as ImageView (load) participant DR as AnimatedImageDrawable V->>IL: components { add(AnimatedImageDecoder.Factory()) }.build() IL-->>V: ImageLoader V->>IV: load(gifResId, imageLoader) IV->>DEC: GIF 프레임 디코딩 DEC-->>IV: ScaleDrawable(AnimatedImageDrawable) IV->>DR: Animatable.start() (재생) DR-->>V: onAnimationEnd → 1초 후 재시작 동기화

흐름. GIF 디코더를 등록한 ImageLoader로 GIF를 로드 → 디코딩된 AnimatedImageDrawable을 Animatable.start()로 재생 → 종료 콜백에서 반복 재생을 동기화.

클래스 다이어그램

관계. 두 사용처 모두 AnimatedImageDecoder.Factory()를 등록한 ImageLoader를 만들어 GIF를 로드하고, WheelTutorialView는 디코딩된 AnimatedImageDrawable의 재생/반복을 직접 제어합니다.

핵심 코드

ui/tutorial/WheelTutorialView.kt — GIF 디코더 포함 ImageLoader 로 로드
val imageLoader = ImageLoader.Builder(context)
    .components {
        add(AnimatedImageDecoder.Factory())
    }
    .build()

if (isRing) {
    binding.ivWheelTutorialRing.load(R.drawable.tutorial_wheel_ring_anim, imageLoader)
} else {
    binding.ivWheelTutorialWheel.load(R.drawable.tutorial_wheel_wheel_anim, imageLoader)
}
ui/tutorial/WheelTutorialView.kt — 디코딩 결과 재생/반복 동기화 (발췌)
target { drawable ->
    val drawable = drawable.asDrawable(context.resources)
    setImageDrawable(drawable)
    if (drawable is ScaleDrawable) {
        val animatable = drawable as Animatable
        val child = drawable.child
        if (child is AnimatedImageDrawable) {
            child.registerAnimationCallback(object : Animatable2.AnimationCallback() {
                override fun onAnimationEnd(d: Drawable?) {
                    // 모든 화살표 애니메이션이 끝나면 1초 후 재시작
                    jobs[id] = findViewTreeLifecycleOwner()?.lifecycleScope?.launch {
                        delay(1000); animatable.start()
                    }
                }
            })
        }
        animatable.start()
    }
}
