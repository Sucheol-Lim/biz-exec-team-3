기능 개요

TV에서는 포커스가 화면 흐름을 좌우하므로, 안드로이드 기본 포커스 검색에 맡기지 않고 RSLinearLayoutManager가 포커스 이동을 직접 보조합니다. onInterceptFocusSearch()에서 현재 포커스 위치와 방향으로 다음 대상 위치를 계산하고, 방향이 리스트 축과 어긋나거나(isOutOfDirection) 범위를 벗어나면(isOutOfRange) 콜백 훅(onFocusRightNotOrientated 등)을 부르며 포커스가 튀지 않게 막습니다. 정상 이동이면 smoothScrollToPosition으로 대상 위치를 부드럽게 스냅합니다.

focusedCenter = true로 두면 calculateDtToFit()이 선택 아이템을 박스 중앙에 맞춰, VOD 프레임 리스트처럼 가운데 정렬이 필요한 곳에서 쓰입니다. snapPreference로 스냅 기준(SNAP_TO_START/ANY)도 화면별로 다르게 지정합니다.

입력 안정화의 핵심은 키 디스패치입니다. TvActivity.dispatchKeyEvent()는 deviceId < 0(가상/합성 입력)인 D-pad 방향키를 그대로 소비해 흘려보냅니다. 그 외 키는 최상단 TvFragment로 라우팅하여, 롱프레스면 onKeyLongPressed, ACTION_DOWN이면 onKeyDown, ACTION_UP이면 onKeyUp으로 분기합니다. 입력 장치가 만들어 내는 부가 합성 이벤트가 화면 포커스를 흔드는 것을 차단하려는 처리입니다.

deviceId < 0 소비의 의미
음수 deviceId는 실제 물리 입력이 아닌 합성/가상 입력을 뜻합니다. Aero Pointer/Ring 모드 전환 과정에서 발생할 수 있는 합성 D-pad 방향키를 true로 소비해, 의도치 않은 이중 포커스 이동을 막습니다.

흐름. Activity가 키를 받아 합성 방향키는 소비하고, 일반 입력은 최상단 Fragment로 라우팅하며, 포커스 이동은 커스텀 레이아웃 매니저가 스냅으로 보정합니다.

핵심 코드

ui/base/TvActivity.kt — 음수 deviceId 방향키 소비 후 라우팅
override fun dispatchKeyEvent(event: KeyEvent): Boolean {
    if (event.deviceId < 0 &&
        (event.keyCode == KeyEvent.KEYCODE_DPAD_UP || event.keyCode == KeyEvent.KEYCODE_DPAD_DOWN ||
         event.keyCode == KeyEvent.KEYCODE_DPAD_LEFT || event.keyCode == KeyEvent.KEYCODE_DPAD_RIGHT)) {
        return true                                  // 합성 방향키 소비
    }
    when (val fragment = navigator.getTopFragment()) {
        is TvFragment<*> -> {
            if (event.action == KeyEvent.ACTION_DOWN) {
                if (event.isLongPress) fragment.onKeyLongPressed(event) else fragment.onKeyDown(event)
            } else if (event.action == KeyEvent.ACTION_UP) {
                fragment.onKeyUp(event)
            }
            return true
        }
    }
    return super.dispatchKeyEvent(event)
}
ui/common/RSLinearLayoutManager.kt — 포커스 검색 가로채기 후 스냅
override fun onInterceptFocusSearch(focused: View, direction: Int): View? {
    if (_isScrolling) return focused
    _currentPosition = getPosition(focused)
    val targetPosition = getTargetPosition(direction)
    if (isOutOfDirection(direction)) return focused.also { handleOutOfDirection(direction) }
    if (isOutOfRange(targetPosition)) return focused.also { handleOutOfRange(direction) }
    return super.onInterceptFocusSearch(focused, direction).also {
        doScrollTargetPosition(targetPosition, direction)   // smoothScrollToPosition 스냅
    }
}
