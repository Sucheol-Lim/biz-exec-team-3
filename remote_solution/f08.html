캡처 영역 비트맵 추출

루트 뷰와 비디오 TextureView 표면을 함께 그려 캡처한 뒤 200x200 썸네일을 만들고 CaptureResult.SUCCESS로 콜백합니다. 성공 시 상품 상세 오버레이(브랜드/가격 등 하드코딩)를 띄웁니다.

기능 개요

원 판정·모핑이 끝나면 captureCircleBitmapAndNotify()가 그려진 원의 내부 영역을 캡처합니다. 일반적인 View.draw()만으로는 ExoPlayer가 사용하는 TextureView 영상 표면이 함께 캡처되지 않습니다. 그래서 먼저 루트 뷰를 비트맵 캔버스에 그린 뒤, PlayerView의 videoSurfaceView가 TextureView면 getBitmap()으로 영상 프레임을 따로 받아 화면 좌표 오프셋만큼 이동시켜 같은 캔버스 위에 합성합니다.

캡처 직전에는 CircleInkView 자신을 INVISIBLE로 잠깐 숨겨, 그려둔 원/획이 캡처 결과에 포함되지 않게 합니다. 합성된 풀 비트맵에서 원의 바운딩(cx±r, cy±r)을 정사각형으로 잘라내고, 이를 200x200 썸네일로 다운스케일합니다.

캡처 후 약 1초간 원 바깥을 어둡게 처리한 검색 오버레이(showSearchOverlay)를 보여 준 다음, 썸네일이 있으면 onCircleCaptured(CaptureResult.SUCCESS(thumb)), 없으면 ERROR로 콜백합니다. VodFragment는 SUCCESS를 받으면 makeCircleDetailView()로 상품 상세 오버레이를 채우고 노출합니다.

데모용 상세 데이터
검색 결과 상세(브랜드명·상품명·가격·색상 등)는 인식 결과가 아니라 타이틀별로 하드코딩되어 있습니다. 예로 The Devil Wears Prada 2는 "Valentino Garavani / Patent Rockstud Caged Pump", Lilo & Stitch는 "Disney / Stitch Big Feet Plush"를 표시합니다. 캡처된 200x200 썸네일은 검색 인식에 사용되지 않고 캡처 동작 자체를 시연합니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant CV as CircleInkView participant ROOT as rootView participant PV as PlayerView (TextureView) participant VF as VodFragment CV->>CV: this.visibility = INVISIBLE (원/획 제외) CV->>ROOT: root.draw(canvas) (UI 합성) CV->>PV: videoSurfaceView.getBitmap() (영상 프레임) PV-->>CV: tvBitmap CV->>CV: canvas.drawBitmap(tvBitmap, dx, dy) 합성 CV->>CV: 원 바운딩 정사각 crop → 200x200 thumb CV->>CV: showSearchOverlay = true (1초) CV->>VF: onCircleCaptured(SUCCESS(thumb)) VF->>VF: makeCircleDetailView() + 상세 오버레이 VISIBLE

흐름. 루트 UI와 영상 텍스처를 한 캔버스에 합성 → 원 영역을 정사각형으로 잘라 200x200 썸네일 생성 → 1초 검색 오버레이 후 SUCCESS 콜백 → 상세 오버레이 노출.

관계. CircleInkView가 PlayerView의 TextureView 비트맵을 합성해 캡처하고, 결과 SUCCESS(thumb)를 받은 VodFragment가 상품 상세 오버레이를 띄웁니다.

핵심 코드

ui/vod/CircleInkView.kt — 루트 + TextureView 합성 후 썸네일 (발췌)
this.visibility = View.INVISIBLE            // 그린 원/획 제외
val full = Bitmap.createBitmap(root.width, root.height, Bitmap.Config.ARGB_8888)
val canvas = Canvas(full)
root.draw(canvas)

val playerView = root.findViewById<View>(R.id.playerView)
if (playerView is PlayerView) {
    val surfaceView = playerView.videoSurfaceView
    if (surfaceView is TextureView) {
        val tvBitmap = surfaceView.getBitmap()
        // 화면 좌표 오프셋만큼 이동시켜 영상 프레임 합성
        canvas.drawBitmap(tvBitmap, dx, dy, null)
    }
}
val result = Bitmap.createBitmap(full, safeLeft, safeTop, size, size)
val thumb = Bitmap.createScaledBitmap(result, 200, 200, true)
ui/vod/CircleInkView.kt — 1초 오버레이 후 결과 콜백
postDelayed({
    val t = pendingThumb
    showSearchOverlay = false
    this.visibility = View.INVISIBLE
    if (t != null) {
        onCircleCaptured?.invoke(CaptureResult.SUCCESS(t))
    } else {
        onCircleCaptured?.invoke(CaptureResult.ERROR())
    }
}, 1000L)
