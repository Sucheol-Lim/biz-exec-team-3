인터랙션 튜토리얼 오버레이

기능 개요

차세대 입력 장치의 인터랙션은 처음 보면 직관적이지 않으므로, 각 화면에서 사용법을 애니메이션으로 안내하는 튜토리얼 오버레이를 제공합니다. 세 가지가 있습니다. FavoriteTutorialView(드래그 즐겨찾기), CircleTutorialView(원 그리기), WheelTutorialView(휠/링 회전)입니다. 모두 FrameLayout을 상속한 커스텀 뷰로, 각자 startAnimation()/stopAnimation()을 가집니다.

즐겨찾기 튜토리얼은 HomeFragment.onViewCreated()에서 "최초 진입(isFirstLaunch)이고 장치가 MN3"일 때, 그리고 정적 플래그 FavoriteTutorialView.isShown이 false일 때만 한 번 노출됩니다. 포스터를 잡아 하단으로 옮기는 동작을 코루틴 기반 select → move → unselect 단계 애니메이션으로 반복 재생합니다.

VOD 화면에서는 VodFragment.initTutorial()이 콘텐츠/장치 종류로 분기합니다. Circle to Search 대상이면 CircleTutorialView가 미리 정의된 100여 개 linePoints를 따라 원 그리는 벡터를 이동시키고, 휠 대상이면 WheelTutorialView가 휠 또는 링 GIF를 재생합니다. 튜토리얼이 떠 있을 때 키 입력/클릭이 오면 stopTutorial()로 닫고 입력을 소비합니다.

노출 조건 요약
장치가 DEFAULT(미연결)면 VOD 튜토리얼은 initTutorial() 초입에서 그대로 반환되어 표시되지 않습니다. 즐겨찾기 튜토리얼은 MN3 연결 + 홈 최초 진입에서만, 휠 튜토리얼은 링/휠 구분(isRing)에 따라 다른 GIF로 표시됩니다.

흐름. 장치/콘텐츠 종류를 확인해 알맞은 튜토리얼 오버레이를 띄우고 애니메이션을 반복하며, 사용자 입력이 오면 닫습니다.

핵심 코드

ui/home/HomeFragment.kt — MN3 최초 진입 시 즐겨찾기 튜토리얼
override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
    super.onViewCreated(view, savedState)
    if (isFirstLaunch && bluetoothViewModel.getGattDeviceType() == Device.MN3) {
        startTutorial()
        isFirstLaunch = false
    }
}

private fun startTutorial() {
    if (!FavoriteTutorialView.isShown) {
        FavoriteTutorialView.isShown = true
        with(binding.favoriteTutorial) {
            isVisible = true
            startAnimation()
        }
    }
}
ui/vod/VodFragment.kt — 콘텐츠/장치별 튜토리얼 분기
fun initTutorial() {
    if (bluetoothViewModel.getGattDeviceType() == Device.DEFAULT) return
    if (isVodForCircleToSearch(title) && !isRandomPlay) {
        startCircleTutorial()
    }
    if (isVodForWheelPlay(title) || isRandomPlay) {
        startWheelTutorial(isRing = bluetoothViewModel.getGattDeviceType() == Device.SMART_RING)
    }
}
