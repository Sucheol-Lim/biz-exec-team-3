부팅 · 페일세이프 복구

BootScreen/BootViewModel은 일반 부팅 화면이 아니라, 페일세이프(FailSafe) 에러 표시와 복구 다운로드 진행률 표시 두 모드를 하나의 화면으로 처리합니다.

기능 개요

BootScreen.onViewCreated()는 진입 Bundle의 CountOn 플래그로 두 모드를 가릅니다. true면 페일세이프 레이어(llFailSafeLayer)를 보여주고 BootViewModel.observeErrorCode()로 에러 코드(130-99-020/130-99-030/기타)에 대응하는 안내 문구를 표시하며, observeCount()로 재시도·재부팅까지 남은 카운트를 갱신합니다. CountOn이 아니고 Message가 있으면 일반 레이어(llNormalLayer)로 전환해 observeDownloadProgress()로 복구 이미지 다운로드 진행률(%)을 표시합니다.

BootViewModel은 세 스트림(getFailSafeErrorCode·getFailSafeCount·getDownloadProgress) 전부를 StorageRepository에서 RxJava3 Observable로 구독하고, AndroidSchedulers.mainThread()로 관찰해 UI 스레드에서 바로 갱신합니다. 화면 소멸 시 dispose()가 세 Disposable을 모두 해제합니다.

페일세이프란
단말 소프트웨어가 손상되거나 부팅에 실패했을 때 진입하는 복구 모드로, 사용자에게 에러 코드와 재시도 횟수를 보여주거나(CountOn) 복구 이미지를 내려받는 진행률을 보여줍니다(Message). ui/popup/FailSafeRecoveryPopup과 같은 맥락의 복구 경로입니다.

관계. BootScreen/BootViewModel은 앱 공통 베이스(ATVScreen/ATVViewModel)를 상속하고, 실제 데이터는 StorageRepository 하나에서 세 종류의 스트림으로 가져옵니다.

핵심 코드

ui/boot/BootScreen.kt — CountOn 플래그로 두 모드 분기
val countOn = bundle.getBoolean("CountOn")
if (countOn == true) {
    binding.llFailSafeLayer.isVisible = true
    viewModel.observeErrorCode { code ->
        binding.tvFsMessage.text = when (code) {
            "130-99-020" -> getString(R.string.FAIL_SAFE_ERROR_020)
            "130-99-030" -> getString(R.string.FAIL_SAFE_ERROR_030)
            else -> getString(R.string.FAIL_SAFE_ERROR_010)
        }
    }
    viewModel.observeCount { count -> binding.tvFsCount.text = count.toString() }
} else {
    val message = bundle.getString("Message")
    if (!message.isNullOrBlank()) {
        binding.llNormalLayer.isVisible = true
        viewModel.observeDownloadProgress { progress ->
            binding.tvProgress.text = progress.toInt().toString() + "%"
        }
    }
}
