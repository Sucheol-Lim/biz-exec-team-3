부팅 · 페일세이프 복구

BootScreen은 com.altimedia.nav.app.AppScreenFragment로 이관되어 타입이 있는 Args(countOn, message)로 진입 인자를 받습니다. 다운로드 진행률 표시 모드는 이번 정리 구간에서 제거되어, 지금은 페일세이프 에러 표시와 일반 안내 문구 두 경로만 남았습니다.

기능 개요

BootScreen이 f01에서 다룬 nav 엔진 이관 대상에 포함되면서, 진입 방식이 느슨한 Bundle.getBoolean("CountOn")/getString("Message")에서 DestinationArgs를 구현하는 타입 있는 Args(countOn, message)로 바뀌었습니다. onArgs(args)에서 캐스팅에 실패하면 즉시 error()로 죽어 배선 오류를 조기에 드러냅니다. args.countOn이 true면 페일세이프 레이어(llFailSafeLayer)를 보여주고 BootViewModel.observeErrorCode()로 에러 코드(130-99-020/130-99-030/기타)에 대응하는 안내 문구를 표시하며, observeCount()로 재시도·재부팅까지 남은 카운트를 갱신합니다. 그렇지 않고 args.message가 비어 있지 않으면 일반 레이어(llNormalLayer)에 그 문구를 그대로 표시합니다.

BootViewModel은 StorageRepository에서 getFailSafeCount()·getFailSafeErrorCode() 두 스트림만 RxJava3 Observable로 구독합니다. 이전에 있던 다운로드 진행률(getDownloadProgress) 스트림과 관련 Disposable은 이번 레거시 정리(OTA 테스트 플래그·팩토리 리셋 경로 제거)를 거치며 사라졌습니다 — 복구 이미지 다운로드 진행률 UI는 더 이상 이 화면이 담당하지 않습니다. BootViewModel 자신은 아직 신형 nav 기반 ViewModel이 아니라 레거시 ATVViewModel을 그대로 상속하고 있어, 화면(View)만 먼저 이관되고 ViewModel은 뒤따라가는 과도기 상태입니다.

페일세이프란
단말 소프트웨어가 손상되거나 부팅에 실패했을 때 진입하는 복구 모드로, 사용자에게 에러 코드와 재시도 횟수를 보여줍니다(countOn). ui/popup/FailSafeRecoveryPopup과 같은 맥락의 복구 경로이며, 그 팝업 역시 같은 시기에 nav 엔진으로 이관됐습니다(→ f08 참고).

흐름. 진입은 이제 Navigator.activate로 타입 있는 Args를 넘겨받아 두 표시 모드로 갈리고, 페일세이프 모드만 StorageRepository의 Rx 스트림을 구독해 실시간으로 텍스트를 갱신합니다.

관계. BootScreen은 신형 AppScreenFragment(nav.app, f01 참고)를 상속해 타입 있는 Args로 진입하지만, BootViewModel은 아직 레거시 ATVViewModel을 상속한 채 StorageRepository에서 두 스트림(다운로드 진행률 제외)만 구독합니다.

핵심 코드

ui/boot/BootScreen.kt — 타입 있는 Args로 두 모드 분기
class Args(
    val countOn: Boolean = false,
    val message: String? = null,
) : DestinationArgs

private lateinit var args: Args

override suspend fun onArgs(args: DestinationArgs) {
    this.args = args as? Args ?: error("BootScreen 은 Args 가 필요하다")
}

override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
    super.onViewCreated(view, savedInstanceState)
    if (args.countOn) {
        binding.llFailSafeLayer.isVisible = true
        binding.llNormalLayer.isVisible = false
        viewModel.observeErrorCode { code ->
            binding.tvFsMessage.text = when (code) {
                "130-99-020" -> requireContext().resources.getString(R.string.FAIL_SAFE_ERROR_020)
                "130-99-030" -> requireContext().resources.getString(R.string.FAIL_SAFE_ERROR_030)
                else -> requireContext().resources.getString(R.string.FAIL_SAFE_ERROR_010)
            }
        }
        viewModel.observeCount { count -> binding.tvFsCount.text = count.toString() }
    } else {
        binding.llFailSafeLayer.isVisible = false
        val message = args.message
        if (!message.isNullOrBlank()) {
            binding.llNormalLayer.isVisible = true
            binding.tvNormalMessage.text = message
        } else {
            binding.llNormalLayer.isVisible = false
        }
    }
}
