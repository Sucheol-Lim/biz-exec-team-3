기능 개요

ui/setting은 메뉴 목록(SettingScreen/SettingViewModel, adapter/SettingMenuAdapter)에서 각 항목으로 진입하는 개별 View/ViewModel 쌍을 다수 보유합니다 — CAS 정보(CasInfoView/CasInfoModel), 시청등급(ParentalControlView/ParentalControlViewModel), 즐겨찾기·잠금 채널(FavoriteLockChannelView), 녹화/예약(MyRecordsView/MyRemindersView), 대여·구매 이력(RentalPurchaseHistoryView), Wifi 신호(WifiPowerLevelView), 공장 초기화(FactoryResetView) 등입니다. 각 ViewModel은 SettingBaseViewModel을 상속해 공통 로딩·에러 처리를 물려받습니다.

예를 들어 ParentalControlViewModel은 ModifyProfileUseCase로 프로필의 limitLevel(시청등급 제한)을 변경하고, 성공 시 4개 등급 목록(Rating)에서 선택된 항목만 isSelected를 갱신해 LiveData로 다시 내보냅니다. 데이터는 안드로이드 LiveData(설정 도메인)와 RxJava3(재생·라이브 도메인)가 화면 성격에 따라 혼용됩니다.

설계 포인트 — 목록 갱신은 불변 리스트 재구성
ParentalControlViewModel.setRatingData()는 기존 리스트를 직접 변경하지 않고, 선택 여부만 다시 계산한 새 ArrayList를 만들어 postValue합니다. LiveData 관찰자가 참조 동일성으로 변경을 놓치는 문제를 피하기 위한 흔한 패턴입니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant UI as ParentalControlView participant VM as ParentalControlViewModel participant UC as ModifyProfileUseCase participant SRV as 백엔드 (SI/impl-*) UI->>VM: setRatingData(rating, profile) VM->>VM: loading.postValue(true) VM->>UC: invoke(profileCode, photo, nickName, limitLevel, funcSwitch) UC->>SRV: 프로필 갱신 요청 SRV-->>UC: 성공/실패 alt 성공 UC-->>VM: onSuccess VM->>VM: 등급 목록 재구성(isSelected 갱신) VM->>VM: _ratingData.postValue(newList) VM->>VM: loading.postValue(false) else 실패 UC-->>VM: onError VM->>VM: loading.postValue(false) + 에러 처리 end VM-->>UI: LiveData 관찰 → 목록/로딩 UI 갱신

흐름. 설정 변경은 UseCase를 거쳐 백엔드에 반영되고, 성공 시 화면이 보여줄 목록 전체를 새로 구성해 LiveData로 통보합니다.

핵심 코드

ui/setting/view/ParentalControlViewModel.kt — 불변 리스트 재구성으로 선택 갱신
fun setRatingData(rating: Rating, profile: UserProfile) {
    loading.postValue(true)
    modifyProfileUseCase(
        profileCode = profile.profileCode, photo = profile.photo, nickName = profile.nickName,
        limitLevel = rating.limitLevel, funcSwitch = profile.funcSwitch,
    ).subscribe(
        {
            val list = ArrayList<Rating>(4)
            _ratingData.value?.map {
                list.add(Rating(it.id, it.title, it.limitLevel, it.id == rating.id))
            }
            _ratingData.postValue(list)
            loading.postValue(false)
        },
        { /* onError - 로딩 해제 + 에러 처리 */ },
    )
}
