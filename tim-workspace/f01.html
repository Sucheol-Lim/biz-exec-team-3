기능 개요

이 엔진은 Fragment 어휘를 전혀 모릅니다. Destination 인터페이스와 DestinationSpec(id·plane·factory 선언)만 다루고, 실제 화면 생성·배치·제거는 DestinationHost(어댑터)에 위임합니다. 화면이 놓이는 z-order 층은 Plane으로 앱이 직접 선언하므로, 팝업 위에 토스트를 얹거나 상시 채널 배너를 별도 층에 두는 TV 앱 특유의 요구를 엔진 수정 없이 수용합니다.

모든 변경 연산(activate/deactivate/closePlane/closeAll)은 suspend이며 Mutex로 직렬화됩니다. 완료를 콜백으로 넘기지 않으므로 "닫고 나서 열기" 같은 흐름이 중첩되지 않고, 닫기·열기가 겹쳐 실행되며 포커스 처리가 어긋나는 경쟁 상태를 원천 차단합니다. 예외는 항상 배선 오류(미등록 Plane 사용, Plane.depth 중복 등)일 때만 던지고, 사용자가 만들 수 있는 상태(이미 닫힌 목적지를 다시 닫기 등)는 조용히 무시합니다.

설계 포인트 — 뷰를 직접 만지지 않는다
Navigator는 활성/비활성 전환을 Destination.onActiveChanged() 콜백으로 통보만 하고, 실제 포커스·표시 적용은 각 목적지가 스스로 합니다. 매니저가 외부에서 뷰를 직접 조작하면 앱이 별도 트랜잭션을 걸었을 때 되돌릴 주체가 없어지기 때문입니다.

흐름. activate는 락 안에서 동일 id 정리 → root 정리 → 인스턴스화 → 인자 검증(onArgs) → 포커스 차단 통보 → 실제 배치(place) → 스택 push 순서로 진행됩니다. place가 완료된 뒤에야 반환되므로 호출부는 "화면이 실제로 떴다"를 신뢰하고 다음 코드를 이어갈 수 있습니다.

관계. Navigator는 DestinationStacks(내부 저장)와 KeyRouter(키 라우팅)를 소유하고, 실제 화면 생성·배치는 DestinationHost 구현체(Fragment 어댑터)에 위임합니다. 화면 자신은 DestinationSpec을 companion object로 소유해 컴파일 타임에 검사되는 참조로 activate를 호출합니다.

핵심 코드

nav/engine/Navigator.kt — activate: 동일 id 정리 → root 정리 → 배치
private suspend fun doActivate(spec: DestinationSpec, args: DestinationArgs): Destination {
    require(planes.any { it.depth == spec.plane.depth }) {
        "unknown plane ${spec.plane}. declared planes: ${planes.map { it.name }}"
    }
    // 같은 id 가 이미 있으면 닫고 다시 만든다.
    stacks.find(spec.id)?.let { doClose(it) }

    // root 면 아래 스택은 무의미하다.
    if (spec.root) {
        stacks.descending().filterNot { it.spec.persistent }.forEach { doClose(it) }
    }

    val previousTop = stacks.topWhere { !it.spec.transient }
    val destination = host.instantiate(spec, args)
    destination.onArgs(args)                       // 인자 검증은 스택에 올리기 전에

    applyActivation(newDestination = destination, previousTop = previousTop)  // 포커스 차단은 place 보다 먼저
    host.place(destination, spec.plane)
    stacks.push(destination)
    return destination
}
nav/engine/DestinationSpec.kt — 화면이 스스로 스펙을 소유
class DetailFragment : DestinationFragment() {
    class Args(val programCode: String) : DestinationArgs
    companion object {
        val Spec = DestinationSpec(
            id = DestinationId("Detail"),
            plane = AppPlanes.Screen,
            factory = { DetailFragment() },
        )
    }
}
