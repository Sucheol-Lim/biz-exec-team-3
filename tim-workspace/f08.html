기능 개요

"BlurPopup과 BaseAnimationPopup을 삭제한다"는 커밋을 기점으로, 팝업 전용 클래스 계층(ATVPopup·BaseAnimationPopup)이 사라지고 화면과 같은 AppFragment<VB> 베이스를 씁니다. 각 팝업은 companion object에 DestinationSpec을 선언해 plane(대개 AppPlanes.Popup, 반드시 응답해야 하는 FailSafeRecoveryPopup은 AppPlanes.System)과 keyMonopoly(키 독점 여부)를 명시합니다. 콜백도 ConsumeCallback<Int> 같은 전용 인터페이스 대신 Args 데이터 클래스가 들고 있는 평범한 코틀린 람다(onButtonClick: ((Int) -> Unit)?)로 바뀌었습니다 — Activity 스코프 안에서 직접 넘기므로 Bundle에 담을 Parcelable일 필요가 없기 때문입니다.

도메인별로 bundle/·coupon/·purchase/·applist/·play/(프로모션·구매·재생 관련), FailSafeRecoveryPopup·GlobalErrorPopup·ProvisionErrorPopup(장애·에러), CampaignPopup·CommonPopup·MesNotificationPopup·MesWebViewPopup·PasswordPopup·LoadingPopup·ToastPopup 등으로 ui/popup 아래 26개 팝업이 분류됩니다. 과거 ott/ 하위의 로그인·가입·QR결제 팝업들과 OtaUpdatePopup은 이번 구간에서 사라졌고, 로그인 플로우는 새 홈 UI(f01)의 ui/home/subview/profile/popup(ProfileLoginPopup·ProfileAvatarSelectPopup 등)으로 대체됐습니다.

설계 포인트 — keyMonopoly로 키 독점
FailSafeRecoveryPopup.Spec은 keyMonopoly = true로 키 입력을 독점합니다(f01의 DestinationSpec.keyMonopoly와 동일한 필드). 페일세이프처럼 사용자가 반드시 응답해야 하는 팝업에서, 아래 화면이 리모컨 키를 가로채지 못하게 합니다. 소스 주석에는 "구 keyMonopoly = true"라고 남아 있어, 레거시 필드가 이름 그대로 새 엔진에 옮겨왔음을 보여줍니다.

흐름. 팝업은 Navigator.activate로 Destination이 되어 뜨고, 버튼 포커스 이동과 OK 확정만 자체 처리하며, 실제 "무엇을 할지"는 Args에 담긴 람다를 통해 호출부로 위임합니다. 닫기는 layerManager.deactivateLayer(this) 대신 closeSelf()(nav.app.AppFragment) 한 줄입니다.

관계. 삭제된 ATVPopup/BaseAnimationPopup 대신, 모든 팝업이 화면과 동일한 AppFragment를 상속하고 DestinationSpec으로 자신의 평면·키 독점 여부를 선언하는 평면적 구조가 됐습니다. 로그인 계열 팝업은 ott/가 아니라 ui/home/subview/profile/popup으로 옮겨졌습니다.

핵심 코드

ui/popup/FailSafeRecoveryPopup.kt — AppFragment 기반, onKey + closeSelf
class FailSafeRecoveryPopup : AppFragment<PopupFailSafeRecoveryBinding>() {

    class Args(val onButtonClick: ((Int) -> Unit)? = null) : DestinationArgs

    private lateinit var args: Args
    override suspend fun onArgs(args: DestinationArgs) {
        this.args = args as? Args ?: error("FailSafeRecoveryPopup 은 Args 가 필요하다")
    }

    override fun onKey(stroke: KeyStroke): Boolean {
        if (stroke.action != KeyAction.DOWN) return false
        when (stroke.code) {
            ATVKeyCode.KEY_RIGHT, ATVKeyCode.KEY_LEFT -> when (lastFocusView) {
                binding.btnOk -> binding.btnCancel.requestFocus()
                binding.btnCancel -> binding.btnOk.requestFocus()
            }
            ATVKeyCode.KEY_EXIT, ATVKeyCode.KEY_PREV -> closeSelf()
            ATVKeyCode.KEY_OK -> {
                if (binding.btnOk.hasFocus()) { closeSelf(); onButtonClick?.invoke(0) }
                else if (binding.btnCancel.hasFocus()) { closeSelf(); onButtonClick?.invoke(1) }
                else closeSelf()
            }
        }
        return true
    }

    companion object {
        val Spec = DestinationSpec(
            id = DestinationId("FailSafeRecoveryPopup"),
            plane = AppPlanes.System,
            factory = { FailSafeRecoveryPopup() },
            keyMonopoly = true,   // 구 keyMonopoly = true
        )
    }
}
