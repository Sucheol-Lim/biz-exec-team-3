기능 개요

PlayerAdapter 인터페이스는 play/stop/pause/resume/seek/setSpeed 같은 제어 함수와, state·position·duration·videoTracks/audioTracks/subtitleTracks를 전부 RxJava3 Observable로 노출하는 상태 스트림으로 구성됩니다. 재생 상태는 PlayerState 열거형(ON_READY·BUFFERING·PLAYING·PAUSED·STOPPED·FINISHED·RELEASED·ON_ERROR)으로 정규화되어, 상위 핸들러(f03)는 ExoPlayer 고유 상태 코드를 몰라도 PlayerState.isNotPlaying() 같은 헬퍼로 판단할 수 있습니다.

실제 구현체 ExoPlayerAdapter는 PlayerViewLifecycleObserver·PlayerOwnerLifecycleObserver·PlayerViewLayoutChangeObserver 세 옵저버 인터페이스도 함께 구현해, 화면/생명주기/레이아웃 변경에 반응합니다. exoplayer/ads 패키지의 ImaAdSupport/ImaAdSupportImpl이 Google IMA SDK 기반 광고 삽입을 별도 관심사로 분리해 붙습니다.

앱 쪽 어댑터는 또 한 겹 감싼다
앱(app-tv-android)은 player-kt의 PlayerAdapter를 직접 쓰지 않고, :player:core(VodPlayerView)·:player:impl-mock(MockVodPlayerAdapter)·:player:impl-tt4k(TTExoPlayerAdapter)로 한 번 더 감쌉니다. TIM 백엔드가 준비되지 않은 구간은 mock 구현으로, 기존 Türk Telekom 연동이 남은 구간은 tt4k 구현으로 전환할 수 있게 하기 위해서입니다(→ f05 서비스 인터페이스 추상화 참고).

핵심 코드

base/adapter/PlayerAdapter.kt — 계약: 상태는 전부 Observable
interface PlayerAdapter :
    PlayerViewLifecycleObserver, PlayerOwnerLifecycleObserver, PlayerViewLayoutChangeObserver
{
    val state: Observable<PlayerState>
    val currentState: PlayerState
    val position: Observable<Long>
    val videoTracks: Observable<List<TrackInfo>>

    fun play(uri: Uri, playPosition: Long = 0L, params: PlayParams? = null,
             callback: PlayResultCallback<PlayResultData>? = null)
    fun pause(params: PlayParams? = null, callback: PlayResultCallback<PlayResultData>? = null)
    fun setSpeed(playSpeed: Float)
    fun seek(playPosition: Long)
    fun release()
}
base/adapter/PlayerState.kt — 재생 중 여부를 계약 레벨에서 판정
enum class PlayerState {
    ON_READY, BUFFERING, PLAYING, PAUSED, STOPPED, FINISHED, RELEASED, ON_ERROR,
}

fun PlayerState.isNotPlaying(): Boolean =
    this == PlayerState.ON_READY || this == PlayerState.STOPPED ||
        this == PlayerState.FINISHED || this == PlayerState.RELEASED || this == PlayerState.ON_ERROR
