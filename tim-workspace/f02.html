기능 개요

LiveTvViewModel은 ChannelRepository/ProgramRepository(SI 계층)와 ChannelAdapter/ChannelPlayerAdapter(player 계층)를 함께 주입받아, 채널 목록·현재 프로그램·재생 상태(PlayerState)를 하나의 화면 상태로 합성합니다. 미니가이드(MiniGuideView)는 채널 링(ring) 탐색과 tuneMiniGuideChannel()/tunePreviousChannel()로 실제 튜닝을 트리거하고, 이미 같은 채널을 보고 있으면 재튜닝 없이 OSD만 다시 띄웁니다.

모자이크 채널(MosaicUseCase)은 여러 채널의 현재 프로그램을 RxJava3 Observable로 동시에 구독하되, distinctUntilChanged로 PPV·차단·스킵·구독 상태가 실제로 바뀔 때만 갱신합니다. 채널 OSD(ChannelOsdView)와 핑거프린트 워터마크(FingerPrintView·FingerPrintRepository)는 콘텐츠 보호·시청 경험을 위한 오버레이로 함께 그려지고, GPT 광고(GPTAdsController)도 이 화면 레벨에서 함께 제어됩니다.

설계 포인트 — 중복 튜닝 방지
미니가이드/이전채널 이동 모두 channelAdapter.getCurrentTuningChannelId()로 이미 그 채널을 재생 중인지 먼저 확인합니다. 같으면 channelAdapter.tune()을 호출하지 않고 OSD 표시(setOsdShowEvent)와 UI 상태 전환(LiveTvUiState.MiniGuide)만 수행해, 불필요한 재튜닝으로 인한 화면 끊김을 피합니다.

최근 커밋 구간(내비게이션 엔진 이관·v8.26 SI 확장·홈 UI 교체 등)은 ui/livetv 패키지 자체를 건드리지 않았습니다 — LiveTvViewModel.kt는 여전히 1,427줄로 동일하고, 아래 코드 스니펫도 최신 소스와 줄 단위로 일치함을 재확인했습니다. 다만 이 화면이 의존하는 ChannelAdapter/ChannelPlayerAdapter의 상위 재생 계층은 f03·f04에서 PlayHub 도입 등으로 재구성됐습니다.

핵심 코드

ui/livetv/LiveTvViewModel.kt — 중복 튜닝 방지 분기
fun tuneMiniGuideChannel() {
    val channelList = channelRepository.getChannelList()
    val currentMiniGuideChannel = channelList.firstOrNull { it.id == _miniGuideCurrentChannelId.value?.value }
    if (currentMiniGuideChannel != null) {
        val currentTuningChannelId = channelAdapter.getCurrentTuningChannelId()
        if (currentMiniGuideChannel.id == currentTuningChannelId) {
            setOsdShowEvent(true)
            setUiState(LiveTvUiState.MiniGuide)
        } else {
            channelAdapter.tune(channelId = currentMiniGuideChannel.id) {
                Timber.d("tuneMiniGuideChannel() tune result: $it")
            }
        }
    }
}
ui/livetv/mosaic/MosaicUseCase.kt — 모자이크 채널의 현재 프로그램 관찰
fun observeCurrentProgram(channelId: ChannelId): Observable<Pair<Channel?, Program?>> {
    return channelRepository.getChannelObservable(id = channelId)
        .distinctUntilChanged { prv, cur ->
            prv.value?.id == cur.value?.id &&
                prv.value?.isPPV == cur.value?.isPPV &&
                prv.value?.isBlocked == cur.value?.isBlocked &&
                prv.value?.isSkipped == cur.value?.isSkipped &&
                prv.value?.isSubscribed == cur.value?.isSubscribed
        }
        .flatMap { channelNullable ->
            programRepository.getCurrentProgramObservable(channelId)
                // 빈 프로그램이면 채널 prevue로 폴백— 생략
                .map { channelNullable.value to it.value }
        }
}
