기능 개요

PlatformFlavor enum(build-logic/convention)이 platform 단일 차원(dimension)에 플레이버를 등록합니다. "rename-tim-jade" PR을 거치며 tivibuEv 식별자가 jade로 바뀌었지만 applicationId = "tivibu.android.stb"·minSdk 26/targetSdk 36은 그대로입니다. stvOtt(com.ttnet.tivibutv)는 "tt4k 하드웨어가 없는 플랫폼"이라는 주석과 함께 dependency:platform:smarttv를 검증하기 위해 유지되고 있고, zteAosp(com.zte.aosp)는 "AOSP STB 대응이 확정되면 되살린다"는 주석을 남긴 채 enum 등록 자체가 주석 처리되어 비활성 상태입니다(소스 디렉터리 app/src/zteAosp는 그대로 남아 있습니다).

같은 파일에는 실험했다가 되돌린 흔적도 남아 있습니다 — server flavor dimension(ServerFlavor.staging/product)을 추가했다가 "복원이 필요하면 '[gradle] remove server flavor dimension' 커밋을 확인하라"는 주석과 함께 전체를 주석 처리로 되돌렸습니다. 서버 환경 전환은 대신 DomainConfig::serverType과 persist.sys.altimedia.build.type 시스템 프로퍼티로 처리합니다. :dependency:platform:tt4k 모듈도 :dependency:platform:jade로 개명되어(namespace = "com.altimedia.dependency.platform.jade") 이름 정리가 모듈 레벨까지 내려갔습니다.

레거시 연동은 걷어내는 방향 — AIDL·mzcast·런처 authority
"레거시 mzcast/TIM-OTA/런처 AIDL 연동 삭제" 커밋으로 app/build.gradle.kts의 androidComponents.beforeVariants staging 스위치와, tivibuEv(현 jade) 플레이버가 갖고 있던 manifestPlaceholders["launcherDataProviderAuthority"] 오버라이드가 함께 사라졌습니다. 기존 TT 런처와의 결합을 끊어내는 방향으로 정리가 진행 중임을 보여줍니다.

시퀀스 다이어그램

sequenceDiagram autonumber participant DEV as 빌드 명령 participant GR as Gradle (AGP) participant FL as PlatformFlavor participant EXT as configureFlavors() DEV->>GR: ./gradlew assembleJadeDebug (예) GR->>EXT: productFlavors 블록 평가 EXT->>FL: PlatformFlavor.values() 순회 — jade, stvOtt (zteAosp는 주석 처리돼 제외) FL-->>EXT: jade(applicationId=tivibu.android.stb, minSdk=26, targetSdk=36) EXT->>GR: applicationId/minSdk/targetSdk/versionName 적용 GR-->>DEV: 선택된 플레이버 조합만 빌드

흐름. PlatformFlavor enum 값이 그대로 Gradle productFlavors로 등록되며, zteAosp는 enum 자체가 주석 처리돼 있어 이 순회에 참여하지 않습니다. 과거 있던 stvOtt 전용 staging 변형 스위치(beforeVariants)는 레거시 연동 정리 과정에서 제거됐습니다.

클래스 다이어그램

관계. PlatformFlavor enum 하나가 Gradle 플레이버 등록의 유일한 원천이며, ServerFlavor라는 두 번째 차원을 시도했다가 되돌린 주석이 같은 파일에 나란히 남아 있습니다. tt4k 모듈은 jade로 개명됐습니다.

핵심 코드

build-logic/convention/.../Flavor.kt — jade 개명, zteAosp 비활성, ServerFlavor 실험 후 되돌림
@Suppress("EnumEntryName")
enum class FlavorDimension {
//    server,
    platform,
    ;
}

/**
 * system value 이용 (DomainConfig::serverType, "persist.sys.altimedia.build.type" 참고)
 * 복원이 필요한 경우 "[gradle] remove server flavor dimension" 커밋 확인
 */
//enum class ServerFlavor(val dimension: FlavorDimension, val isDefault: Boolean = false) {
//    staging(FlavorDimension.server),
//    product(FlavorDimension.server, true),
//    ;
//}

enum class PlatformFlavor(
    val dimension: FlavorDimension,
    val isDefault: Boolean = false,
    val key: String,
    val applicationId: String? = null,
    // Google Play 정책(2026.11.1 시한) 대응: jade flavor에 targetSdk 36 / minSdk 26 상향.
    // zteAosp 는 기존 값을 유지한다.
    val minSdk: Int? = null,
    val targetSdk: Int? = null,
) {
    jade(FlavorDimension.platform, true, key = "PLATFORM_JADE",
        applicationId = "tivibu.android.stb", minSdk = 26, targetSdk = 36),
    // tt4k 하드웨어가 없는 플랫폼이라 dependency:platform:smarttv 를 물린다.
    stvOtt(FlavorDimension.platform, key = "PLATFORM_STV_OTT",
        applicationId = "com.ttnet.tivibutv", minSdk = 26, targetSdk = 36),
    // zteAosp 비활성화 (2026-08-31). AOSP STB 대응이 확정되면 이 줄들을 되살린다.
//    zteAosp(FlavorDimension.platform, key = "PLATFORM_ZTE_AOSP", applicationId = "com.zte.aosp"),
    ;
}
